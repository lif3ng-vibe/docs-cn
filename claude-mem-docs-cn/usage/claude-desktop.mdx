<Note>
**可用范围**：claude-mem 的 MCP 工具可在 macOS 与 Windows 的 Claude Desktop 中使用。
</Note>

## 概览

Claude Desktop 可以通过 **MCP 工具**访问你的 claude-mem 记忆数据库，从而在 Claude Desktop 对话中直接检索此前的会话、决策与观察记录。

## 前置条件

配置 MCP 工具之前，请确保：

1. **claude-mem 已安装**，且 worker 服务正在运行
2. **MCP 服务器已在 Claude Desktop 中配置**（使用的是 `mcp-search` MCP 服务器）

### 确认 worker 正在运行

```bash
WORKER_PORT=$(jq -r .CLAUDE_MEM_WORKER_PORT ~/.claude-mem/settings.json)
curl http://127.0.0.1:$WORKER_PORT/api/health
# 应返回：{"status":"ok"}
```

## 安装步骤

### 第 1 步：配置 MCP 服务器

该 skill 依赖 `mcp-search` MCP 服务器。在 Claude Desktop 配置中加入以下内容：

<Tabs>
  <Tab title="macOS">
    编辑 `~/Library/Application Support/Claude/claude_desktop_config.json`：

    ```json
    {
      "mcpServers": {
        "mcp-search": {
          "command": "node",
          "args": [
            "/Users/YOUR_USERNAME/.claude/plugins/marketplaces/thedotmack/plugin/scripts/mcp-server.cjs"
          ]
        }
      }
    }
    ```
  </Tab>
  <Tab title="Windows">
    编辑 `%APPDATA%\Claude\claude_desktop_config.json`：

    ```json
    {
      "mcpServers": {
        "mcp-search": {
          "command": "node",
          "args": [
            "C:\\Users\\YOUR_USERNAME\\.claude\\plugins\\marketplaces\\thedotmack\\plugin\\scripts\\mcp-server.cjs"
          ]
        }
      }
    }
    ```
  </Tab>
</Tabs>

<Warning>
请将 `YOUR_USERNAME` 替换为你的实际用户名。编辑配置后需重启 Claude Desktop。
</Warning>

### 第 2 步：重启 Claude Desktop

关闭并重新打开 Claude Desktop，使 MCP 服务器配置生效。

## 用法

安装完成后，只要你问起过往的工作，该 skill 就会自动激活：

```
"What did we do last session?"
"Did we fix this bug before?"
"How did we implement authentication?"
"What decisions did we make about the API?"
"Show me changes to worker-service.ts"
```

## 可用的 MCP 工具

该 skill 提供三个核心 MCP 工具，遵循三层工作流模式：

| 工具 | 说明 |
|------|------|
| `search` | 检索记忆索引，返回带 ID 的紧凑结果，便于继续过滤 |
| `timeline` | 获取查询或观察记录 ID 周边的时序上下文 |
| `get_observations` | 按 ID 获取完整的观察记录详情（请先用 `search`/`timeline` 过滤，再行调用） |

### 省 token 的工作流

1. **`search`** → 获取带 ID 的索引（每条约耗 50-100 token）
2. **`timeline`** → 获取目标结果周边的上下文
3. **`get_observations`** → 仅对过滤后的 ID 拉取完整详情

与一步到位拉取完整详情相比，这一三层做法约可节省 10 倍 token。

## 故障排查

### 未出现 Skill

1. 确认该 zip 文件已正确安装
2. 查看 Claude Desktop 的 skill 安装日志
3. 重启 Claude Desktop

### MCP 服务器连接失败

1. 确认 worker 正在运行：`curl http://127.0.0.1:$WORKER_PORT/api/health`
2. 检查配置中的 MCP 服务器路径
3. 在 Claude Desktop 日志中查找错误

<Tabs>
  <Tab title="macOS">
    ```bash
    # 查看 Claude Desktop 日志
    tail -f ~/Library/Logs/Claude/claude.log
    ```
  </Tab>
  <Tab title="Windows">
    查看 `%APPDATA%\Claude\logs\`
  </Tab>
</Tabs>

### 检索无返回结果

1. 确保 claude-mem 已经记录过会话（可访问 http://127.0.0.1:$WORKER_PORT 检查）
2. 确认数据库存在：`ls ~/.claude-mem/claude-mem.db`
3. 直接测试 API：`curl "http://127.0.0.1:$WORKER_PORT/api/search?query=test"`
