## 设计特异性判定（先行结论）

**低——GitHub Primer 令牌逐字取用的通用聚合页模板，换成任何文档聚合站可原样上线。**
色板即 Primer（#0969da / #1f2328 / #d0d7de / #636c76），「6 主题色」是 6 个 GitHub 色相的浅 tint 变奏；PRODUCT.md 最锋利的四个差异化资产（AI 编码生态、终端文化命名、中英对照、快照同步机制）在视觉上零表达；项目名是终端世界的名字却用系统 UI 字体，等宽母题缺席；21 卡零 logo 零图形元素。

确定性扫描：48 条发现——47 条 cramped-padding 全部落在卡片标签胶囊 `.tag`（垂直内边距 ~1.6px，文字贴边，判真阳性），1 条 em-dash-overuse（建议级，35 处）。检测器抓到了设计评审未点名的一处：标签胶囊文字上下贴边。无头覆盖层仅报 em-dash（34 处，计数口径差 1）；覆盖层只在隔离子代理会话中存在，用户浏览器无注入。

## 情绪旅程

全程无峰：找到目标=点卡片开新标签，零确认感。三个谷底：0 结果空城页；多选筛选后 F5 全蒸发；移动端滚 4000px 后改筛选要滚回页顶。终点「GitHub · 非官方翻译」诚实但寒酸。信任安抚不一致：快照日期/页数只在部分 desc 散文里出现。

## 优点

1. **空交集预防（chips 动态置灰）**：15 标签多选取交集的高危模式被源头消灭，超模板水平的交互决策。
2. **约束遵从不牺牲质感**：零外部请求单文件里仍有 auto-animate 过渡、localStorage 预读防闪烁、白名单回落校验。
3. **设置系统克制且真实生效**：6 色×3 卡风×双语标签×3 显隐全部即时持久，为站点增长预留密度调节。

## 优先问题

1. **[P0] 主行动可供性倒置**：产品意义=整卡点击进中文文档，却是页面唯一无视觉线索的动作；「官方文档/仓库」两个离站出口反而是卡上最重的按钮。修法：主行显性化（hover 提示/箭头/底色），次按钮降级为弱化图标。→ /impeccable layout
2. **[P0] 空态死胡同 + 高亮模式静默**：空态仅一行灰字无恢复路径；高亮模式无命中完全静默。修法：空态加「清除搜索/清除全部筛选」+ 显示当前生效条件；高亮模式显示「N 处命中」。→ /impeccable harden
3. **[P1] 状态易失且不可分享**：筛选集与搜索词不入 URL、刷新即丢；卡无 id 锚点。修法：querystring 同步（?q=&tags=）+ popstate + 卡锚点。→ /impeccable harden
4. **[P1] 移动端首屏配比与拇指区**：390px 首屏约 48% 是 chrome；交互全钉页顶，无吸顶无返回顶部。修法：chips 折叠或单行滚动；吸顶迷你筛选摘要；返回顶部。→ /impeccable adapt
5. **[P2] 信任信号散文化 + 模板脸**：页数/快照/工具链埋在散文无法扫视；标签胶囊文字贴边（检测器实证 47 处）。修法：结构化元数据行（`916 页 · 快照 2026-10 · Mintlify`）；卡名等宽字体；内联 SVG 单字标；标签胶囊垂直内边距 ≥0.2rem。→ /impeccable typeset + /impeccable bolder

## 人格红旗

- **Jordan（首访者）**：视觉引导的第一次点击可能直接离站（官方文档/仓库）；副标题零差异化；target=_blank 无提示突然开新标签。
- **Riley（压力测试）**：0 结果死胡同（截图实证）；高亮模式无命中零反馈（代码路径确认）；刷新丢全部筛选；dialog 无「完成」钮、✕ 约 24px。Esc/焦点圈原生 dialog 通过——唯一全过项。
- **Casey（移动单手）**：chips ~28-30px、按钮 ~30px、✕ ~24px，全低于 44px 最佳实践；搜索筛选钉页顶拇指难及区。做对的：≤560px 块布局避免遮挡。
- **AI 工具链中文开发者（项目人格）**：搜索框 190px 缩右上角，⌘K 人群的第一公民被做成最小控件；项目名的终端气质零视觉回应；工具链类型（Starlight/Docusaurus/Mintlify）不可见；无单卡分享锚点。

## 次要观察

- desc 混入维护者向内部话语（"origin side for the CN compare pair" 等）；两张英文镜像卡 desc 纯英文。
- mark 高亮 22% accent 底色在 green/teal 主题偏淡，建议双通道（加深+下划线）。
- 标签字号 0.72rem（≈11.5px）对低视力偏小；无深色模式，6 主题全是浅色变奏。
- 卡名用 `<p>` 而非标题标签，读屏无法按标题导航。
- 搜索不含标签文本；「全部」chip 兼任清除语义含糊；无「已选 n 个标签」计数。
- 页脚可加「收录 21 站 · 更新于 2026-10」零成本信任增强。
- 文档漂移：PRODUCT.md 写「23+ 站点条目」，sites.json 实为 21 条，需订正。
