# 防护栏测试演练场

通过交互式演练场界面，实时测试并对比多个防护栏（guardrails）。

<Image img={require('../../../img/guardrail_playground.png')} alt="防护栏测试演练场" />

## 如何使用防护栏测试演练场

借助防护栏测试演练场，你可以用示例输入快速测试并对比不同防护栏的行为。

### 测试防护栏的步骤

1. **进入 Guardrails 版块**
   - 打开 LiteLLM 管理界面（Admin UI）
   - 进入 **Guardrails** 版块

2. **打开 Test Playground**
   - 点击页面顶部的 **Test Playground** 标签页

3. **选择要测试的防护栏**
   - 勾选你想对比的防护栏
   - 可以同时选中多个防护栏，观察它们对同一输入各自的响应

4. **输入测试内容**
   - 在文本框中输入或粘贴你的测试内容
   - 可以是一段提示词（prompt）、一条消息，或任何你想让防护栏检验的文本

5. **运行测试**
   - 点击 **Test guardrails** 按钮（或按 Enter 键）

6. **查看结果**
   - 查看每个所选防护栏的输出
   - 对比不同防护栏处理同一输入的方式
   - 结果会显示输入是通过了防护栏，还是被其拦截

## 适用场景

非常适合正在评估防护栏方案的**安全团队**与 **LiteLLM 管理员**。

这为 LiteLLM 用户带来以下收益：

- **对比防护栏响应**：同时在多个提供商（Lakera、Noma AI、Bedrock Guardrails 等）上测试同一提示词。

- **验证配置**：在部署到生产环境之前，确认你的防护栏能拦下你关心的威胁。
