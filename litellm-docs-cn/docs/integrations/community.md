# 成为集成合作伙伴

欢迎各位集成合作伙伴！👋

我们很高兴你能参与共建 LiteLLM。要开始上手并与 LiteLLM 社区建立联系：

## 获取支持并建立联系 {#get-support--connect}


加入 [Slack](https://litellmossslack.slack.com/) 或 [Discord](https://discord.com/invite/wuPM9dRgDw) 与社区建立联系，你可以和其他开发者交流，为你的集成获取帮助与反馈，并随时了解 LiteLLM 的最新进展。

## 我们为集成合作伙伴提供的支持

- 来自 LiteLLM 团队的**直接支持**
- 针对你集成实现的**反馈建议**
- 与不断壮大的 LLM 开发者社区**携手协作**
- 让你的集成在我们的文档中获得**曝光展示**

## 有疑问？

加入我们的 Slack 社区后，前往 **`#integration-partners`** 频道做个自我介绍并提出问题。我们的团队和社区成员很乐意帮助你基于 LiteLLM 构建出色的集成。

我们期待与你合作。
