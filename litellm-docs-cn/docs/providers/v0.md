# v0

## 概览

| 属性 | 说明 |
|-------|-------|
| 描述 | v0 提供针对代码生成优化的 AI 模型，尤其适合创建 Next.js 应用、React 组件以及现代 Web 开发。 |
| LiteLLM 中的提供商路由 | `v0/` |
| 提供商文档链接 | [v0 API 文档 ↗](https://v0.dev/docs/v0-model-api) |
| Base URL | `https://api.v0.dev/v1` |
| 支持的操作 | [`/chat/completions`](/docs/providers/v0#用法---litellm-python-sdk) |

<br />
<br />

https://v0.dev/docs/v0-model-api

**我们支持全部 v0 模型，发送补全（completion）请求时只需在模型名前加上 `v0/` 前缀**

## 可用模型

| 模型 | 说明 | 上下文窗口 | 最大输出 |
|-------|-------------|----------------|------------|
| `v0/v0-1.5-lg` | 面向高级代码生成与推理的大型模型 | 512,000 tokens | 512,000 tokens |
| `v0/v0-1.5-md` | 面向日常代码生成任务的中型模型 | 128,000 tokens | 128,000 tokens |
| `v0/v0-1.0-md` | 旧版中型模型 | 128,000 tokens | 128,000 tokens |

## 必需变量

```python showLineNumbers title="环境变量"
os.environ["V0_API_KEY"] = ""  # your v0 API key from v0.dev
```

注意：访问 v0 API 需要 Premium 或 Team 套餐。请访问 [v0.dev/chat/settings/billing](https://v0.dev/chat/settings/billing) 进行升级。

## 用法 - LiteLLM Python SDK

### 非流式

```python showLineNumbers title="v0 非流式补全"
import os
import litellm
from litellm import completion

os.environ["V0_API_KEY"] = ""  # your v0 API key

messages = [{"content": "Create a React button component with hover effects", "role": "user"}]

# v0 call
response = completion(
    model="v0/v0-1.5-md", 
    messages=messages
)

print(response)
```

### 流式

```python showLineNumbers title="v0 流式补全"
import os
import litellm
from litellm import completion

os.environ["V0_API_KEY"] = ""  # your v0 API key

messages = [{"content": "Create a React button component with hover effects", "role": "user"}]

# v0 call with streaming
response = completion(
    model="v0/v0-1.5-md", 
    messages=messages,
    stream=True
)

for chunk in response:
    print(chunk)
```

### 视觉/多模态支持

所有 v0 模型均支持视觉输入，可以在发送文字的同时附带图片：

```python showLineNumbers title="v0 视觉/多模态"
import os
import litellm
from litellm import completion

os.environ["V0_API_KEY"] = ""  # your v0 API key

messages = [{
    "role": "user",
    "content": [
        {
            "type": "text",
            "text": "Recreate this UI design in React"
        },
        {
            "type": "image_url",
            "image_url": {
                "url": "https://example.com/ui-design.png"
            }
        }
    ]
}]

response = completion(
    model="v0/v0-1.5-lg",
    messages=messages
)

print(response)
```

### 函数调用

v0 支持函数调用（function calling），可用于生成结构化输出：

```python showLineNumbers title="v0 函数调用"
import os
import litellm
from litellm import completion

os.environ["V0_API_KEY"] = ""  # your v0 API key

tools = [
    {
        "type": "function",
        "function": {
            "name": "create_component",
            "description": "Create a React component",
            "parameters": {
                "type": "object",
                "properties": {
                    "component_name": {
                        "type": "string",
                        "description": "The name of the component"
                    },
                    "props": {
                        "type": "array",
                        "items": {"type": "string"},
                        "description": "List of component props"
                    }
                },
                "required": ["component_name"]
            }
        }
    }
]

response = completion(
    model="v0/v0-1.5-md",
    messages=[{"role": "user", "content": "Create a Button component with onClick and disabled props"}],
    tools=tools,
    tool_choice="auto"
)

print(response)
```

## 用法 - LiteLLM 代理

将以下内容添加到 LiteLLM 代理配置文件中：

```yaml showLineNumbers title="config.yaml"
model_list:
  - model_name: v0-large
    litellm_params:
      model: v0/v0-1.5-lg
      api_key: os.environ/V0_API_KEY

  - model_name: v0-medium
    litellm_params:
      model: v0/v0-1.5-md
      api_key: os.environ/V0_API_KEY

  - model_name: v0-legacy
    litellm_params:
      model: v0/v0-1.0-md
      api_key: os.environ/V0_API_KEY
```

启动 LiteLLM 代理服务器：

```bash showLineNumbers title="启动 LiteLLM 代理"
litellm --config config.yaml

# RUNNING on http://0.0.0.0:4000
```

## 支持的 OpenAI 参数

v0 支持以下 OpenAI 兼容参数：

| 参数 | 类型 | 说明 |
|-----------|------|-------------|
| `messages` | array | **必填**。包含 'role' 与 'content' 的消息对象数组 |
| `model` | string | **必填**。模型 ID（v0-1.5-lg、v0-1.5-md、v0-1.0-md） |
| `stream` | boolean | 可选。启用流式响应 |
| `tools` | array | 可选。可用工具/函数列表 |
| `tool_choice` | string/object | 可选。控制工具/函数调用的行为 |

注意：与完整的 OpenAI API 相比，v0 支持的参数较为有限。`temperature`、`max_tokens`、`top_p` 等参数均不受支持。
