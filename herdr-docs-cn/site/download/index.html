下载 Herdr
免费且开源。

在 Mac 上直接下载，或在任意终端粘贴一行命令。无论哪种方式，你都会得到应用本身；如果还没有 herdr-core，它也会一并装好。之后，应用会自行更新。

下载 Mac 版 Apple silicon · 或从终端安装：
$ curl -fsSL https://releases.herdr.dev/app/install.sh | sh
$ powershell -c "irm https://releases.herdr.dev/app/install.ps1 | iex"
macOSApple silicon。下载 .dmg 并将 Herdr 拖入"应用程序"文件夹，或使用上面那行命令。
Linuxx86_64 与 arm64。会将 Herdr 添加到你的应用启动器。
Windowsx86_64。会在开始菜单中添加条目。
iPhone、iPad 与 Android在手机上查看哪些智能体需要你，并直接回应。它通过 SSH 连接你各台机器上的 herdr-core（不是 Herdr TUI）。进一步了解手机应用

接下来

  1. 打开 Herdr，在标签页栏点 + 启动一个智能体：Claude Code、Codex，或任意程序。
  2. 把智能体指向它的指南。 ~/.config/herdr-app/AGENTS.md 会告诉它能改动的一切。
  3. 说出你想要的样子。一块看板、每个标签页一个计时器，或者换一种外观。也可以挑一个别人做好的。
