Tab numbers

Herdr's own tab bar, with each tab's shortcut number in a small badge before its icon: 1, 2, 3, so you can see which Ctrl+<n> reaches which tab. The number is drawn, not part of the tab's name, so names elsewhere (the agents list) don't change.
