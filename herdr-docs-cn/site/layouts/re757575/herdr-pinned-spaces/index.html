和內建 main 一樣的雙欄視窗，多了「釘選 space」：左側 spaces 清單中，被釘選的 space 名稱旁有一顆圖釘；被釘選的 space 擋掉會讓整個 space 消失的關閉操作（cmd-w、右鍵 Close、指令面板的關閉項目）。釘選用右鍵選單或 cmd-shift-k 切換。它是防誤觸，不是鎖。
