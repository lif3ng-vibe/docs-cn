Plans

Herdr's default window with a third side panel, Plans, beside Files and Changes. It shows the spec-driven plans of the shown space's repo (docs/plans/.plan.md, the format /start-planning writes): each plan's status, a progress bar, its tickets with their state, and the Herdr agents working on them. ↗ on a plan opens the plan file in the Files panel.
