隐私

Herdr 运行在你自己的机器上，所以这里其实没什么可多说的。本页说明 Herdr 桌面应用、iOS 与 Android 版 Herdr 应用以及 herdr.dev 会向 Herdr, Inc. 发送哪些数据，以及我们会保留哪些。

##移动应用

应用只通过 SSH 与你添加的机器通信。你的终端数据只在手机与你的机器之间往返，绝不经过我们。没有登录、没有广告、没有追踪，也没有统计分析。

听写功能在你手机上本地运行。如果你改用 Apple 或 Google 的语音引擎，则适用它们各自的隐私政策。语音模型会从 huggingface.co 和 github.com 一次性下载。

听写时应用会请求麦克风权限；附加图片时会请求访问你的照片或相机。随消息附加的图片只会发往你自己的机器，随反馈附加的图片才会发给我们。

##反馈

当你在反馈表单中按下发送时（手机端或桌面端皆然），我们会收到你的留言、你填写的邮箱（如有）、你附加的截图，以及应用版本、系统、设备类型和 herdr-core 版本。我们用这些信息来修复问题并回复你。请不要把机密信息放进截图里。

##桌面应用

桌面应用每天发送一份匿名使用报告，内容为固定清单内的计数与名称，比如你使用了哪些智能体和布局、打开了多少个标签页。它绝不会发送终端内容、文件名或提示词。你可以在设置中将其关闭。

这款应用是开源的，你可以在仓库中确切核对它发送了什么。

当 releases.herdr.dev 提供下载时，我们会统计版本、平台和国家。

##herdr.dev

网站由 Cloudflare 托管，它会看到常规的请求数据。

##我们会保留什么

使用报告保留 3 个月；反馈则保留到我们处理完毕，或你要求我们删除为止。我们不存储 IP 地址，也不出售或共享其中任何数据。这些数据由 Cloudflare 为我们托管。

如需删除某些数据，请发邮件至 [email protected] 并告诉我们是什么数据。
