##看看谁需要你

每个智能体都会告诉 Herdr 自己是在工作、已完成，还是在等你。侧边栏和标签页会标出谁在需要你，其余的就不必挨个查看了。

每个仓库用一个空间，每个任务用一个标签页。

##关掉应用，它们照常工作

你的智能体运行在 herdr-core——一个跑在你机器上的小型服务——而不是窗口里。退出应用、升级它，甚至任由它崩溃，每个终端都还在你离开时的位置。

##所有机器汇聚一个侧边栏
 
添加任何能通过 SSH 访问的机器，比如一台服务器、虚拟机或云端沙箱。它的空间和智能体会出现在同一个侧边栏里、归在它的名字下，你在那里启动智能体的方式也一模一样。
  
# 或者直接问你的智能体："add my server vps"
hc machine add vps
 
在你的笔记本休眠或应用关闭期间，那里的智能体会一直运行。
 
 
 
##什么都能改
 
Herdr 把自己的布局、侧边栏、标签页、快捷键和主题都存成 ~/.config/herdr-app 下的纯文本文件。里面的一份 AGENTS.md 会向你的智能体解释它们的用处。你说出想要什么，智能体来动手写。
 
~/.config/herdr-app/
├── AGENTS.md        what your agent can change
├── settings.json    fonts, theme, sounds
├── keys.json
├── layouts/
│   ├── main.json
│   └── board.json
├── mods/
│   ├── agents/main.js
│   └── tabs/main.js
└── themes/
 
❯ put a timer on each tab: how long its agent has been working

⏺ Update(mods/tabs/main.js)
  ⎿  Updated mods/tabs/main.js with 6 additions and 1 removal

⏺ Done. Each tab shows how long its agent has been at it.
 
   
 
 
 
##任何智能体都行
 
Herdr 运行的是真正的终端，所以你的智能体照现在的方式用就行。支持 OSC 7501（一个开放的状态协议）的智能体，还能显示自己是在工作、已完成，还是需要你。你自己的脚本只要一行代码也能做到。
 
# 一行代码，你自己的脚本也能成为智能体
printf '\e]7501;state=blocked:app=my-agent\e\\'

##常见问题
 
 Herdr 是什么？ 
一款用于运行编码智能体的原生应用。智能体运行在 herdr-core 里，所以你关掉窗口它们也照常运行，而且你的智能体可以改变这个应用的任何部分。
 
 
 它和 Herdr TUI 有什么不同？ 
Herdr TUI 是最早的 Herdr：一个自带服务器的终端应用。这是基于 herdr-core 全新构建的独立程序。两者不共享智能体，一边运行的不会出现在另一边。Herdr TUI 依然可用，它的一切资料都在 herdr.dev/tui。
 
 
 它支持哪些智能体？ 
只要能在终端里运行就行。会说 OSC 7501（一个开放的状态上报协议）的智能体，还能显示自己是在工作、已完成，还是需要你。不会说这个协议的智能体照样能跑，只是没有状态可显示。
 
 
 我的智能体没出现在智能体列表里 
这个列表只显示通过 OSC 7501 上报状态的智能体，所以请检查以下几点：
 
     
  • 旧版本的智能体可能还不支持上报。请把智能体升级到新版。
    •  
  • 在 Herdr 内的 tmux 里运行的智能体无法透过 tmux 上报。请直接在 Herdr 窗格里运行它。
    •  
  • 在 Herdr TUI 里启动的智能体运行在它自己的服务器里，所以不会出现在这个应用中。
    •  
 
 
 退出、升级或重启之后会发生什么？ 
退出或升级应用不会有任何影响：每个智能体都在 herdr-core 里继续运行。如果机器重启或 herdr-core 停止，里面的程序也会停下。它们的窗格会恢复，并在原来的文件夹里打开一个 shell，但 Herdr 不会重启智能体，也不会接续它做到一半的工作。重新启动它，接着干就行。
 
 
 它支持哪些系统？ 
macOS（Apple 芯片）、Linux（x86_64 和 arm64）和 Windows（x86_64）。其他机器可以通过 SSH 接入，不管它们跑的是什么系统。手机端：iPhone、iPad 和 Android，可从 App Store 和 Google Play 下载。
 
 
 它是免费的吗？ 
是的。应用、herdr-core 和 Herdr TUI 全部开源。
