指南
直接问你的智能体。

Herdr 能做的每一件事都写在应用内的指南里，供你的智能体（agent）随时查阅，且始终与你手头的版本一致。这些内容全部开源，需要了解更多时，你的智能体可以直接去读代码。

##开始使用

  1. 安装 Herdr。一条命令搞定，见下载页。
  2. 从标签页栏的 + 启动一个智能体：Claude Code、Codex，或任意程序。
  3. 让它读这份指南。教程到这就完了。
❯ Read ~/.config/herdr-app/AGENTS.md

之后想要什么，直接开口。做得到的，你的智能体自会知道怎么做；做不到的，它会告诉你原因。

##可以这样问

这些提示词都实测有效。可以直接照用，也可以当作起点。

你的智能体看板

❯

给我做一个布局（layout），把我的智能体摆成几列卡片：需要你、工作中、已完成。

你的布局旁边多出一个新布局，按 ctrl-shift-l 即可在两者之间切换。

每个标签页都有一个计时器

❯

给每个标签页（tab）加一个计时器：显示它的智能体已经工作了多久。

你的智能体会克隆一份标签页栏，然后在克隆的那份上动手改，Herdr 原有的原封不动。

把你的服务器放进侧边栏

❯

把我的服务器加为一台机器（machine），然后在那边开一个空间（space），在里面启动 Claude。

那台机器上的智能体会与这台电脑的智能体出现在同一列表里。

会回报结果的审查者

❯

在这个分支上启动一个审查者，告诉我它发现了什么。

它是你智能体手下的一名辅助智能体（helper）。它自己干活、回报结果，由你的智能体汇总。

每个 issue 一个 worktree

❯

为 issue 42 开一个 worktree，让 Codex 在里面开工，任务就用这个 issue。

为该分支新建一个空间，嵌在所属仓库之下，智能体已经就位开工。

你的外观

❯

改用浅色主题，字体用 15 号 Geist Mono，智能体需要我时的提示音换柔和一点。

在每个未锁定这些设置的布局里，你的设置都会随之生效。

手机上的一声提醒

❯

当有智能体需要我时，用 ntfy 给我的手机发一条通知。

一个小小的 mod（功能扩展），负责盯着智能体并调用 ntfy.sh。

别人家的布局

❯

读一下 ~/.config/herdr-app/AGENTS.md，然后添加这个布局：herdr.dev/layouts/herdrdev/pasture

你的智能体会先把每个文件读一遍，把布局加在你的旁边，然后切换过去。

别人家的 mod

❯

读一下 ~/.config/herdr-app/AGENTS.md，然后添加这个 mod：herdr.dev/mods/herdrdev/tmux-prefix

你的智能体会先把每个文件读一遍，把 mod 及其按键绑定加在你的配置旁边。

##继续深入

  • 你的智能体读的那份指南 →所有命令、文件与设置。为智能体而写，人也能读。
  • 源码 →应用本体、herdr-core 和每一个 mod。永远比任何手册都更新。
  • 布局 →大家做出了什么，又是怎么做出来的。
  • 单独使用 herdr-core →面向服务器、脚本和你自己的客户端。智能体去读 hc --skill。
  • Discord →提问、出主意，晒出你的作品。
