一个月前，我们开源了 **Astryx**——一个代码优先、AI 友好的 React + StyleX 设计系统，在 Meta 内部构建和打磨了八年。目标：给每一位构建者——无论人还是智能体（agent）——一个完全可定制、生产级、且对如今编写大部分 UI 的工具清晰可读的设计系统。一个月过去，早期信号表明这个押注得到了回应。

## 数字里的第一个月

- **GitHub**：10.3K stars · 758 forks · 发布周一度登上 GitHub Trending 全仓库榜第 2
- **npm**：@astryxdesign/core 190K · cli 126K · themes 480K，分布在这 7 套主题上
- **[astryx.atmeta.com](http://astryx.atmeta.com/)**：224K 访客 · 179 万次页面浏览
- **社区贡献**：87 人提交过 PR · 61 位作者向全部分支推了 815 个 commit

## 用 Astryx 构建

第一个月内就有真实项目在 Astryx 上交付：从一家[在发布数小时内重建了整个网站](https://moonveil.ai/)的公司，到一批不断增长、现已投入生产的社区站点。

![用 Astryx 构建的网站与产品界面拼贴](/blog/one-month-of-astryx/community-showcase.png)

## 社区告诉我们的

讨论汇聚在 Astryx 的差异化所在：CLI、MCP 服务器与智能体优先的架构：

- Dominic Nguyen（Chromatic 与 Storybook 创始人）在一篇帖子中把 Astryx 描述为"**一个由智能体创造大多数 UI 的世界的基础设施**"，该帖成为全网互动量最高的 Astryx 相关提及（[链接](https://www.linkedin.com/posts/domyen_meta-just-open-sourced-a-design-system-theyve-share-7478518968098529280-R3p4/)）。
- Aurora Scharff（React/Vercel 工程师）对 Astryx 站点做了性能画像，通过一次 Cache Components 迁移，让导航**感觉即时、最快提升 3 倍**（[链接](https://x.com/aurorascharff/status/2078110561640845708)）。
- Yangshun Tay（GreatFrontEnd 联合创始人）称 Astryx 是"**正确打开方式的 Tokenmaxxing**"，称赞其庞大的组件集（包括 agentic UI）、灵活的 CSS 变量主题定制与 AI 友好的 CLI（[链接](https://www.linkedin.com/posts/yangshun_meta-just-released-a-new-frontend-open-source-ugcPost-7477245799542837248-pcwN/)）。
- 数日之内，独立的源码级分析自发出现在[日语](https://x.com/wataryooou/status/2070445582993244377)、[韩语](https://x.com/ngnicky/status/2074380595078258779)和[中文](https://m.sohu.com/a/1042830838_120333371)开发者社区。
- 社区正在反哺：从 Figma 映射工作到与我们一起深挖 MCP 内部实现的开发者，社区主导的主题与翻译势头也在增长。

## 我们要去的方向

发布是起点，不是终点。我们当下的重点是质量与深度：加固组件、扩充主题与模板、收紧 AI 创作闭环（vibe tests + design-judge），并让外部贡献者更轻松地与我们共建。社区贡献从现在起是一等输入。

## 致谢

致每一个 star、转发、提 issue、交 PR 的人：谢谢你们。Astryx 因你而更好，而我们才刚刚上路。
