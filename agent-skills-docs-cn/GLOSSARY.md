# Agent Skills 中文文档术语表（翻译统一口径）

延续 [[mattpocock-skills-docs-cn]] 的译名基准：agent → 智能体、spec → 规格（spec）、code review → 代码评审、feedback loop → 反馈回路、token/TDD/MCP/PR 不译。

## 不译名单（保留英文原词）

| 英文 | 处理 |
|---|---|
| /spec /plan /build /test /review /webperf /code-simplify /ship | 斜杠命令名一律不译 |
| SKILL.md、CLAUDE.md、AGENTS.md、CONTEXT.md | 文件名不译 |
| frontmatter | 不译，首现可注「frontmatter（元数据头）」 |
| Claude Code、Codex、Cursor、Antigravity、Windsurf、Gemini CLI、OpenCode、Copilot | 产品名不译 |
| npm、npx、git、Node、GitHub、localStorage | 工具/命令不译 |
| agent-skills | 项目名不译 |
| evals / evals framework | 不译，首现注「评估套件（evals）」 |
| fixture | 不译（测试夹具），按语境译「测试样例」时注原词一次 |
| PPTX | 不译 |
| Geist、Geist Mono | 字体名不译 |
