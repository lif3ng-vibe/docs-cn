## 导航与搜索

这些工具把页面装入浏览器。

| 工具 | 摘要 |
|---|---|
| [`goto`](#goto) | 打开 URL 并将页面保留在内存中 |
| [`search`](#search) | 网页搜索，结果以 markdown 返回 |

### goto

把当前页面导航到某个 URL。`waitUntil` 事件触发（默认 `load`）后返回 HTTP 状态码，或返回超时提示；4xx 或 5xx 说明拿到的是错误页而非内容——继续阅读前先检查；加载后由 JavaScript 渲染的内容此时可能尚未出现（见 `waitForState`）。页面会保持加载状态，供后续读取和操作。想一次调用完成导航加读取，可直接给 `markdown`、`tree` 或 `html` 传 `url`；当下一步是操作或 `extract` 时用 `goto`。

| 参数 | 类型 | 必填 | 描述 |
|---|---|---|---|
| `url` | string | yes | 要导航到的 URL，必须是合法 URL。 |
| `timeout` | integer | no | 可选超时时间，单位毫秒。默认 10000。 |
| `waitUntil` | string | no | 标志导航完成的事件。默认 'load'。当页面的晚期脚本（广告）拖住 'load' 事件时，建议用 'domcontentloaded' 配合 waitForSelector。避免 'done'（完全静止）：对后台持续活动的页面它是最慢的选择，且可能一直跑到超时。取值：`load`、`domcontentloaded`、`networkalmostidle`、`networkidle`、`done`。 |

记录到已保存脚本。返回结果页面状态（`url`、`httpStatus`、`title`）。

### search

执行网页搜索并以 markdown 返回结果：\{title, url, snippet\} 组成的编号列表。搜索按 brave、tavily、exa、keenable 的顺序尝试，各自的 API key（BRAVE_API_KEY、TAVILY_API_KEY、EXA_API_KEY 或 KEENABLE_API_KEY）设置了才启用；keenable 没有密钥也可通过公共端点使用（按客户端 IP 限流）。尽量用它，而不是直接 goto 到 google.com/search（Google 会按 User-Agent/TLS 拦截浏览器）。浏览器不会真正导航——要打开某条结果，用其 URL 调 `goto`。

| 参数 | 类型 | 必填 | 描述 |
|---|---|---|---|
| `query` | string | yes | 搜索关键词。 |
| `timeout` | integer | no | 可选超时时间，单位毫秒。默认 10000。 |

### markdown

把页面（或子树）渲染为 markdown。用 `selector` 或 `backendNodeId` 圈定范围，只读相关区域——整页 markdown 是最后手段。用 `maxBytes` 截断长页。

| 参数 | 类型 | 必填 | 描述 |
|---|---|---|---|
| `selector` | string | no | 可选 CSS 选择器。只为该元素的子树渲染 markdown。 |
| `backendNodeId` | integer | no | 可选后端节点 ID。只为该节点的子树渲染 markdown。0 视为未传。 |
| `maxBytes` | integer | no | 可选的输出大小软上限（字节）。超限内容在 UTF-8 边界处截断，并追加一个简短的 '[truncated]' 标记。 |
| `strip` | object | no | 可选。从输出中省略某些元素分组；分组与 html 工具的 strip 相同。读内容时关键是 `shell`（按标记识别的页面外壳）和 `clutter`（只保留主内容，类似阅读模式）；`ui` 还会去掉图片。可选键：`js`、`css`、`ui`、`invisible`、`shell`、`clutter`。 |
| `url` | string | no | 可选 URL，渲染前先导航过去。空字符串视为未传。 |
| `timeout` | integer | no | 可选超时时间，单位毫秒。默认 10000。 |

传入 `url` 时先导航。

| `selector` | string | no | 可选 CSS 选择器。设置后只输出该元素的 outerHTML。 |
| `backendNodeId` | integer | no | 可选后端节点 ID。设置后只输出该节点的 outerHTML。0 视为未传。 |
| `maxBytes` | integer | no | 可选的输出大小软上限（字节）。超限内容在 UTF-8 边界处截断，并追加一个简短的 '[truncated]' 标记。 |
| `strip` | object | no | 可选。从输出中省略某些元素分组：`js`（script、noscript、script 预加载）、`css`（style、样式表链接）、`ui`（css 加 img、picture、video、audio、svg、canvas、iframe）、`invisible`（被作者样式规则或内联样式设为 display:none 的元素）、`shell`（nav、aside、dialog、页面级页眉/页脚及对应的 landmark role；若会丢掉大部分正文则跳过）、`clutter`（只保留主内容，类似阅读模式；包含 `shell` 与 `invisible`，捡得太少时回退为 `shell`）。\{"js":true,"css":true\} 能让页面输出显著变小。可选键：`js`、`css`、`ui`、`invisible`、`shell`、`clutter`。 |
| `url` | string | no | 可选 URL，输出前先导航过去。空字符串视为未传。 |
| `timeout` | integer | no | 可选超时时间，单位毫秒。默认 10000。 |

### tree

页面的语义大纲，缩进文本形式：每行一个节点，含 role、可访问名称、值与 backendNodeId，另带勾选状态与下拉选项（选中项有标记）。面对陌生页面的默认首选读取方式；input 与 select 的值已包含在内，无需再调 `nodeDetails` 读取。传 `backendNodeId` 可圈定子树，传 `maxDepth` 可先纵览结构再深入。任何改变页面的操作之后都要重新读取，因为它描述的 DOM 可能已变化；用 `nodeDetails` 把 backendNodeId 转成可用于操作的 CSS 选择器。

| 参数 | 类型 | 必填 | 描述 |
|---|---|---|---|
| `url` | string | no | 可选 URL，抓取语义树前先导航过去。空字符串视为未传。 |
| `timeout` | integer | no | 可选超时时间，单位毫秒。默认 10000。 |
| `backendNodeId` | integer | no | 可选后端节点 ID，传了就返回该元素的树而不是文档根的树。0 视为未传。 |
| `maxDepth` | integer | no | 可选返回树的最大深度。适合先探索高层结构。 |
| `maxBytes` | integer | no | 可选输出大小上限（字节）。超限后按优先级保留行（告警、对话框、非法字段与焦点元素优先，其次是控件与有名称的节点，再是文本；列表项按广度优先），被丢弃的行计入 '[+N more @id]' 标记。id 是承载这些行的节点的 backendNodeId，通常是不打印自身的列表项或列表：传 backendNodeId=id 调 tree 即可读取。 |

传入 `url` 时先导航。

## 数据提取与脚本

这些工具从已加载的页面返回结构化结果。

| 工具 | 摘要 |

### evaluate

在当前页面上下文里执行 JavaScript——专用工具表达不了的页面侧逻辑用它兜底；取数据优先 `extract`，做操作优先 click/fill 等。它运行在页面里，看不到 agent 脚本的变量或内置对象——任何值都要插值进 `script` 字符串。裸的末尾表达式会返回其值；支持顶层 `await` 与 `return`（此时主体作为 async 函数运行，用 `return` 产出值）。对象和数组以 JSON 返回，无需 `JSON.stringify`。提供 url 时先导航过去。`globalThis.lp` 对象是一个 Session 级桥接存储：`lp.foo = ...` 写入的值会在 evaluate 结束时自动同步，导航后仍在；此前经 `/extract save=` 或 `/evaluate save=` 设置的值以 `lp.<名称>` 出现。

| 参数 | 类型 | 必填 | 描述 |
|---|---|---|---|
| `script` | string | yes | 在页面上下文执行的 JavaScript。裸的末尾表达式，或带顶层 `await` 的 `return`，即为结果。 |
| `url` | string | no | 可选 URL，执行前先导航过去。空字符串视为未传。 |
| `timeout` | integer | no | 可选超时时间，单位毫秒。默认 10000。 |
| `save` | string | no | 可选桥接存储键。evaluate 的返回值存为该名字，并在后续 evaluate 中以 `lp.<名称>` 重新暴露。对象、数组与字符串自动序列化——无需 JSON.stringify。 |

记录到已保存脚本。

### extract

从当前页面提取结构化数据（先导航）。`schema` 是一个 JSON 对象（以字符串传入），把输出字段名映射到 CSS 选择器规格。它不是 JSON Schema——没有 "type"/"properties" 包装；键就是你的输出字段。取值形态：
```text
"<sel>"                                → 首个匹配的文本（去空白；无匹配为 null）
["<sel>"]                              → 全部匹配的文本（string[]）
{"selector":"<sel>","attr":"<name>"}   → 首个匹配的属性值（href/src 解析为绝对 URL）
[{"selector":"<sel>","attr":"<name>"}] → 全部匹配的属性（string[]）
[{"selector":"<sel>","fields":{…}}]    → 每个匹配一个对象；字段选择器相对该匹配解析，可用上述任意形态（"" = 匹配自身文本；嵌套数组可做每项子列表）
```
在任何数组的对象规格里加 "limit": N 可限制匹配数。
每个提取值都是字符串或 null——数字请下游解析。空数组是合法结果；但若所有顶层键都落空，调用会报错：先检查页面（tree/markdown），修正选择器后重试。
数据类任务用 extract 收尾——它是唯一会被记录为可回放 `extract(...)` 脚本调用的读取操作；从聊天里 `markdown` 文本摘出来的答案不算。

示例（schema → 结果）：
```text
{"karma": "#karma"} → {"karma":"42"}
{"items": [".story .title"]} → {"items":["Title 1","Title 2"]}
{"top3": [{"selector":".story .title","limit":3}]} → {"top3":["A","B","C"]}
{"links": [{"selector":"a.title","attr":"href"}]} → {"links":["https://site/a","https://site/b"]}
{"stories": [{"selector":".athing","fields":{"title":".titleline","rank":".rank"}}]} → {"stories":[{"title":"Foo","rank":"1"}]}
```

| 参数 | 类型 | 必填 | 描述 |
|---|---|---|---|
| `schema` | string | yes | 以字符串传入的提取 schema：把输出字段名映射到 CSS 选择器规格的 JSON 对象字面量（见工具描述）。不是 JSON Schema。 |
| `save` | string | no | 可选桥接存储键。提取出的 JSON 存为该名字，并在后续 /evaluate 调用中以 `lp.<名称>` 暴露。 |

记录到已保存脚本。

### scroll

把窗口或某个元素的滚动容器滚到绝对位置；省略某轴则保持该轴当前偏移。用 CSS 选择器（可回放性更好）或 backendNodeId 定位元素；都不传则滚动窗口。页面脚本会收到 `scroll` 事件，随滚动加载的内容（无限信息流、懒加载列表）可能出现：之后请重新读取页面，若仍在加载则配合 `waitForState`。返回最终滚动位置以及当前页面 URL 与标题。

| 参数 | 类型 | 必填 | 描述 |
|---|---|---|---|
| `selector` | string | no | 可选：要滚动元素的 CSS 选择器。优先于 backendNodeId。若元素本身不是滚动容器，则滚动其最近的可滚动祖先。 |
| `backendNodeId` | integer | no | 可选：要滚动元素的后端节点 ID。若元素本身不是滚动容器，则滚动其最近的可滚动祖先。两者都不传（或为 0）时滚动窗口。 |
| `x` | integer | no | 可选：水平滚动偏移。 |
| `y` | integer | no | 可选：垂直滚动偏移。 |

记录到已保存脚本。返回结果页面状态（`url`、`httpStatus`、`title`）。

### hover

悬停在元素上，触发 mouseover 与 mouseenter 事件。传 CSS 选择器（可回放性更好）或 backendNodeId 二选一。适合菜单、工具提示与悬停态。

| 参数 | 类型 | 必填 | 描述 |
|---|---|---|---|
| `selector` | string | no | 要悬停元素的 CSS 选择器。优先于 backendNodeId。 |
| `backendNodeId` | integer | no | 要悬停元素的后端节点 ID。 |

记录到已保存脚本。返回结果页面状态（`url`、`httpStatus`、`title`）。

### press

按下键盘按键，派发 keydown 与 keyup 事件。键名如 'Enter'、'Tab'、'Escape'、'ArrowDown'、'Backspace'，或单字符如 'a'、'1'。常见简写会自动归一：'enter'/'return' → 'Enter'，'esc' → 'Escape'，'up'/'down'/'left'/'right' → 'Arrow*'，'space' → ' '。在表单输入框或提交按钮上按 'Enter' 会触发表单隐式提交。

| 参数 | 类型 | 必填 | 描述 |
|---|---|---|---|
| `key` | string | yes | 要按的键（如 'Enter'、'Tab'、'a'）。 |
| `selector` | string | no | 可选目标元素的 CSS 选择器。优先于 backendNodeId。 |
| `backendNodeId` | integer | no | 可选目标元素的后端节点 ID。selector 与 backendNodeId 都不传时默认作用于 document；0 视为未传。 |

记录到已保存脚本。返回结果页面状态（`url`、`httpStatus`、`title`）。

### selectOption

在 &lt;select> 下拉元素中按 value 选中一项。传 CSS 选择器（可回放性更好）或 backendNodeId 二选一。会派发 input 与 change 事件。

| 参数 | 类型 | 必填 | 描述 |
|---|---|---|---|
| `selector` | string | no | &lt;select> 元素的 CSS 选择器。优先于 backendNodeId。 |
| `backendNodeId` | integer | no | &lt;select> 元素的后端节点 ID。 |
| `value` | string | yes | 要选中的选项 value。 |

记录到已保存脚本。返回结果页面状态（`url`、`httpStatus`、`title`）。

### setChecked

勾选或取消勾选复选框/单选按钮。传 CSS 选择器（可回放性更好）或 backendNodeId 二选一。会派发 input、change 与 click 事件。

| 参数 | 类型 | 必填 | 描述 |
|---|---|---|---|
| `selector` | string | no | 复选框或单选输入元素的 CSS 选择器。优先于 backendNodeId。 |
| `backendNodeId` | integer | no | 复选框或单选输入元素的后端节点 ID。 |
| `checked` | boolean | yes | true 为勾选，false 为取消。默认 `true`。 |

记录到已保存脚本。返回结果页面状态（`url`、`httpStatus`、`title`）。

## 等待

这些工具阻塞到页面满足某个条件为止。

| 工具 | 摘要 |
|---|---|
| [`waitForSelector`](#waitforselector) | 等待元素出现 |
| [`waitForScript`](#waitforscript) | 等到 JS 表达式为真 |
| [`waitForState`](#waitforstate) | 等页面达到某加载状态 |

### waitForSelector

等待匹配 CSS 选择器的元素出现在页面中。返回匹配元素的后端节点 ID。

| 参数 | 类型 | 必填 | 描述 |
|---|---|---|---|
| `selector` | string | yes | 要等待的 CSS 选择器。 |
| `timeout` | integer | no | 可选超时时间，单位毫秒。默认 5000；页面尚未到达 'load' 时默认 15000。 |

记录到已保存脚本。

### waitForScript

等到某个 JS 表达式返回真值。事件循环每 tick 重新求值。用于 CSS 选择器表达不了的同步场景——例如 `window.dataLoaded === true`、`document.readyState === 'complete'`、`document.querySelectorAll('.row').length >= 5`。

| 参数 | 类型 | 必填 | 描述 |
|---|---|---|---|
| `script` | string | yes | 每个 tick 求值直到为真的 JS 表达式。必须是表达式（不能是语句）。 |
| `timeout` | integer | no | 可选超时时间，单位毫秒。默认 5000；页面尚未到达 'load' 时默认 15000。 |

记录到已保存脚本。

### waitForState

等待当前页面达到某加载状态（不导航）。`goto` 之后页面以快速的 `load` 快照返回，加载后由 JS 渲染的内容（XHR 加载的列表、信息流、搜索结果）可能还没出现。当一次读取看起来不完整——空列表、转圈、骨架屏——用 'networkidle' 调这个工具然后重新读取。优先 'networkidle'；后台持续活动的站点（广告、轮询）用 'done' 会很慢。

| 参数 | 类型 | 必填 | 描述 |
|---|---|---|---|
| `state` | string | yes | 要等待的加载状态。'networkidle' = 网络已平稳（收尾动态页面的常规选择）。取值：`load`、`domcontentloaded`、`networkalmostidle`、`networkidle`、`done`。 |
| `timeout` | integer | no | 可选超时时间，单位毫秒。默认 5000。 |

记录到已保存脚本。

## 状态与调试

这些工具检查 DOM 之外的浏览器状态。

| 工具 | 摘要 |
|---|---|
| [`consoleLogs`](#consolelogs) | 读取缓冲的控制台消息 |
| [`getUrl`](#geturl) | 显示当前页面 URL |
| [`getCookies`](#getcookies) | 显示已存储的 Cookie |
| [`getEnv`](#getenv) | 读取或列出 LP_* 环境变量 |

### consoleLogs

获取当前页面缓冲的 console.log/warn/error 消息。返回自上次调用以来的全部消息并清空缓冲区。

无参数。

### getUrl

当前页面 URL。浏览器里可能已加载了一个本次对话不可见的页面（命令、回放的脚本）——当用户提到"当前页面/站点"时，先调它再假设什么都没加载。也可用来验证导航或检测重定向。

无参数。

### getCookies

浏览器中存储的 Cookie。默认返回域名匹配当前页面主机的 Cookie。传 `url=<URL>` 按其他主机过滤，或 `all=true` 无视主机导出全部。调试鉴权与会话状态时有用。

| 参数 | 类型 | 必填 | 描述 |
|---|---|---|---|
| `url` | string | no | 只输出匹配该 URL 主机的 Cookie。默认当前页面。空字符串视为未传。 |
| `all` | boolean | no | true 时无视主机导出全部 Cookie。优先于 `url`。默认 `false`。 |

### getEnv

传 `name`：读取一个 LP_* 环境变量（其他命名空间一律报未设置）——仅用于非敏感配置（基础 URL、开关）。不传 `name`：列出已设置的 LP_* 名字（不含值）——安全的凭据探测。涉密请用 `$LP_*` 占位符作为工具参数；绝不按名字索要凭据本体（值会进入你的上下文）。

| 参数 | 类型 | 必填 | 描述 |
|---|---|---|---|
| `name` | string | no | 可选。传了必须以 LP_ 开头；返回其值。省略时返回已设置的 LP_* 名字列表。 |
