### 元命令

这些命令配置 REPL，永远不会发给模型。

| 命令 | 描述 |
|---|---|
| `/help [command]` | 列出命令，或显示某个命令的帮助 |
| `/quit` | 退出 REPL |
| `/verbosity <low\|medium\|high>` | 设置 agent 输出详细程度 |
| `/effort <null\|none\|minimal\|low\|medium\|high\|xhigh>` | 设置单轮推理强度 |
| `/stream [on\|off]` | 开关助手文本的流式输出 |
| `/usage` | 显示本次会话的 token 用量与缓存统计 |
| `/clear` | 清空对话历史与用量统计（保留页面/Cookie） |
| `/reset` | 重置对话与浏览器会话（丢弃页面/Cookie） |
| `/save [filename.js] [prompt]` | 把本次会话保存到文件 |
| `/load <path>` | 从磁盘加载并运行脚本 |
| `/model [name]` | 更换模型 |
| `/provider [name\|null]` | 更换 provider，'null' 表示禁用 LLM |
| `/searchEngine <auto\|brave\|tavily\|exa\|keenable>` | 更换网页搜索引擎 |

### LLM 命令

这些命令向模型发送预构建的提示，因此需要配置 provider。

| 命令 | 描述 |
|---|---|
| `/login` | 使用 $LP_* 凭据登录 |
| `/logout` | 退出当前站点 |
| `/acceptCookies` | 关掉 Cookie 同意横幅 |

### 浏览器命令

每个浏览器工具都能直接作为斜杠命令运行，无需调用模型。单个必填参数可以按位置传；其余用 `key=value` 或 JSON 对象。

| 命令 | 描述 |
|---|---|
| [`/goto <url> [timeout=…] [waitUntil=…]`](/reference/browser-tools#goto) | 打开 URL 并将页面保留在内存中 |
| [`/search <query> [timeout=…]`](/reference/browser-tools#search) | 网页搜索，结果以 markdown 返回 |
| [`/markdown [selector=…] [backendNodeId=…] [maxBytes=…] [strip=…] [url=…] [timeout=…]`](/reference/browser-tools#markdown) | 把页面或子树渲染为 markdown |
| [`/html [selector=…] [backendNodeId=…] [maxBytes=…] [strip=…] [url=…] [timeout=…]`](/reference/browser-tools#html) | 页面或某个节点的原始 HTML |
| [`/screenshot [path=…] [selector=…] [backendNodeId=…] [fullPage=…] [strip=…] [url=…] [timeout=…]`](/reference/browser-tools#screenshot) | 页面或某个节点的截图 |
| [`/links [limit=…] [url=…] [timeout=…]`](/reference/browser-tools#links) | 列出页面上的全部链接 |
| [`/tree [url=…] [timeout=…] [backendNodeId=…] [maxDepth=…] [maxBytes=…]`](/reference/browser-tools#tree) | 页面的语义 DOM 树 |
| [`/nodeDetails <backendNodeId>`](/reference/browser-tools#nodedetails) | 按 backendNodeId 检查节点 |
| [`/interactiveElements [url=…] [timeout=…]`](/reference/browser-tools#interactiveelements) | 列出页面上的可交互元素 |
| [`/structuredData [url=…] [timeout=…]`](/reference/browser-tools#structureddata) | 提取 JSON-LD / OpenGraph 数据 |
| [`/detectForms [url=…] [timeout=…]`](/reference/browser-tools#detectforms) | 列出表单及其字段 |
| [`/findElement [role=…] [name=…]`](/reference/browser-tools#findelement) | 按 role 或 name 查找元素 |
| [`/evaluate <script> [url=…] [timeout=…] [save=…]`](/reference/browser-tools#evaluate) | 在页面里执行 JavaScript |
| [`/extract <schema> [save=…]`](/reference/browser-tools#extract) | 通过 CSS 选择器 schema 提取结构化数据 |
| [`/click [selector=…] [backendNodeId=…]`](/reference/browser-tools#click) | 点击元素 |
| [`/fill <value> [selector=…] [backendNodeId=…]`](/reference/browser-tools#fill) | 向输入框输入文本 |
| [`/scroll [selector=…] [backendNodeId=…] [x=…] [y=…]`](/reference/browser-tools#scroll) | 滚动页面或元素 |
| [`/hover [selector=…] [backendNodeId=…]`](/reference/browser-tools#hover) | 悬停元素 |
| [`/press <key> [selector=…] [backendNodeId=…]`](/reference/browser-tools#press) | 按下键盘按键 |
| [`/selectOption <value> [selector=…] [backendNodeId=…]`](/reference/browser-tools#selectoption) | 在下拉框中选中一项 |
| [`/setChecked <checked> [selector=…] [backendNodeId=…]`](/reference/browser-tools#setchecked) | 勾选或取消勾选 |
| [`/waitForSelector <selector> [timeout=…]`](/reference/browser-tools#waitforselector) | 等待元素出现 |
| [`/waitForScript <script> [timeout=…]`](/reference/browser-tools#waitforscript) | 等到 JS 表达式为真 |
| [`/waitForState <state> [timeout=…]`](/reference/browser-tools#waitforstate) | 等页面达到某加载状态 |
| [`/consoleLogs`](/reference/browser-tools#consolelogs) | 读取缓冲的控制台消息 |
| [`/getUrl`](/reference/browser-tools#geturl) | 显示当前页面 URL |
| [`/getCookies [url=…] [all=…]`](/reference/browser-tools#getcookies) | 显示已存储的 Cookie |
| [`/getEnv [name=…]`](/reference/browser-tools#getenv) | 读取或列出 LP_* 环境变量 |
