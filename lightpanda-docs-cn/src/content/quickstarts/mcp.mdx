# MCP

Lightpanda 的 [MCP](https://modelcontextprotocol.io) 服务器把浏览器工具——导航、读取、点击、填写、提取等——暴露给任何说 Model Context Protocol 的 AI 应用。接一次，之后用自然语言给 agent 下提示词就行。

## 前置条件

- 一个 MCP 宿主：Claude Desktop、Cursor、Windsurf 或自定义客户端。

## 步骤

<Steps>

### 安装 Lightpanda

```sh copy
curl -fsSL https://pkg.lightpanda.io/install.sh | bash
export PATH="$HOME/.local/bin:$PATH"
```

其他方式：[Windows 上的 WSL2](/run-locally/installation/one-liner#windows--wsl2)、[Docker](/run-locally/installation/docker)、[包管理器](/run-locally/installation/package-managers)。

### 连接你的 AI agent

你的 MCP 宿主会自行启动 `lightpanda mcp`，并通过 stdin/stdout 与之通信，因此需要二进制的完整路径。用下面的命令打印：

```sh copy
command -v lightpanda
```

直接写 `lightpanda` 在这里可能不奏效：MCP 宿主在你的终端之外启动它，看不到你安装时设置的 `PATH`。

打开宿主的 MCP 配置：

- **Claude Desktop**：Settings > Developer > Edit Config（会打开 `claude_desktop_config.json`）
- **Cursor**：项目内的 `.cursor/mcp.json`，或全局的 `~/.cursor/mcp.json`
- **Windsurf**：`~/.codeium/windsurf/mcp_config.json`

添加 Lightpanda，把 `/path/to/lightpanda` 换成刚才打印出来的路径：

```json copy
{
  "mcpServers": {
    "lightpanda": {
      "command": "/path/to/lightpanda",
      "args": ["mcp"]
    }
  }
}
```

<Callout type="info" emoji="ℹ️">
  请尊重 `robots.txt`，避免对小站点发起高频请求。在 `args` 里加上 `--obey-robots` 可让 Lightpanda 自动遵循 `robots.txt`。
</Callout>

### 试一试

[quotes.toscrape.com](https://quotes.toscrape.com) 是 Zyte 搭建的公开抓取练习站：一个虚构的名言目录，其搜索页通过 AJAX 表单按作者和标签筛选。

给你的 agent 下这样的提示词：

```text copy
Go to quotes.toscrape.com/search.aspx and find which tags Albert Einstein's quotes are filed under, then give me his inspirational one.
```

agent 会把工具调用串成一条链来回答：用 `goto` 打开搜索页，用 `detectForms` 找到作者和标签下拉框，用 `selectOption` 选作者（这会为该作者重新加载标签列表），再 `selectOption` 选标签，`click` 点击搜索，`waitForState` 等结果加载，最后 `extract` 提取名言。

</Steps>

## 走向生产环境

[Lightpanda Cloud](/run-on-lightpanda-cloud/getting-started) 通过 [Streamable HTTP](https://modelcontextprotocol.io/specification/2025-03-26/basic/transports#streamable-http) 暴露同一个 MCP 服务器，无需安装或保活任何进程。借助 [mcp-remote](https://www.npmjs.com/package/mcp-remote)——只支持 stdio 的 MCP 宿主连远程服务器所需的桥接——把宿主指向离你最近的端点：

```json copy
{
  "mcpServers": {
    "lightpanda-cloud": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "https://euwest.cloud.lightpanda.io/mcp?token=TOKEN"
      ]
    }
  }
}
```

更多 [MCP 选项](/usage/mcp)与全部工具见 [MCP 工具参考](/reference/mcp-tools)。
