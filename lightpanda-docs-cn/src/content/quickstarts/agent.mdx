# Agent

`lightpanda agent` 让你通过对话驱动无头浏览器。用自然语言或斜杠命令告诉它去哪里、提取什么，它就会操控一个真实的浏览器完成工作。之后还能把会话保存成脚本，无需 LLM 即可回放。

## 前置条件

- LLM 供应商的 API key，如 Anthropic、OpenAI 或 Gemini，也可以用本地 Ollama 服务器。`lightpanda agent --no-llm` 无需以上任何一项，仅用斜杠命令运行。

## 步骤

<Steps>

### 安装 Lightpanda

```sh copy
curl -fsSL https://pkg.lightpanda.io/install.sh | bash
export PATH="$HOME/.local/bin:$PATH"
```

其他方式：[Windows 上的 WSL2](/run-locally/installation/one-liner#windows--wsl2)、[Docker](/run-locally/installation/docker)、[包管理器](/run-locally/installation/package-managers)。

### 设置供应商的 API key

```sh copy
export ANTHROPIC_API_KEY=<YOUR_ANTHROPIC_KEY>
```

供应商与环境变量的完整列表见 [Agent 参考](/reference/cli/agent#选项)。

### 启动 REPL

```sh copy
lightpanda agent
```

<Callout type="info" emoji="ℹ️">
  请尊重 `robots.txt`，避免对小站点发起高频请求。传入 `--obey-robots` 可让 Lightpanda 自动遵循 `robots.txt`。
</Callout>

### 告诉它你要什么

```console
❯ go to news.ycombinator.com and get me the top story title and points
```

agent 完成导航、提取并打印答案。也可以直接用命令驱动它。下面的 `/links` 会打印当前页面上的所有链接：

```console
❯ /goto news.ycombinator.com
❯ /links
```

### 保存为可复现脚本

```console
❯ /save <my_script>.js
```

退出 REPL，然后用 Lightpanda 回放脚本，无需 LLM：

```sh copy
lightpanda run <my_script>.js
```

</Steps>
