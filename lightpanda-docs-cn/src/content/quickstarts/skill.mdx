# Skill

Lightpanda skill 教会编码 Agent 如何使用 Lightpanda：哪种接口适合哪类任务、该怎么调用。装一次之后，用大白话描述你想要什么就行，不用再去查命令。

源码见：[lightpanda-io/agent-skill](https://github.com/lightpanda-io/agent-skill)。

## 前置条件

- 一个支持 skills 的编码 Agent，如 Claude Code、Cursor 或 Windsurf。完整列表见 [skills.sh](https://skills.sh)。

## 步骤

<Steps>

### 安装 Skill

<Tabs items={['skills.sh', 'Claude Code plugin', 'Manual']} className="-mb-4">
  <Tabs.Tab>
需要 [Node.js](https://nodejs.org/en/download)：

```sh copy
npx skills add lightpanda-io/agent-skill
```

它会询问要添加哪些 skill、面向哪个 agent。选 `lightpanda`，如果打算保存可复现的脚本，再加上 `pandascript`。
  </Tabs.Tab>
  <Tabs.Tab>
安装 skill 并接好 MCP 服务器：

```sh copy
/plugin marketplace add lightpanda-io/agent-skill
/plugin install lightpanda@lightpanda
```
  </Tabs.Tab>
  <Tabs.Tab>
把仓库克隆到你 agent 的 skills 目录。以 Claude Code 为例：

```sh copy
git clone https://github.com/lightpanda-io/agent-skill ~/.claude/skills/lightpanda
ln -s ~/.claude/skills/lightpanda/pandascript ~/.claude/skills/pandascript
```

第二行为回放脚本添加 `pandascript` skill。请保留整个目录：该 skill 会运行自带的 `scripts/install.sh`。其他 agent 请查阅各自的文档找 skills 目录。
  </Tabs.Tab>
</Tabs>

### 安装 Lightpanda

让你的 agent 执行：

```text copy
Install lightpanda for me.
```

这个 skill 知道安装脚本、你所在平台的包管理器选项以及各种常见的坑，所以它会直接跑对命令，无需你查任何东西。

<Callout type="info" emoji="ℹ️">
想自己动手？运行[一行命令安装](/run-locally/installation/one-liner)：

```sh copy
curl -fsSL https://pkg.lightpanda.io/install.sh | bash
export PATH="$HOME/.local/bin:$PATH"
```

其他方式：[Windows 上的 WSL2](/run-locally/installation/one-liner#windows--wsl2)、[Docker](/run-locally/installation/docker)、[包管理器](/run-locally/installation/package-managers)。
</Callout>

### 试一试

[quotes.toscrape.com](https://quotes.toscrape.com) 是 Zyte 搭建的公开抓取练习站：一个虚构的名言目录，其搜索页通过 AJAX 表单按作者和标签筛选。让你的 agent 执行：

```text copy
Go to quotes.toscrape.com/search.aspx and find which tags Albert Einstein's quotes are filed under, then give me his inspirational one.
```

这需要真实的交互（选作者、等标签列表重新加载、选标签、提交），而不是简单的获取。由哪个接口来处理取决于你的配置：连着 MCP 服务器就走 MCP，否则 skill 会退回自己运行 `lightpanda agent --task "..."`。

也可以让它检查一个现有项目：

```text copy
I have an existing Playwright project. Check whether my tests would work with Lightpanda instead of Chrome, and flag anything that wouldn't.
```

换成 Lightpanda 时有哪些关键差异，这个 skill 心里有数。比如 Lightpanda 没有图形渲染，依赖截图或视觉布局的测试迁移不过去；Playwright 要用 `connectOverCDP` 连接运行中的 Lightpanda，而不是自己启动 Chromium。

</Steps>
