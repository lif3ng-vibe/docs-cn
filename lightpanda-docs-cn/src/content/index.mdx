# Lightpanda 文档

<div className="mt-6 border-l-2 border-[var(--primary)] pl-4 text-lg font-medium text-[var(--foreground)]">
  为机器打造的无头浏览器：比 Chrome 快 9 倍，内存占用少 16 倍。
</div>

Lightpanda 从零构建、不做图形渲染，因此能够瞬间启动、内存占用极低，同一硬件上可以跑多得多的会话。它依然能执行 JavaScript，并支持现代网站所依赖的各类 Web API，非常适合 AI Agent、LLM 训练、搜索索引、抓取与测试等场景。想知道它为何而生、如何融入你的技术栈，请参阅 [Lightpanda 是什么](/core-concepts/what-is-lightpanda)。
