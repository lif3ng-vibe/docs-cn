# 限额与计费

Lightpanda Cloud 按浏览器时间计费。你从免费套餐开始，需要更多时长或更高并发时可以升级。

## 套餐

- **Explorer** 免费，提供面向测试规模设计的浏览器时长池与并发上限，支持渠道为 Discord 社区。
- **Builder** 面向生产工作负载：更大的每月浏览器时长池与并发会话额度，超出包含时长后按小时费率计费，另提供邮件与 Slack 支持。
- **Enterprise** 提供定制的用量、并发与支持，附 SLA。需要大用量、本地部署或私有云，请[联系我们](mailto:hello@lightpanda.io)。

## 用量如何计算

**浏览器时长**（browser hours）是会话保持打开的总时长，按秒计量、在整个计费周期内累加，因此短会话几乎不花钱。计入每月池的就是这个数字，付费套餐的超额费用也由它按每小时费率算出。

**并发会话**（concurrent sessions）是同一瞬间打开的会话数。这个限制关乎并行度，而非总量：只要同一时刻重叠的会话数不超过上限，套餐的并发上限并不妨碍你一天跑很多会话。

无论你以哪种方式打开会话——CDP、MCP、HTTP API 还是从 Playground——这两项限制同样适用。

## 触达限额时

如果你打开的会话数超过并发上限，多出的会话会被拒绝，返回 HTTP `429 Too Many Requests`。等某个运行中的会话结束后重试，或升级以获得更高并发。

每月浏览器时长用完后，行为取决于你的套餐。免费套餐会暂停，直到当月池重置；付费套餐继续运行，超出部分按所在套餐的每小时费率计费。

有些限额与套餐无关。CDP 连接 15 分钟后就会关闭，无论你的池里还剩多少时长，因此要把长任务拆分到多个会话。MCP 会话在 5 分钟没有请求后关闭，保持活跃则可一直运行。
