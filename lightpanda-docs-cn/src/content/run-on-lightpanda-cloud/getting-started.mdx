# 入门

Lightpanda Cloud 替你运行浏览器。无需安装或保活任何进程，只要一个 API token，就能通过 CDP、MCP 或 HTTP API 驱动它。

## 创建账号与 token

在 [console.lightpanda.io/signup](https://console.lightpanda.io/signup) 注册。我们会给你发送一封邮件，里面是生成 API token 的链接。

<Callout type="warning">
token 只在生成时显示一次。请把它存到安全的地方。丢了的话，在控制台重新生成一个。
</Callout>

## 将 CDP 客户端连接到 Lightpanda Cloud

<Callout type="info">
想生成开箱即用的代码片段，可以用控制台里的[脚本生成器](https://console.lightpanda.io/tools/script-generator)。
</Callout>

连接离你的脚本最近的区域。下面的片段都使用 `euwest`：

- `wss://euwest.cloud.lightpanda.io/ws`（欧洲西部）
- `wss://uswest.cloud.lightpanda.io/ws`（美国西部）

  <Tabs.Tab>
建议把 token 存在环境变量里，而不是硬编码进脚本：


```js copy
import puppeteer from 'puppeteer-core';

const browser = await puppeteer.connect({
  browserWSEndpoint: `wss://euwest.cloud.lightpanda.io/ws?token=${process.env.LPD_TOKEN}`,
});
```

完整脚本见 [Puppeteer 页面](/usage/cdp/puppeteer)。

### 连接选项

Cloud 默认提供 Lightpanda。调试时可以在 URL 后附加 `browser=chrome`，改跑 Google Chrome——但 Chrome 并不适用于生产流量。显式加 `browser=lightpanda` 可强制使用 Lightpanda。

同一个 URL 还接受 [`proxy` 参数](/guides/configure-a-proxy#在-lightpanda-cloud-上使用代理)，让会话走共享代理，或走你在控制台[代理页面](https://console.lightpanda.io/proxies)添加的自有代理。

## 其他功能：Playground、HTTP API 与 MCP

Cloud 还提供：

- **[Playground](/run-on-lightpanda-cloud/playground)**：直接在控制台里编写并运行脚本，本地完全无需配置。
- **[HTTP API](/usage/api)**：单次请求即可获取页面的 HTML 或 Markdown，无需 CDP 脚本。
- **[MCP](/usage/mcp)** 服务器：让 AI 应用通过 Model Context Protocol 驱动浏览器。
