# Playground

Playground 是控制台里的一个[代码编辑器](https://console.lightpanda.io/playground/scripts)，在 Lightpanda Cloud 上运行你的自动化脚本。

## 编写并运行脚本

脚本通过 `CDP_WS_URL` 访问浏览器——这是 Playground 替你设置好的环境变量：

<Tabs items={['Playwright', 'Puppeteer']}>
  <Tabs.Tab>
```js copy
import { chromium } from 'playwright-core';

// Connect Playwright's chromium driver to the browser.
const browser = await chromium.connectOverCDP(process.env.CDP_WS_URL);

const context = await browser.newContext({});
const page = await context.newPage();

await page.goto('https://wikipedia.com/');

const title = await page.locator('h1').textContent();
console.log(title);

await page.close();
await context.close();
await browser.close();
```
  </Tabs.Tab>
  <Tabs.Tab>
```js copy
import puppeteer from 'puppeteer-core';

// Connect Puppeteer to the browser.
const browser = await puppeteer.connect({
  browserWSEndpoint: process.env.CDP_WS_URL,
});

const context = await browser.createBrowserContext();
const page = await context.newPage();

await page.goto('https://wikipedia.com/');

const title = await page.$eval('h1', el => el.textContent);
console.log(title);

await page.close();
await context.close();
await browser.disconnect();
```
  </Tabs.Tab>
</Tabs>

## CDP_WS_URL 里有什么

你不需要在脚本里硬编码 token。`CDP_WS_URL` 存的是你的客户端经由 Chrome DevTools 协议（CDP）访问浏览器所用的 WebSocket 地址，由 Default variables 面板中的选项拼装而成：

| 默认变量 | 取值 | 控制什么 |
| --- | --- | --- |
| Region | `euwest`、`uswest` | 由哪个区域提供浏览器服务 |
| Token | 你的某个有效 token | 本次运行用哪个 token 鉴权 |
| Browser | `lightpanda`、`chrome` | 运行哪个浏览器。Chrome 仅用于调试，不适用于生产流量 |
| Proxy | 你的某个代理，或不使用 | 浏览器使用的出口 IP |

把你所用的客户端连到 `process.env.CDP_WS_URL` 即可。

<Callout type="info">
`console.log(process.env.CDP_WS_URL)` 打印的是 `***`，不是 URL。该 URL 携带为本次运行创建的访问 token，而运行输出会保存在控制台里，因此 Playground 会把输出中出现的 URL 全部打码。
</Callout>

## 运行时提供什么

脚本运行在一个隔离容器中。两个 CDP 客户端都按固定版本预装，无需安装步骤：

| 包 | 版本 |
| --- | --- |
| `playwright-core` | 1.50.0 |
| `puppeteer-core` | 24.0.0 |

环境的其余部分也是固定的：

- **语言**。JavaScript 和 TypeScript 都通过 [tsx](https://tsx.is/) 运行，因此两者无需配置即可使用 `import` 语法和顶层 `await`。
- **包**。除上述两个客户端外，无法安装任何其他东西。
- **文件系统**。只读，仅 `/tmp` 可写。

每次运行都有上限：

| 限额 | 数值 |
| --- | --- |
| 运行时长 | 5 分钟 |
| 内存 | 256 MB |
| CPU | 1 核 |
| 捕获的输出 | 256 KB |
| 进程数 | 64 |

达到 5 分钟的运行会被终止并报 `timeout running program`。超过 256 KB 的输出会被丢弃，该运行会被标记为截断。

这些上限作用于脚本进程。脚本驱动的浏览器会话同样计入你的[套餐限额](/run-on-lightpanda-cloud/limits-and-billing)。

[Runs 页面](https://console.lightpanda.io/playground/script-runs)展示过去 30 天的运行历史与输出。
