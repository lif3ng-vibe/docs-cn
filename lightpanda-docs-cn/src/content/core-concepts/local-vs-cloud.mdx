# 本地与 Cloud 的选择

Lightpanda 用两种方式运行同一套引擎。你可以自己在自己的机器或基础设施上运行二进制，也可以连接 Lightpanda Cloud，让远程浏览器代劳。引擎完全相同，不同的是浏览器跑在哪里、你能用哪些接口，以及流量被谁看到。

## 选本地还是 Cloud

**想完全掌控、任何东西都不离开本机时，选本地**。二进制跑在你自己的硬件上，你访问的页面与提取的数据都留在你的基础设施内。本地提供全部接口：

- [CDP 服务器](/run-locally/commands#serve-命令)或 [WebDriver BiDi](/usage/bidi/selenium) 服务器
- [MCP 服务器](/usage/mcp)，包含全部工具
- 内置的 [AI agent](/usage/agent)

进程、扩缩容、网络出口都由你自己管理。

**不想自己运行和扩展浏览器时，用 Cloud**。注册账号、拿到 token，连接远程浏览器即可，没有进程要管，也没有主机要维护。Lightpanda Cloud 在它的服务器上运行浏览器，并补齐了托管服务所需的部分：用于管理账号与 token、查看近期会话的[控制台](https://console.lightpanda.io)；按用量计费、带并发与每月限额的套餐；在目标网站封禁数据中心 IP 时能派上用场的托管代理池；以及单次请求即可返回页面 HTML 或 Markdown、无需 CDP 脚本的 [HTTP API](/usage/api)。由于请求在 Lightpanda 的服务器上运行，你的目标 URL 和抓取到的内容都会经过 Lightpanda 的基础设施。

## 机密性与遥测

最关键的区别在于你的流量流向哪里。

本地运行时，浏览器跑在你自己的机器上。你加载的页面、页面内容和你的 cookie 永远不会到达 Lightpanda，只会到达你访问的网站，以及你配置的代理（如果有的话）。二进制确实会向 `telemetry.lightpanda.io` 发送匿名使用遥测：某次导航是否用了 TLS、上下文类型（页面、iframe、弹窗），对 agent 还包括 LLM 供应商与模型名称。其中绝不包含你访问的 URL 或页面内容。调试构建中遥测默认关闭，任何构建都可以通过设置 `LIGHTPANDA_DISABLE_TELEMETRY` 环境变量禁用。详见[遥测](/run-locally/installation/nightly-builds#遥测)。

跑在 Cloud 上时，浏览器运行在 Lightpanda 的服务器上，你的目标 URL 与返回的页面都会经过 Lightpanda 的基础设施。你可以在[仪表盘](https://console.lightpanda.io)查看近期会话。如果工作负载不能离开你自己的环境，请选本地。

## 功能覆盖

下表展示每种模式下可用的接口与功能。覆盖范围仍在扩大，Cloud 尚未在所有接口上与本地对齐。

<Callout type="info">
Cloud 的覆盖仍在建设中。Cloud 通过 SSE 暴露 MCP 服务器，工具是本地可用工具的一个子集。
</Callout>

| 接口 / 功能 | 本地 | Cloud |
| --- | --- | --- |
| [CDP 服务器](/run-locally/commands#serve-命令)（`serve`） | 是 | 是 |
| [MCP 服务器](/usage/mcp) | 是，全部工具 | 部分，工具子集 |
| [AI agent](/usage/agent) | 是 | 否 |
| [`fetch` 命令](/run-locally/commands#fetch-命令) | 是 | 否 |
| [HTTP API](/usage/api) | 否 | 是 |
| [代理](/guides/configure-a-proxy) | 是，你自己的代理 | 是，可选国家的共享池，或你自己的 |

CDP 方面，两种模式说的是同一个协议：同一批 [Puppeteer](/usage/cdp/puppeteer)、[Playwright](/usage/cdp/playwright)、[chromedp](/usage/cdp/chromedp) 脚本，既可连本地端点，也可带 token 连 Cloud 端点。[HTTP API](/usage/api) 是本地 [`fetch`](/run-locally/commands#fetch-命令) 命令在 Cloud 上的对应物：两者都是一次性返回 HTML 或 Markdown，无需 CDP 脚本。如何连接 Cloud，见[入门](/run-on-lightpanda-cloud/getting-started)。
