# 与网页交互

在本指南中，你将使用 Lightpanda 在
[HackerNews](https://news.ycombinator.com/) 上执行一次搜索，等待动态
结果加载，并从页面中提取结构化数据。

这个示例必须用 Lightpanda，因为 HackerNews 通过 XHR 请求展示搜索
结果——直接抓取原始 HTML 拿不到它们。

## 前置条件

你需要在电脑上安装 [Node.js](https://nodejs.org/en/download)。

创建一个 `hn-scraper` 目录并初始化一个新的 Node.js 项目。`npm init`
的提示一路接受默认值即可。

```sh copy
mkdir hn-scraper && \
  cd hn-scraper && \
  npm init
```

安装 `lightpanda` 包，以及
[`puppeteer-core`](https://www.npmjs.com/package/puppeteer-core) *或*
[`playwright-core`](https://www.npmjs.com/package/playwright-core) npm 包。

<Callout type="info" emoji="">
  与 `puppeteer` 和 `playwright` 不同，`puppeteer-core` 和
  `playwright-core` 不会下载 Chromium 浏览器。
</Callout>

## 创建 index.js

创建 `index.js` 文件，导入相关包、配置连接并设置浏览器生命周期：

<Tabs items={['puppeteer', 'playwright']} className="-mb-4">
  <Tabs.Tab id="puppeteer" className="m-0">
```javascript copy
'use strict'

import { lightpanda } from '@lightpanda/browser';
import puppeteer from 'puppeteer-core';

const lpdopts = {
  host: '127.0.0.1',
  port: 9222,
};

const puppeteeropts = {
  browserWSEndpoint: 'ws://' + lpdopts.host + ':' + lpdopts.port,
};

(async () => {
  // Start Lightpanda browser in a separate process.
  const proc = await lightpanda.serve(lpdopts);

  // Connect Puppeteer to the browser.
  const browser = await puppeteer.connect(puppeteeropts);
  const context = await browser.createBrowserContext();
  const page = await context.newPage();

  // Disconnect Puppeteer.
  await page.close();
  await context.close();
  await browser.disconnect();

  // Stop Lightpanda browser process.
  proc.stdout.destroy();
  proc.stderr.destroy();
  proc.kill();
})();
```
  </Tabs.Tab>

  await page.close();
  await context.close();
  await browser.close();

  // Stop Lightpanda browser process.
  proc.stdout.destroy();
  proc.stderr.destroy();
  proc.kill();
})();

## 完整脚本

<Tabs items={['puppeteer', 'playwright']} className="-mb-4">
  <Tabs.Tab id="puppeteer" className="m-0">
```javascript copy
'use strict'

import { lightpanda } from '@lightpanda/browser';
import puppeteer from 'puppeteer-core';

const lpdopts = {
  host: '127.0.0.1',
  port: 9222,
};

const puppeteeropts = {
  browserWSEndpoint: 'ws://' + lpdopts.host + ':' + lpdopts.port,
};

(async () => {
  // Start Lightpanda browser in a separate process.
  const proc = await lightpanda.serve(lpdopts);

  // Connect Puppeteer to the browser.
  const browser = await puppeteer.connect(puppeteeropts);
  const context = await browser.createBrowserContext();
  const page = await context.newPage();

  // Go to hackernews home page.
  await page.goto("https://news.ycombinator.com/");

  // Type the search term and submit.
  await page.type('input[name="q"]', 'lightpanda');
  await page.keyboard.press('Enter');

  // Wait until the search results are loaded.
  await page.waitForFunction(() => {
    return document.querySelector('.Story_container') != null;
  }, { timeout: 5000 });

  // Loop over search results to extract data.
  const res = await page.evaluate(() => {
    return Array.from(document.querySelectorAll('.Story_container')).map(row => {
      return {
        title: row.querySelector('.Story_title span').textContent,
        url: row.querySelector('.Story_title a').getAttribute('href'),
        meta: Array.from(row.querySelectorAll('.Story_meta > span:not(.Story_separator, .Story_comment)')).map(row => {
          return row.textContent;
        }),
      }
    });
  });

  console.log(res);

  // Disconnect Puppeteer.
  await page.close();
  await context.close();
  await browser.disconnect();

  // Stop Lightpanda browser process.
  proc.stdout.destroy();
  proc.stderr.destroy();
  proc.kill();
})();
```
  </Tabs.Tab>
