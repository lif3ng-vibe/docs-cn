# 获取 Markdown 与无障碍树

Lightpanda 在 JavaScript 执行完毕后，直接从浏览器引擎输出 Markdown
与无障碍树（accessibility tree）形式的页面内容，无需外部 HTML 转
Markdown 工具。

<Callout type="info" emoji="ℹ️">
  本指南介绍**三种本地方式**：CLI、CDP 和 MCP。Cloud 用法见
  [用法](/usage/cdp/puppeteer)章节。
</Callout>

## 总览

从任意网页获取 Markdown 与无障碍树的三种途径：

| 途径 | 适合场景 | 方式 |
|---|---|---|
| **CLI** `fetch --dump markdown` | 脚本、流水线、快速提取 | 单条命令，输出到 stdout |
| **CDP** `LP.getMarkdown` | Puppeteer/Playwright 自动化 | 编程调用，可在页面交互之后 |
| **MCP** 服务器 | AI agent / LLM 工具集成 | 基于 stdio 的 Model Context Protocol |

## CLI：`fetch --dump`

`fetch` 命令获取一个 URL、执行 JavaScript，并把结果转储到 stdout。
可独立运行，无需浏览器会话或 CDP 连接。

### 语法

```sh
lightpanda fetch --dump <format> [options] <URL>

# 格式：
#   html                完整渲染后的 HTML（JS 执行后）
#   markdown            CommonMark markdown
#   semantic_tree       JSON 格式的无障碍树
#   semantic_tree_text  人类可读的无障碍树
```

### 输出格式

![输出格式对比：example.com 的 HTML、Markdown 与语义树](https://cdn.lightpanda.io/website/assets/images/docs/markdown-output-formats.png)
*同一页面（example.com）的三种输出格式。Markdown 剔除所有非语义标记，得到更小的表示。*

| 格式 | 说明 | 适合场景 |
|---|---|---|
| `html` | JS 执行后的完整 DOM，以 HTML 呈现 | 归档、diff、调试 |
| `markdown` | CommonMark markdown（链接、标题、列表、表格） | AI/LLM 上下文、摘要 |
| `semantic_tree` | 结构化 JSON 形式的完整无障碍树 | 无障碍审计、结构化解析 |
| `semantic_tree_text` | 缩进排版、人类可读的无障碍树 | 快速无障碍检查、调试 |

### 基本示例

```sh copy
lightpanda fetch --dump markdown https://example.com
```

<details>
<summary>示例输出</summary>

```markdown
# Example Domain

This domain is for use in documentation examples without needing permission. Avoid use in operations.

[Learn more](https://iana.org/domains/example)
```

</details>

### `--with-frames` 选项

在输出中包含渲染后的 iframe 内容。不加该选项时，iframe 内容会被排除。

```sh copy
# 不含 iframe 内容（默认）
lightpanda fetch --dump markdown https://example.com

# 包含 iframe 内容
lightpanda fetch --dump markdown --with-frames https://example.com
```

在没有 iframe 的页面上，两种方式输出完全一致。

### `--strip-mode` 选项

从输出中移除若干组标签。多个取值可用逗号组合：

```sh copy
# 从输出中移除 JavaScript 和 CSS
lightpanda fetch --dump html --strip-mode js,css https://example.com

# 只保留主要内容，阅读模式风格
lightpanda fetch --dump html --strip-mode clutter https://example.com
```

全部选项见 [fetch 命令参考](/reference/cli/fetch#选项)。

### 语义树输出

`semantic_tree` 格式以结构化 JSON 返回页面的无障碍树：

```sh copy
lightpanda fetch --dump semantic_tree https://example.com
```

每个节点包含：

| 字段 | 类型 | 说明 |
|---|---|---|
| `nodeId` | string | 节点的唯一标识符 |
| `backendDOMNodeId` | integer | 后端 DOM 节点 ID |
| `nodeName` | string | HTML 元素名（如 `h1`、`p`、`a`、`text`） |
| `xpath` | string | 节点的 XPath |
| `nodeType` | integer | DOM 节点类型（1 = 元素，3 = 文本，9 = 文档） |
| `isInteractive` | boolean | 该元素是否可交互 |
| `role` | string | ARIA 角色（如 `heading`、`paragraph`、`link`、`none`） |
| `name` | string | 计算得到的无障碍名称 |
| `nodeValue` | string | 文本内容（文本节点） |
| `attributes` | object | HTML 属性（如 `href`、`lang`） |
| `children` | array | 子节点 |

<details>
<summary>示例输出（前两层）</summary>

```json
{
  "nodeId": "1",
  "backendDOMNodeId": 1,
  "nodeName": "root",
  "xpath": "",
  "nodeType": 9,
  "children": [{
    "nodeId": "2",
    "backendDOMNodeId": 2,
    "nodeName": "html",
    "xpath": "/html[1]",
    "nodeType": 1,
    "isInteractive": false,
    "role": "none",
    "attributes": {"lang": "en"},
    "children": ["..."]
  }]
}
```

</details>

`semantic_tree_text` 格式以紧凑可读的形式输出相同数据：

```sh copy
lightpanda fetch --dump semantic_tree_text https://example.com
```

<details>
<summary>示例输出</summary>

```
[1] RootWebArea: Example Domain
  [5] heading: Example Domain
  [6] paragraph:
    [7] StaticText: This domain is for use in documentation examples without needing permission. Avoid use in operations.
  [8] paragraph:
    [9] link: Learn more
```

</details>

> CLI 的 `semantic_tree` 与 CDP 的 `Accessibility.getFullAXTree` 返回不同的
> JSON schema。CLI 使用扁平字段名（`role`、`name` 为字符串）；CDP 使用带
> 类型的对象（如 `role: { type: "role", value: "heading" }`）。CDP schema 见
> [CDP：无障碍树](#cdp无障碍树)。

## CDP：`LP.getMarkdown`

在服务器模式（`lightpanda serve`）下，Lightpanda 暴露一个 WebSocket
CDP 端点，其中带有自定义的 **LP 域**。`LP.getMarkdown` 会把当前页面的
实时 DOM 转换为 Markdown。

`--dump markdown` 是从零处理一个 URL，而 `LP.getMarkdown` 则在调用时
转换 DOM。你可以先点击、填表或等待动态内容，再调用它来捕获当前状态。

### 启动 CDP 服务器

```sh copy
# 启动 CDP 服务器（默认：ws://127.0.0.1:9222）
lightpanda serve

# 自定义 host 与端口
lightpanda serve --host 0.0.0.0 --port 9333

# 验证是否已在运行
curl http://127.0.0.1:9222/json/version
```

### 使用 `LP.getMarkdown`

<Tabs items={['Puppeteer', 'Playwright']} className="-mb-4">
  <Tabs.Tab id="Playwright" className="m-0">
```javascript copy
// install: npm install playwright-core
import { chromium } from 'playwright-core';

const browser = await chromium.connectOverCDP('ws://127.0.0.1:9222');
const context = await browser.newContext();
const page = await context.newPage();

await page.goto('https://example.com');

const client = await page.context().newCDPSession(page);
const result = await client.send('LP.getMarkdown', {});
console.log(result.markdown);

await page.close();
await context.close();
await browser.close();
```
  </Tabs.Tab>
  <Tabs.Tab id="Puppeteer" className="m-0">

```javascript copy
// install: npm install puppeteer-core
import puppeteer from 'puppeteer-core';

const browser = await puppeteer.connect({
  browserWSEndpoint: 'ws://127.0.0.1:9222',
});

const context = await browser.createBrowserContext();
const page = await context.newPage();
const client = await page.createCDPSession();

await page.goto('https://example.com', { waitUntil: 'networkidle0' });

const result = await client.send('LP.getMarkdown', {});
console.log(result.markdown);

await page.close();
await context.close();
await browser.disconnect();
```

  </Tabs.Tab>
</Tabs>

> `LP.getMarkdown` 在本地与
> [Lightpanda Cloud](https://console.lightpanda.io/signup) 上工作方式相同。

> `LP.getMarkdown` 支持通过指定 DOM 节点只转换页面的局部，适合跳过
> 页眉、页脚和侧边栏。

## CDP：无障碍树

Lightpanda 支持标准的 CDP `Accessibility.getFullAXTree` 命令，以结构化
节点数组返回完整的无障碍树，与 Chrome 的 CDP 实现兼容。

### 在 Puppeteer 中的用法

```javascript copy
const client = await page.createCDPSession();
const result = await client.send('Accessibility.getFullAXTree', {});

console.log(JSON.stringify(result.nodes, null, 2));
console.log(`Total nodes: ${result.nodes.length}`);
```

### 在 Playwright 中的用法

```javascript copy
const client = await page.context().newCDPSession(page);
const result = await client.send('Accessibility.getFullAXTree', {});
console.log(JSON.stringify(result.nodes, null, 2));
```

### AX 节点结构

<details>
<summary>示例节点结构</summary>

```json
{
  "nodeId": 6,
  "backendDOMNodeId": 6,
  "role": { "type": "role", "value": "heading" },
  "ignored": false,
  "name": {
    "type": "computedString",
    "value": "Example Domain",
    "sources": [{ "type": "contents" }]
  },
  "properties": [
    { "name": "level", "value": { "type": "integer", "value": 1 } }
  ],
  "parentId": 5,
  "childIds": [9]
}
```

</details>

| 字段 | 类型 | 说明 |
|---|---|---|
| `nodeId` | integer | 节点的唯一标识符 |
| `backendDOMNodeId` | integer | 后端 DOM 节点 ID |
| `role` | object | `{ type: "role", value: "<role>" }` —— ARIA 角色 |
| `ignored` | boolean | 该节点在无障碍计算中是否被忽略 |
| `ignoredReasons` | array | 节点被忽略的原因（如适用） |
| `name` | object | `{ type: "computedString", value: "<name>", sources: [...] }` |
| `properties` | array | ARIA 属性（如 `level`、`url`、`focusable`） |
| `parentId` | integer | 父节点 ID |
| `childIds` | array | 子节点 ID 列表 |

对于 `example.com`，CDP 无障碍树包含 **12 个节点**。

## MCP 服务器

Lightpanda 内置 MCP（Model Context Protocol）服务器，可直接与 AI 工具
及 LLM 框架集成。

```sh copy
lightpanda mcp
```

MCP 服务器暴露 `markdown` 和 `semantic_tree` 两个工具。

| 名称 | 说明 |
|-|-|
| markdown | 以 markdown 格式获取页面内容。若提供 url，会先导航到该 url。 |
| semantic_tree | 以简化的语义 DOM 树形式获取页面内容，便于 AI 推理。若提供 url，会先导航到该 url。 |

> MCP 服务器的完整文档——工具、资源、握手协议、agent 配置与 HTTP
> 传输——见 [MCP 服务器指南](/usage/mcp)与
> [MCP 工具参考](/reference/mcp-tools)。
