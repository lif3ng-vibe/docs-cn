# 将 Stagehand 与 Lightpanda 搭配使用

[Stagehand](https://www.stagehand.dev/) 是一个广受欢迎的
[开源](https://github.com/browserbase/stagehand) AI 浏览器自动化框架。

借助 Stagehand，你可以用自然语言和代码来控制浏览器。

由于 Lightpanda 支持
[无障碍树（accessibility tree）](https://github.com/lightpanda-io/browser/pull/1308)，你可以在
Stagehand 脚本中用它替代 Chrome。

<Callout type="info" emoji="ℹ️">
  本指南使用**本地 CDP**。Lightpanda 通过 `@lightpanda/browser` npm 包
  作为本地进程启动。Cloud 用法见
  [用法 / CDP](/usage/cdp/puppeteer)章节。
</Callout>

## 安装 Lightpanda 与 Stagehand 依赖

如果尚未初始化，先创建一个新的 npm 项目，然后安装 Stagehand 依赖。

```sh copy
npm init
```

```sh copy
npm install @browserbasehq/stagehand@3 @lightpanda/browser
```

请停留在 Stagehand 3.x 版本线。Stagehand 4 把 DOM 相关工作移入了一个
Chrome 扩展，而 `localBrowser.connect()` 要通过 CDP 的 `Extensions` 域
加载该扩展——Lightpanda 并未实现这个域，因此 4.x 无法连接。本指南
使用的是 3.x 的 API。

## 结合 Lightpanda 编写 Stagehand 脚本

现在，编辑 `index.js` 文件，编写连接 Lightpanda 的 Stagehand 脚本。

```javascript copy
'use strict'

import { lightpanda } from '@lightpanda/browser';

import { Stagehand } from "@browserbasehq/stagehand";
import { z } from "zod/v3";

const lpdopts = { host: '127.0.0.1', port: 9222 };

const stagehandopts = {
  // Enable LOCAL env to configure the CDP url manually in the launch options.
  env: "LOCAL",
  localBrowserLaunchOptions: {
      cdpUrl: 'ws://' + lpdopts.host + ':' + lpdopts.port,
  },
  // You need an ANTHROPIC_API_KEY env var.
  model: "anthropic/claude-haiku-4-5",
  verbose: 0,
};

(async () => {
  // Start Lightpanda browser in a separate process.
  const proc = await lightpanda.serve(lpdopts);

  try {
    // Connect Stagehand to the browser.
    const stagehand = new Stagehand(stagehandopts);

    await stagehand.init();

    // Impportant: in the official documentation, Stagehand uses the default
    // existing page. But Lightpanda requires an explicit page's creation
    // instead.
    const page = await stagehand.context.newPage();

    await page.goto('https://demo-browser.lightpanda.io/amiibo/', {waitUntil: "networkidle"});
    const name = await stagehand.extract("Extract character's name", z.string());
    console.log("===", name);

    await stagehand.close()

  } finally {
    // Stop Lightpanda browser process.
    proc.stdout.destroy();
    proc.stderr.destroy();
    proc.kill();
  }
})();
```

## 运行脚本

运行脚本之前，请确保已把有效的 Anthropic API key 导出到环境变量
`ANTHROPIC_API_KEY`。你也可以使用 Stagehand 支持的
[其他模型](https://docs.stagehand.dev/v3/configuration/models)。

```sh copy
node index.js
```

你应当看到如下日志：
```sh
=== Sandy
```
