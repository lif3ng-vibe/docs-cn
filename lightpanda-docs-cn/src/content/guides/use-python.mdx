# 使用 Lightpanda Python SDK

在本指南中，你将使用
[`lightpanda` Python 包](https://pypi.org/project/lightpanda/)抓取一个由
JavaScript 渲染的页面，并用 `page.extract` 从中提取结构化数据。

该包内置 Lightpanda 浏览器二进制文件，无需对接额外客户端，也无需单独
下载浏览器，这一点与通过 [Playwright](/usage/cdp/playwright) 或
[Selenium](/usage/bidi/selenium) 驱动 Lightpanda 不同。完成同样的抓取
任务，它的内存占用也比 [Selenium + Chrome 组合低一个数量级](https://github.com/lightpanda-io/lightpanda-python/blob/main/examples/compare.py)。

你需要 Python 3.10 或更新版本。

从 PyPI 安装 [`lightpanda` 包](https://pypi.org/project/lightpanda/)。

## 创建 scrape.py

创建 `scrape.py` 文件，导入 `Browser` 并打开一个会话：

```python copy
from lightpanda import Browser

with Browser() as browser, browser.new_session() as page:
    pass
```

`Browser()` 会启动内置的 Lightpanda 二进制文件，并在 `with` 块退出时
将其停止。

## 导航并提取

使用 `page.goto` 加载
[quotes.toscrape.com/js](https://quotes.toscrape.com/js/)——一个由客户端
JavaScript 渲染名言的页面。然后用一个 schema 描述要从每个 `.quote`
元素中提取的字段，并调用 `page.extract`：

```python copy
SCHEMA = {
    "quotes": [
        {
            "selector": ".quote",
            "fields": {"text": ".text", "author": ".author", "tags": [".tag"]},
        }
    ],
}

page.goto(url="https://quotes.toscrape.com/js/")
data = page.extract(schema=SCHEMA)
print(data["quotes"])
```

`extract` 会把每个 `.quote` 元素作为一条记录返回，其中 `tags` 解析为
该元素内所有 `.tag` 的列表。对这个页面直接用 `requests.get` 会得到零条
名言，因为 DOM 只有在页面 JavaScript 执行之后才会构建。

## 完整脚本

顺着站点自己的"Next"链接收集所有页面，而不只是第一页：

```python copy
from collections import Counter

from lightpanda import Browser

SCHEMA = {
    "quotes": [
        {
            "selector": ".quote",
            "fields": {"text": ".text", "author": ".author", "tags": [".tag"]},
        }
    ],
    "next": {"selector": "li.next a", "attr": "href"},
}

with Browser() as browser, browser.new_session() as page:
    quotes = []
    url = "https://quotes.toscrape.com/js/"
    while url:
        page.goto(url=url)
        data = page.extract(schema=SCHEMA)
        quotes.extend(data["quotes"])
        url = data["next"]

    print(f"{len(quotes)} quotes")
    tags = Counter(tag for q in quotes for tag in q["tags"])
    print("Top tags:", tags.most_common(5))
```

## 使用 asyncio 并发抓取

当你想一次抓取多个页面而不是逐个抓取，或者你的代码本身运行在异步
应用中（例如用 FastAPI 搭建的 Web 服务器），一次阻塞调用会卡住其中
其他事务时，请用 `AsyncBrowser` 代替 `Browser`。此时每个方法都变为
可 await；`AsyncBrowser` 会把每次调用放到浏览器自己的线程池上执行，
因此绝不会阻塞你的事件循环。

该站的十个页面按编号排列，因此可以用 `asyncio.gather` 一次性获取
全部，而不必顺着分页链接逐页抓取。`browser.session()` 会打开一个
限定在单个任务范围内的会话，并在该任务结束时关闭它：

```python copy
import asyncio
from collections import Counter

from lightpanda import AsyncBrowser

SCHEMA = {
    "quotes": [
        {
            "selector": ".quote",
            "fields": {"text": ".text", "author": ".author", "tags": [".tag"]},
        }
    ],
}

URLS = [f"https://quotes.toscrape.com/js/page/{n}/" for n in range(1, 11)]


async def scrape_one(browser, url):
    async with browser.session() as page:
        await page.goto(url=url)
        data = await page.extract(schema=SCHEMA)
        return data["quotes"]


async def main():
    async with AsyncBrowser() as browser:
        results = await asyncio.gather(*(scrape_one(browser, url) for url in URLS))
    quotes = [quote for page_quotes in results for quote in page_quotes]

    print(f"{len(quotes)} quotes")
    tags = Counter(tag for q in quotes for tag in q["tags"])
    print("Top tags:", tags.most_common(5))

asyncio.run(main())
```

<Callout type="info" emoji="ℹ️">
  每个浏览器操作都是 `Session` 的一个方法，在 IDE 中带类型标注与
  文档，操作名与参数均为 snake_case（`wait_for_selector`、
  `backend_node_id`）。
</Callout>

所有方法的签名与 docstring 见 [Python SDK 参考](/reference/python)。

## 重放已保存的脚本

如果你已有 PandaScript——由
[Lightpanda Agent](/guides/lightpanda-agent-tutorial) 或 MCP `save`
工具录制的 `.js` 文件——可以用 `run_script` 从 Python 中重放它，无需
调用 LLM：

```python copy
from lightpanda import run_script

output = run_script("scrape.js")
print(output)
```

`run_script` 会在底层执行 `lightpanda run <script>` 并返回其 stdout；
非零退出码会抛出 `ScriptError`。`run_script_async` 是可 await 的变体。

## 遵守 robots.txt

浏览器可以替你执行 `robots.txt`（默认关闭）。要启用它，请在任意入口
通过 `args=` 传入浏览器 flag：

使用 `Browser`（或 `AsyncBrowser`）时：

```python copy
Browser(args=["--obey-robots"])
```

使用 `run_script` 时：

```python copy
run_script("scrape.js", args=["--obey-robots"])
```

被站点禁止的请求将直接失败而不被发送：`Session` 调用会抛出
`ToolError`，`run_script` 会抛出 `ScriptError`。

同样的 flag 也适用于
[`CDPServer`](/reference/python#cdpserver) 和
[`WebDriverServer`](/reference/python#webdriverserver)，在这两者上，
被拦截的请求会以 Playwright 或 Selenium 的导航错误形式出现，而不是
Python 异常。

<Callout type="warning" emoji="⚠️">
  该规则适用于**每一个**请求，而不只是你请求的那个页面。不少站点
  禁用了自家资源所在的目录，因此一个允许抓取的页面，其脚本和样式
  可能被拦截，最终渲染成空白。这是 `robots.txt` 得到遵守的表现，
  不是故障。在 `--obey-robots` 下如果某个页面返回异常空白，请先读
  一读该站的 `robots.txt`，再下结论说哪里坏了。
</Callout>
