# 获取 HTML 网页

在本指南中，你将把一个 Chrome DevTools 协议（CDP）客户端连接到
Lightpanda，并从 [Wikipedia 页面](https://en.wikipedia.org/wiki/Web_browser)中提取所有参考文献链接。

与只能获取原始 HTML 的 [curl](https://curl.se/) 不同，Lightpanda 能在
浏览器内直接执行 JavaScript 并运行 query selector，因此适合处理动态页面。

## 前置条件

你需要在电脑上安装 [Node.js](https://nodejs.org/en/download)。

创建一个 `hn-scraper` 目录并初始化一个新的 Node.js 项目。`npm init`
的提示一路接受默认值即可。

```sh copy
mkdir hn-scraper && \
  cd hn-scraper && \
  npm init
```

安装 `lightpanda` 包，以及
[`puppeteer-core`](https://www.npmjs.com/package/puppeteer-core) *或*
[`playwright-core`](https://www.npmjs.com/package/playwright-core) npm 包。

<Callout type="info" emoji="">
  与 `puppeteer` 和 `playwright` 不同，`puppeteer-core` 和
  `playwright-core` 不会下载 Chromium 浏览器。
</Callout>

## 创建 index.js

创建 `index.js` 文件，导入相关包、配置连接并设置浏览器生命周期：

<Tabs items={['puppeteer', 'playwright']} className="-mb-4">
  <Tabs.Tab id="puppeteer" className="m-0">
```javascript copy
'use strict'

import { lightpanda } from '@lightpanda/browser';
import puppeteer from 'puppeteer-core';

const lpdopts = {
  host: '127.0.0.1',
  port: 9222,
};

const puppeteeropts = {
  browserWSEndpoint: 'ws://' + lpdopts.host + ':' + lpdopts.port,
};

(async () => {
  // Start Lightpanda browser in a separate process.
  const proc = await lightpanda.serve(lpdopts);

  // Connect Puppeteer to the browser.
  const browser = await puppeteer.connect(puppeteeropts);
  const context = await browser.createBrowserContext();
  const page = await context.newPage();

  // Disconnect Puppeteer.
  await page.close();
  await context.close();
  await browser.disconnect();

  // Stop Lightpanda browser process.
  proc.stdout.destroy();
  proc.stderr.destroy();
  proc.kill();
})();
```
  </Tabs.Tab>
  <Tabs.Tab id="playwright" className="m-0">
```javascript copy
'use strict'

import { lightpanda } from '@lightpanda/browser';
import { chromium } from 'playwright-core';

const lpdopts = {
  host: '127.0.0.1',
  port: 9222,
};

const playwrightopts = {
  endpointURL: 'ws://' + lpdopts.host + ':' + lpdopts.port,
};

(async () => {
  // Start Lightpanda browser in a separate process.
  const proc = await lightpanda.serve(lpdopts);

  // Connect Playwright's chromium driver to the browser.
  const browser = await chromium.connectOverCDP(playwrightopts);
  const context = await browser.newContext({});
  const page = await context.newPage();

  // Disconnect Playwright.
  await page.close();
  await context.close();
  await browser.close();

  // Stop Lightpanda browser process.
  proc.stdout.destroy();
  proc.stderr.destroy();
  proc.kill();
})();
```

## 导航并提取

使用 `page.goto` 导航到 Wikipedia 页面，然后运行 query selector
提取所有外部参考文献链接：

<Tabs items={['puppeteer', 'playwright']} className="-mb-4">
  <Tabs.Tab id="puppeteer" className="m-0">
```javascript copy
  // Go to Wikipedia page.
  await page.goto("https://en.wikipedia.org/wiki/Web_browser");

  // Extract all links from the references list of the page.
  const reflist = await page.evaluate(() => {
    return Array.from(document.querySelectorAll('.references a.external')).map(row => {
      return row.getAttribute('href');
    });
  });

  // Display the result.
  console.log("all reference links", reflist);
```
  </Tabs.Tab>

  // Go to Wikipedia page.

## 完整脚本

<Tabs items={['puppeteer', 'playwright']} className="-mb-4">
  <Tabs.Tab id="puppeteer" className="m-0">
```javascript copy
'use strict'

import { lightpanda } from '@lightpanda/browser';
import puppeteer from 'puppeteer-core';

const lpdopts = {
  host: '127.0.0.1',
  port: 9222,
};

const puppeteeropts = {
  browserWSEndpoint: 'ws://' + lpdopts.host + ':' + lpdopts.port,
};

(async () => {
  // Start Lightpanda browser in a separate process.
  const proc = await lightpanda.serve(lpdopts);

  // Connect Puppeteer to the browser.
  const browser = await puppeteer.connect(puppeteeropts);
  const context = await browser.createBrowserContext();
  const page = await context.newPage();

  // Go to Wikipedia page.
  await page.goto("https://en.wikipedia.org/wiki/Web_browser");

  // Extract all links from the references list of the page.
  const reflist = await page.evaluate(() => {
    return Array.from(document.querySelectorAll('.references a.external')).map(row => {
      return row.getAttribute('href');
    });
  });

  // Display the result.
  console.log("all reference links", reflist);

  // Disconnect Puppeteer.
  await page.close();
  await context.close();
  await browser.disconnect();

  // Stop Lightpanda browser process.
  proc.stdout.destroy();
  proc.stderr.destroy();
  proc.kill();
})();
```
