# 从源码构建

## 前置条件

Lightpanda 使用 [Zig](https://ziglang.org/) `0.14.0` 编写。构建本项目需要安装对应版本的 Zig。

还需要安装 [Rust](https://rust-lang.org/tools/install/)，用于构建依赖。

Lightpanda 还依赖
[zig-js-runtime](https://github.com/lightpanda-io/zig-js-runtime/)（含 v8）、
[Libcurl](https://curl.se/libcurl/) 与 [html5ever](https://github.com/servo/html5ever)。

为了给 zig-js-runtime 构建 v8 引擎，需要先安装一些库：

**基于 Debian/Ubuntu 的 Linux**：

```bash copy
sudo apt install xz-utils ca-certificates \
        pkg-config libglib2.0-dev \
        clang make curl git
```

**macOS 需要安装 [Xcode](https://developer.apple.com/xcode/) 以及 homebrew 中的以下包**：

```bash copy
brew install cmake
```

## 构建与运行

可以用 `make build` 构建整个浏览器，调试环境则用 `make build-dev`。

也可以直接使用 zig 命令以调试模式运行：

```bash copy
zig build run
```

<Callout type="info" emoji="ℹ️">
    构建过程会下载并编译 V8，可能耗时很长，超过 1 小时。
    你可以手动下载一份[预构建版本](https://github.com/lightpanda-io/zig-v8-fork/releases)来省去这一步，并使用 `-Dprebuilt_v8_path=` 选项。
</Callout>

### 内嵌 v8 快照

Lightpanda 使用 v8 快照。默认情况下快照在启动时创建，但你可以用以下命令将其内嵌：

生成快照。
```bash copy
zig build snapshot_creator -- src/snapshot.bin
```

使用快照二进制文件构建。
```bash copy
zig build -Dsnapshot_path=../../snapshot.bin
```

更多细节见 [#1279](https://github.com/lightpanda-io/browser/pull/1279)。

## 遥测

默认情况下，Lightpanda 会收集并发送使用遥测数据。设置环境变量 `LIGHTPANDA_DISABLE_TELEMETRY=true` 即可关闭。Lightpanda 的隐私政策见：[https://lightpanda.io/privacy-policy](https://lightpanda.io/privacy-policy)。
