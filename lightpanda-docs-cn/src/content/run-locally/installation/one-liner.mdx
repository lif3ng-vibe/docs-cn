# 一行命令安装

Linux 或 macOS 用户可以用以下命令安装 Lightpanda。
Windows 用户请查看[专门章节](#windows--wsl2)。

```bash copy
curl -fsSL https://pkg.lightpanda.io/install.sh | bash
```

<Callout type="info" emoji="ℹ️">
使用一行命令安装器安装 Lightpanda，需要已备好 `curl`、`jq` 与 `sha256sum`。
</Callout>

安装器会把二进制文件放到 `~/.local/bin/lightpanda`（可通过环境变量 `LIGHTPANDA_DIR` 覆盖该目录）。如果该目录尚未加入 `PATH`，安装器会给出警告，且在你手动添加之前找不到 `lightpanda`：

```bash copy
export PATH="$HOME/.local/bin:$PATH"
```

把这一行加入你的 shell 配置文件（`~/.bashrc`、`~/.zshrc` 等）即可永久生效。

默认情况下，安装器会安装最新的 Nightly 构建。
你也可以指定某个发布版本：

```bash copy
curl -fsSL https://pkg.lightpanda.io/install.sh | bash -s "1.0.0"
```

## Windows + WSL2

Lightpanda 浏览器可以在 Windows 的 WSL（Windows Subsystem for Linux）中运行。如果尚未安装过 WSL，请按以下步骤操作（更多信息见：[MS Windows install WSL](https://learn.microsoft.com/en-us/windows/wsl/install)）。
在**管理员** shell 中安装并打开 WSL + Ubuntu：
  1. `wsl --install`
  2. 重启
  3. `wsl --install -d Ubuntu`
  4. `wsl`

WSL 和 Linux 发行版装好之后，浏览器即可按与 Linux 相同的方式安装。
在 WSL 内安装 Lightpanda 浏览器：
```bash copy
curl -L -o lightpanda https://github.com/lightpanda-io/browser/releases/download/nightly/lightpanda-x86_64-linux && \
chmod a+x ./lightpanda
```

## 遥测

默认情况下，Lightpanda 会收集并发送使用遥测数据。设置环境变量 `LIGHTPANDA_DISABLE_TELEMETRY=true` 即可关闭。Lightpanda 的隐私政策见：[https://lightpanda.io/privacy-policy](https://lightpanda.io/privacy-policy)。
