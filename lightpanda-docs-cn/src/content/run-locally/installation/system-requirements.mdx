# 系统要求

- x86-64 架构：Debian 12、Ubuntu 22.04、Ubuntu 24.04（glibc 2.35 或更高版本）。
- arm64 架构：Debian 13、Ubuntu 24.04（glibc 2.38 或更高版本）。
- macOS 14.8.9 Sonoma 或更高版本。
- Windows 10+ 或 Windows Server 2016+，需通过 Windows Subsystem for Linux（WSL）运行。
