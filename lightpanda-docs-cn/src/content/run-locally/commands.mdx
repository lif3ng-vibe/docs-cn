# 命令

## fetch 命令

抓取一个或多个 URL，并把渲染后的结果输出到 stdout。每个 URL 都会在独立页面中加载并执行 JavaScript，因此你拿到的是最终 DOM，而不是服务器的原始响应。

```sh copy
lightpanda fetch --obey-robots --log-level info --dump html https://demo-browser.lightpanda.io/campfire-commerce/
```
```sh
$time=1785335542796 $scope=frame $level=info $msg="navigate" url=https://demo-browser.lightpanda.io/campfire-commerce/ method=GET reason=address_bar body=false req_id=1 type=root
$time=1785335543068 $scope=browser $level=info $msg="executing script" src=https://demo-browser.lightpanda.io/campfire-commerce/script.js kind=javascript cacheable=true
$time=1785335543139 $scope=http $level=info $msg="request complete" source=xhr url=https://demo-browser.lightpanda.io/campfire-commerce/json/product.json status=200 len=4770
$time=1785335543140 $scope=http $level=info $msg="request complete" source=fetch url=https://demo-browser.lightpanda.io/campfire-commerce/json/reviews.json status=200 len=1615
<!DOCTYPE html>
...
```

用 `--dump` 选择输出格式，用 `--wait-*` 系列选项控制页面运行时长。全部选项见 [fetch 命令参考](/reference/cli/fetch#选项)。

## serve 命令

将 Lightpanda 作为服务器启动，供自动化客户端连接。默认使用 [CDP](https://chromedevtools.github.io/devtools-protocol/)（Chrome DevTools 协议，CDP）；传入 `--protocol webdriver` 则改用 WebDriver：HTTP 上的[经典协议](https://w3c.github.io/webdriver/)，以及 WebSocket 上的 [BiDi](https://w3c.github.io/webdriver-bidi/)。传入 `--protocol cdp --protocol webdriver` 可在同一端口上同时提供 CDP 与 WebDriver 服务。

```sh copy
lightpanda serve --obey-robots
```
```sh
$time=1785335600862 $scope=app $level=note $msg="server running" address=127.0.0.1:9222
```

全部选项见 [serve 命令参考](/reference/cli/serve#选项)。

服务器启动后，**连接 CDP 客户端**：

- [Puppeteer](/usage/cdp/puppeteer)
- [Playwright](/usage/cdp/playwright)
- [Chromedp](/usage/cdp/chromedp)

添加 `--protocol webdriver` 后，**连接 WebDriver 客户端**：

- [Puppeteer](/usage/bidi/puppeteer)
- [Selenium](/usage/bidi/selenium)

## MCP

将 Lightpanda 作为基于 stdio 的 [Model Context Protocol](https://modelcontextprotocol.io)（MCP）服务器启动，用 LLM 来控制它。

```sh copy
lightpanda mcp
```

全部选项见 [mcp 命令参考](/reference/cli/mcp#选项)，可用工具见 [MCP 工具参考](/reference/mcp-tools)。

服务器启动后，**连接 MCP 客户端**，使用[你偏好的 LLM](/usage/mcp#接入-ai-agent)。详情见 [MCP 用法](/usage/mcp)。

## Agent

将 Lightpanda 作为一个能浏览网页的交互式 AI Agent 启动。

```sh copy
lightpanda agent
```

Agent 会自动从环境中检测 API key，并打开一个 REPL，你可以在其中用自然语言输入指令。也可以用 `--task "..."` 执行单个任务后退出，或者用 `lightpanda run script.js` 回放已保存的脚本，全程不调用任何 LLM。

全部选项见 [agent 命令参考](/reference/cli/agent#选项)。

## run 命令

运行已保存的 [PandaScript](/usage/pandascript)（`.js` 自动化脚本），然后退出。不调用 LLM，也不需要 API key。

```sh copy
lightpanda run script.js
```

用 `lightpanda agent --task "..." --save script.js`，或在 Agent REPL 中输入 `/save`，即可生成可供回放的脚本。

全部选项见 [run 命令参考](/reference/cli#run)。

更多细节参见 [Agent](/usage/agent) 与 [PandaScript](/usage/pandascript) 用法。

## Shell 自动补全

`lightpanda completion <bash | fish | zsh>` 会打印一份针对命令、flag 及其取值的补全脚本。运行 `echo $SHELL` 查看你使用的 shell，然后把脚本保存到该 shell 加载补全的位置：

<Tabs items={['bash', 'fish', 'zsh']}>
  <Tabs.Tab>
需要安装 [bash-completion](https://github.com/scop/bash-completion) 包。

```sh copy
mkdir -p ~/.local/share/bash-completion/completions
lightpanda completion bash > ~/.local/share/bash-completion/completions/lightpanda
```
  </Tabs.Tab>
  <Tabs.Tab>
```sh copy
mkdir -p ~/.config/fish/completions
lightpanda completion fish > ~/.config/fish/completions/lightpanda.fish
```
  </Tabs.Tab>
  <Tabs.Tab>
```sh copy
mkdir -p ~/.zfunc
lightpanda completion zsh > ~/.zfunc/_lightpanda
```

然后在 `~/.zshrc` 中、`compinit` 之前添加 `fpath=(~/.zfunc $fpath)`。
  </Tabs.Tab>
</Tabs>

打开一个新的 shell，然后在 `lightpanda` 之后按 <kbd>Tab</kbd> 补全命令，在 `--` 之后补全 flag，或在 `--dump` 这类 flag 之后补全其取值。

更新 Lightpanda 后请重新生成脚本，以纳入新命令和 flag。
