# Chromedp

配合 [Chromedp](https://github.com/chromedp/chromedp) 使用 Lightpanda，
它是一个面向 Chrome DevTools 协议（CDP）的 Go 客户端。

更多示例见
[demo/chromedp](https://github.com/lightpanda-io/demo/tree/main/chromedp)。

<Tabs items={['Local', 'Cloud']}>
  <Tabs.Tab>
把 Lightpanda 作为本地 CDP 服务器启动（全部选项见
[serve 命令参考](/reference/cli/serve#选项)）：

```sh copy
lightpanda serve --host 127.0.0.1 --port 9222
```

使用 `NewRemoteAllocator` 连接 Chromedp：

```go copy
package main

import (
    "context"
    "log"

    "github.com/chromedp/chromedp"
)

func main() {
    ctx, cancel := chromedp.NewRemoteAllocator(context.Background(),
        "ws://127.0.0.1:9222", chromedp.NoModifyURL,
    )
    defer cancel()

    ctx, cancel = chromedp.NewContext(ctx)
    defer cancel()

    var title string
    if err := chromedp.Run(ctx,
        chromedp.Navigate("https://wikipedia.com/"),
        chromedp.Title(&title),
    ); err != nil {
        log.Fatalf("Failed getting page's title: %v", err)
    }

    log.Println("Got title of:", title)
}
```

导出你的 API token 并连接云端端点：

```sh copy
export LPD_TOKEN="your token here"
```

```go copy
package main

import (
	"context"
	"log"
	"os"

	"github.com/chromedp/chromedp"
)

func main() {
	ctx, cancel := chromedp.NewRemoteAllocator(context.Background(),
		"wss://euwest.cloud.lightpanda.io/ws?token="+os.Getenv("LPD_TOKEN"), chromedp.NoModifyURL,
	)
	defer cancel()

	ctx, cancel = chromedp.NewContext(ctx)
	defer cancel()

	var title string
	if err := chromedp.Run(ctx,
		chromedp.Navigate("https://lightpanda.io"),
		chromedp.Title(&title),
	); err != nil {
		log.Fatalf("Failed getting title of lightpanda.io: %v", err)
	}

	log.Println("Got title of:", title)
}
```

## Cloud 选项

### 端点
根据你的位置，使用以下端点连接：
- `wss://euwest.cloud.lightpanda.io/ws`（欧洲西部）
- `wss://uswest.cloud.lightpanda.io/ws`（美国西部）

### 浏览器

默认情况下 Cloud 提供
[Lightpanda 浏览器](https://github.com/lightpanda-io/browser)。
用 `browser=chrome` 可选择 Google Chrome，或用 `browser=lightpanda`
强制使用 Lightpanda。

```text copy
wss://euwest.cloud.lightpanda.io/ws?browser=chrome&token=TOKEN
```

### 代理

**fast_dc**——默认，单一共享数据中心 IP。

**datacenter**——自动轮换的共享数据中心 IP 池。接受可选的 `country`
查询参数（两位国家代码）。

```text copy
wss://euwest.cloud.lightpanda.io/ws?proxy=datacenter&country=de&token=TOKEN
```
