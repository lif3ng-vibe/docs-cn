# Puppeteer

通过 Chrome DevTools 协议（CDP）配合
[Puppeteer](https://pptr.dev/) 使用 Lightpanda。

更多示例见
[demo/puppeteer](https://github.com/lightpanda-io/demo/tree/main/puppeteer)。

<Tabs items={['Local', 'Cloud']}>
  <Tabs.Tab>
把 Lightpanda 作为本地 CDP 服务器启动（全部选项见
[serve 命令参考](/reference/cli/serve#选项)）：

```sh copy
lightpanda serve --host 127.0.0.1 --port 9222
```

使用 `browserWSEndpoint` 连接 Puppeteer——它是 Puppeteer 用来附加到
已在运行的浏览器的 WebSocket URL，而不是自己再启动一个浏览器：

```js copy
'use strict'

import puppeteer from 'puppeteer-core'

const browser = await puppeteer.connect({
  browserWSEndpoint: 'ws://127.0.0.1:9222',
})

const context = await browser.createBrowserContext()
const page = await context.newPage()

await page.goto('https://wikipedia.com/')

const title = await page.title()
console.log(title)

await page.close()
await context.close()
await browser.disconnect()
```

设置你的 API token 并连接云端端点。连接使用 `wss://`（基于 TLS 的
WebSocket）而非本地的 `ws://`：

```sh copy
export LPD_TOKEN="your token here"
```

```js copy
'use strict'

import puppeteer from 'puppeteer-core'

const browser = await puppeteer.connect({
  browserWSEndpoint: 'wss://euwest.cloud.lightpanda.io/ws?token=' + process.env.LPD_TOKEN,
})
const context = await browser.createBrowserContext()
const page = await context.newPage()

// ...

await page.close()
await context.close()
await browser.disconnect()
```

在 [Playground](/run-on-lightpanda-cloud/playground) 中，控制台会替你
构建好这个 URL 并以 `CDP_WS_URL` 暴露。在该运行时中请把
`process.env.CDP_WS_URL` 传给 `browserWSEndpoint`，因为那里不存在
`LPD_TOKEN`。

## Cloud 选项

### 端点

连接离你最近的区域：

- `wss://euwest.cloud.lightpanda.io/ws`（欧洲西部）
- `wss://uswest.cloud.lightpanda.io/ws`（美国西部）

### 浏览器

默认情况下 Cloud 运行
[Lightpanda](https://github.com/lightpanda-io/browser)。用
`browser=chrome` 可改为请求 Google Chrome 实例，或用
`browser=lightpanda` 显式强制使用 Lightpanda。

```text copy
wss://euwest.cloud.lightpanda.io/ws?browser=chrome&token=TOKEN
```

### 代理

`proxy` 参数控制 Cloud 浏览器抓取页面时使用的出口 IP——可用于地理
定向或避开限流。

**fast_dc**——默认。单一共享数据中心 IP，为速度优化。

**datacenter**——自动轮换的共享数据中心 IP 池。接受可选的 `country`
参数（两位国家代码）以定向到特定国家。

```text copy
wss://euwest.cloud.lightpanda.io/ws?proxy=datacenter&country=de&token=TOKEN
```
