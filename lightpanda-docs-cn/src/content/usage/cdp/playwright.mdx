# Playwright

通过 Chrome DevTools 协议（CDP）配合
[Playwright](https://playwright.dev/) 使用 Lightpanda，支持 JavaScript
或 Python。

更多示例见
[demo/playwright](https://github.com/lightpanda-io/demo/tree/main/playwright)（JavaScript）。

<Tabs items={['Local', 'Cloud']}>
  <Tabs.Tab>
把 Lightpanda 作为本地 CDP 服务器启动（全部选项见
[serve 命令参考](/reference/cli/serve#选项)）：

```sh copy
lightpanda serve --host 127.0.0.1 --port 9222
```

连接 Playwright：

<Tabs items={['JavaScript', 'Python']} className="-mb-4">
  <Tabs.Tab id="javascript" className="m-0">
```js copy
import { chromium } from 'playwright-core';

const browser = await chromium.connectOverCDP('ws://127.0.0.1:9222');

const context = await browser.newContext({});
const page = await context.newPage();

await page.goto('https://wikipedia.com/');

const title = await page.locator('h1').textContent();
console.log(title);

await page.close();
await context.close();
await browser.close();
```

安装 [`playwright` 包](https://pypi.org/project/playwright/)：

```sh copy
pip install playwright
```

```python copy
from playwright.sync_api import sync_playwright

with sync_playwright() as p:
    browser = p.chromium.connect_over_cdp("ws://127.0.0.1:9222")
    context = browser.new_context()
    page = context.new_page()

    page.goto("https://wikipedia.com/")

    title = page.title()
    print(title)

    page.close()
    context.close()
    browser.close()
```

设置你的 API token 并连接云端端点。连接使用 `wss://`（基于 TLS 的
WebSocket）而非本地的 `ws://`：

```sh copy
export LPD_TOKEN="your token here"
```

在 [Playground](/run-on-lightpanda-cloud/playground) 中，控制台会替你
构建好这个 URL 并以 `CDP_WS_URL` 暴露。在该运行时中请使用

（Python），因为那里不存在 `LPD_TOKEN`。

## Cloud 选项

### 端点

根据你的位置，使用以下端点连接：
- `wss://euwest.cloud.lightpanda.io/ws`（欧洲西部）
- `wss://uswest.cloud.lightpanda.io/ws`（美国西部）

### 浏览器

默认情况下 Cloud 提供
[Lightpanda 浏览器](https://github.com/lightpanda-io/browser)。
用 `browser=chrome` 可选择 Google Chrome，或用 `browser=lightpanda`
强制使用 Lightpanda。

```text copy
wss://euwest.cloud.lightpanda.io/ws?browser=chrome&token=TOKEN
```

### 代理

`proxy` 参数控制 Cloud 浏览器抓取页面时使用的出口 IP——可用于地理
定向或避开限流。

**fast_dc**——默认。单一共享数据中心 IP，为速度优化。

**datacenter**——自动轮换的共享数据中心 IP 池。接受可选的 `country`
参数（两位国家代码）以定向到特定国家。

```text copy
wss://euwest.cloud.lightpanda.io/ws?proxy=datacenter&country=de&token=TOKEN
```
