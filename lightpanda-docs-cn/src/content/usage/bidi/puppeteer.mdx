# Puppeteer（BiDi）

配合 [Puppeteer](https://pptr.dev/) 使用 Lightpanda，走
[WebDriver BiDi](https://w3c.github.io/webdriver-bidi/) 而非
Chrome DevTools 协议（CDP）。无论哪种方式，Puppeteer 的公开 API
完全相同，改变的只是连接方式。

更多示例见
[demo/puppeteer/bidi](https://github.com/lightpanda-io/demo/tree/main/puppeteer/bidi)。

<Callout type="warning">
  BiDi 支持尚新，还未覆盖完整规范。在隔离沙箱中运行的 Puppeteer
  辅助方法，例如 `page.title()`、`page.waitForSelector()`、
  `page.click(selector)` 和 `page.type()`，会报
  `sandboxes are not supported` 错误：请改用 `page.evaluate()` 和
  `page.waitForFunction()`。如果脚本需要的命令尚缺，欢迎
  [提交 issue](https://github.com/lightpanda-io/browser/issues)。
</Callout>

启用 `webdriver` 协议启动 Lightpanda（全部选项见
[serve 命令参考](/reference/cli/serve#选项)）：

```sh copy
lightpanda serve --host 127.0.0.1 --port 9222 --protocol webdriver
```

用 `protocol: 'webDriverBiDi'` 把 Puppeteer 连接到 `/session` 路径：

```js copy
'use strict'

import puppeteer from 'puppeteer-core'

const browser = await puppeteer.connect({
  browserWSEndpoint: 'ws://127.0.0.1:9222/session',
  protocol: 'webDriverBiDi',
})

const context = await browser.createBrowserContext()
const page = await context.newPage()

await page.goto('https://wikipedia.com/', { waitUntil: 'load' })

const title = await page.evaluate(() => document.title)
console.log(title)

await page.close()
await context.close()
await browser.disconnect()
```
