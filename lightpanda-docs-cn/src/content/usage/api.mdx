# HTTP API

## 连接

Lightpanda Cloud 提供 HTTP API，让你无需编写和运行 CDP 脚本，就能
轻松获取 Lightpanda 的结果。

参见
[Lightpanda Cloud 入门](/run-on-lightpanda-cloud/getting-started)，
创建账号、生成 token，并选择你所在区域的 URL。

## 获取 URL

该 API 让你获取一个 URL，并以 HTML 或 markdown 格式取回渲染后的页面。
完整的参数列表与响应格式见 [HTTP API 参考](/reference/http-api)。

例如，以 markdown 格式获取一个页面：

```sh copy
$ curl -XPOST \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  https://euwest.cloud.lightpanda.io/api/fetch \
  --data '{"url":"https://example.com", "output_format":"markdown"}'
```
