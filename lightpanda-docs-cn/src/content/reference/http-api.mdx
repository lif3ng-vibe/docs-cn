# HTTP API

抓取 URL 并获取渲染后的页面。实战用法参见 [HTTP API 的使用方法](/usage/api)。

## 抓取 URL

`POST /api/fetch` 端点返回包含页面内容的 JSON 消息。

### 请求

请求需要携带带有你的 token 的 Bearer 鉴权头，以及 `Content-Type: application/json` 头。

该端点接受以下参数：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| `url` | string | 是 | — | 要抓取的 URL。 |
| `output_format` | `html` \| `markdown` | 否 | `html` | — |
| `wait_ms` | uint | 否 | `5000` | 获取页面前等待的时长，单位为毫秒。`0` 也会回退到默认值；并不表示“不等待”。 |
| `wait_event` | `DOMContentLoaded` \| `load` \| `networkAlmostIdle` \| `networkIdle` | 否 | `networkIdle` | 获取页面前需要等待的事件。 |
| `raw` | bool | 否 | `false` | 为 true 时，直接返回原始 HTML 或 Markdown，不带 JSON 包装，`Content-Type` 分别为 `text/html` 或 `text/plain`。 |
| `proxy_name` | string | 否 | `fast_dc` | — |
| `country` | string | 否 | — | 两位字母的国家代码，大小写不敏感。仅在 `datacenter` 代理下使用。 |

```sh copy
curl -XPOST \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  https://euwest.cloud.lightpanda.io/api/fetch \
  --data '{
    "url": "https://lightpanda.io",
    "output_format": "markdown",
    "wait_ms": 50000,
    "wait_event": "networkIdle",
    "raw": false
  }'
```

### 响应

若请求中 `raw` 为 `false`，则返回 JSON 响应。

| 字段 | 类型 | 说明 |
|---|---|---|
| `data` | string | 页面内容，格式由 `output_format` 参数指定。 |
| `status` | int | 响应状态码。 |
| `headers` | object, optional | 服务器返回的 HTTP 头。 |

```json copy
{
  "data": "\n# Example Domain\n\nThis domain is for use in documentation examples without needing permission. Avoid use in operations.\n\n[Learn more](https://iana.org/domains/example)\n",
  "status": 200,
  "headers": {
    "age": "10026",
    "allow": "GET, HEAD",
    "cf-cache-status": "HIT",
    "cf-ray": "9f0dd9374a2320ab-IAD",
    "content-encoding": "br",
    "content-type": "text/html",
    "date": "Thu, 23 Apr 2026 15:19:47 GMT",
    "last-modified": "Sat, 18 Apr 2026 00:51:00 GMT",
    "server": "cloudflare"
  }
}
```
