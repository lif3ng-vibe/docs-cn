# CLI 参考

Lightpanda 以单个二进制文件发布。调用时先给出命令名，再跟上该命令的参数：

```sh
lightpanda <command> [arguments]
```

可用命令如下：

| 命令 | 说明 |
|---|---|
| [`agent`](/reference/cli/agent) | 启动一个能浏览网页的交互式 AI Agent |
| [`completion`](#completion) | 打印 shell 补全脚本（bash、fish、zsh） |
| [`fetch`](/reference/cli/fetch) | 抓取指定的 URL |
| [`help`](#help) | 显示这条帮助信息 |
| [`mcp`](/reference/cli/mcp) | 启动 MCP（Model Context Protocol）服务器（stdio 或 HTTP） |
| [`run`](#run) | 运行已保存的脚本（无 LLM），然后退出 |
| [`serve`](/reference/cli/serve) | 启动 WebSocket CDP 服务器 |
| [`version`](#version) | 显示 lightpanda 的版本 |

用 `lightpanda help <command>` 查看某个命令的更多信息。

每个命令还接受一组共享的[通用选项](/reference/cli/common-options)。

## completion

把针对命令、flag 及其取值的 shell 补全脚本打印到 stdout。安装方法见[如何安装 shell 补全](/run-locally/commands#shell-自动补全)。

```sh copy
lightpanda completion fish > ~/.config/fish/completions/lightpanda.fish
```

```console
usage: lightpanda completion <bash | fish | zsh>

Prints a shell completion script for lightpanda to stdout.

Examples:
  lightpanda completion fish | source
  lightpanda completion fish > ~/.config/fish/completions/lightpanda.fish
  lightpanda completion bash > ~/.local/share/bash-completion/completions/lightpanda
  lightpanda completion zsh > ~/.zfunc/_lightpanda
          then add `fpath=(~/.zfunc $fpath)` before `compinit` in ~/.zshrc
```

## help

显示上面的命令清单；`lightpanda help <command>` 则显示单个命令自己的参考。`--help` 与 `-h` 也可用，在顶层或任何命令之后都行。

```sh copy
lightpanda help [command]
```

## run

运行已保存的脚本，然后退出。不调用 LLM，也不需要 API key。见[如何运行已保存的脚本](/run-locally/commands#run-命令)。

```sh copy
lightpanda run script.js
```

```console
usage: lightpanda run <SCRIPT | -> [COMMON_OPTIONS]

Examples:
  lightpanda run script.js                        (replay a saved script)
  cat script.js | lightpanda run -                (read the script from stdin)

Arguments:
<SCRIPT>
          Path to a .js script to run, then exit. Produce one with
          `lightpanda agent --task "..." --save script.js`, or `/save` from the
          agent REPL. Pass `-` to read the script from stdin instead.
          Caution: .js files can contain evaluate(...) calls that run
          arbitrary JavaScript in the page. Only run scripts you trust, the
          same way you would a shell script.
```

该命令也接受[通用选项](/reference/cli/common-options)。

脚本格式见 [PandaScript 参考](/reference/pandascript)。

## version

显示 lightpanda 的版本。

```sh copy
lightpanda version
```

```console
usage: lightpanda version [OPTIONS]

options:
  --check
          Checks whether a newer release of lightpanda is available. When one is
          found, prints the running version, the latest release, and how to
          update.
```
