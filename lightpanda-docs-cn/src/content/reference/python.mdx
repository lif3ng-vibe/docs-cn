# Python SDK

[`lightpanda` 包](https://pypi.org/project/lightpanda/)的全部公开类、方法、属性与异常，签名与 docstring 均来自代码本身。实战演练见[使用 Python SDK](/guides/use-python)。每个同步类都有一个方法相同、可 await 的 asyncio 孪生类；下文的 async 小节只列出孪生类新增的成员。

## Browser [#browser]

一个 lightpanda 浏览器进程。首次使用时拉起内置的二进制文件。

不可通过 fork 继承：``os.fork()``/``multiprocessing`` 之后，需在子进程中重新创建 Browser。

```python
class Browser(
    binary: str | os.PathLike | None = None,
    env: dict[str, str] | None = None,
    timeout: float = 300.0,
    verbose: bool = False,
    args: Sequence[str] = ()
)
```

拉起浏览器进程并获取其工具列表。


**参数**：
 - **binary**：lightpanda 二进制文件的路径。省略时依次从 ``LIGHTPANDA_BIN`` 环境变量、包内置的二进制文件、``PATH`` 中解析。
 - **env**：为拉起的进程附加的环境变量。
 - **timeout**：等待任意请求响应的秒数，超时则抛出 [`ProtocolError`](#protocolerror)。
 - **verbose**：让浏览器自身的日志输出到 stderr。
 - **args**：传给浏览器进程的额外 CLI flag，例如用 ``["--obey-robots"]`` 强制遵守 ``robots.txt``，或 ``["--http-cache-dir", path]``、cookie 相关 flag。

可作为上下文管理器（`with`）使用。

## Session [#session]

一个隔离的浏览上下文（拥有自己的页面、cookie 与内存）。

不要直接构造——请使用 [`Browser.new_session()`](#browser-new-session)。

浏览器操作是仅限关键字参数的方法，按浏览器自身的操作名转为 snake_case 命名：``waitForSelector`` 操作对应 [`wait_for_selector()`](#session-wait-for-selector)，其 ``backendNodeId`` 参数对应 ``backend_node_id``。

当方法同时接受 ``selector`` 与 ``backend_node_id`` 时，两者传其一即可。为保证可复现性优先用 ``selector``，两者都传时也以 ``selector`` 为准；``backend_node_id`` 取 [`tree()`](#session-tree)、[`links()`](#session-links) 或 [`find_element()`](#session-find-element) 返回的值。

[`call()`](#session-call) 是逃生舱口，按浏览器声明的原样传入操作名与参数名。操作失败会抛出 [`ToolError`](#toolerror)。

```python
class Session(browser: Browser, session_id: str)
```

可作为上下文管理器（`with`）使用。

### Session.evaluate [#session-evaluate]

```python
def evaluate(
    self,
    *,
    script: str,
    url: str | None = None,
    timeout: int | None = None,
    save: str | None = None
) -> Any
```

在当前页面上下文中执行 JavaScript——专用工具表达不了的页面侧逻辑，可用这个逃生舱口；取数据优先用 [`extract`](#session-extract)，做操作优先用 click/fill 等。它在页面内运行，因此看不到 agent 脚本的变量或内置对象——需要用的值请内插到 `script` 字符串里。裸尾表达式会返回其值；支持顶层 `await` 与 `return`（此时函数体作为 async 函数运行，因此用 `return` 产出值）。对象与数组以 JSON 返回，无需 `JSON.stringify`。若提供 url，会先导航过去。`globalThis.lp` 对象暴露一个 Session 作用域的桥接存储：通过 `lp.foo = ...` 写入的值会在 evaluate 结束时自动同步，导航后依然存在；此前通过 `/extract save=` 或 `/evaluate save=` 设置的值会以 `lp.<name>` 出现。


**参数**：
 - **script**：在页面上下文中运行的 JavaScript。裸尾表达式，或带顶层 `await` 的 `return`，即为结果。
 - **url**：可选，先导航到该 URL 再求值。空字符串视为未提供。
 - **timeout**：可选超时，单位毫秒。默认 10000。
 - **save**：可选的桥接存储键。evaluate 的返回值会以该名称存储，并在后续 evaluate 中重新以 `lp.<name>` 暴露。对象、数组与字符串自动序列化——无需 JSON.stringify。

### Session.extract [#session-extract]

```python
def extract(self, *, schema: str | dict | list, save: str | None = None) -> Any
```

从当前页面提取结构化数据（会先导航）。`schema` 是一个 JSON 对象（以字符串传入），把输出字段名映射到 CSS 选择器规则。它不是 JSON Schema——没有 "type"/"properties" 包装；键就是你的输出字段。取值形式：
```text
"<sel>"                                → first match's text (trimmed; null if no match)
["<sel>"]                              → every match's text (string[])
{"selector":"<sel>","attr":"<name>"}   → first match's attribute value (href/src resolved to absolute URLs)
[{"selector":"<sel>","attr":"<name>"}] → every match's attribute (string[])
[{"selector":"<sel>","fields":{…}}]    → one object per match; field selectors resolve relative to that match and accept any shape above ("" = the match's own text; nest arrays for per-item sub-lists)
```
在任意数组的对象规则内加 "limit": N 可限制匹配数。
每个提取到的值都是字符串或 null——数字请在下游解析。空数组是合法结果；但若所有顶层键都未匹配，调用会报错：先用 tree/markdown 查看页面，再用修正后的选择器重试。
数据类任务请以 extract 收尾——它是唯一会被记录为可回放 `extract(...)` 脚本调用的读取操作；从对话中 [`markdown`](#session-markdown) 文本里摘出来的答案不算。

示例（schema → 结果）：
```text
{"karma": "#karma"} → {"karma":"42"}
{"items": [".story .title"]} → {"items":["Title 1","Title 2"]}
{"top3": [{"selector":".story .title","limit":3}]} → {"top3":["A","B","C"]}
{"links": [{"selector":"a.title","attr":"href"}]} → {"links":["https://site/a","https://site/b"]}
{"stories": [{"selector":".athing","fields":{"title":".titleline","rank":".rank"}}]} → {"stories":[{"title":"Foo","rank":"1"}]}
```


**参数**：
 - **schema**：以字符串传入的提取 schema：一个把输出字段名映射到 CSS 选择器规则的 JSON 对象字面量（见工具描述）。不是 JSON Schema。
 - **save**：可选的桥接存储键。提取到的 JSON 会以该名称存储，并在后续 /evaluate 调用中以 `lp.<name>` 暴露。

### Session.goto [#session-goto]

```python
def goto(
    self,
    *,
    url: str,
    timeout: int | None = None,
    wait_until: str | None = None
) -> PageResult
```

把当前页面导航到一个 URL。`waitUntil` 触发后（默认 `load`）返回 HTTP 状态，或超时提示；4xx 或 5xx 表示拿到的是错误页而非目标内容——继续读取前先检查；由加载后 JavaScript 渲染的内容可能尚未出现（见 `waitForState`）。页面会保持加载状态，供后续读取与操作。想在一次调用里边导航边读取，请改用 [`markdown`](#session-markdown)、[`tree`](#session-tree) 或 [`html`](#session-html) 的 `url` 参数；下一步是操作或 [`extract`](#session-extract) 时再用 [`goto`](#session-goto)。


**参数**：
 - **url**：要导航到的 URL，必须是合法 URL。
 - **timeout**：可选超时，单位毫秒。默认 10000。

**返回**：
> PageResult：即上文描述的那句话，并带有以下属性（缺失时为 None）：
> 
> - `url`：调用完成后所加载页面的 URL。
> - `http_status`：该页面自身文档的响应状态。尚未收到响应时缺失。4xx/5xx 表示这是错误页，而非目标内容。

### Session.tree [#session-tree]

```python

    self,
    *,
    url: str | None = None,
    timeout: int | None = None,
    backend_node_id: int | None = None,
```

## PageResult [#pageresult]

导航或操作的应答：一句话，同时携带字段。

## AsyncBrowser [#asyncbrowser]

由 asyncio 驱动的 lightpanda 浏览器进程。

子进程由 [`start()`](#asyncbrowser-start) 拉起——进入 ``async with`` 时和 [`new_session()`](#browser-new-session) 都会自动调用。与 [`Browser`](#browser) 一样，不可通过 fork 继承。

[`Browser`](#browser) 的每个公开方法与属性在 `AsyncBrowser` 上都存在，名称与签名相同；方法都是可 `await` 的协程。下面只列出 `AsyncBrowser` 新增的成员。

```python
class AsyncBrowser(
    binary: str | os.PathLike | None = None,
    env: dict[str, str] | None = None,
    timeout: float = 300.0,
    verbose: bool = False,
    args: Sequence[str] = (),
    max_concurrency: int = 32
)
```

仅保存配置；进程由 [`start()`](#asyncbrowser-start) 拉起。

## CDPServer [#cdpserver]

在 127.0.0.1 上提供 Chrome DevTools 协议（CDP）服务的 lightpanda 进程。

```python
from lightpanda import CDPServer
from playwright.sync_api import sync_playwright

with CDPServer() as server, sync_playwright() as p:
    browser = p.chromium.connect_over_cdp(server.ws_endpoint)
```

## WebDriverServer [#webdriverserver]

在 127.0.0.1 上提供 WebDriver（经典协议与 BiDi）服务的 lightpanda 进程。

```python
from lightpanda import WebDriverServer
from selenium import webdriver
from selenium.webdriver.common.by import By

with WebDriverServer() as server:
    # Selenium requires an options object; Lightpanda accepts any browser's.
    driver = webdriver.Remote(command_executor=server.http_endpoint, options=webdriver.ChromeOptions())
    driver.get("https://example.com")
    print(driver.find_element(By.CSS_SELECTOR, "h1").text)
    driver.quit()
```

[`http_endpoint`](#webdriverserver-http-endpoint) 即 Selenium 的 ``command_executor``。浏览器通过 HTTP 提供经典 WebDriver（导航、元素查找与交互、脚本执行、actions、cookie）；对以 ``webSocketUrl`` 能力创建的会话（Selenium 的 ``options.web_socket_url = True``），还通过 WebSocket 提供 BiDi 模块（``session``、``browser``、``browsingContext``、``script``、``input``），经 ``driver.browsing_context`` 与 ``driver.script`` 访问。传 ``args=["--protocol", "cdp"]`` 可在同一端口上同时提供 CDP（``--protocol`` 是叠加式的）。进程由 [`close()`](#webdriverserver-close) 或退出 ``with`` 块停止；在 Linux 上解释器退出时也会停止。
