# 浏览器工具

Lightpanda 通过以下几套接口暴露同一组浏览器工具：[MCP 服务器](/reference/mcp-tools)通过 `tools/call` 提供它们，[Agent](/reference/cli/agent#repl-命令) 代模型调用并以斜杠命令的形式暴露它们，[PandaScript](/reference/pandascript) 则把它们记录为 `page` 方法。本页按浏览器声明的形式列出每个工具及其参数。

以元素为目标的工具接受 `selector` 或 `backendNodeId`。为了保证可复现性，推荐使用 `selector`；两个都传时也以 `selector` 为准。`backendNodeId` 的值来自此前的一次 `tree`、`links` 或 `findElement` 调用。
