title: "Agent（智能体）"

一个被装上[工具](/terms/tool)、[系统提示词](/terms/system-prompt)和[上下文窗口](/terms/context-window)的[model](/terms/model)，即[harness](/terms/harness)，与用户交替进行[turn](/terms/turn)。_Claude Code 是 agent。Cursor 是 agent。Claude.ai 是 agent。_Agent 是你实际交谈的对象——它是运动中的模型，为一个目的配置好。

与本词典多数术语不同，"agent"不指一个机械部件。模型是一个装[参数](/terms/parameters)的文件；harness是你能指着的软件。agent两者都不是——它是你正在与之说话的单位。人们不断把[AI](/terms/ai)拟人化，而 agent 就是那个被拟人化的单位：你委托的那位，读你消息并作答的那位，"它又把构建弄坏了"里的那个"它"。当你说 agent 做了什么，你的意思是模型加 harness 做了它，但你把这套组合当作单一 actor 对待。

这个观念比这波 AI 更老。软件 agent——你把目标委托给它、由它代你行动的程序——和 AI 一样古老。

避免："the AI"、"the bot"（太含糊——它们掩盖了你指的到底是参数还是被装配起来的整体）。

用法：

"迁移你们用哪个 agent？"

"本地 Claude Code，UI 活用 Cursor——底下同一个模型，不同的 harness。"
