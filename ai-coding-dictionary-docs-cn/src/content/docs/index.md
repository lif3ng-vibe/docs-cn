**AI 编码给人一种只属于专家的错觉**。没解释过的行话。莫名其妙的失败。和产出对不上号的账单。

其实不是。很多困惑是被制造出来的：**有一整套靠风投输血的经济体，就指望它难懂**。

基本的交手词汇，一个下午就能学会。有了它们，整件事就不再像靠猜。

为什么上下文会退化？为什么账单那么高？为什么同一条提示词今天和明天的表现不一样？

每一个都有干净的答案——只要有人告诉你该用哪些词。

这本词典就是干这个的。**AI 编码的词汇表，译成平实的语言**。

**想要词汇之外的东西？**加入 62,000 多位开发者的行列：**[aihero.dev/newsletter](https://www.aihero.dev/s/dictionary-newsletter)**，获取作者最新的技能、AI 工程思考，以及让你保持领先的资源。

## 使用说明

- 每个词条**保留英文原词**（写在页面标题里），旁边是中文译名——因为你在工具文档、报错和社区讨论里遇到的都是英文原词
- 正文为中文意译；词条之间互相链接，顺着读就是一条学习路径
- 七个 Section 是一条由浅入深的课程线：从模型本身，到会话与上下文，到工具与环境，到失败模式，到交接、记忆与工作模式
- 顶部搜索框可全文检索（中英文均可）
