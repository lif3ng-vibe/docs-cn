技能v4.7.1October 23, 2026

发现直接标上你的 pull request，安装也更经得起离线。

检测器现在可以在 GitHub 上为 pull request 添加标注，断网时的更新也不会再动你已安装的技能。

  • pull request 上的发现。在 GitHub Actions 任务里，impeccable detect --github 会把每条发现变成引发它的那一行代码上的标注。--list-rules 打印每条规则的类别与描述，--scope 与 --no-advisory 可以收窄列表。两项都感谢 @mvanhorn。
  • 重新审视硬偏移阴影。偏移 4px 以上的锐利阴影现在只标记为建议（advisory）而非失败，因为它可能是刻意为之的新粗野主义（neobrutalist）选择。想保留时可用 data-impeccable-ignore="hard-offset-shadow"。感谢 @mager 的贡献。
  • Cursor 会检查它刚做的修改。设计钩子改为在每次写入之后运行而不是拦截写入，每次修改只扫描一次。update 与 doctor --fix 会迁移已有钩子。
  • 钩子能找到你的项目。在项目上层文件夹里启动的会话，现在也会对它编辑过的每个项目做会话结束评审。用户目录下的 Codex 钩子能被识别，doctor 会检查它们的启动器。感谢 @Shandy1972v。
  • 更可靠的安装。下载慢时只要数据仍在到达就会继续等待，而不是在 120 秒时失败。如果更新无法取到程序包，你已安装的技能保持原样。每份 Windows .cmd 都带 CRLF 换行符，Copilot 全局钩子可在 Windows 上工作，Impeccable 打印出的命令也能在 PowerShell 中运行。
  • Live mode。调参值在关闭面板并刷新页面后依然保留（感谢 @mager）。修补页面的 Content-Security-Policy meta 标签不再损坏文件，手机上加载 live mode 时不再弹出键盘。
  • 更少误报。straggler 改为测量最后一个词而不是估算它（感谢 @stedmanhalliday），margin 简写中的负值不再丢失。法律与脚注区块豁免于行宽与小字号检查。URL 扫描会跳过 Cookie 提示、启动闸门和隐藏的视觉稿，对比度也能正确读取渐变文字与深色底。srcset 设置的图片会计入，cramped-padding 能看穿透明包裹层（感谢 @BibaPutt）。
  • 阿拉伯文字。harden 现在覆盖 ZWNJ、Yeh 与 Kaf 变体、本地数字和历法，适用于阿拉伯文字语言。感谢 @FawwazLawal。
  • 修复。忽略模式里的 **/ 会在文件夹边界停下，一个豁免不再误跳过无关页面。Live mode 能在阻止存储的页面中启动。audit 的对比度与触控目标检查与 WCAG AA 对齐。感谢 @srobroek。

技能v4.7.0October 20, 2026

桌面应用、更少误报，以及更轻量的技能。

Impeccable 现在可以在 Electron 或桌面 Web 应用运行时扫描它，检测器又针对真实网站做了一轮精度打磨，技能在每个会话中的开销也更低。

  • critique 与 audit 桌面应用。以调试端口启动 Electron、NW.js、CEF 或 WebView2 应用，impeccable detect --cdp 9222 就会按当前状态扫描你打开的那个窗口，并且让它分毫不变。critique 与 audit 都认识这套流程。
  • 两项新的排版检查。straggler 会在段落以孤零零一个词收尾时报警，unbalanced-heading 针对末行只剩残段的标题。在 text-wrap: balance 与 pretty 已经解决问题的位置，这两项检查会自动收手。
  • 真实页面上更少误报。看起来像按钮的标签、卡片编号、可滚动的代码示例、幕布式页脚与透传覆盖层背后的文字、深色光晕上的浅色文案、毛玻璃，现在都按访客所见来读取。边框强调按选择器逐个判断，而不是看附近有多少空行。
  • 更轻量的技能。每个会话加载的描述缩短了 30%，并且现在能识别撰写 DESIGN.md 或整理设计系统的请求。旧的命令文件去掉了大呼小叫的 CRITICAL、NEVER 横幅，完整构建之外的 polish 轮次也不会在两轮后被截断。
  • 评审页面跟随深色模式。决策页与评审页会匹配你的系统外观，而视觉稿与截图保留各自的底色。
  • Monorepo 会挑对应用。context 只把渲染 UI 的工作区列为目标，不再把 tsconfig、lint 或脚本包算进来。
  • 修复。Live mode 可通过纯 HTTP 在局域网或 Tailscale 地址上启动。决策卡片可在 WebKit 内嵌浏览器中渲染，页面一次性加载大量图片时不再卡在 pending。放弃包裹层已丢失原元素的变体时，不再误删该元素。中断的引擎下载会自我清理，Windows 上也是如此。

技能v4.4.0October 1, 2026

页面组装之前，先由你过目每个部件。

当构建从一张已批准的视觉稿开始时，Impeccable 会在组装页面之前停下来，把每个组件拿给你看。什么能上线由你决定。

  • 在浏览器里评审组件套件。每张插画、照片和渲染出的组件都紧挨着它在视觉稿中的裁切。你可以批准，也可以说出需要修改的地方，智能体会修好它供下一轮使用。重复的部件（比如一排卡片）会一起评审。批准结果跨轮次延续，文件有改动的组件会再次评审。
  • 然后检查首屏。页面组装完成后，你对照视觉稿评审首屏。接受即结束该构建的评审；智能体会沿同一方向完成其余部分。没人在键盘前时，评审会等你，而不是自行通过。
  • 应用要有应用的样子。在仪表盘、工具与文档上，选中的方向现在只塑造字体、强调色、密度和一处标志性细节，而导航、表格、图表与控件保持用户已经熟悉的标准样式。落地页与作品集依然享受全套待遇。
  • 按需出变体。新的 /impeccable generate 命令只要一句话，比如 “generate 3 bold variants of the pricing cards”，就能在你打开的页面上找到该元素，并在约一分钟内让变体在浏览器中轮播。选中一个，它就变成源代码。
  • 值得信赖的发现。行宽、内边距和另外三项渲染检查，现在测量的是浏览器实际画出的线条与盒子，每条发现都会注明触发时的屏幕宽度。浅淡的占位文字会被抓到。你在 DESIGN.md 中定义的颜色不再被当成千篇一律的 AI 配色，Tailwind 加载圈也不再被算作强调色边框。
  • 触控由触控来测。adapt、audit 与 harden 现在会实际演练每个控件的主要手势，而不是拿一张缩放过的截图当凭证。
  • 不再误报更新。已是最新版本的安装不再声称有可用更新。
