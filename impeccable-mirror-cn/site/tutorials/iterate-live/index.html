开始之前

你需要安装好 Impeccable，有一个能在你的项目上工作的智能体会话，以及一个在本地运行的网页。Live Mode 支持常见的开发服务器和静态 HTML。如果还没有安装，参见入门教程。

给页面足够的真实内容，以便判断结果。init 和 document 保存的上下文能帮助智能体保留你的产品与视觉决策。没有这些文件也可以试试 generate；它会从当前页面读取视觉风格。

从书面请求开始

如果你已经清楚要改什么，就在智能体对话里直接说明：

/impeccable generate 3 layout variants of the event card. Make the date easier to scan and keep the reservation button with the event details.

Impeccable 会连接到页面，找到这张卡片，并开始生成备选方案。保持智能体会话活跃，然后直接跳到下文的比较各个变体。比较与采纳的控件完全相同。

给命令一个方向和一个元素；数量是可选的，默认为三个。更多示例参见 generate 参考。想自己选取并标注元素，请按照下文的 Live Mode 步骤操作。

1. 启动 Live Mode

在你的智能体对话中运行：

/impeccable live

Impeccable 会连接到项目，并带着工具栏打开页面。使用控件期间，请保持智能体会话活跃。

首次设置时会发生什么？

Impeccable 会识别你的开发服务器所服务的页面，并准备它的 Live Mode 配置。一个本地辅助服务负责把浏览器控件连接到你的智能体。

有些项目带有会阻止这一连接的内容安全策略（CSP）。如需改动，Impeccable 会先解释，并在修改策略前征求你的同意。具体改动取决于你的框架；某些配置需要手动调整。

请打开你应用的 URL。辅助服务器的地址是另一个服务，不是你正在编辑的页面。

2. 选取要修改的部分

在工具栏中启用选取（Pick），然后点击标题、卡片或区块。高亮会标示选中范围，旁边会出现一个请求输入框。

本例中，选中整张活动卡片并输入：

让下一个活动更容易扫读，预订操作也更容易找到。保留全部活动详情、字体和颜色。

你可以选择 layout 或 bolder 之类的动作来聚焦工作重点。批注和手绘笔迹可以指向选中范围中的具体位置。一句朴素的请求就足以开始。

按下标有生成变体（Generate variants）的生成箭头。在备选方案准备期间，让智能体保持工作。

3. 比较各个变体

使用上一个和下一个控件在备选方案之间切换。计数器会显示当前查看的是哪一个。

在上下文中审视结果：是什么在引导视线、占用了多少空间，以及它是否仍然属于这个页面。变体默认会保留你的设计风格。想要不同的风格时，请明确要求重新设计。

某些选中范围会提供微调（Tune）控件，用来调节间距或强调程度等特质。它们直接调整当前变体，无需再生成一轮。本例中，你可以调整分组之间的空间和标题字号。

如果所有备选方案都不理想，就弃用这一组，换一个更具体的请求再试。

4. 保留一个并检查

选择采纳（Accept）来保留当前变体。Impeccable 会把结果写入真实源码，并移除临时预览代码。弃用这一组则会恢复原始的选中状态。

查看源码 diff，并亲手试用受影响的界面。检查窄屏，以及视觉比较没有覆盖到的行为。如果页面由另一个文件生成，请按源码映射提示操作，让改动落到那个原始文件。

5. 结束会话

先采纳或弃用当前这一组，然后使用退出控件，或让智能体停止 Live Mode。它会停止辅助服务并移除临时连接。项目配置会保留下来，供下次会话使用。

如果你是从 generate 开始的，Impeccable 会在处理完你的选择后关闭 Live Mode 连接。开发服务器会带着已采纳的结果继续运行。

试试整页定向

要做出超出单个选中范围的修改，可使用工具栏中的Steer（为整页定向）。输入或说出一个方向，比如“让活动日期在这整个页面上都更容易找到”。智能体会直接处理该请求，而不会先生成一组元素变体。

你也可以直接插入新元素或编辑文字，并应用到源码。Live Mode 参考对这些选项有详细说明。

如果卡住了

  • 没有工具栏：查看智能体的设置消息，确认你打开的是应用 URL。让它检查连接，以及任何阻止连接的策略。
  • 生成停止响应：保持智能体会话活跃。如果它被中断，先让它恢复 Live Mode 并检查未完成的会话，再重新开始。
  • 结果感觉偏离品牌：检查请求内容和项目里已记录的上下文。刷新过时的上下文，并点名当前设计中你想保留的部分。
  • 无法定位源码：听从智能体的解释。不要把改动硬塞进下次构建就会替换掉的生成产物。

想在决定改进什么时获得帮助，可以使用 critique；也可以直接向 Impeccable 描述一个新页面。
