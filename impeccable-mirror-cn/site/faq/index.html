常见问题

完成安装、保持 Impeccable 为最新版本，并在出问题时找到解决办法。

我是 AI 编程工具的新手，该从哪里开始？

在一个受支持的编程工具里打开你的项目，然后跟随入门教程。它会带你完成安装与项目上下文设置，再让你选择构建新页面还是改进现有页面。

你不需要设计经验，也不必记住一堆设计术语。只要描述你在做什么、给谁用、哪里感觉不对劲。例如，在智能体对话里输入：

/impeccable 这个仪表盘上重要信息容易被淹没，帮我把它变得更清晰。

如果你对编程工具本身也不熟悉，先看它的「打开项目」和「与智能体对话」入门指南。Impeccable 可以边用边学。

如何安装 Impeccable，或使用下载的文件？

在终端里，进入项目文件夹并运行：

npx impeccable install

选择你的编程工具，以及是只装到当前项目还是所有项目。安装器会自动挑选匹配的构建版本。需要 Node.js 18.19 或更高版本。安装完成后请重新加载你的编程工具。

下载的是 ZIP？ 把其中内容（包括隐藏文件夹）复制到项目根目录，与 package.json 或 src/ 并排，不要多套一层文件夹。压缩包里的 README.txt 说明了每种工具对应的文件夹。

例如，Codex 的项目级安装包含：

your-project/
├── .agents/
│   └── skills/
│       └── impeccable/
│           └── SKILL.md
├── package.json
└── src/

在 macOS 上，在访达中按 Command–Shift–. 显示隐藏文件夹。其他安装方式见「安装 Impeccable」。

如何更新 Impeccable？

如果是用 Impeccable 安装器安装的，请在终端里运行：

npx impeccable update

在项目文件夹里运行。如果项目级和用户级安装并存，会让你选择更新哪一个；也可以直接用 --project 或 --user 指定。

想先检查是否有更新，运行 npx impeccable check。更新会替换 Impeccable 安装的文件；不会动你项目的 PRODUCT.md 和 DESIGN.md。

用其他方式安装的？ 就走同样的渠道更新：

  • 市场或插件：用你编程工具的插件管理器更新。
  • npx skills：重新运行 npx skills add pbakaus/impeccable。这会安装通用构建；Impeccable 安装器则会为你的工具挑选专用构建。
  • ZIP：从主页下载当前压缩包，替换已安装的 Impeccable 文件。

之后重新加载编程工具。只有确实想覆盖现有安装时才用 npx impeccable install --force。

Impeccable 没出现或没反应，应该检查什么？
  1. 检查安装。确认安装时选对了你在用的编程工具；项目级安装必须装在当前打开的项目里。复制 ZIP 安装的话，也要检查隐藏文件夹。
  2. 重新加载工具。新装的技能可能要重载或新开会话才会出现。
  3. 直接呼叫 Impeccable。在智能体对话里试试：
/impeccable

设计命令都隶属这个主技能。audit、polish、critique 不需要单独安装。

用命令框里的切换开关可换成 Codex 语法。在 Codex CLI 或 IDE 扩展中，也可以打开 /skills 或输入 $ 查看已装技能。参见Codex 技能指引。

还是没有？检查你工具的技能设置与发现列表：

  • Cursor：在发现的技能里找 Impeccable。参见 Cursor 技能文档。
  • Gemini CLI：运行 /skills list；改动安装后用 /skills reload。参见 Gemini 技能管理。
  • GitHub Copilot：确认你使用的环境支持 agent skills。参见 Copilot agent skills 文档。

如果 Impeccable 已可用但自动检查毫无动静，请按钩子设置指南排查。技能发现与钩子运行权限是两个独立的检查。

能给常用命令设个快捷方式吗？

在智能体对话里固定（pin）它：

/impeccable pin critique

这会在你的编程工具里添加 critique 的快捷方式。它会把请求转发给 Impeccable，因此主技能的改进会同步生效。polish、audit、live 等命令也可以固定。

移除快捷方式：

/impeccable unpin critique

移除快捷方式后主命令仍然可用。快捷方式名称以编程工具的技能或命令列表里显示的为准。

什么时候用 generate 而不是 live？

如果你能点名元素、说清想探索的方向，就用 generate。在智能体对话里运行：

/impeccable generate 给定价卡片来 3 个大胆的变体

智能体会找到该元素，并在运行中的页面上展示备选方案。逐一比较，在控件可用时微调，然后采纳其一写入源码，或整组丢弃。

如果要在浏览器里进行持续会话——自己挑选元素、加批注，或用 Steer 做整页级请求——就用 live。两个命令都适用于 Web 项目，除非你主动要求改变，否则都会遵循你现有的设计风格。

Impeccable 免费吗？

免费。Impeccable 的公开技能、命令、CLI 与检测引擎都以 Apache 2.0 许可证开源。

你的编程工具或模型供应商可能按用量收费，包括图像生成。这些费用与 Impeccable 无关。内置支持、OpenAI API 兜底与计费指引见「启用图像生成」。
