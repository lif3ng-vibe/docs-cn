启用图像生成

把视觉方向再推进一步。

本页内容 6 个小节
  1. 收获与代价
  2. 为你的编码工具启用
  3. 使用编码工具自带的图像生成
  4. 使用 OpenAI API key
  5. 确认已就绪
  6. 图像生成不可用时

图像生成给了 Impeccable 探索更大胆的构图和更有创意的视觉方向的空间。一张生成的视觉稿可以定下超出编码模型自然水平的视觉目标。

收获与代价

  • 视觉稿先行（comp 主导）：视觉野心更大。你可以选择一个超出编码模型惯常范围的方向。但图像到代码的转写是有损的：视觉稿的一部分气质与细节会改变或丢失。Impeccable 会帮你弥合差距；预计要几轮提示与评审，而非一次到位。
  • 不用图像生成：首次构建更可预测。Impeccable 仍会先提出概念，然后直接以代码构建（代码主导）。结果开箱看往往更连贯，但模型只在自身自然的视觉上限之内构建，执行通常不够大胆。

当视觉方向重要到值得花时间精修时，选视觉稿主导。当你想要一个足够强的首次实现、又想省去对照视觉参考的功夫时，选代码主导。图像生成也可以创建插画等成品素材；启用它之后，两种构建工作流都仍然可用。

为你的编码工具启用

选择你的设置路径：

  • 使用内置图像生成适用于 Codex、Cursor 等工具。无需 OpenAI API key。
  • 连接 OpenAI API key适用于没有图像生成的工具。使用你 API 项目的计费。

已经设置好了？确认已就绪。

使用编码工具自带的图像生成

只要可用，Impeccable 会优先使用编码工具自带的图像生成工具。这条路径无需你提供 OpenAI API key。

  • Codex：在项目聊天里直接要一张图，或附上 $imagegen。内置生成计入 Codex 用量限额。Codex 图像生成。
  • Cursor：让 Agent 生成图像。它可以预览并保存到你的项目里。Cursor 的图像生成指南。

可用性取决于你的工具、账号和工作区设置。如果智能体没有图像生成工具，就走下面的 API 路径。能读截图不等于能生成图像。

使用 OpenAI API key

对于没有内置图像生成的编码工具，Impeccable 内置了一个 OpenAI API 兜底，使用智能体环境中的 OPENAI_API_KEY。智能体需要获得许可，才能运行该辅助命令并访问 OpenAI API。

1. 创建 key 并确认 API 计费

在你的 OpenAI API 项目中创建 key，并确认该项目已开通计费且有图像生成权限。参见 OpenAI API 快速上手与图像生成要求。

API 图像使用你 API 项目的计费

首次兜底渲染之前，Impeccable 应当会先告知。每张视觉稿或每次修订都可能新增一次请求。大批量生成之前，请查看当前 API 定价。

2. 让 key 对智能体可用

对于基于终端的编码工具，先在终端里设置该变量，再从同一终端启动工具。在本地把占位符替换成你的 key。

macOS 或 Linux：

export OPENAI_API_KEY="your_api_key_here"

Windows PowerShell：

$env:OPENAI_API_KEY = "your_api_key_here"

这些示例只为当前终端会话以及由它启动的工具设置 key。要让未来的会话也生效，请使用你工具的环境或机密配置。

key 必须在智能体执行命令的地方可用。配置之后请重启智能体会话。不要把 key 放进聊天、提交到仓库的文件，或 PUBLIC_*、VITE_* 这类暴露给浏览器的变量。

桌面应用、远程工作区、容器与 .env 文件

请使用你工具的环境或机密配置。在一个不相干的终端里设置 key，不会更新已在运行的应用或远程机器。

项目的 .env 文件只有在你的启动流程会把它加载进智能体的命令环境时才有效。兜底读取的是 OPENAI_API_KEY；仅有 .env 文件并不代表已就绪。

确认已就绪

在项目的智能体聊天里问：

/impeccable check whether image generation is available for this project. Tell me whether you can use a built-in image tool or the OpenAI API fallback. Do not generate an image or print any secret values.

这一步只检查工具可用性或 key 是否存在，不会生成图像。要验证生成确实成功，可以让它生成一张小测试图；这会消耗你工具的图像额度或 API 计费。

在智能体的终端里检查 API key

让智能体在它自己的命令环境里运行这条命令。它只输出该变量是否存在：

node -e 'console.log(process.env.OPENAI_API_KEY ? "OPENAI_API_KEY is set" : "OPENAI_API_KEY is missing")'

检测到 key 并不代表它有效、计费已开通，或网络允许发起请求。

然后继续构建新东西。图像生成可用且没有已保存偏好时，Impeccable 默认视觉稿先行（comp 主导）。你可以在选择器里改选直接构建（代码主导），或让 Impeccable 把它保存为你的默认项。

视觉稿和成品素材有什么区别？

视觉稿（mockup，也叫 comp）是提议界面的图像。你确认构图之后，智能体再以这个视觉目标构建可用的界面。视觉稿不会替代可用的控件、无障碍文本或响应式布局。

素材是界面实际用到的图像：产品插画、背景或抠图。两种构建工作流都可以使用生成的素材。选代码主导只是跳过视觉稿确认环节，并不会关闭你所需素材的图像生成。

图像生成不可用时

智能体能读截图，却不能生成图像

检查它是否真的配有图像生成工具，或者配置 OpenAI API 兜底。只有视觉理解能力是不够的。

key 在你的终端里设了，智能体却拿不到

在智能体运行的地方设置。重启应用或终端工具，并单独检查远程或容器环境。

检测到了 key，但生成失败

读一下返回的错误。按需逐项检查 key 是否有效、项目权限、图像模型访问权、API 计费、用量限额和网络访问。

选择器里没有视觉稿/代码切换

没有图像生成可用时，Impeccable 会采用代码主导。配置好访问权限后，开一个新会话确认就绪状态。

图像生成可用，但选择器默认在代码

检查你已保存的 buildPath 偏好。更改默认值，或只为本次会话切换。

没有图像生成也可以继续工作。Impeccable 会直接以代码构建，你在运行中的界面里评审设计。
