colorize

用颜色厘清操作与状态，并体现设计的性格。

本页内容 3 个小节
  1. 试一试
  2. 工作原理
  3. 检查结果

当页面显得平淡，或颜色能让结构更易理解时，就用 colorize。Impeccable 让颜色承担明确的职责，比如标记选中、区分状态，或强化既定的视觉方向。

试一试

/impeccable colorize 发布仪表盘。让已发布的内容更容易被注意到，并保留我们现有的品牌色。

指明目标，以及必须保留的颜色或含义。Impeccable 会先读项目的设计上下文、令牌和现有界面，再决定处理方式。

工作原理

Impeccable 先判断颜色能在哪里发挥作用，再一致地加以应用：

  • 层级与氛围：把颜色给应该领衔的内容、动作或区域。
  • 状态与含义：按产品惯例区分选中、成功、警告等状态。
  • 体系一致性：在组件与主题间复用既定的品牌色与色彩角色。
  • 无障碍：检查对比度，在颜色之外保留文字标签、形状等其他线索。

既有的色彩约定优先。重要的品牌选择不明确时，Impeccable 会先问你。它在项目当前的色彩体系内工作，不需要推翻调色板，也不必给每块中性表面都染色。

检查结果

目标动作或状态更容易找到了吗？检查文字和控件与背景的对比，包括悬停、焦点、错误以及所支持的各套主题。确保页面不单靠颜色也能被理解。

想减少互相抢戏的点缀色，就用 quieter；文字层级还需下功夫，就用 typeset。
