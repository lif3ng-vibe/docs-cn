从 Impeccable 开始

构建你构想中的界面，或改进手头已有的界面。

安装方式
$ 
npx impeccable install

如果你使用 GitHub Copilot 应用，Impeccable 已内置其中。在 Settings → Experimental 中启用，然后为你的项目完成设置。

安装选项与工具支持

选择你的编码工具，为当前项目或所有项目安装。安装器会为你的工具挑选对应的构建。

每个构建都包含你的工具所支持的文件位置与集成，外加针对其模型常见设计错误的指导。

› 
/plugin marketplace add pbakaus/impeccable

在 Claude Code 对话中运行。然后打开 /plugin，选择 Discover，安装 Impeccable。

$ 
npx skills add pbakaus/impeccable

在终端中运行即可安装共享技能。想获得为你的编码工具定制的集成，请使用推荐的安装器。

开始使用

› 
/impeccable init

在智能体对话中，把你的受众与目标保存进 PRODUCT.md。

之后可用 npx impeccable update 更新

通过 Claude Code 的 /plugin 菜单更新。

用 npx skills update impeccable 更新 Impeccable

想在动手前先看视觉稿？

视觉稿先行（comp 主导）会打开更大胆的视觉方向，需要花几轮把图像转译成代码。直接构建（代码主导）往往首轮构建更连贯，视觉上则相对保守。

用你的编码工具或 OpenAI API 密钥启用图像生成。对比两种工作流 →

持续设计

在设计系统内工作记录共享规则，让下一个页面也合拍。→生成变体在对话中点名元素与方向，然后在页面上比较。→在浏览器里迭代点名或选取元素，比较各变体，采纳其一。→用可视化覆盖层评审理解各项发现，决定要修什么。→

检查与排错

自动设计检查在智能体编辑时向它提供检测器反馈。→运行检测扫描在终端里检查文件或渲染后的页面。→修复安装问题找出过期的上下文与失效的钩子。→

命令参考

当你清楚想要哪种改动时，就用一条聚焦的命令。

创建 2

  • impeccable描述你想构建或改进的东西。
  • shape把想法变成一份可据以构建的设计简报。

评估 2

  • audit找出实现问题，并为修复排定优先级。
  • critique找出拖累设计的地方，以及该先改进什么。

精修 8

  • animate用动效让变化、关系与反馈一目了然。
  • bolder让现有区块更有存在感，同时忠于原有设计。
  • colorize用颜色厘清操作与状态，并体现设计的性格。
  • delight让那些重要的瞬间出人意料、令人满足，且分明属于你。
  • layout安排页面，让人知道该看哪里、什么与什么是一体的。
  • overdrive超越预期，让界面带来非凡感受。
  • quieter降低视觉噪音，同时保留设计的个性。
  • typeset让整个产品的文本更易读、易扫读、易辨认。

简化 3

  • adapt让现有设计在别的屏幕、设备或平台上同样好用。
  • clarify帮用户明白发生了什么、下一步该做什么。
  • distill减少杂乱，让重要的东西更容易找到。

加固 4

  • harden在数据、连接或操作出问题时，让界面保持可用。
  • onboard帮新用户尽快抵达第一个有用的结果。
  • optimize找出让界面变慢的原因，修复并度量结果。
  • polish让现有页面更有完成度、运转更好。

系统 5

  • document记录你的视觉系统，让后续工作有章可循。
  • extract把重复的 UI 模式提炼为共享组件与样式。
  • generate点名一个元素，比较各变体，留下最合意的那个。
  • init为 Impeccable 提供上下文，让它为你的项目做设计。
  • live指向你的页面，探索各变体，留下你喜欢的那个。
