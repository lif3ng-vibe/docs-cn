OpenRig 0.5.7 让运行中的拓扑不必手工编写 YAML 即可创建和重塑，并为智能体提供所加入工作的连贯、可寻址的安装。

## 弹性拓扑生命周期

- **免 YAML 创建。** 仅凭公开的 CLI 输入即可启动一个 rig，无需先编写 RigSpec。
- **就地扩展拓扑。** 向现有工作舱（pod）添加一个或多个成员，或创建并填充一个新的工作舱，混合结果如实上报。
- **保持声明忠实。** Spec show/export 保留拓扑，包括成员声明的智能体镜像来源，因此保存与重建不会悄然改变该成员的启动方式。
- **安全收缩。** 目标仍持有进行中的工作时，移除会被拒绝。显式的 drain 回退会保留队列条目的身份与状态，验证回退会话仍然存活，并只移除预期的席位或工作舱。普通的清理（无在途工作）依旧直接执行。

## 连贯的工作交付

- **可组合的产品旅程 SDLC。** 交付的工作模型组合了世界、项目、任务（mission）与切片（slice）上下文，而非要求一份单一的巨型简报。
- **实用的工作安装默认值。** 全新的项目、任务与切片脚手架提供惯用的 Markdown 与 manifest 文件，且不会覆盖已撰写的内容。
- **可选的 YAML 增强。** 项目 manifest 可添加撰写的项目意图与有序的上下文地址。可选值无效时明确告警，并保留安全的默认安装。
- **可寻址的 Markdown 加载。** 已安装的技能可以按相对地址解析精确的 Markdown 小节，包括经由常规的插件符号链接投影。
- **明确的项目身份。** 智能体可以选择和切换项目，而不必在根目录之间携带上下文；含糊、重复与未知的身份会被拒绝，而不是猜测。
- **完整的纯插件公开技能目录。** 每一个仅由插件提供的目录内公开技能，都会连同其说明所引用的辅助文件一并投影。
