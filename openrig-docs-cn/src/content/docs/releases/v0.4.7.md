> **⚠️ 里程碑：** v0.4.7 是 **Web UI 转入维护模式**的一版。自此版本起，CLI 成为首要产品呈现面；Web UI 仍随版、仍可用，但不再接收新特性工作。如果你今天仍从浏览器驱动 OpenRig，请规划向 CLI 的过渡（并自 v0.5.0 起过渡到终端 TUI：`rig` / `rig tui`）。0.4.7 随版的具体内容见下方 UI 小节。

## 摘要——恢复诚实性、starter 引导、技能浪潮、Slack 连接器与 UI 维护模式

**恢复诚实性是贯穿主线**。在恢复出的 restore 上，启动序列现在会在角色定义的首条消息之前加载该席位适用的技能预载（skill preload）——恢复中的席位在开工之前就知道自己的技能。压缩恢复是诚实的：会话记录摄取显式暴露降级状态，压缩后的恢复加审计以席位空闲为门，从而"restore-sent"真正意味着"已送达"。守护进程存活上报是诚实的——死席位把有效 running 降到 0 并上报 `attention_required`；席位不在时 `rig send` 与 `rig capture` 返回显式的"session missing"错误。CLI 探测诚实上报不确定性——无法确认的状态返回 `UNKNOWN` 且不给错误的启动建议；确认已停止的席位会失败并给出可操作的指引。

迁移仅增量。现有 v0.4.6 数据库在新守护进程上运行 `rig daemon start` 即可升级。

## 随版内容

### starter 引导

产品团队 starter 的引导更干净，并且 starter 席位在全新开始与恢复两种情况下都获得技能预载。默认文化在启动时加载，rig 规格在加载时接受审计。**v0.4.7 之前实例化的 rig 需要重新实例化**（或做规格级修补）才能获得 starter 修复——加载器与审计变更立即生效，但 starter 规格内容在实例化时落地。

### 技能浪潮

捆绑技能层获得公开路由与默认投影，外加公开技能剥离（public-skill strip）与镜像控制，外加一个让文档化技能数量保持诚实的插件修复。捆绑技能库存大幅增长，从寥寥数个扩展到覆盖核心、PM、工作舱（pod）与流程各家族的广泛覆盖。

### Slack 连接器与人工队列

头等的 Slack 连接器形态（CLI `rig slack` 命令 + 支撑库）。托管式创建跨越一次不确定的本地探测，直达真实的已配置守护进程结果。

### CLI 契约诚实性

`--json` 错误、标志校验与带范围的 overdue 行为为机器可读用途收紧。

### UI——转入维护模式

**Web UI 在本版本冻结于维护模式**。措辞以 CLI 为本——绝不说"弃用"（deprecated）；UI 仍随版、仍能运行，但不再接收新特性工作，CLI/TUI 是今后的首要呈现面。为向用户明确此状态而在 v0.4.7 落地的有：

- Web UI 内一条可关闭的应用内横幅，宣布维护模式状态。
- `rig ui open` 在启动时于 stderr 打印一则提示，让驱动 CLI 的操作者在打开浏览器之前就知道该状态。
- README 与面向用户的文档全面更新了定位文案。

既有的 v0.4.6 部署继续工作；没有任何移除。实质的产品投入转向 CLI，并自 v0.5.0 起转向终端 TUI。

### 队列、拓扑与评审打磨

- 队列精简列表行对被省略的字段加以标注，使"省略"与"空"可以区分。
- 嵌套审批（Nested Approve）会发布 missions 根相对的 scope 路径。
- mission 评审卡的构成经过打磨。
- 未验证的已交付条目读作"artifact-recorded"而非"什么都没交付"。
- 抽屉式文件查看器经 file-asset API 解析正文中的内联图片。
- 证明工作（proof-of-work）的 Markdown 链接在应用内抽屉中打开。
- 文档守卫为 `docs/DESIGN.md` 编码了根放置规则。

### 主机容量指引

建议：在主机上添加 swap，并以每席位约 2 GB RSS 作为观察到的基线来规划。

## 行为与兼容性

- **迁移**——仅增量。现有 v0.4.6 数据库在新守护进程上运行 `rig daemon start` 即可升级。
- **Rig 规格 starter 行为**——加载器与审计变更立即生效；starter 规格内容在 rig 实例化时落地。v0.4.7 之前实例化的 rig 需要重新实例化（或做规格级修补）才能获得 starter 修复。
- **席位存活 API**——消费方应以诚实的生命周期状态（每几秒更新一次）作为席位存活的键依据，而非旧的 session-status 字段，后者的过期清理已列入后续版本跟踪。
- **Web UI 姿态**——冻结于维护模式；无 CLI 呈现面破坏。本版本未从 UI 移除任何东西。
