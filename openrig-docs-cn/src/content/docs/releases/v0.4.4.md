## 摘要——多主机与活笔记（Living Notes）

OpenRig v0.4.4 落地多主机基础：一个共享的 rig 拓扑现在可以横跨多台主机，带一个分阶段的拉起流程、真实的跨主机文件移动，以及一个合并拓扑内所有主机信号的统一 For-You 活动信息流。VPS 产品工厂的故事为真实的多主机运营而硬化。

在多主机基础之外，本版本发布了**活笔记（Living Notes）信号层**——一个持久的、由智能体撰写的笔记呈现面，沿 mission 树串起 INTENT → PLAN → DELIVERED，并带一个一结构评审契约——自左向右读作一列垂直堆叠（INTENT 在上、PLAN 居中、DELIVERED 在下；计划变更时删除而非降级）。撰写呈现面让落笔便宜；评审呈现面让"意图 versus 实际构建"一眼可读。

操作者 UX 新增 **`rig ps` 整合默认**（token 高效默认值家族获得渐进披露，让默认视图一眼可读又不隐藏舰队）、一个在正确层级向操作者呈现多智能体状态的**智能体层级协作面板**，以及把发布 / 交付 / 生命周期杠杆收进单一控制面的 **operationalize-SDLC 控制平面**。as-built 文档收尾将一切补齐到位。

迁移（若有）均为增量式。现有 v0.4.3 数据库在新守护进程上运行 `rig daemon start` 即可升级。

## 随版内容

### 多主机基础

- **可分享的整拓扑分阶段拉起**——一个 rig 拓扑可以分阶段横跨多台主机拉起；规格与守护进程协同推进，直至整个舰队转绿，而不要求单主机一次性拉起。此版本之前，整拓扑拉起假定单台主机。
- **VPS 产品工厂多主机硬化**——已发布的 `openrig-user`/`openrig-architect` 操作者流程在 VPS / 自托管产品工厂场景下正确工作；多主机握手 + 注册硬化。
- **多主机统一 For-You 信息流**——For-You 信息流聚合拓扑内所有已注册主机的活动，而不仅是本地守护进程。0.4.3 的流分类器 + 真实数据忠实度逐主机生效，并向上游合并。一次真实主机的信息流订阅采集作为双保险证明随版（见已知后续项）。
- **`rig file` 跨主机移动**——文件经由 `rig file` 呈现面在拓扑的已注册主机之间移动。真实已注册主机的两主机端到端往返，在已并入的 VM 替身之上证明了该流程。

### 活笔记（Living Notes）

- **信号层**——mission 与切片层级上一个持久的、由智能体撰写的笔记呈现面；INTENT / PLAN / DELIVERED 条目带着智能体署名 + 时间戳沿 mission 树向下串接。
- **撰写呈现面**——低成本的撰写呈现面让活笔记成为智能体记录决策、计划与已交付工作的一等场所。
- **一结构评审契约（§3.1）——纠错式重建**——活笔记评审呈现面自左向右读作一个**单一垂直堆叠**（INTENT 在上，PLAN + 样机居中，DELIVERED 连同配对证明在下）；计划变更会**删除**旧计划并写入新计划——绝不降级 / 堆叠多份互相竞争的计划。经人工评审后，纠错式重建取代了更早的三栏布局。

### 操作者 UX

- **`rig ps` 整合默认 + 渐进披露**——默认的 `rig ps` 现在把舰队的可读行整合为一个一眼可读的默认视图；经 `--full` / `-A` / 逐范围过滤的渐进披露让丰富的逐节点记录仍可获取。遵循 0.4.0 建立的 token 高效默认值家族。
- **智能体层级协作面板**——一个限定在正确层级（工作区 / mission / 切片）的协作呈现面，让操作者看到真实的协作状态而不至于淹没在逐席位细节里。与 0.4.1 随版的工作区可观测标签页组合。

### 教义

- **让 SDLC 控制面运营化**——发布 / 交付 / 生命周期杠杆收进单一呈现面。随 0.4.1 → 0.4.3 发布的那些车道（发布切口的 squash + 有界 diff、sidecar 操作者主机切换、整理环节）现已成为头等的控制面动作，而非生命周期内的部落智慧。
- **as-built 文档收尾**——as-built 文档家族（`docs/as-built/architecture.md`、`docs/as-built/cli-reference.md`、codemaps）已补齐到 0.4.4 随版内容为止。

## 行为与兼容性

- **迁移**——仅增量。现有 v0.4.3 数据库在新守护进程上运行 `rig daemon start` 即可升级。
- **多主机注册**——多主机握手向后兼容单主机部署；单主机运行不变。
- **`rig ps` 默认视图**——整合默认是一个精简可读的视图；`--full` 返回 v0.4.3 的默认形态。
- **For-You 信息流**——多主机信息流聚合经由已注册主机成员关系选择性开启；单主机拓扑看不到任何行为变化。
