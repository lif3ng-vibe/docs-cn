OpenRig 是一个多智能体协作框架（multi-agent harness），让 Claude Code、Codex 与
Pi 作为一个系统协同工作——适合跨越数周甚至数月的项目。所有智能体都在你自己
的账户与终端里运行，自托管（self-hosted），数据不出本机。
