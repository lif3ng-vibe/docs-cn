**本文档是成熟度模型按址寻得的规范之家**：阶梯、它的时间尺度、晋升与降级、凭据规则，以及成熟度在各呈现面上的携带之处。一个说不清自身信任模型的语料，无法告诉你它正在腐坏——这就是本文档存在的理由。

## 阶梯

知识攀爬四个梯级：

**DATA → FIELD NOTES / OBSERVATIONS → INSIGHTS → CANON**（数据 → 现场笔记 / 观察 → 洞察 → 正典）

信任随成熟度走，而**一条论断的地址告诉你它的信任**。每个梯级的预期变化速率大约比下一级慢一个数量级：

| 梯级 | 变化时间尺度 | 存放之处（按地址） |
|---|---|---|
| 正典（canon） | 年——"它一直为真；我们只是发现并整理它" | `conventions/` · `doctrine/` · 原语 · `SOP.md` · `CULTURE.md` |
| 洞察 | 月——稳定，仍在积累信用 | `LEARNED.md` 的上半部 · 多数技能的判断性内容 |
| 现场笔记 / 观察 | 天至周——追踪现实 | `NOTES.md` · `LEARNED.md` 的生料半部 · `field-notes/` |
| 数据 | 连续 | 流事件 · 会话记录 · 回执 · 日志 |

## 正典由其时间尺度定义

"使某物成为正典的，是它的预期变化速率非常长。"正典之下的一切都变得更快，且在阶梯上越往下越快。对正典呈现面的一次更新，几乎从不意味着"正典变了"——它意味着我们发现或整理了更多本来就是正典的东西。`LEARNED.md` 是追踪变动现实的文件；`SOP.md` 是沉淀已定真相的文件。

落到体感上的推论：**正典的 diff 应当读起来像增补**。对既有正典行的频繁编辑是一个坏味道——要么这一行从来不是正典（降级它），要么有真实的东西变了（一次转向 pivot，值得仪式对待）。

## 晋升与降级

晋升在每个梯级上都是一个显式动作：**收获 / 注意 → 折入——以自己的话 → 整理**（显式、带日期）。内容以其现有成熟度进入体感层（`LEARNED.md`），随时间证明自己稳定，然后毕业。

发现向上流动；正典几乎从不向下回流——一旦回流，那是一次值得注意的降级事件。**降级合法但高声**：它刻意发出信号——被默认的正典不再成立。

## 凭据（warrant）规则

**一条被晋升的论断携带其压缩凭据**（warrant）——为它挣得信任的那道伤疤、那份证据或那纸裁定随行。"没有凭据的正典，是格式精美的货物崇拜。"凭据等级在凭据被点名时保持可辨：一条有决策背书的论断与一条反复被证实的法则，无需假装携带同样的证据。本文档自己的 frontmatter 就实践着这条规则。

## 成熟度是多维的

上文的认识论阶梯是一个维度。第二个是**上下文架构阶梯**：上下文如何被生产——底梯级是世界形状的散文（prose-in-a-world-shape）：可理解、有效、易漂移；顶梯级是从源派生（derived-from-source）：内容不会腐坏，因为一条命令就能重新派生它。

产品的要素是**阶梯概念——把系统造得让信息向上攀爬**，而不是任何具体的层数。这里的层数是描述性的，不是规范性的。系统设计应当把攀爬纳入考量：让日后派生成其为可能的接缝；自出生即打标签，使信任元数据在任何机器读取之前就开始积累。

## 两种编码，同一阶梯

成熟度在各呈现面上的携带方式不同。它们是同一阶梯的两种编码，由呈现面支持什么来选择——不是矛盾。

**语料与树文件按地址携带成熟度**。文件名法则就是阶梯：`NOTES.md` 之所以是现场笔记，因为名字就是这么说的；`conventions/` 与 `doctrine/` 因位置而是正典。晋升或降级是一次**移动**，而一次响亮地弄断引用的移动是特性——改变信任应当有仪式感。不需要逐节的级别标签；地址就是标签。

**包（pack）、lore 与 scope 条目自出生即以阶段字段携带成熟度**，使用随发行交付的词汇表（四个梯级加两个出口）：

`wip | provisional | established | canonical | superseded | retired`

`superseded` 必须点名其后继；`retired` 意为禁用。这些是**仅有的**合法取值——发明的阶段（shape、shaped、draft）会被拒绝。在新约定下铸造的条目自出生即带阶段：从第一天起打标签是免费的，事后补打是考古。

本节是 lore 与包工作的阶段词汇来源。分类轴（WORLD / LORE / SKILLS / MISSION）与阶段正交：**分类说它是什么种类，阶段说它多可信**。

## 成熟度不是什么

有两条轴习惯上与成熟度混为一谈，而它们不是：

- **受众 / 安放位置**。受众决定知识住在哪里——哪个高度、哪个文件；成熟度给其中的行定级。一个工作舱级条目可以是生观察，一个席位级条目可以是正典。晋升为正典是一次成熟度事件，不是沿树上移。关于机制的事实可以跳级（一条命令的验证即可定案）；关于实践的推断必须积累证据。
- **特性生命周期**。"特性生命周期独立于认识成熟度"——生命周期（`active | deprecated | retired`）回答智能体是否还应在一个行为之上继续构建；成熟度回答一条知识有多可信。

## 方向，而非构造

一种可能的终局是一个级别优先的语料树：一个地址字符串同时携带信任、领域、论断与新鲜度。它只是方向。

**本文档没有任何东西被机械化**：没有强制工具、没有批量重贴标签、也没有新的分层方案。本文档确立的是上述词汇表与自出生打标签；读取器、一致性检查与晋升工具都在其范围之外。
