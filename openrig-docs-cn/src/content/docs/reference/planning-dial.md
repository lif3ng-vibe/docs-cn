---
title: "规划档盘——一份计划获得多少严谨度，逐件选定"
---

规划是一条光谱，不是二值开关。波次模型（wave model）被选中时，构建的投入随波次构成而变化；规划需要同样的灵活性，否则每个构件都套用同一个协议——琐碎的被过度加工，困难的被加工不足。按工作自身的不确定性与后果来选档。

## 档级——按构件是什么来升档

- **P0——迷你需求 + 指针**。几句可观察的成果与去哪里查看；怎么做由构建者自行弄清。适用于简单、可逆、路径成熟的工作。
- **P1——成文规格**。意图、迷你需求、失败测试先行的证明契约、声明过的领地。默认档。
- **P2——再加一轮研究**，在规格冻结之前运行，绝不在构建期间进行。研究提示词由掌握产品上下文的智能体撰写（见下文语境门禁）；执行可以扇出到任意智能体——网络腿、文档腿、读代码腿并行。研究成果以**上下文**的形式、带着引用返回，绝不附带处方；随后要对照你自己的架构与意图做综合，且做法因绿地（greenfield，从头设计这个新东西）与棕地（brownfield，磨砺你既有的方法）而异。
- **P3——再加一轮对抗审查**（adversarial pass）。一位非作者、掌握产品上下文的人，以产品目标为裁判，从两个方向攻击这份计划。修订必须带着证明契约的牙齿落地——一个新的或被修改的复选框——绝不作为散文式建议。
- **P4——再加一道盲设计门禁**。在阅读既有设计（priors）之前，先提交一份从零开始的设计，然后做差异比对。相近 → 继续；显著不同 → 停下来与负责人开一场设计会。

## 语境门禁

只有安装了该产品世界上下文的智能体，才可以撰写研究提示词、执行对抗审查，或就架构问题发表意见。执行侧的研究者与构建者无需这种安装——但**创建**其指令的智能体必须具备。理由：由不了解产品用途的人塑造的研究，会流畅地回答一个错误的问题。

## 什么够得上 P2 或 P3——重要性不是判据

当一份规格若不靠研究就会在某个未决的外部未知上冻结时——一道可行性之门，或一个只有研究才能闭合的开放设计空间——该构件够得上 **P2**。当其失效模式对作者自身不可见时——承重基座，一个貌似合理、自我一致的计划会恰好带上它本要消灭的那种疾病——该构件够得上 **P3**。判别式是"一个错误的计划是否代价高昂、难以撤销、且从内部不可见"——绝不是"这个构件是否居于中心"。没有无法闭合的未知或作者盲区的失效模式，重要性本身只停在 P1。规划是纯文本工作；让它的范围与未决问题及错误计划的代价成比例，而不是为某个档级假定固定时长。

## 成本校准

把研究的范围限定在可能改变计划的那类未知上；把对抗审查的范围限定在作者可能错过的失效模式上。记录已解决的问题与由此产生的设计变更，让负责人得以判断所选档级的价值。把计划好的研究安排在构建分派之前运行，此时其答案仍能塑造规格。
