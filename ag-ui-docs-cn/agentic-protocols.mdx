## 智能体协议

智能体生态正在迅速围绕一组开放且互补的协议整合成型——每个协议各解决一个不同的交互层。AG-UI 已成为 AI 协议版图中的第三根支柱：

  <img src="/images/ai-protocol-stack.png" alt="AI 协议栈" style={{maxWidth: '40%', height: 'auto', borderRadius: '8px'}} />
</div>

你可以通过 **AG-UI**、**MCP** 和 **A2A** 把应用直接连接到智能体。


- **MCP**（Model Context Protocol）把智能体连接到工具与上下文——而这些工具本身也正变得越来越智能体化。
- **A2A**（Agent to Agent）把智能体连接到其他智能体。
- **AG-UI**（Agent–User Interaction）把智能体连接到用户（经由面向用户的应用）。
    
    你可以把 AG-UI 理解为一个**包罗万象的协议**——它源自自下而上的真实需求，为构建一流的智能体应用而生。
    

这三种智能体协议彼此互补、技术目标各不相同；单个智能体完全可以——而且经常——同时使用这三者。

## AG-UI 与 MCP、A2A 的握手对接

AG-UI 的贡献者最近加入了握手对接机制，让 AG-UI 能够通过 MCP 和 A2A 协议为智能体"打头阵"，从而使 AG-UI 客户端应用与库可以无缝使用支持 MCP 和 A2A 的智能体。

AG-UI 的使命是支持现代智能体应用所需的全部构建模块。

## 生成式 UI 规范

最近，多个[生成式 UI 规范](./concepts/generative-ui-specs)（包括 MCP-UI、Open JSON UI 和 A2UI）相继发布，它们允许智能体通过交互协议输出 UI 组件。AG-UI 与所有这些规范都能配合使用。欢迎访问我们的[生成式 UI 规范页面](./concepts/generative-ui-specs)了解更多。
