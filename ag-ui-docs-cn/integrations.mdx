本页展示各种智能体–用户交互协议（AG-UI）集成，体现该协议的能力与多样性。

## 前端集成

- **[CopilotKit](https://copilotkit.ai)**——为你的产品打造 AI copilot。

## 智能体框架

- **[LangChain](https://www.langchain.com/langgraph)**——在智能体控制与自主性之间取得平衡
- **[Microsoft Agent Framework](https://github.com/microsoft/agent-framework)**——用于构建、编排与部署 AI 智能体及多智能体工作流的框架，支持 Python 与 .NET。
- **[Google ADK](https://google.github.io/adk-docs/)**——Google 的 Agent Development Kit，用于结合 Gemini 模型构建 AI 智能体。AG-UI 同时支持其 [Python 中间件](https://github.com/ag-ui-protocol/ag-ui/tree/main/integrations/adk-middleware/python)与 [JavaScript 运行时集成](/integrations/google-adk-js)，并配有 [ADK JavaScript 实时演示](https://dojo.ag-ui.com/adk-js/feature/agentic_chat?openCopilot=true)。
- **[Google Antigravity](https://github.com/google-antigravity/antigravity-sdk-python)**——Google 的智能体 harness SDK，在一个打包的本地进程中运行模型、其工具与会话
- **[AWS Strands Agents](https://github.com/strands-agents/sdk-python)**——一种模型驱动的 AI 智能体构建方式
- **[Mastra](https://mastra.ai)**——TypeScript 智能体框架
- **[Pydantic AI](https://github.com/pydantic/pydantic-ai)**——可直接用于生产环境的 Python AI 智能体
- **[Agno](https://agno.com)**——用于构建多智能体系统的全栈框架
- **[LlamaIndex](https://www.llamaindex.ai)**——面向 LLM 应用的数据框架，具备 RAG 能力与工作流编排
- **[CrewAI](https://crewai.com)**——用强大的 AI 智能体简化各行业的工作流。
- **[AG2](https://ag2.ai)**——开源 AgentOS
- **[Claude Managed Agents](https://platform.claude.com/docs/en/managed-agents/overview)**——Anthropic 托管的智能体会话，已通过 TypeScript、Python 与 .NET 桥接到 AG-UI
- **[Claude Agent SDK](https://github.com/ag-ui-protocol/ag-ui/tree/main/integrations/claude-agent-sdk)**——Anthropic 的本地智能体 SDK，通过 AG-UI 提供服务
- **[Langroid](https://github.com/ag-ui-protocol/ag-ui/tree/main/integrations/langroid)**——用于构建多智能体 LLM 应用的轻量 Python 框架
- **[OpenAI Agents SDK](https://openai.github.io/openai-agents-python/)**——OpenAI 用于构建智能体应用的 Python 框架
- **[Cloudflare Agents](https://github.com/ag-ui-protocol/ag-ui/tree/main/integrations/community/cloudflare-agents)**——运行于 Cloudflare Workers 与 Durable Objects 之上的智能体，通过 AG-UI 提供服务
- **[Omnara](https://omnara.com)**——面向持久化托管智能体的开源控制平面，已通过 TypeScript 桥接到 AG-UI（[快速上手](/integrations/omnara)）

## 基础设施与部署

- **[Amazon Bedrock AgentCore](https://aws.amazon.com/bedrock/agentcore/)**——全托管基础设施，可将 AG-UI 智能体部署到生产环境，原生支持该协议，并提供托管身份验证、会话隔离与自动扩缩容。请参阅[部署指南](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/runtime-agui.html)与[发布公告](https://aws.amazon.com/about-aws/whats-new/2026/03/amazon-bedrock-agentcore-runtime-ag-ui-protocol/)。

## 规范（标准）
- **[Oracle Open Agent Spec](http://oracle.github.io/agent-spec/)**——一种用于定义智能体系统的可移植语言
- **[A2A Middleware](https://a2a-protocol.org/)**——为智能体互操作提供权威的通用语言

## 生成式 UI
- **[A2UI](https://github.com/google/A2UI)**——声明式生成式 UI，用于生成丰富、可交互的界面
- **[MCP Apps](https://blog.modelcontextprotocol.io/posts/2025-11-21-mcp-apps/)**——把来自 MCP 服务端的交互式 UI 组件直接渲染到你的对话界面中
