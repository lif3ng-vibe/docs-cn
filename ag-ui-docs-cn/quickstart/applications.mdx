# 简介

AG-UI 提供一套简洁的事件驱动协议，让任意智能体（agent）都能向任意客户端流式输出丰富、结构化的内容。它可以把任意智能体系统连接到任意客户端。

客户端指任何能够接收、展示并响应 AG-UI 事件的系统。有关现有客户端与集成的更多信息，请参阅[集成](/integrations)页面。

# 自动化搭建
AG-UI 提供一个 CLI 工具，可以自动创建或生成一个搭配任意客户端与服务端的新应用。

```sh
npx create-ag-ui-app@latest
```

<img
  className="w-full rounded-3xl mx-auto"
  src="https://copilotkit-public-assets.s3.us-east-1.amazonaws.com/docs/ag-ui/quickstart.gif"
/>

搭建完成后，用以下命令启动服务端

```sh
npm run dev
```

对于 CopilotKit 示例，打开 [http://localhost:3000](http://localhost:3000) 即可看到应用运行的效果。
