# AbstractAgent

`AbstractAgent` 类是智能体–用户交互协议中所有智能体实现的基础。它负责核心事件流处理、状态管理与消息历史。

```typescript
import { AbstractAgent } from "@ag-ui/client"
```

## 配置

默认情况下，所有智能体都通过向构造函数传入一个可选的 `AgentConfig` 对象来完成配置。

```typescript
interface AgentConfig {
  agentId?: string // The identifier of the agent
  description?: string // A description of the agent, used by the LLM
  threadId?: string // The conversation thread identifier
  initialMessages?: Message[] // An array of initial messages
  initialState?: State // The initial state of the agent
  maxEnforcedEntries?: number // Entry limit per incoming event, and per outgoing input for HttpAgent (default 1,000,000; Infinity disables)
}
```

### 在子类中添加配置选项

要添加更多配置选项，建议扩展 `AgentConfig` 接口，并在你的子类中用扩展后的配置调用超类构造函数，如下所示：

```typescript
interface MyAgentConfig extends AgentConfig {
  myConfigOption: string
}

class MyAgent extends AbstractAgent {
  private myConfigOption: string

  constructor(config: MyAgentConfig) {
    super(config)
    this.myConfigOption = config.myConfigOption
  }
}
```

## 核心方法

### runAgent()

执行智能体并处理其结果的主要方法。

```typescript
runAgent(parameters?: RunAgentParameters, subscriber?: AgentSubscriber): Promise<RunAgentResult>
```

#### 参数

```typescript
interface RunAgentParameters {
  runId?: string // Unique ID for this execution run
  tools?: Tool[] // Available tools for the agent
  context?: Context[] // Contextual information
  forwardedProps?: Record<string, any> // Additional properties to forward
}
```

可选的 `subscriber` 参数允许你提供一个 [AgentSubscriber](/sdk/js/client/subscriber)，用于处理此次运行期间的事件。

#### 返回值

```typescript
interface RunAgentResult {
  result: any // The final result returned by the agent
  newMessages: Message[] // New messages added during this run
}
```

### subscribe()

添加一个 [AgentSubscriber](/sdk/js/client/subscriber)，用于处理跨多次智能体运行的事件。

```typescript
subscribe(subscriber: AgentSubscriber): { unsubscribe: () => void }
```

返回一个带有 `unsubscribe()` 方法的对象，以便在不再需要该订阅者时将其移除。

### use()

向智能体的事件处理管线添加中间件（middleware）。

```typescript
use(...middlewares: (Middleware | MiddlewareFunction)[]): this
```

中间件可以是以下两种形式：
- **函数式中间件**：转换事件流的简单函数
- **类式中间件**：`Middleware` 类的实例，用于有状态操作

```typescript
// Function middleware
agent.use((input, next) => {
  console.log("Processing:", input.runId);
  return next.run(input);
});

// Class middleware
agent.use(new FilterToolCallsMiddleware({
  allowedToolCalls: ["search"]
}));

// Chain multiple middleware
agent.use(loggingMiddleware, authMiddleware, filterMiddleware);
```

中间件按添加顺序执行，每个中间件包裹下一个。中间件会在 `runAgent()` 中生效；`connectAgent()` 目前则直接调用 `connect()`。更多细节参见 [Middleware 文档](/sdk/js/client/middleware)。

### getCapabilities()

返回智能体当前的能力（capabilities）。可选方法——子类可实现它来声明自己支持哪些能力；未实现时返回 `undefined`。

```typescript
getCapabilities?(): Promise<AgentCapabilities>
```

完整的 `AgentCapabilities` 类型定义与用法模式参见 [Capabilities（能力）](/concepts/capabilities)。

### abortRun()

取消当前的智能体执行。

```typescript
abortRun(): void
```

### clone()

创建智能体实例的深拷贝。

```typescript
clone(): AbstractAgent
```

### connectAgent()

与实现了 `connect()` 方法的智能体建立持久连接。

```typescript
connectAgent(parameters?: RunAgentParameters, subscriber?: AgentSubscriber): Promise<RunAgentResult>
```

与 `runAgent()` 类似，但内部使用 `connect()` 方法。智能体必须实现 `connect()`，否则该功能需由 [CopilotKit](https://copilotkit.ai) 之类的框架提供。

## 可观察属性

### events$

智能体执行期间发出的所有事件组成的可观察流。

```typescript
events$: Observable<BaseEvent>
```

该属性提供对智能体事件流的直接访问。事件通过 `ReplaySubject` 存储，因此较晚加入的订阅者也能收到全部历史事件。

## 属性

- `agentId`：智能体实例的唯一标识符
- `description`：人类可读的描述
- `threadId`：会话线程标识符
- `messages`：会话消息数组
- `state`：当前智能体状态对象
- `events$`：智能体执行期间发出的所有 `BaseEvent` 对象组成的可观察流（对较晚加入的订阅者进行重放）

## 受保护方法

这些方法供子类实现或扩展：

### run()

执行智能体并返回一个可观察的事件流。

```typescript
protected abstract run(input: RunAgentInput): RunAgent
```

### connect()

建立持久连接并返回一个可观察的事件流。

```typescript
protected connect(input: RunAgentInput): RunAgent
```

重写该方法以实现持久连接。默认实现会抛出 `ConnectNotImplementedError`。

### apply()

处理运行产生的事件并更新智能体状态。

```typescript
protected apply(input: RunAgentInput): ApplyEvents
```

### prepareRunAgentInput()

为智能体执行准备输入参数。

```typescript
protected prepareRunAgentInput(parameters?: RunAgentParameters): RunAgentInput
```

### onError() 与 onFinalize()

用于错误处理与清理操作的生命周期钩子。

```typescript
protected onError(error: Error): void
protected onFinalize(): void
```
