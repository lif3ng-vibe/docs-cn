# @ag-ui/client

智能体–用户交互协议（AG-UI）客户端 SDK 为 AI 系统提供多种智能体连接方式。该包构建于核心类型与事件之上，为智能体实现交付灵活的连接方案。

```bash
npm install @ag-ui/client
```

## AbstractAgent

`AbstractAgent` 是实现自定义智能体连接的抽象智能体基类（base agent class）。继承该类并实现 `run()`，即可将你自己的服务或智能体实现接入 AG-UI。

- [配置](/sdk/js/client/abstract-agent#配置) - 使用智能体 ID、消息与状态完成设置
- [核心方法](/sdk/js/client/abstract-agent#核心方法) - 运行、中止与克隆功能
- [受保护方法](/sdk/js/client/abstract-agent#受保护方法) - 面向自定义实现的可扩展钩子
- [属性](/sdk/js/client/abstract-agent#属性) - 状态与消息追踪

## Middleware

- [函数式中间件](/sdk/js/client/middleware#函数式中间件) - 用普通函数完成简单转换
- [类式中间件](/sdk/js/client/middleware#类式中间件) - 带配置的有状态中间件
- [内置中间件](/sdk/js/client/middleware#内置中间件) - FilterToolCallsMiddleware 等
- [中间件模式](/sdk/js/client/middleware#中间件模式) - 常见用例与示例

## AgentSubscriber

面向事件驱动的订阅者（subscriber）系统，用于在智能体执行期间处理生命周期事件与状态变更：

- [事件处理器](/sdk/js/client/subscriber#事件处理器) - 生命周期、消息、工具调用与状态事件
- [状态管理](/sdk/js/client/subscriber#state-management) - 变更控制与传播处理
- [使用示例](/sdk/js/client/subscriber#usage-examples) - 日志、持久化与错误处理模式
- [集成](/sdk/js/client/subscriber#与智能体集成) - 在智能体上注册与使用订阅者
