# HttpAgent

`HttpAgent` 继承自 `AbstractAgent`，提供基于 HTTP 的方式连接远程 AI 智能体。它负责请求/响应周期，并将 HTTP 事件流转换为标准的智能体–用户交互协议事件。

```typescript
import { HttpAgent } from "@ag-ui/client"
```

## 配置

创建 HTTP 智能体时，需要提供一个 `HttpAgentConfig` 对象：

```typescript
interface HttpAgentConfig extends AgentConfig {
  url: string // Endpoint URL for the agent service
  headers?: Record<string, string> // Optional HTTP headers
}
```

## 创建 HttpAgent

```typescript
const agent = new HttpAgent({
  url: "https://api.example.com/v1/agent",
  headers: {
    Authorization: "Bearer your-api-key",
  },
})
```

## 方法

### runAgent()

通过向配置的端点发起 HTTP 请求来执行智能体。

```typescript
runAgent(parameters?: RunAgentParameters, subscriber?: AgentSubscriber): Promise<RunAgentResult>
```

#### 参数

`parameters` 参数遵循标准的 `RunAgentParameters` 接口。可选的 `subscriber` 参数允许你提供一个 [AgentSubscriber](/sdk/js/client/subscriber)，用于处理此次运行期间的事件。

#### 返回值

```typescript
interface RunAgentResult {
  result: any // The final result returned by the agent
  newMessages: Message[] // New messages added during this run
}
```

### subscribe()

添加一个 [AgentSubscriber](/sdk/js/client/subscriber)，用于处理跨多次智能体运行的事件。

```typescript
subscribe(subscriber: AgentSubscriber): { unsubscribe: () => void }
```

返回一个带有 `unsubscribe()` 方法的对象，以便在不再需要该订阅者时将其移除。

### abortRun()

使用 AbortController 取消当前的 HTTP 请求。

```typescript
abortRun(): void
```

## 受保护方法

### requestInit()

配置 HTTP 请求。重写该方法即可自定义请求的发起方式。

```typescript
protected requestInit(input: RunAgentInput): RequestInit
```

默认实现：

```typescript
{
  method: "POST",
  headers: {
    ...this.headers,
    "Content-Type": "application/json",
    Accept: "text/event-stream",
  },
  body: JSON.stringify(input),
  signal: this.abortController.signal,
}
```

### run()

使用 HTTP 请求实现 `AbstractAgent` 中的抽象方法 `run()`。

```typescript
run(input: RunAgentInput): RunAgent
```

## 属性

- `url`：智能体服务的端点 URL
- `headers`：随请求一起发送的 HTTP 请求头
- `abortController`：用于取消请求的 AbortController 实例
