# @ag-ui/core

智能体–用户交互协议 SDK 采用基于事件的流式架构与强类型数据结构。该包提供了连接智能体系统的基础。

```bash
npm install @ag-ui/core
```

## 类型

构成系统基石的核心数据结构：

- [RunAgentInput](/sdk/js/core/types#runagentinput) - 运行智能体的输入参数
- [Message](/sdk/js/core/types#message-types) - 用户与助手之间的通信及工具使用
- [Context](/sdk/js/core/types#context) - 提供给智能体的上下文信息
- [Tool](/sdk/js/core/types#tool) - 定义智能体可以调用的函数
- [State](/sdk/js/core/types#state) - 智能体状态管理

## 事件

驱动智能体与前端之间通信的事件：

- [生命周期事件](/sdk/js/core/events#lifecycle-events) - 运行与步骤追踪
- [文本消息事件](/sdk/js/core/events#text-message-events) - 助手消息流式传输
- [工具调用事件](/sdk/js/core/events#tool-call-events) - 函数调用生命周期
- [状态管理事件](/sdk/js/core/events#state-management-events) - 智能体状态更新
- [特殊事件](/sdk/js/core/events#special-events) - 原始事件与自定义事件
