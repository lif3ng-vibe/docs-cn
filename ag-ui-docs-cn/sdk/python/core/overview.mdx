# ag_ui.core

智能体–用户交互协议（AG-UI）SDK 采用基于事件的流式架构和强类型数据结构。本包为
连接智能体系统提供基础。

```python
from ag_ui.core import ...
```

## 类型

构成系统基础模块的核心数据结构：

- [RunAgentInput](/sdk/python/core/types#runagentinput) - 运行智能体的输入参数
- [消息类型](/sdk/python/core/types#message-types) - 用户与助手的通信以及工具使用
- [上下文](/sdk/python/core/types#context) - 提供给智能体的上下文信息
- [工具](/sdk/python/core/types#tool) - 定义智能体可以调用的函数
- [状态](/sdk/python/core/types#state) - 智能体状态管理

- [工具调用事件](/sdk/python/core/events#tool-call-events) - 函数调用的生命周期
- [状态管理事件](/sdk/python/core/events#state-management-events) -
  智能体状态更新
