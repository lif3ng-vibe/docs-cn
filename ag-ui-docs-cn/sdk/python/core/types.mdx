# 核心类型

智能体–用户交互协议（AG-UI）Python SDK 构建在一组核心类型之上，它们表示整个系统中
使用的基础结构。本页记录这些类型及其属性。

## RunAgentInput

`from ag_ui.core import RunAgentInput`

运行智能体的输入参数。在 HTTP API 中，它是 `POST` 请求的请求体。

`tools` 包含客户端为本次运行提供的工具。后端定义的工具应保留在后端智能体或框架配置
中，并可通过智能体能力单独对外宣告。

```python
class RunAgentInput(ConfiguredBaseModel):
    thread_id: str
    run_id: str
    parent_run_id: Optional[str] = None
    state: Any = None  # optional: absent means "no state"; a bare null reads as absent
    messages: List[Message]
    tools: List[Tool]
    context: List[Context]
    forwarded_props: Any
    resume: Optional[List[ResumeEntry]] = None
```

| 属性              | 类型                          | 说明                                                                                         |
| ----------------- | ----------------------------- | --------------------------------------------------------------------------------------------------- |
| `thread_id`       | `str`                         | 会话线程的 ID                                                                       |
| `run_id`          | `str`                         | 当前运行的 ID                                                                               |
| `parent_run_id`   | `Optional[str]`               | （可选）派生出本次运行的父运行的 ID                                                      |
| `state`           | `Any`                         | （可选）智能体当前状态；缺省表示“无状态”，裸 `null` 读作缺省 |
| `messages`        | `List[Message]`               | 会话中的消息列表                                                                |
| `tools`           | `List[Tool]`                  | 本次运行可用的客户端提供工具                                                        |
| `context`         | `List[Context]`               | 提供给智能体的上下文对象列表                                                       |
| `forwarded_props` | `Any`                         | 转发给智能体的附加属性                                                        |
| `resume`          | `Optional[List[ResumeEntry]]` | 以中断结果结束的运行在恢复时的逐中断响应                      |

## ResumeEntry

`from ag_ui.core import ResumeEntry`

`RunAgentInput.resume` 中每个中断对应一条响应，针对上一次运行中的某个中断。
完整的 resume 契约见[中断](/concepts/interrupts#resuming-a-run)。

```python
class ResumeEntry(GeneratedBaseModel):
    interrupt_id: str
    status: ResumeStatus  # "resolved" | "cancelled"
    payload: Optional[Any] = None
    metadata: Optional[Metadata] = None
```

| 属性           | 类型                       | 说明                                                                           |
| -------------- | -------------------------- | ------------------------------------------------------------------------------------- |
| `interrupt_id` | `str`                      | 本条目所针对的中断的 ID                                              |
| `status`       | `ResumeStatus`             | 用户已响应时为 `"resolved"`，用户放弃时为 `"cancelled"`                   |
| `payload`      | `Optional[Any]`            | 响应本身，依据该中断的 `response_schema` 校验              |
| `metadata`     | `Optional[Dict[str, Any]]` | 关于该响应的信封数据——签名、路由 key 等——绝不是答案本身 |

`metadata` 遵循协议中其他所有元数据相同的约定：按键开放，key 下允许任意 JSON 值
（包括 `None`）；对象本身要么缺省、要么是映射（mapping），在线上绝不会是 `null`；
并且 `ag-ui` 这个 key 保留为 AG-UI 自用。resume 条目是一个请求字段，因此不会有任何
内容合并进它；见[元数据](/concepts/metadata#resume-entries)。

## 消息类型

SDK 包含若干消息类型，表示系统中不同种类的消息。

<Note>
  每种消息类型都携带可选的 `metadata` 对象（`Optional[Dict[str, Any]]`），`ToolCall`
  也是。为省篇幅，两者都从下面的分类型表格中省略。它按键开放——key 下允许任意
  JSON 值，包括 `None`——对象本身可以缺省但绝不会是 `None`。
  `ag-ui` key 保留为 AG-UI 自用。元数据会随消息由其事件构建而逐步累积，工具调用事件
  则累积到工具调用本身；合并规则见[元数据](/concepts/metadata)。
</Note>

### PartSource

表示非文本部分的提供方式。

```python
PartSource = Annotated[
    Union[DataSource, UrlSource, FileSource],
    Field(discriminator="type"),
]

class DataSource(ConfiguredBaseModel):
    type: Literal["data"]
    value: str
    mime_type: str

class UrlSource(ConfiguredBaseModel):
    type: Literal["url"]
    value: str
    mime_type: Optional[str] = None

class FileSource(ConfiguredBaseModel):
    type: Literal["file"]
    value: str  # the handle, exactly as the provider issued it
    provider: Optional[str] = None  # who issued it, e.g. "openai", "anthropic", "google"
    mime_type: Optional[str] = None
```

`FileSource` 指代已经存放在模型提供商处的字节——例如 OpenAI 或 Anthropic 的文件 ID、
Gemini 的文件 URI。不会发生任何抓取，`value` 是不透明的：智能体把它交回自己的提供商
或丢弃该部分，绝不会把它当作 URL。

### TextPart

表示用户消息或工具结果内的文本部分。

```python
class TextPart(ConfiguredBaseModel):
    type: Literal["text"]
    id: Optional[str] = None
    text: str
    metadata: Optional[Any] = None
```

| 属性       | 类型              | 说明                                                               |
| ---------- | ----------------- | ------------------------------------------------------------------------- |
| `type`     | `Literal["text"]` | 标识该部分的类型                                                  |
| `id`       | `Optional[str]`   | 在所属消息内标识该部分                                    |
| `text`     | `str`             | 文本内容                                                              |
| `metadata` | `Optional[Any]`   | 关于该部分的附加信息，例如搜索命中的来源与标题 |

### BinaryInputContent

表示图像、音频或文件等二进制数据。

```python
class BinaryInputContent(ConfiguredBaseModel):
    type: Literal["binary"]
    mime_type: str
    id: Optional[str] = None
    url: Optional[str] = None
    data: Optional[str] = None
    filename: Optional[str] = None
```

| 属性        | 类型                | 说明                                   |
| ----------- | ------------------- | --------------------------------------------- |
| `type`      | `Literal["binary"]` | 标识该片段的类型                  |
| `mime_type` | `str`               | MIME 类型，例如 `"image/png"`          |
| `id`        | `Optional[str]`     | 对先前已上传内容的引用      |
| `url`       | `Optional[str]`     | 可获取该内容的远程 URL |
| `data`      | `Optional[str]`     | base64 编码的内容                        |
| `filename`  | `Optional[str]`     | 可选的文件名提示                        |

> **校验**：`id`、`url`、`data` 至少要提供一个。
>
> **已废弃**：`BinaryInputContent` 仍作为临时兼容模型保留。请优先使用下文的模态特有
> 部分。
