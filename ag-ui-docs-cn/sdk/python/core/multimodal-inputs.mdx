# 多模态输入

`UserMessage.content` 接受纯文本或多模态部分（parts）的有序列表。

```python
from ag_ui.core import (
    UserMessage,
    TextPart,
    ImagePart,
    DocumentPart,
    UrlSource,
)

message = UserMessage(
    id="user-1",
    content=[
        TextPart(text="Summarize this PDF and screenshot"),
        ImagePart(
            source=UrlSource(
                value="https://example.com/screen.png",
                mime_type="image/png",
            )
        ),
        DocumentPart(
            source=UrlSource(
                value="https://example.com/report.pdf",
                mime_type="application/pdf",
            )
        ),
    ],
)
```

## 来源类型

用 `source.type` 描述负载的交付方式：

- `data`：内联 base64 负载，`mime_type` 必填
- `url`：HTTP(S) 或 data URL，`mime_type` 可选

## 常见用例

### 视觉问答

```python
from ag_ui.core import UserMessage, TextPart, ImagePart, UrlSource

message = UserMessage(
    id="q1",
    content=[
        TextPart(text="What issue do you see in this UI?"),
        ImagePart(
            source=UrlSource(
                value="https://example.com/ui.png",
                mime_type="image/png",
            ),
            metadata={"detail": "high"},
        ),
    ],
)
```

### 音频转录

```python
from ag_ui.core import UserMessage, TextPart, AudioPart, UrlSource

message = UserMessage(
    id="q2",
    content=[
        TextPart(text="Transcribe this recording."),
        AudioPart(
            source=UrlSource(
                value="https://example.com/meeting.wav",
                mime_type="audio/wav",
            )
        ),
    ],
)
```

### 已废弃的二进制模型

`BinaryInputContent` 已废弃，使用时会发出 `DeprecationWarning`。它作为迁移到模态
特有部分之前的临时兼容路径保留。
