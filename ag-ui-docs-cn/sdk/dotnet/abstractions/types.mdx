# AGUI.Abstractions 类型

`AGUI.Abstractions` 包含 AG-UI .NET 客户端与服务端共用的协议模型。JSON 线上名称
（wire names）采用 camel-case，与 AG-UI 协议保持一致。

## RunAgentInput

`RunAgentInput` 是运行智能体的请求负载（payload）。在 HTTP API 中，它是
`POST` 请求的请求体。

```csharp
using System.Text.Json;
using AGUI.Abstractions;

var input = new RunAgentInput
{
    ThreadId = "thread-1",
    RunId = "run-1",
    Messages =
    [
        new AGUIUserMessage
        {
            Id = "msg-1",
            Content = "Hello!"
        }
    ],
    Tools =
    [
        new AGUITool
        {
            Name = "get_weather",
            Description = "Get the weather for a city",
            Parameters = JsonDocument.Parse("""
                {
                  "type": "object",
                  "properties": {
                    "city": { "type": "string" }
                  },
                  "required": ["city"]
                }
                """).RootElement.Clone()
        }
    ]
};
```

| C# 属性 | JSON 字段 | 类型 | 说明 |
| ----------- | ---------- | ---- | ----------- |
| `ThreadId` | `threadId` | `string` | 会话线程的 ID |
| `RunId` | `runId` | `string` | 当前运行的 ID |
| `ParentRunId` | `parentRunId` | `string?` | 可选的血统指针，用于分支或时间旅行 |
| `Messages` | `messages` | `IList<AGUIMessage>` | 对话消息 |
| `Tools` | `tools` | `IList<AGUITool>?` | 智能体可用的工具 |
| `State` | `state` | `JsonElement?` | 当前的前端或智能体状态 |
| `Resume` | `resume` | `IList<AGUIResume>?` | 被中断运行的 resume 负载 |
| `Context` | `context` | `IList<AGUIContext>?` | 提供给智能体的上下文对象 |
| `ForwardedProperties` | `forwardedProps` | `JsonElement` | 客户端转发的附加属性 |

## AGUIResume

`RunAgentInput.Resume` 中每个中断对应一条响应，针对上一次运行中的某个中断。
完整的 resume 契约见[中断](/concepts/interrupts#resuming-a-run)。

| C# 属性 | JSON 字段 | 类型 | 说明 |
| ----------- | ---------- | ---- | ----------- |
| `InterruptId` | `interruptId` | `string` | 本条目所针对的中断的 ID |
| `Status` | `status` | `string` | 用户已响应时为 `ResumeStatus.Resolved`，用户放弃时为 `ResumeStatus.Cancelled` |
| `Payload` | `payload` | `JsonElement?` | 响应本身，依据该中断的 `responseSchema` 校验 |
| `Metadata` | `metadata` | `JsonElement?` | 关于该响应的信封数据——签名、路由 key 等——绝不是答案本身 |

`Metadata` 遵循协议中其他所有元数据相同的约定：按键开放（open by key），key 下允许
任意 JSON 值（包括 `null`）；对象本身要么缺省、要么是对象，在线上绝不会是 `null`；
并且 `ag-ui` 这个 key（`AGUIMetadata.ReservedKey`）保留为 AG-UI 自用。resume 条目是
一个请求字段，因此不会有任何内容合并进它；见[元数据](/concepts/metadata#resume-entries)。
对于非工具类中断，托管层（hosting layer）会把它带到 `InterruptResponseContent.Metadata`
上，`AGUIChatClient` 再把它从 `InterruptResponseContent` 复制到它发送的条目上。
工具批准条目会经由 MEAI 自己的批准内容类型转换，而那些类型没有元数据入口——如果在那里
需要元数据，请通过 `RunAgentInput.Resume` 读取原始条目。

## 消息类型

消息构成一棵以 `AGUIMessage` 为根的封闭层级。基类型只携带所有角色共享的字段：
`Id`、`Role` 和 `Metadata`。角色特有的属性，例如 `content`、`name`、
`encryptedValue`、`toolCalls` 和 `toolCallId`，则声明在各个 sealed 角色类上。

<Note>
  每个消息角色以及 `AGUIToolCall` 都携带 `Metadata`（`JsonElement?`，JSON 字段
  `metadata`），为省篇幅下表将其省略。它按键开放——key 下允许任意 JSON 值，
  包括 `null`——对象本身可以缺省但绝不会是 `null`。
  `AGUIMetadata.ReservedKey`（`"ag-ui"`）保留为 AG-UI 自用。
  元数据会随消息由其事件构建而逐步累积，工具调用事件则累积到工具调用本身；
  合并规则见[元数据](/concepts/metadata)。
</Note>

```csharp
public abstract class AGUIMessage
{
    public string? Id { get; set; } // "id"
    public abstract string Role { get; } // "role"
    public JsonElement? Metadata { get; set; } // "metadata"
}
```

### 角色

| -------- | ---------- |
| `AGUIRoles.Developer` | `developer` |
| `AGUIRoles.System` | `system` |
| `AGUIRoles.Assistant` | `assistant` |
| `AGUIRoles.User` | `user` |
| `AGUIRoles.Tool` | `tool` |
| `AGUIRoles.Activity` | `activity` |
| `AGUIRoles.Reasoning` | `reasoning` |

### AGUIUserMessage

`AGUIUserMessage.Content` 是一个 `AGUIContent` 值，用于建模 AG-UI 的线上联合类型
（wire union）`string | InputContent[]`。

```csharp
var textOnly = new AGUIUserMessage
{
    Id = "user-1",
    Content = "Summarize this image."
};

AGUIInputContent textPart = new AGUITextInputContent
{
    Text = "What is shown here?"
};

AGUIInputContent imagePart = new AGUIImageInputContent
{
    Source = new AGUIInputContentUrlSource
    {
        Value = "https://example.com/screen.png",
        MimeType = "image/png"
    }
};

var multimodal = new AGUIUserMessage
{
    Id = "user-2",
    Content = [textPart, imagePart]
};
```

`AGUIContent` 支持从 `string`、`List<AGUIInputContent>` 和
`AGUIInputContent[]` 隐式转换，也提供了 collection builder，因此 C# 集合表达式可以
直接使用。读取时它实现 `IReadOnlyList<AGUIInputContent>`；纯字符串会以单个
`AGUITextInputContent` 部分的形式暴露。

| C# 属性 | JSON 字段 | 类型 | 说明 |
| ----------- | ---------- | ---- | ----------- |
| `Id` | `id` | `string?` | 消息 ID |
| `Role` | `role` | `"user"` | 固定角色判别值 |
| `Content` | `content` | `AGUIContent` | 纯文本或有序的多模态部分 |
| `Name` | `name` | `string?` | 可选的用户名称 |
| `EncryptedValue` | `encryptedValue` | `string?` | 可选的不透明加密值 |

`AGUIInputContent` 层级详见[多模态输入](/sdk/dotnet/abstractions/multimodal-inputs)。

### AGUIToolMessage

```csharp

{
    Id = "tool-msg-1",
    ToolCallId = "call-1",
    Content = """{"temperature":72}"""
```

## 工具

`AGUITool` 定义智能体可以调用的工具。

```csharp
var tool = new AGUITool
{
    Name = "get_weather",
    Description = "Get the weather for a city",
    Parameters = JsonDocument.Parse("""
        {
          "type": "object",
          "properties": {
            "city": { "type": "string" }
          },
          "required": ["city"]
        }
        """).RootElement.Clone(),
    Metadata = JsonDocument.Parse("""{"ui":"compact"}""").RootElement.Clone()
};
```

| C# 属性 | JSON 字段 | 类型 | 说明 |
| ----------- | ---------- | ---- | ----------- |
| `Name` | `name` | `string` | 工具名称 |
| `Description` | `description` | `string?` | 可选的工具描述 |
| `Parameters` | `parameters` | `JsonElement` | 工具参数的 JSON Schema |
| `Metadata` | `metadata` | `JsonElement?` | 可选的任意工具元数据 |

## 状态

状态在 `RunAgentInput.State` 上表示为 `JsonElement?`，在 `StateSnapshotEvent` 和
`StateDeltaEvent` 中表示为 `JsonElement` 负载。

```csharp
input.State = JsonDocument.Parse("""{"draft":"hello"}""").RootElement.Clone();
```

状态的 schema 由智能体定义，协议只负责携带它。

## AgentCapabilities

`AgentCapabilities` 是智能体可以暴露的结构化声明，客户端借此发现它支持哪些能力。
所有字段均为可选。

```csharp
var capabilities = new AgentCapabilities
{
    Identity = new IdentityCapabilities
    {
        Name = "Support Agent",
        Version = "1.0.0"
    },
    Transport = new TransportCapabilities
    {
        Streaming = true,
        Resumable = true
    },
    Tools = new ToolsCapabilities
    {
        Supported = true,
        ClientProvided = true
    },
    Multimodal = new MultimodalCapabilities
    {
        Input = new MultimodalInputCapabilities
        {
            Image = true,
            Audio = true,
            Pdf = true
        }
    }
};
```

| C# 属性 | JSON 字段 | 类型 | 说明 |
| ----------- | ---------- | ---- | ----------- |
| `Identity` | `identity` | `IdentityCapabilities?` | 智能体身份与元数据 |
| `Transport` | `transport` | `TransportCapabilities?` | 流式、websocket、二进制、推送与可恢复性支持 |
| `Tools` | `tools` | `ToolsCapabilities?` | 工具支持与工具调用配置 |
| `Output` | `output` | `OutputCapabilities?` | 结构化输出与支持的 MIME 类型 |
| `State` | `state` | `StateCapabilities?` | 快照、增量、记忆与持久化支持 |
| `MultiAgent` | `multiAgent` | `MultiAgentCapabilities?` | 委托、交接与子智能体信息 |
| `Reasoning` | `reasoning` | `ReasoningCapabilities?` | 推理、流式与加密推理支持 |
| `Multimodal` | `multimodal` | `MultimodalCapabilities?` | 多模态输入与输出支持 |
| `Execution` | `execution` | `ExecutionCapabilities?` | 代码执行与迭代/时间限制 |
| `HumanInTheLoop` | `humanInTheLoop` | `HumanInTheLoopCapabilities?` | 批准、干预、反馈、中断与带编辑批准 |
| `Custom` | `custom` | `JsonElement?` | 集成特有的能力，按键开放；用 `JsonSerializer.SerializeToElement(...)` 构建 |

协议层面的概念与使用模式见[能力](/concepts/capabilities)。

## 序列化

所有协议类型都注册在 `AGUIJsonSerializerContext`（一个源生成的
`JsonSerializerContext`）中。在对 AOT 敏感的代码里序列化协议类型时请使用它。

```csharp
var json = JsonSerializer.Serialize(
    input,
    AGUIJsonSerializerContext.Default.RunAgentInput);
```
