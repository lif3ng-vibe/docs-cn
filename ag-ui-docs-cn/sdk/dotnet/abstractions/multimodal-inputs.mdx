# 多模态输入

`AGUIUserMessage.Content` 通过 `AGUIContent` 联合类型接受纯文本或多模态内容部分
（content parts）的有序数组。

```csharp
using System.Text.Json;
using AGUI.Abstractions;

var message = new AGUIUserMessage
{
    Id = "user-1",
    Content =
    [
        new AGUITextInputContent
        {
            Text = "Summarize this PDF and screenshot"
        },
        new AGUIImageInputContent
        {
            Source = new AGUIInputContentUrlSource
            {
                Value = "https://example.com/screen.png",
                MimeType = "image/png"
            }
        },
        new AGUIDocumentInputContent
        {
            Source = new AGUIInputContentUrlSource
            {
                Value = "https://example.com/report.pdf",
                MimeType = "application/pdf"
            }
        }
    ]
};
```

## 用户消息内容

用户消息的 AG-UI 线上模型是 `content: string | InputContent[]`。
在 .NET 中由 `AGUIContent` 表示。

```csharp
var plainText = new AGUIUserMessage
{
    Id = "user-1",
    Content = "Hello"
};

var parts = new AGUIUserMessage
{
    Id = "user-2",
    Content =
    [
        new AGUITextInputContent { Text = "Describe this image." },
        new AGUIImageInputContent
        {
            Source = new AGUIInputContentUrlSource
            {
                Value = "https://example.com/image.png",
                MimeType = "image/png"
            }
        }
    ]
};
```

`AGUIContent` 支持从 `string`、`List<AGUIInputContent>` 和
`AGUIInputContent[]` 隐式转换，支持集合表达式，并实现
`IReadOnlyList<AGUIInputContent>` 以提供规范化的读取。当存储的值是字符串时，
只读列表门面会把它暴露为单个 `AGUITextInputContent`。

## 输入内容类型

所有内容部分都派生自 `AGUIInputContent`，并使用 JSON `type` 判别值。

| C# 类型 | JSON `type` | 属性 |
| ------- | ----------- | ---------- |
| `AGUITextInputContent` | `text` | `text` |
| `AGUIImageInputContent` | `image` | `source`, optional `metadata` |
| `AGUIAudioInputContent` | `audio` | `source`, optional `metadata` |
| `AGUIVideoInputContent` | `video` | `source`, optional `metadata` |
| `AGUIDocumentInputContent` | `document` | `source`, optional `metadata` |
| `AGUIBinaryInputContent` | `binary` | `mimeType`, optional `id`, `url`, `data`, `filename` |

### 文本

```csharp
var text = new AGUITextInputContent
{
    Text = "What issue do you see in this UI?"
};
```

| C# 属性 | JSON 字段 | 类型 | 说明 |
| ----------- | ---------- | ---- | ----------- |
| `Type` | `type` | `"text"` | 内容判别值 |
| `Id` | `id` | `string?` | 可选的部分标识符 |
| `Text` | `text` | `string` | 文本内容 |
| `Metadata` | `metadata` | `JsonElement?` | 可选的元数据，例如搜索命中的来源与标题 |

### 媒体部分

图像、音频、视频和文档都派生自 `AGUIMediaInputContent`。

```csharp
var image = new AGUIImageInputContent
{
    Source = new AGUIInputContentUrlSource
    {
        Value = "https://example.com/ui.png",
        MimeType = "image/png"
    },
    Metadata = JsonDocument.Parse("""{"detail":"high"}""").RootElement.Clone()
};
```

| C# 属性 | JSON 字段 | 类型 | 说明 |
| ----------- | ---------- | ---- | ----------- |
| `Type` | `type` | `"image"`、`"audio"`、`"video"` 或 `"document"` | 内容判别值 |
| `Id` | `id` | `string?` | 可选的部分标识符 |
| `Source` | `source` | `AGUIInputContentSource` | 数据、URL 或提供商文件来源 |
| `Metadata` | `metadata` | `JsonElement?` | 可选的模态特有元数据 |

当服务端把 AG-UI 请求适配到 Microsoft.Extensions.AI 时，
`AGUIChatMessageExtensions.AsChatMessages()` 会把数据来源映射为 `DataContent`、
URL 来源映射为 `UriContent`、文件来源映射为 `HostedFileContent`（句柄（handle）成为
`FileId`；`Provider` 在那边没有对应物，会在这一跳被丢弃，不过它在 JSON 与 protobuf
之间可以完整往返）。来源的 MIME 类型会保留；当 URL 来源省略 `mimeType` 时，
`UriContent` 会从 URL 推断。如果 URL 没有可识别的扩展名，规范判别值会补上
`image/*`、`audio/*` 或 `video/*`，以免丢失模态信息。

完整的 `metadata` 值会保留在 MEAI 内容的 `AdditionalProperties["metadata"]`
键下，包括对象形状的值。对于内联数据，字符串类型的 `metadata.filename` 属性还会赋给
`DataContent.Name`，让支持文件的提供商能收到文件名。

在客户端方向，`AsAGUIMessages(jsonSerializerOptions)` 会根据 MIME 类型把
`DataContent` 和 `UriContent` 映射为规范的媒体部分，并把它们的
`AdditionalProperties` 序列化为该部分的 `metadata`。当该属性尚不存在时，
`DataContent.Name` 会作为 `metadata.filename` 一并包含。

### 二进制

`AGUIBinaryInputContent` 表示任意的二进制输入部分。

```csharp
var binary = new AGUIBinaryInputContent
{
    MimeType = "application/octet-stream",
    Data = "AAECAwQ=",
    Filename = "payload.bin"
};
```

| C# 属性 | JSON 字段 | 类型 | 说明 |
| ----------- | ---------- | ---- | ----------- |
| `Type` | `type` | `"binary"` | 内容判别值 |
| `MimeType` | `mimeType` | `string` | MIME 类型 |
| `Id` | `id` | `string?` | 可选的二进制标识符 |
| `Url` | `url` | `string?` | 可选的二进制数据 URL |
| `Data` | `data` | `string?` | 可选的内联 base64 数据 |
| `Filename` | `filename` | `string?` | 可选的文件名 |

## 来源类型

媒体输入部分使用 `AGUIInputContentSource`，一个以 JSON 字段 `type` 为判别依据的
层级结构。

### 数据来源

内联 base64 负载使用 `AGUIInputContentDataSource`。`mimeType` 为必填。

```csharp
var source = new AGUIInputContentDataSource
{
    Value = "iVBORw0KGgo...",
    MimeType = "image/png"
};
```

| C# 属性 | JSON 字段 | 类型 | 说明 |
| ----------- | ---------- | ---- | ----------- |
| `Type` | `type` | `"data"` | 来源判别值 |
| `Value` | `value` | `string` | 内联 base64 负载 |
| `MimeType` | `mimeType` | `string` | 负载的 MIME 类型 |

### URL 来源

HTTP(S) URL 或 data URL 使用 `AGUIInputContentUrlSource`。`mimeType` 可选。

```csharp
var source = new AGUIInputContentUrlSource
{
    Value = "https://example.com/meeting.wav",
    MimeType = "audio/wav"
};
```

| C# 属性 | JSON 字段 | 类型 | 说明 |
| ----------- | ---------- | ---- | ----------- |
| `Type` | `type` | `"url"` | 来源判别值 |
| `Value` | `value` | `string` | URL 或 data URL |
| `MimeType` | `mimeType` | `string?` | 可选的 MIME 类型 |

### 文件来源

已经存放在模型提供商处的字节使用 `AGUIInputContentFileSource`——例如 OpenAI 或
Anthropic 的文件 ID、Gemini 的文件 URI。不会发生任何抓取，`Value` 是不透明的：
把它交回签发它的提供商，或者丢弃该部分。`provider` 和 `mimeType` 可选。

```csharp
var source = new AGUIInputContentFileSource
{
    Value = "file-abc123",
    Provider = "openai",
    MimeType = "application/pdf"
};
```

| C# 属性 | JSON 字段 | 类型 | 说明 |
| ----------- | ---------- | ---- | ----------- |
| `Type` | `type` | `"file"` | 来源判别值 |
| `Value` | `value` | `string` | 提供商的句柄，与签发时完全一致 |
| `Provider` | `provider` | `string?` | 签发方，例如 `"openai"`、`"anthropic"`、`"google"` |
| `MimeType` | `mimeType` | `string?` | 可选的 MIME 类型 |

## 常见用例

### 视觉问答

```csharp
var message = new AGUIUserMessage
{
    Id = "q1",
    Content =
    [
        new AGUITextInputContent
        {
            Text = "What issue do you see in this UI?"
        },
        new AGUIImageInputContent
        {
            Source = new AGUIInputContentUrlSource
            {
                Value = "https://example.com/ui.png",
                MimeType = "image/png"
            },
            Metadata = JsonDocument.Parse("""{"detail":"high"}""").RootElement.Clone()
        }
    ]
};
```

### 音频转录

```csharp
var message = new AGUIUserMessage
{
    Id = "q2",
    Content =
    [
        new AGUITextInputContent
        {
            Text = "Transcribe this recording."
        },
        new AGUIAudioInputContent
        {
            Source = new AGUIInputContentUrlSource
            {
                Value = "https://example.com/meeting.wav",
                MimeType = "audio/wav"
            }
        }
    ]
};
```

### 混合媒体对比

```csharp
var message = new AGUIUserMessage
{
    Id = "q3",
    Content =
    [
        new AGUITextInputContent
        {
            Text = "Compare the screenshot with the spec."
        },
        new AGUIImageInputContent
        {
            Source = new AGUIInputContentDataSource
            {
                Value = "iVBORw0KGgo...",
                MimeType = "image/png"
            }
        },
        new AGUIDocumentInputContent
        {
            Source = new AGUIInputContentUrlSource
            {
                Value = "https://example.com/spec.pdf",
                MimeType = "application/pdf"
            }
        }
    ]
};
```

<Tip>
  简单的纯文本轮次直接用字符串形式的 `Content` 即可。当顺序很重要，或用户消息在文本
  之外还包含媒体时，使用多模态部分。
</Tip>
