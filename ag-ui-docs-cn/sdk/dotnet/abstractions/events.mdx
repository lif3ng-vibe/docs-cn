# 事件

AG-UI 采用基于事件的流式架构。事件是智能体后端向前端 UI 传递信息的基本单位。
在 .NET 中，每个协议事件都派生自 `BaseEvent`，并带有 `type` 判别值（discriminator）。

## 事件类型常量

`AGUIEventTypes` 定义了 SCREAMING_SNAKE_CASE 形式的线上判别值：

```csharp

AGUIEventTypes.RunFinished; // "RUN_FINISHED"

AGUIEventTypes.StateDelta; // "STATE_DELTA"
AGUIEventTypes.MessagesSnapshot; // "MESSAGES_SNAPSHOT"
```

## BaseEvent

所有事件都继承自 `BaseEvent`。

```csharp
public abstract class BaseEvent
{
    public abstract string Type { get; } // "type"
    public long? Timestamp { get; set; } // "timestamp"
    public JsonElement? RawEvent { get; set; } // "rawEvent"
    public JsonElement? Metadata { get; set; } // "metadata"
}
```

| C# 属性 | JSON 字段 | 类型 | 说明 |
| ----------- | ---------- | ---- | ----------- |
| `Type` | `type` | `string` | 事件判别值 |
| `Timestamp` | `timestamp` | `long?` | 可选的事件时间戳 |
| `RawEvent` | `rawEvent` | `JsonElement?` | 可选的原始事件数据 |
| `Metadata`  | `metadata`  | `JsonElement?` | 可选的附加信息，按键开放 |

`Metadata` 按键开放：key 下允许任意 JSON 值，包括 `null`。对象可以缺省，但一旦出现
就绝不会是 `null`——显式的 `null` 读回时视为缺省，缺省的对象在线上直接省略，而不会
序列化为 `null`。`AGUIMetadata.ReservedKey`（`"ag-ui"`）保留为 AG-UI 自用。

## 生命周期事件

生命周期事件表示运行与步骤的生命周期。

### RunStartedEvent

表示一次智能体运行的开始。

```csharp
var evt = new RunStartedEvent
{
    ThreadId = "thread-1",
    RunId = "run-1",
    ParentRunId = "run-0",
    Input = input,
    ProtocolVersion = AGUIProtocol.Version
};
```

| C# 属性 | JSON 字段 | 类型 | 说明 |
| ----------- | ---------- | ---- | ----------- |
| `Type` | `type` | `"RUN_STARTED"` | 事件判别值 |
| `ThreadId` | `threadId` | `string` | 会话线程 ID |
| `RunId` | `runId` | `string` | 智能体运行 ID |
| `ParentRunId` | `parentRunId` | `string?` | 可选的父运行 ID |
| `Input` | `input` | `RunAgentInput?` | 可选的运行输入负载 |
| `ProtocolVersion` | `protocolVersion` | `string?` | 生产者（producer）所使用的 AG-UI 协议版本。每个手工构建的事件都应将其设为 `AGUIProtocol.Version`（`"1.0"`）；没有该字段的事件流会被当作 1.0 之前的版本读取 |

### RunFinishedEvent

表示一次智能体运行的完成。

```csharp
var evt = new RunFinishedEvent
{
    ThreadId = "thread-1",
    RunId = "run-1",
    Outcome = new RunFinishedSuccessOutcome()
};
```

| C# 属性 | JSON 字段 | 类型 | 说明 |
| ----------- | ---------- | ---- | ----------- |
| `Type` | `type` | `"RUN_FINISHED"` | 事件判别值 |
| `ThreadId` | `threadId` | `string` | 会话线程 ID |
| `RunId` | `runId` | `string` | 智能体运行 ID |
| `Result` | `result` | `JsonElement?` | 可选的运行结果 |
| `Outcome` | `outcome` | `RunFinishedOutcome?` | 可选的带类型结果（outcome） |
| `Usage` | `usage` | `IList<TokenUsage>?` | 可选的本次运行 token 用量 |

`RunFinishedOutcome` 是一个多态值，`type` 为 `"success"` 或
`"interrupt"`。`RunFinishedInterruptOutcome` 携带 `interrupts`，即一个
`IList<AGUIInterrupt>`。

`Usage` 在 [TokenUsage](#tokenusage) 一节说明。

### TokenUsage

由提供商上报的 token 用量，两个终止性运行事件都会携带。每个 `(provider, model)`
组合各占一条记录，因此调用多个模型的运行会把它们分开记录；只需要总数的消费方可以对
各条记录求和。

```csharp
var evt = new RunFinishedEvent
{
    ThreadId = "thread-1",
    RunId = "run-1",
    Outcome = new RunFinishedSuccessOutcome(),
    Usage =
    [
        new TokenUsage
        {
            Provider = "openai",
            Model = "gpt-4o",
            InputTokens = 658,
            OutputTokens = 188,
            TotalTokens = 846
        }
    ]
};
```

| C# 属性 | JSON 字段 | 类型 | 说明 |
| ----------- | ---------- | ---- | ----------- |
| `Provider` | `provider` | `string?` | 服务该请求的提供商 |
| `Model` | `model` | `string?` | 服务该请求的模型 |
| `InputTokens` | `inputTokens` | `long?` | 全部输入 token，含缓存读取与写入 |
| `OutputTokens` | `outputTokens` | `long?` | 全部输出 token，含推理 |
| `TotalTokens` | `totalTokens` | `long?` | `inputTokens` 加 `outputTokens` |
| `ReasoningTokens` | `reasoningTokens` | `long?` | 用于推理的输出 token；是 `outputTokens` 的一部分 |
| `CachedInputTokens` | `cachedInputTokens` | `long?` | 从提示词缓存读取的输入 token；是 `inputTokens` 的一部分 |
| `CacheWriteInputTokens` | `cacheWriteInputTokens` | `long?` | 写入提示词缓存的输入 token；是 `inputTokens` 的一部分。`Microsoft.Extensions.AI` 没有为它提供一等属性，因此 `AGUI.Server` 从 `UsageDetails.AdditionalCounts["CacheWriteInputTokens"]` 读取，`AGUI.Client` 写入该处 |

每个字段都是可选的。为 null 的计数表示提供商没有上报该值，这与上报为零不同——因此
`usage` 绝不编造提供商未提供的计数。该类型设计上只含数字：不携带任何提示词、补全、
消息、工具参数或线程/运行/用户标识符。

使用 `AGUI.Server` 托管时，Microsoft.Extensions.AI 以 `UsageContent` 上报的用量会
自动累积并附加到终止事件上。`ModelId` 提供模型标签；提供商标签用
`AGUIStreamOptions.WithUsageProvider("openai")` 设置。

## 子智能体事件

这些事件报告智能体已把工作委托给子智能体，前端借此可以把输出归因到产生它的子智能体。
归因本身以可选的 `SubagentRunId` 字段随大多数其他事件类型一起传输。

`SubagentRunId` 标识的是**一次调用**，而不是可复用的子智能体定义——同一个子智能体运行
两次会得到两个不同的值。完整模型见[子智能体](/concepts/subagents)。

### SubagentStartedEvent

宣告一次新的子智能体调用，并给出用于展示的名称。

```csharp
var evt = new SubagentStartedEvent
{
    SubagentRunId = "sub-1",
    Name = "researcher",
    Description = "Searches for supporting sources"
};
```

| C# 属性 | JSON 字段 | 类型 | 说明 |
| ----------- | ---------- | ---- | ----------- |
| `Type` | `type` | `"SUBAGENT_STARTED"` | 事件判别值 |
| `SubagentRunId` | `subagentRunId` | `string` | 本次调用的不透明 ID |
| `Name` | `name` | `string` | 声明的子智能体名称，用于展示 |
| `Description` | `description` | `string?` | 可选的描述 |
| `ParentSubagentRunId` | `parentSubagentRunId` | `string?` | 嵌套时的外层子智能体 |
| `ParentToolCallId` | `parentToolCallId` | `string?` | 派生出该子智能体的工具调用 |
| `ParentMessageId` | `parentMessageId` | `string?` | 持有该工具调用的消息 |

### SubagentFinishedEvent

将一次子智能体调用标记为完成。

```csharp
var evt = new SubagentFinishedEvent { SubagentRunId = "sub-1" };
```

| C# 属性 | JSON 字段 | 类型 | 说明 |
| ----------- | ---------- | ---- | ----------- |
| `Type` | `type` | `"SUBAGENT_FINISHED"` | 事件判别值 |
| `SubagentRunId` | `subagentRunId` | `string` | 与 `SubagentStartedEvent` 中的 ID 一致 |
| `Result` | `result` | `object?` | 可选负载，对应 `RunFinishedEvent.Result` |
| `Outcome` | `outcome` | `SubagentFinishedOutcome?` | `SubagentFinishedSuccessOutcome` 或 `SubagentFinishedSuspendedOutcome`（带可选的 `InterruptIds`）；`null` 表示成功（沿用旧的读法）。Suspended 表示子智能体已设置检查点、等待外部输入；`InterruptIds` 指出哪些运行级中断的答案可以恢复它 |

| ----------- | ---------- | ---- | ----------- |
| `Type` | `type` | `"SUBAGENT_ERROR"` | 事件判别值 |
| `SubagentRunId` | `subagentRunId` | `string` | 与 `SubagentStartedEvent` 中的 ID 一致 |
| `Message` | `message` | `string` | 人类可读的错误消息 |
| `Code` | `code` | `string?` | 可选的错误码 |

### 其他事件上的归因

大多数事件类型都暴露可选的 `SubagentRunId`。不带该字段的事件属于父智能体，因此从不
设置该字段的事件流，其行为与子智能体出现之前完全一致。

`RunStartedEvent`、`RunFinishedEvent` 和 `RunErrorEvent` 不可归因——它们描述的是
运行整体。`MessagesSnapshotEvent` 则按消息携带归因。

`StateSnapshotEvent` 和 `StateDeltaEvent` 可以归因，但其归因表示的是
来源（provenance）而非所有权——它记录是哪个子智能体产生了这次更新。状态始终以运行
为作用域，因此带归因的快照或增量与不带归因的一样，都应用到该运行的唯一一份状态文档上。

当事件转换为 `Microsoft.Extensions.AI` 类型时，归因会保留在
`ChatMessage.AdditionalProperties` 中、键为 `agui.subagentRunId`，因为那些类型没有
专门的字段。

## 特殊事件

### RawEvent

透传未处理的外部数据。

```csharp
var evt = new RawEvent
{
    Event = JsonDocument.Parse("""{"provider":"example","event":"token"}""").RootElement.Clone(),
    Source = "provider"
};
```

| C# 属性 | JSON 字段 | 类型 | 说明 |
| ----------- | ---------- | ---- | ----------- |
| `Type` | `type` | `"RAW"` | 事件判别值 |
| `Event` | `event` | `JsonElement` | 原始负载 |
| `Source` | `source` | `string?` | 可选的来源标识 |

### CustomEvent

携带应用特有的数据。

```csharp
var evt = new CustomEvent
{
    Name = "progress",
    Value = JsonDocument.Parse("""{"percent":50}""").RootElement.Clone()
};
```

| C# 属性 | JSON 字段 | 类型 | 说明 |
| ----------- | ---------- | ---- | ----------- |
| `Type` | `type` | `"CUSTOM"` | 事件判别值 |
| `Name` | `name` | `string` | 自定义事件名称 |
| `Value` | `value` | `JsonElement?` | 可选的自定义负载 |

## 序列化

`BaseEvent` 使用基于判别值的 JSON 转换器，以 `type` 字段为键。
所有具体事件类型都注册在 `AGUIJsonSerializerContext` 中。

```csharp
BaseEvent evt = new TextMessageContentEvent
{
    MessageId = "msg-1",
    Delta = "Hello"
};

var json = JsonSerializer.Serialize(
    evt,
    AGUIJsonSerializerContext.Default.BaseEvent);
```
