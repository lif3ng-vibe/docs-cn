# AGUI.Abstractions

`AGUI.Abstractions` 是 AG-UI .NET SDK 的协议类型包，定义了 AG-UI 客户端与服务端共用的
事件、消息、工具、上下文、能力、中断以及序列化类型。

```bash
dotnet add package AGUI.Abstractions
```

该包不预设 HTTP、ASP.NET Core 或任何特定的智能体运行时，它是 `@ag-ui/core` 在 .NET
侧的对应包：为事件流和请求负载提供稳定的线上类型（wire types）。

<Note>
  `AGUI.Abstractions` 面向 `net10.0`、`net9.0`、`net8.0`、
  `netstandard2.0` 和 `net472`，并兼容 AOT：可序列化的协议类型都注册在源生成的
  `AGUIJsonSerializerContext` 中。
</Note>

## SDK 包

.NET SDK 拆分为多个小包，协议类型、线上格式、客户端代码与服务端代码可以按需独立采用。

| 包 | 用途 |
| --- | --- |
| `AGUI.Abstractions` | 协议事件、消息、工具、能力、中断以及 JSON 序列化。 |
| `AGUI.Formatting` | 事件流格式化器抽象与 SSE（服务器推送事件）支持。 |
| `AGUI.Protobuf` | protobuf 事件流格式化与二进制协议支持。 |
| `AGUI.Client` | 用于消费 AG-UI 端点的 HTTP 客户端与 `IChatClient` 实现。 |
| `AGUI.Server` | 与框架无关的适配器，将 `ChatResponseUpdate` 流转换为 AG-UI 事件。 |

## 线上格式与对等性

基于 SSE 的 JSON 是全保真的事件流。`AGUI.Formatting` 定义了事件流格式化器契约与
SSE 支持；`AGUI.Protobuf` 则为共享 proto schema 所支持的协议子集提供二进制事件流格式化。

协议对等性从 `AGUI.Abstractions` 开始维护。当 TypeScript 参考实现新增或修改某个线上
类型（wire type）时，对应的 .NET 事件、消息、工具或能力类型应同步更新，
`AGUIJsonSerializerContext` 与兼容性测试样例（compatibility fixtures）也应一并更新。
凡是协议变更新增或修改了 .NET 类型，公开 API 追踪文件都应随之更新。

```bash
cd sdks/dotnet
dotnet test tests/AGUI.Abstractions.UnitTests/
dotnet test tests/AGUI.Formatting.UnitTests/
dotnet test tests/AGUI.Protobuf.UnitTests/
```

## 类型

构成协议基础模块的核心数据结构：

- [RunAgentInput](/sdk/dotnet/abstractions/types#runagentinput) - 运行智能体时的
  输入负载
- [消息类型](/sdk/dotnet/abstractions/types#消息类型) - 对话、工具、活动与
  推理消息
- [AGUIContext](/sdk/dotnet/abstractions/types#上下文) - 提供给智能体的上下文信息
- [AGUITool](/sdk/dotnet/abstractions/types#工具) - 带 JSON Schema 参数的工具定义
- [AgentCapabilities](/sdk/dotnet/abstractions/types#agentcapabilities) -
  结构化的能力声明

## 事件

事件驱动智能体与前端之间的通信：

- [生命周期事件](/sdk/dotnet/abstractions/events#生命周期事件) - 运行与
  步骤追踪
- [文本消息事件](/sdk/dotnet/abstractions/events#文本消息事件) -
  助手消息流式传输
- [工具调用事件](/sdk/dotnet/abstractions/events#工具调用事件) -
  函数调用的生命周期
- [状态管理事件](/sdk/dotnet/abstractions/events#状态管理事件) -
  智能体状态与消息快照
- [推理事件](/sdk/dotnet/abstractions/events#推理事件) -
  推理流支持
- [活动事件](/sdk/dotnet/abstractions/events#活动事件) -
  结构化进度与瞬态 UI 状态
- [特殊事件](/sdk/dotnet/abstractions/events#特殊事件) - Raw 事件与
  自定义事件
