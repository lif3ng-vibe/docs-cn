# 可扩展性

`AGUIStreamOptions` 用于定制 `ChatResponseUpdate` 流到 AG-UI 事件的转换方式。它是
流式 API 且仅由方法构成：创建一个实例，注册 `Map*` 钩子，然后传给
`ToChatRequestContext`。

```csharp
var streamOptions = new AGUIStreamOptions()
    .MapResultAsStateSnapshot("create_plan");

var ctx = input.ToChatRequestContext(jsonSerializerOptions, streamOptions);
```

当服务端需要呈现框架特有的内容类型、自定义中断、状态更新或流式工具参数预览时，
使用流选项。

## 内置转换

常见路径不需要流选项。托管层已经映射：

- `TextContent` → `TEXT_MESSAGE_*`
- `TextReasoningContent` → `REASONING_*`
- `FunctionCallContent` → `TOOL_CALL_*`
- `FunctionResultContent` → `TOOL_CALL_RESULT`
- `ToolApprovalRequestContent` 与 `InterruptRequestContent` → 中断结果
- 携带 `BaseEvent` 的 `ChatResponseUpdate.RawRepresentation` → 直接作为该事件

<Note>
  如果 `ChatResponseUpdate.RawRepresentation` 是一个 `BaseEvent`，托管层会原样发出
  它。对于自定义 `IChatClient` 包装层来说，这往往是注入 `StateSnapshotEvent`、
  `CustomEvent` 或 `RawEvent` 值的最简单方式。
</Note>

## MapContent

`MapContent(Func<AIContent, IEnumerable<BaseEvent>?> mapper)` 接收一个尚未被其他
映射器处理的 `AIContent`，返回要发出的 AG-UI 事件。返回 `null` 则让下一个映射器
尝试处理该内容。

```csharp
using AGUI.Abstractions;
using AGUI.Server;
using Microsoft.Extensions.AI;

public sealed class WorkflowStepContent : AIContent
{
    public string StepName { get; set; } = string.Empty;
}

var streamOptions = new AGUIStreamOptions()
    .MapContent(content =>
        content is WorkflowStepContent step
            ? [new StepStartedEvent { StepName = step.StepName }]
            : null);
```

框架特有的内容类型，例如工作流标记、进度通知或领域事件，都适合用这个钩子。

<Tip>
  `TextReasoningContent` 已经被原生处理。Step 07 示例会发出
  `TextReasoningContent`，托管层无需自定义 `MapContent` 配置就能把它转换为推理事件。
</Tip>

## MapInterrupt

`MapInterrupt(Func<AIContent, AGUIInterrupt?> mapper)` 接收一个尚未被其他映射器处理
的 `AIContent`，当运行需要用户输入时返回一个 `AGUIInterrupt`。托管层会发出带中断
结果的 `RunFinishedEvent` 并停止运行。返回 `null` 则继续尝试下一个映射器或
`MapContent`。

```csharp
using AGUI.Abstractions;
using AGUI.Server;
using Microsoft.Extensions.AI;

public sealed class ConfirmationRequiredContent : AIContent
{
    public string RequestId { get; set; } = string.Empty;

    public string Message { get; set; } = string.Empty;
}

var streamOptions = new AGUIStreamOptions()
    .MapInterrupt(content =>
        content is ConfirmationRequiredContent confirmation
            ? new AGUIInterrupt
            {
                Id = confirmation.RequestId,
                Reason = InterruptReasons.Confirmation,
                Message = confirmation.Message,
            }
            : null);
```

内置 `InterruptRequestContent` 或工具批准内容没有覆盖的自定义人在回路
（human-in-the-loop）内容，适合用这个钩子。

## MapCall

`MapCall(string toolName, Func<FunctionCallContent, IEnumerable<BaseEvent>>
mapper)` 接收匹配的 `FunctionCallContent`，在正常的工具调用 start、args、end 事件
之后发出额外事件。

```csharp
using System.Text.Json;
using AGUI.Abstractions;
using AGUI.Server;

string? lastDocument = null;

var streamOptions = new AGUIStreamOptions()
    .MapCall("write_document", call =>
    {
        var document = call.Arguments?.TryGetValue("document", out var value) == true
            ? value?.ToString()
            : null;

        if (string.IsNullOrEmpty(document) || document == lastDocument)
        {
            return [];
        }

        lastDocument = document;

        var snapshot = JsonSerializer.SerializeToElement(new
        {
            document
        });

        return [new StateSnapshotEvent { Snapshot = snapshot }];
    });
```

它适合做流式工具参数预览。例如，当模型正在为 `write_document` 构建参数时，UI 可以
在服务端侧工具完成之前就更新实时文档预览。

## MapResult

`MapResult(string toolName, Func<FunctionResultContent,
IEnumerable<BaseEvent>> mapper)` 接收匹配的工具结果，在正常的
`ToolCallResultEvent` 之后发出额外事件。

```csharp
using System.Text.Json;
using AGUI.Abstractions;
using AGUI.Server;

var streamOptions = new AGUIStreamOptions()
    .MapResult("save_recipe", result =>
    {
        var snapshot = JsonSerializer.SerializeToElement(new
        {
            saved = true,
            recipe = result.Result,
        });

        return
        [
            new StateSnapshotEvent { Snapshot = snapshot },
            new CustomEvent
            {
                Name = "recipe.saved",
                Value = snapshot,
            },
        ];
    });
```

当一个服务端侧的工具结果还应该更新状态、活动或应用特有的 UI 时，使用这个钩子。

## 状态映射辅助方法

两个便捷方法覆盖了常见的状态管理场景：

```csharp
var streamOptions = new AGUIStreamOptions()
    .MapResultAsStateSnapshot("create_plan")
    .MapResultAsStateDelta("update_plan_step");
```

- `MapResultAsStateSnapshot(toolName)` 发出一个 `StateSnapshotEvent`
- `MapResultAsStateDelta(toolName)` 发出一个 `StateDeltaEvent`

两个辅助方法都要求 `FunctionResultContent.Result` 是 `JsonElement`。如果你的工具
返回其他类型，请改用 `MapResult` 并自行序列化该值。

## RawRepresentation 透传

对自定义 `IChatClient` 包装层来说，把 `RawRepresentation` 设为 AG-UI 事件往往比
定义新的 `AIContent` 类型更简单。

```csharp
using System.Text.Json;
using AGUI.Abstractions;
using Microsoft.Extensions.AI;

var state = JsonSerializer.SerializeToElement(new
{
    status = "ready"
});

yield return new ChatResponseUpdate
{
    RawRepresentation = new StateSnapshotEvent
    {
        Snapshot = state,
    },
};
```

转换器会直接发出 `StateSnapshotEvent`。如果该原始事件出现在运行开始之前，托管层会
先发出 `RUN_STARTED`。

## 链式注册

可以注册多个 `MapContent` 或 `MapInterrupt` 回调。它们按注册顺序依次尝试，第一个
非 null 的结果生效。

```csharp
var streamOptions = new AGUIStreamOptions()
    .MapInterrupt(TryMapConfirmation)
    .MapInterrupt(TryMapInputRequest)
    .MapContent(TryMapWorkflowStep)
    .MapContent(TryMapProgress);
```

映射要保持小而专注。标准文本、推理、工具与中断交给内置转换处理，只为你的服务端特有
的事件添加流选项。
