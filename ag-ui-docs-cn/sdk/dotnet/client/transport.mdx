# 传输层

`AGUI.Client` 通过 `IAGUITransport` 把对话客户端与线上协议解耦。
`AGUIChatClient` 构建 `RunAgentInput`，把它交给传输层，并消费由此产生的 AG-UI
`BaseEvent` 流。

```csharp
using AGUI.Abstractions;
using AGUI.Client;
```

## IAGUITransport

`IAGUITransport` 只有一个方法：

```csharp
public interface IAGUITransport
{
    IAsyncEnumerable<BaseEvent> SendAsync(
        RunAgentInput input,
        CancellationToken cancellationToken);
}
```

输入包含 AG-UI 线程 ID、运行 ID、消息历史、工具、状态、上下文、转发属性，以及被中断
运行的所有 resume 条目。输出是[事件参考](/sdk/dotnet/abstractions/events)中描述的
有序 AG-UI 事件流。

## HTTP 传输层

`AGUIChatClientOptions(HttpClient, endpoint)` 构造函数会在内部创建内置的
HTTP 传输层：

```csharp
using AGUI.Client;
using Microsoft.Extensions.AI;

using HttpClient httpClient = new();
IChatClient client = new AGUIChatClient(new(httpClient, "https://api.example.com/agent"));
```

内置传输层以 HTTP `POST` 发送请求，请求体是序列化后的 `RunAgentInput`。响应按
SSE（服务器推送事件）读取，每个 SSE 条目都被反序列化为一个 `BaseEvent`。

<Note>
  `AGUIHttpTransport` 是 `AGUIChatClientOptions(HttpClient, endpoint)` 构造函数
  使用的内置 HTTP+SSE 实现。大多数应用不需要直接实例化传输层。
</Note>

## 自定义传输层

想在没有服务端的情况下测试，或想使用另一种传输层时，实现 `IAGUITransport`，
然后把实现传给 `AGUIChatClient`。

```csharp
using System.Runtime.CompilerServices;
using AGUI.Abstractions;
using AGUI.Client;
using Microsoft.Extensions.AI;

public sealed class InMemoryAGUITransport : IAGUITransport
{
    public List<RunAgentInput> Requests { get; } = [];

    public async IAsyncEnumerable<BaseEvent> SendAsync(
        RunAgentInput input,
        [EnumeratorCancellation] CancellationToken cancellationToken)
    {
        Requests.Add(input);
        await Task.Yield();

        string threadId = string.IsNullOrEmpty(input.ThreadId) ? "thread_1" : input.ThreadId;
        string runId = string.IsNullOrEmpty(input.RunId) ? "run_1" : input.RunId;

        yield return new RunStartedEvent { ThreadId = threadId, RunId = runId, ProtocolVersion = AGUIProtocol.Version };
        yield return new TextMessageStartEvent { MessageId = "msg_1", Role = AGUIRoles.Assistant };
        yield return new TextMessageContentEvent { MessageId = "msg_1", Delta = "Hello from AG-UI" };
        yield return new TextMessageEndEvent { MessageId = "msg_1" };
        yield return new RunFinishedEvent { ThreadId = threadId, RunId = runId };
    }
}

IAGUITransport transport = new InMemoryAGUITransport();
IChatClient client = new AGUIChatClient(new() { Transport = transport });
```

## 事件转换

传输层返回 AG-UI 协议事件。`AGUIChatClient` 随后把它们转换为
`ChatResponseUpdate` 值：

- `RUN_STARTED` 确定 AG-UI 线程 ID 与运行 ID。
- 文本消息事件变成流式文本更新。
- 工具调用事件变成 MEAI 函数调用内容。
- 中断结果变成 `ToolApprovalRequestContent` 或
  `InterruptRequestContent`。
- `RUN_ERROR` 变成 `ErrorContent` 更新。它的 `message` 映射到
  `ErrorContent.Message`，可选的 `code` 映射到
  `ErrorContent.ErrorCode`。当事件携带部分 `usage` 时，客户端还会发出
  `UsageContent` 更新，让 `ChatResponse.Usage` 包含失败前已消耗的 token。

每个更新上的 `ResponseId` 对应 AG-UI 的运行 ID。客户端在产出更新前会清空
`ConversationId`，让调用方继续向无状态的 AG-UI 服务端发送完整的消息历史。

## 取消

`SendAsync` 会收到调用方的 `CancellationToken`。自定义传输层在发送请求和产出事件的
过程中都应响应它：

```csharp
public async IAsyncEnumerable<BaseEvent> SendAsync(
    RunAgentInput input,
    [EnumeratorCancellation] CancellationToken cancellationToken)
{
    cancellationToken.ThrowIfCancellationRequested();

    await Task.Delay(TimeSpan.FromMilliseconds(10), cancellationToken);
    yield return new RunStartedEvent
    {
        ThreadId = input.ThreadId,
        RunId = input.RunId,
        ProtocolVersion = AGUIProtocol.Version,
    };

    cancellationToken.ThrowIfCancellationRequested();
    yield return new RunFinishedEvent { ThreadId = input.ThreadId, RunId = input.RunId };
}
```
