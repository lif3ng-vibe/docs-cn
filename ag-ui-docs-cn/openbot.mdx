OpenBot 是 CopilotKit 团队推出的智能体工作台产品——模块化、可自托管、面向企业的 AI 同事工作区。它把 AG-UI 协议用于产品实践：智能体在各自的"电脑"上完成任务，人类掌握审批与决策权。
