## **AG-UI 与生成式 UI 规范**

多个近期发布的规范让智能体能够返回生成式 UI，大大增强了智能体与用户对话的能力和灵活性。

A2UI、MCP-UI 与 Open-JSON-UI 都是**生成式 UI 规范**。生成式 UI 让智能体对用户的响应不再局限于文本，还可以是动态的 UI 组件。

| **规范** | **来源/维护方** | **用途** |
| --- | --- | --- |
| **A2UI** | Google | 一套声明式、对 LLM 友好的生成式 UI 规范。基于 JSONL 且支持流式，面向与平台无关的渲染而设计。 |
| **Open-JSON-UI** | OpenAI | 对 OpenAI 内部声明式生成式 UI schema 的公开标准化。 |
| **MCP-UI** | Microsoft + Shopify | 一个完全开放的、基于 iframe 的生成式 UI 标准，扩展 MCP 以支持面向用户的体验。 |

尽管名字相近，**AG-UI 并不是生成式 UI 规范**——它是一个**用户交互协议**，在智能体与应用之间提供**双向的运行时连接**。

AG-UI 原生支持上述所有生成式 UI 规范，同时也允许开发者定义**自己的自定义生成式 UI 标准**。
