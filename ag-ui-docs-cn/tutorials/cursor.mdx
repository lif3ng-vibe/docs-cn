本指南将帮助你配置 Cursor，以便更快地构建自定义的智能体–用户交互协议（AG-UI）服务端与客户端。相同的原则也适用于 Windsurf、VSCode 等其他 IDE。

## 将文档添加到 Cursor

1. 打开 Cursor 设置
2. 前往 Features > Docs，点击"+ Add new Doc"
3. 粘贴以下 URL：https://docs.ag-ui.com/llms-full.txt
4. 点击"Add"

## 使用文档

现在你可以借助这份文档来构建你的 AG-UI 项目。输入 `@` 符号、选择"Docs"，再从列表中选择"Agent User Interaction Protocol"，即可把文档加载进当前提示词。祝你编码愉快！

## 最佳实践

使用 Cursor 构建 AG-UI 服务端时：

- 把复杂问题拆解成更小的步骤
- 通过查看智能体编辑了哪些文件（在聊天输入框上方）来了解它做了什么
- 让智能体编写单元测试来验证你的实现
- 严格遵循 AG-UI 协议规范
