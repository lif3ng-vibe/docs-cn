---
title: "事件流"
description: "八大事件族，以及每一族由谁来消费——1.0"
---

生产者要说的一切都以事件到达，分属八个事件族。每族绑定一种[事件模式](/spec/1.0/basic/patterns)并附加自己的规则；每族面向消费者的不同部分：

| 事件族 | 事件 | 模式 | 消费方 |
| --- | --- | --- | --- |
| [运行与步骤](/spec/1.0/events/lifecycle) | `RUN_STARTED` · `RUN_FINISHED` · `RUN_ERROR` · `STEP_STARTED` · `STEP_FINISHED` | 生命周期 | 客户端本身 |
| [文本消息](/spec/1.0/events/text-messages) | `TEXT_MESSAGE_*` | 流式 | UI |
| [工具调用](/spec/1.0/events/tool-calls) | `TOOL_CALL_*` | 流式 | 应用 |
| [推理](/spec/1.0/events/reasoning) | `REASONING_*` | 流式 | UI |
| [状态](/spec/1.0/events/state) | `STATE_SNAPSHOT` · `STATE_DELTA` · `MESSAGES_SNAPSHOT` | 快照–增量 | 应用存储 |
| [活动](/spec/1.0/events/activity) | `ACTIVITY_SNAPSHOT` · `ACTIVITY_DELTA` | 快照–增量 | UI |
| [子智能体](/spec/1.0/events/subagents) | `SUBAGENT_STARTED` · `SUBAGENT_FINISHED` · `SUBAGENT_ERROR` | 生命周期 | 客户端本身 |
| [透传](/spec/1.0/events/passthrough) | `RAW` · `CUSTOM` | 独立 | 应用，自愿启用 |

这些事件族所含的三十一个事件类型，罗列于[事件模型](/spec/1.0/basic)，其形态归 [schema](/spec/1.0/schema) 管辖。对生产者而言只有运行生命周期是强制的——其余每族都是特性，有内容要表达时才发出。消费者 MUST 全部接受：来自消费者用不上事件族的事件，仍是一件格式良好的事件，不是[无法识别的内容](/spec/1.0/basic/processing)。
