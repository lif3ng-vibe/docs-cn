# Meta 事件提案

## 摘要

### 问题陈述

目前，AG-UI 事件与智能体运行紧密耦合。没有一种标准化方式，可以把独立于智能体执行生命周期的用户反馈、注解或外部信号附加到事件流上。

### 动机

AG-UI 扩展了 **MetaEvents**——一类新的事件，可以出现在事件流的任意位置，独立于智能体运行。MetaEvents 提供了一种把注解、信号或反馈附加到序列化流上的方式。它们可能来自用户、客户端或外部系统，而非智能体。例子包括对消息点赞/点踩之类的反应。

## 详细规范

### 总览

本提案引入：

- 用于带外注解的新 **MetaEvent** 类型
- 可以出现在流中任意位置的事件
- 对用户反馈、标签与外部注解的支持
- 面向应用专属数据的可扩展负载结构

## 新类型：MetaEvent

```typescript
type MetaEvent = BaseEvent & {
  type: EventType.META
  /**
   * Application-defined type of the meta event.
   * Examples: "thumbs_up", "thumbs_down", "tag", "note"
   */
  metaType: string

  /**
   * Application-defined payload.
   * May reference other entities (e.g., messageId) or contain freeform data.
   */
  payload: Record<string, unknown>
}
```

### 关键特性

- **与运行无关**：MetaEvents 不绑定任何特定的运行生命周期
- **位置灵活**：可以出现在运行之前、之间或之后
- **来源多样**：可能来自用户、客户端或外部系统
- **可扩展**：应用自定义自己的 metaType 取值与负载 schema

## 实现示例

### 用户反馈

**点赞**：

```json
{
  "id": "evt_123",
  "ts": 1714063982000,
  "type": "META",
  "metaType": "thumbs_up",
  "payload": {
    "messageId": "msg_456",
    "userId": "user_789"
  }
}
```

**带理由的点踩**：

```json
{
  "id": "evt_124",
  "ts": 1714063985000,
  "type": "META",
  "metaType": "thumbs_down",
  "payload": {
    "messageId": "msg_456",
    "userId": "user_789",
    "reason": "inaccurate",
    "comment": "The calculation seems incorrect"
  }
}
```

### 注解

**用户笔记**：

```json
{
  "id": "evt_789",
  "ts": 1714064001000,
  "type": "META",
  "metaType": "note",
  "payload": {
    "text": "Important question to revisit",
    "relatedRunId": "run_001",
    "author": "user_123"
  }
}
```

**标签指派**：

```json
{
  "id": "evt_890",
  "ts": 1714064100000,
  "type": "META",
  "metaType": "tag",
  "payload": {
    "tags": ["important", "follow-up"],
    "threadId": "thread_001"
  }
}
```

## 常见 Meta 事件类型

应用可以定义自己的类型，以下是常用的类型：

| MetaType | 描述 | 典型负载 |
| ------------- | ----------------- | ---------------------------------- |
| `thumbs_up` | 正面反馈 | `{ messageId, userId }` |
| `thumbs_down` | 负面反馈 | `{ messageId, userId, reason? }` |
| `note` | 用户注解 | `{ text, relatedId?, author }` |
| `tag` | 分类 | `{ tags[], targetId }` |
| `bookmark` | 稍后保存 | `{ messageId, userId }` |
| `copy` | 内容已复制 | `{ messageId, content }` |
| `share` | 内容已分享 | `{ messageId, method }` |
| `rating` | 数值评分 | `{ messageId, rating, maxRating }` |

## 用例

### 用户反馈收集

采集用户对智能体回复的反应，用于质量改进。

### 会话注解

允许用户在会话的重要部分添加笔记、标签或书签。

### 分析与追踪

在不影响智能体执行的情况下记录用户交互与行为。

### 内容审核

标记内容，供外部审核系统复审。

### 协作功能

让多个用户可以在共享会话上注解或评论。

### 审计链路

为所有交互创建完整记录，而不仅仅是智能体的回复。
