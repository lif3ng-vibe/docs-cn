# 命名约定

把你的包添加到 `integrations/` 目录下，并附上文档与测试。

如果你的集成还在开发中，也依然可以把它添加到 main 分支。可以用 `wip-` 作为前缀（例如 `integrations/wip-your-integration`）；如果你是第三方贡献者，则使用 `community` 前缀（例如 `integrations/community/your-integration`）。

如有问题与讨论，请使用 [GitHub Discussions](https://github.com/ag-ui-protocol/ag-ui/discussions)。
