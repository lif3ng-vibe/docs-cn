在 iOS 模拟器中控制真实的 Mobile Safari，进行原汁原味的移动 Web 测试。基于 Appium 与 XCUITest 实现原生自动化。

## 环境要求

- 已安装 Xcode 的 macOS
- iOS 模拟器运行时（通过 Xcode 下载）
- Appium 及 XCUITest 驱动

## 初始配置

```bash
# 全局安装 Appium
npm install -g appium

# 安装 iOS 的 XCUITest 驱动
appium driver install xcuitest
```

## 列出可用设备

查看系统上所有可用的 iOS 模拟器：

agent-browser device list

## 基本用法

使用 `-p ios` flag 启用 iOS 模式。工作流与桌面端完全一致：

```bash
# 在 iPhone 16 Pro 上启动 Safari
agent-browser -p ios --device "iPhone 16 Pro" open https://example.com

# 获取带引用（ref）的快照（与桌面端相同）
agent-browser -p ios snapshot -i

# 使用引用（ref）交互
agent-browser -p ios tap @e1
agent-browser -p ios fill @e2 "text"

# 截图
agent-browser -p ios screenshot mobile.png

# 关闭会话（同时关闭模拟器）
agent-browser -p ios close
```

## 移动端专有命令

```bash
# 滑动手势
agent-browser -p ios swipe up
agent-browser -p ios swipe down
agent-browser -p ios swipe left
agent-browser -p ios swipe right

# 带距离的滑动（像素）
agent-browser -p ios swipe up 500

# 点按（click 的别名，触屏语境下语义更清晰）
agent-browser -p ios tap @e1
```

## 环境变量

通过环境变量配置 iOS 模式：

```bash
export AGENT_BROWSER_PROVIDER=ios
export AGENT_BROWSER_IOS_DEVICE="iPhone 16 Pro"

# 此后所有命令都走 iOS
agent-browser open https://example.com
agent-browser snapshot -i
agent-browser tap @e1
```

## 支持的设备

Xcode 中所有可用的 iOS 模拟器均受支持，包括：

- 所有 iPhone 机型（iPhone 15、16、17、SE 等）
- 所有 iPad 机型（iPad Pro、iPad Air、iPad mini 等）
- 多个 iOS 版本（17.x、18.x 等）

通过 USB 连接的**真机**也受支持（见下文）。

## 真机支持

Appium 可以控制经 USB 连接的 iOS 真机上的 Safari。这需要额外的一次性配置。

### 1. 获取设备 UDID

```bash
# 列出已连接的设备
xcrun xctrace list devices

# 或通过系统信息工具
system_profiler SPUSBDataType | grep -A 5 "iPhone\|iPad"
```

### 2. 签名 WebDriverAgent（一次性）

WebDriverAgent 需要用你的 Apple Developer 证书签名后才能在真机上运行。

```bash
# 打开 WebDriverAgent 的 Xcode 工程
cd ~/.appium/node_modules/appium-xcuitest-driver/node_modules/appium-webdriveragent
open WebDriverAgent.xcodeproj
```

在 Xcode 中：

1. 选择 `WebDriverAgentRunner` target
2. 进入 Signing & Capabilities
3. 选择你的 Team（需要 Apple Developer 账号，免费版即可）
4. 让 Xcode 自动管理签名

### 3. 配合 agent-browser 使用

```bash
# 经 USB 连接设备后，使用 UDID
agent-browser -p ios --device "<DEVICE_UDID>" open https://example.com

# 设备名唯一时也可直接用设备名
agent-browser -p ios --device "John's iPhone" open https://example.com
```

### 真机注意事项

- 首次运行会向设备安装 WebDriverAgent（设备上可能弹出「信任」提示）
- 设备必须已解锁并经 USB 连接
- 初次连接比模拟器稍慢
- 测得的是真实 Safari 的性能与行为
- 首次安装后，前往「设置 → 通用 → VPN 与设备管理」信任开发者证书

## 性能说明

- **首次启动**：需要 30-60 秒启动模拟器与 Appium
- **后续命令**：很快（模拟器保持运行）
- **close 命令**：会关闭模拟器与 Appium 服务器

## 故障排查

### 找不到 Appium

```bash
# 确认 Appium 已全局安装
npm install -g appium
appium driver install xcuitest

# 验证安装
appium --version
```

### 没有可用模拟器

打开 Xcode，从**设置 → 平台**下载 iOS 模拟器运行时。

### 模拟器无法启动

先从 Xcode 或「模拟器」应用手动启动模拟器，确认其可正常工作，再用 agent-browser 重试。
