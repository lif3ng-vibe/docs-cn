[Browserless](https://browserless.io) 提供带 Sessions API 的云浏览器基础设施。在没有本地浏览器的环境中运行 agent-browser 时使用它。

## 设置

```bash
export BROWSERLESS_API_KEY="your-api-token"
agent-browser -p browserless open https://example.com
```

或在 CI/脚本中使用环境变量：

```bash
export AGENT_BROWSER_PROVIDER=browserless
export BROWSERLESS_API_KEY="your-api-token"
agent-browser open https://example.com
```

`-p` flag 优先于 `AGENT_BROWSER_PROVIDER`。

启用后，agent-browser 会连接 Browserless 云会话，而不是启动本地浏览器。所有命令的工作方式完全相同。

从 [Browserless 仪表盘](https://browserless.io)获取 API 令牌。
