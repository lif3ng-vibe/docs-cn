title: "设置 Apple 以与 Tailscale 配合使用"

---

最后验证于 Sep 26, 2025

**你应该可以直接使用 Apple ID 登录 Tailscale，无需额外配置。**

要在 Tailscale 中使用 Apple 作为你的身份提供方，请在[注册 Tailscale 账户](https://login.tailscale.com/start)时选择 **Sign up with Apple**。

*（图：注册 Tailscale 时选择 Apple）*

> **注意：**
>
> 遗憾的是，我们无法将 tailnet 迁移到 Apple 作为身份提供方，也无法从 Apple 迁出。
