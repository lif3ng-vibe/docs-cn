[**Tailscale 快速开始**](/docs/how-to/quickstart)——几分钟内安装好 Tailscale。创建你的私有网络，随时随地管理任何设备。

[**术语与概念**](/docs/reference/glossary)——了解 Tailscale 的术语与概念。

[**安装 Tailscale**](/docs/install)——安装与卸载 Tailscale 客户端。

[**受支持的 SSO 身份提供方**](/docs/integrations/identity)——Tailscale 构建在你已在使用的 IdP 或 SSO 提供方之上，可利用这些提供方的能力实现安全访问，包括通行密钥（passkey）、2FA 和 MFA。

[**Tailnet 名称与类型**](/docs/concepts/tailnet-name)——tailnet 使用多种名称类型来标识设备和管理访问，包括 Tailnet DNS、machine、Tailnet ID 和 Legacy ID，各自有不同的用途。
