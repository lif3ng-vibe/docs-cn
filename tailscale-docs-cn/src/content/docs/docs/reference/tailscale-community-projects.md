Tailscale Community Projects 是一个经过精选的集合，收录基于 Tailscale 平台构建、由社区支持的开源项目。这些项目展示了如何利用 Tailscale 的网络与身份原语，为组织和社区构建安全、私密的工具。

Tailscale Community Projects 分为以下几类：

* **应用（Apps）**：用户部署在自己的 Tailscale 网络（即 tailnet）内部、原生利用 Tailscale 的应用程序。
* **工具（Tools）**：用户手动或在流水线中运行的程序和脚本，让 Tailscale 管理体验更顺畅。
* **扩展（Extensions）**：用户部署后用于修改或扩展 Tailscale 核心功能的应用程序。
* **界面（Interfaces）**：让用户以超越标准 Tailscale 客户端或网页界面的新方式与设备上的 Tailscale 交互的应用程序。

该平台既包含由 Tailscale 发起的项目，也包含来自更广泛的 Tailscale 社区的项目。关于可用项目的详细信息，请参阅 Tailscale Community Projects [目录][co-community-projects]。

## 收录考量

是否收录进目录完全由 Tailscale 自行决定，不保证任何项目一定会被收录。如果你希望你的项目被考虑收录，请参阅 Community Projects [目录][co-community-projects]中的说明。

评估项目提交时考虑的一些关键方面是：

* **开源**：第三方社区项目可以采用任何有效的开源促进会（OSI）[许可证][xt-osi-licenses]。项目应拥有自己的代码仓库，社区成员可以在其中审查代码、提交 issue 和 pull request。
* **积极维护**：虽然不要求针对问题/缺陷做特定的工作，但我们要求项目尽快修复任何被报告的安全漏洞。
* **合规**。提交的项目应遵守已公布的 Tailscale 指南。

Tailscale 会定期监控目录中的项目，以确保它们持续满足这些要求。我们保留因任何原因将项目从目录中移除的权利。

关于第三方社区项目的信息，请参阅相应项目的文档。
