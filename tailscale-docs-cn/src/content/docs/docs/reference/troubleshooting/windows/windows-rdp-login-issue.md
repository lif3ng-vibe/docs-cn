最后验证于 Feb 18, 2026

如果你在本地使用 PIN（Windows Hello）登录 Windows，可能会发现无法通过远程桌面（RDP）登录。Windows 要求 RDP 连接使用传统的账户密码。

如果你没有账户密码——例如 Windows 11 默认使用 PIN（Windows Hello）——就需要更改登录选项并启用密码认证。更多信息请参阅 Microsoft 支持主题[Windows 登录选项与账户保护][xt-ms-docs-signin-options]。

[xt-ms-docs-signin-options]: https://support.microsoft.com/en-US/accounts-billing/security/sign-in-options-in-windows
