最后验证于 Feb 18, 2026

Apple TV 无法被访问最常见的原因，是它已进入睡眠状态且未配置为家庭中枢（home hub）——配置为家庭中枢后，它可以在睡眠模式下仍保持与网络的连接。有关配置和验证 Apple TV 家庭中枢的信息，请参阅[在 Apple TV 上安装 Tailscale][docs-appletv-troubleshoot]。
