最后验证于 Feb 18, 2026

首次在 Mac 上启动 Tailscale 时，你可能会看到 **System Extension Blocked**（系统扩展被阻止）或 **System Extension Approval Required**（需要批准系统扩展）消息。如果出现这些消息，请参阅[在 macOS 上授权 Tailscale 系统扩展][docs-macos-sysext]了解后续步骤。
