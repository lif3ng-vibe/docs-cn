最后验证于 Feb 18, 2026

要从 iPhone 访问 Mac 上的文件：

1. 在 iPhone 上打开"文件"（Files）App。
2. 进入**浏览**标签页。
3. 选择右上角的（图标）。
4. 选择**连接服务器**，并输入你的 Mac 的 Tailscale IP 地址。

现在，你可以浏览 Mac 通过服务器消息块（SMB）协议共享的所有文件夹。
