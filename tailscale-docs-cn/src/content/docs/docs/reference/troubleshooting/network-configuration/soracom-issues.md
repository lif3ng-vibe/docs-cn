最后验证于 Mar 16, 2026

Tailscale 可以在 SoraCOM 上工作，但无法使用身份服务提供商的 DNS 服务器。我们建议在管理控制台的 [DNS](https://console.tailscale.com/admin/dns) 页面开启 **Override DNS servers**（覆盖 DNS 服务器）开关。
