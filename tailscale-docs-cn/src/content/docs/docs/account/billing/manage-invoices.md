title: "管理你的发票"
description: "你可以下载 Tailscale 账户过去 12 个月的 PDF 发票。"
---

最后验证于 Apr 8, 2026

> **注意：** 按发票付款适用于 [Enterprise 套餐](https://tailscale.com/pricing)。

你可以下载 Tailscale 账户过去 12 个月的 PDF 发票。

> **注意：**
>
> 你需要是[所有者、管理员或账单管理员](/docs/reference/user-roles)才能下载发票。
>
> 如果你通过 AWS Marketplace 或 Azure Marketplace 等合作伙伴计划购买了 Tailscale，请通过 AWS 或 Azure 门户获取发票。这些发票在其各自的合作伙伴门户中管理，而不是在 Tailscale 管理控制台中。

1. 前往管理控制台的 [Billing](https://console.tailscale.com/admin/settings/billing) 页面。
2. 选择 **Invoices** 标签页。
3. 选择你想下载的发票对应的下载图标。
4. 更新你的信息，然后选择 **Save**。

对于基于信用额度的合同，此区域只显示已付款或待付款金额对应的发票。如果你需要发票方面的帮助，请联系 [Tailscale 支持团队][co-contact-support-billing]。

[co-contact-support-billing]: https://tailscale.com/contact/support/?type=billing
