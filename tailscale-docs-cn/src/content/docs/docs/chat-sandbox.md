The Aperture chat sandbox gives the AI assistant a private, isolated Linux environment to run code, analyze data, and produce downloadable files during a chat conversation. Tailscale provisions and manages the infrastructure that runs it. An admin can ask Tailscale to enable the sandbox for their instance. This hub organizes the sandbox documentation by task.
