Tailscale helps organizations meet the security and compliance requirements of regulated environments such as banking, healthcare, and government. Route traffic through fixed IPs for allowlisting, enforce device compliance before granting access, and maintain full audit trails of all connections.

## Popular workflows

[**Provide a static IP egress address to a regulated environment**](/docs/use-cases/regulated-environment/static-egress-ip-allowlist) — Use a static egress IP address for allowlisting when accessing regulated environments like banks or healthcare systems.

[**Enforce device compliance before granting access**](/docs/use-cases/regulated-environment/enforce-device-compliance) — Use Tailscale's device posture features to verify device health and restrict access to sensitive resources based on compliance status.
