---
title: "Infrastructure as code"
description: "Infrastructure as Code integrations let you deploy infrastructure programmatically."
---

Last validated Jan 28, 2025

Use Tailscale's integrations with Infrastructure as Code (IaC) platforms to deploy infrastructure programmatically to your Tailscale network (known as a tailnet). IaC tools let you manage Tailscale resources and settings, including tailnet policy configurations, DNS settings, device properties, and auth keys.

[**Manage Tailscale resources using Terraform**](/docs/integrations/terraform-provider) — Use the Terraform Tailscale provider to interact with the Tailscale API.

[**Manage Tailscale resources using Pulumi**](/docs/integrations/pulumi-provider) — Use the Pulumi Tailscale provider to interact with the Tailscale API.
