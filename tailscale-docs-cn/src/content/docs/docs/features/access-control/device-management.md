Tailscale 提供多种方式，让你管理哪些设备可以加入你的 Tailscale 网络（即 tailnet）。设备可以是个人电脑、移动设备、服务器或其他类型的客户端。

[**添加设备**](/docs/features/access-control/device-management/how-to/set-up) — 将新设备加入你的 Tailscale 网络。

[**设备审批**](/docs/features/access-control/device-management/device-approval) — 在新设备加入 Tailscale 网络之前进行审核与批准。

你无需使用 Tailscale 命令行界面（CLI）即可配置 Tailscale 设置，也适用于没有内置 GUI 的设备。

[**使用网页界面管理设备**](/docs/features/client/device-web-interface) — 通过网页界面管理你的单台设备。

使用设备态势（device posture）收集设备属性，并将其作为 tailnet 内连接规则的一部分。

[**设备态势管理**](/docs/features/device-posture) — 使用设备态势在 tailnet 中强制执行设备规则。
