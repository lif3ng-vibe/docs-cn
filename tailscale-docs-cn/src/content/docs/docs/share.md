description: "查看 tailnet 中的服务、共享机器并共享文件。"
---

最后验证于 Jan 5, 2026

查看机器上的服务、在 Tailscale 网络（即 tailnet）之外安全共享资源，以及在 tailnet 中的设备之间互传文件。

[**查看网络上的端点列表**](/docs/features/services)——了解如何监控 Tailscale 网络中机器上运行的端点，并轻松连接到它们。

[**将你的机器共享给其他用户**](/docs/features/sharing)——让另一个 tailnet 上的 Tailscale 用户访问你 tailnet 内的私有机器，同时不将机器公开暴露。

[**Taildrop**](/docs/features/taildrop)——在 Tailscale 网络上的你的个人设备之间互传文件。
