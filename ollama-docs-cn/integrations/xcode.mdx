## 安装

安装 [XCode](https://developer.apple.com/xcode/)


## 配合 Ollama 使用 
<Note> 请确保已设置 Apple Intelligence，且 XCode 最新版本为 v26.0 </Note>

1. 点击左上角的 **XCode** > **Settings** 
<div style={{ display: 'flex', justifyContent: 'center' }}>
  <img 
    src="/images/xcode-intelligence-window.png" 
    alt="Xcode Intelligence window"
    width="50%"
  />
</div>

2. 选择 **Locally Hosted**，输入端口 **11434**，然后点击 **Add**
<div style={{ display: 'flex', justifyContent: 'center' }}>
  <img 
    src="/images/xcode-locally-hosted.png" 
    alt="Xcode settings"
    width="50%"
  />
</div>

3. 选择左上角的**星形图标**，点击**下拉菜单**
<div style={{ display: 'flex', justifyContent: 'center' }}>
  <img 
    src="/images/xcode-chat-icon.png" 
    alt="Xcode settings"
    width="50%"
  />
</div>
4. 点击 **My Account**，选择你想要的模型


## 直接连接到 ollama.com
1. 在 ollama.com 上创建 [API 密钥](https://ollama.com/settings/keys) 
2. 选择 **Internet Hosted**，将 URL 输入为 `https://ollama.com`  
3. 输入你的 **Ollama API 密钥**，然后点击 **Add**
