## 安装

安装 [marimo](https://marimo.io)。可以使用 `pip` 或 `uv`。你
也可以用 `uv` 为 marimo 创建一个沙箱环境，运行：

```
uvx marimo edit --sandbox notebook.py
```

## 配合 Ollama 使用

1. 在 marimo 中，进入用户设置并切换到 AI 标签页。在这里
你可以找到 Ollama 并将其配置为 AI 提供商。本地使用时，
通常把基础 URL 指向 `http://localhost:11434/v1`。

</div>

## 连接到 ollama.com

1. 使用 `ollama signin` 登录 Ollama 云端
2. 在 ollama 模型设置中添加一个 ollama 托管的模型，如 `gpt-oss:120b`。
3. 现在你就可以在 marimo 中使用这个模型了！
