## 安装

安装 [Cline CLI](https://docs.cline.bot/usage/cli-overview)。IDE 扩展见 [Cline](/integrations/cline)。

```bash
npm install -g cline
```

<Note>如果 Cline CLI 尚未安装且 `npm` 可用，`ollama launch cline` 会提示安装 `cline@latest`。</Note>

## 配合 Ollama 使用

### 快速设置

```bash
ollama launch cline
```

通过 `ollama launch cline` 启动时，Ollama 会将 Cline 的提供商设为 Ollama，把它指向本地 Ollama 端点，并选中你选择的模型。

不启动、只进行配置：

```shell
ollama launch cline --config
```

### 直接用模型运行

```shell
ollama launch cline --model qwen3.5
```

使用云端模型：

```shell
ollama launch cline --model kimi-k2.6:cloud
```


### 向 Cline 传递提示词

`--` 之后的参数会直接传给 Cline：

```shell
ollama launch cline -- "summarize this repository"
```

打开 Cline 的看板（Kanban）：

```shell
ollama launch cline -- kanban
```

### 手动设置

要手动配置 Cline CLI，先确保 Ollama 正在运行且你想用的模型可用：

```shell
ollama pull qwen3.5
```

然后运行 Cline 的交互式认证流程：

```shell
cline auth
```

选择 Ollama 作为提供商，收到提示时将基础 URL 设为 `http://localhost:11434`，并选择诸如 `qwen3.5` 或 `kimi-k2.6:cloud` 的模型。

查看当前 Cline 配置：

```shell
cline config
```

启动交互式会话：

```shell
cline
```
