[OpenCode](https://opencode.ai) 是一个在终端中运行的开源编码代理，它能读取你的项目、编辑文件并运行命令。

Ollama 会将 OpenCode 配置为使用本地与云端模型。

## 快速开始

使用 Ollama 启动 OpenCode：

```shell
ollama launch opencode
```

## 手动设置

<p className="manual-step-title">1. 安装 OpenCode</p>

<CodeGroup>

```shell macOS / Linux
curl -fsSL https://opencode.ai/install | bash
```

```powershell Windows
npm install -g opencode-ai
```

</CodeGroup>

<p className="manual-step-title">2. 将 Ollama 配置为提供商</p>

在 `opencode.json` 中添加一个 Ollama 提供商：

```json
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "ollama": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Ollama",
      "options": {
        "baseURL": "http://localhost:11434/v1"
      },
      "models": {
        "qwen3.5": {
          "name": "qwen3.5"
        }
      }
    }
  }
}
```

<p className="manual-step-title">3. 运行 OpenCode</p>

```shell
opencode
```

要在不启动交互式会话的情况下为 OpenCode 配置 Ollama：

```shell
ollama launch opencode --config
```

### 配置优先级

`ollama launch opencode` 会以内联配置启动 OpenCode，用于所选的 Ollama 模型。它不会覆盖 `~/.config/opencode/opencode.json`；已有的 OpenCode 设置仍然生效。

仅在 `opencode.json` 中定义的模型不会出现在 `ollama launch` 的模型选择器中。

参见 OpenCode 的[配置优先级](https://opencode.ai/docs/config/#precedence-order)。
