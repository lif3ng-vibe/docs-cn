### GPU 选择

如果你的系统中有多块 NVIDIA GPU，想限制 Ollama 只使用其中一部分，可以将 `CUDA_VISIBLE_DEVICES` 设置为逗号分隔的 GPU 列表。
可以使用数字 ID，但顺序可能会有变化，因此 UUID 更可靠。
运行 `nvidia-smi -L` 可以查看各 GPU 的 UUID。如果你想
忽略 GPU 并强制使用 CPU，可以给一个无效的 GPU ID（如 "-1"）。

### Linux 休眠恢复

在 Linux 上，经过一次挂起/恢复循环后，Ollama 有时会无法发现
你的 NVIDIA GPU，从而回退到 CPU 上运行。可以通过重新加载 NVIDIA UVM 驱动来规避这个
驱动缺陷：`sudo rmmod nvidia_uvm &&
sudo modprobe nvidia_uvm`

### Linux 上的覆盖设置

Ollama 使用的 AMD ROCm 库并不支持所有 AMD GPU。某些
情况下，你可以强制系统尝试使用一个相近的 LLVM target。例如，Radeon RX 5400 是 `gfx1034`（也写作 10.3.4），
但 ROCm 目前不支持该 target。最接近的受支持 target
是 `gfx1030`。你可以将环境变量 `HSA_OVERRIDE_GFX_VERSION` 设为
`x.y.z` 格式。举例来说，要强制系统在 RX 5400 上运行，你
需要在服务器上设置环境变量 `HSA_OVERRIDE_GFX_VERSION="10.3.0"`。如果你的 AMD GPU 不受支持，可以参考下方
受支持类型的列表进行试验。

如果你有多块 GFX 版本不同的 GPU，可以在环境变量后追加数字设备
编号来分别设置。例如，
`HSA_OVERRIDE_GFX_VERSION_0=10.3.0` 和 `HSA_OVERRIDE_GFX_VERSION_1=11.0.0`。

### GPU 选择

如果你的系统中有多块 AMD GPU，想限制 Ollama 只使用其中
一部分，可以将 `ROCR_VISIBLE_DEVICES` 设置为逗号分隔的 GPU 列表。
可以使用 `rocminfo` 查看设备列表。如果你想忽略 GPU
并强制使用 CPU，可以给一个无效的 GPU ID（如 "-1"）。在可用时，请使用
`Uuid` 而非数字值来唯一标识设备。

### 容器权限

在某些 Linux 发行版上，SELinux 可能会阻止容器
访问 AMD GPU 设备。你可以在宿主机上运行
`sudo setsebool container_use_devices=1` 来允许容器使用设备。

## Vulkan GPU 支持

Windows 和 Linux 上的更多 GPU 支持通过
[Vulkan](https://www.vulkan.org/) 提供。后端安装后 Vulkan 默认启用。在 Windows 上，大多数 GPU 厂商的驱动
都自带 Vulkan 支持，无需额外的设置步骤。大多数 Linux
发行版需要安装额外组件，而且你可能在 Mesa 与 GPU 厂商专属包之间
有多种 Vulkan 驱动可选

- Linux Intel GPU 说明 - https://dgpu-docs.intel.com/driver/client/overview.html
- Linux AMD GPU 说明 - https://amdgpu-install.readthedocs.io/en/latest/install-script.html#specifying-a-vulkan-implementation

对于某些 Linux 发行版上的 AMD GPU，你可能需要将 `ollama` 用户加入 `render` 用户组。

Ollama 调度器利用 GPU 库上报的可用显存数据来
做出最优的调度决策。Vulkan 需要额外的能力或
以 root 身份运行才能暴露这些可用显存数据。如果既没有 root 权限也没有该
能力，Ollama 将使用模型的近似大小
来尽力做出调度决策。

```bash
sudo setcap cap_perfmon+ep /usr/local/bin/ollama
```

### GPU 选择

要选择特定的 Vulkan GPU，可以按照 [FAQ](faq#如何配置-ollama-服务器) 中的说明，将 Ollama 服务器上的环境变量
`GGML_VK_VISIBLE_DEVICES` 设置为一个或多个数字 ID。如果你
在使用基于 Vulkan 的 GPU 时遇到任何问题，可以通过设置 `OLLAMA_VULKAN=0` 或 `GGML_VK_VISIBLE_DEVICES=-1` 禁用所有 Vulkan GPU。

在 Vulkan iGPU 不稳定的混合 iGPU/dGPU 系统上，保持 Vulkan
启用，并将 `GGML_VK_VISIBLE_DEVICES` 设置为独立显卡的索引。例如，当 `Vulkan1` 是独立
GPU 时，使用 `GGML_VK_VISIBLE_DEVICES=1`。
