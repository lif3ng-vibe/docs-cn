---
title: "流式"
---

流式输出让你可以在模型生成文本的同时将其渲染出来。

通过 REST API 使用时流式默认开启，但在 SDK 中默认关闭。

要在 SDK 中启用流式，将 `stream` 参数设为 `True`。

## 流式核心概念
1. 对话：流式输出助手消息的各个部分。每个数据块都包含 `content`，你可以在消息到达时逐段渲染。
1. 思考：支持思考的模型会在每个数据块中随常规内容一起输出 `thinking` 字段。在流式数据块中检测该字段，即可在最终答案到达前显示或隐藏推理过程。
1. 工具调用：留意每个数据块中流式传来的 `tool_calls`，执行所请求的工具，并将工具输出追加回对话。

## 处理流式数据块


<Note> 必须累加这些部分字段，才能维护对话的历史记录。这对工具调用尤其重要：思考内容、模型发起的工具调用以及执行得到的工具结果，都必须在下一次请求中传回给模型。 </Note>

<Tabs>
  <Tab title="Python">

    ```python
    from ollama import chat

    stream = chat(
      model='qwen3',
      messages=[{'role': 'user', 'content': 'What is 17 × 23?'}],
      stream=True,
    )

    in_thinking = False
    content = ''
    thinking = ''
    for chunk in stream:
      if chunk.message.thinking:
        if not in_thinking:
          in_thinking = True
          print('Thinking:\n', end='', flush=True)
        print(chunk.message.thinking, end='', flush=True)
        # 累加部分思考内容
        thinking += chunk.message.thinking
      elif chunk.message.content:
        if in_thinking:
          in_thinking = False
          print('\n\nAnswer:\n', end='', flush=True)
        print(chunk.message.content, end='', flush=True)
        # 累加部分内容
        content += chunk.message.content

      # 将累加的字段追加到消息中，供下一次请求使用
      new_messages = [{ role: 'assistant', thinking: thinking, content: content }]
    ```

  <Tab title="JavaScript">

    ```javascript
    import ollama from 'ollama'

    async function main() {
      const stream = await ollama.chat({
        model: 'qwen3',
        messages: [{ role: 'user', content: 'What is 17 × 23?' }],
        stream: true,
      })

      let inThinking = false
      let content = ''
      let thinking = ''

      for await (const chunk of stream) {
        if (chunk.message.thinking) {
          if (!inThinking) {
            inThinking = true
            process.stdout.write('Thinking:\n')
          }
          process.stdout.write(chunk.message.thinking)
          // accumulate the partial thinking
          thinking += chunk.message.thinking
        } else if (chunk.message.content) {
          if (inThinking) {
            inThinking = false
            process.stdout.write('\n\nAnswer:\n')
          }
          process.stdout.write(chunk.message.content)
          // accumulate the partial content
          content += chunk.message.content
        }
      }

      // append the accumulated fields to the messages for the next request
      new_messages = [{ role: 'assistant', thinking: thinking, content: content }]
    }

    main().catch(console.error)
    ```
