**GET** `/api/ps`

获取当前正在运行的模型列表

## 请求示例

```bash 列出运行中模型
curl http://localhost:11434/api/ps
```

## 响应

### 200

当前已加载到内存中的模型

**`PsResponse`** 属性：

| 属性 | 类型 | 必填 | 描述 |
| --- | --- | --- | --- |
| `models` | `array<Ps>` | 否 | 当前正在运行的模型 |
