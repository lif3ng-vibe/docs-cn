## 探索模型

选择云端模型，或在自己的电脑上运行模型。

<CardGroup cols={2}>
  <Card title="云端模型" icon="cloud" href="/cloud">
    无需本地 GPU 即可运行模型。
  </Card>
  <Card title="本地模型" icon="hard-drive" href="/quickstart#run-a-model-locally">
    下载 Ollama，在你的电脑上运行一个模型。
  </Card>
</CardGroup>

浏览[模型库](https://ollama.com/search)，查找编码、视觉、嵌入和推理模型。
