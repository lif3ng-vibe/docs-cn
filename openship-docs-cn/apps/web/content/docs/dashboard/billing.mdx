<Callout title="仅限 Openship Cloud">
Billing 管理的是所选组织**在 Openship Cloud 上的资源**。
自托管的资源是免费的；已连接 Cloud 的实例可以管理 Cloud 计费。
</Callout>

## 自托管没有计费

纯**自托管**的 OpenShip 没有任何需要支付的东西，也不显示计费数据——
Billing 区干脆不会出现。你只需为自己买单基础设施。

## Openship Cloud

在 Cloud 上，**Billing** 是你查看用量、更换套餐、获取账单的地方。
各套餐、价格与每套餐的限制发布在[定价页](/pricing)；本界面的页眉横条显示你套餐内已用掉的计量点数（credit）和提供方上报的容量。CPU、RAM 与磁盘配额在整个命名空间内共享，包括已停止的工作区和待生效的变更；点数不是分钟数。
云流量是计量的，但未知的流量上限不会显示为无限。套餐定价与限制由 OpenShip 制定；各组织购买的条款会被保留供续期使用。

| 标签页 | 功能 |
| --- | --- |
| **Overview** | 当前套餐、计费周期和点数余额。 |
| **Usage** | 周期内的计量用量，以图表呈现。 |
| **Plans** | 升级或降级——发起一个 Stripe Checkout 会话。 |
| **Top-ups** | 在现有套餐上一次性购买点数，不改变资源限制。 |
| **Payment Method** | 打开 Stripe 门户管理银行卡。 |
| **Invoices** | 打开 Stripe 门户下载账单。 |

从 **Plans** 取消订阅，会让订阅在你已付费的这个周期结束后终止；之后新的计费工作会被阻止。你可以在那个周期结束前恢复续订。取消不会删除资源。

更换套餐会开启一个不按比例折算（proration）的新全价周期。支付返回页会核验具体的 checkout 与点数发放。它显示 pending、refunded、disputed 或 failed 状态，而不是从浏览器 URL 推断成功。账单与支付方式门户按所选组织隔离打开，与其他客户和经销账户互不干扰。

这一屏背后的接口参见[计费 API](/docs/api/billing)。

## 点数告警与恢复

当 Cloud 点数不足时，控制台会出现一条常驻横幅，链接到受影响工作区的计费页面。达到最后一级警告、进入宽限点数以及点数耗尽时，还会弹出一个可关闭的对话框。只有当充值可用时，点数包购买才会出现。

警告级别、通知方式，以及购买后余额如何刷新，参见[点数告警与恢复](/docs/guides/billing#credit-warnings-and-recovery)。
