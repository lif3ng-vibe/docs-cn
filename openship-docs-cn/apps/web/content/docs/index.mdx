## 核心概念

**组织**（organization）拥有项目（project），并向其成员授予访问权限。**项目**保存源代码与配置。**部署**是对该项目的一次构建与发布。**服务**（service）是项目内的工作负载，例如一个应用或数据库。

环境、运行时（runtime）、服务器与域名等内容，参见[核心概念](/docs/getting-started/core-concepts)。
