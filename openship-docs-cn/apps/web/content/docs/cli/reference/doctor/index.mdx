## openship doctor

检查数据库与服务健康状态，并修复损坏的本地数据库

```text
openship doctor [options]
```

| 选项 | 含义 |
| --- | --- |
| `--fix` | 尝试自动修复数据库（备份 → 自愈 → 重启），全程无交互提示 |
