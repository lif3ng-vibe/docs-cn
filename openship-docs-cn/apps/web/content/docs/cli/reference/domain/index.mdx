## openship domain

管理自定义域名、DNS 验证与 SSL 证书

```text
openship domain [options] [command]
```

| 子命令 | 用途 |
| --- | --- |
| [`list [options]`](/docs/cli/reference/domain#openship-domain-list) | 列出项目的自定义域名 |
| [`add [options] <hostname>`](/docs/cli/reference/domain#openship-domain-add) | 为项目添加自定义域名 |
| [`preview <hostname>`](/docs/cli/reference/domain#openship-domain-preview) | 预览某主机名所需的 DNS 记录（不保存任何变更） |
| [`verify <id>`](/docs/cli/reference/domain#openship-domain-verify) | 对域名执行 DNS 验证 |
| [`primary <id>`](/docs/cli/reference/domain#openship-domain-primary) | 将某域名设为项目的主主机名 |
| [`records <id>`](/docs/cli/reference/domain#openship-domain-records) | 显示既有域名的 DNS 记录 |
| [`renew <id>`](/docs/cli/reference/domain#openship-domain-renew) | 为域名续期 SSL 证书 |
| [`verify-ssl <id>`](/docs/cli/reference/domain#openship-domain-verify-ssl) | 复查某域名的 SSL 证书是否已签发且有效（不重新签发） |
| [`renew-all`](/docs/cli/reference/domain#openship-domain-renew-all) | 为组织中所有临近到期的域名续期 SSL |

## openship domain add

为项目添加自定义域名

```text
openship domain add [options] <hostname>
```

| 参数 | 含义 |
| --- | --- |
| `hostname` | 域名主机名（例如 app.example.com） |

| 选项 | 含义 |
| --- | --- |
| `-p, --project <id>` | 要挂载该域名的项目 ID |
| `--primary` | 将该域名标记为项目的主域名（默认：false） |
