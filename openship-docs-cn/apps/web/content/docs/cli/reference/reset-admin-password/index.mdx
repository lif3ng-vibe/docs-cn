## openship reset-admin-password

重置本机（THIS machine）的本地管理员登录（无需登录凭据）

```text
openship reset-admin-password [options]
```

| 选项 | 说明 |
| --- | --- |
| `--port <port>` | 运行中服务的 API 端口（默认：本次安装解析到的端口，否则为 4000） |
| `--email <email>` | 同时设置管理员邮箱 |
| `--name <name>` | 同时设置管理员显示名称 |
| `--password <password>` | 新密码（省略时交互提示输入） |
