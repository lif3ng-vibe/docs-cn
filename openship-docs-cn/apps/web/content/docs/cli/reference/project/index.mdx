## openship project

管理 Openship 项目

```text
openship project|projects [options] [command]
```

| 子命令 | 用途 |
| --- | --- |
| [`list\|ls`](/docs/cli/reference/project#openship-project-list) | 列出当前组织中的项目 |
| [`get <id>`](/docs/cli/reference/project#openship-project-get) | 查看单个项目 |
| [`rename <id> <name>`](/docs/cli/reference/project#openship-project-rename) | 修改项目的显示名称 |
| [`release-image [options] <id>`](/docs/cli/reference/project#openship-project-release-image) | 跟踪并部署带版本号的预构建容器镜像 |
| [`create [options]`](/docs/cli/reference/project#openship-project-create) | 创建项目 |
| [`delete\|rm [options] <id>`](/docs/cli/reference/project#openship-project-delete) | 删除项目（拆除所有资源） |
| [`env`](/docs/cli/reference/project#openship-project-env) | 管理项目环境变量 |
| [`git`](/docs/cli/reference/project/git#openship-project-git) | 管理 Git 关联与自动部署 |
| [`connect [options] <id> <domain>`](/docs/cli/reference/project#openship-project-connect) | 为项目连接自定义域名 |
| [`enable <id>`](/docs/cli/reference/project#openship-project-enable) | 启动一个已停止的项目 |
| [`disable <id>`](/docs/cli/reference/project#openship-project-disable) | 停止一个运行中的项目 |
| [`sleep-mode <id> <mode>`](/docs/cli/reference/project#openship-project-sleep-mode) | 设置项目的休眠模式 |
| [`transfer <id> <direction>`](/docs/cli/reference/project#openship-project-transfer) | 将项目升级到 Openship Cloud，或迁回来（仅自托管） |
| [`logs [options] <id>`](/docs/cli/reference/project#openship-project-logs) | 查看或流式输出运行时（容器）日志 |
| [`server-logs [options] <id>`](/docs/cli/reference/project#openship-project-server-logs) | 查看或流式输出 HTTP 请求日志（edge/OpenResty） |

## openship project connect

为项目连接自定义域名

```text
openship project connect [options] <id> <domain>
```

| 参数 | 说明 |
| --- | --- |
| `id` | 项目 ID |
| `domain` | 自定义域名的主机名 |

| 选项 | 说明 |
| --- | --- |
| `--include-www` | 同时连接 www. 变体 |

## openship project create

创建项目

```text
openship project create [options]
```

| 选项 | 说明 |
| --- | --- |
| `--name <name>` | 项目名称 |
| `--slug <slug>` | 自由子域名的 slug（slug.opsh.io） |
| `--git-owner <owner>` | GitHub 所有者/组织 |
| `--git-repo <repo>` | GitHub 仓库名 |
| `--git-branch <branch>` | 要部署的 Git 分支 |
| `--framework <framework>` | 技术栈/框架 ID |
| `--local-path <path>` | 本地源路径 |
| `--port <port>` | 容器端口 |
| `--type <type>` | 项目类型：app \| docker \| services \| monorepo |
| `--server <id>` | 已注册的服务器 ID（参见 `openship server list`） |

## openship project delete

删除项目（拆除所有资源）

```text
openship project delete|rm [options] <id>
```

| 参数 | 说明 |
| --- | --- |
| `id` | 项目 ID |

| 选项 | 说明 |
| --- | --- |
| `--force` | 取消正在进行的任务并强制删除 |
| `--force-orphan` | 无法销毁的资源先转为孤儿，再删除记录 |
| `--wipe-volumes` | 同时销毁持久化卷 |
| `-y, --yes` | 跳过确认提示 |

| --- | --- |

| 选项 | 说明 |
| --- | --- |

## openship project env set

合并环境变量：upsert KEY=VALUE 键值对，和/或删除键

```text
openship project env set [options] <id>
```

| 参数 | 说明 |
| --- | --- |
| `id` | 项目 ID |

| 选项 | 说明 |
| --- | --- |
| `--environment <env>` | 目标环境（默认："production"） |
| `--set <pair>` | 要 upsert 的 KEY=VALUE（可重复）（默认：[]） |
| `--unset <key>` | 要删除的 KEY（可重复）（默认：[]） |
| `--secret` | 将所有 --set 的值标记为敏感值 |

## openship project release-image

跟踪并部署带版本号的预构建容器镜像

```text
openship project release-image [options] <id>
```

| 参数 | 说明 |
| --- | --- |
| `id` | 项目 ID |

| 选项 | 说明 |
| --- | --- |
| `--image-template <reference>` | 镜像引用，含 &#123;tag&#125; 或 &#123;version&#125;，例如 ghcr.io/acme/api:&#123;tag&#125; |
| `--github-repo <owner/repo>` | 从 GitHub Releases 解析版本 |
| `--version-url <https-url>` | 返回版本号或标签的 HTTPS 端点 |
| `--pin <version>` | 部署固定版本，而不是已发现的最新发布 |
