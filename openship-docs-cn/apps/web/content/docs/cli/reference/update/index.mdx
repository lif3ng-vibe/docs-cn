## openship update

将 Openship CLI 及其打包的服务端更新到最新发布版本

```text
openship update [options]
```

| 选项 | 说明 |
| --- | --- |
| `--check` | 只报告当前版本与最新版本；不安装 |
| `--via <manager>` | 用哪个包管理器更新：bun \| npm |
| `--rebuild` | 源码安装：即使已处于远端最新提交也重新构建 |
