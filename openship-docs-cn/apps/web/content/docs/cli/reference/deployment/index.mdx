## openship deployment

管理部署（列出、查看、重新部署、回滚等）

```text
openship deployment|deployments [options] [command]
```

| 子命令 | 用途 |
| --- | --- |
| [`list [options]`](/docs/cli/reference/deployment#openship-deployment-list) | 列出部署（全组织范围，或限定到某项目） |
| [`get <id>`](/docs/cli/reference/deployment#openship-deployment-get) | 查看单次部署 |
| [`info <id>`](/docs/cli/reference/deployment#openship-deployment-info) | 查看某次部署的容器信息 |
| [`usage <id>`](/docs/cli/reference/deployment#openship-deployment-usage) | 查看某次部署的容器资源用量 |
| [`redeploy [options] <id>`](/docs/cli/reference/deployment#openship-deployment-redeploy) | 从一次既有部署重新部署 |
| [`rollback <id>`](/docs/cli/reference/deployment#openship-deployment-rollback) | 回滚到之前的某次部署 |
| [`pin [options] <id>`](/docs/cli/reference/deployment#openship-deployment-pin) | 固定（或解除固定）某次部署的回滚产物 |
| [`cancel <id>`](/docs/cli/reference/deployment#openship-deployment-cancel) | 取消进行中的部署 |
| [`restart <id>`](/docs/cli/reference/deployment#openship-deployment-restart) | 重启某次部署的容器 |
| [`reject <id>`](/docs/cli/reference/deployment#openship-deployment-reject) | 拒绝一次等待保留/拒绝决定的已完成部署 |
| [`keep <id>`](/docs/cli/reference/deployment#openship-deployment-keep) | 保留一次等待保留/拒绝决定的已完成部署 |
| [`pending <id>`](/docs/cli/reference/deployment#openship-deployment-pending) | 查看某次部署当前的提示与待决定事项 |
| [`respond [options] <id>`](/docs/cli/reference/deployment#openship-deployment-respond) | 回应部署的待处理提示 |
| [`rm [options] <id>`](/docs/cli/reference/deployment#openship-deployment-rm) | 删除一次部署 |
| [`ssl`](/docs/cli/reference/deployment#openship-deployment-ssl) | SSL 证书操作 |

## openship deployment list

列出部署（全组织范围，或限定到某项目）

```text
openship deployment list [options]
```

| 选项 | 含义 |
| --- | --- |
| `--project <id>` | 限定到某项目（默认取关联项目） |
| `--env <environment>` | 按环境筛选：production \| preview |
| `--limit <n>` | 最大获取行数（默认："50"） |

## openship deployment pin

固定（或解除固定）某次部署的回滚产物

```text

```

| 参数 | 含义 |
| --- | --- |
| `id` | 部署 ID |

| 选项 | 含义 |
| --- | --- |
| `--off` | 解除固定而非固定 |

## openship deployment redeploy

从一次既有部署重新部署

```text
openship deployment redeploy [options] <id>
```

| 参数 | 含义 |
| --- | --- |
| `id` | 部署 ID |

| 选项 | 含义 |
| --- | --- |
| `--use-existing-commit` | 重建同一 commit 而非该分支上的最新提交 |

## openship deployment ssl renew

```text

```

| 参数 | 含义 |
| --- | --- |
| `domain` | 要续期的域名 |

| 选项 | 含义 |
| --- | --- |
| `--www` | 同时续期 www 子域名（单独处理——拥有各自的证书） |
