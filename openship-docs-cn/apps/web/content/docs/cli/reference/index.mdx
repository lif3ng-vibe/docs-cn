使用 `openship <command> --help` 检查你机器上已安装的版本。`<value>` 为必填，`[value]` 为可选。别名会在命令名旁列出。

## 全局选项

| 选项 | 含义 |
| --- | --- |
| `-V, --version` | 输出版本号 |
| `--json` | 机器可读的 JSON 输出（仅 stdout 数据） |
| `--native-config <file>` | 使用显式受信任的 JavaScript 配置运行 SDK 命令 |
| `-h, --help` | 显示命令帮助 |

全局选项应放在命令之前，例如 `openship --json project list`。使用 `--native-config` 前先参见[原生模式](/docs/cli/native)。

## 本地安装

| 命令 | 用途 |
| --- | --- |
| [`openship up`](/docs/cli/reference/up) | 以常驻服务启动 Openship（开机自启 + 自动重启）；--foreground 可前端附着运行 |
| [`openship stop`](/docs/cli/reference/stop) | 停止 Openship（由 `openship up` 启动）——重启后不会自动再启动 |
| [`openship status`](/docs/cli/reference/status) | 查看本地 Openship 服务（安装/运行状态、端口）与激活上下文的 API 健康状况 |
| [`openship doctor`](/docs/cli/reference/doctor) | 检查数据库与服务的健康状况，并修复损坏的本地数据库 |
| [`openship open`](/docs/cli/reference/open) | 在浏览器中打开 Openship 控制台 |
| [`openship install`](/docs/cli/reference/install) | 下载并安装适用于当前操作系统的 Openship 桌面应用 |
| [`openship update`](/docs/cli/reference/update) | 将 Openship CLI 与随附的服务端更新到最新发行版 |
| [`openship uninstall`](/docs/cli/reference/uninstall) | 从本机移除 Openship：停止它、删除其数据（数据库、证书、edge 配置）、镜像与 ~/.openship。已部署的应用不受影响，继续运行。 |
| [`openship reset-admin-password`](/docs/cli/reference/reset-admin-password) | 重置本机上的本地管理员登录（无需先登录） |
