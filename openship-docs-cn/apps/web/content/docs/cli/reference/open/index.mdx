## openship open

在浏览器中打开 Openship 控制台

```text
openship open [options]
```

| 选项 | 说明 |
| --- | --- |
| `--cloud` | 打开托管的云端控制台（app.openship.io） |
| `--dashboard-url <url>` | 要打开的控制台基础 URL |
| `--context <name>` | 打开该 context 的控制台 URL |
| `--path <path>` | 要打开的控制台路径（例如 /settings） |
