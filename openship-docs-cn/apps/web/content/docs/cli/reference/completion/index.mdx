## openship completion

生成 shell 补全脚本

```text
openship completion [options] <shell>
```

| 参数 | 含义 |
| --- | --- |
| `shell` | 补全脚本对应的 shell 类型（可选值："zsh"、"bash"、"fish"、"powershell"） |
