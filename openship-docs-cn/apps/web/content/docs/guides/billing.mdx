## 自托管免费

如果你在自己的机器或服务器上运行 Openship，**Openship 软件本身无须付费**。你只需要为自己的基础设施付费（服务器、带宽，以及你选择使用的第三方服务）。Openship 本身以 Apache 2.0 许可开源——永久免费，没有席位上限，也没有计量收费。

## Openship Cloud

Openship Cloud 是托管运行的选择：由我们来运行服务器、边缘网络和备份。选择付费套餐即可创建 Cloud 项目、构建并运行工作负载。月付套餐为 $5 / $20 / $40 / $99，企业定制条款请通过销售团队洽谈。没有套餐的账户没有包含的 Cloud 算力。Hobby 是面向轻度使用的有限额度；持续托管可能需要充值。

所有套餐、价格与每个套餐的限制都集中在一处——见[定价页](/pricing)。同一份目录也由 `GET /api/billing/plans` 提供。这些价格、点数额度与限制由 Openship 掌控。你订阅时购买的条款会保存下来供续订使用，即便目录日后变动。点数是计量的；容量限制并不承诺固定的运行时长。

运行中服务的额度在整个组织范围通用。一个 Compose 项目运行在一台 Cloud VM 上，必须装得进这台机器的 CPU、内存和磁盘容量，包括需要构建源码时的临时构建资源。纯镜像模板不预留源码构建机。更大的套餐让你跨项目运行更多服务；而不是让它们合并成一台任意大的 VM。如果整套栈超出了该容量，请拆分到多个项目或调小机器规格。

当前各月付套餐包含 400 / 1,700 / 3,500 / 9,000 个计量点数。命名空间总上限为 1 / 2 / 4 / 8 vCPU、4 / 6 / 8 / 16 GB 内存、16 / 32 / 128 / 256 GB 磁盘，分别对应 Hobby / Starter / Pro / Team。已停止的工作区、构建主机和待生效的资源配置变更都计入分配。此外还有单台 VM 的限制；服务数量并不保证每个服务都能同时以最大规格运行。

点数包提供 $5 加 400 点、$20 加 1,700 点、$50 加 4,500 点。点数不等于分钟：实际消耗取决于活跃 Oblien 费率卡下的 CPU、内存与流量。额外点数延长使用量；升级套餐提高容量。此前购买的点数授权与价格仍与其保存的订阅绑定。

每个套餐都包含**不限量的团队成员**：你看到的价格覆盖的是整个组织，而非按人头计费。

## 管理你的套餐

控制台（dashboard）中的 **Billing** 区域以标签页组织：

| 标签页 | 功能 |
| --- | --- |
| **Overview** | 当前套餐、计费周期与点数余额。 |
| **Usage** | 本周期内计量用量的图表。 |
| **Plans** | 升级或降级——会发起一个 Stripe Checkout 会话。 |
| **Top-ups** | 在现有套餐之上一次性加购点数；不提高资源上限。 |
| **Payment Method** | 打开 Stripe 门户管理银行卡。 |
| **Invoices** | 打开 Stripe 门户下载账单。 |

取消订阅后，套餐在你已付费的周期结束前保持有效，之后阻止新的计费性工作。在付费期结束前你可以撤销已计划的取消。取消不会删除任何东西。每个组织都有各自的账单门户、支付历史和命名空间额度。

当符合条件的付费套餐用完点数时，仍可继续加购点数（Top-ups），包括在已计划的取消生效之前。它们无法重启已终止或已逾期的套餐；请先恢复订阅再购买更多点数。

套餐变更在付款后开启一个全新的全价计费周期，不会自动按比例折算，也不会退还旧周期费用。切到更小的限制之前，先停止/缩容或移除任何超出新套餐的资源。结账返回页会等待付款与点数发放；未完成的履约不会显示为购买成功。

这些操作背后的端点请参见[计费 API](/docs/api/billing)。

## 点数告警与恢复

Cloud 告警使用你工作区（workspace）当前的点数余额，含已购买的点数。默认告警阈值为 80% 和 95%。点数偏低期间横幅持续可见；在最终告警阈值、宽限点数开始发放、或点数耗尽时，会出现一个可关闭的对话框。

选择 **Buy more credits** 在可加购时打开点数包，或选择 **Open billing** 查看套餐与选项。购买后请等待结账界面确认点数已发放。回到控制台时告警会刷新，且在其可见期间每分钟刷新一次。购买点数不会提高套餐的 CPU、内存或其他资源限制。

计费告警遵循你的通知偏好。邮件通知需要已验证的邮箱地址和一条可用的邮件连接；控制台告警独立可用。告警中的链接会选中该告警所属的工作区。如果你访问不了它，请用属于该工作区的账号登录。
