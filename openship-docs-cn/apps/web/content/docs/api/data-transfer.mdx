## 团队模式迁移

按以下三条路径之一将单用户实例迁入团队模式（team mode），也可以反向迁回。这四条路由都要求组织管理员（org admin/owner）身份，并且除非 `teamMode === "single_user"`，否则拒绝（**409**）。参见 [cloud connect / 迁移指南](/docs/guides/cloud-connect-migration)。

预检与启动（路径 A——你自己的服务器）共用一个请求体：

```
POST /api/system/migration/start
```

<TypeTable
  type={{
    serverId: { type: 'string', description: '迁移目标所用的已保存服务器。', required: true },
    domain: { type: '{ kind: "custom", hostname } | { kind: "free", slug }', description: '迁移后的实例将可通过哪个地址访问——自定义主机名或免费子域名 slug。', required: true },
  }}
/>

- `POST /api/system/migration/start-cloud`——路径 B，迁移到 Openship Cloud。请求体：`{ allowNonEmptyTarget?: boolean }`。
- `POST /api/system/migration/start-tunnel`——路径 C，通过一条 edge 隧道暴露。请求体：`{ slug: string }`（必填）。
- `POST /api/system/migration/switch-back`——反向执行以上任一路径。请求体：`{ abandonRemote?: boolean }`。

<Callout title="切换回来会切断队友的访问" type="warn">
反向迁回单用户模式会吊销队友的访问权限。远端会保留一份副本 30 天宽限期，以便你反悔时还能找回。
</Callout>

## 实例与项目数据传输

导出整个实例，或一个依赖完整的项目与环境集合。这些路由需要**实例管理员**权限（`requireInstanceAdmin()` 外加一个 handler 级检查）。仅有工作区所有者（owner）角色不代表可以访问实例凭据。

```
POST /api/system/data-transfer/export
```

项目导入会把所有权重映射到当前请求的工作区。它们不会包含实例账号/设置，
会复用匹配的服务器连接，并且默认跳过已存在的项目。overwrite 模式会替换所选项目，包括移除所选类别中只存在于目标侧的记录，并清空那些在源侧已被清空的凭据。被排除出导入的类别会原样保留。共享依赖会保留，除非显式启用
`overwriteDependencies`。源侧的 local 主机需要一条显式的 `serverMappings`
记录（没有服务器数据行的项目使用 `local`）。Cloud 项目要求连接的是同一 cloud 账号。项目归档不能与 `wipe` 一起使用。

大文件请使用分块上传端点。上传完成后，向该会话的 `preview` 端点 POST `{ selection }`。它会在不消耗上传内容的前提下返回 `projects`、`servers`、`availableServers`、行数、`rowsRemoved`、`warnings` 与
`blockers`。然后向
`/api/system/data-transfer/import/session/:sessionId/finalize/stream` POST `{ mode, passphrase, selection }` 来应用。校验会在导入事务内部再次执行。审阅失败或密码错误都会保留已上传的分块。

新的实例与项目导出使用信封版本 4，内容为**未加密的 JSON**，包括环境变量值、SSH 密钥、令牌、部署快照以及内联的 Compose 配置。无需密码；旧版导出客户端提供的 `passphrase` 会被忽略。要省略凭据，请显式设置
`includeSecrets: false`。导入仍然接受版本 1–3（包括旧版密码保护文件），并使用目标实例的密钥加密恢复后的凭据。目标实例无法存储的表或字段的归档，会在任何数据变更之前被整体拒绝；
请更新目标实例，而不是丢失这些字段。卷数据、源代码文件夹与宿主机 TLS 文件仍保留在原服务器上。

在项目导入中，环回（loopback）服务器连接需要显式映射。指向源本地存储或备份主机已变化的备份策略会被禁用，直到运营者验证目标存储为止。直传支持整实例导出；项目选择则使用文件审阅与导入端点。

<Callout title="导入限制与错误" type="error">
导入请求体上限为 **500 MB**（超出返回 **413 `PAYLOAD_TOO_LARGE`**）。格式错误的文件，或旧版加密归档的密码错误/缺失，返回 **400**。项目依赖/映射冲突返回 **409
`PROJECT_IMPORT_REQUIRES_REVIEW`**；整实例 merge 的冲突返回 **409 `PK_COLLISION`**。要解决项目冲突，请选择项目范围并指定明确的 overwrite 选项。并发的迁移/导入返回 **503 `BUSY`**。
</Callout>

| 操作 | REST API |
| --- | --- |
| 接收一次已授权直传的一个分块。 | `PUT /api/system/data-transfer/direct/chunk/:sessionId/:index`<br />`Handler authentication` · 自托管 |
| 收尾一次已接收的直传并流式输出进度。 | `POST /api/system/data-transfer/direct/chunk/:sessionId/finalize/stream`<br />`Handler authentication` · 自托管 |
| 保持直传分块会话存活。 | `POST /api/system/data-transfer/direct/chunk/:sessionId/heartbeat`<br />`Handler authentication` · 自托管 |
| 打开一次直传分块上传。 | `POST /api/system/data-transfer/direct/chunk/init`<br />`Handler authentication` · 自托管 |
| 接收一次直传的整实例传输。 | `POST /api/system/data-transfer/direct/receive`<br />`Handler authentication` · 自托管 |
| 把一个实例发送到已授权目标。 | `POST /api/system/data-transfer/direct/send`<br />`settings:admin` · 自托管 |
| 把一个实例发送到已授权目标并流式输出进度。 | `POST /api/system/data-transfer/direct/send/stream`<br />`settings:admin` · 自托管 |
| 创建一个直传会话。 | `POST /api/system/data-transfer/direct/session`<br />`settings:admin` · 自托管 |
| 导出实例或所选项目（实例管理员）。 | `POST /api/system/data-transfer/export`<br />`settings:admin` · 自托管 |
| 导入一个导出文件，≤500 MB，可指定范围与冲突选项（实例管理员）。 | `POST /api/system/data-transfer/import`<br />`settings:admin` · 自托管 |
| 打开一个分块文件导入会话。 | `POST /api/system/data-transfer/import/session`<br />`settings:admin` · 自托管 |
| 上传一个文件导入分块。 | `PUT /api/system/data-transfer/import/session/:sessionId/chunk/:index`<br />`settings:admin` · 自托管 |
| 应用一次已审阅的文件导入并流式输出进度。 | `POST /api/system/data-transfer/import/session/:sessionId/finalize/stream`<br />`settings:admin` · 自托管 |
| 预览一个已上传文件的所选范围、冲突与服务器映射。 | `POST /api/system/data-transfer/import/session/:sessionId/preview`<br />`settings:admin` · 自托管 |
| 列出可导出的项目与实例数据行数（实例管理员）。 | `GET /api/system/data-transfer/preview`<br />`settings:admin` · 自托管 |
| 预览一个项目选择及其依赖（实例管理员）。 | `POST /api/system/data-transfer/preview`<br />`settings:admin` · 自托管 |
| 团队迁移就绪检查（只读）。 | `POST /api/system/migration/preflight`<br />`settings:admin` · 自托管 |
| 将单用户迁移到 → 你自己的远端服务器。 | `POST /api/system/migration/start`<br />`settings:admin` · 自托管 |
| 迁移到 → Openship Cloud。 | `POST /api/system/migration/start-cloud`<br />`settings:admin` · 自托管 |
| 通过一条 edge 隧道暴露本实例。 | `POST /api/system/migration/start-tunnel`<br />`settings:admin` · 自托管 |
| 反向迁移回单用户模式。 | `POST /api/system/migration/switch-back`<br />`settings:admin` · 自托管 |
