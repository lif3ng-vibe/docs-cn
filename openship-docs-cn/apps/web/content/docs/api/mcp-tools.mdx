本目录由 MCP 发现所使用的路由元数据生成。对你的实例运行 `tools/list` 可获取其当前输入 schema
以及你的凭据可用的工具。参见 [MCP 安装](/docs/mcp)、[协议与参数](/docs/api/mcp)以及
[集群/扩缩容工作流](/docs/guides/mcp-clusters-and-scaling)。

当前 API 共有 **424 个不重复的工具**。下文的权限标签描述路由的初始权限；共享操作还会强制执行
工作区、资源、源访问与实例管理要求。自托管工具在托管的云控制器上不可用。
