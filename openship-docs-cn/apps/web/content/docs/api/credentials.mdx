---
title: 提供方凭据
description: 存储并校验组织持有的镜像仓库与 DNS 凭据。
---

提供方凭据（provider credential）让 Openship 能拉取私有镜像或更新 DNS。一个凭据归属于
一个组织。读取操作只暴露公开字段与掩码后的密钥指示；创建、修改、验证或移除凭据需要管理员权限。

## 发现支持的提供方

在构建凭据表单之前，先读取提供方定义。每个定义都包含其 ID、能力、选择器要求与字段键。创建凭据时，请在 `values` 对象中使用这些键。

<Tabs items={['SDK', 'REST API']} groupId="api-transport" persist>
<Tab value="SDK">

```ts
const providers = await ship.credentials.listProviders();
console.log(providers);
```

</Tab>
<Tab value="REST API">

```bash
curl "$OPENSHIP_URL/api/credentials/providers" \
  -H "Authorization: Bearer $OPENSHIP_TOKEN"
```

</Tab>
</Tabs>

## 创建或更新凭据

| 字段 | 类型 | 用途 |
| --- | --- | --- |
| `provider` | `string` | 创建时必填；提供方目录中的一个 ID，最长 64 个字符。 |
| `name` | `string` | 创建时必填；1–100 个字符的显示名称。 |
| `selector` | `string` 或 `null` | 提供方特定的镜像仓库或账号选择器。 |
| `values` | `Record<string, string>` | 创建时必填；由提供方定义的公开字段与密钥字段。 |

更新接受 `name`、`selector` 与 `values`。提供方不可更改。请使用来自你凭据表单或密钥库中的值；读取返回的掩码值不能当作替换用的密钥。

## 验证已保存的凭据

<Tabs items={['SDK', 'REST API']} groupId="api-transport" persist>
<Tab value="SDK">

```ts
const credential = await ship.credentials.verify("cred_123");
console.log(credential.status, credential.lastError);
```

</Tab>
<Tab value="REST API">

```bash
curl -X POST "$OPENSHIP_URL/api/credentials/cred_123/verify" \
  -H "Authorization: Bearer $OPENSHIP_TOKEN"
```

</Tab>
</Tabs>

验证会返回凭据的状态、`lastVerifiedAt` 与 `lastError`。将凭据用于部署之前，请先检查其状态。DNS 连接工作流参见 [DNS 提供方](/docs/api/dns)。

## 操作

{/* api-operations:start */}

| 操作 | SDK | REST API |
| --- | --- | --- |
| 列出提供方凭据类型与必填字段。 | `credentials.listProviders()` | `GET /api/credentials/providers`<br />`settings:read` |
| 列出已存储的凭据（密钥已掩码）。 | `credentials.list()` | `GET /api/credentials`<br />`settings:read` |
| 存储一个提供方凭据。 | `credentials.create(input)` | `POST /api/credentials`<br />`settings:admin` |
| 读取一条掩码后的凭据。 | `credentials.get(id)` | `GET /api/credentials/:id`<br />`settings:read` |
| 重命名、重新限定范围或轮换凭据。 | `credentials.update(id, input)` | `PATCH /api/credentials/:id`<br />`settings:admin` |
| 移除凭据。 | `credentials.remove(id)` | `DELETE /api/credentials/:id`<br />`settings:admin` |
| 用凭据对接其提供方进行校验并记录结果。 | `credentials.verify(id)` | `POST /api/credentials/:id/verify`<br />`settings:admin` |

{/* api-operations:end */}
