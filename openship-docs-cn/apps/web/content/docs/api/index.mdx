## 发起请求

使用一个可以读取你组织内项目的令牌。SDK 返回应用层结果；
REST 返回该端点的 JSON 响应。

<Tabs items={['SDK', 'REST API']} groupId="api-transport" persist>
<Tab value="SDK">

```ts title="list-projects.mts"
import { OpenshipClient } from "openship";

const token = process.env.OPENSHIP_TOKEN;
const organizationId = process.env.OPENSHIP_ORGANIZATION_ID;
if (!token || !organizationId) throw new Error("Set a token and organization ID");

const ship = new OpenshipClient({
  baseUrl: "https://ship.example.com",
  token,
  organizationId,
});

const projects = await ship.projects.list({ page: 1, perPage: 20 });
console.log(projects.data);
```

</Tab>
<Tab value="REST API">

```bash
export OPENSHIP_URL="https://ship.example.com"
export OPENSHIP_ORGANIZATION_ID="org_123"
# 将 OPENSHIP_TOKEN 设置为你的个人访问令牌。

curl "$OPENSHIP_URL/api/projects?page=1&perPage=20" \
  -H "Authorization: Bearer $OPENSHIP_TOKEN" \
  -H "X-Organization-Id: $OPENSHIP_ORGANIZATION_ID" \
  -H "X-Openship-Scope: fixed"
```

</Tab>
</Tabs>

### 示例约定

资源示例中的 `ship` 指代已配置的远端客户端或[原生用户作用域](/docs/api/sdk/identity)。
把 `proj_123` 之类的 ID 换成你自己的。REST 示例使用上面的地址与令牌；令牌的组织绑定
作用于每一个请求。要让组织固定而不依赖默认值，请附带上文所示的两个作用域请求头。
[旧版本 API 必须支持固定作用域](/docs/api/sdk/compatibility#固定组织作用域)。

具名 SDK 方法会在适用时解包响应信封。例如，`projects.get(id)` 直接返回一个项目，
而其 REST 端点返回 `{ data: project }`。ID 在 SDK 中可能是方法参数，在 REST 中则是 URL、
查询或请求体字段；代码标签页展示了这一映射。
