# 自托管 vs 托管平台：真实成本拆解

“直接用 Vercel”是个好建议——直到账单寄到。我们把同一个 Next.js 应用跑在三套环境上，逐项记录了 30 天的全部开销。

## 测试应用

一个生产级 Next.js 15 应用，具备：
- 约 50 个路由，启用 ISR
- Postgres 数据库
- Redis 缓存
- 每月约 10 万访问者
- 每月约 500GB 流量

## 结果

| | Vercel Pro | AWS（ECS + RDS） | Openship（自托管） |
|---|---|---|---|
| 计算 | $150/月 | $85/月 | $24/月 |
| 数据库 | $50/月（Neon） | $45/月 | 包含 |
| 流量 | $120/月 | $45/月 | 包含 |
| SSL/域名 | 包含 | $1/月 | 包含 |
| **合计** | **$320/月** | **$176/月** | **$24/月** |

自托管 Openship 跑在一台 Hetzner VPS 上（CPX31：4 vCPU、8GB 内存、160GB SSD）。

## 取舍

托管平台让你零运维：推代码，就部署。这是实实在在的价值。

但 Openship 把差距缩小了一大截：
- **AI 包办配置**——构建识别、Dockerfile 生成与 SSL 全部自动。
- **一条命令部署**——`openship deploy` 一样快。
- **内置监控**——日志、指标与告警开箱即用。

剩下的取舍是服务器维护——系统更新、磁盘空间、在线率监控。对大多数团队来说，每月不过几个小时。

## 什么时候适合自托管

以下情况适合自托管：
- 在托管平台上月账单超过约 100 美元
- 你有数据主权或合规要求
- 你想要可预期的固定价格
- 你要部署多个应用（成本不随之增加）
