agent-desktop 共有 11 个分组、60 条命令。每条命令都输出一个 JSON 信封，包含 `version`、`ok`、`command`，以及 `data` 或 `error` 二者之一；[JSON 输出](/desktop/json-output)定义了这一格式。

```bash
agent-desktop --help               # 列出全部命令
agent-desktop <command> --help     # 查看某条命令的 flag 与参数
agent-desktop skills get desktop   # 读取编译进二进制文件的智能体使用指南
```

`--help` 输出的是你所安装二进制文件支持的 flag。对所有命令都生效的 flag，例如 `--headed`、`--session`、`--agent-id`、`--trace`，以及操作后的 `--wait-for` 系列 flag，在[配置](/desktop/configuration)中统一说明。
