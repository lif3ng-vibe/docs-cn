# agent-desktop 文档翻译任务简报

## 任务
把指定的 MDX 文件从英文翻译为简体中文。逐个文件处理,
每个工具回复只输出/写入一个文件,然后继续下一个。
全部完成后输出一行统计:完成文件清单。

## 输出位置
原地翻译:直接覆盖 content/docs/ 下对应文件(保持路径与文件名不变,
slug/文件名/frontmatter 键名一律不动)。

## 锚点映射(必须)
每个文件翻译前,先扫描其中所有标题(## 及以上,含 ### 等)与页内
#锚点 链接。产出 .anchor-maps/<相对路径>.map.md:
格式每行 `英文标题 | 中文标题 | 新锚点`;没有标题的文件写空表。

## 翻译规范
- 不译:代码块、命令行、flag、环境变量、报错原文、路径、API/方法名、
  配置键、表格中的命令/取值列;CLI 命令清单的 # 注释要译。
- 要译:frontmatter title/description(一句话)、正文意译、表头与说明列、
  :::tip/callout 块、Diagram 的 title prop、表格内单元格说明文。
- 术语与排版按术语表 GLOSSARY.md(注入材料)。
- 全角标点;中英文/数字之间一个半角空格;引号用“”弯引号。
- 粗体 CJK 闭合:粗体闭合 ** 前不能是全角标点后接文字。
  句读移出粗体:**……。**后文 ✗ → **……**。后文 ✓;**标题:** → **标题**:
- frontmatter description 以 @ 开头必须加引号。
- MDX 组件标签(如 <Diagram name=...>)原样保留,只译自然文本。
- 页内锚点链接(#xxx)保留原样,回修由主会话统一做;链接路径一律不动。
