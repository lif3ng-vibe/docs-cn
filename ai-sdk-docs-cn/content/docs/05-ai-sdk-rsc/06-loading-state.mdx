# Handling Loading State

<Note type="warning">
  AI SDK RSC 目前处于实验性阶段。我们建议在生产环境中使用
  [AI SDK UI](/docs/ai-sdk-ui/overview)。有关从 RSC 迁移到 UI
  的指导，请参阅我们的[迁移指南](/docs/ai-sdk-rsc/migrating-to-ui)。
</Note>

由于语言模型的响应往往需要一段时间才能完成，能够向用户展示加载状态至关重要。这为用户提供了系统正在处理其请求的视觉反馈，有助于保持良好的用户体验。

使用 AI SDK RSC 处理加载状态有三种方法：

- 以传统 Next.js 应用的方式管理加载状态。即在客户端设置一个加载状态变量，并在收到响应时更新它。
- 将加载状态从服务器流式传输到客户端。这种方式让你能在更细的粒度上追踪加载状态，并向用户提供更详细的反馈。
- 将加载组件从服务器流式传输到客户端。这种方式让你可以在等待模型响应的同时，将 React 服务器组件（RSC）流式传输到客户端。

## 在客户端处理加载状态

### 客户端

让我们创建一个简单的 Next.js 页面，在表单提交时调用 `generateResponse` 函数。该函数接收用户的提示词（`input`），然后生成响应（`response`）。为了处理加载状态，使用 `loading` 状态变量：表单提交时将 `loading` 设为 `true`，收到响应后再设回 `false`。在响应流式传输期间，输入框将被禁用。

```tsx filename='app/page.tsx'
'use client';

import { useState } from 'react';
import { generateResponse } from './actions';
import { readStreamableValue } from '@ai-sdk/rsc';

// Force the page to be dynamic and allow streaming responses up to 30 seconds
export const maxDuration = 30;

export default function Home() {
  const [input, setInput] = useState<string>('');
  const [generation, setGeneration] = useState<string>('');
  const [loading, setLoading] = useState<boolean>(false);

  return (
    <div>
      <div>{generation}</div>
      <form
        onSubmit={async e => {
          e.preventDefault();
          setLoading(true);
          const response = await generateResponse(input);

          let textContent = '';

          for await (const delta of readStreamableValue(response)) {
            textContent = `${textContent}${delta}`;
            setGeneration(textContent);
          }
          setInput('');
          setLoading(false);
        }}
      >
        <input
          type="text"
          value={input}
          disabled={loading}
          className="disabled:opacity-50"
          onChange={event => {
            setInput(event.target.value);
          }}
        />
        <button>Send Message</button>
      </form>
    </div>
  );
}
```

### 服务端

现在来实现 `generateResponse` 函数。使用 `streamText` 函数针对输入生成响应。

```typescript filename='app/actions.ts'
'use server';

import { streamText } from 'ai';
__PROVIDER_IMPORT__;
import { createStreamableValue } from '@ai-sdk/rsc';

export async function generateResponse(prompt: string) {
  const stream = createStreamableValue();

  (async () => {
    const { textStream } = streamText({
      model: __MODEL__,
      prompt,
    });

    for await (const text of textStream) {
      stream.update(text);
    }

    stream.done();
  })();

  return stream.value;
}
```

## 从服务器流式传输加载状态

如果你想在更细的粒度上追踪加载状态，可以创建一个新的可流式值来存储自定义变量，然后在前端读取它。让我们更新示例，创建一个新的可流式值来追踪加载状态：

### 服务端

```typescript filename='app/actions.ts' highlight='9,22,25'
'use server';

import { streamText } from 'ai';
__PROVIDER_IMPORT__;
import { createStreamableValue } from '@ai-sdk/rsc';

export async function generateResponse(prompt: string) {
  const stream = createStreamableValue();
  const loadingState = createStreamableValue({ loading: true });

  (async () => {
    const { textStream } = streamText({
      model: __MODEL__,
      prompt,
    });

    for await (const text of textStream) {
      stream.update(text);
    }

    stream.done();
    loadingState.done({ loading: false });
  })();

  return { response: stream.value, loadingState: loadingState.value };
}
```

### 客户端

```tsx filename='app/page.tsx' highlight="22,34-42"
'use client';

import { useState } from 'react';
import { generateResponse } from './actions';
import { readStreamableValue } from '@ai-sdk/rsc';

// Force the page to be dynamic and allow streaming responses up to 30 seconds
export const maxDuration = 30;

export default function Home() {
  const [input, setInput] = useState<string>('');
  const [generation, setGeneration] = useState<string>('');
  const [loading, setLoading] = useState<boolean>(false);

  return (
    <div>
      <div>{generation}</div>
      <form
        onSubmit={async e => {
          e.preventDefault();
          setLoading(true);
          const { response, loadingState } = await generateResponse(input);

          let textContent = '';

          // read both streamable values concurrently
          await Promise.all([
            (async () => {
              for await (const responseDelta of readStreamableValue(response)) {
                textContent = `${textContent}${responseDelta}`;
                setGeneration(textContent);
              }
            })(),
            (async () => {
              for await (const loadingDelta of readStreamableValue(
                loadingState,
              )) {
                if (loadingDelta) {
                  setLoading(loadingDelta.loading);
                }
              }
            })(),
          ]);
          setInput('');
          setLoading(false);
        }}
      >
        <input
          type="text"
          value={input}
          disabled={loading}
          className="disabled:opacity-50"
          onChange={event => {
            setInput(event.target.value);
          }}
        />
        <button>Send Message</button>
      </form>
    </div>
  );
}
```

这让你能够就生成过程向用户提供更详细的反馈。

## 使用 `streamUI` 流式传输加载组件

如果你正在使用 [ `streamUI` ](/docs/reference/ai-sdk-rsc/stream-ui) 函数，可以以 React 组件的形式将加载状态流式传输到客户端。`streamUI` 支持 [JavaScript 生成器函数](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/function*)，它允许你在其他阻塞工作完成的同时产出某个值（在这里是 React 组件）。

## 服务端

```ts
'use server';

import { openai } from '@ai-sdk/openai';
import { streamUI } from '@ai-sdk/rsc';

export async function generateResponse(prompt: string) {
  const result = await streamUI({
    model: openai('gpt-6-astra'),
    prompt,
    text: async function* ({ content }) {
      yield <div>loading...</div>;
      return <div>{content}</div>;
    },
  });

  return result.value;
}
```

<Note>
  请记得将文件从 `.ts` 改为 `.tsx`，因为你正在 `streamUI` 函数中定义 React 组件。
</Note>

## 客户端

```tsx
'use client';

import { useState } from 'react';
import { generateResponse } from './actions';
import { readStreamableValue } from '@ai-sdk/rsc';

// Force the page to be dynamic and allow streaming responses up to 30 seconds

export default function Home() {

  const [generation, setGeneration] = useState<React.ReactNode>();

      <form
        onSubmit={async e => {
          e.preventDefault();

        }}

        <input
          type="text"
          value={input}
          onChange={event => {
            setInput(event.target.value);
          }}
        />
        <button>Send Message</button>
      </form>
    </div>
  );
}
```
