为了高效地使用 AI SDK，建议先熟悉以下概念：

## 生成式人工智能

**生成式人工智能**（generative artificial intelligence）指的是这样一类模型：它们根据统计上的可能性来预测并生成各种类型的输出（如文本、图像或音频），其依据是从训练数据中学到的模式。例如：

- 给定一张照片，生成式模型可以生成一段图注。
- 给定一个音频文件，生成式模型可以生成一段语音转写（transcription）。
- 给定一段文字描述，生成式模型可以生成一幅图像。

## 大语言模型

**大语言模型（LLM，large language model）**是生成式模型的一个子集，主要专注于**文本**。大语言模型以一个词序列作为输入，目标是预测接下来最可能出现的序列。它会为各种可能的后续序列分配概率，然后从中选择一个。模型会持续生成序列，直到满足某个指定的停止条件。

大语言模型通过在海量书面文本上训练来学习，因此它们更适合某些使用场景，而不太适合另一些。例如，在 GitHub 数据上训练的模型，对源代码中序列的概率分布会理解得特别好。

然而，理解大语言模型的局限性至关重要。当被问到不太知名或不存在的信息（例如某位亲友的生日）时，大语言模型可能会"产生幻觉"，即编造信息。因此，务必考虑你需要的信息在模型中的覆盖程度如何。

## 嵌入模型

**嵌入模型**（embedding model）用于将复杂数据（如单词或图像）转换为稠密向量（即一列数字）表示，即嵌入（embedding）。与生成式模型不同，嵌入模型不会生成新的文本或数据。相反，它们提供实体之间语义与句法关系的表示，这些表示可以作为其他模型或其他自然语言处理任务的输入。
