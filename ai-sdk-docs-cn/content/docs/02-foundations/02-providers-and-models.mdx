# Providers and Models

OpenAI、Anthropic 等公司（即提供商，provider）通过各自的 API 提供一系列具有不同优势与能力的大语言模型（LLM）。

每个提供商通常都有自己独特的模型接入方式，这使得切换提供商变得复杂，并增加了被厂商锁定（vendor lock-in）的风险。

为解决这些挑战，AI SDK Core 通过一套[语言模型规范](https://github.com/vercel/ai/tree/main/packages/provider/src/language-model/v3)提供了与 LLM 交互的标准化方式，抽象掉了提供商之间的差异。这一统一接口让你可以在提供商之间轻松切换，同时对所有提供商使用相同的 API。
