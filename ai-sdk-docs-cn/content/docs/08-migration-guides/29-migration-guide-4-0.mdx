# Migrate AI SDK 3.4 to 4.0

<Note>
  欲了解本次发布的更多信息，请查阅 [AI SDK 4.0 发布博客文章](https://vercel.com/blog/ai-sdk-4-0)。
</Note>

## 推荐迁移流程

1. 备份你的项目。如果使用版本控制系统，请确保所有历史版本都已提交。
1. [迁移到 AI SDK 3.4](/docs/migration-guides/migration-guide-3-4)。
1. 升级到 AI SDK 4.0。
1. 使用 [codemod](#codemods) 自动迁移代码。
   > 如果不想使用 codemod，我们建议在升级到 AI SDK 4.0 之前先解决所有弃用警告。
1. 按照下文的破坏性变更指南操作。
1. 确认项目运行正常。
1. 提交你的变更。

## AI SDK 4.0 包版本

你需要在 `package.json` 文件中将以下包更新到相应版本：

- `ai` 包：`4.0.*`
- `@ai-sdk/provider-utils` 包：`2.0.*`
- `@ai-sdk/*` 包：`1.0.*`（其他 `@ai-sdk/*` 包）

## Codemods

当某个功能被弃用、移除或发生其他变更时，AI SDK 提供 Codemod 转换来帮助你升级代码库。

Codemod 是在代码库上以编程方式运行的转换。它让你无需逐个文件手动修改，就能轻松应用大量变更。

<Note>
  Codemod 只是协助升级的工具，可能无法覆盖你需要做出的所有变更，部分改动可能仍需手动完成。
</Note>

在项目根目录运行以下命令，即可执行 4.0 升级流程提供的所有 codemod：

```sh
npx @ai-sdk/codemod upgrade
```

只运行 v4 codemod：

```sh
npx @ai-sdk/codemod v4
```

也可以指定 codemod 名称来单独运行某个 codemod：

```sh
npx @ai-sdk/codemod <codemod-name> <path>
```

例如，运行某个特定的 v4 codemod：

```sh
npx @ai-sdk/codemod v4/replace-baseurl src/
```

另请参阅 [codemod 对照表](#codemod-对照表)。此外，最新的一批 codemod 可以在
[`@ai-sdk/codemod`](https://github.com/vercel/ai/tree/main/packages/codemod/src/codemods)
仓库中找到。

## 提供商变更

### 移除 `baseUrl` 选项

所有提供商都移除了 `baseUrl` 选项。请改用 `baseURL` 选项。

```ts filename="AI SDK 3.4"
const perplexity = createOpenAI({
  // ...
  baseUrl: 'https://api.perplexity.ai/',
});
```

```ts filename="AI SDK 4.0"
const perplexity = createOpenAI({
  // ...
  baseURL: 'https://api.perplexity.ai/',
});
```

### Anthropic 提供商

#### 移除 `Anthropic` 门面

`Anthropic` 门面（facade）已从 Anthropic 提供商中移除。
请改用 `anthropic` 对象或 `createAnthropic` 函数。

```ts filename="AI SDK 3.4"
const anthropic = new Anthropic({
  // ...
});
```

```ts filename="AI SDK 4.0"
const anthropic = createAnthropic({
  // ...
});
```

#### 移除 `topK` 设置

<Note type="warning">
  此变更没有可用的 codemod。请手动检查并更新你的代码。
</Note>

Anthropic 提供商移除了模型特定的 `topK` 设置。
你可以改用标准的 `topK` 设置。

```ts filename="AI SDK 3.4"
const result = await generateText({
  model: anthropic('claude-3-5-sonnet-latest', {
    topK: 0.5,
  }),
});
```

```ts filename="AI SDK 4.0"
const result = await generateText({
  model: anthropic('claude-3-5-sonnet-latest'),
  topK: 0.5,
});
```

## AI SDK Core 变更

### `streamText` 立即返回

`streamText` 函数现在立即返回，不再返回 Promise。
无需再 await `streamText` 的结果。

```ts filename="AI SDK 3.4"
const result = await streamText({
  // ...
});
```

```ts filename="AI SDK 4.0"
const result = streamText({
  // ...
});
```

### `streamObject` 立即返回

`streamObject` 函数现在立即返回，不再返回 Promise。
无需再 await `streamObject` 的结果。

```ts filename="AI SDK 3.4"
const result = await streamObject({
  // ...
});
```

```ts filename="AI SDK 4.0"
const result = streamObject({
  // ...
});
```

### 移除 roundtrips

`generateText` 和 `streamText` 函数移除了 `maxToolRoundtrips` 和 `maxAutomaticRoundtrips` 选项（往返调用）。
请改用 `maxSteps` 选项。

`GenerateTextResult` 类型移除了 `roundtrips` 属性。
请改用 `steps` 属性。

```ts filename="AI SDK 3.4"
const { text, roundtrips } = await generateText({
  maxToolRoundtrips: 1, // or maxAutomaticRoundtrips
  // ...
});
```

```ts filename="AI SDK 4.0"
const { text, steps } = await generateText({
  maxSteps: 2,
  // ...
});
```

### 移除 `nanoid` 导出

`nanoid` 导出已被移除。请改用 [`generateId`](/docs/reference/ai-sdk-core/generate-id)。

```ts filename="AI SDK 3.4"
import { nanoid } from 'ai';
```

```ts filename="AI SDK 4.0"
import { generateId } from 'ai';
```

### 生成的 ID 默认长度增大

<Note type="warning">
  此变更没有可用的 codemod。请手动检查并更新你的代码。
</Note>

[`generateId`](/docs/reference/ai-sdk-core/generate-id) 函数现在生成 16 字符的 ID。之前的默认值是 7 个字符。

如果你限制了 ID 的长度，可能因此需要更新数据库 schema。

```ts filename="AI SDK 4.0"
import { generateId } from 'ai';

const id = generateId(); // now 16 characters
```

const { messages } = useChat({

## AI SDK 2.x 旧版变更

<Note type="warning">
  本节的变更没有可用的 codemod。请手动检查并更新你的代码。
</Note>

### 移除 2.x 旧版提供商

AI SDK 2.x 的旧版提供商已被移除。请改用新的 [AI SDK 提供商架构](/docs/foundations/providers-and-models)。

#### 移除 2.x 旧版函数与工具调用

`useChat` 和 `Message` 移除了旧版的 `function_call` 和 `tools` 选项。
`Message` 类型移除了 `name` 属性。
请改用 [AI SDK Core 工具调用](/docs/ai-sdk-core/tools-and-tool-calling)。

### 移除 2.x 提示词辅助函数

在 AI SDK 提供商架构下，用于构造消息提示词的辅助函数已不再需要，因此被移除。

### 移除 2.x 的 `AIStream`

`AIStream` 函数及相关导出已被移除。
请改用 [`streamText`](/docs/reference/ai-sdk-core/stream-text) 函数及其 `toDataStream()` 方法。

### 移除 2.x 的 `StreamingTextResponse`

`StreamingTextResponse` 函数已被移除。
请改用 [`streamText`](/docs/reference/ai-sdk-core/stream-text) 函数及其 `toDataStreamResponse()` 方法。

### 移除 2.x 的 `streamToResponse`

`streamToResponse` 函数已被移除。
请改用 [`streamText`](/docs/reference/ai-sdk-core/stream-text) 函数及其 `pipeDataStreamToResponse()` 方法。

### 移除 2.x 的 RSC `Tokens` 流式传输

2.x 的旧版 `Tokens` RSC 流式传输已被移除。
`Tokens` 实现于 AI SDK RSC 之前，已不再需要。
