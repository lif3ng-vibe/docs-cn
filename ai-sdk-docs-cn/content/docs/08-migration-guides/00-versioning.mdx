# Versioning

每个版本号遵循以下格式：`MAJOR.MINOR.PATCH`

- **主版本**（Major）：包含破坏性更新、需要修改代码的 API 变更。
- **次版本**（Minor）：以博客文章形式汇总新功能与改进，随公开发布一同推出并重点介绍其价值。
- **补丁版本**（Patch）：新功能与错误修复。

## API 稳定性

我们通过以下方式标明 API 的稳定性：

### 稳定 API

所有不带特殊前缀的 API 均视为稳定 API，可直接用于生产环境。我们对稳定功能保持向后兼容，只在主版本中引入破坏性变更。

### 实验性 API

带有 `experimental_` 或 `Experimental_` 前缀的 API（例如 `experimental_generateImage()`）仍处于开发阶段，在任何版本中都可能发生变更。要安全地使用实验性 API：

1. 先在开发环境中测试，不要在生产环境使用
2. 升级前查看发布说明
3. 为潜在的代码改动做好准备

<Note type="warning">
  如果你使用了实验性 API，请确保将 AI SDK 版本号精确固定（避免使用 ^ 或 ~ 版本范围），以防止出现意外的破坏性变更。
</Note>

### 已弃用 API

标记为 `deprecated` 的 API 将在未来的主版本中移除。你可以等到主版本发布后再更新代码。处理弃用项的方法：

1. 切换到推荐的替代 API
2. 参照迁移指南（随主版本一同发布）

<Note>
  对于主版本，我们会尽可能提供自动化 codemod，帮助你将代码迁移到新版本。
</Note>
