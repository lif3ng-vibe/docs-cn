# `useChat()`

让你能够轻松地为聊天机器人应用创建对话式用户界面。它支持从你的 AI 提供商流式传输聊天消息、管理聊天状态，并在收到新消息时自动更新 UI。

<Note>
  `useChat` API 在 AI SDK 5.0 中进行了重大更新。它现在采用基于
  transport 的架构，不再在内部管理输入状态。详情请参阅
  [迁移指南](/docs/migration-guides/migration-guide-5-0#usechat-变更)。
</Note>

## React 渲染与共享 Chat 实例

在 React 中，`messages`、`status` 和 `error` 描述的是当前渲染对应的快照。
底层的 `Chat` 会随着流分块的处理而更新。React 可能会批量处理更新，
而 `throttle` 可以延迟消息渲染，但不会延迟流处理或回调。
状态与错误更新会附带最新消息，因此已完成或已失败的响应会以其最终消息快照渲染。

每次 `useChat({ chat })` 调用都会独立订阅。共享同一个 `Chat`
的消费者在使用不同节流间隔时，可能显示不同的消息快照。
函数式 `setMessages` 更新器接收的是 Chat 的最新消息，这些消息可能比
当前渲染中的消息更新。
