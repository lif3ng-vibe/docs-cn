# `useObject()`

<Note>
  `useObject` 可用于 React、Svelte、Vue 以及 SolidJS 社区集成。Angular 提供等价的
  `StructuredObject` 服务。
</Note>

让你能够消费表示 JSON 对象的文本流，并根据 schema 将其解析为完整对象。
你可以在后端将它与 [`streamText`](/docs/reference/ai-sdk-core/stream-text) 和 [`Output.object()`](/docs/reference/ai-sdk-core/output#output-object) 结合使用。

```tsx
'use client';

import { useObject } from '@ai-sdk/react';

export default function Page() {
  const { object, submit } = useObject({
    api: '/api/use-object',
    schema: z.object({ content: z.string() }),
  });

  return (
    <div>
      <button onClick={() => submit('example input')}>Generate</button>
      {object?.content && <p>{object.content}</p>}
    </div>
  );
}
```
