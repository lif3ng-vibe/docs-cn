# `LanguageModelV4Middleware`

<Note type="warning">
  语言模型中间件是一项实验性功能。
</Note>

语言模型中间件提供了一种通过拦截和修改对语言模型的调用来增强语言模型行为的方式。它可以以与具体语言模型无关的方式添加防护栏（guardrails）、RAG、缓存和日志记录等特性。

更多信息请参阅 [语言模型中间件](/docs/ai-sdk-core/middleware)。
