# `streamText()`

从语言模型流式生成文本。

你可以将 streamText 函数用于聊天机器人等交互式用例和其他实时应用，还可以借助工具生成 UI 组件。

```ts
import { streamText } from 'ai';
__PROVIDER_IMPORT__;

const { textStream } = streamText({
  model: __MODEL__,
  prompt: 'Invent a new holiday and describe its traditions.',
});

for await (const textPart of textStream) {
  process.stdout.write(textPart);
}
```

有关 `runtimeContext`、`toolsContext`、工具 `context` 以及敏感上下文过滤的指引，请参阅[运行时与工具上下文](/docs/ai-sdk-core/runtime-and-tool-context)。

要查看 `streamText` 的实际用法，请查看[这些示例](#示例)。

## 类型

### `ActiveTools`

```ts
type ActiveTools<TOOLS extends ToolSet> =
  | ReadonlyArray<keyof TOOLS & string>
  | undefined;
```

将生成步骤限制为所列的工具名称。`undefined` 表示不应用任何工具限制。
