# `experimental_getRealtimeToolDefinitions()`

<Note type="warning">
  `experimental_getRealtimeToolDefinitions` 属于实验性实时 API。
</Note>

将 AI SDK 的 `ToolSet` 转换为提供商中立的实时工具定义（realtime tool definitions），可传入实时会话的 setup 请求。

在创建短期实时提供商 token 的服务器端 setup 端点中使用它。

```ts
import { openai } from '@ai-sdk/openai';
import { experimental_getRealtimeToolDefinitions, tool } from 'ai';
import { z } from 'zod';

const tools = {
  getWeather: tool({
    description: 'Get the current weather for a city',
    inputSchema: z.object({
      city: z.string(),
    }),
  }),
};

const toolDefinitions = await experimental_getRealtimeToolDefinitions({
  tools,
});

const token = await openai.experimental_realtime.getToken({
  model: 'gpt-realtime',
  sessionConfig: {
    tools: toolDefinitions,
  },
});
```

## 说明

- `experimental_getRealtimeToolDefinitions` 不负责工具执行。请使用
  [`experimental_useRealtime`](/docs/reference/ai-sdk-ui/use-realtime)
  的 `onToolCall` 与 `addToolOutput` 来执行工具并返回结果。
- 提供商工具会被跳过，因为实时提供商期望会话配置中是常规的函数定义。
- 在返回定义之前，动态工具描述会使用 `toolsContext` 中匹配的值进行解析。
