# `embedMany()`

使用嵌入（embedding）模型为多个值生成嵌入。

当模型对单次调用可处理的嵌入数量或 UTF-8 输入字节数有限制时，`embedMany` 会自动将大请求拆分为更小的块。提供商可以使用保守的字节预算，使请求保持在聚合 token 限制以下，而无需在 AI SDK core 包中加入分词器。超过字节预算的单个值会单独发送一次调用，因为拆分它会改变最终得到的嵌入。

```ts
import { embedMany } from 'ai';

const { embeddings } = await embedMany({
  model: 'openai/text-embedding-3-small',
  values: [
    'sunny day at the beach',
    'rainy afternoon in the city',
    'snowy night in the mountains',
  ],
});
```
