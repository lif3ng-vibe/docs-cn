# AI SDK Core

[AI SDK Core](/docs/ai-sdk-core) 是一组函数，让你能够与语言模型及其他 AI 模型交互。
这些函数设计得易用且灵活，让你可以从语言模型和其他 AI 模型生成文本、结构化数据与嵌入（embedding）。
