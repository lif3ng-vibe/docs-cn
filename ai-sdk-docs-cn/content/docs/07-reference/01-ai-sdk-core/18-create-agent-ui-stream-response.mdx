# `createAgentUIStreamResponse`

`createAgentUIStreamResponse` 函数执行一个[智能体（Agent）](/docs/reference/ai-sdk-core/agent)，将其流式输出作为 UI 消息流运行，并返回一个 HTTP [Response](https://developer.mozilla.org/en-US/docs/Web/API/Response) 对象，其响应体就是实时流式传输的 UI 消息输出。它专为交付实时智能体结果的 API 路由设计，例如聊天端点或流式工具调用操作。

## 导入

<Snippet
  text={`import { createAgentUIStreamResponse } from "ai"`}
  prompt={false}
/>

## 用法

```ts
import { ToolLoopAgent, createAgentUIStreamResponse } from 'ai';
__PROVIDER_IMPORT__;

const agent = new ToolLoopAgent({
  model: __MODEL__,
  instructions: 'You are a helpful assistant.',
  tools: { weather: weatherTool, calculator: calculatorTool },
});

export async function POST(request: Request) {
  const { messages } = await request.json();

  return createAgentUIStreamResponse({
    agent,
    uiMessages: messages,
    abortSignal: request.signal, // optional: aborts when the client disconnects
    // experimental_sandbox, // optional: passed through to tool execution
    // ...other UIMessageStreamOptions like sendSources, experimental_transform, etc.
  });
}
```

## 返回值

返回一个 `Promise<Response>`，其 `body` 是来自智能体的流式 UI 消息输出。可将其用作无服务器、Next.js、Express、Hono 或边缘运行时环境中 API/服务器处理函数的返回值。

可使用 `onUIMessageStepEnd` 在每个智能体步骤之后持久化累积的 UI 响应。该回调会在对应的 `finish-step` 分块继续之前被等待完成。请使用幂等写入，并将模型输出、推理内容、工具输入和工具输出作为敏感对话数据加以保护。现有的 `onStepEnd` 回调仍然是底层生成回调，用于获取用量、结束原因和原始步骤细节。

## 示例：Next.js API Route Handler

```ts
import { createAgentUIStreamResponse } from 'ai';
import { MyCustomAgent } from '@/agent/my-custom-agent';

export async function POST(request: Request) {
  const { messages } = await request.json();

  return createAgentUIStreamResponse({
    agent: MyCustomAgent,
    uiMessages: messages,
    // experimental_sandbox, // optional
    sendSources: true, // (optional)
    // headers, status, abortSignal, and other UIMessageStreamOptions also supported
  });
}
```

## 工作原理

- 1. **UI 消息校验**：根据智能体指定的工具和要求，校验传入的 `uiMessages` 数组。
- 2. **模型消息转换**：将校验后的 UI 消息转换为智能体所需的内部模型消息格式。
- 3. **流式输出智能体结果**：调用智能体的 `.stream({ prompt, ... })` 获得分块流（步骤/UI 消息），并透传 `experimental_sandbox` 等选项。
- 4. **创建 HTTP 响应**：将输出流包装为可读的 HTTP `Response` 对象，向客户端流式传输 UI 消息分块。

## 说明

- 你的智能体**必须**实现 `.stream({ prompt, ... })` 并定义 `tools` 属性（即使只是 `{}`），才能与此函数配合使用。
- **仅限服务端**：此 API 只应在后端/服务器端上下文中调用（API 路由、边缘/无服务器/服务器 Route Handler 等）。不可在浏览器中使用。
- 当你的智能体工具在执行期间需要实验性沙箱环境时，请传入 `experimental_sandbox`。
- 还有更多选项（`headers`、`status`、UI 流选项、转换等）可用于高级场景。
- 此功能基于 [ReadableStream](https://developer.mozilla.org/en-US/docs/Web/API/ReadableStream)，因此你的平台/客户端必须支持 HTTP 流式消费。
