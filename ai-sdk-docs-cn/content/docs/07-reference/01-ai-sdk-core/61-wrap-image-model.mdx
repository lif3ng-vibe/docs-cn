# `wrapImageModel()`

`wrapImageModel` 函数提供了一种通过中间件包装图像模型来增强其行为的方式。

```ts
import { generateImage, wrapImageModel } from 'ai';
import { openai } from '@ai-sdk/openai';

const model = wrapImageModel({
  model: openai.image('gpt-image-2.5-sunburst'),
  middleware: yourImageModelMiddleware,
});

const { image } = await generateImage({
  model,
  prompt: 'Santa Claus driving a Cadillac',
});
```

### 返回值

一个应用了中间件的全新 `ImageModelV4` 实例。被包装的模型
默认会保留原始模型的 `supportsFileInputs` 与 `supportsMaskInputs`
能力。中间件可以通过
`overrideSupportsFileInputs` 和 `overrideSupportsMaskInputs` 覆盖它们。从覆盖函数返回
`undefined` 会刻意将该项能力标记为未知。

```ts
const model = wrapImageModel({
  model: originalModel,
  middleware: {
    specificationVersion: 'v4',
    overrideSupportsFileInputs: () => true,
    overrideSupportsMaskInputs: () => false,
  },
});
```
