# `customProvider()`

通过自定义提供商（custom provider），你可以把任意 id 映射到任意模型。
这让你能够设置自定义模型配置、别名等。
自定义提供商还支持回退（fallback）提供商，这对于包装现有提供商并添加额外
功能非常有用。自定义提供商可以暴露语言、嵌入、图像、语音转写、语音、
重排序、视频、文件以及技能能力。

### 示例：自定义模型设置

你可以使用 `customProvider` 创建自定义提供商。

```ts
import { openai } from '@ai-sdk/openai';
import { customProvider } from 'ai';

// custom provider with different model settings:
export const myOpenAI = customProvider({
  languageModels: {
    // replacement model with custom settings:
    'gpt-6-astra': wrapLanguageModel({
      model: openai('gpt-6-astra'),
      middleware: defaultSettingsMiddleware({
        settings: {
          providerOptions: {
            openai: {
              reasoningEffort: 'high',
            },
          },
        },
      }),
    }),
    // alias model with custom settings:
    'gpt-6-astra-reasoning-high': wrapLanguageModel({
      model: openai('gpt-6-astra'),
      middleware: defaultSettingsMiddleware({
        settings: {
          providerOptions: {
            openai: {
              reasoningEffort: 'high',
            },
          },
        },
      }),
    }),
  },
  fallbackProvider: openai,
});
```

## 实验性决策模型

传入 `decisionModels: Record<string, Experimental_DecisionModel>` 可为决策模型
实例或字符串 ID 定义别名。返回的提供商会增加
`decisionModel(alias): Experimental_DecisionModelV4`。字符串别名默认通过
Gateway 解析，或通过显式配置的、带有 `decisionModel` 方法的默认提供商解析。
未知别名会在可用时使用回退提供商的决策工厂；模型失败与不支持的问题不会
触发替换。

当决策能力或模型不可用时，会抛出带 `modelType: 'decisionModel'` 的
`NoSuchModelError`；未知的注册表提供商则抛出
`NoSuchProviderError`。这些能力属于结构上的扩展，不会
被加入稳定的 `ProviderV4` 契约。在未配置默认提供商时，
直接的决策字符串 ID 会默认使用 Gateway。
可运行的用法示例见[决策](/docs/ai-sdk-core/decisions#模型别名与注册表)。
