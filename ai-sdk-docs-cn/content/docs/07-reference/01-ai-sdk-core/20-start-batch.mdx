# `experimental_startBatch()`

<Note type="warning">
  批处理（batch）支持为实验性功能，API 可能在补丁版本中变更。
</Note>

启动一个异步批处理，包含文本或图像生成请求。有关批处理生命周期的完整指南，请参阅
[批处理](/docs/ai-sdk-core/batch)。

```ts
import { experimental_startBatch as startBatch } from 'ai';

const batch = await startBatch({
  requests: [
    {
      id: 'france',
      type: 'text',
      model: 'gpt-5.4-nano',
      prompt: 'What is the capital of France?',
    },
  ],
});
```
