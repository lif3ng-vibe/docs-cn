# `createAgentUIStream`

`createAgentUIStream` 函数执行一个[智能体（Agent）](/docs/reference/ai-sdk-core/agent)，消费一组 UI 消息，并通过异步可迭代对象将智能体的输出作为 UI 消息分块流式输出。这让你能在自己的运行时中实时、增量地渲染 AI 助手输出，同时完全掌控工具调用、中间推理和交互式 UI 功能——非常适合构建由智能体驱动的聊天 API、仪表盘或机器人。

## 导入

<Snippet text={`import { createAgentUIStream } from "ai"`} prompt={false} />

## 用法

```ts
import { ToolLoopAgent, createAgentUIStream } from 'ai';
__PROVIDER_IMPORT__;

const agent = new ToolLoopAgent({
  model: __MODEL__,
  instructions: 'You are a helpful assistant.',
  tools: { weather: weatherTool, calculator: calculatorTool },
});

export async function* streamAgent(
  uiMessages: unknown[],
  abortSignal?: AbortSignal,
) {
  const stream = await createAgentUIStream({
    agent,
    uiMessages,
    abortSignal,
    // experimental_sandbox, // optional: pass an experimental sandbox through to tool execution
    // ...other options (see below)
  });

  for await (const chunk of stream) {
    yield chunk; // Each chunk is a UI message output from the agent.
  }
}
```

## 返回值

返回一个 `Promise<AsyncIterableStream<UIMessageChunk>>`，其中每个产出的分块都是智能体输出的 UI 消息（参见 [`UIMessage`](/docs/reference/ai-sdk-core/ui-message)）。可以用任意异步迭代循环消费，也可以通过管道传给流式 HTTP 响应、socket 或任何其他接收端。

## 示例

```ts
import { createAgentUIStream } from 'ai';

const controller = new AbortController();

const stream = await createAgentUIStream({
  agent,
  uiMessages: [{ role: 'user', content: 'What is the weather in SF today?' }],
  abortSignal: controller.signal,
  // experimental_sandbox, // optional
  sendStart: true,
  // ...other UIMessageStreamOptions
});

for await (const chunk of stream) {
  // Each chunk is a UI message update — stream it to your client, dashboard, logs, etc.
  console.log(chunk);
}

// Call controller.abort() to cancel the agent operation early.
```

## 在每一步之后持久化 UI 消息

当你需要在每个智能体步骤之后获取累积的 [`UIMessage`](/docs/reference/ai-sdk-core/ui-message) 时，可以使用 `onUIMessageStepEnd`：

```ts
const stream = await createAgentUIStream({
  agent,
  uiMessages,
  generateMessageId: () => crypto.randomUUID(),
  onUIMessageStepEnd: async ({ messages, responseMessage, isContinuation }) => {
    await upsertConversation({
      messages,
      responseMessage,
      isContinuation,
    });
  },
  onEnd: async ({ responseMessage }) => {
    // Save final metadata and any partial message when the stream ends.
    await upsertMessage(responseMessage);
  },
});

for await (const chunk of stream) {
  // Consume or forward the stream so the callback can run.
}
```

`onStepEnd` 和 `onUIMessageStepEnd` 作用于不同层级。`onStepEnd` 接收底层生成步骤的结果，包括用量、结束原因和工具调用细节。`onUIMessageStepEnd` 则在该步骤被转换为 UI 消息部分之后运行，并接收目前为止累积的响应消息。

该回调在 UI 流被消费时运行，并会在 `finish-step` 分块继续沿流传递之前被等待完成。这会延迟 UI 流的交付，但并不保证下一次模型调用尚未开始。如果回调抛出异常，错误会传给 `onError`，流式输出继续进行。请使用幂等写入，因为每次回调都包含同一条响应消息的不断增长的快照。UI 消息可能包含模型输出、推理内容、工具输入和工具输出，因此应采用与最终对话持久化相同的访问控制和敏感数据处理措施。

## 工作原理

1. **UI 消息校验**：输入的 `uiMessages` 数组会使用智能体的 `tools` 定义进行校验和规范化。任何无效消息都会导致错误。
2. **转换为模型消息**：校验后的 UI 消息会按智能体的要求转换为特定于模型的消息格式。
3. **智能体流式输出**：以转换后的模型消息调用智能体的 `.stream({ prompt, ... })` 方法，并传入可选的调用选项、中止信号、experimental_sandbox 以及任何实验性转换。
4. **UI 消息流构建**：结果流会被转换并以 UI 消息分块组成的流式异步可迭代对象形式暴露出来，供你消费。

## 说明

- 智能体**必须**实现 `.stream({ prompt, ... })` 方法并定义其支持的 `tools` 属性。
- 该工具返回异步可迭代对象以获得最大的流式灵活性。若需 HTTP 响应，请参阅 [`createAgentUIStreamResponse`](/docs/reference/ai-sdk-core/create-agent-ui-stream-response)（Web）或 [`pipeAgentUIStreamToResponse`](/docs/reference/ai-sdk-core/pipe-agent-ui-stream-to-response)（Node.js）。
- `uiMessages` 参数的名称是 `uiMessages`，而**不是** `messages`。
- 你可以通过 `UIMessageStreamOptions` 提供高级选项（例如包含来源或消息元数据）。
- 每步的 UI 消息持久化请使用 `onUIMessageStepEnd`；底层生成的遥测信息和步骤细节请使用 `onStepEnd`。
- 要取消流，请通过 `abortSignal` 参数传入 [`AbortSignal`](https://developer.mozilla.org/en-US/docs/Web/API/AbortSignal)。
- 当你的智能体工具在执行期间需要实验性沙箱环境时，请传入 `experimental_sandbox`。
