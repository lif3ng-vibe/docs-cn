# `experimental_getBatchResults()`

<Note type="warning">
  批处理（batch）支持为实验性功能，API 可能在补丁版本中变更。
</Note>

以异步可迭代对象的形式返回异步批处理中各请求的终态结果。有关批处理生命周期的完整指南，请参阅
[批处理](/docs/ai-sdk-core/batch)。

```ts
import { anthropic } from '@ai-sdk/anthropic';
import { experimental_getBatchResults as getBatchResults } from 'ai';

for await (const item of getBatchResults({ provider: anthropic, batch })) {
  if (item.status === 'succeeded') {
    console.log(item.id, item.text);
  } else {
    console.error(item.id, item.error);
  }
}
```

### 返回值

返回一个 `AsyncIterableStream<Experimental_BatchItemResult>`，其中包含成功、失败、已取消或已过期请求的结果。该流既可以作为异步可迭代对象消费，也可以作为 `ReadableStream` 消费。

成功的条目包含 `id`、`status: 'succeeded'`、`text`、规范化的 `content`（包括文本、推理、来源、文件、工具调用和工具结果）、
`finishReason`、`usage`，以及可选的响应元数据和提供商元数据。`text` 是各文本部分的拼接结果，当结果不含文本部分时可以是空字符串。
失败、已取消和已过期的条目包含请求 `id`、各自的终态，以及可选的错误详情。
