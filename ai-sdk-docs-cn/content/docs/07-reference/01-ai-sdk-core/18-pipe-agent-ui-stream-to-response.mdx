# `pipeAgentUIStreamToResponse`

`pipeAgentUIStreamToResponse` 函数运行一个[智能体（Agent）](/docs/reference/ai-sdk-core/agent)，并将产生的 UI 消息输出直接流式传输到 Node.js [`ServerResponse`](https://nodejs.org/api/http.html#class-httpserverresponse) 对象。它非常适合在 Express、Hono 或自定义 Node 服务器等基于 Node.js 的框架中构建实时流式 API 端点（用于聊天、工具调用等）。

## 导入

<Snippet
  text={`import { pipeAgentUIStreamToResponse } from "ai"`}
  prompt={false}
/>

## 用法

```ts
import { pipeAgentUIStreamToResponse } from 'ai';
import { MyAgent } from './agent';

export async function handler(req, res) {
  const { messages } = JSON.parse(req.body);

  await pipeAgentUIStreamToResponse({
    response: res, // Node.js ServerResponse
    agent: MyAgent,
    uiMessages: messages, // Required: array of input UI messages
    // abortSignal: optional AbortSignal for cancellation
    // experimental_sandbox: optional experimental sandbox passed through to tool execution
    // status: 200,
    // headers: { ... },
    // ...other optional UI message stream options
  });
}
```

## 返回值

返回一个 `Promise<void>`。当 UI 消息流已完整发送到给定的 ServerResponse 后，该函数即完成。

可使用 `onUIMessageStepEnd` 在每个智能体步骤之后持久化累积的 UI 响应。它会在对应的 `finish-step` 分块被写入管道之前被等待完成。请使用幂等写入，并将模型输出、推理内容、工具输入和工具输出作为敏感对话数据加以保护。若需要底层生成的用量、结束原因或原始步骤细节，请改用现有的 `onStepEnd` 回调。

## 示例：Express Route Handler

```ts
import { pipeAgentUIStreamToResponse } from 'ai';
import { openaiWebSearchAgent } from './openai-web-search-agent';

app.post('/chat', async (req, res) => {
  // Use req.body.messages as input UI messages
  await pipeAgentUIStreamToResponse({
    response: res,
    agent: openaiWebSearchAgent,
    uiMessages: req.body.messages,
    // experimental_sandbox, // optional
    // abortSignal: yourController.signal
    // status: 200,
    // headers: { ... },
    // ...more options
  });
});
```

## 工作原理

1. **运行智能体**：以提供的 UI 消息和选项调用智能体的 `.stream` 方法，按需将其转换为模型消息，并透传 `experimental_sandbox` 等选项。
2. **流式输出 UI 消息**：将智能体输出作为 UI 消息流写入 `ServerResponse` 管道，通过流式 HTTP 响应发送数据（包括相应的请求头）。
3. **中止信号处理**：如果提供了 `abortSignal`，一旦信号触发（例如客户端断开连接），流式输出即被取消。
4. **不返回响应对象**：与返回 `Response` 的 Edge/无服务器 API 不同，此函数直接将字节写入 ServerResponse，不返回响应对象。

## 说明

- **中止处理**：为了最佳健壮性，请使用 `AbortSignal`（例如接入 Express/Hono 的客户端断开事件），以确保快速取消智能体计算和流式输出。
- **仅限 Node.js**：只适用于 Node.js [ServerResponse](https://nodejs.org/api/http.html#class-httpserverresponse) 对象（例如 Express、Hono 的 node 适配器等），不适用于 Edge/无服务器/Web 的 Response API。
- **流式支持**：请确保你的客户端（及所有代理）正确支持流式 HTTP 响应以获得完整效果。
- **参数命名**：为了与 SDK 智能体工具保持一致，输入消息的属性名为 `uiMessages`（而非 `messages`）。
- 当你的智能体工具在执行期间需要实验性沙箱环境时，请传入 `experimental_sandbox`。
