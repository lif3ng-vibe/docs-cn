# `Experimental_SandboxSession`

`Experimental_SandboxSession` 接口描述了一个工具可用来运行命令的执行环境。通过 `experimental_sandbox` 选项将实验性沙箱传递给 `generateText`、`streamText`、`ToolLoopAgent.generate`、`ToolLoopAgent.stream` 或智能体 UI 流辅助函数，即可让它在工具描述函数与工具执行中可用。

<Note type="warning">
  该 API 是实验性的，可能在补丁版本中发生变化。传入实验性沙箱并不会把工具本身
  沙箱化。除非工具显式地将工作委托给实验性沙箱，否则工具代码仍运行在你的应用
  进程中。
</Note>

## 类型定义

```ts
type Experimental_SandboxSession = {
  readonly description: string;
  readonly run: (options: {
    command: string;
    workingDirectory?: string;
    env?: Record<string, string>;
    abortSignal?: AbortSignal;
  }) => PromiseLike<{
    exitCode: number;
    stdout: string;
    stderr: string;
  }>;
};
```

## 示例

```ts
const result = await generateText({
  model: __MODEL__,
  tools: { shell },
  experimental_sandbox,
  prompt: 'Run the test suite.',
});
```

在工具内部，从 `execute` 的第二个参数读取实验性沙箱：

```ts
const shell = tool({
  inputSchema: z.object({
    command: z.string(),
    workingDirectory: z.string().optional(),
  }),
  execute: async (
    { command, workingDirectory },
    { abortSignal, experimental_sandbox },
  ) => {
    if (!experimental_sandbox) {
      throw new Error('Experimental sandbox is not available');
    }

    return experimental_sandbox.run({
      command,
      workingDirectory,
      abortSignal,
    });
  },
});
```
