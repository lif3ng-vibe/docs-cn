# `experimental_listBatches()`

<Note type="warning">
  批处理（batch）支持为实验性功能，API 可能会在补丁版本中变更。
</Note>

列出异步批次（batch）的一页内容及其最新的规范化状态。批处理生命周期的完整指南请参阅 [Batch](/docs/ai-sdk-core/batch)。

```ts
import { experimental_listBatches as listBatches } from 'ai';

const page = await listBatches({
  provider,
  limit: 20,
  cursor,
});

console.log(page.batches, page.nextCursor);
```
