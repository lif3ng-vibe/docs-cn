# `experimental_cancelBatch()`

<Note type="warning">
  批处理（batch）支持为实验性功能，API 可能在补丁版本中变更。
</Note>

请求取消一个异步批处理。调用成功只表示提供商接受了取消请求，并不代表取消已完成。有关批处理生命周期的完整指南，请参阅
[批处理](/docs/ai-sdk-core/batch)。

```ts
import { experimental_cancelBatch as cancelBatch } from 'ai';

const result = await cancelBatch({
  provider,
  batch,
});

console.log(result.providerMetadata);
```
