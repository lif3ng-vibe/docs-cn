# `generateVideo()`

在工作流中以持久化方式生成视频。该辅助函数会使用 Workflow webhook URL 启动一个异步视频生成任务，挂起工作流直到提供商发送终结通知，然后通过一次状态请求获取已完成的结果。

与 `ai` 包中的 [`experimental_generateVideo`](/docs/reference/ai-sdk-core/generate-video) 不同，该辅助函数不会下载由提供商托管的视频。URL 结果保持为 URL，你的工作流可以自行决定在另一步骤中持久化、复制或处理它们，而无需让视频字节跨越工作流步骤边界进行序列化。

```ts
import { experimental_generateVideo as generateVideo } from '@ai-sdk/workflow/video';

export async function videoWorkflow(prompt: string) {
  'use workflow';

  // The workflow suspends while the video renders, consuming no compute.
  const result = await generateVideo({
    model: 'klingai/kling-v3.0-t2v',
    prompt,
  });

  return result.videos;
}
```

所选模型必须支持异步启动与状态查询操作以及提供商 webhook。该辅助函数必须在 Workflow SDK 工作流中调用。

## 返回值

返回来自提供商的已完成状态结果。`videos` 包含按 `type` 区分的原始提供商视频数据：

- `url`：提供商托管的 URL 与媒体类型
- `base64`：Base64 编码的视频数据与媒体类型
- `binary`：一个 `Uint8Array` 与媒体类型

托管 URL 可能会过期。如需保留某个视频，请在单独的工作流步骤中处理它。
