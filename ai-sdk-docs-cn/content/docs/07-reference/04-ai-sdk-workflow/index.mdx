# AI SDK Workflow

[`@ai-sdk/workflow`](/docs/agents/workflow-agent) 提供 `WorkflowAgent` 类，用于构建在工作流中运行的持久化、可恢复的智能体（agent）。它负责工具 schema 序列化、工作流步骤边界以及内置的工具审批流程。
