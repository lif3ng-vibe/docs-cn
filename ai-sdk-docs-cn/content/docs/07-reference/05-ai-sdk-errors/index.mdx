# AI SDK Errors

AI SDK 暴露了类型化的错误（typed errors），让应用无需匹配错误消息字符串即可处理预期的失败模式。

## 导入错误

应用包的名称是 `ai`，而不是 `@ai-sdk/ai`。它从 `@ai-sdk/provider` 重新导出了常见的提供商级错误，以及 AI SDK Core 抛出的更高层错误：

```typescript
import { APICallError, NoObjectGeneratedError } from 'ai';
```

直接依赖 `@ai-sdk/provider` 的提供商实现，可以改为从该包导入其提供商级错误：

```typescript
import { APICallError, InvalidResponseDataError } from '@ai-sdk/provider';
```

## 迁移到类型化错误处理

用可用的最具体的静态 `isInstance` 守卫，替换基于消息匹配或无条件宽泛的 `catch` 块。当你需要针对任意 AI SDK 错误的回退（fallback）时，最后再检查 `AISDKError`：

```typescript
import { AISDKError, APICallError, generateText } from 'ai';

try {
  await generateText({
    model,
    prompt: 'Write a vegetarian lasagna recipe for 4 people.',
  });
} catch (error) {
  if (APICallError.isInstance(error)) {
    console.error('Provider request failed:', error.statusCode);
    return;
  }

  if (AISDKError.isInstance(error)) {
    console.error('AI SDK error:', error.name);
    return;
  }

  throw error;
}
```

当错误类提供了 `ErrorClass.isInstance(error)` 时，优先使用它而不是 `error instanceof ErrorClass`。静态守卫在同时加载了多个 AI SDK 包版本时也能正常工作。

## 常见失败模式

| 失败模式 | 应检查的错误 |
| --- | --- |
| 提供商请求因网络错误或非成功响应而失败 | [`APICallError`](/docs/reference/ai-sdk-errors/ai-api-call-error) |
| 自动重试次数耗尽 | [`RetryError`](/docs/reference/ai-sdk-errors/ai-retry-error) |
| 响应流开始之后提供商报告错误 | [`StreamProviderError`](/docs/reference/ai-sdk-errors/ai-stream-provider-error) |
| 结构化输出无法解析或校验 | [`NoObjectGeneratedError`](/docs/reference/ai-sdk-errors/ai-no-object-generated-error)；可检查其 `cause` 是否为 [`JSONParseError`](/docs/reference/ai-sdk-errors/ai-json-parse-error) 或 [`TypeValidationError`](/docs/reference/ai-sdk-errors/ai-type-validation-error) |
| 生成调用未返回可用输出 | [`NoOutputGeneratedError`](/docs/reference/ai-sdk-errors/ai-no-output-generated-error) 或特定模态的 `No*GeneratedError` |
| 模型调用了不存在的工具，或提供了无效的工具输入 | [`NoSuchToolError`](/docs/reference/ai-sdk-errors/ai-no-such-tool-error) 或 [`InvalidToolInputError`](/docs/reference/ai-sdk-errors/ai-invalid-tool-input-error) |
| 工具调用修复失败 | [`ToolCallRepairError`](/docs/reference/ai-sdk-errors/ai-tool-call-repair-error) |
| 响应违反了强制的 `toolChoice` | [`ToolChoiceViolationError`](/docs/reference/ai-sdk-errors/ai-tool-choice-violation-error) |
| 消息历史中包含未解析的工具调用或无效的批准 | [`MissingToolResultsError`](/docs/troubleshooting/missing-tool-results-error)、[`InvalidToolApprovalError`](/docs/reference/ai-sdk-errors/ai-invalid-tool-approval-error) 或 [`InvalidToolApprovalSignatureError`](/docs/reference/ai-sdk-errors/ai-invalid-tool-approval-signature-error) |
| 提供商或模型无法解析 | [`NoSuchProviderError`](/docs/reference/ai-sdk-errors/ai-no-such-provider-error)、[`NoSuchModelError`](/docs/reference/ai-sdk-errors/ai-no-such-model-error) 或 [`NoSuchProviderReferenceError`](/docs/reference/ai-sdk-errors/ai-no-such-provider-reference-error) |
| 提供商响应为空、格式错误或无效 | [`EmptyResponseBodyError`](/docs/reference/ai-sdk-errors/ai-empty-response-body-error)、[`JSONParseError`](/docs/reference/ai-sdk-errors/ai-json-parse-error) 或 [`InvalidResponseDataError`](/docs/reference/ai-sdk-errors/ai-invalid-response-data-error) |
| 所请求的模型或提供商不支持某项能力或规范版本 | [`UnsupportedFunctionalityError`](/docs/reference/ai-sdk-errors/ai-unsupported-functionality-error) 或 [`UnsupportedModelVersionError`](/docs/troubleshooting/unsupported-model-version) |
| UI 消息无法转换，或 UI 消息流无效 | [`MessageConversionError`](/docs/reference/ai-sdk-errors/ai-message-conversion-error) 或 [`UIMessageStreamError`](/docs/reference/ai-sdk-errors/ai-ui-message-stream-error) |
