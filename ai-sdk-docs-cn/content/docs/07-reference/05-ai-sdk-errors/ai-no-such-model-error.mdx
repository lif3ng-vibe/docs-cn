# AI_NoSuchModelError

此错误在找不到指定模型 ID 时发生。

## 属性

- `modelId`：未找到的模型 ID
- `modelType`：模型类型（`'languageModel'`、`'embeddingModel'`、`'imageModel'`、`'transcriptionModel'`、`'speechModel'` 或 `'rerankingModel'`）
- `message`：错误消息（可选，由 `modelId` 和 `modelType` 自动生成）

## 排查此错误

你可以使用以下方式检查某个错误是否为 `AI_NoSuchModelError` 的实例：

```typescript
import { NoSuchModelError } from 'ai';

if (NoSuchModelError.isInstance(error)) {
  // Handle the error
}
```

实验性的决策解析使用 `modelType: 'decisionModel'`。它涵盖不可用的决策能力，
以及未知的决策模型或提供商 ID。参见 [Decisions](/docs/ai-sdk-core/decisions#默认提供商字符串)。
