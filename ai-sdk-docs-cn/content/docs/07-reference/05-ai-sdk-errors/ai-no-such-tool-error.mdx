# AI_NoSuchToolError

此错误在模型尝试调用一个不可用的工具时发生。

## 属性

- `toolName`：未找到的工具名称
- `availableTools`：可用工具名称数组（可选）
- `message`：错误消息（可选，由 `toolName` 和 `availableTools` 自动生成）

## 排查此错误

你可以使用以下方式检查某个错误是否为 `AI_NoSuchToolError` 的实例：

```typescript
import { NoSuchToolError } from 'ai';

if (NoSuchToolError.isInstance(error)) {
  // Handle the error
}
```
