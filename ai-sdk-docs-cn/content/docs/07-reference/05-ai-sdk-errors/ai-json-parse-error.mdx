# AI_JSONParseError

当 JSON 解析失败时会引发此错误。

## 属性

- `text`：无法解析的文本值
- `cause`：底层的解析错误（在构造函数中必填）

## 排查此错误

你可以使用以下方式检查错误是否为 `AI_JSONParseError` 的实例：

```typescript
import { JSONParseError } from 'ai';

if (JSONParseError.isInstance(error)) {
  // Handle the error
}
```
