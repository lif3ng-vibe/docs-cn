# `streamUI`

<Note type="warning">
  AI SDK RSC 目前为实验性功能。我们建议在生产环境中使用 [AI SDK UI](/docs/ai-sdk-ui/overview)。有关从 RSC 迁移到 UI 的指引，请参阅我们的[迁移指南](/docs/ai-sdk-rsc/migrating-to-ui)。
</Note>

一个从 LLM 提供商创建可流式 UI 的辅助函数。此函数与 AI SDK Core API 类似，并支持相同的模型接口。

要查看 `streamUI` 的实际效果，请查看[这些示例](#示例)。

## 导入

<Snippet text={`import { streamUI } from "@ai-sdk/rsc"`} prompt={false} />
