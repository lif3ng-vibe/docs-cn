# `useActions`

<Note type="warning">
  AI SDK RSC 目前处于实验性阶段。我们建议在生产环境中使用 [AI SDK
  UI](/docs/ai-sdk-ui/overview)。有关从 RSC 迁移到 UI 的指导，请参阅[迁移指南](/docs/ai-sdk-rsc/migrating-to-ui)。
</Note>

它是一个 Hook，帮助你在客户端访问 Server Action。这对于构建需要用户与服务器交互的界面尤其有用。

必须通过此 Hook 访问这些 Server Action，因为它们在经过上下文传递时会被修补。直接访问它们可能导致 [Cannot find Client Component 错误](/docs/troubleshooting/server-actions-in-client-components)。

## 导入

<Snippet text={`import { useActions } from "@ai-sdk/rsc"`} prompt={false} />

## API 签名

### 返回值

`Record<string, Action>`，即 Server Action 的字典。
