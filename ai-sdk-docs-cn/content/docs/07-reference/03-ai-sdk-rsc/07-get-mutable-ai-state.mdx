# `getMutableAIState`

<Note type="warning">
  AI SDK RSC 目前处于实验性阶段。我们建议在生产环境中使用 [AI SDK
  UI](/docs/ai-sdk-ui/overview)。有关从 RSC 迁移到 UI 的指导，请参阅[迁移指南](/docs/ai-sdk-rsc/migrating-to-ui)。
</Note>

获取 AI 状态的可变副本。可以用它在服务器端更新状态。

## 导入

<Snippet
  text={`import { getMutableAIState } from "@ai-sdk/rsc"`}
  prompt={false}
/>
