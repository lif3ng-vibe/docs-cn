# Vercel Deployment Guide

在本指南中，你将使用 [Next.js](https://nextjs.org)（App Router）把一个 AI 应用部署到 [Vercel](https://vercel.com)。

Vercel 是一个面向开发者的平台，提供更快构建和部署 Web 应用所需的工具、工作流和基础设施，无需额外配置。

Vercel 支持在你每次推送分支以及向 GitHub、GitLab 和 Bitbucket 项目的生产分支合并时自动部署。它是部署 AI 应用的绝佳选择。

## 开始之前

要跟随本指南操作，你需要：

- 一个 Vercel 账号
- 一个 Git 提供商的账号（本教程将使用 [GitHub](https://github.com)）
- 一个 OpenAI API 密钥

本指南将教你如何把你在 Next.js（App Router）快速上手教程中构建的应用部署到 Vercel。如果你尚未完成快速上手指南，可以从[这个仓库](https://github.com/vercel-labs/ai-sdk-deployment-guide)开始。

## 提交变更

Vercel 提供强大的以 Git 为中心的工作流，每当你推送到仓库的 main 分支时，它都会自动把你的应用部署到生产环境。

在提交本地变更之前，请确保你有 `.gitignore` 文件，并且其中排除了环境变量（`.env`）和 node 模块（`node_modules`）。

如果你有任何本地变更，可以通过运行以下命令来提交：

```bash
git add .
git commit -m "init"
```

## 创建 Git 仓库

你可以在终端中或 [github.com](https://github.com/) 上创建 GitHub 仓库。在本教程中，你将使用 GitHub CLI（[更多信息](https://cli.github.com/)）。

创建你的 GitHub 仓库：

1. 访问 [github.com](https://github.com/)
2. 点击右上角的"加号"图标，选择"New repository"
3. 为你的仓库取一个名字（可以是任意名称）
4. 点击"Create repository"

创建仓库后，GitHub 会将你重定向到新仓库。

1. 向下滚动页面，复制"...or push an existing repository from the command line"标题下的命令
2. 回到终端，粘贴并运行这些命令

注意：如果你遇到 "error: remote origin already exists." 这个报错，说明你的本地仓库仍然链接到你之前克隆的仓库。要"解除链接"，可以运行以下命令：

```bash
rm -rf .git
git init
git add .
git commit -m "init"
```

然后重新运行上一步的代码片段。

## 在 Vercel 中导入项目

在 [New Project](https://vercel.com/new) 页面的 **Import Git Repository** 区域，选择你要从中导入项目的 Git 提供商，然后按照提示登录你的 GitHub 账号。

登录后，你应该能在"Import Git Repository"区域看到上一步新建的仓库。点击该项目旁边的"Import"按钮。

### 添加环境变量

你的应用在开发环境中使用 `.env.local` 文件以环境密钥的形式存储 OpenAI API 密钥。要把这个 API 密钥添加到生产部署中，请展开"Environment Variables"区域并粘贴你的 `.env.local` 文件。Vercel 会自动解析你的变量，并以合适的 `key:value` 格式录入。

### 部署

点击 **Deploy** 按钮。Vercel 将根据所选配置创建项目并部署。

### 尽情享受彩带吧！

要查看你的部署，在仪表板中选择该项目，然后选择 **Domain**。现在任何拥有该 URL 的人都可以访问这个页面。

## 注意事项

部署 AI 应用时，有一些与基础设施相关的注意事项需要了解。

### 函数时长

大多数情况下，你会在服务器上调用大语言模型（LLM）。默认情况下，Vercel 无服务器函数在 Hobby 套餐下的最长执行时长为 10 秒。根据提示词的不同，LLM 完成响应可能需要超过这个限制的时间。如果响应未在此限制内完成，服务器将抛出错误。

你可以使用 [route segment config](https://nextjs.org/docs/app/api-reference/file-conventions/route-segment-config) 来指定 Vercel 函数的最长执行时长。要更新最长时长，请将以下 route segment config 添加到 Route Handler 或调用 Server Action 的页面顶部。

```ts
export const maxDuration = 30;
```

在 Hobby 套餐下你可以将最长时长提高到 60 秒。其他套餐的限制请[参阅文档](https://vercel.com/docs/functions/runtimes#max-duration)。

### 请求取消

`useChat` 和 `useCompletion` 等 AI SDK UI 辅助函数在你调用 `stop()` 时会中止客户端请求。要把这个取消操作传播到 Vercel Function 及其模型请求，你必须：

1. 使用 Node.js 运行时（Next.js Route Handler 的默认运行时）。
2. 在 `vercel.json` 中为该路由启用 [`supportsCancellation`](https://vercel.com/docs/functions/functions-api-reference#cancel-requests)。
3. 将路由的 `req.signal` 作为 `abortSignal` 传给 `streamText` 或 `generateText`。

例如，为你的聊天路由启用取消功能：

```json filename="vercel.json"
{
  "functions": {
    "app/api/chat/route.ts": {
      "supportsCancellation": true
    }
  }
}
```

然后将请求信号转发给 AI SDK：

```ts filename="app/api/chat/route.ts" highlight="10"
import { convertToModelMessages, streamText, type UIMessage } from 'ai';
__PROVIDER_IMPORT__;

export async function POST(req: Request) {
  const { messages }: { messages: UIMessage[] } = await req.json();

  const result = streamText({
    model: __MODEL__,
    messages: convertToModelMessages(messages),
    abortSignal: req.signal,
  });

  return result.toUIMessageStreamResponse();
}
```

如果没有 `supportsCancellation`，调用 `stop()` 只会关闭客户端的流，但不会取消 Vercel Function 或模型请求。完整的客户端与服务器配置请参阅[停止流式传输](/docs/advanced/stopping-streams)。

## 安全注意事项

鉴于调用 LLM 的高昂成本，必须采取适当措施保护你的应用免受滥用。

### 速率限制

速率限制是一种调控网络流量的方法，它为客户端在给定时间段内可向服务器发送的请求数量设定上限。

按照[这份指南](https://vercel.com/guides/securing-ai-app-rate-limiting)为你的应用添加速率限制。

### 防火墙

防火墙帮助保护你的应用和网站免受 DDoS 攻击和未经授权的访问。

[Vercel Firewall](https://vercel.com/docs/security/vercel-firewall) 是一套专为安全而设计的工具与基础设施。它会自动缓解 DDoS 攻击，Enterprise 团队还可以为其站点获得更进一步的定制，包括专属支持和自定义 IP 屏蔽规则。
