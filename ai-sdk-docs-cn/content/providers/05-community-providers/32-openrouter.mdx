# OpenRouter

[OpenRouter](https://openrouter.ai/) 是一个统一的 API 网关，提供对来自 Anthropic、Google、Meta、Mistral 等领先提供商的数百个 AI 模型的访问。适用于 AI SDK 的 OpenRouter 提供商可以与所有这些模型无缝集成，同时具备独特优势：

- **通用模型访问**：一个 API key 即可使用来自多个提供商的数百个模型
- **成本高效**：按量付费，无月费或承诺消费
- **价格透明**：所有模型都有清晰的按 token 计价
- **高可用性**：企业级基础设施，支持自动故障转移
- **集成简单**：所有模型使用统一的标准化 API
- **最新模型**：新模型发布后立即可用

在 [OpenRouter 文档](https://openrouter.ai/docs)中了解更多 OpenRouter 的能力。

## 安装

OpenRouter 提供商包含在 `@openrouter/ai-sdk-provider` 模块中，你可以通过以下方式安装：

<InstallPackages packages="@openrouter/ai-sdk-provider" />

## 提供商实例

使用 `createOpenRouter` 函数创建 OpenRouter 提供商实例：

```typescript
import { createOpenRouter } from '@openrouter/ai-sdk-provider';

const openrouter = createOpenRouter({
  apiKey: 'YOUR_OPENROUTER_API_KEY',
});
```

你可以在 [OpenRouter 控制台](https://openrouter.ai/keys)获取你的 OpenRouter API key。

## 语言模型

OpenRouter 同时支持聊天模型与补全（completion）模型。聊天模型使用 `openrouter.chat()`，补全模型使用 `openrouter.completion()`：

```typescript
// Chat models (recommended)
const chatModel = openrouter.chat('anthropic/claude-3.5-sonnet');

// Completion models
const completionModel = openrouter.completion(
  'meta-llama/llama-3.1-405b-instruct',
);
```

完整可用模型列表请参阅 [OpenRouter 模型文档](https://openrouter.ai/docs#models)。

## 示例

以下是在 AI SDK 中使用 OpenRouter 的示例：

### `generateText`

```javascript
import { createOpenRouter } from '@openrouter/ai-sdk-provider';
import { generateText } from 'ai';

const openrouter = createOpenRouter({
  apiKey: 'YOUR_OPENROUTER_API_KEY',
});

const { text } = await generateText({
  model: openrouter.chat('anthropic/claude-3.5-sonnet'),
  prompt: 'What is OpenRouter?',
});

console.log(text);
```

### `streamText`

```javascript
import { createOpenRouter } from '@openrouter/ai-sdk-provider';
import { streamText } from 'ai';

const openrouter = createOpenRouter({
  apiKey: 'YOUR_OPENROUTER_API_KEY',
});

const result = streamText({
  model: openrouter.chat('meta-llama/llama-3.1-405b-instruct'),
  prompt: 'Write a short story about AI.',
});

for await (const chunk of result.textStream) {
  console.log(chunk);
}
```

## 高级功能

OpenRouter 提供多项高级功能，以增强你的 AI 应用：

1. **模型灵活性**：在数百个模型之间切换，无需更改代码或管理多个 API key。

2. **成本管理**：通过控制台实时跟踪每个模型的用量与成本。

3. **企业支持**：面向大流量用户提供自定义 SLA 与专属支持。

4. **跨提供商兼容**：在不同模型提供商之间使用相同的代码结构。

5. **定期更新**：新模型与新功能上线即可自动使用。

有关这些功能与高级配置选项的更多信息，请访问 [OpenRouter 文档](https://openrouter.ai/docs)。
