# Automatic1111

[AUTOMATIC1111](https://github.com/AUTOMATIC1111/stable-diffusion-webui) 是一个流行的 Stable Diffusion Web 界面，为图像生成提供了一整套丰富的功能。AI SDK 的 [Automatic1111 提供商](https://github.com/Ponesicek/automatic1111-provider)可以与本地部署的 AUTOMATIC1111 实例无缝集成，并具备以下独特优势：

- **本地掌控**：使用本地 Stable Diffusion 模型，完全掌控图像生成过程
- **零 API 费用**：无单次请求计费，可无限量生成图像
- **模型灵活**：可使用任意 Stable Diffusion checkpoint
- **隐私保障**：所有生成过程都在你自己的硬件上本地完成
- **社区模型**：可使用来自 Civitai 和 HuggingFace 的数千个社区创作模型

更多 AUTOMATIC1111 的功能介绍，请参阅 [AUTOMATIC1111 文档](https://github.com/AUTOMATIC1111/stable-diffusion-webui)。

## 安装

你需要以启用 `--api` 标志的方式运行 AUTOMATIC1111。使用以下命令启动你的 AUTOMATIC1111 实例：

```bash
# Windows
./webui.bat --api

# Linux/Mac
./webui.sh --api
```

Automatic1111 提供商包含在 `automatic1111-provider` 模块中，可通过以下方式安装：

```bash
# pnpm
pnpm add automatic1111-provider

# npm
npm install automatic1111-provider

# yarn
yarn add automatic1111-provider
```

## 提供商实例

使用 `createAutomatic1111` 函数创建 Automatic1111 提供商实例：

```typescript
import { createAutomatic1111 } from 'automatic1111-provider';

const automatic1111 = createAutomatic1111({
  baseURL: 'http://127.0.0.1:7860', // Your AUTOMATIC1111 instance
});
```

## 图像模型

Automatic1111 提供商通过 `image()` 方法支持图像生成：

```typescript
// Basic image generation
const imageModel = automatic1111.image('v1-5-pruned-emaonly');

// With custom model
const sdxlModel = automatic1111.image('sd_xl_base_1.0');
```

## 示例

### 基本图像生成

```typescript
import { automatic1111 } from 'automatic1111-provider';
import { generateImage } from 'ai';

const { images } = await generateImage({
  model: automatic1111.image('v1-5-pruned-emaonly'),
  prompt: 'A beautiful sunset over mountains',
  size: '512x512',
});
```

### 高级配置

```typescript
const { images } = await generateImage({
  model: automatic1111.image('realistic-vision-v4'),
  prompt: 'Portrait of a wise old wizard with a long beard',
  n: 2,
  seed: 12345,
  providerOptions: {
    automatic1111: {
      negative_prompt: 'blurry, ugly, deformed, low quality',
      steps: 40,
      cfg_scale: 8.5,
      sampler_name: 'DPM++ SDE Karras',
      styles: ['photorealistic', 'detailed'],
      check_model_exists: true,
    },
  },
});
```

## 提供商选项

Automatic1111 提供商支持以下选项，用于自定义图像生成：

### 可用选项

| 选项                 | 类型       | 默认值      | 说明                                     |
| -------------------- | ---------- | ----------- | ---------------------------------------- |
| `negative_prompt`    | `string`   | `undefined` | 图像中不希望出现的内容                   |
| `steps`              | `number`   | `20`        | 采样步数                                 |
| `cfg_scale`          | `number`   | `7`         | CFG（Classifier Free Guidance）系数      |
| `sampler_name`       | `string`   | `"Euler a"` | 采样方法                                 |
| `denoising_strength` | `number`   | `undefined` | 图生图（img2img）的去噪强度（0.0-1.0）   |
| `styles`             | `string[]` | `undefined` | 应用预定义风格                           |
| `check_model_exists` | `boolean`  | `false`     | 生成前校验模型是否存在                   |

## 模型管理

该提供商会自动检测你的 AUTOMATIC1111 实例中可用的模型。要使用某个模型：

1. 将你的 `.safetensors` 或 `.ckpt` 模型文件放入 `models/Stable-diffusion/` 文件夹
2. 重启 AUTOMATIC1111，或在 Web 界面中刷新模型列表
3. 在提供商中使用确切的模型名称（不带文件扩展名）
