# Nia

[Nia](https://www.trynia.ai/) 由 Nozomio Labs 开发，是一个提供技术性、最新上下文的 API。它支持为文档、代码仓库、PDF 和数据集建立索引，再用 AI 进行搜索，让你的智能体（agent）得到真实答案而非幻觉。[`@nozomioai/nia-ai-sdk`](https://www.npmjs.com/package/@nozomioai/nia-ai-sdk) 包通过工具、中间件和直接流式辅助函数将 Nia 集成到 AI SDK 中。

它适用于以下工作流：

- 将 Nia Tracer 作为工具调用，用于公开 GitHub 与文档研究
- 将 Nia Oracle 作为工具调用，针对已索引的代码仓库、文档、PDF 和数据集进行有据可依的研究
- 将 Nia Document Agent 作为工具调用，进行深度文档分析与结构化提取
- 使用基于 Nia 的中间件增强现有的 AI SDK 模型
- 在应用中直接以流式接收 Tracer、Oracle 或 Document Agent 事件

更多信息请参阅 [Nia 文档](https://docs.trynia.ai/)。

## 设置

Nia 适配器包含在 `@nozomioai/nia-ai-sdk` 包中，安装方式如下：

<InstallPackages packages="@nozomioai/nia-ai-sdk" />

如果你想将 Nia 中间件与某个模型提供商搭配使用，还需安装该提供商的包。例如：

```bash
pnpm add @ai-sdk/openai
```

设置你的 Nia API 密钥：

```bash
export NIA_API_KEY=nia_your_api_key
```

你可以在 [Nia 控制台](https://www.trynia.ai/)获取 API 密钥。

## 工具用法

Nia 很适合作为一组 AI SDK 工具使用，直接传给 `generateText` 或 `streamText` 即可。

### `generateText`

```ts
import { generateText } from 'ai';
import { openai } from '@ai-sdk/openai';
import { createNiaResearchTools } from '@nozomioai/nia-ai-sdk';

const tools = createNiaResearchTools({
  apiKey: process.env.NIA_API_KEY!,
  tracer: {
    defaultRequest: {
      mode: 'tracer-deep',
    },
  },
  oracle: {
    defaultRequest: {
      repositories: ['vercel/ai'],
      dataSources: ['Vercel AI SDK'],
    },
  },
  documentAgent: {
    defaultRequest: {
      sourceId: 'src_abc123',
    },
  },
});

const result = await generateText({
  model: openai('gpt-4.1'),
  prompt:
    'Research how AI SDK middleware works, then summarize the best integration pattern.',
  tools,
});

console.log(result.text);
```

你可以将任意服务键设为 `false` 来完全禁用它，例如只需要 Tracer 时设置 `oracle: false`。当提供了针对单个服务的传输选项（如单独的 `apiKey`）时，它们会覆盖顶层选项。

该 SDK 还导出了 `createTracerTool()`、`createOracleTool()` 和 `createDocumentAgentTool()`，适用于只需要单个工具的场景。

## 中间件用法

当你希望 Nia 在基础模型运行前丰富最后一条用户消息时，可以使用中间件。

### `withOracleContext`

```ts
import { generateText } from 'ai';
import { openai } from '@ai-sdk/openai';
import { withOracleContext } from '@nozomioai/nia-ai-sdk';

const model = withOracleContext(openai('gpt-4.1'), {
  apiKey: process.env.NIA_API_KEY!,
  defaultRequest: {
    repositories: ['vercel/ai'],
    dataSources: ['Vercel AI SDK'],
  },
});

const result = await generateText({
  model,
  prompt: 'How should I think about AI SDK middleware for retrieval?',
});

console.log(result.text);
```

你可以用同样的方式使用 `withTracerContext()` 进行公开 GitHub 研究，处理已索引的 PDF 或文档时则可使用 `withDocumentAgentContext()`。

如需更细粒度的控制，可以使用更底层的 `createTracerMiddleware()`、`createOracleMiddleware()` 和 `createDocumentAgentMiddleware()` 导出，它们返回原始的 `LanguageModelMiddleware` 对象，可自行组合。

## 直接流式辅助函数

如果你需要原始的 Nia 任务事件，可以使用直接流式辅助函数：

- `streamTracer()`
- `streamOracle()`
- `streamOracleSessionChat()`
- `streamDocumentAgent()`

```ts
import { streamTracer } from '@nozomioai/nia-ai-sdk';

const session = await streamTracer(
  {
    apiKey: process.env.NIA_API_KEY!,
  },
  {
    query: 'How does generateText stream responses?',
    repositories: ['vercel/ai'],
    mode: 'tracer-fast',
  },
);

for await (const event of session.events) {
  console.log(event.event, event.data);
}
```
