# Letta 提供商

[Letta AI SDK 提供商](https://github.com/letta-ai/vercel-ai-sdk-provider) 让你可以在 AI SDK 中使用 Letta 智能体（agent）。

特性包括：

- 持久化与长期记忆
- 访问智能体级与模型级的推理消息，并带来源标注
- 支持自定义的智能体配置工具与 MCP（Model Context Protocol）
- 由智能体管理的文件系统操作，通过工具进行文件访问
- 内置 Letta 与 AI SDK 消息格式互转工具
- [Letta Send Message API 的所有特性](https://docs.letta.com/api-reference/agents/messages/create-stream)，例如[长时间运行的智能体执行](https://docs.letta.com/guides/agents/long-running)

## 支持的模型

支持的模型完整列表请查看 [Letta 文档](https://docs.letta.com/connecting-model-providers/supported-models)。对于列表中没有的模型，你可以尝试将 Letta 配置为使用 [OpenAI 代理](https://docs.letta.com/guides/server/providers/openai-proxy)。

## 安装

可通过以下方式安装 Letta 提供商：

<InstallPackages packages="@letta-ai/vercel-ai-sdk-provider" />

## 提供商实例

你可以从 `@letta-ai/vercel-ai-sdk-provider` 导入提供商实例 `lettaCloud` 或 `lettaLocal`：

```ts
// For cloud users
import { lettaCloud } from '@letta-ai/vercel-ai-sdk-provider';

// For self-hosted users
import { lettaLocal } from '@letta-ai/vercel-ai-sdk-provider';

// Create a custom Letta provider
import { createLetta } from '@letta-ai/vercel-ai-sdk-provider';

const letta = createLetta({
  baseUrl: '<your-base-url>',
  token: '<your-access-token>',
});
```

## 基本用法

在 [Letta 仪表盘](https://app.letta.com/api-keys)获取你的 API key。

```bash
# .env
LETTA_API_KEY=your-letta-api-key
```

```typescript
import { lettaCloud } from '@letta-ai/vercel-ai-sdk-provider';
import { generateText } from 'ai';

const result = await generateText({
  model: lettaCloud(), // Model configuration (LLM, temperature, etc.) is managed through your Letta agent
  providerOptions: {
    letta: {
      agent: { id: 'your-agent-id' },
    },
  },
  prompt: 'Write a vegetarian lasagna recipe for 4 people.',
});

console.log(result.text);
```

## 高级用法

### 提供商选项

你可以通过 `providerOptions.letta` 参数配置 Letta 特有的设置：

```typescript
import { lettaCloud } from '@letta-ai/vercel-ai-sdk-provider';
import { streamText } from 'ai';

const result = streamText({
  model: lettaCloud(),
  providerOptions: {
    letta: {
      agent: {
        id: 'your-agent-id',
        maxSteps: 100,
        includePings: true,
        streamTokens: true,
      },
      timeoutInSeconds: 300,
    },
  },
  prompt: 'Tell me a story about a robot learning to paint',
});
```

#### 智能体配置

配置消息创建时智能体特有的参数。这些设置对流式与非流式操作均生效。

可用选项：

- `id`（`string`，必填）：你的 Letta 智能体 ID
- `maxSteps`（`number`）：智能体执行的最大步数
- `includePings`（`boolean`）：是否在流中包含 ping 消息
- `streamTokens`（`boolean`）：启用逐 token 流式输出
- `background`（`boolean`）：为长时间运行的操作启用后台执行
- 更多参数请查看 [Letta API 文档](https://docs.letta.com/api-reference/agents/messages/create-stream)

#### 超时配置

**类型**：`number`

**默认值**：`1000`

设置智能体响应的最大等待时间（秒）。对于长时间运行的智能体操作或复杂推理链，这个设置非常重要。

```typescript
const result = streamText({
  model: lettaCloud(),
  providerOptions: {
    letta: {
      agent: { id: 'your-agent-id' },
      timeoutInSeconds: 300, // Wait up to 5 minutes
    },
  },
  prompt: 'Process this complex task...',
});
```

## 自定义工具与 MCP

Letta 智能体通过提供商执行的工具支持自定义工具与 MCP（Model Context Protocol）服务器。在 [Letta 智能体上完成配置](https://docs.letta.com/guides/agents/custom-tools)后，你可以使用 `letta.tool()` 将它们包含在请求中，工具执行由 Letta 处理。

```typescript
import { streamText } from 'ai';
import { z } from 'zod';
import { lettaCloud } from '@letta-ai/vercel-ai-sdk-provider';

// Use with streaming
const result = streamText({
  model: lettaCloud(),
  tools: {
    web_search: lettaCloud.tool('web_search'),
    memory_insert: lettaCloud.tool('memory_insert'),
    memory_replace: lettaCloud.tool('memory_replace'),
    core_memory_append: lettaCloud.tool('core_memory_append'),
    my_custom_tool: lettaCloud.tool('my_custom_tool'),
    // Optionally provide description and schema (placeholders only - execution handled by Letta)
    typed_query: lettaCloud.tool('typed_query', {
      description: 'Query with typed parameters',
      inputSchema: z.object({
        query: z.string(),
      }),
    }),
  },
  providerOptions: {
    letta: {
      agent: { id: agentId },
    },
  },
  prompt: 'Tell me a story about a robot learning to paint',
});
```

## 使用其他 Letta 客户端函数

`vercel-ai-sdk-provider` 扩展自 [@letta-ai/letta-client](https://www.npmjs.com/package/@letta-ai/letta-client)，你可以通过 `lettaCloud.client`、`lettaLocal.client` 或自定义生成的 `letta.client` 直接访问这些操作

```ts
// with Letta Cloud
import { lettaCloud } from '@letta-ai/vercel-ai-sdk-provider';

lettaCloud.client.agents.list();

// with Letta Local
import { lettaLocal } from '@letta-ai/vercel-ai-sdk-provider';

lettaLocal.client.agents.list();
```
