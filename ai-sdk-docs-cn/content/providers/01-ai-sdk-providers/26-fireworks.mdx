# Fireworks 提供商

[Fireworks](https://fireworks.ai/) 是一个通过其 [API](https://readme.fireworks.ai/) 运行和测试 LLM 的平台。

## 安装

Fireworks 提供商包含在 `@ai-sdk/fireworks` 模块中，可以通过以下方式安装：

<InstallPackages packages="@ai-sdk/fireworks" />

## 提供商实例

你可以从 `@ai-sdk/fireworks` 导入默认提供商实例 `fireworks`：

```ts
import { fireworks } from '@ai-sdk/fireworks';
```

如果需要自定义配置，可以从 `@ai-sdk/fireworks` 导入 `createFireworks`，
并使用你的设置创建提供商实例：

```ts
import { createFireworks } from '@ai-sdk/fireworks';

const fireworks = createFireworks({
  apiKey: process.env.FIREWORKS_API_KEY ?? '',
});
```

你可以使用以下可选设置来定制 Fireworks 提供商实例：

- **baseURL** _string_

  为 API 调用使用不同的 URL 前缀，例如使用代理服务器。
  默认前缀为 `https://api.fireworks.ai/inference/v1`。

- **apiKey** _string_

  通过 `Authorization` 请求头发送的 API 密钥。默认取
  `FIREWORKS_API_KEY` 环境变量。

- **headers** _Record&lt;string,string&gt;_

  请求中包含的自定义请求头。

- **fetch** _(input: RequestInfo, init?: RequestInit) => Promise&lt;Response&gt;_

  自定义 [fetch](https://developer.mozilla.org/en-US/docs/Web/API/fetch) 实现。

## 语言模型

你可以使用提供商实例创建 [Fireworks 模型](https://fireworks.ai/models)。
第一个参数是模型 ID，例如 `accounts/fireworks/models/firefunction-v1`：

```ts
const model = fireworks('accounts/fireworks/models/firefunction-v1');
```

### 推理模型

对于支持推理力度（reasoning effort）的模型，请使用顶层 `reasoning` 参数。
Fireworks 会将 `'minimal'` 映射为 `'low'`，将 `'xhigh'` 或 `'max'` 映射为 `'high'`，
并在进行转换时返回兼容性警告。流式调用会在 `stream-start` 事件中包含该警告。
显式指定的 `providerOptions.fireworks.reasoningEffort` 优先于顶层设置。

Fireworks 使用 `<think>` 标签在生成的文本中暴露 `deepseek-r1` 的思考内容。
你可以使用 `extractReasoningMiddleware` 提取这些推理内容，并将其作为结果上的 `reasoning` 属性暴露出来：

```ts
import { fireworks } from '@ai-sdk/fireworks';
import { wrapLanguageModel, extractReasoningMiddleware } from 'ai';

const enhancedModel = wrapLanguageModel({
  model: fireworks('accounts/fireworks/models/deepseek-r1'),
  middleware: extractReasoningMiddleware({ tagName: 'think' }),
});
```

然后你就可以在 `generateText` 和 `streamText` 等函数中使用这个增强后的模型。

### 示例

你可以使用 `generateText` 函数配合 Fireworks 语言模型来生成文本：

```ts
import { fireworks } from '@ai-sdk/fireworks';
import { generateText } from 'ai';

const { text } = await generateText({
  model: fireworks('accounts/fireworks/models/firefunction-v1'),
  prompt: 'Write a vegetarian lasagna recipe for 4 people.',
});
```

Fireworks 语言模型也可以用于 `streamText` 函数
（参见 [AI SDK Core](/docs/ai-sdk-core)）。

### 提供商选项

Fireworks 聊天模型支持一些不属于
[标准调用设置](/docs/ai-sdk-core/settings)的额外提供商选项。你可以在 `providerOptions` 参数中传入它们：

```ts
import {
  fireworks,
  type FireworksLanguageModelOptions,
} from '@ai-sdk/fireworks';
import { generateText } from 'ai';

const { text, reasoningText } = await generateText({
  model: fireworks('accounts/fireworks/models/kimi-k2p6'),
  providerOptions: {
    fireworks: {
      thinking: { type: 'enabled', budgetTokens: 4096 },
      reasoningHistory: 'interleaved',
    } satisfies FireworksLanguageModelOptions,
  },
  prompt: 'How many "r"s are in the word "strawberry"?',
});
```

Fireworks 聊天模型支持以下可选提供商选项：

- **promptCacheKey** _string_

  一个稳定且不透明的键（key），通过将共享提示词前缀的请求路由到同一个
  Fireworks 副本来提高提示词缓存命中率。同一次对话中的所有步骤和调用应复用
  同一个键，不相关的对话则使用不同的键。

- **serviceTier** _'priority'_

  在高峰流量期间使用 Fireworks Priority 服务路径以获得更高的可靠性。
  提供商将其作为 Fireworks 的 `service_tier` 请求字段发送。

- **thinking** _object_

  针对 Kimi K2.6 等思考/推理模型的配置。
  - **type** _'enabled' | 'disabled'_

    是否启用思考模式。

  - **budgetTokens** _number_

    思考的最大 token 数（最小值为 1024）。

- **reasoningHistory** _'disabled' | 'interleaved' | 'preserved'_

  控制多轮对话中推理历史的处理方式：
  - `'disabled'`：从历史中移除推理内容
  - `'interleaved'`：在单个回合内的工具调用之间保留推理内容
  - `'preserved'`：在历史中保留全部推理内容

### 提示词缓存亲和性

[Fireworks 提示词缓存](https://docs.fireworks.ai/guides/prompt-caching)
是自动的，但缓存的前缀仅对单个副本（replica）本地有效。将
`promptCacheKey` 设置为一个不透明的会话或对话标识符，可以提高
缓存亲和性。提供商会将其作为 Fireworks 的
[`prompt_cache_key`](https://docs.fireworks.ai/api-reference/post-chatcompletions)
请求字段发送。

AI SDK 会在多步 `generateText` 或 `streamText` 调用中为每个模型步骤
复用相同的提供商选项，因此一个键即可覆盖完整的工具循环：

```ts
import {
  fireworks,
  type FireworksLanguageModelOptions,
} from '@ai-sdk/fireworks';
import { generateText, isStepCount, tool } from 'ai';
import { z } from 'zod';

const sessionId = 'conversation-123';

const result = await generateText({
  model: fireworks('accounts/fireworks/models/kimi-k2p6'),
  providerOptions: {
    fireworks: {
      promptCacheKey: sessionId,
    } satisfies FireworksLanguageModelOptions,
  },
  tools: {
    weather: tool({
      description: 'Get the weather for a city.',
      inputSchema: z.object({ city: z.string() }),
      execute: async ({ city }) => `It is sunny in ${city}.`,
    }),
  },
  stopWhen: isStepCount(5),
  prompt: 'What is the weather in San Francisco?',
});

console.log(result.usage.inputTokenDetails.cacheReadTokens);
```

对于可复用的 `ToolLoopAgent`，可以使用调用选项（call options）为每次对话提供一个键。
后续继续该对话的智能体调用请再次传入相同的键：

```ts
import {
  fireworks,
  type FireworksLanguageModelOptions,
} from '@ai-sdk/fireworks';
import { ToolLoopAgent } from 'ai';
import { z } from 'zod';
import { weatherTool } from './weather-tool';

const agent = new ToolLoopAgent({
  model: fireworks('accounts/fireworks/models/kimi-k2p6'),
  callOptionsSchema: z.object({
    sessionId: z.string(),
  }),
  prepareCall: ({ options, ...settings }) => ({
    ...settings,
    providerOptions: {
      fireworks: {
        promptCacheKey: options.sessionId,
      } satisfies FireworksLanguageModelOptions,
    },
  }),
  tools: { weather: weatherTool },
});

const result = await agent.generate({
  prompt: 'What is the weather in San Francisco?',
  options: {
    sessionId: 'conversation-123',
  },
});
```

缓存键请使用非身份识别性的值，而不要使用电子邮件地址或其他个人信息。

### Priority 服务层级

[Fireworks Priority 层级](https://docs.fireworks.ai/serverless/serving-paths)
会优先于 Standard 流量处理受支持的模型。将 `serviceTier` 设置为
`'priority'` 即可发送 Fireworks 的 `service_tier` 请求字段：

```ts
import {
  fireworks,
  type FireworksLanguageModelOptions,
} from '@ai-sdk/fireworks';
import { generateText } from 'ai';

const result = await generateText({
  model: fireworks('accounts/fireworks/models/glm-5p2'),
  providerOptions: {
    fireworks: {
      serviceTier: 'priority',
    } satisfies FireworksLanguageModelOptions,
  },
  prompt: 'Write a haiku about reliable inference.',
});
```

## 嵌入模型

你可以使用 `.embeddingModel()` 工厂方法创建调用 Fireworks 嵌入 API 的模型：

```ts
const model = fireworks.embeddingModel('nomic-ai/nomic-embed-text-v1.5');
```

你可以使用 `embed` 函数配合 Fireworks 嵌入模型来生成嵌入（embedding）：

```ts
import { fireworks } from '@ai-sdk/fireworks';
import { embed } from 'ai';

const { embedding } = await embed({
  model: fireworks.embeddingModel('nomic-ai/nomic-embed-text-v1.5'),
  value: 'sunny day at the beach',
});
```

### 模型能力

| 模型                             | 维度       | 最大 token 数 |
| -------------------------------- | ---------- | ------------- |
| `nomic-ai/nomic-embed-text-v1.5` | 768        | 8192          |

<Note>
  更多嵌入模型请参见 [Fireworks 模型
  页面](https://fireworks.ai/models)查看完整的可用模型列表。
</Note>

## 图像模型

你可以使用 `.image()` 工厂方法创建 Fireworks 图像模型。
有关使用 AI SDK 进行图像生成的更多信息，请参见 [generateImage()](/docs/reference/ai-sdk-core/generate-image)。

```ts
import { fireworks, type FireworksImageModelOptions } from '@ai-sdk/fireworks';
import { generateImage } from 'ai';

const { image } = await generateImage({
  model: fireworks.image('accounts/fireworks/models/flux-1-dev-fp8'),
  prompt: 'A futuristic cityscape at sunset',
  aspectRatio: '16:9',
  providerOptions: {
    fireworks: {
      guidance_scale: 4.5,
      num_inference_steps: 8,
    } satisfies FireworksImageModelOptions,
  },
});
```

<Note>
  各模型对 `size` 和 `aspectRatio` 参数的支持情况不一。支持的尺寸请参见下方
  [模型能力](#模型能力-1)部分，或查看 [Fireworks 模型
  页面](https://fireworks.ai/models)上该模型的文档了解更多细节。
</Note>

### 提供商选项

Fireworks 图像模型通过 `providerOptions.fireworks` 对象支持灵活的提供商选项。使用 `FireworksImageModelOptions` 类型可以校验已知的 Fireworks 图像选项，同时仍允许模型特定的选项透传。

以下是可用的带类型的提供商选项：

- **guidance_scale** _number_

  图像扩散过程的免分类器引导（classifier-free guidance）强度。

- **num_inference_steps** _number_

  FLUX 工作流图像生成的去噪步数。

- **output_format** _'jpeg' | 'png'_

  FLUX Kontext 图像生成与编辑所需的输出格式。

- **prompt_upsampling** _boolean_

  是否让 Fireworks 自动修改提示词以获得更具创意的生成结果。

- **safety_tolerance** _number_

  输入与输出的内容审核容忍度，取值范围为 `0` 到 `6`。Fireworks 将图生图请求限制为 `2`。

- **webhook_url** _string_

  接收异步 Kontext 请求 webhook 通知的 URL。

- **webhook_secret** _string_

  用于 webhook 签名验证的密钥。

- **cfg_scale** _number_

  旧版 `image_generation` 模型的引导强度。

- **steps** _number_

  旧版 `image_generation` 模型的生成步数。

### 图像编辑

Fireworks 通过 FLUX Kontext 模型（`flux-kontext-pro` 和 `flux-kontext-max`）支持图像编辑。通过 `prompt.images` 传入输入图像，即可对现有图像进行变换或编辑。

<Note>
  Fireworks Kontext 模型不支持显式遮罩（mask）。编辑由
  提示词驱动——请在文本提示词中描述你想要修改的内容。
</Note>

#### 基本图像编辑

使用文本提示词变换现有图像：

```ts
const imageBuffer = readFileSync('./input-image.png');

const { images } = await generateImage({
  model: fireworks.image('accounts/fireworks/models/flux-kontext-pro'),
  prompt: {
    text: 'Turn the cat into a golden retriever dog',
    images: [imageBuffer],
  },
  providerOptions: {
    fireworks: {
      output_format: 'jpeg',
      safety_tolerance: 2,
    } satisfies FireworksImageModelOptions,
  },
});
```

#### 风格迁移

为图像应用艺术风格：

```ts
const imageBuffer = readFileSync('./input-image.png');

const { images } = await generateImage({
  model: fireworks.image('accounts/fireworks/models/flux-kontext-pro'),
  prompt: {
    text: 'Transform this into a watercolor painting style',
    images: [imageBuffer],
  },
  aspectRatio: '1:1',
});
```

<Note>
  输入图像可以是 `Buffer`、`ArrayBuffer`、`Uint8Array` 或
  base64 编码的字符串。Fireworks 每个请求仅支持单张输入图像。
</Note>
