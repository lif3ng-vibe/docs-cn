# DeepInfra 提供商

[DeepInfra](https://deepinfra.com) 提供商通过 DeepInfra API 提供对最先进模型的支持，包括 Llama 3、Mixtral、Qwen 以及许多其他热门开源模型。

## 安装

DeepInfra 提供商可通过 `@ai-sdk/deepinfra` 模块获取，可以通过以下方式安装：

<InstallPackages packages="@ai-sdk/deepinfra" />

## 提供商实例

你可以从 `@ai-sdk/deepinfra` 导入默认提供商实例 `deepInfra`：

```ts
import { deepInfra } from '@ai-sdk/deepinfra';
```

如果需要自定义配置，可以从 `@ai-sdk/deepinfra` 导入 `createDeepInfra`，并用你的设置创建提供商实例：

```ts
import { createDeepInfra } from '@ai-sdk/deepinfra';

const deepInfra = createDeepInfra({
  apiKey: process.env.DEEPINFRA_API_KEY ?? '',
});
```

你可以使用以下可选设置来自定义 DeepInfra 提供商实例：

- **baseURL** _string_

  为 API 调用使用不同的 URL 前缀，例如使用代理服务器。默认前缀为 `https://api.deepinfra.com/v1`。

  注意：语言模型和嵌入使用 `{baseURL}/openai` 下的 OpenAI 兼容端点，而图像模型使用 `{baseURL}/inference`。

- **apiKey** _string_

  通过 `Authorization` 请求头发送的 API 密钥。默认取 `DEEPINFRA_API_KEY` 环境变量。

- **headers** _Record&lt;string,string&gt;_

  请求中包含的自定义请求头。

- **fetch** _(input: RequestInfo, init?: RequestInit) => Promise&lt;Response&gt;_

  自定义 [fetch](https://developer.mozilla.org/en-US/docs/Web/API/fetch) 实现。默认使用全局 `fetch` 函数。可以把它当作中间件拦截请求，或用于测试等场景提供自定义 fetch 实现。

## 语言模型

你可以使用提供商实例创建语言模型。第一个参数是模型 ID，例如：

```ts
import { deepInfra } from '@ai-sdk/deepinfra';
import { generateText } from 'ai';

const { text } = await generateText({
  model: deepInfra('meta-llama/Meta-Llama-3.1-70B-Instruct'),
  prompt: 'Write a vegetarian lasagna recipe for 4 people.',
});
```

DeepInfra 语言模型也可以在 `streamText` 函数中使用（参见 [AI SDK Core](/docs/ai-sdk-core)）。

## 图像模型

你可以使用 `.image()` 工厂方法创建 DeepInfra 图像模型。有关使用 AI SDK 进行图像生成的更多信息，参见 [generateImage()](/docs/reference/ai-sdk-core/generate-image)。

```ts
import { deepInfra, type DeepInfraImageModelOptions } from '@ai-sdk/deepinfra';
import { generateImage } from 'ai';

const { image } = await generateImage({
  model: deepInfra.image('stabilityai/sd3.5'),
  prompt: 'A futuristic cityscape at sunset',
  aspectRatio: '16:9',
});
```

<Note>
  不同模型对 `size` 和 `aspectRatio` 参数的支持情况各不相同。支持的选项与附加参数请查看 [DeepInfra 模型页](https://deepinfra.com/models/text-to-image) 上各模型自己的文档。
</Note>

### 模型特有选项

你可以使用 `providerOptions.deepinfra` 字段传入模型特有的参数：

```ts
import { deepInfra } from '@ai-sdk/deepinfra';
import { generateImage } from 'ai';

const { image } = await generateImage({
  model: deepInfra.image('stabilityai/sd3.5'),
  prompt: 'A futuristic cityscape at sunset',
  aspectRatio: '16:9',
  providerOptions: {
    deepinfra: {
      num_inference_steps: 30,
    } satisfies DeepInfraImageModelOptions,
  },
});
```

以下选项可通过 `providerOptions.deepinfra` 使用。你可以用 `DeepInfraImageModelOptions` 为它们标注类型。

- **negative_prompt** _string_

  描述生成图像中应避免出现的内容的文本。

- **num_inference_steps** _number_

  对暴露此选项的模型，指定去噪步数。

- **guidance_scale** _number_

  对暴露此选项的模型，指定引导系数（guidance scale）。

- **guidance** _number_

  对暴露此选项的图像编辑模型，指定引导值。

- **response_format** _'b64_json'_

  OpenAI 兼容图像响应的格式。DeepInfra 目前支持 `b64_json`。

- **quality** _string_

  OpenAI 兼容的图像质量选项。

- **style** _string_

  OpenAI 兼容的图像风格选项。

- **user** _string_

  你的最终用户的唯一标识符。

<Note>
  DeepInfra 图像生成模型会暴露模型特有的参数。额外的字段可以通过 `providerOptions.deepinfra` 传入，并由 DeepInfra 校验。
</Note>

### 图像编辑

DeepInfra 通过 `Qwen/Qwen-Image-Edit` 等模型支持图像编辑。通过 `prompt.images` 传入输入图像，即可对现有图像进行变换或编辑。

#### 基本图像编辑

使用文本提示词变换现有图像：

```ts
const imageBuffer = readFileSync('./input-image.png');

const { images } = await generateImage({
  model: deepInfra.image('Qwen/Qwen-Image-Edit'),
  prompt: {
    text: 'Turn the cat into a golden retriever dog',
    images: [imageBuffer],
  },
  size: '1024x1024',
});
```

#### 使用蒙版进行局部重绘（inpainting）

使用蒙版编辑图像的特定部分。蒙版中的透明区域指示图像应被编辑的位置：

```ts
const image = readFileSync('./input-image.png');
const mask = readFileSync('./mask.png');

const { images } = await generateImage({
  model: deepInfra.image('Qwen/Qwen-Image-Edit'),
  prompt: {
    text: 'A sunlit indoor lounge area with a pool containing a flamingo',
    images: [image],
    mask: mask,
  },
});
```

#### 多图合成

将多张参考图像合成到单一输出中：

```ts
const cat = readFileSync('./cat.png');
const dog = readFileSync('./dog.png');

const { images } = await generateImage({
  model: deepInfra.image('Qwen/Qwen-Image-Edit'),
  prompt: {
    text: 'Create a scene with both animals together, playing as friends',
    images: [cat, dog],
  },
});
```

<Note>
  输入图像可以以 `Buffer`、`ArrayBuffer`、`Uint8Array` 或 base64 编码字符串的形式提供。DeepInfra 使用位于 `https://api.deepinfra.com/v1/openai/images/edits` 的 OpenAI 兼容图像编辑 API。
</Note>

### 模型能力

对于支持宽高比的模型，通常支持以下比例：
`1:1 (default), 16:9, 1:9, 3:2, 2:3, 4:5, 5:4, 9:16, 9:21`

对于支持 size 参数的模型，尺寸通常必须满足：

- 为 32 的倍数
- 宽和高在 256 到 1440 像素之间
- 默认尺寸为 1024x1024

## 嵌入模型

你可以使用 `.embeddingModel()` 工厂方法创建 DeepInfra 嵌入模型。有关 AI SDK 嵌入模型的更多信息，参见 [embed()](/docs/reference/ai-sdk-core/embed)。

```ts
import { deepInfra } from '@ai-sdk/deepinfra';
import { embed } from 'ai';

const { embedding } = await embed({
  model: deepInfra.embeddingModel('BAAI/bge-large-en-v1.5'),
  value: 'sunny day at the beach',
});
```
