# Google Vertex 提供商

[AI SDK](/docs) 的 Google Vertex 提供商为 [Google Vertex AI](https://cloud.google.com/vertex-ai) API 提供语言模型支持，包括 [Google 的 Gemini 模型](https://cloud.google.com/vertex-ai/generative-ai/docs/learn/models)、[Anthropic 的 Claude 合作伙伴模型](https://cloud.google.com/vertex-ai/generative-ai/docs/partner-models/use-claude)、[xAI 的 Grok 合作伙伴模型](https://cloud.google.com/vertex-ai/generative-ai/docs/partner-models/grok)，以及 [MaaS（Model as a Service）开放模型](https://cloud.google.com/vertex-ai/generative-ai/docs/maas/use-open-models)。

<Note>
  Google Vertex 提供商同时兼容 Node.js 与 Edge 运行时。Edge 运行时通过
  `@ai-sdk/google-vertex/edge` 子模块提供支持。更多细节请参见下方的
  [Google Vertex Edge 运行时](#google-vertex-edge-runtime)、
  [Google Vertex Anthropic Edge 运行时](#google-vertex-anthropic-edge-runtime)
  和 [Google Vertex MaaS Edge 运行时](#google-vertex-maas-edge-runtime)章节。
</Note>

## 安装

Google Vertex、Google Vertex Anthropic、Google Vertex xAI 和 Google Vertex MaaS 提供商都包含在 `@ai-sdk/google-vertex` 模块中。你可以使用以下命令安装：

<InstallPackages packages="@ai-sdk/google-vertex" />

## Google Vertex 提供商用法

Google Vertex 提供商实例用于创建调用 Vertex AI API 的模型实例。该提供商提供的模型包括 [Google 的 Gemini 模型](https://cloud.google.com/vertex-ai/generative-ai/docs/learn/models)。如果你想使用 [Anthropic 的 Claude 模型](https://cloud.google.com/vertex-ai/generative-ai/docs/partner-models/use-claude)，请参见下方的 [Google Vertex Anthropic 提供商](#google-vertex-anthropic-提供商用法)章节。

<Note>
  Vertex Gemini 模型沿用 Google 提供商的前向兼容模型分类。无法识别的
  `gemini-*` ID 和 `-latest` 别名会使用最新的受支持 Gemini 请求行为，而已知
  的旧版 ID 则保留其代际专属的工具、推理、函数响应和思考签名处理方式。
  所选的 Vertex 模型仍须支持每个所请求的特性。
</Note>

### 提供商实例

你可以从 `@ai-sdk/google-vertex` 导入默认的提供商实例 `googleVertex`：

```ts
import { googleVertex } from '@ai-sdk/google-vertex';
```

如果需要自定义配置，可以从 `@ai-sdk/google-vertex` 导入 `createGoogleVertex`，并使用你的设置创建提供商实例：

```ts
import { createGoogleVertex } from '@ai-sdk/google-vertex';

const googleVertex = createGoogleVertex({
  project: 'my-project', // optional
  location: 'us-central1', // optional
});
```

Google Vertex 根据你的运行时环境和需求支持多种身份验证方式。

#### Node.js 运行时

Node.js 运行时是 AI SDK 默认支持的运行时。它通过 [`google-auth-library`](https://github.com/googleapis/google-auth-library-nodejs?tab=readme-ov-file#ways-to-authenticate) 支持所有标准的 Google Cloud 身份验证选项。典型用法是将 json 凭据文件的路径设置到 `GOOGLE_APPLICATION_CREDENTIALS` 环境变量中。凭据文件可以从 [Google Cloud Console](https://console.cloud.google.com/apis/credentials) 获取。

如果你想自定义 Google 身份验证选项，可以将它们作为选项传给 `createGoogleVertex` 函数，例如：

```ts
import { createGoogleVertex } from '@ai-sdk/google-vertex';

const googleVertex = createGoogleVertex({
  googleAuthOptions: {
    credentials: {
      client_email: 'my-email',
      private_key: 'my-private-key',
    },
  },
});
```

##### 可选提供商设置

你可以使用以下可选设置来自定义提供商实例：

- **project** _string_

  用于 API 调用的 Google Cloud 项目 ID。
  默认使用 `GOOGLE_VERTEX_PROJECT` 环境变量。

- **location** _string_

  用于 API 调用的 Google Cloud 位置（location），例如 `us-central1`。
  默认使用 `GOOGLE_VERTEX_LOCATION` 环境变量。

- **googleAuthOptions** _object_

  可选。[Google Auth Library](https://github.com/googleapis/google-auth-library-nodejs/) 使用的身份验证选项。另见 [GoogleAuthOptions](https://github.com/googleapis/google-auth-library-nodejs/blob/08978822e1b7b5961f0e355df51d738e012be392/src/auth/googleauth.ts#L87C18-L87C35) 接口。
  - **authClient** _object_
    要使用的 `AuthClient`。

  - **keyFilename** _string_
    .json、.pem 或 .p12 密钥文件的路径。

  - **keyFile** _string_
    .json、.pem 或 .p12 密钥文件的路径。

  - **credentials** _object_
    包含 client_email 与 private_key 属性的对象，或外部账号客户端选项。

  - **clientOptions** _object_
    传给客户端构造函数的选项对象。

  - **scopes** _string | string[]_
    目标 API 请求所需的授权范围（scope）。

  - **projectId** _string_
    你的项目 ID。

  - **universeDomain** _string_
    指定 Cloud 宇宙（universe）的默认服务域名。

- **headers** _Resolvable&lt;Record&lt;string, string | undefined&gt;&gt;_

  要包含在请求中的请求头。可以多种格式提供：
  - 请求头键值对的记录：`Record<string, string | undefined>`
  - 返回请求头的函数：`() => Record<string, string | undefined>`
  - 返回请求头的异步函数：`async () => Record<string, string | undefined>`
  - 解析为请求头的 Promise：`Promise<Record<string, string | undefined>>`

- **fetch** _(input: RequestInfo, init?: RequestInit) => Promise&lt;Response&gt;_

  自定义 [fetch](https://developer.mozilla.org/en-US/docs/Web/API/fetch) 实现。
  默认使用全局 `fetch` 函数。
  你可以将其用作拦截请求的中间件，
  或在测试等场景中提供自定义 fetch 实现。

- **baseURL** _string_

  可选。Google Vertex API 调用的基础 URL，例如使用代理服务器时。默认根据 location 和 project 构造：
  `https://${location}-aiplatform.googleapis.com/v1/projects/${project}/locations/${location}/publishers/google`

- **toolResultDownloads** _object_

  在将工具结果中的远程文件以内联数据形式发送给 Vertex 之前进行下载的设置。
  对 Gemini 3 及更高版本的模型，受支持的 Google Cloud Storage URL 会被直接转发。
  支持的 MIME 类型请参见[工具结果文件](#工具结果文件)。
  - **maxBytes** _number_

    每个下载文件的最大字节数。默认 7 MiB。

#### Edge 运行时

Edge 运行时（如 Cloudflare Workers）是更靠近网络边缘、离用户更近的轻量级 JavaScript 环境。它们只提供标准 Node.js API 的一个子集。
例如，无法直接访问文件系统，而且许多 Node.js 专有库
（包括标准 Google Auth 库）都不兼容。

Google Vertex 提供商的 Edge 运行时版本通过环境变量支持 Google 的[应用默认凭据（Application Default Credentials）](https://github.com/googleapis/google-auth-library-nodejs?tab=readme-ov-file#application-default-credentials)。这些值可以从 [Google Cloud Console](https://console.cloud.google.com/apis/credentials) 的 json 凭据文件中获取。

你可以从 `@ai-sdk/google-vertex/edge` 导入默认的提供商实例 `googleVertex`：

```ts
import { googleVertex } from '@ai-sdk/google-vertex/edge';
```

<Note>
  `/edge` 子模块已包含在 `@ai-sdk/google-vertex` 包中，因此无需单独安装。
  你必须从 `@ai-sdk/google-vertex/edge` 导入，以区别于 Node.js 提供商。
</Note>

如果需要自定义配置，可以从 `@ai-sdk/google-vertex/edge` 导入 `createGoogleVertex`，并使用你的设置创建提供商实例：

```ts
import { createGoogleVertex } from '@ai-sdk/google-vertex/edge';

const googleVertex = createGoogleVertex({
  project: 'my-project', // optional
  location: 'us-central1', // optional
});
```

对于 Edge 运行时身份验证，你需要用 Google Default Application Credentials JSON 文件中的这些值设置以下环境变量：

- `GOOGLE_CLIENT_EMAIL`
- `GOOGLE_PRIVATE_KEY`
- `GOOGLE_PRIVATE_KEY_ID`（可选）

这些值可以从 [Google Cloud Console](https://console.cloud.google.com/apis/credentials) 的服务账号 JSON 文件中获取。

##### 可选提供商设置

你可以使用以下可选设置来自定义提供商实例：

- **project** _string_

  用于 API 调用的 Google Cloud 项目 ID。
  默认使用 `GOOGLE_VERTEX_PROJECT` 环境变量。

- **location** _string_

  用于 API 调用的 Google Cloud 位置（location），例如 `us-central1`。
  默认使用 `GOOGLE_VERTEX_LOCATION` 环境变量。

- **googleCredentials** _object_

  可选。Edge 提供商用于身份验证的凭据。这些凭据通常通过环境变量设置，来源于服务账号 JSON 文件。
  - **clientEmail** _string_
    服务账号 JSON 文件中的客户端邮箱。默认取 `GOOGLE_CLIENT_EMAIL` 环境变量的内容。

  - **privateKey** _string_
    服务账号 JSON 文件中的私钥。默认取 `GOOGLE_PRIVATE_KEY` 环境变量的内容。

  - **privateKeyId** _string_
    服务账号 JSON 文件中的私钥 ID（可选）。默认取 `GOOGLE_PRIVATE_KEY_ID` 环境变量的内容。

- **headers** _Resolvable&lt;Record&lt;string, string | undefined&gt;&gt;_

  要包含在请求中的请求头。可以多种格式提供：
  - 请求头键值对的记录：`Record<string, string | undefined>`
  - 返回请求头的函数：`() => Record<string, string | undefined>`
  - 返回请求头的异步函数：`async () => Record<string, string | undefined>`
  - 解析为请求头的 Promise：`Promise<Record<string, string | undefined>>`

- **fetch** _(input: RequestInfo, init?: RequestInit) => Promise&lt;Response&gt;_

  自定义 [fetch](https://developer.mozilla.org/en-US/docs/Web/API/fetch) 实现。
  默认使用全局 `fetch` 函数。
  你可以将其用作拦截请求的中间件，
  或在测试等场景中提供自定义 fetch 实现。

#### Express 模式

Express 模式提供一种简化的身份验证方式，使用 API 密钥代替 OAuth 或服务账号凭据。使用 express 模式时，不需要 `project` 和 `location` 设置。

```ts
import { createGoogleVertex } from '@ai-sdk/google-vertex';

const googleVertex = createGoogleVertex({
  apiKey: process.env.GOOGLE_VERTEX_API_KEY,
});
```

##### 可选提供商设置

- **apiKey** _string_

  Google Vertex AI 的 API 密钥。提供后，提供商将使用带 API 密钥验证的 express 模式代替 OAuth。
  默认使用 `GOOGLE_VERTEX_API_KEY` 环境变量。

### 语言模型

你可以使用提供商实例创建调用 Vertex API 的模型。
第一个参数是模型 ID，例如 `gemini-3.8-flash`。

```ts
const model = googleVertex('gemini-3.8-flash');
```

<Note>
  如果你使用的是[自己的模型](https://cloud.google.com/vertex-ai/docs/training-overview)，
  模型名称需要以 `projects/` 开头。
</Note>

Google Vertex 模型还支持一些不属于[标准调用设置](/docs/ai-sdk-core/settings)的模型专属设置。你可以将它们作为选项参数传入：

```ts
import { googleVertex } from '@ai-sdk/google-vertex';
import { type GoogleLanguageModelOptions } from '@ai-sdk/google';

const model = googleVertex('gemini-3.1-pro-preview');

await generateText({
  model,
  providerOptions: {
    vertex: {
      safetySettings: [
        {
          category: 'HARM_CATEGORY_UNSPECIFIED',
          threshold: 'BLOCK_LOW_AND_ABOVE',
        },
      ],
    } satisfies GoogleLanguageModelOptions,
  },
});
```

Google Vertex 模型支持以下可选提供商选项：

- **cachedContent** _string_

  可选。用作预测上下文的缓存内容名称。
  格式：projects/\{project\}/locations/\{location\}/cachedContents/\{cachedContent\}

- **structuredOutputs** _boolean_

  可选。启用结构化输出。默认为 true。

  当 JSON Schema 包含 Google Vertex 所用 OpenAPI schema 版本不支持的元素时，
  该选项很有用。如有需要，你可以用它禁用结构化输出。

  更多细节请参见[故障排查：Schema 限制](#schema-限制)。

- **safetySettings** _Array\<\{ category: string; threshold: string \}\>_

  可选。模型的安全设置。
  - **category** _string_

    安全设置的类别。可以是以下之一：
    - `HARM_CATEGORY_UNSPECIFIED`
    - `HARM_CATEGORY_HATE_SPEECH`
    - `HARM_CATEGORY_DANGEROUS_CONTENT`
    - `HARM_CATEGORY_HARASSMENT`
    - `HARM_CATEGORY_SEXUALLY_EXPLICIT`
    - `HARM_CATEGORY_CIVIC_INTEGRITY`

  - **threshold** _string_

    安全设置的阈值。可以是以下之一：
    - `HARM_BLOCK_THRESHOLD_UNSPECIFIED`
    - `BLOCK_LOW_AND_ABOVE`
    - `BLOCK_MEDIUM_AND_ABOVE`
    - `BLOCK_ONLY_HIGH`
    - `BLOCK_NONE`

- **audioTimestamp** _boolean_

  可选。为音频文件启用时间戳理解。默认为 false。

  这对生成带准确时间戳的转写文本很有用。
  用法细节请参阅 [Google 文档](https://cloud.google.com/vertex-ai/generative-ai/docs/multimodal/audio-understanding)。

- **labels** _object_

  可选。定义用于账单报告的标签。

  用法细节请参阅 [Google 文档](https://cloud.google.com/vertex-ai/generative-ai/docs/multimodal/add-labels-to-api-calls)。

- **imageConfig** _object_

  可选。图像生成的配置。仅 Gemini 图像模型支持。

  用法细节请参阅 [Google 的 GenerationConfig 文档](https://docs.cloud.google.com/vertex-ai/generative-ai/docs/reference/rest/v1/GenerationConfig)。
  - **aspectRatio** _string_

    可选。生成图像的宽高比。默认为 1:1 方形，或在有输入图像时匹配其输出尺寸。可以是以下之一：
    - 1:1
    - 2:3
    - 3:2
    - 3:4
    - 4:3
    - 4:5
    - 5:4
    - 9:16
    - 16:9
    - 21:9

  - **imageSize** _string_

    可选。控制输出图像的分辨率。默认为 1K。可以是以下之一：
    - 1K
    - 2K
    - 4K

  - **personGeneration** _string_

    可选。控制图像中人物的生成。可以是以下之一：
    - `PERSON_GENERATION_UNSPECIFIED`
    - `ALLOW_ALL`
    - `ALLOW_ADULT`
    - `ALLOW_NONE`

  - **prominentPeople** _string_

    可选。控制是否允许生成知名人物（名人）。与 `personGeneration` 一起设置时，`personGeneration` 优先。可以是以下之一：
    - `PROMINENT_PEOPLE_UNSPECIFIED`
    - `ALLOW_PROMINENT_PEOPLE`
    - `BLOCK_PROMINENT_PEOPLE`

  - **imageOutputOptions** _\{ mimeType?: 'image/jpeg' | 'image/png', compressionQuality?: number \}_

    可选。生成图像的输出格式。

- **streamFunctionCallArguments** _boolean_

  可选。设为 true 时，函数调用参数将在流式响应中增量流式传输。
  这使 `tool-input-delta` 事件能在模型生成函数调用参数的同时到达，
  降低工具调用的感知延迟。默认为 `false`。仅 Vertex AI API（非 Gemini API）上的
  Gemini 3+ 模型支持。

  细节请参阅 [Google 文档](https://docs.cloud.google.com/vertex-ai/generative-ai/docs/multimodal/function-calling#streaming-fc)。

- **sharedRequestType** _'priority' | 'flex' | 'standard'_

  可选。通过设置 `X-Vertex-AI-LLM-Shared-Request-Type` 请求头来选择按需付费
  （PayGo）档位。`'priority'` 以溢价换取稳定低延迟，`'flex'` 以更长预期延迟
  换取五折优惠。两者仅 `global` 端点和部分 Gemini 模型支持。

  默认情况下——已分配预置吞吐量（Provisioned Throughput）且未设置
  `requestType` 时——请求会先消耗预置吞吐量配额，只有在其容量耗尽时才
  回退到所选共享档位。要完全绕过预置吞吐量，还需设置
  `requestType: 'shared'`。

  实际服务的档位会通过
  `result.providerMetadata.googleVertex.usageMetadata.trafficType` 返回，
  取值为 `ON_DEMAND_PRIORITY`、`ON_DEMAND_FLEX`，或（高负载下降级时的）
  普通 `ON_DEMAND`。

  支持的模型、爬坡限制和降级行为请参见
  [Priority PayGo](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/priority-paygo)
  与 [Flex PayGo](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/flex-paygo)。

- **requestType** _'shared'_

  可选。设置 `X-Vertex-AI-LLM-Request-Type` 请求头。与 `sharedRequestType`
  组合使用可完全跳过预置吞吐量，让请求走共享 PayGo 容量。参见
  [Priority PayGo](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/priority-paygo)。

你可以使用 Google Vertex 语言模型通过 `generateText` 函数生成文本：

```ts highlight="1,4"
import { googleVertex } from '@ai-sdk/google-vertex';
import { generateText } from 'ai';

const { text } = await generateText({
  model: googleVertex('gemini-3.1-pro-preview'),
  prompt: 'Write a vegetarian lasagna recipe for 4 people.',
});
```

Google Vertex 语言模型也可以用在 `streamText` 函数中
（参见 [AI SDK Core](/docs/ai-sdk-core)）。

#### 微调模型（Tuned Models）

[微调模型（Tuned Models）](https://cloud.google.com/vertex-ai/generative-ai/docs/deploy/overview)
从已部署的端点提供服务，通过端点 ID 而非发布模型名称来寻址。传入带
`endpoints/` 前缀的端点资源，提供商就会把请求路由到已部署端点
（`.../locations/{location}/endpoints/{ENDPOINT_ID}`），而不是基础模型
路径（`.../publishers/google/models/{MODEL_ID}`）：

```ts
import { googleVertex } from '@ai-sdk/google-vertex';
import { generateText } from 'ai';

const { text } = await generateText({
  model: googleVertex('endpoints/YOUR_ENDPOINT_ID'),
  prompt: 'Write a vegetarian lasagna recipe for 4 people.',
});
```

请使用已部署的 **endpoint** ID，而不是微调模型 ID（一个微调模型同时拥有
`models/...` 资源和单独的 `endpoints/...` 资源；只有端点可用于推理调用）。
请求与响应格式与基础模型完全相同，因此所有标准调用设置和提供商选项继续有效。

<Note>
  微调模型需要标准 Google Cloud 凭据，以及已部署端点所在的
  project/location（通过 `GOOGLE_VERTEX_PROJECT` /
  `GOOGLE_VERTEX_LOCATION` 或 `createGoogleVertex` 设置）。
  微调模型不支持 [Express 模式](#express-模式)的 API 密钥。
</Note>

#### 代码执行

通过[代码执行（Code Execution）](https://cloud.google.com/vertex-ai/generative-ai/docs/multimodal/code-execution)，Vertex AI 上的部分 Gemini 模型可以生成并执行 Python 代码。这使模型能够执行计算、数据处理和其他程序化任务，以增强其响应。

你可以在请求中添加 `code_execution` 工具来启用代码执行。

```ts
import { googleVertex } from '@ai-sdk/google-vertex';
import { generateText } from 'ai';

const result = await generateText({
  model: googleVertex('gemini-3.1-pro-preview'),
  tools: { code_execution: googleVertex.tools.codeExecution({}) },
  prompt:
    'Use python to calculate 20th fibonacci number. Then find the nearest palindrome to it.',
});
```

响应将包含已执行代码的 `tool-call` 和 `tool-result` 部分。

#### URL 上下文

URL 上下文（URL Context）允许 Gemini 模型检索和分析 URL 中的内容。支持的模型：Gemini 2.0 及更新版本。

```ts
import { googleVertex } from '@ai-sdk/google-vertex';
import { generateText } from 'ai';

const result = await generateText({
  model: googleVertex('gemini-3.1-pro-preview'),
  tools: { url_context: googleVertex.tools.urlContext({}) },
  prompt: 'What are the key points from https://example.com/article?',
});
```

#### Google 搜索

Google 搜索让 Gemini 模型能够访问实时网络信息。支持的模型：Gemini 2.0 及更新版本。

```ts
import { googleVertex } from '@ai-sdk/google-vertex';
import { generateText } from 'ai';

const result = await generateText({
  model: googleVertex('gemini-3.1-pro-preview'),
  tools: { google_search: googleVertex.tools.googleSearch({}) },
  prompt: 'What are the latest developments in AI?',
});
```

#### 企业网络搜索（Enterprise Web Search）

[企业网络搜索（Enterprise Web Search）](https://cloud.google.com/vertex-ai/generative-ai/docs/grounding/web-grounding-enterprise)使用面向合规的网络索引提供接地（grounding），专为金融、医疗和公共部门等强监管行业设计。与标准 Google 搜索接地不同，企业网络搜索不会记录客户数据，并支持 VPC 服务控制。支持的模型：Gemini 2.0 及更新版本。

```ts
import { googleVertex } from '@ai-sdk/google-vertex';
import { generateText } from 'ai';

const result = await generateText({
  model: googleVertex('gemini-3.8-flash'),
  tools: {
    enterprise_web_search: googleVertex.tools.enterpriseWebSearch({}),
  },
  prompt: 'What are the latest FDA regulations for clinical trials?',
});
```

#### Google 地图

Google 地图接地让 Gemini 模型能够访问 Google Maps 数据，生成具备位置感知的响应。支持的模型：Gemini 2.0 及更新版本。

```ts
import { googleVertex } from '@ai-sdk/google-vertex';
import { type GoogleLanguageModelOptions } from '@ai-sdk/google';
import { generateText } from 'ai';

const result = await generateText({
  model: googleVertex('gemini-3.8-flash'),
  tools: {
    google_maps: googleVertex.tools.googleMaps({}),
  },
  providerOptions: {
    vertex: {
      retrievalConfig: {
        latLng: { latitude: 34.090199, longitude: -117.881081 },
      },
    } satisfies GoogleLanguageModelOptions,
  },
  prompt: 'What are the best Italian restaurants nearby?',
});
```

可选的 `retrievalConfig.latLng` 提供商选项为附近地点的查询提供位置上下文。该配置适用于所有支持位置上下文的接地工具。

#### 函数调用参数流式传输

对于 Vertex AI 上的 Gemini 3 Pro 及更新模型，你可以将 `streamFunctionCallArguments`
设为 `true`，在函数调用参数生成的同时将其流式传输。当需要调用函数时，
`tool-input-delta` 事件会增量到达，而无需等待完整参数，从而降低感知延迟。
该选项默认为 `false`。

```ts
import { googleVertex } from '@ai-sdk/google-vertex';
import { type GoogleLanguageModelOptions } from '@ai-sdk/google';
import { streamText } from 'ai';
import { z } from 'zod';

const result = streamText({
  model: googleVertex('gemini-3.1-pro-preview'),
  prompt: 'What is the weather in Boston and San Francisco?',
  tools: {
    getWeather: {
      description: 'Get the current weather in a given location',
      inputSchema: z.object({
        location: z.string().describe('City name'),
      }),
    },
  },
  providerOptions: {
    vertex: {
      streamFunctionCallArguments: true,
    } satisfies GoogleLanguageModelOptions,
  },
});

for await (const part of result.stream) {
  switch (part.type) {
    case 'tool-input-start':
      console.log(`Tool call started: ${part.toolName}`);
      break;
    case 'tool-input-delta':
      process.stdout.write(part.delta);
      break;
    case 'tool-call':
      console.log(`Tool call complete: ${part.toolName}`, part.input);
      break;
  }
}
```

<Note>
  此特性仅在 Vertex AI API 上可用，Gemini API 不支持。与 Google 提供商一起
  使用时会发出警告，且该选项将被忽略。
</Note>

#### 推理（思考 token）

Google Vertex AI 通过其对 Gemini 模型的支持，也能输出「思考」token，代表模型的推理过程。AI SDK 将其作为推理信息暴露出来。

要通过 Vertex 为兼容的 Gemini 模型启用思考 token，请在 `thinkingConfig` 提供商选项中设置 `includeThoughts: true`。这些选项通过 `providerOptions.vertex` 传入：

```ts
import { googleVertex } from '@ai-sdk/google-vertex';
import { type GoogleLanguageModelOptions } from '@ai-sdk/google';
import { generateText, streamText } from 'ai';

// For generateText:
const { text, reasoningText, reasoning } = await generateText({
  model: googleVertex('gemini-3.8-flash'), // Or other supported model via Vertex
  providerOptions: {
    vertex: {
      thinkingConfig: {
        includeThoughts: true,
        // thinkingLevel: 'high', // Optional
      },
    } satisfies GoogleLanguageModelOptions,
  },
  prompt: 'Explain quantum computing in simple terms.',
});

console.log('Reasoning:', reasoningText);
console.log('Reasoning Details:', reasoning);
console.log('Final Text:', text);

// For streamText:
const result = streamText({
  model: googleVertex('gemini-3.8-flash'), // Or other supported model via Vertex
  providerOptions: {
    vertex: {
      thinkingConfig: {
        includeThoughts: true,
        // thinkingLevel: 'high', // Optional
      },
    } satisfies GoogleLanguageModelOptions,
  },
  prompt: 'Explain quantum computing in simple terms.',
});

for await (const part of result.stream) {
  if (part.type === 'reasoning') {
    process.stdout.write(`THOUGHT: ${part.textDelta}\n`);
  } else if (part.type === 'text-delta') {
    process.stdout.write(part.textDelta);
  }
}
```

当 `includeThoughts` 为 true 时，API 响应中标记为 `thought: true` 的部分将被作为推理处理。

- 在 `generateText` 中，它们会汇入 `reasoningText`（string）与 `reasoning`（array）字段。
- 在 `streamText` 中，它们会以 `reasoning` 流部分的形式发出。

<Note>
  模型兼容性与更多细节请参阅 [Google Vertex AI 关于
  "thinking" 的文档](https://cloud.google.com/vertex-ai/generative-ai/docs/thinking)。
</Note>

### 工具结果文件

对于 Gemini 3 及更新版本的模型，工具结果可以包含 Google Cloud Storage
（`gs://`）文件 URL。Vertex 直接以 `functionResponse.parts[].fileData`
的形式接收这些引用，而不会把文件下载进 SDK 进程。支持的 MIME 类型为
`image/png`、`image/jpeg`、`image/webp`、`application/pdf` 和 `text/plain`。
请指定完整的 MIME 类型；`image` 这类顶级类型不足以描述 GCS 工具结果。

在工具的 `toModelOutput` 结果中使用文件部分：

```ts
toModelOutput: ({ output }) => ({
  type: 'content',
  value: [
    {
      type: 'file',
      mediaType: 'image/png',
      data: {
        type: 'url',
        url: new URL(output.gcsUri),
        originalUrl: output.gcsUri,
      },
    },
  ],
}),
```

当 URL 解析会改变原本不透明的 GCS URI 时（例如路径包含空格），请附上
`originalUrl`，让 Vertex 收到确切的对象引用。Vertex 调用方必须有权访问所引用的对象。

HTTP(S) 工具结果文件会被下载并以内联数据发送，受
`toolResultDownloads.maxBytes` 约束。较旧的 Gemini 模型或上述清单之外的
MIME 类型不支持 GCS 工具结果的直接转发。

### 缓存内容

Google Vertex AI 同时支持显式缓存与隐式缓存，帮助降低重复内容的成本。

#### 隐式缓存

```ts
import { googleVertex } from '@ai-sdk/google-vertex';
import { generateText } from 'ai';

// Structure prompts with consistent content at the beginning
const baseContext =
  'You are a cooking assistant with expertise in Italian cuisine. Here are 1000 lasagna recipes for reference...';

  model: googleVertex('gemini-3.1-pro-preview'),

// Check cached token count in usage metadata
console.log('Cached tokens:', providerMetadata.vertex);
// e.g.
// {
//   groundingMetadata: null,
//   safetyRatings: null,
//   usageMetadata: {
//     cachedContentTokenCount: 2027,
//     thoughtsTokenCount: 702,
//     promptTokenCount: 2152,
//     candidatesTokenCount: 710,
//     totalTokenCount: 3564
//   }
// }
```

#### 显式缓存

你可以对 Gemini 模型使用显式缓存。请查看 [Vertex AI 上下文缓存文档](https://cloud.google.com/vertex-ai/generative-ai/docs/context-cache/context-cache-overview)，确认你的模型是否支持缓存。

首先，使用开启了 Vertex 模式的 Google GenAI SDK 创建缓存：

```ts
import { GoogleGenAI } from '@google/genai';

const ai = new GoogleGenAI({
  vertexai: true,
  project: process.env.GOOGLE_VERTEX_PROJECT,
  location: process.env.GOOGLE_VERTEX_LOCATION,
});

const model = 'gemini-3.1-pro-preview';

// Create a cache with the content you want to reuse
const cache = await ai.caches.create({
  model,
  config: {
    contents: [
      {
        role: 'user',
        parts: [{ text: '1000 Lasagna Recipes...' }],
      },
    ],
    ttl: '300s', // Cache expires after 5 minutes
  },
});

console.log('Cache created:', cache.name);
// e.g. projects/my-project/locations/us-central1/cachedContents/abc123
```

然后在 AI SDK 中使用该缓存：

```ts
import { googleVertex } from '@ai-sdk/google-vertex';
import { type GoogleLanguageModelOptions } from '@ai-sdk/google';
import { generateText } from 'ai';

const { text: veggieLasagnaRecipe } = await generateText({
  model: googleVertex('gemini-3.1-pro-preview'),
  prompt: 'Write a vegetarian lasagna recipe for 4 people.',
  providerOptions: {
    vertex: {
      cachedContent: cache.name,
    } satisfies GoogleLanguageModelOptions,
  },
});

const { text: meatLasagnaRecipe } = await generateText({
  model: googleVertex('gemini-3.1-pro-preview'),
  prompt: 'Write a meat lasagna recipe for 12 people.',
  providerOptions: {
    vertex: {
      cachedContent: cache.name,
    } satisfies GoogleLanguageModelOptions,
  },
});
```

### 故障排查

#### Schema 限制

Google Vertex API 使用 OpenAPI 3.0 schema 的一个子集，
不支持联合类型（union）等特性。
这种情况下你会得到如下错误：

`GenerateContentRequest.generation_config.response_schema.properties[occupation].type: must be specified`

默认情况下结构化输出是启用的（工具调用时则是必需的）。
你可以禁用对象生成的结构化输出作为变通方案：

```ts highlight="7,12"
import { googleVertex } from '@ai-sdk/google-vertex';
import { type GoogleLanguageModelOptions } from '@ai-sdk/google';
import { generateText, Output } from 'ai';

const result = await generateText({
  model: googleVertex('gemini-3.1-pro-preview'),
  providerOptions: {
    vertex: {
      structuredOutputs: false,
    } satisfies GoogleLanguageModelOptions,
  },
  output: Output.object({
    schema: z.object({
      name: z.string(),
      age: z.number(),
      contact: z.union([
        z.object({
          type: z.literal('email'),
          value: z.string(),
        }),
        z.object({
          type: z.literal('phone'),
          value: z.string(),
        }),
      ]),
    }),
  }),
  prompt: 'Generate an example person for testing.',
});
```

以下 Zod 特性已知无法与 Google Vertex 一起使用：

- `z.union`
- `z.record`

### 嵌入模型

你可以使用 `.embeddingModel()` 工厂方法创建调用 Google Vertex AI 嵌入 API 的模型：

```ts
const model = googleVertex.embeddingModel('text-embedding-005');
```

Google Vertex AI 嵌入模型支持额外的设置。你可以将它们作为选项参数传入：

```ts
import {
  googleVertex,
  type GoogleVertexEmbeddingModelOptions,
} from '@ai-sdk/google-vertex';
import { embed } from 'ai';

const model = googleVertex.embeddingModel('text-embedding-005');

const { embedding } = await embed({
  model,
  value: 'sunny day at the beach',
  providerOptions: {
    vertex: {
      outputDimensionality: 512, // optional, number of dimensions for the embedding
      taskType: 'SEMANTIC_SIMILARITY', // optional, specifies the task type for generating embeddings
      autoTruncate: false, // optional
    } satisfies GoogleVertexEmbeddingModelOptions,
  },
});
```

Google Vertex AI 嵌入模型支持以下可选提供商选项：

- **outputDimensionality**: _number_

  可选。输出嵌入的降维维度。设置后，输出嵌入中多余的值会从末尾截断。

- **taskType**: _string_

  可选。指定生成嵌入的任务类型。支持的任务类型包括：
  - `SEMANTIC_SIMILARITY`: 针对文本相似度优化。
  - `CLASSIFICATION`: 针对文本分类优化。
  - `CLUSTERING`: 针对基于相似度的文本聚类优化。
  - `RETRIEVAL_DOCUMENT`: 针对文档检索优化。
  - `RETRIEVAL_QUERY`: 针对基于查询的检索优化。
  - `QUESTION_ANSWERING`: 针对问答优化。
  - `FACT_VERIFICATION`: 针对事实核查优化。
  - `CODE_RETRIEVAL_QUERY`: 针对基于自然语言查询检索代码块优化。

- **title**: _string_

  可选。被嵌入文档的标题。提供额外上下文有助于模型产出更好的嵌入。仅在 `taskType` 设为 `'RETRIEVAL_DOCUMENT'` 时有效。

- **autoTruncate**: _boolean_

  可选。设为 `true` 时，输入文本超过最大长度会被截断。设为 `false` 时，输入文本过长会返回错误。默认为 `true`。

### 图像模型

你可以使用 `.image()` 工厂方法创建 Gemini 图像模型。这些模型通过语言模型
`:generateContent` API 提供图像输出。
关于使用 AI SDK 进行图像生成的更多内容，请参见
[generateImage()](/docs/reference/ai-sdk-core/generate-image)。

#### Gemini 图像模型

[Gemini 图像模型](https://cloud.google.com/vertex-ai/generative-ai/docs/models/gemini/2-5-flash-image)（如 `gemini-3.1-flash-image-preview`）是多模态输出语言模型，可与 `generateImage()` 一起使用，获得更简单的图像生成体验。内部实现上，提供商以 `responseModalities: ['IMAGE']` 调用语言模型 API。

```ts
import { googleVertex } from '@ai-sdk/google-vertex';
import { generateImage } from 'ai';

const { image } = await generateImage({
  model: googleVertex.image('gemini-3.1-flash-image-preview'),
  prompt: 'A photorealistic image of a cat wearing a wizard hat',
  aspectRatio: '1:1',
});
```

Gemini 图像模型还支持通过提供输入图像进行图像编辑：

```ts
import { googleVertex } from '@ai-sdk/google-vertex';
import { generateImage } from 'ai';
import fs from 'node:fs';

const sourceImage = fs.readFileSync('./cat.png');

const { image } = await generateImage({
  model: googleVertex.image('gemini-3.1-flash-image-preview'),
  prompt: {
    text: 'Add a small wizard hat to this cat',
    images: [sourceImage],
  },
});
```

<Note>
  输入图像必须以 `Buffer`、`ArrayBuffer`、`Uint8Array` 或 base64 编码字符串提供。
  `generateImage()` 搭配 Google Vertex 图像模型不支持 URL 输入，包括 HTTP 和
  `gs://` URL。
</Note>

<Note>
  Gemini 图像模型不支持 `size` 或 `n` 参数。请用 `aspectRatio` 代替
  `size`。基于蒙版的局部重绘（inpainting）同样不支持。
</Note>

<Note>
  Gemini 图像模型是可同时生成文本和图像的多模态输出模型。对于需要同时输出
  文本与图像、或希望更精细控制生成过程的高级用例，你可以直接将它们与
  `generateText()` 一起使用。
</Note>

#### 提供商选项

更多配置可以通过 Google Vertex 提供商选项完成。你可以使用 `GoogleVertexVideoModelOptions` 类型校验提供商选项。

```ts
import { googleVertex } from '@ai-sdk/google-vertex';
import { GoogleVertexVideoModelOptions } from '@ai-sdk/google-vertex';
import { experimental_generateVideo as generateVideo } from 'ai';

const { video } = await generateVideo({
  model: googleVertex.video('veo-3.1-generate-001'),

```

可用的提供商选项如下：

- **generateAudio** _boolean_

  是否在生成视频的同时生成音频。

- **personGeneration** `'dont_allow'` | `'allow_adult'` | `'allow_all'`

  是否允许在视频中生成人物。

- **negativePrompt** _string_

  描述生成视频中不希望出现的元素。

- **gcsOutputDirectory** _string_

  存储生成视频的 Cloud Storage URI。

- **referenceImages** _Array\<\{ bytesBase64Encoded?: string; gcsUri?: string \}\>_

- **pollIntervalMs** _number_

  轮询任务状态的间隔（毫秒）。

- **pollTimeoutMs** _number_

  视频生成的最大等待时间（毫秒）。

<Note>
  视频生成是异步过程，可能耗时数分钟。对于更长的视频或更高分辨率，建议将
  `pollTimeoutMs` 设置为至少 10 分钟（600000 毫秒）。
</Note>

### 语音模型

你可以使用 `.speech()` 工厂方法创建调用 Vertex AI API 的
[Gemini 文本转语音（text-to-speech）](https://docs.cloud.google.com/text-to-speech/docs/gemini-tts)模型。
关于使用 AI SDK 进行语音生成的更多内容，请参见
[generateSpeech()](/docs/reference/ai-sdk-core/generate-speech)。

```ts
import { googleVertex } from '@ai-sdk/google-vertex';
import { generateSpeech } from 'ai';

const result = await generateSpeech({
  model: googleVertex.speech('gemini-2.5-flash-tts'),
  text: 'Hello, world!',
  voice: 'Kore', // Gemini voice name
});
```

`voice` 参数接受 Gemini [30 个预置语音](https://ai.google.dev/gemini-api/docs/speech-generation#voices)之一
（如 `Kore`、`Puck`、`Zephyr`），默认为 `Kore`。多说话人对话可通过
`providerOptions.googleVertex.multiSpeakerVoiceConfig` 使用。

默认情况下，音频以可播放的 WAV 格式返回（Gemini 返回原始 PCM，由提供商包装）。
设置 `outputFormat: 'pcm'` 可获得原始的 16 位有符号小端（little-endian）单声道字节；
采样率通过 `result.providerMetadata.google.sampleRate` 返回。

### 语音转写模型

你可以使用 `.transcription()` 工厂方法搭配
[`transcribe()`](/docs/reference/ai-sdk-core/transcribe)，通过 Google Cloud Speech-to-Text 模型转写音频。

```ts
import { googleVertex } from '@ai-sdk/google-vertex';
import { transcribe } from 'ai';
import { readFile } from 'fs/promises';

const result = await transcribe({
  model: googleVertex.transcription('chirp_2'),
  audio: await readFile('audio.wav'),
});
```

该提供商支持 [Chirp](https://docs.cloud.google.com/speech-to-text/docs/models/chirp-3)
模型 `chirp_2` 和 `chirp_3`，以及用于电话音频的 `telephony`。
Speech-to-Text 使用标准 Google Cloud 凭据（OAuth、应用默认凭据或服务账号），
调用 Cloud Speech-to-Text API。语音转写模型不支持 Express 模式 API 密钥。
请将 `GOOGLE_VERTEX_LOCATION`（或 `providerOptions.googleVertex.region`）设为
Speech-to-Text 区域。对于 Chirp，`chirp_2` 可在 `us-central1`、
`europe-west4` 和 `asia-southeast1` 使用；`chirp_3` 可在 `us` 和 `eu`
多区域使用。Chirp 在 `global` Speech-to-Text 位置不可用，
且这些区域与 Vertex AI 区域不同。`telephony` 的可用性取决于所选的
Speech-to-Text 区域和语言。

同步 API 最多转写一分钟或 10 MB 的音频，以先达到者为准。口说语言默认自动检测；
可传入 `languageCodes` 加以限制。对于 `telephony`，请传入受支持的语言代码，
如 `['en-US']`。

```ts
const result = await transcribe({
  model: googleVertex.transcription('chirp_3'),
  audio: await readFile('audio.wav'),
  providerOptions: {
    googleVertex: {
      region: 'us',
      languageCodes: ['en-US'],
    },
  },
});
```

可用的提供商选项如下：

- **languageCodes** _string[]_

  要识别的 BCP-47 语言代码，或使用 `['auto']` 自动检测口说语言。
  默认为 `['auto']`。多个显式语言代码需要 `us` 或 `eu` 等多区域
  Speech-to-Text 端点。

- **enableAutomaticPunctuation** _boolean_

  是否为转写文本添加标点。默认为 `true`。

- **enableWordTimeOffsets** _boolean_

  是否在 `result.segments` 中包含词级时间戳。默认为
  `true`。Google 指出启用词级时间戳可能降低转写的质量与速度。

- **region** _string_

  请求使用的 Speech-to-Text 区域。默认为提供商的
  `location`。

#### 语音转写模型能力

| 模型        | 词级时间戳                                                | 语言检测                                                                       |
| ----------- | --------------------------------------------------------- | ------------------------------------------------------------------------------ |
| `chirp_2`   | 可用，可能在质量与速度上有折中                            | 通过 `['auto']` 自动检测                                                       |
| `chirp_3`   | 可用，可能在转写质量上有折中                              | 通过 `['auto']` 自动检测                                                       |
| `telephony` | 可用                                                      | 显式指定受支持的语言代码，支持备选语言检测                                     |

## Google Vertex Anthropic 提供商用法

[AI SDK](/docs) 的 Google Vertex Anthropic 提供商通过 Google Vertex AI API 提供 Anthropic 的 Claude 模型支持。本节介绍如何设置和使用 Google Vertex Anthropic 提供商。

### 提供商实例

你可以从 `@ai-sdk/google-vertex/anthropic` 导入默认的提供商实例 `vertexAnthropic`：

```typescript
import { createVertexAnthropic } from '@ai-sdk/google-vertex/anthropic';

const vertexAnthropic = createVertexAnthropic({
```

#### Edge 运行时

Edge 运行时（如 Cloudflare Workers）是更靠近网络边缘、离用户更近的轻量级 JavaScript 环境。它们只提供标准 Node.js API 的一个子集。
例如，无法直接访问文件系统，而且许多 Node.js 专有库
（包括标准 Google Auth 库）都不兼容。

Google Vertex Anthropic 提供商的 Edge 运行时版本通过环境变量支持 Google 的[应用默认凭据（Application Default Credentials）](https://github.com/googleapis/google-auth-library-nodejs?tab=readme-ov-file#application-default-credentials)。这些值可以从 [Google Cloud Console](https://console.cloud.google.com/apis/credentials) 的 json 凭据文件中获取。

```typescript
import { vertexAnthropic } from '@ai-sdk/google-vertex/anthropic/edge';
```

```typescript
import { createVertexAnthropic } from '@ai-sdk/google-vertex/anthropic/edge';
```

- `GOOGLE_CLIENT_EMAIL`
- `GOOGLE_PRIVATE_KEY`
- `GOOGLE_PRIVATE_KEY_ID`（可选）

### 语言模型

你可以使用提供商实例创建调用 [Anthropic Messages API](https://docs.anthropic.com/claude/reference/messages_post) 的模型。
第一个参数是模型 ID，例如 `claude-sonnet-5-5`。
部分模型具备多模态能力。

```ts
const model = vertexAnthropic('claude-sonnet-5-5');
```

你可以使用 Anthropic 语言模型通过 `generateText` 函数生成文本：

```ts
import { vertexAnthropic } from '@ai-sdk/google-vertex/anthropic';
import { generateText } from 'ai';

const { text } = await generateText({
  model: vertexAnthropic('claude-sonnet-5-5'),
  prompt: 'Write a vegetarian lasagna recipe for 4 people.',
});
```

Anthropic 语言模型也可以用在 `streamText` 函数中，
并通过 [`Output`](/docs/reference/ai-sdk-core/output) 支持结构化数据生成
（参见 [AI SDK Core](/docs/ai-sdk-core)）。

<Note>
  Anthropic API 会在延迟一段时间后一次性返回流式工具调用。这会导致结构化输出
  生成在延迟后整体完成，而不是增量流式输出。
</Note>

Anthropic 模型支持以下可选提供商选项：

- `sendReasoning` _boolean_

  可选。是否在发送给模型的请求中包含推理内容。默认为 `true`。

  如果模型在处理包含推理内容的请求时出现问题，你可以将其设为 `false`，
  在请求中省略这些内容。

- `thinking` _object_

  可选。更多细节请参见[推理章节](#推理reasoning)。

- `metadata` _object_

  可选。随请求包含的元数据。细节请参见 [Anthropic API 文档](https://platform.claude.com/docs/en/api/messages/create)。
  - `userId` _string_ - 终端用户的外部标识符。

### 推理（reasoning）

Anthropic 为 `claude-3-7-sonnet@20250219` 模型提供推理支持。

你可以使用 `thinking` 提供商选项启用它，
并以 token 为单位指定思考预算。

```ts
import { vertexAnthropic } from '@ai-sdk/google-vertex/anthropic';
import { generateText } from 'ai';

const { text, reasoningText, reasoning } = await generateText({
  model: vertexAnthropic('claude-3-7-sonnet@20250219'),
  prompt: 'How many people will live in the world in 2040?',
  providerOptions: {
    anthropic: {
      thinking: { type: 'enabled', budgetTokens: 12000 },
    },
  },
});

console.log(reasoningText); // reasoning text
console.log(reasoning); // reasoning details including redacted reasoning
console.log(text); // text response
```

关于如何在聊天机器人中集成推理的更多细节，
请参见 [AI SDK UI：聊天机器人](/docs/ai-sdk-ui/chatbot#推理)。

#### 缓存控制

<Note>
  Anthropic 缓存控制在 Google Vertex 上处于 Pre-GA（正式发布前）状态。
  更多信息请参见 [Google Vertex Anthropic 缓存控制
  文档](https://cloud.google.com/vertex-ai/generative-ai/docs/partner-models/claude-prompt-caching)。
</Note>

在消息和消息部分中，你可以使用 `providerOptions` 属性设置缓存控制断点。
将 `providerOptions` 对象中的 `anthropic` 属性设为 `{ cacheControl: { type: 'ephemeral' } }` 即可设置缓存控制断点。

对于 `generateText` 和 `streamText`，缓存读取与缓存写入（创建）的 token 数都会在标准
`usage` 对象上返回。你可以通过
`result.usage.inputTokenDetails.cacheReadTokens` 与
`result.usage.inputTokenDetails.cacheWriteTokens` 访问它们。

```ts highlight="8,16-18,27-31"
import { vertexAnthropic } from '@ai-sdk/google-vertex/anthropic';
import { generateText } from 'ai';

const errorMessage = '... long error message ...';

const result = await generateText({
  model: vertexAnthropic('claude-sonnet-5-5'),
  messages: [
    {
      role: 'user',
      content: [
        { type: 'text', text: 'You are a JavaScript expert.' },
        {
          type: 'text',
          text: `Error message: ${errorMessage}`,
          providerOptions: {
            anthropic: { cacheControl: { type: 'ephemeral' } },
          },
        },
        { type: 'text', text: 'Explain the error message.' },
      ],
    },
  ],
});

console.log(result.text);
console.log(
  'Cache read tokens:',
  result.usage.inputTokenDetails.cacheReadTokens,
);
console.log(
  'Cache write tokens:',
  result.usage.inputTokenDetails.cacheWriteTokens,
);
```

你也可以在 messages 数组开头提供多条系统消息，从而对系统消息使用缓存控制：

```ts highlight="3,7-9"
const result = await generateText({
  model: vertexAnthropic('claude-sonnet-5-5'),
  messages: [
    {
      role: 'system',
      content: 'Cached system message part',
      providerOptions: {
        anthropic: { cacheControl: { type: 'ephemeral' } },
      },
    },
    {
      role: 'system',
      content: 'Uncached system message part',
    },
    {
      role: 'user',
      content: 'User prompt',
    },
  ],
});
```

关于 Anthropic 提示词缓存的更多内容，请参见 [Google Vertex AI 的 Claude 提示词缓存文档](https://cloud.google.com/vertex-ai/generative-ai/docs/partner-models/claude-prompt-caching)与 [Anthropic 的 Cache Control 文档](https://docs.anthropic.com/en/docs/build-with-claude/prompt-caching)。

### 工具

Google Vertex Anthropic 支持 Anthropic 内置工具的一个子集。以下工具可通过提供商实例的 `tools` 属性使用：

1. **Bash 工具**：允许运行 bash 命令。
2. **文本编辑器工具**：提供查看和编辑文本文件的功能。
3. **计算机工具**：支持控制计算机上的键盘和鼠标操作。
4. **网络搜索工具**：提供对实时网络内容的访问。

<Note>
  Google Vertex 上仅支持 Anthropic 工具的一个子集。代码执行、Memory 和
  Web Fetch 等工具不可用。如需使用全部 Anthropic 工具，请使用常规的
  `@ai-sdk/anthropic` 提供商。
</Note>

<Note>
  Google Vertex Anthropic 不支持工具定义上的 strict 模式。在工具上设置
  `strict: true` 会被忽略，并发出警告。
</Note>

关于 Anthropic 工具的更多背景，请参见 [Anthropic 文档](https://platform.claude.com/docs/en/agents-and-tools/tool-use/overview)。

#### Bash 工具

Bash 工具允许运行 bash 命令。以下是创建和使用它的方法：

```ts
const bashTool = vertexAnthropic.tools.bash_20250124({
  execute: async ({ command, restart }) => {
    // Implement your bash command execution logic here
    // Return the result of the command execution
  },
});
```

参数：

- `command` (string)：要运行的 bash 命令。除非工具正在重启，否则必填。
- `restart` (boolean, optional)：设为 true 将重启此工具。

#### 文本编辑器工具

文本编辑器工具提供查看和编辑文本文件的功能：

```ts
const textEditorTool = vertexAnthropic.tools.textEditor_20250124({
  execute: async ({
    command,
    path,
    file_text,
    insert_line,
    new_str,
    insert_text,
    old_str,
    view_range,
  }) => {
    // Implement your text editing logic here
    // Return the result of the text editing operation
  },
});
```

参数：

- `command` ('view' | 'create' | 'str_replace' | 'insert' | 'undo_edit')：要运行的命令。注意：`textEditor_20250429` 和 `textEditor_20250728` 不支持 `undo_edit`。
- `path` (string)：文件或目录的绝对路径，例如 `/repo/file.py` 或 `/repo`。
- `file_text` (string, optional)：`create` 命令必填，为要创建文件的内容。
- `insert_line` (number, optional)：`insert` 命令必填。在其后插入新字符串的行号。
- `new_str` (string, optional)：`str_replace` 命令的新字符串。
- `insert_text` (string, optional)：`insert` 命令必填，为要插入的文本。
- `old_str` (string, optional)：`str_replace` 命令必填，为要替换的字符串。
- `view_range` (number[], optional)：`view` 命令可选，用于指定要显示的行范围。
- `max_characters` (number, optional)：可选，文件中可查看的最大字符数（仅在 `textEditor_20250728` 中可用）。

#### 计算机工具

计算机工具支持控制计算机上的键盘和鼠标操作：

```ts
const computerTool = vertexAnthropic.tools.computer_20241022({
  displayWidthPx: 1920,
  displayHeightPx: 1080,
  displayNumber: 0, // Optional, for X11 environments

  execute: async ({ action, coordinate, text }) => {
    // Implement your computer control logic here
    // Return the result of the action

    // Example code:
    switch (action) {
      case 'screenshot': {
        // multipart result:
        return {
          type: 'image',
          data: fs
            .readFileSync('./data/screenshot-editor.png')
            .toString('base64'),
        };
      }
      default: {
        console.log('Action:', action);
        console.log('Coordinate:', coordinate);
        console.log('Text:', text);
        return `executed ${action}`;
      }
    }
  },

  // map to tool result content for LLM consumption:
  toModelOutput({ output }) {
    return typeof output === 'string'
      ? [{ type: 'text', text: output }]
      : [{ type: 'file-data', data: output.data, mediaType: 'image/png' }];
  },
});
```

参数：

- `action` ('key' | 'type' | 'mouse_move' | 'left_click' | 'left_click_drag' | 'right_click' | 'middle_click' | 'double_click' | 'screenshot' | 'cursor_position')：要执行的操作。
- `coordinate` (number[], optional)：`mouse_move` 和 `left_click_drag` 操作必填。指定 (x, y) 坐标。
- `text` (string, optional)：`type` 和 `key` 操作必填。

#### 网络搜索工具

网络搜索工具让 Claude 能够直接访问实时网络内容：

```ts
const webSearchTool = vertexAnthropic.tools.webSearch_20250305({
  maxUses: 5, // Optional: Maximum number of web searches Claude can perform
```

  - `city` (string, optional)：城市名。
  - `region` (string, optional)：地区或州。
  - `country` (string, optional)：国家。
  - `timezone` (string, optional)：IANA 时区 ID。

这些工具可与受支持的 Claude 模型配合使用，实现更复杂的交互与任务。

## Google Vertex xAI 提供商用法

更多信息请参见 [Vertex AI Grok 文档](https://cloud.google.com/vertex-ai/generative-ai/docs/partner-models/grok)。

### 提供商实例

你可以从 `@ai-sdk/google-vertex/xai` 导入默认的提供商实例 `googleVertexXai`：

```typescript
import { googleVertexXai } from '@ai-sdk/google-vertex/xai';
```

如果需要自定义配置，可以从 `@ai-sdk/google-vertex/xai` 导入 `createGoogleVertexXai`，并使用你的设置创建提供商实例：

```typescript
import { createGoogleVertexXai } from '@ai-sdk/google-vertex/xai';

const googleVertexXai = createGoogleVertexXai({
  project: 'my-project', // optional
```

#### Node.js 运行时

在 Node.js 环境中，Google Vertex xAI 提供商通过 `google-auth-library` 支持所有标准的 Google Cloud 身份验证选项：

```typescript
import { createGoogleVertexXai } from '@ai-sdk/google-vertex/xai';

const googleVertexXai = createGoogleVertexXai({
  googleAuthOptions: {
    credentials: {
      client_email: 'my-email',
      private_key: 'my-private-key',
    },
  },
});
```

##### 可选提供商设置

- **project** _string_

  Google Cloud 项目 ID。默认使用 `GOOGLE_VERTEX_PROJECT` 环境变量。

- **location** _string_

  Google Cloud 位置（location）。Grok 模型在 global 端点可用。默认使用 `GOOGLE_VERTEX_LOCATION` 环境变量。未设置时默认为 `global`。

- **googleAuthOptions** _object_

  可选。[Google Auth Library](https://github.com/googleapis/google-auth-library-nodejs/) 使用的身份验证选项。

- **headers** _Resolvable&lt;Record&lt;string, string | undefined&gt;&gt;_

  要包含在请求中的请求头。

- **fetch** _(input: RequestInfo, init?: RequestInit) => Promise&lt;Response&gt;_

  自定义 [fetch](https://developer.mozilla.org/en-US/docs/Web/API/fetch) 实现。
