# ByteDance 提供商

[ByteDance](https://www.bytedance.com/) 提供商通过 [BytePlus ModelArk](https://docs.byteplus.com/en/docs/ModelArk/) 平台支持 Seedance 系列视频生成模型与 Seedream 系列图像生成模型。Seedance 提供高质量的文生视频与图生视频能力，包括音视频同步、首尾帧控制与多参考图生成（参见[视频生成 API](https://docs.byteplus.com/en/docs/ModelArk/Video_Generation_API)）。Seedream 提供文生图与图生图能力，包括多图融合与批量图像生成（参见[图像生成 API](https://docs.byteplus.com/en/docs/ModelArk/1824690)）。

## 安装

ByteDance 提供商可通过 `@ai-sdk/bytedance` 模块获取，可以通过以下方式安装：

<InstallPackages packages="@ai-sdk/bytedance" />

## 提供商实例

你可以从 `@ai-sdk/bytedance` 导入默认提供商实例 `byteDance`：

```ts
import { byteDance } from '@ai-sdk/bytedance';
```

如果需要自定义配置，可以导入 `createByteDance` 并使用你的设置创建提供商实例：

```ts
import { createByteDance } from '@ai-sdk/bytedance';

const byteDance = createByteDance({
  apiKey: 'your-api-key', // optional, defaults to ARK_API_KEY environment variable
  baseURL: 'custom-url', // optional
  headers: {
    /* custom headers */
  }, // optional
});
```

你可以使用以下可选设置来自定义 ByteDance 提供商实例：

- **baseURL** _string_

  为 API 调用使用不同的 URL 前缀，例如使用代理服务器。默认前缀为 `https://ark.ap-southeast.bytepluses.com/api/v3`。

- **apiKey** _string_

  通过 `Authorization` 请求头发送的 API 密钥。默认取 `ARK_API_KEY` 环境变量。你可以在 BytePlus 控制台中[获取 API 密钥](https://console.byteplus.com/ark/apiKey)。

- **headers** _Record&lt;string,string&gt;_

  请求中包含的自定义请求头。

- **fetch** _(input: RequestInfo, init?: RequestInit) => Promise&lt;Response&gt;_

  自定义 [fetch](https://developer.mozilla.org/en-US/docs/Web/API/fetch) 实现。可以用它作为中间件拦截请求，或为测试等场景提供自定义 fetch 实现。

## 图像模型

你可以使用 `.image()` 工厂方法创建 ByteDance Seedream 图像模型。
有关在 AI SDK 中进行图像生成的更多信息，参见 [generateImage()](/docs/reference/ai-sdk-core/generate-image)。

### 文生图

从文本提示词生成图像：

```ts
import { byteDance, type ByteDanceImageModelOptions } from '@ai-sdk/bytedance';
import { generateImage } from 'ai';

const { image } = await generateImage({
  model: byteDance.image('seedream-5-0-260128'),
  prompt: 'A salamander in a forest pond at dusk surrounded by fireflies',
  size: '2048x2048',
  providerOptions: {
    bytedance: {
      watermark: false,
    } satisfies ByteDanceImageModelOptions,
  },
});
```

<Note>
  ByteDance 通过 ModelArk 模型 id（如 `seedream-5-0-260128`）或账号专属的端点 id（如 `ep-...`）来标识 Seedream 模型。`size` 参数接受像素尺寸（`{width}x{height}`）；`2K` 等分辨率级别可通过 `providerOptions.bytedance.size` 传入。
</Note>

### 图像编辑

通过 `prompt.images` 传入输入图像，对已有图像进行变换（图生图）：

```ts
import { readFileSync } from 'node:fs';
import { byteDance, type ByteDanceImageModelOptions } from '@ai-sdk/bytedance';
import { generateImage } from 'ai';

const inputImage = readFileSync('./input-image.png');

const { image } = await generateImage({
  model: byteDance.image('seedream-5-0-260128'),
  prompt: {
    text: 'Change the salamander to a snow weasel',
    images: [inputImage],
  },
  providerOptions: {
    bytedance: {
      watermark: false,
    } satisfies ByteDanceImageModelOptions,
  },
});
```

你还可以传入多张图像，把多个参考图的风格与元素融合到单一输出中（多图融合）。图像可以以二进制数据、base64 字符串或 URL 的形式提供：

```ts
import { byteDance, type ByteDanceImageModelOptions } from '@ai-sdk/bytedance';
import { generateImage } from 'ai';

const { image } = await generateImage({
  model: byteDance.image('seedream-5-0-260128'),
  prompt: {
    text: 'Replace the clothing in image 1 with the outfit from image 2',
    images: ['https://example.com/model.png', 'https://example.com/outfit.png'],
  },
  providerOptions: {
    bytedance: {
      watermark: false,
    } satisfies ByteDanceImageModelOptions,
  },
});
```

<Note>
  Seedream 不支持基于蒙版的局部重绘（inpainting）。请在提示词中描述所需的修改，也可以选择在输入图像上绘制标记（交互式编辑，由 `dola-seedream-5-0-pro-260628` 支持）。
</Note>

### 图像模型选项

以下选项可通过 `providerOptions.bytedance` 使用。你可以用 `ByteDanceImageModelOptions` 为其标注类型。

- **watermark** _boolean_

  是否在输出图像右下角添加“AI 生成”水印。

- **outputFormat** _'png' | 'jpeg'_

  生成的图像文件格式。`seedream-5-0` 和 `dola-seedream-5-0-pro` 支持此选项；`seedream-4-5` / `seedream-4-0` 始终返回 `jpeg`。

- **size** _string_

  分辨率级别（如 `1K`、`2K`、`3K`、`4K`），可作为通过顶层 `size` 参数传递像素尺寸的替代方案。设置后将覆盖顶层 `size`。可用级别因模型而异。

- **sequentialImageGeneration** _'auto' | 'disabled'_

  设为 `'auto'` 可批量生成一组相关图像（如分镜或品牌视觉素材）。默认为 `'disabled'`（单张图像）。

- **maxImages** _number_

  `sequentialImageGeneration` 为 `'auto'` 时可生成的最大图像数量。输入参考图像数与生成图像数之和不得超过模型上限。

- **optimizePromptMode** _'standard' | 'fast'_

  提示词优化模式。`seedream-4-0` 同时支持 `standard` 与 `fast`；其他模型仅支持 `standard`。

<Note>
  其他 ModelArk 字段也可以通过 `providerOptions.bytedance` 传入，并由 ModelArk 进行校验。
</Note>

### 图像模型能力

| 模型              | 模型 ID                                                  | 能力                                                                                                                                  |
| ----------------- | -------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| Seedream 5.0 Pro  | `dola-seedream-5-0-pro-260628`                           | 文生图、单图/多图生图、交互式编辑（标记）。尺寸：1K、2K。格式：png、jpeg。最多 10 个参考图。                                           |
| Seedream 5.0 Lite | `seedream-5-0-260128`（别名 `seedream-5-0-lite-260128`） | 文生图、单图/多图生图、批量生成。尺寸：2K、3K、4K。格式：png、jpeg。最多 14 个参考图。                                                |
| Seedream 4.5      | `seedream-4-5-251128`                                    | 文生图、单图/多图生图、批量生成。尺寸：2K、4K。格式：jpeg。最多 14 个参考图。                                                         |
| Seedream 4.0      | `seedream-4-0-250828`                                    | 文生图、单图/多图生图、批量生成、快速提示词模式。尺寸：1K、2K、4K。格式：jpeg。最多 14 个参考图。                                      |

<Note>
  如有需要，你也可以传入任意模型或端点 id 字符串，例如此处尚未列出的未来模型。AI SDK 集成目前不支持流式图像输出。
</Note>

## 视频模型

你可以使用 `.video()` 工厂方法创建 ByteDance 视频模型。
有关在 AI SDK 中进行视频生成的更多信息，参见 [generateVideo()](/docs/reference/ai-sdk-core/generate-video)。

### 文生视频

从文本提示词生成视频：

```ts
import { byteDance, type ByteDanceVideoModelOptions } from '@ai-sdk/bytedance';
import { experimental_generateVideo as generateVideo } from 'ai';

const { video } = await generateVideo({
  model: byteDance.video('seedance-1-0-pro-250528'),
  prompt:
    'Photorealistic style: Under a clear blue sky, a vast expanse of white daisy fields stretches out. The camera gradually zooms in and fixates on a close-up of a single daisy.',
  aspectRatio: '16:9',
  duration: 5,
  providerOptions: {
    bytedance: {
      watermark: false,
    } satisfies ByteDanceVideoModelOptions,
  },
});

console.log(video.url);
```

### 图生视频

从首帧图像生成视频，文本提示词可选：

```ts
import { byteDance, type ByteDanceVideoModelOptions } from '@ai-sdk/bytedance';
import { experimental_generateVideo as generateVideo } from 'ai';

const { video } = await generateVideo({
  model: byteDance.video('seedance-1-5-pro-251215'),
  prompt: {
    image: 'https://example.com/first-frame.png',
    text: 'The cat slowly turns its head and blinks',
  },
  duration: 5,
  providerOptions: {
    bytedance: {
      watermark: false,
    } satisfies ByteDanceVideoModelOptions,
  },
});
```

<Note>
  当输出比例由输入决定时——首帧或首尾帧图生视频、视频编辑与视频延展——请传入 `aspectRatio: 'adaptive'` 或完全省略 `aspectRatio`。较新的 Seedance 模型在这些路径下会拒绝显式的比例设置，因为输出会继承输入媒体的比例。
</Note>

### 带音频的图生视频

Seedance 1.5 Pro 支持在生成视频的同时生成同步音频：

```ts
import { byteDance, type ByteDanceVideoModelOptions } from '@ai-sdk/bytedance';
import { experimental_generateVideo as generateVideo } from 'ai';

const { video } = await generateVideo({
  model: byteDance.video('seedance-1-5-pro-251215'),
  prompt: {
    image: 'https://example.com/pianist.png',
    text: 'A young man sits at a piano, playing calmly. Gentle piano music plays in sync with his movements.',
  },
  duration: 5,
  providerOptions: {
    bytedance: {
      generateAudio: true,
      watermark: false,
    } satisfies ByteDanceVideoModelOptions,
  },
});
```

### 首尾帧视频

在起始与结束关键帧图像之间生成平滑过渡：

```ts
import { byteDance, type ByteDanceVideoModelOptions } from '@ai-sdk/bytedance';
import { experimental_generateVideo as generateVideo } from 'ai';

const { video } = await generateVideo({
  model: byteDance.video('seedance-1-5-pro-251215'),
  prompt: {
    image: 'https://example.com/first-frame.jpg',
    text: 'Create a 360-degree orbiting camera shot based on this photo',
  },
  duration: 5,
  providerOptions: {
    bytedance: {
      lastFrameImage: 'https://example.com/last-frame.jpg',
      generateAudio: true,
      watermark: false,
    } satisfies ByteDanceVideoModelOptions,
  },
});
```

### 多参考图生视频

使用 Seedance 1.0 Lite I2V 模型时，你可以提供多张参考图像（1-4 张），模型会据此忠实地还原物体的形状、颜色与纹理：

```ts
import { byteDance, type ByteDanceVideoModelOptions } from '@ai-sdk/bytedance';
import { experimental_generateVideo as generateVideo } from 'ai';

const { video } = await generateVideo({
  model: byteDance.video('seedance-1-0-lite-i2v-250428'),
  prompt:
    'A boy wearing glasses and a blue T-shirt from [Image 1] and a corgi dog from [Image 2], sitting on the lawn from [Image 3], in 3D cartoon style',
  aspectRatio: '16:9',
  duration: 5,
  providerOptions: {
    bytedance: {
      referenceImages: [
        'https://example.com/boy.png',
        'https://example.com/corgi.png',
        'https://example.com/lawn.png',
      ],
      watermark: false,
    } satisfies ByteDanceVideoModelOptions,
  },
});
```

### 参考视频

Seedance 2.0 支持参考视频，用于引导生成视频的风格、运动或构图：

```ts
import { byteDance, type ByteDanceVideoModelOptions } from '@ai-sdk/bytedance';
import { experimental_generateVideo as generateVideo } from 'ai';

const { video } = await generateVideo({
  model: byteDance.video('dreamina-seedance-2-0-260128'),
  prompt:
    'First-person perspective promotional ad, using the composition and camera movement from the reference video',
  aspectRatio: '16:9',
  duration: 4,
  providerOptions: {
    bytedance: {
      referenceVideos: ['https://example.com/reference-video.mp4'],
      watermark: false,
    } satisfies ByteDanceVideoModelOptions,
  },
});
```

### 参考音频

Seedance 2.0 支持参考音频，可用作生成视频的背景音乐或音效：

```ts
import { byteDance, type ByteDanceVideoModelOptions } from '@ai-sdk/bytedance';
import { experimental_generateVideo as generateVideo } from 'ai';

const { video } = await generateVideo({
  model: byteDance.video('dreamina-seedance-2-0-260128'),
  prompt: 'A serene mountain landscape at sunrise with gentle camera movement',
  aspectRatio: '16:9',
  duration: 4,
  providerOptions: {
    bytedance: {
      referenceAudio: ['https://example.com/background-music.mp3'],
      generateAudio: true,
      watermark: false,
    } satisfies ByteDanceVideoModelOptions,
  },
});
```

### 调用方管理的回调

使用 `experimental_startVideo({ model, prompt, webhookUrl })` 注册一个由应用自己持有的回调接收器。SDK 会将 `webhookUrl` 作为 `callback_url` 转发，并优先于 `providerOptions.bytedance.callback_url`。省略 `webhookUrl` 时，原始的 `callback_url` 会原样透传。

[BytePlus 回调协议](https://docs.byteplus.com/en/docs/ModelArk/1520757)会发送进度通知（`'queued'` 或 `'running'`）以及终止通知（`'succeeded'`、`'failed'` 或 `'expired'`）。你的接收器必须过滤进度通知，并将回调与任务关联起来。使用 `experimental_getVideoStatus(model, { operation })` 并传入 `experimental_startVideo` 返回的 operation，即可在收到终止通知后查询状态并获取结果。已过期的任务会返回错误状态以及提供商的诊断详情。

这些模型有意不暴露 `handleWebhookOption`，因为其回调协议要求接收器能够感知进度。核心的 [`generateVideo({ webhook })`](/docs/reference/ai-sdk-core/generate-video) 会回退到轮询，而不会调用 webhook 工厂。直接调用 `generateVideo()` 同样采用轮询。Workflow 现有的原生 webhook 能力检查会拒绝将这些直连提供商模型用于基于 webhook 的生成；如需调用方管理的回调，请使用显式的 start/status 流程。

### 视频模型选项

以下选项可通过 `providerOptions.bytedance` 使用。你可以用 `ByteDanceVideoModelOptions` 为其标注类型。

#### 生成选项

- **watermark** _boolean_

  是否为生成的视频添加水印。

- **generateAudio** _boolean_

  是否为视频生成同步音频。由 Seedance 1.5 Pro 和 Seedance 2.0 支持。

- **cameraFixed** _boolean_

  是否在生成过程中固定镜头。

- **returnLastFrame** _boolean_

  是否返回生成视频的最后一帧。对连续生成多段视频很有用。

- **serviceTier** _'default' | 'flex'_

  推理层级。`'default'` 为在线推理。`'flex'` 为离线推理，价格为 50%，但延迟更高（响应时间在小时量级）。

- **draft** _boolean_

  启用草稿采样模式，以较低成本生成预览。仅 Seedance 1.5 Pro 支持。会生成 480p 预览视频，便于在正式生成全画质视频前快速迭代。

#### 图像输入选项

- **lastFrameImage** _string_

  首尾帧视频生成中最后一帧图像的 URL。模型会在首帧（通过 `image` 提示词提供）与该尾帧之间生成平滑过渡。由 Seedance 1.5 Pro、1.0 Pro 和 1.0 Lite I2V 支持。

- **referenceImages** _string[]_

  多参考图生视频中参考图像 URL 的数组。模型会从每张图像中提取关键特征并在视频中还原。在提示词中使用 `[Image 1]`、`[Image 2]` 等来引用具体图像。

#### 媒体参考选项

- **referenceVideos** _string[]_

  参考视频 URL 数组（最多 3 个，每个最长 15 秒），用于参考引导的视频生成。模型会利用参考视频引导风格、运动或构图。由 Seedance 2.0 支持。

- **referenceAudio** _string[]_

  参考音频 URL 数组（最多 3 个，每个最长 15 秒），用于音频引导的视频生成。模型会将参考音频用作背景音乐或同步音效。支持 data URI（如 `data:audio/wav;base64,...`）。由 Seedance 2.0 支持。

#### 轮询选项

ByteDance 视频生成基于任务：提供商创建一个任务，AI SDK 轮询该任务直至完成。通过 [`generateVideo()`](/docs/reference/ai-sdk-core/generate-video) 的顶层 `poll` 选项配置轮询：

已配置的 ByteDance API 来源在首次状态请求时被信任，而每次重定向到其他来源前都会先进行校验。

```ts
const { video } = await generateVideo({
  model: byteDance.video('seedance-1-0-pro-250528'),
  prompt: 'A futuristic city with flying cars',
  poll: {
    intervalMs: 2000, // how often to check the task (default: 5000)
    timeoutMs: 900000, // give up after 15 minutes (default: 600000)
  },
});
```

<Note>
  `pollIntervalMs` 和 `pollTimeoutMs` 提供商选项已弃用且会被忽略，传入任一都会发出警告。视频生成可能耗时数分钟，对于耗时较长的任务，请将 `poll.timeoutMs` 调高到 10 分钟默认值以上。
</Note>
