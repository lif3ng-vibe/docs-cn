# Cheaper Inference 提供商

[Cheaper Inference](https://cheaperinference.com/) 是一个 API 网关，通过 OpenAI 兼容 API 提供对来自多家 AI 实验室模型的访问。你可以通过 `@ai-sdk/openai-compatible` 模块，将其 Chat Completions 端点与 AI SDK 一起使用。

## 设置

安装 OpenAI Compatible 提供商：

<InstallPackages packages="@ai-sdk/openai-compatible" />

创建一个 Cheaper Inference API key，并将其设置为服务端环境变量：

```bash
export CHEAPER_INFERENCE_API_KEY=your-api-key
```

有关创建 API key 的说明，请参阅 [Cheaper Inference 集成指南](https://cheaperinference.com/docs/integrations#framework-vercel)。

## 提供商实例

使用 `createOpenAICompatible` 创建一个 Cheaper Inference 提供商实例：

```ts
import { createOpenAICompatible } from '@ai-sdk/openai-compatible';

const cheaperInference = createOpenAICompatible({
  name: 'cheaper-inference',
  apiKey: process.env.CHEAPER_INFERENCE_API_KEY,
  baseURL: 'https://api.cheaperinference.com/v1',
});
```

`apiKey` 设置会将你的 key 作为 Bearer token 放入 `Authorization` 请求头发送。

## 语言模型

将 Cheaper Inference 模型 ID 传给提供商实例即可创建语言模型：

```ts
const model = cheaperInference('gpt-5.4');
```

### 生成文本

使用 `generateText` 通过该模型生成文本：

```ts
import { createOpenAICompatible } from '@ai-sdk/openai-compatible';
import { generateText } from 'ai';

const cheaperInference = createOpenAICompatible({
  name: 'cheaper-inference',
  apiKey: process.env.CHEAPER_INFERENCE_API_KEY,
  baseURL: 'https://api.cheaperinference.com/v1',
});

const { text } = await generateText({
  model: cheaperInference('gpt-5.4'),
  prompt: 'Explain what an API gateway does in one sentence.',
});

console.log(text);
```

### 流式生成文本

使用 `streamText` 在文本生成的同时以流式方式输出：

```ts
import { createOpenAICompatible } from '@ai-sdk/openai-compatible';
import { streamText } from 'ai';

const cheaperInference = createOpenAICompatible({
  name: 'cheaper-inference',
  apiKey: process.env.CHEAPER_INFERENCE_API_KEY,
  baseURL: 'https://api.cheaperinference.com/v1',
});

const result = streamText({
  model: cheaperInference('gpt-5.4'),
  prompt: 'Count from 1 to 5, separated by spaces.',
});

for await (const textPart of result.textStream) {
  process.stdout.write(textPart);
}
```

## 支持的模型与能力

本集成使用 Cheaper Inference 的 OpenAI 兼容 Chat Completions 端点进行文本生成与流式输出。对工具、视觉（vision）以及其他模型特定特性的支持取决于所选模型。

模型目录会随时间变化。请使用需要鉴权的 [`GET /models`](https://api.cheaperinference.com/v1/models) 端点查询当前的模型 ID、能力与定价。
