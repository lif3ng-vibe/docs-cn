# LangSmith 可观测性

[LangSmith](https://docs.langchain.com/langsmith/) 是一个用于构建生产级 LLM 应用（LLM application）的平台。
它让你能够密切监控并评估自己的应用，从而快速且放心地交付。

无需使用 LangChain 的开源框架。

<Note>
  本指南的另一个版本也可在 [LangSmith
  文档](https://docs.langchain.com/langsmith/trace-with-vercel-ai-sdk)中查看。
  如果你使用的是 AI SDK v4 与较旧版本的 `langsmith` 客户端，请参阅该页面链接的旧版指南。
</Note>

## 安装

<Note>本指南中的步骤假定你使用 `langsmith>=0.3.63`。</Note>

安装一个 [AI SDK 模型提供商](/providers/ai-sdk-providers)与 [LangSmith 客户端 SDK](https://npmjs.com/package/langsmith)。
下面的代码片段将使用 [AI SDK 的 OpenAI 提供商](/providers/ai-sdk-providers/openai)，但你也可以使用任何[其他受支持的提供商](/providers/ai-sdk-providers)。

<InstallPackages packages="@ai-sdk/openai langsmith" />

接下来，设置所需的环境变量。

```bash
export LANGCHAIN_TRACING=true
export LANGCHAIN_API_KEY=<your-api-key>

export OPENAI_API_KEY=<your-openai-api-key> # The examples use OpenAI (replace with your selected provider)
```

## 追踪日志

要开始追踪，你需要在代码开头导入并调用 `wrapAISDK` 方法：

```ts highlight="6"
import { openai } from '@ai-sdk/openai';
import * as ai from 'ai';

import { wrapAISDK } from 'langsmith/experimental/vercel';

const { generateText, streamText } = wrapAISDK(ai);

await generateText({
  model: openai('gpt-5.4-nano'),
  prompt: 'Write a vegetarian lasagna recipe for 4 people.',
});
```

你应该会在 LangSmith 仪表盘中看到[类似这样的](https://smith.langchain.com/public/4f0e689e-c801-44d3-8857-93b47ab100cc/r) trace。

你也可以追踪带有工具调用的运行（run）：

```ts
import * as ai from 'ai';
import { tool, isStepCount } from 'ai';
import { openai } from '@ai-sdk/openai';
import { z } from 'zod';

import { wrapAISDK } from 'langsmith/experimental/vercel';

const { generateText, streamText } = wrapAISDK(ai);

await generateText({
  model: openai('gpt-5.4-nano'),
  messages: [
    {
      role: 'user',
      content: 'What are my orders and where are they? My user ID is 123',
    },
  ],
  tools: {
    listOrders: tool({
      description: 'list all orders',
      inputSchema: z.object({ userId: z.string() }),
      execute: async ({ userId }) =>
        `User ${userId} has the following orders: 1`,
    }),
    viewTrackingInformation: tool({
      description: 'view tracking information for a specific order',
      inputSchema: z.object({ orderId: z.string() }),
      execute: async ({ orderId }) =>
        `Here is the tracking information for ${orderId}`,
    }),
  },
  stopWhen: isStepCount(5),
});
```

结果会得到[类似这样的](https://smith.langchain.com/public/6075fa2c-d255-4885-a66a-4fc798afaa9f/r) trace。

其他 AI SDK 方法可以完全照常使用。

### 配合 `traceable` 使用

你可以在 AI SDK 调用外层或 AI SDK 工具调用内部包裹 `traceable` 调用。如果你想
在 LangSmith 中把多个运行归为一组，这会很有用：

```ts
import * as ai from 'ai';
import { tool, isStepCount } from 'ai';
import { openai } from '@ai-sdk/openai';
import { z } from 'zod';

import { traceable } from 'langsmith/traceable';
import { wrapAISDK } from 'langsmith/experimental/vercel';

const { generateText, streamText } = wrapAISDK(ai);

const wrapper = traceable(
  async (input: string) => {
    const { text } = await generateText({
      model: openai('gpt-5.4-nano'),
      messages: [
        {
          role: 'user',
          content: input,
        },
      ],
      tools: {
        listOrders: tool({
          description: 'list all orders',
          inputSchema: z.object({ userId: z.string() }),
          execute: async ({ userId }) =>
            `User ${userId} has the following orders: 1`,
        }),
        viewTrackingInformation: tool({
          description: 'view tracking information for a specific order',
          inputSchema: z.object({ orderId: z.string() }),
          execute: async ({ orderId }) =>
            `Here is the tracking information for ${orderId}`,
        }),
      },
      stopWhen: isStepCount(5),
    });
    return text;
  },
  {
    name: 'wrapper',
  },
);

await wrapper('What are my orders and where are they? My user ID is 123.');
```

得到的 trace 会[像这样](https://smith.langchain.com/public/ff25bc26-9389-4798-8b91-2bdcc95d4a8e/r)。

## 在无服务器环境中追踪

在无服务器（serverless）环境中追踪时，你必须等待所有运行刷新（flush）完毕，环境才能关闭。
具体示例请参阅 LangSmith 文档的[这一节](https://docs.langchain.com/langsmith/trace-with-vercel-ai-sdk#tracing-in-serverless-environments)。
