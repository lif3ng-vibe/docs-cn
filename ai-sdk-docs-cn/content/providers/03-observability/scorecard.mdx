# Scorecard

[Scorecard](https://www.scorecard.io/) 是一个用于监控与评估 LLM 应用的可观测性平台。
与 AI SDK 集成后，你可以使用 Scorecard 对你的 LLM 提供商（provider）、提示词（prompt）和应用流程进行追踪、监控与分析。

## 设置

Scorecard 支持 [AI SDK 遥测数据](/docs/ai-sdk-core/telemetry)。
你需要先在 https://app.scorecard.io 注册，并从你的[设置页面](https://app.scorecard.io/settings)获取 API Key。

### Next.js

要让 AI SDK 将遥测数据发送到 Scorecard，请先在项目中设置这些环境变量：

```bash
OTEL_EXPORTER_OTLP_ENDPOINT=https://tracing.scorecard.io/otel/v1/traces
OTEL_EXPORTER_OTLP_HEADERS="Authorization=Bearer <Your Scorecard API Key>"
```

接下来，安装 `@ai-sdk/otel`，并在项目根目录创建 `instrumentation.ts` 文件，用于初始化 OpenTelemetry 并注册 AI SDK 遥测集成：

```typescript filename="instrumentation.ts"
import { registerTelemetry } from 'ai';
import { LegacyOpenTelemetry } from '@ai-sdk/otel';
import { registerOTel } from '@vercel/otel';

registerTelemetry(new LegacyOpenTelemetry());

export function register() {
  registerOTel({
    serviceName: 'my-service-name',
  });
}
```

集成注册完成后，所有 AI SDK 调用都会自动捕获遥测数据：

```typescript
import { generateText } from 'ai';
import { openai } from '@ai-sdk/openai';

const result = await generateText({
  model: openai('gpt-6-luna'),
  prompt: 'Tell me a joke',
});
```

## 你会在 Scorecard 中看到什么

集成完成后，你可以在 Scorecard 控制台中查看：

- **LLM 调用追踪**：每条 AI SDK 调用的详细信息
- **性能指标**：延迟、token 用量与成本追踪
- **模型信息**：使用了哪些模型与提供商
- **自定义上下文**：你通过 `context` 选项提供的任何额外上下文
- **错误追踪**：失败的请求与调试信息
- **用量分析**：LLM 用量的模式与趋势
