# Hono

你可以在 [Hono](https://hono.dev/) 服务器中使用 AI SDK 生成文本与对象，并将其流式传输给客户端。

## 示例

以下示例会启动一个监听 8080 端口的简单 HTTP 服务器。例如可以用 `curl` 测试它：

```bash
curl -X POST http://localhost:8080
```

<Note>
  这些示例使用 Vercel AI Gateway。请确保你的 AI Gateway API key 已设置在
  `AI_GATEWAY_API_KEY` 环境变量中。
</Note>

**完整示例**：[github.com/vercel/ai/examples/hono](https://github.com/vercel/ai/tree/main/examples/hono)

### UI 消息流

你可以将 `createUIMessageStreamResponse` 与 `toUIMessageStream` 结合使用，创建格式正确的流式响应。

```ts filename='index.ts'
import { serve } from '@hono/node-server';
import {
  createUIMessageStreamResponse,
  streamText,
  toUIMessageStream,
} from 'ai';
import { Hono } from 'hono';

const app = new Hono();

app.post('/', async c => {
  const result = streamText({
    model: 'openai/gpt-6-astra',
    prompt: 'Invent a new holiday and describe its traditions.',
  });
  return createUIMessageStreamResponse({
    stream: toUIMessageStream({ stream: result.stream }),
  });
});

serve({ fetch: app.fetch, port: 8080 });
```

### 文本流

你可以将 `createTextStreamResponse` 与 `toTextStream` 结合使用，返回文本流响应。

```ts filename='index.ts'
import { serve } from '@hono/node-server';
import { createTextStreamResponse, streamText, toTextStream } from 'ai';
import { Hono } from 'hono';

const app = new Hono();

app.post('/text', async c => {
  const result = streamText({
    model: 'openai/gpt-6-astra',
    prompt: 'Write a short poem about coding.',
  });
  return createTextStreamResponse({
    stream: toTextStream({ stream: result.stream }),
  });
});

serve({ fetch: app.fetch, port: 8080 });
```

### 发送自定义数据

你可以使用 `createUIMessageStream` 和 `createUIMessageStreamResponse` 向客户端发送自定义数据。

```ts filename='index.ts'
import { serve } from '@hono/node-server';
import {
  createUIMessageStream,
  createUIMessageStreamResponse,
  streamText,
  toUIMessageStream,
} from 'ai';
import { Hono } from 'hono';

const app = new Hono();

app.post('/stream-data', async c => {
  // immediately start streaming the response
  const stream = createUIMessageStream({
    execute: ({ writer }) => {
      writer.write({ type: 'start' });

      writer.write({
        type: 'data-custom',
        data: {
          custom: 'Hello, world!',
        },
      });

      const result = streamText({
        model: 'openai/gpt-6-astra',
        prompt: 'Invent a new holiday and describe its traditions.',
      });

      writer.merge(
        toUIMessageStream({
          stream: result.stream,
          sendStart: false,
          onError: error => {
            // Error messages are masked by default for security reasons.
            // If you want to expose the error message to the client, you can do so here:
            return error instanceof Error ? error.message : String(error);
          },
        }),
      );
    },
  });
  return createUIMessageStreamResponse({ stream });
});

serve({ fetch: app.fetch, port: 8080 });
```
