# Express

你可以在 [Express](https://expressjs.com/) 服务器中使用 AI SDK 生成文本与对象，并将其流式传输给客户端。

## 示例

以下示例会启动一个监听 8080 端口的简单 HTTP 服务器。例如可以用 `curl` 测试它：

```bash
curl -X POST http://localhost:8080
```

<Note>
  这些示例使用 Vercel AI Gateway。请确保你的 AI Gateway API key 已设置在
  `AI_GATEWAY_API_KEY` 环境变量中。
</Note>

**完整示例**：[github.com/vercel/ai/examples/express](https://github.com/vercel/ai/tree/main/examples/express)

### UI 消息流

你可以使用 `pipeUIMessageStreamToResponse` 辅助函数把流数据通过管道写入服务器响应。

```ts filename='index.ts'
import {
  pipeUIMessageStreamToResponse,
  streamText,
  toUIMessageStream,
} from 'ai';
import express, { Request, Response } from 'express';

const app = express();

app.post('/', async (req: Request, res: Response) => {
  const result = streamText({
    model: 'openai/gpt-6-astra',
    prompt: 'Invent a new holiday and describe its traditions.',
  });

  pipeUIMessageStreamToResponse({
    response: res,
    stream: toUIMessageStream({ stream: result.stream }),
  });
});

app.listen(8080, () => {
  console.log(`Example app listening on port ${8080}`);
});
```

### 发送自定义数据

`pipeUIMessageStreamToResponse` 可用于向客户端发送自定义数据。

```ts filename='index.ts'
import {
  createUIMessageStream,
  pipeUIMessageStreamToResponse,
  streamText,
  toUIMessageStream,
} from 'ai';
import express, { Request, Response } from 'express';

const app = express();

app.post('/custom-data-parts', async (req: Request, res: Response) => {
  pipeUIMessageStreamToResponse({
    response: res,
    stream: createUIMessageStream({
      execute: async ({ writer }) => {
        writer.write({ type: 'start' });

        writer.write({
          type: 'data-custom',
          data: {
            custom: 'Hello, world!',
          },
        });

        const result = streamText({
          model: 'openai/gpt-6-astra',
          prompt: 'Invent a new holiday and describe its traditions.',
        });

        writer.merge(
          toUIMessageStream({ stream: result.stream, sendStart: false }),
        );
      },
    }),
  });
});

app.listen(8080, () => {
  console.log(`Example app listening on port ${8080}`);
});
```

### 文本流

你可以使用 `pipeTextStreamToResponse` 向客户端发送文本流。

```ts filename='index.ts'
import { pipeTextStreamToResponse, streamText, toTextStream } from 'ai';
import express, { Request, Response } from 'express';

const app = express();

app.post('/', async (req: Request, res: Response) => {
  const result = streamText({
    model: 'openai/gpt-6-astra',
    prompt: 'Invent a new holiday and describe its traditions.',
  });

  pipeTextStreamToResponse({
    response: res,
    stream: toTextStream({ stream: result.stream }),
  });
});

app.listen(8080, () => {
  console.log(`Example app listening on port ${8080}`);
});
```
