# Get started with OpenAI o3-mini

<Note>
  本指南介绍 o3-mini，并有意保留其模型 ID。如需当前模型，请参阅 [OpenAI 提供商文档](/providers/ai-sdk-providers/openai)。
</Note>

随着 [OpenAI o3-mini 模型的发布](https://openai.com/index/openai-o3-mini/)，现在是开始构建 AI 应用的最佳时机，尤其是那些需要复杂 STEM 推理能力的应用。

[AI SDK](/) 是一个强大的 TypeScript 工具包，用于结合 OpenAI o3-mini 这样的大型语言模型（LLM）以及 React、Next.js、Vue、Svelte、Node.js 等流行框架构建 AI 应用。

## OpenAI o3-mini

OpenAI 最近发布了一款针对 STEM 推理优化的新 AI 模型，在科学、数学和编程任务上表现出色。o3-mini 在这些领域达到了 o1 的性能，同时响应更快、成本更低。该模型支持工具调用、结构化输出和系统消息，是广泛应用的绝佳选择。

o3-mini 提供三个推理力度（reasoning effort）级别：

1. [**Low**]：为速度优化，同时保持可靠的推理能力
2. [**Medium**]：均衡方案，与 o1 的性能水平相当
3. [**High**]：推理能力增强，在许多 STEM 领域超过 o1

### 基准测试

OpenAI o3-mini 在各个技术领域展现出亮眼的表现：

- 在 AIME 竞赛数学题上达到 87.3% 的准确率
- 在博士级科学问题（GPQA Diamond）上达到 79.7% 的准确率
- 在竞赛编程（Codeforces）上取得 2130 Elo 等级分
- 在经验证的软件工程任务（SWE-bench）上达到 49.3% 的准确率

<Note>这些基准测试结果使用的是 high 推理力度设置。</Note>

### o3-mini 的提示词工程

o3-mini 模型在使用简单直接的提示词时表现最佳。一些提示词工程技巧，如少样本提示（few-shot prompting）或指示模型"逐步思考"，可能无法提升性能，有时甚至会适得其反。以下是一些最佳实践：

1. 保持提示词简单直接：该模型擅长理解并响应简短清晰的指令，无需冗长的指引。
2. 避免思维链提示：由于该模型会在内部进行推理，提示它"逐步思考"或"解释你的推理"是不必要的。
3. 使用分隔符提升清晰度：使用三引号、XML 标签或小节标题等分隔符来清晰标示输入的不同部分。

## AI SDK 快速上手

AI SDK 是一款 TypeScript 工具包，旨在帮助开发者使用 React、Next.js、Vue、Svelte、Node.js 等构建 AI 驱动的应用。将 LLM 集成到应用中相当复杂，且高度依赖于你所使用的具体模型提供商（provider）。

AI SDK 抽象掉了不同模型提供商之间的差异，消除了构建聊天机器人的样板代码，并让你能够超越纯文本输出，生成丰富、可交互的组件。

AI SDK 的核心是 [AI SDK Core](/docs/ai-sdk-core/overview)，它提供了调用任意 LLM 的统一 API。使用 AI SDK 调用 OpenAI o3-mini 只需要下面这段代码：

```ts
import { generateText } from 'ai';
import { openai } from '@ai-sdk/openai';

const { text } = await generateText({
  model: openai('o3-mini'),
  prompt: 'Explain the concept of quantum entanglement.',
});
```

<Note>
  要使用 o3-mini，你必须使用 1.1.9 或更高版本的 @ai-sdk/openai。
</Note>

<Note>
  系统消息会自动转换为 OpenAI developer 消息。
</Note>

### 调整推理力度

你可以通过 `reasoningEffort` 参数控制 o3-mini 消耗的推理力度。该参数可设置为 `low`、`medium` 或 `high`，用于调整模型在生成响应前花在内部推理上的时间与算力。

```ts highlight="9"
import { generateText } from 'ai';
import { openai } from '@ai-sdk/openai';

// Reduce reasoning effort for faster responses
const { text } = await generateText({
  model: openai('o3-mini'),
  prompt: 'Explain quantum entanglement briefly.',
  providerOptions: {
    openai: { reasoningEffort: 'low' },
  },
});
```

### 生成结构化数据

虽然文本生成很有用，但你可能还想生成结构化的 JSON 数据。例如，你可能想从文本中提取信息、对数据进行分类，或生成合成数据。AI SDK Core 提供了 [`generateText`](/docs/reference/ai-sdk-core/generate-text) 和 [`streamText`](/docs/reference/ai-sdk-core/stream-text) 搭配 `Output` 来生成结构化数据，让你能够将模型输出约束到特定的 schema。

```ts
import { generateText, Output } from 'ai';
import { openai } from '@ai-sdk/openai';
import { z } from 'zod';

const { output } = await generateText({
  model: openai('o3-mini'),
  output: Output.object({
    schema: z.object({
      recipe: z.object({
        name: z.string(),
        ingredients: z.array(
          z.object({ name: z.string(), amount: z.string() }),
        ),
        steps: z.array(z.string()),
      }),
    }),
  }),
  prompt: 'Generate a lasagna recipe.',
});
```

这段代码会生成一个符合指定 zod schema 的类型安全菜谱。

### 在 AI SDK 中使用工具

o3-mini 开箱即支持工具调用，使其能够与外部系统交互并执行离散任务。下面是在 AI SDK 中使用工具调用的示例：

```ts
import { generateText, tool } from 'ai';
import { openai } from '@ai-sdk/openai';
import { z } from 'zod';

const { text } = await generateText({
  model: openai('o3-mini'),
  prompt: 'What is the weather like today in San Francisco?',
  tools: {
    getWeather: tool({
      description: 'Get the weather in a location',
      inputSchema: z.object({
        location: z.string().describe('The location to get the weather for'),
      }),
      execute: async ({ location }) => ({
        location,
        temperature: 72 + Math.floor(Math.random() * 21) - 10,
      }),
    }),
  },
});
```

在这个示例中，`getWeather` 工具让模型能够获取实时天气数据（为简化起见做了模拟），增强了它提供准确、最新信息的能力。

### 构建交互式界面

AI SDK Core 可以与 AI SDK 的另一个强大组件 [AI SDK UI](/docs/ai-sdk-ui/overview) 搭配使用，简化使用 Next.js、Nuxt、SvelteKit 等流行框架构建聊天、补全和助手界面的过程。

AI SDK UI 提供了强大的抽象，简化了在前端管理聊天流和 UI 更新的复杂任务，让你能够更高效地开发生动的 AI 驱动界面。

通过三个主要 Hook——[`useChat`](/docs/reference/ai-sdk-ui/use-chat)、[`useCompletion`](/docs/reference/ai-sdk-ui/use-completion) 和 [`useObject`](/docs/reference/ai-sdk-ui/use-object)——你可以在应用中集成实时聊天、文本补全、流式 JSON 和交互式助手功能。

让我们来探索如何结合 [Next.js](https://nextjs.org)、AI SDK 与 OpenAI o3-mini 构建一个聊天机器人：

在新建的 Next.js 应用中，先安装 AI SDK 和 OpenAI 提供商：

<Snippet text="pnpm install ai @ai-sdk/openai @ai-sdk/react" />

然后，为聊天端点创建一个 Route Handler：

```tsx filename="app/api/chat/route.ts"
import { openai } from '@ai-sdk/openai';
import {
  convertToModelMessages,
  createUIMessageStreamResponse,
  streamText,
  toUIMessageStream,
  UIMessage,
} from 'ai';

// Allow responses up to 5 minutes
export const maxDuration = 300;

export async function POST(req: Request) {
  const { messages }: { messages: UIMessage[] } = await req.json();

  const result = streamText({
    model: openai('o3-mini'),
    messages: await convertToModelMessages(messages),
  });

  return createUIMessageStreamResponse({
    stream: toUIMessageStream({ stream: result.stream }),
  });
}
```

最后，更新根页面（`app/page.tsx`）以使用 `useChat` Hook：

```tsx filename="app/page.tsx"
'use client';

import { useChat } from '@ai-sdk/react';
import { type FormEvent, useState } from 'react';

export default function Page() {
  const { messages, sendMessage } = useChat();
  const [input, setInput] = useState('');

  function handleSubmit(event: FormEvent<HTMLFormElement>) {
    event.preventDefault();

    if (input.trim()) {
      sendMessage({ text: input });
      setInput('');
    }
  }

  return (
    <>
      {messages.map(message => (
        <div key={message.id}>
          {message.role === 'user' ? 'User: ' : 'AI: '}
          {message.parts.map((part, index) =>
            part.type === 'text' ? <span key={index}>{part.text}</span> : null,
          )}
        </div>
      ))}
      <form onSubmit={handleSubmit}>
        <input
          name="prompt"
          value={input}
          onChange={event => setInput(event.currentTarget.value)}
        />
        <button type="submit">Submit</button>
      </form>
    </>
  );
}
```

根页面（`app/page.tsx`）上的 useChat Hook 会在用户提交消息时向你的 AI 提供商端点（`app/api/chat/route.ts`）发起请求。随后消息会显示在聊天 UI 中。

1. 浏览 [ai-sdk.dev/docs](/docs) 上的文档，了解 AI SDK 的全部能力。

5. 查看 [vercel.com/templates?type=ai](https://vercel.com/templates?type=ai) 上开箱即用的 AI 模板。
