# Building an AI Agent in Slack with the AI SDK

在本指南中，你将学习如何构建一个由 AI SDK 驱动的 Slackbot。该机器人能够利用线程的完整上下文，响应私信以及频道中的提及。

## Slack 应用设置

在开始构建之前，你需要创建并配置一个 Slack 应用：

1. 打开 [api.slack.com/apps](https://api.slack.com/apps)
2. 点击 “Create New App” 并选择 “From scratch”
3. 为应用命名并选择你的工作区
4. 在 “OAuth & Permissions” 下，添加以下 bot token scopes：
   - `app_mentions:read`
   - `chat:write`
   - `im:history`
   - `im:write`
   - `assistant:write`
5. 把应用安装到你的工作区（“OAuth Tokens” 小节下的按钮）
6. 复制 Bot User OAuth Token 和 Signing Secret，下一步会用到
7. 在 App Home -> Show Tabs -> Chat Tab 下，勾选 “Allow users to send Slash commands and messages from the chat tab”

## 项目结构

起始仓库已包含：

- Slack 工具函数（`lib/slack-utils.ts`），包括校验传入请求、把 Slack 线程转换为 AI SDK 兼容的消息格式、获取 Slackbot 用户 ID 等函数
- 通用工具函数（`lib/utils.ts`），包括 Exa 的初始设置
- 处理不同类型 Slack 事件的文件（`lib/handle-messages.ts` 和 `lib/handle-app-mention.ts`）
- 一个用于 Slack 事件的 API 端点（`POST`）（`api/events.ts`）

## 事件处理器

首先，看看我们的 API 路由（`api/events.ts`）：

```typescript
import type { SlackEvent } from '@slack/web-api';
import {
  assistantThreadMessage,
  handleNewAssistantMessage,
} from '../lib/handle-messages';
import { waitUntil } from '@vercel/functions';
import { handleNewAppMention } from '../lib/handle-app-mention';
import { verifyRequest, getBotId } from '../lib/slack-utils';

export async function POST(request: Request) {
  const rawBody = await request.text();
  const payload = JSON.parse(rawBody);
  const requestType = payload.type as 'url_verification' | 'event_callback';

  // See https://api.slack.com/events/url_verification
  if (requestType === 'url_verification') {
    return new Response(payload.challenge, { status: 200 });
  }

  await verifyRequest({ requestType, request, rawBody });

  try {
    const botUserId = await getBotId();

    const event = payload.event as SlackEvent;

    if (event.type === 'app_mention') {
      waitUntil(handleNewAppMention(event, botUserId));
    }

    if (event.type === 'assistant_thread_started') {
      waitUntil(assistantThreadMessage(event));
    }

    if (
      event.type === 'message' &&
      !event.subtype &&
      event.channel_type === 'im' &&
      !event.bot_id &&
      !event.bot_profile &&
      event.bot_id !== botUserId
    ) {
      waitUntil(handleNewAssistantMessage(event, botUserId));
    }

    return new Response('Success!', { status: 200 });
  } catch (error) {
    console.error('Error generating response', error);
    return new Response('Error generating response', { status: 500 });
  }
}
```

该文件定义了一个 `POST` 函数来处理来自 Slack 的传入请求。首先，你检查请求类型，判断它是否为 URL 验证请求。如果是，就用 Slack 提供的 challenge 字符串作出响应。如果是事件回调，你先验证请求，然后就可以访问事件数据。这里就是你可以实现事件处理逻辑的地方。

接下来你处理三种类型的事件：`app_mention`、`assistant_thread_started` 和 `message`：

- 对于 `app_mention`，你用事件和 bot 用户 ID 调用 `handleNewAppMention`。
- 对于 `assistant_thread_started`，你用事件调用 `assistantThreadMessage`。
- 对于 `message`，你用事件和 bot 用户 ID 调用 `handleNewAssistantMessage`。

最后，你向 Slack 返回一条成功消息。注意，每个处理函数都包裹在 `waitUntil` 函数中。来看看这是什么意思，以及为什么它很重要。

### waitUntil 函数

Slack 期望在 3 秒内收到响应，以确认请求正在被处理。然而，生成 AI 响应可能需要更长时间。如果你没有在 3 秒内响应 Slack 请求，Slack 会再次发送请求，导致你的 API 路由被再次调用、LLM 被再次调用，最终用户又会收到一条响应。为解决这个问题，你可以使用 `waitUntil` 函数，它允许你在响应发出之后继续运行 AI 逻辑，而不会阻塞响应本身。

这意味着你的 API 端点会：

1. 立即响应 Slack（3 秒内）
2. 异步继续处理该消息
3. 在 AI 响应就绪时发送

## 事件处理逻辑

来看看目前每种事件类型是如何处理的。

### 应用提及

当用户在频道中提及你的机器人时，会触发 `app_mention` 事件。`handle-app-mention.ts` 中的 `handleNewAppMention` 函数处理这些提及：

1. 检查消息是否来自机器人，以避免无限响应循环
2. 创建一个状态更新器，显示机器人正在“思考”
3. 如果提及发生在线程中，则获取线程历史
4. 用消息内容调用 LLM（使用你将在下一节实现的 `generateResponse` 函数）
5. 用 AI 响应更新最初的“思考中”消息

以下是 `handleNewAppMention` 函数的代码：

```typescript filename="lib/handle-app-mention.ts"
import { AppMentionEvent } from '@slack/web-api';
import { client, getThread } from './slack-utils';
import { generateResponse } from './generate-response';

const updateStatusUtil = async (
  initialStatus: string,
  event: AppMentionEvent,
) => {
  const initialMessage = await client.chat.postMessage({
    channel: event.channel,
    thread_ts: event.thread_ts ?? event.ts,
    text: initialStatus,
  });

  if (!initialMessage || !initialMessage.ts)
    throw new Error('Failed to post initial message');

  const updateMessage = async (status: string) => {
    await client.chat.update({
      channel: event.channel,
      ts: initialMessage.ts as string,
      text: status,
    });
  };
  return updateMessage;
};

export async function handleNewAppMention(
  event: AppMentionEvent,
  botUserId: string,
) {
  console.log('Handling app mention');
  if (event.bot_id || event.bot_id === botUserId || event.bot_profile) {
    console.log('Skipping app mention');
    return;
  }

  const { thread_ts, channel } = event;
  const updateMessage = await updateStatusUtil('is thinking...', event);

  if (thread_ts) {
    const messages = await getThread(channel, thread_ts, botUserId);
    const result = await generateResponse(messages, updateMessage);
    updateMessage(result);
  } else {
    const result = await generateResponse(
      [{ role: 'user', content: event.text }],
      updateMessage,
    );
    updateMessage(result);
  }
}
```

接下来看看新的助手线程和消息是如何处理的。

### 助手线程消息

当用户与你的助手开启一个线程时，会触发 `assistant_thread_started` 事件。`handle-messages.ts` 中的 `assistantThreadMessage` 函数负责处理它：

1. 向线程发送一条欢迎消息
2. 设置建议提示词（prompt），帮助用户上手

以下是 `assistantThreadMessage` 函数的代码：

```typescript filename="lib/handle-messages.ts"
import type { AssistantThreadStartedEvent } from '@slack/web-api';
import { client } from './slack-utils';

export async function assistantThreadMessage(
  event: AssistantThreadStartedEvent,
) {
  const { channel_id, thread_ts } = event.assistant_thread;
  console.log(`Thread started: ${channel_id} ${thread_ts}`);
  console.log(JSON.stringify(event));

  await client.chat.postMessage({
    channel: channel_id,
    thread_ts: thread_ts,
    text: "Hello, I'm an AI assistant built with the AI SDK by Vercel!",
  });

  await client.assistant.threads.setSuggestedPrompts({
    channel_id: channel_id,
    thread_ts: thread_ts,
    prompts: [
      {
        title: 'Get the weather',
        message: 'What is the current weather in London?',
      },
      {
        title: 'Get the news',
        message: 'What is the latest Premier League news from the BBC?',
      },
    ],
  });
}
```

### 私信

对于发给你的机器人的私信，会触发 `message` 事件，由 `handle-messages.ts` 中的 `handleNewAssistantMessage` 函数处理：

1. 校验消息不是来自机器人
2. 更新状态，显示正在生成响应
3. 获取对话历史
4. 携带对话上下文调用 LLM
5. 把 LLM 的响应发布到线程

以下是 `handleNewAssistantMessage` 函数的代码：

```typescript filename="lib/handle-messages.ts"
import type { GenericMessageEvent } from '@slack/web-api';
import { client, getThread } from './slack-utils';
import { generateResponse } from './generate-response';

export async function handleNewAssistantMessage(
  event: GenericMessageEvent,
  botUserId: string,
) {
  if (
    event.bot_id ||
    event.bot_id === botUserId ||
    event.bot_profile ||
    !event.thread_ts
  )
    return;

  const { thread_ts, channel } = event;
  const updateStatus = updateStatusUtil(channel, thread_ts);
  updateStatus('is thinking...');

  const messages = await getThread(channel, thread_ts, botUserId);
  const result = await generateResponse(messages, updateStatus);

  await client.chat.postMessage({
    channel: channel,
    thread_ts: thread_ts,
    text: result,
    unfurl_links: false,
    blocks: [
      {
        type: 'section',
        text: {
          type: 'mrkdwn',
          text: result,
        },
      },
    ],
  });

  updateStatus('');
}
```

事件处理器就位后，现在来实现 AI 逻辑。

## 实现 AI 逻辑

应用的核心是 `lib/generate-response.ts` 中的 `generateResponse` 函数，它使用 AI SDK 处理消息并生成响应。

实现方式如下：

```typescript filename="lib/generate-response.ts"
import { generateText, ModelMessage } from 'ai';
__PROVIDER_IMPORT__;

export const generateResponse = async (
  messages: ModelMessage[],
  updateStatus?: (status: string) => void,
) => {
  const { text } = await generateText({
    model: __MODEL__,
    instructions: `You are a Slack bot assistant. Keep your responses concise and to the point.
    - Do not tag users.
    - Current date is: ${new Date().toISOString().split('T')[0]}`,
    messages,
  });

  // Convert markdown to Slack mrkdwn format
  return text.replace(/\[(.*?)\]\((.*?)\)/g, '<$2|$1>').replace(/\*\*/g, '*');
};
```

这个基础实现：

1. 使用 AI SDK 的 `generateText` 函数调用配置的模型
2. 提供系统提示词来引导模型的行为
3. 把响应转换为 Slack 的 markdown 格式

## 用工具增强

AI SDK 真正的威力来自让机器人执行操作的工具。我们来添加两个实用的工具：

```typescript filename="lib/generate-response.ts"
import { generateText, tool, ModelMessage, isStepCount } from 'ai';
__PROVIDER_IMPORT__;
import { z } from 'zod';
import { exa } from './utils';

export const generateResponse = async (
  messages: ModelMessage[],
  updateStatus?: (status: string) => void,
) => {
  const { text } = await generateText({
    model: __MODEL__,
    instructions: `You are a Slack bot assistant. Keep your responses concise and to the point.
    - Do not tag users.
    - Current date is: ${new Date().toISOString().split('T')[0]}
    - Always include sources in your final response if you use web search.`,
    messages,
    stopWhen: isStepCount(10),
    tools: {
      getWeather: tool({
        description: 'Get the current weather at a location',
        inputSchema: z.object({
          latitude: z.number(),
          longitude: z.number(),
          city: z.string(),
        }),
        execute: async ({ latitude, longitude, city }) => {
          updateStatus?.(`is getting weather for ${city}...`);

          const response = await fetch(
            `https://api.open-meteo.com/v1/forecast?latitude=${latitude}&longitude=${longitude}&current=temperature_2m,weathercode,relativehumidity_2m&timezone=auto`,
          );

          const weatherData = await response.json();
          return {
            temperature: weatherData.current.temperature_2m,
            weatherCode: weatherData.current.weathercode,
            humidity: weatherData.current.relativehumidity_2m,
            city,
          };
        },
      }),
      searchWeb: tool({
        description: 'Use this to search the web for information',
        inputSchema: z.object({
          query: z.string(),
          specificDomain: z
            .string()
            .nullable()
            .describe(
              'a domain to search if the user specifies e.g. bbc.com. Should be only the domain name without the protocol',
            ),
        }),
        execute: async ({ query, specificDomain }) => {
          updateStatus?.(`is searching the web for ${query}...`);
          const { results } = await exa.searchAndContents(query, {
            livecrawl: 'always',
            numResults: 3,
            includeDomains: specificDomain ? [specificDomain] : undefined,
          });

          return {
            results: results.map(result => ({
              title: result.title,
              url: result.url,
              snippet: result.text.slice(0, 1000),
            })),
          };
        },
      }),
    },
  });

  // Convert markdown to Slack mrkdwn format
  return text.replace(/\[(.*?)\]\((.*?)\)/g, '<$2|$1>').replace(/\*\*/g, '*');
};
```

在这个更新后的实现中：

1. 你添加了两个工具：
   - `getWeather`：获取指定位置的天气数据
   - `searchWeb`：使用 Exa API 在网络上搜索信息

2. 你设置了 `stopWhen: isStepCount(10)` 来启用多步对话。它定义了智能体在模型生成工具调用时的停止条件。这会自动把工具结果发回给 LLM，以便在 LLM 认为必要时触发额外的工具调用或响应。这让你的 LLM 调用从一次性操作变成了多步智能体流程。

## 工作原理

当用户与你的机器人交互时：

1. Slack 事件由你的 API 端点接收并处理
2. 用户消息和线程历史被传给 `generateResponse` 函数
3. AI SDK 处理消息，并可能按需调用工具
4. 响应被转换为 Slack 格式并发回给用户

工具会根据用户意图自动调用。例如，如果用户问 “What's the weather in London?”，AI 会：

1. 识别出这是一个天气查询
2. 用伦敦的坐标（由 LLM 推断）调用 `getWeather` 工具
3. 处理天气数据
4. 生成最终响应，回答用户的问题

   - `app_mention`
   - `assistant_thread_started`
   - `message:im`

最后，前往 Slack，给机器人发一条消息来测试应用。
