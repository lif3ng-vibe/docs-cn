在深入之前，先来看看 RAG 是什么，以及为什么要使用它。

### 什么是 RAG？

RAG 是检索增强生成（retrieval augmented generation）的缩写。简单来说，RAG 就是向大语言模型（LLM）提供与提示词（prompt）相关的特定信息的过程。

### RAG 为什么重要？

尽管 LLM 非常强大，但它们能推理的信息仅限于训练时使用的数据。当你向 LLM 询问训练数据之外的信息时——比如专有数据，或模型训练截止日期之后发生的常识——这个问题就会显现出来。RAG 通过获取与提示词相关的信息并将其作为上下文传给模型，解决了这个问题。

举一个简单的例子，假设你问模型你最喜欢的食物是什么：

```txt
**input**
What is my favorite food?

**generation**
I don't have access to personal information about individuals, including their
favorite foods.
```

不出所料，模型并不知道答案。但想象一下，如果除了你的提示词之外，模型还收到了一些额外的上下文：

```txt
**input**
Respond to the user's prompt using only the provided context.
user prompt: 'What is my favorite food?'
context: user loves chicken nuggets

**generation**
Your favorite food is chicken nuggets!
```

就这样，你通过为查询提供相关信息增强了模型的生成能力。只要模型掌握了相应的信息，它现在就很有可能对用户查询返回准确的回答。但它如何检索到相关信息呢？答案在于一个叫做嵌入（embedding）的概念。

<Note>
  你可以为 RAG 应用获取任意上下文（例如 Google 搜索）。嵌入（embedding）与向量数据库只是实现语义搜索的一种特定检索方式。
</Note>

### 嵌入（embedding）

[嵌入（embedding）](/docs/ai-sdk-core/embeddings)是一种将单词、短语或图像表示为高维空间中向量的方法。在这个空间中，相似的词彼此靠近，词与词之间的距离可以用来衡量它们的相似度。

在实际应用中，这意味着如果你对 `cat` 和 `dog` 这两个词做嵌入，可以预期它们在向量空间中的位置会彼此接近。计算两个向量之间相似度的过程称为余弦相似度（cosine similarity），其值为 1 表示高度相似，为 -1 表示高度相反。

<Note>
  如果觉得这很复杂也不必担心，入门只需有一个高层次的理解即可！想要更深入地了解嵌入，请参阅[这篇指南](https://jalammar.github.io/illustrated-word2vec/)。
</Note>

如前所述，嵌入是表示**单词和短语**语义的一种方式。这意味着输入越长，嵌入的质量就越低。那么，如果要嵌入的内容比一个简单的短语更长，该怎么办呢？

### 分块

分块（chunking）指的是把特定的源材料拆分成更小的片段。分块有很多不同的方法，值得多做实验，因为最有效的方法会因用例而异。一种简单常见的分块方法（也是本指南将采用的方法）是按句子切分书面内容。

将源材料妥善分块后，你可以对每个片段做嵌入，然后把嵌入和片段一起存入数据库。嵌入可以存储在任何支持向量的数据库中。在本教程中，你将使用 [Postgres](https://www.postgresql.org/) 配合 [pgvector](https://github.com/pgvector/pgvector) 插件。

### 创建嵌入表

目前，你的应用只有一张表（`resources`），其中有一列（`content`）用于存储内容。记住，每条 `resource`（源材料）都需要分块、嵌入，然后再存储。我们来创建一个名为 `embeddings` 的表来存放这些分块。

创建一个新文件（`lib/db/schema/embeddings.ts`）并添加以下代码：

```tsx filename="lib/db/schema/embeddings.ts"
import { nanoid } from '@/lib/utils';
import { index, pgTable, text, varchar, vector } from 'drizzle-orm/pg-core';
import { resources } from './resources';

export const embeddings = pgTable(
  'embeddings',
  {
    id: varchar('id', { length: 191 })
      .primaryKey()
      .$defaultFn(() => nanoid()),
    resourceId: varchar('resource_id', { length: 191 }).references(
      () => resources.id,
      { onDelete: 'cascade' },
    ),
    content: text('content').notNull(),
    embedding: vector('embedding', { dimensions: 1536 }).notNull(),
  },
  table => ({
    embeddingIndex: index('embeddingIndex').using(
      'hnsw',
      table.embedding.op('vector_cosine_ops'),
    ),
  }),
);
```

这张表有四列：

- `id` - 唯一标识符
- `resourceId` - 指向完整源材料的外键关联
- `content` - 纯文本分块
- `embedding` - 纯文本分块的向量表示

要执行相似度搜索，还需要在此列上建立一个索引（[HNSW](https://github.com/pgvector/pgvector?tab=readme-ov-file#hnsw) 或 [IVFFlat](https://github.com/pgvector/pgvector?tab=readme-ov-file#ivfflat)）以获得更好的性能。

要将此变更推送到数据库，运行以下命令：

<Snippet text="pnpm db:push" />

### 生成分块

记住，要生成嵌入，你需要先拿到一段源材料（长度未知），把它拆分成更小的分块，对每个分块做嵌入，然后把分块保存到数据库。我们先创建一个把源材料拆分成小块的函数。

```tsx filename="lib/ai/embedding.ts"
const generateChunks = (input: string): string[] => {
  return input
    .trim()
    .split('.')
    .filter(i => i !== '');
};
```

该函数接收输入字符串并按句点拆分，过滤掉空项，返回一个字符串数组。在你的项目中值得尝试不同的分块技术，因为最优方法会因场景而异。

### 生成嵌入

我们来添加一个生成嵌入的函数。把以下代码复制到你的 `lib/ai/embedding.ts` 文件中。

```tsx filename="lib/ai/embedding.ts" highlight="1,3,12-21"
import { embedMany } from 'ai';

const embeddingModel = 'openai/text-embedding-ada-002';

const generateChunks = (input: string): string[] => {
  return input
    .trim()
    .split('.')
    .filter(i => i !== '');
};

export const generateEmbeddings = async (
  value: string,
): Promise<Array<{ embedding: number[]; content: string }>> => {
  const chunks = generateChunks(value);
  const { embeddings } = await embedMany({
    model: embeddingModel,
    values: chunks,
  });
  return embeddings.map((e, i) => ({ content: chunks[i], embedding: e }));
};
```

在这段代码中，你首先定义了用于嵌入的模型。本例中使用的是 OpenAI 的 `text-embedding-ada-002` 嵌入模型。

接下来，你创建了一个名为 `generateEmbeddings` 的异步函数。该函数接收源材料（`value`）作为输入，返回一个对象数组组成的 promise，每个对象包含一个嵌入和对应内容。在函数内部，你先为输入生成分块，然后把分块传给从 AI SDK 导入的 [`embedMany`](/docs/reference/ai-sdk-core/embed-many) 函数，它会返回所传入分块的嵌入。最后，你遍历并以可直接存入数据库的格式返回这些嵌入。

### 更新 Server Action

打开 `lib/actions/resources.ts` 文件。该文件有一个函数 `createResource`，顾名思义，它允许你创建资源。

```tsx filename="lib/actions/resources.ts"
'use server';

import {
  NewResourceParams,
  insertResourceSchema,
  resources,
} from '@/lib/db/schema/resources';
import { db } from '../db';

export const createResource = async (input: NewResourceParams) => {
  try {
    const { content } = insertResourceSchema.parse(input);

    const [resource] = await db
      .insert(resources)
      .values({ content })
      .returning();

    return 'Resource successfully created.';
  } catch (e) {
    if (e instanceof Error)
      return e.message.length > 0 ? e.message : 'Error, please try again.';
  }
};
```

该函数是一个 [Server Action](https://nextjs.org/docs/app/building-your-application/data-fetching/server-actions-and-mutations#with-client-components)，文件顶部的 `“use server”;` 指令说明了这一点。这意味着它可以在 Next.js 应用的任何地方被调用。该函数接收输入，通过 [Zod](https://zod.dev) schema 确保输入符合正确的 schema，然后在数据库中创建新资源。这里是为新创建的资源生成并存储嵌入的理想位置。

用以下代码更新该文件：

```tsx filename="lib/actions/resources.ts" highlight="9-10,21-27,29"
'use server';

import {
  NewResourceParams,
  insertResourceSchema,
  resources,
} from '@/lib/db/schema/resources';
import { db } from '../db';
import { generateEmbeddings } from '../ai/embedding';
import { embeddings as embeddingsTable } from '../db/schema/embeddings';

export const createResource = async (input: NewResourceParams) => {
  try {
    const { content } = insertResourceSchema.parse(input);

    const [resource] = await db
      .insert(resources)
      .values({ content })
      .returning();

    const embeddings = await generateEmbeddings(content);
    await db.insert(embeddingsTable).values(
      embeddings.map(embedding => ({
        resourceId: resource.id,
        ...embedding,
      })),
    );

    return 'Resource successfully created and embedded.';
  } catch (error) {
    return error instanceof Error && error.message.length > 0
      ? error.message
      : 'Error, please try again.';
  }
};
```

首先，调用上一步创建的 `generateEmbeddings` 函数，传入源材料（`content`）。拿到源材料的嵌入（`e`）后，就可以把它们存入数据库，同时在每条嵌入旁传入 `resourceId`。

### 创建根页面

很好！接下来构建前端。AI SDK 的 [`useChat`](/docs/reference/ai-sdk-ui/use-chat) Hook 让你可以轻松为智能体创建对话式用户界面。

用以下代码替换你的根页面（`app/page.tsx`）。

```tsx filename="app/page.tsx"
'use client';

import { useChat } from '@ai-sdk/react';
import { useState } from 'react';

export default function Chat() {
  const [input, setInput] = useState('');
  const { messages, sendMessage } = useChat();
  return (
    <div className="flex flex-col w-full max-w-md py-24 mx-auto stretch">
      <div className="space-y-4">
        {messages.map(m => (
          <div key={m.id} className="whitespace-pre-wrap">
            <div>
              <div className="font-bold">{m.role}</div>
              {m.parts.map(part => {
                switch (part.type) {
                  case 'text':
                    return <p>{part.text}</p>;
                }
              })}
            </div>
          </div>
        ))}
      </div>

      <form
        onSubmit={e => {
          e.preventDefault();
          sendMessage({ text: input });
          setInput('');
        }}
      >
        <input
          className="fixed bottom-0 w-full max-w-md p-2 mb-8 border border-gray-300 rounded shadow-xl"
          value={input}
          placeholder="Say something..."
          onChange={e => setInput(e.currentTarget.value)}
        />
      </form>
    </div>
  );
}
```

`useChat` Hook 支持从你的 AI 提供商（本例将通过 Vercel AI Gateway 使用 OpenAI）流式传输聊天消息，并在收到新消息时自动更新 UI。聊天输入状态在你的组件中管理。

运行以下命令启动 Next.js 开发服务器：

打开 [http://localhost:3000](http://localhost:3000/)。你会看到一个空页面，底部浮动着一个输入栏。试着发送一条消息，它会在 UI 中闪现一瞬然后消失。这是因为你还没有设置调用模型的对应 API 路由！默认情况下，`useChat` 会向 `/api/chat` 端点发送 POST 请求，请求体为 `messages`。

### 创建 API 路由

在 Next.js 中，你可以使用 [Route Handler](https://nextjs.org/docs/app/building-your-application/routing/route-handlers) 为给定路由创建自定义请求处理器。Route Handler 定义在 `route.ts` 文件中，可以导出 `GET`、`POST`、`PUT`、`PATCH` 等 HTTP 方法。

运行以下命令创建 `app/api/chat/route.ts` 文件：

<Snippet text="mkdir -p app/api/chat && touch app/api/chat/route.ts" />

打开该文件并添加以下代码：

```tsx filename="app/api/chat/route.ts"
import {
  convertToModelMessages,
  createUIMessageStreamResponse,
  streamText,
  toUIMessageStream,
  UIMessage,
} from 'ai';

// Allow streaming responses up to 30 seconds
export const maxDuration = 30;

export async function POST(req: Request) {
  const { messages }: { messages: UIMessage[] } = await req.json();

  const result = streamText({
    model: 'openai/gpt-6-astra',
    messages: await convertToModelMessages(messages),
  });

  return createUIMessageStreamResponse({
    stream: toUIMessageStream({ stream: result.stream }),
  });
}
```

在这段代码中，你声明并导出了一个名为 POST 的异步函数。你从请求体中取出 `messages`，然后将它们连同你想使用的模型一起传给从 AI SDK 导入的 [`streamText`](/docs/reference/ai-sdk-core/stream-text) 函数。最后，你以 `UIMessageStreamResponse` 格式返回模型的响应。

回到浏览器再次尝试发送消息。你应该能看到模型的响应直接流式输出！

### 优化提示词

虽然你现在有了一个能运行的智能体，但它还没什么特别之处。

我们来添加系统指令，以细化并约束模型的行为。这里你希望模型只使用它检索到的信息来生成响应。用以下代码更新你的路由处理器：

```tsx filename="app/api/chat/route.ts" highlight="18-20"
import {
  convertToModelMessages,
  createUIMessageStreamResponse,
  streamText,
  toUIMessageStream,
  UIMessage,
} from 'ai';

// Allow streaming responses up to 30 seconds
export const maxDuration = 30;

export async function POST(req: Request) {
  const { messages }: { messages: UIMessage[] } = await req.json();

  const result = streamText({
    model: 'openai/gpt-6-astra',
    instructions: `You are a helpful assistant. Check your knowledge base before answering any questions.
    Only respond to questions using information from tool calls.
    if no relevant information is found in the tool calls, respond, "Sorry, I don't know."`,
    messages: await convertToModelMessages(messages),
  });

  return createUIMessageStreamResponse({
    stream: toUIMessageStream({ stream: result.stream }),
  });
}
```

回到浏览器，试着问模型你最喜欢的食物是什么。由于模型没有任何相关信息，它现在应该会按照你上面的指令作出回应（“Sorry, I don't know”）。

就目前而言，你的智能体可以说毫无用处。如何让模型具备添加和查询信息的能力呢？

### 使用工具

[工具（tool）](/docs/foundations/tools)是模型可以调用以执行特定任务的函数。你可以把工具想象成你交给模型的一个程序，模型会在它认为必要的时候运行它。

来看看如何创建一个工具，让模型能够创建、嵌入资源并保存到智能体的知识库中。

### 添加资源工具

用以下代码更新你的路由处理器：

```tsx filename="app/api/chat/route.ts" highlight="25-36"
import { createResource } from '@/lib/actions/resources';
import {
  convertToModelMessages,
  createUIMessageStreamResponse,
  streamText,
  tool,
  toUIMessageStream,
  UIMessage,
} from 'ai';
import { z } from 'zod';

// Allow streaming responses up to 30 seconds
export const maxDuration = 30;

export async function POST(req: Request) {
  const { messages }: { messages: UIMessage[] } = await req.json();

  const result = streamText({
    model: 'openai/gpt-6-astra',
    instructions: `You are a helpful assistant. Check your knowledge base before answering any questions.
    Only respond to questions using information from tool calls.
    if no relevant information is found in the tool calls, respond, "Sorry, I don't know."`,
    messages: await convertToModelMessages(messages),
    tools: {
      addResource: tool({
        description: `add a resource to your knowledge base.
          If the user provides a random piece of knowledge unprompted, use this tool without asking for confirmation.`,
        inputSchema: z.object({
          content: z
            .string()
            .describe('the content or resource to add to the knowledge base'),
        }),
        execute: async ({ content }) => createResource({ content }),
      }),
    },
  });

  return createUIMessageStreamResponse({
    stream: toUIMessageStream({ stream: result.stream }),
  });
}
```

在这段代码中，你定义了一个名为 `addResource` 的工具。该工具有三个要素：

- **description**：工具的描述，会影响工具何时被选用。
- **inputSchema**：[Zod schema](/docs/foundations/tools#schema-specification-and-validation-with-zod)，定义工具运行所需的输入。
- **execute**：一个异步函数，会以工具调用的参数被调用。

简单来说，在每次生成时，模型会决定是否应该调用该工具。如果它认为应该调用，就会提取输入，然后向 `messages` 数组追加一条类型为 `tool-call` 的新 `message`。随后 AI SDK 会使用 `tool-call` 消息提供的参数运行 `execute` 函数。

回到浏览器，告诉模型你最喜欢的食物。你应该会在 UI 中看到一个空响应。有事情发生吗？来看看。在一个新的终端窗口运行以下命令。

这会启动 Drizzle Studio，我们可以在其中查看数据库中的行。你应该会看到 `embeddings` 和 `resources` 表中都多了一行你最喜欢的食物！

我们在 UI 上做些修改，以便在工具被调用时告知用户。回到根页面（`app/page.tsx`）并添加以下代码：

```tsx filename="app/page.tsx" highlight="14-32"
'use client';

import { useChat } from '@ai-sdk/react';
import { useState } from 'react';

export default function Chat() {
  const [input, setInput] = useState('');
  const { messages, sendMessage } = useChat();
  return (
    <div className="flex flex-col w-full max-w-md py-24 mx-auto stretch">
      <div className="space-y-4">
        {messages.map(m => (
          <div key={m.id} className="whitespace-pre-wrap">
            <div>
              <div className="font-bold">{m.role}</div>
              {m.parts.map(part => {
                switch (part.type) {
                  case 'text':
                    return <p>{part.text}</p>;
                  case 'tool-addResource':
                  case 'tool-getInformation':
                    return (
                      <p>
                        call{part.state === 'output-available' ? 'ed' : 'ing'}{' '}
                        tool: {part.type}

                          {JSON.stringify(part.input, null, 2)}
                        </pre>
                      </p>
                    );
                }
              })}
            </div>
          </div>
        ))}
      </div>

      <form
        onSubmit={e => {
          e.preventDefault();
          sendMessage({ text: input });
          setInput('');
        }}
      >
        <input
          className="fixed bottom-0 w-full max-w-md p-2 mb-8 border border-gray-300 rounded shadow-xl"

          placeholder="Say something..."
          onChange={e => setInput(e.currentTarget.value)}
```

### 通过多步调用改进用户体验

如果模型还能对这次操作做个总结就更好了。然而从技术上讲，模型一旦调用了工具，它的生成就结束了，因为它已经“生成”了一次工具调用。如何实现这个期望的行为呢？

AI SDK 有一个叫做 [`stopWhen`](/docs/ai-sdk-core/tools-and-tool-calling#multi-step-calls) 的特性，允许在模型生成工具调用时设置停止条件。如果这些停止条件尚未触发，AI SDK 会自动把工具调用结果发回给模型！

打开你的路由处理器（`app/api/chat/route.ts`），在 `streamText` 配置对象中添加以下键：

```tsx filename="app/api/chat/route.ts" highlight="9,25"
import { createResource } from '@/lib/actions/resources';
```

回到浏览器，告诉模型你最喜欢的披萨配料（注意：菠萝不在选项之列）。你应该会看到模型给出后续响应，确认这次操作。

### 检索资源工具

现在模型可以把任意信息添加并嵌入到你的知识库中了。但它还不能查询知识库。我们来创建一个新工具，让模型能够通过在知识库中查找相关信息来回答问题。

要找到相似内容，你需要对用户查询做嵌入，在数据库中搜索语义相似项，然后把这些条目连同查询一起作为上下文传给模型。为此，我们来更新嵌入逻辑文件（`lib/ai/embedding.ts`）：

```tsx filename="lib/ai/embedding.ts" highlight="1-3,26-48"
import { embed, embedMany } from 'ai';
import { db } from '../db';
import { cosineDistance, desc, gt, sql } from 'drizzle-orm';
import { embeddings } from '../db/schema/embeddings';

const embeddingModel = 'openai/text-embedding-ada-002';

const generateChunks = (input: string): string[] => {
  return input
    .trim()
    .split('.')
    .filter(i => i !== '');
};

export const generateEmbeddings = async (
  value: string,
): Promise<Array<{ embedding: number[]; content: string }>> => {
  const chunks = generateChunks(value);
  const { embeddings } = await embedMany({
    model: embeddingModel,
    values: chunks,
  });
  return embeddings.map((e, i) => ({ content: chunks[i], embedding: e }));
};

export const generateEmbedding = async (value: string): Promise<number[]> => {
  const input = value.replaceAll('\\n', ' ');
  const { embedding } = await embed({
    model: embeddingModel,
    value: input,
  });
  return embedding;
};

export const findRelevantContent = async (userQuery: string) => {
  const userQueryEmbedded = await generateEmbedding(userQuery);
  const similarity = sql<number>`1 - (${cosineDistance(
    embeddings.embedding,
    userQueryEmbedded,
  )})`;
  const similarGuides = await db
    .select({ name: embeddings.content, similarity })
    .from(embeddings)
    .where(gt(similarity, 0.5))
    .orderBy(t => desc(t.similarity))
    .limit(4);
  return similarGuides;
};
```

在这段代码中，你添加了两个函数：

- `generateEmbedding`：从输入字符串生成单个嵌入
- `findRelevantContent`：对用户查询做嵌入，在数据库中搜索相似条目，然后返回相关条目

完成后，进入最后一步：创建工具。

回到你的路由处理器（`app/api/chat/route.ts`），添加一个名为 `getInformation` 的新工具：

```ts filename="app/api/chat/route.ts" highlight="12,38-45"

  convertToModelMessages,
  createUIMessageStreamResponse,
  streamText,
  tool,
  toUIMessageStream,
  UIMessage,
  isStepCount,
} from 'ai';

import { findRelevantContent } from '@/lib/ai/embedding';

export async function POST(req: Request) {

  const result = streamText({
    model: 'openai/gpt-6-astra',

    Only respond to questions using information from tool calls.
    if no relevant information is found in the tool calls, respond, "Sorry, I don't know."`,

      addResource: tool({
        description: `add a resource to your knowledge base.
          If the user provides a random piece of knowledge unprompted, use this tool without asking for confirmation.`,

            .string()
            .describe('the content or resource to add to the knowledge base'),
        }),
        execute: async ({ content }) => createResource({ content }),

          question: z.string().describe('the users question'),
        }),
        execute: async ({ question }) => findRelevantContent(question),
      }),
    },
  });

  return createUIMessageStreamResponse({
    stream: toUIMessageStream({ stream: result.stream }),
  });
}
```
