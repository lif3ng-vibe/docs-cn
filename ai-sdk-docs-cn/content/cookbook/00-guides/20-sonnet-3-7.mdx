# Get started with Claude 3.7 Sonnet

<Note type="warning">
  本指南已弃用。[Claude 3.7 Sonnet 已于 2026 年 2 月 19 日退役](https://platform.claude.com/docs/en/about-claude/model-deprecations#2025-10-28-claude-sonnet-3-7-model)，无法再与 Anthropic API 一起使用。
</Note>

随着 [Claude 3.7 Sonnet 的发布](https://www.anthropic.com/news/claude-3-7-sonnet)，现在是开始构建 AI 应用的最佳时机，尤其是那些需要复杂推理能力的应用。

[AI SDK](/) 是一个强大的 TypeScript 工具包，用于结合 Claude 3.7 Sonnet 这样的大型语言模型（LLM）以及 React、Next.js、Vue、Svelte、Node.js 等流行框架构建 AI 应用。

## Claude 3.7 Sonnet

Claude 3.7 Sonnet 是 Anthropic 迄今最智能的模型，也是首个提供扩展思考（extended thinking）的 Claude 模型——即通过细致的逐步推理解决复杂问题的能力。借助 Claude 3.7 Sonnet，你可以在速度与质量之间取得平衡：选择标准思考获得近乎即时的响应，或选择扩展思考进行深度推理。Claude 3.7 Sonnet 在编码方面处于业界顶尖水平，并在计算机操作（computer use）、智能体（agent）能力、复杂推理和内容生成方面都有进步。凭借前沿的性能和对速度的更多控制，Claude 3.7 Sonnet 是驱动 AI 智能体的绝佳选择，尤其是面向客户的智能体和复杂 AI 工作流。

## AI SDK 快速上手

AI SDK 是一款 TypeScript 工具包，旨在帮助开发者使用 React、Next.js、Vue、Svelte、Node.js 等构建 AI 驱动的应用。将 LLM 集成到应用中相当复杂，且高度依赖于你所使用的具体模型提供商（provider）。

AI SDK 抽象掉了不同模型提供商之间的差异，消除了构建聊天机器人的样板代码，并让你能够超越纯文本输出，生成丰富、可交互的组件。

AI SDK 的核心是 [AI SDK Core](/docs/ai-sdk-core/overview)，它提供了调用任意 LLM 的统一 API。下面的历史示例展示了在 Claude 3.7 Sonnet 退役之前如何通过 AI SDK 调用它。该示例已无法与 Anthropic API 配合使用；如需当前可用的示例，请参阅 [Anthropic 提供商文档](/providers/ai-sdk-providers/anthropic)：

```ts
import { anthropic } from '@ai-sdk/anthropic';
import { generateText } from 'ai';

const { text, reasoningText, reasoning } = await generateText({
  model: anthropic('claude-3-7-sonnet-20250219'),
  prompt: 'How many people will live in the world in 2040?',
});
console.log(text); // text response
```

统一的接口也意味着你只需修改两行代码即可轻松切换提供商。例如，通过 Amazon Bedrock 使用 Claude 3.7 Sonnet：

```ts
import { amazonBedrock } from '@ai-sdk/amazon-bedrock';
import { generateText } from 'ai';

const { reasoning, text } = await generateText({
  model: amazonBedrock('anthropic.claude-3-7-sonnet-20250219-v1:0'),
  prompt: 'How many people will live in the world in 2040?',
});
```

### 推理能力

Claude 3.7 Sonnet 引入了新的扩展思考（extended thinking）能力——通过细致的逐步推理解决复杂问题。你可以通过 `thinking` 提供商选项启用它，并以 token 为单位指定思考预算：

```ts
import { anthropic, AnthropicLanguageModelOptions } from '@ai-sdk/anthropic';
import { generateText } from 'ai';

const { text, reasoningText, reasoning } = await generateText({
  model: anthropic('claude-3-7-sonnet-20250219'),
  prompt: 'How many people will live in the world in 2040?',
  providerOptions: {
    anthropic: {
      thinking: { type: 'enabled', budgetTokens: 12000 },
    } satisfies AnthropicLanguageModelOptions,
  },
});

console.log(reasoningText); // reasoning text
console.log(reasoning); // reasoning details including redacted reasoning
console.log(text); // text response
```

### 构建交互式界面

AI SDK Core 可以与 AI SDK 的另一个强大组件 [AI SDK UI](/docs/ai-sdk-ui/overview) 搭配使用，简化使用 Next.js、Nuxt、SvelteKit 等流行框架构建聊天、补全和助手界面的过程。

AI SDK UI 提供了强大的抽象，简化了在前端管理聊天流和 UI 更新的复杂任务，让你能够更高效地开发生动的 AI 驱动界面。

通过三个主要 Hook——[`useChat`](/docs/reference/ai-sdk-ui/use-chat)、[`useCompletion`](/docs/reference/ai-sdk-ui/use-completion) 和 [`useObject`](/docs/reference/ai-sdk-ui/use-object)——你可以在应用中集成实时聊天、文本补全、流式 JSON 和交互式助手功能。

让我们来探索如何结合 [Next.js](https://nextjs.org)、AI SDK 与 Claude 3.7 Sonnet 构建一个聊天机器人：

在新建的 Next.js 应用中，先安装 AI SDK 和 Anthropic 提供商：

<Snippet text="pnpm install ai @ai-sdk/anthropic" />

然后，为聊天端点创建一个 Route Handler：

```tsx filename="app/api/chat/route.ts"
import { anthropic, AnthropicLanguageModelOptions } from '@ai-sdk/anthropic';
import {
  streamText,
  convertToModelMessages,
  createUIMessageStreamResponse,
  toUIMessageStream,
  type UIMessage,
} from 'ai';

export async function POST(req: Request) {
  const { messages }: { messages: UIMessage[] } = await req.json();

  const result = streamText({
    model: anthropic('claude-3-7-sonnet-20250219'),
    messages: await convertToModelMessages(messages),
    providerOptions: {
      anthropic: {
        thinking: { type: 'enabled', budgetTokens: 12000 },
      } satisfies AnthropicLanguageModelOptions,
    },
  });

  return createUIMessageStreamResponse({
    stream: toUIMessageStream({
      stream: result.stream,
      sendReasoning: true,
    }),
  });
}
```

<Note>
  你可以在 `toUIMessageStream` 辅助函数中通过 `sendReasoning: true` 将模型的推理 token 转发给客户端。
</Note>

最后，更新根页面（`app/page.tsx`）以使用 `useChat` Hook：

```tsx filename="app/page.tsx"
'use client';

import { useChat } from '@ai-sdk/react';
import { DefaultChatTransport } from 'ai';
import { useState } from 'react';

export default function Page() {
  const [input, setInput] = useState('');
  const { messages, sendMessage } = useChat({
    transport: new DefaultChatTransport({ api: '/api/chat' }),
  });

  const handleSubmit = (e: React.FormEvent) => {
    e.preventDefault();
    if (input.trim()) {
      sendMessage({ text: input });
      setInput('');
    }
  };

  return (
    <>
      {messages.map(message => (
        <div key={message.id}>
          {message.role === 'user' ? 'User: ' : 'AI: '}
          {message.parts.map((part, index) => {
            // text parts:
            if (part.type === 'text') {
              return <div key={index}>{part.text}</div>;
            }
            // reasoning parts:
            if (part.type === 'reasoning') {
              return <pre key={index}>{part.text}</pre>;
            }
          })}
        </div>
      ))}
      <form onSubmit={handleSubmit}>
        <input
          name="prompt"
          value={input}
          onChange={e => setInput(e.target.value)}
        />
        <button type="submit">Send</button>
      </form>
    </>
  );
}
```

<Note>
  你可以通过消息 `parts` 中的 `reasoning` 部分访问模型的推理 token。
</Note>

根页面（`app/page.tsx`）上的 useChat Hook 会在用户提交消息时向你的 LLM 提供商端点（`app/api/chat/route.ts`）发起请求。随后消息会显示在聊天 UI 中。

## 开始使用

准备好深入了吗？以下是如何开始：

1. 浏览 [ai-sdk.dev/docs](/docs) 上的文档，了解 AI SDK 的能力。
2. 查看 [ai-sdk.dev/examples](/examples) 上的实际示例，看看 SDK 的实际运用。
3. 通过 [ai-sdk.dev/docs/guides](/cookbook/guides) 上的进阶指南深入学习检索增强生成（RAG）等主题。
4. 使用 [vercel.com/templates?type=ai](https://vercel.com/templates?type=ai) 上开箱即用的 AI 模板。

Claude 3.7 Sonnet 为推理密集型 AI 应用开启了新的机遇。今天就开始构建，在你的 AI 项目中发挥高级推理的力量。
