# Get started with DeepSeek R1

<Note>
  DeepSeek 已于 2026 年 7 月 24 日退役 `deepseek-reasoner` API 别名。本历史指南中的 Direct DeepSeek API 示例仅作参考保留，无法再对接当前服务。如需当前的 DeepSeek 推理工作负载，请使用 `deepseek-v4-pro`。
</Note>

随着 [DeepSeek R1 的发布](https://api-docs.deepseek.com/news/news250528)，现在是开始构建 AI 应用的最佳时机，尤其是那些需要复杂推理能力的应用。

[AI SDK](/) 是一个强大的 TypeScript 工具包，用于结合 DeepSeek R1 这样的大型语言模型（LLM）以及 React、Next.js、Vue、Svelte、Node.js 等流行框架构建 AI 应用。

## DeepSeek R1

DeepSeek R1 是一系列旨在处理科学、编程和数学领域复杂推理任务的先进 AI 模型。这些模型经过优化，能够"先思考再回答"，产生详细的内部思维链，帮助解决具有挑战性的问题。

该系列包含两个主要变体：

- **DeepSeek R1-Zero**：仅通过强化学习（RL）训练，未做任何监督微调。它展现出先进的推理能力，但在可读性和格式方面可能存在不足。
- **DeepSeek R1**：将强化学习与冷启动数据及监督微调相结合，同时提升推理性能与输出的可读性。

### 基准测试

DeepSeek R1 模型在推理任务上表现出色，在关键基准测试中交出了具有竞争力的成绩：

- **AIME 2024（Pass\@1）**：79.8%
- **MATH-500（Pass\@1）**：97.3%
- **Codeforces（百分位）**：前 4%（96.3%）
- **GPQA Diamond（Pass\@1）**：71.5%

[来源](https://github.com/deepseek-ai/DeepSeek-R1?tab=readme-ov-file#4-evaluation-results)

### DeepSeek R1 模型的提示词工程

DeepSeek R1 模型在使用结构化、简单直接的提示词时表现出色。以下最佳实践有助于获得最佳性能：

1. **使用结构化格式**：利用模型偏好的输出结构——用 `<think>` 标签承载推理，用 `<answer>` 标签承载最终结果。
2. **优先使用零样本提示词**：避免少样本提示，因为它可能降低性能；相反，直接清晰地陈述问题。
3. **明确输出预期**：通过定义期望的格式来引导模型，例如为可读性使用 markdown，或为清晰性使用类 XML 标签。

## AI SDK 快速上手

AI SDK 是一款 TypeScript 工具包，旨在帮助开发者使用 React、Next.js、Vue、Svelte、Node.js 等构建 AI 驱动的应用。将 LLM 集成到应用中相当复杂，且高度依赖于你所使用的具体模型提供商（provider）。

AI SDK 抽象掉了不同模型提供商之间的差异，消除了构建聊天机器人的样板代码，并让你能够超越纯文本输出，生成丰富、可交互的组件。

AI SDK 的核心是 [AI SDK Core](/docs/ai-sdk-core/overview)，它提供了调用任意 LLM 的统一 API。使用 AI SDK 调用 DeepSeek R1 只需要下面这段代码：

```ts
import { deepSeek } from '@ai-sdk/deepseek';
import { generateText } from 'ai';

const { reasoningText, text } = await generateText({
  model: deepSeek('deepseek-reasoner'),
  prompt: 'Explain quantum entanglement.',
});
```

统一的接口也意味着你只需修改两行代码即可轻松切换提供商。例如，通过 Fireworks 使用 DeepSeek R1：

```ts
import { fireworks } from '@ai-sdk/fireworks';
import {
  generateText,
  wrapLanguageModel,
  extractReasoningMiddleware,
} from 'ai';

// middleware to extract reasoning tokens
const enhancedModel = wrapLanguageModel({
  model: fireworks('accounts/fireworks/models/deepseek-r1'),
  middleware: extractReasoningMiddleware({ tagName: 'think' }),
});

const { reasoningText, text } = await generateText({
  model: enhancedModel,
  prompt: 'Explain quantum entanglement.',
});
```

或者使用 Groq 的 `deepseek-r1-distill-llama-70b` 模型：

```ts
import { groq } from '@ai-sdk/groq';
import {
  generateText,
  wrapLanguageModel,
  extractReasoningMiddleware,
} from 'ai';

// middleware to extract reasoning tokens
const enhancedModel = wrapLanguageModel({
  model: groq('deepseek-r1-distill-llama-70b'),
  middleware: extractReasoningMiddleware({ tagName: 'think' }),
});

const { reasoningText, text } = await generateText({
  model: enhancedModel,
  prompt: 'Explain quantum entanglement.',
});
```

<Note id="deepseek-r1-middleware">
AI SDK 提供了一个[中间件](/docs/ai-sdk-core/middleware)（`extractReasoningMiddleware`），可用于从模型输出中提取推理 token。

在 Together AI 等第三方提供商处使用 DeepSeek-R1 系列模型时，我们建议在 `extractReasoningMiddleware` 函数中使用 `startWithReasoning` 选项，因为这些提供商往往会绕过思考模式。

</Note>

### 构建交互式界面

AI SDK Core 可以与 AI SDK 的另一个强大组件 [AI SDK UI](/docs/ai-sdk-ui/overview) 搭配使用，简化使用 Next.js、Nuxt、SvelteKit 等流行框架构建聊天、补全和助手界面的过程。

AI SDK UI 提供了强大的抽象，简化了在前端管理聊天流和 UI 更新的复杂任务，让你能够更高效地开发生动的 AI 驱动界面。

通过三个主要 Hook——[`useChat`](/docs/reference/ai-sdk-ui/use-chat)、[`useCompletion`](/docs/reference/ai-sdk-ui/use-completion) 和 [`useObject`](/docs/reference/ai-sdk-ui/use-object)——你可以在应用中集成实时聊天、文本补全、流式 JSON 和交互式助手功能。

让我们来探索如何结合 [Next.js](https://nextjs.org)、AI SDK 与 DeepSeek R1 构建一个聊天机器人：

在新建的 Next.js 应用中，先安装 AI SDK 和 DeepSeek 提供商：

<Snippet text="pnpm install ai @ai-sdk/deepseek @ai-sdk/react" />

然后，为聊天端点创建一个 Route Handler：

```tsx filename="app/api/chat/route.ts"
import { deepSeek } from '@ai-sdk/deepseek';
import {
  convertToModelMessages,
  createUIMessageStreamResponse,
  streamText,
  toUIMessageStream,
  UIMessage,
} from 'ai';

export async function POST(req: Request) {
  const { messages }: { messages: UIMessage[] } = await req.json();

  const result = streamText({
    model: deepSeek('deepseek-reasoner'),
    messages: await convertToModelMessages(messages),
  });

  return createUIMessageStreamResponse({
    stream: toUIMessageStream({
      stream: result.stream,
      sendReasoning: true,
    }),
  });
}
```

<Note>
  你可以在 `toUIMessageStream` 辅助函数中通过 `sendReasoning: true` 将模型的推理 token 转发给客户端。
</Note>

最后，更新根页面（`app/page.tsx`）以使用 `useChat` Hook：

```tsx filename="app/page.tsx"
'use client';

import { useChat } from '@ai-sdk/react';
import { useState } from 'react';

export default function Page() {
  const [input, setInput] = useState('');
  const { messages, sendMessage } = useChat();

  const handleSubmit = (e: React.FormEvent<HTMLFormElement>) => {
    e.preventDefault();
    if (input.trim()) {
      sendMessage({ text: input });
      setInput('');
    }
  };

  return (
    <>
      {messages.map(message => (
        <div key={message.id}>
          {message.role === 'user' ? 'User: ' : 'AI: '}
          {message.parts.map((part, index) => {
            if (part.type === 'reasoning') {
              return <pre key={index}>{part.text}</pre>;
            }
            if (part.type === 'text') {
              return <span key={index}>{part.text}</span>;
            }
            return null;
          })}
        </div>
      ))}
      <form onSubmit={handleSubmit}>
        <input
          name="prompt"
          value={input}
          onChange={e => setInput(e.target.value)}
        />
        <button type="submit">Submit</button>
      </form>
    </>
  );
}
```

<Note>
  你可以通过 `message` 对象上的 `parts` 数组访问模型的推理 token，其中推理部分的 `type: 'reasoning'`。
</Note>

根页面（`app/page.tsx`）上的 useChat Hook 会在用户提交消息时向你的 AI 提供商端点（`app/api/chat/route.ts`）发起请求。随后消息会显示在聊天 UI 中。

## 局限性

虽然 DeepSeek R1 模型很强大，但也存在一些局限：

- 不支持工具调用：DeepSeek R1 无法直接与 API 或外部工具交互。
- 不支持对象生成：DeepSeek R1 不支持结构化对象生成。不过，你可以将它与支持结构化对象生成的模型（如 gpt-4o-mini）结合来生成对象。详情请参阅[使用推理模型进行结构化对象生成的菜谱](/cookbook/node/generate-object-reasoning)。
