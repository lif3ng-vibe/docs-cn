# Get started with Llama 3.1

<Note>
  当前一代 Llama 模型是 3.3。请注意，虽然本指南聚焦于 Llama 3.1，但更新的 Llama 3.3 模型现已推出，可能提供更强的能力。本文所述的概念和集成技巧仍然适用，不过你可能希望使用最新一代模型以获得最佳性能。
</Note>

随着 [Llama 3.1 的发布](https://ai.meta.com/blog/meta-llama-3-1/)，现在是开始构建 AI 应用的最佳时机。

[AI SDK](/) 是一个强大的 TypeScript 工具包，用于结合 Llama 3.1 这样的大型语言模型（LLM）以及 React、Next.js、Vue、Svelte、Node.js 等流行框架构建 AI 应用。

## Llama 3.1

Meta 的 Llama 3.1 的发布是 AI 发展史上的一个重要时刻。作为首个最先进的开放权重 AI 模型，Llama 3.1 正在帮助开发者加速构建 AI 应用。这些经过指令微调的模型提供 8B、70B 和 405B 三种尺寸，在对话生成、翻译、推理和代码生成等任务上表现出色。

## 基准测试

Llama 3.1 在常见行业基准测试中超越了大多数现有的开源聊天模型，甚至优于部分闭源模型，在语言细微差别、上下文理解和复杂多步任务方面表现卓越。这些模型经过优化的后训练流程显著改善了响应的对齐度，降低了错误拒答率，并提升了回答的多样性，使 Llama 3.1 成为构建生成式 AI 应用的强大而易用的工具。

## 选择模型尺寸

Llama 3.1 包含一个全新的 405B 参数模型，成为当今最大的开源模型。该模型专为处理最复杂、最严苛的任务而设计。

在 Llama 3.1 的不同尺寸（405B、70B、8B）之间做选择时，需要权衡性能与计算需求。405B 模型为复杂任务提供最高的准确性和能力，但需要大量计算资源。70B 模型对大多数应用而言在性能与效率之间取得了良好平衡；而 8B 模型则适合更简单的任务或资源受限的环境——在这些场景中，速度和更低的计算开销是首要考虑。

## AI SDK 快速上手

AI SDK 是一款 TypeScript 工具包，旨在帮助开发者使用 React、Next.js、Vue、Svelte、Node.js 等构建 AI 驱动的应用。将 LLM 集成到应用中相当复杂，且高度依赖于你所使用的具体模型提供商（provider）。

AI SDK 抽象掉了不同模型提供商之间的差异，消除了构建聊天机器人的样板代码，并让你能够超越纯文本输出，生成丰富、可交互的组件。

AI SDK 的核心是 [AI SDK Core](/docs/ai-sdk-core/overview)，它提供了调用任意 LLM 的统一 API。使用 AI SDK 调用 Llama 3.1（通过 [DeepInfra](https://deepinfra.com)）只需要下面这段代码：

```ts
import { deepInfra } from '@ai-sdk/deepinfra';
import { generateText } from 'ai';

const { text } = await generateText({
  model: deepInfra('meta-llama/Meta-Llama-3.1-405B-Instruct'),
  prompt: 'What is love?',
});
```

<Note>
  Llama 3.1 可与许多 AI SDK 提供商一起使用，包括 [DeepInfra](/providers/ai-sdk-providers/deepinfra)、[Amazon Bedrock](/providers/ai-sdk-providers/amazon-bedrock)、[Baseten](/providers/ai-sdk-providers/baseten)、[Fireworks](/providers/ai-sdk-providers/fireworks) 等。
</Note>

AI SDK Core 抽象掉了不同模型提供商之间的差异，让你可以专注于构建出色的应用。更想使用 [Amazon Bedrock](/providers/ai-sdk-providers/amazon-bedrock)？统一的接口也意味着你只需修改两行代码即可轻松切换模型。

```tsx highlight="2,5"
import { generateText } from 'ai';
import { amazonBedrock } from '@ai-sdk/amazon-bedrock';

const { text } = await generateText({
  model: amazonBedrock('meta.llama3-1-405b-instruct-v1'),
  prompt: 'What is love?',
});
```

### 流式响应

要在模型生成响应的同时进行流式输出，请将你的代码片段改为使用 [`streamText`](/docs/reference/ai-sdk-core/stream-text) 函数。

```tsx
import { streamText } from 'ai';
import { deepInfra } from '@ai-sdk/deepinfra';

const { textStream } = streamText({
  model: deepInfra('meta-llama/Meta-Llama-3.1-405B-Instruct'),
  prompt: 'What is love?',
});
```

### 生成结构化数据

虽然文本生成很有用，但你可能还想生成结构化的 JSON 数据。例如，你可能想从文本中提取信息、对数据进行分类，或生成合成数据。AI SDK Core 提供了 [`generateText`](/docs/reference/ai-sdk-core/generate-text) 和 [`streamText`](/docs/reference/ai-sdk-core/stream-text) 搭配 `Output` 来生成结构化数据，让你能够将模型输出约束到特定的 schema。

```ts
import { generateText, Output } from 'ai';
import { deepInfra } from '@ai-sdk/deepinfra';
import { z } from 'zod';

const { output } = await generateText({
  model: deepInfra('meta-llama/Meta-Llama-3.1-70B-Instruct'),
  output: Output.object({
    schema: z.object({
      recipe: z.object({
        name: z.string(),
        ingredients: z.array(
          z.object({ name: z.string(), amount: z.string() }),
        ),
        steps: z.array(z.string()),
      }),
    }),
  }),
  prompt: 'Generate a lasagna recipe.',
});
```

这段代码会生成一个符合指定 zod schema 的类型安全菜谱。

### 工具

虽然 LLM 拥有惊人的生成能力，但它们在处理离散任务（如数学）和与外部世界交互（如获取天气）方面并不擅长。解决方案是工具（tool）——它们类似于你提供给模型的程序，模型可以视需要选择调用。

### 在 AI SDK 中使用工具

AI SDK 在多个函数中支持工具使用，包括 [`generateText`](/docs/reference/ai-sdk-core/generate-text) 和 [`streamUI`](/docs/reference/ai-sdk-rsc/stream-ui)。通过向 `tools` 参数传入一个或多个工具，你可以扩展 LLM 的能力，使其能够执行离散任务并与外部系统交互。

下面是如何在 AI SDK 和 Llama 3.1 中使用工具的示例：

```ts
import { generateText, tool } from 'ai';
import { deepInfra } from '@ai-sdk/deepinfra';
import { z } from 'zod';

const { text } = await generateText({
  model: deepInfra('meta-llama/Meta-Llama-3.1-70B-Instruct'),
  prompt: 'What is the weather like today?',
  tools: {
    getWeather: tool({
      description: 'Get the weather in a location',
      inputSchema: z.object({
        location: z.string().describe('The location to get the weather for'),
      }),
      execute: async ({ location }) => ({
        location,
        temperature: 72 + Math.floor(Math.random() * 21) - 10,
      }),
    }),
  },
});
```

在这个示例中，`getWeather` 工具让模型能够获取实时天气数据，增强了它提供准确、最新信息的能力。

### 智能体

智能体（agent）让你的 AI 应用更进一步：允许模型以非确定性的方式执行多个步骤（即工具），并基于上下文和用户输入做出决策。

智能体使用 LLM 来选择问题解决过程中的下一步。它们可以在每一步进行推理，并根据不断演变的上下文做出决策。

### 用 AI SDK 实现智能体

AI SDK 通过 `stopWhen` 参数和内置停止条件支持智能体实现。这让模型能够在单次交互中做出多个决策和工具调用。

下面是一个解决数学问题的智能体示例：

```tsx
import { generateText, tool, isStepCount } from 'ai';
import { deepInfra } from '@ai-sdk/deepinfra';
import * as mathjs from 'mathjs';
import { z } from 'zod';

const problem =
  'Calculate the profit for a day if revenue is $5000 and expenses are $3500.';

const { text: answer } = await generateText({
  model: deepInfra('meta-llama/Meta-Llama-3.1-70B-Instruct'),
  instructions:
    'You are solving math problems. Reason step by step. Use the calculator when necessary.',
  prompt: problem,
  tools: {
    calculate: tool({
      description: 'A tool for evaluating mathematical expressions.',
      inputSchema: z.object({ expression: z.string() }),
      execute: async ({ expression }) => mathjs.evaluate(expression),
    }),
  },
  stopWhen: isStepCount(5),
});
```

在这个示例中，智能体可以在需要时多次使用计算器工具，逐步推理解决问题。

### 构建交互式界面

AI SDK Core 可以与 AI SDK 的另一个强大组件 [AI SDK UI](/docs/ai-sdk-ui/overview) 搭配使用，简化使用 Next.js、Nuxt、SvelteKit 等流行框架构建聊天、补全和助手界面的过程。

AI SDK UI 提供了强大的抽象，简化了在前端管理聊天流和 UI 更新的复杂任务，让你能够更高效地开发生动的 AI 驱动界面。

通过三个主要 Hook——[`useChat`](/docs/reference/ai-sdk-ui/use-chat)、[`useCompletion`](/docs/reference/ai-sdk-ui/use-completion) 和 [`useObject`](/docs/reference/ai-sdk-ui/use-object)——你可以在应用中集成实时聊天、文本补全、流式 JSON 和交互式助手功能。

让我们来探索如何结合 [Next.js](https://nextjs.org)、AI SDK 与 Llama 3.1（通过 [DeepInfra](https://deepinfra.com)）构建一个聊天机器人：

```tsx filename="app/api/chat/route.ts"
import { deepInfra } from '@ai-sdk/deepinfra';
import {
  convertToModelMessages,
  createUIMessageStreamResponse,
  streamText,
  toUIMessageStream,
  UIMessage,
} from 'ai';

// Allow streaming responses up to 30 seconds
export const maxDuration = 30;

export async function POST(req: Request) {
  const { messages }: { messages: UIMessage[] } = await req.json();

  const result = streamText({
    model: deepInfra('meta-llama/Meta-Llama-3.1-70B-Instruct'),
    messages: await convertToModelMessages(messages),
  });

  return createUIMessageStreamResponse({
    stream: toUIMessageStream({ stream: result.stream }),
  });
}
```

```tsx filename="app/page.tsx"
'use client';

import { useChat } from '@ai-sdk/react';
import { useState } from 'react';

export default function Page() {
  const [input, setInput] = useState('');
  const { messages, sendMessage } = useChat();

  const handleSubmit = (e: React.FormEvent<HTMLFormElement>) => {
    e.preventDefault();
    if (input.trim()) {
      sendMessage({ text: input });
      setInput('');
    }
  };

  return (
    <>
      {messages.map(message => (
        <div key={message.id}>
          {message.role === 'user' ? 'User: ' : 'AI: '}
          {message.parts.map((part, index) => {
            if (part.type === 'text') {
              return <span key={index}>{part.text}</span>;
            }
            return null;
          })}
        </div>
      ))}
      <form onSubmit={handleSubmit}>
        <input
          name="prompt"
          value={input}
          onChange={e => setInput(e.target.value)}
        />
        <button type="submit">Submit</button>
      </form>
    </>
  );
}
```

根页面（`app/page.tsx`）上的 useChat Hook 会在用户提交消息时向你的 AI 提供商端点（`app/api/chat/route.ts`）发起请求。随后消息会实时流式传回，并显示在聊天 UI 中。

这带来了流畅的聊天体验：用户可以在 AI 响应可用的第一时间看到它，而无需等待整个响应接收完毕。

### 超越文本

AI SDK 的 React 服务器组件（RSC）API 让你能够创建超越简单文本生成的丰富交互式界面。借助 [`streamUI`](/docs/reference/ai-sdk-rsc/stream-ui) 函数，你可以将 React 组件从服务器动态流式传输到客户端。

让我们深入了解如何利用 [AI SDK RSC](/docs/ai-sdk-rsc/overview) 中的工具，使用 Next.js（App Router）构建生成式 UI。

首先，创建一个 Server Action。

```tsx filename="app/actions.tsx"
'use server';

import { streamUI } from '@ai-sdk/rsc';
import { deepInfra } from '@ai-sdk/deepinfra';
import { z } from 'zod';

export async function streamComponent() {
  const result = await streamUI({
    model: deepInfra('meta-llama/Meta-Llama-3.1-70B-Instruct'),
    prompt: 'Get the weather for San Francisco',
    text: ({ content }) => <div>{content}</div>,
    tools: {
      getWeather: {
        description: 'Get the weather for a location',
        inputSchema: z.object({ location: z.string() }),
        generate: async function* ({ location }) {
          yield <div>loading...</div>;
          const weather = '25c'; // await getWeather(location);
          return (
            <div>
              the weather in {location} is {weather}.
            </div>
          );
        },
      },
    },
  });
  return result.value;
}
```

在这个示例中，如果模型决定使用 `getWeather` 工具，它会先在获取天气数据时输出一个 `div`，然后返回一个携带已获取数据的天气组件（注意：本例中为静态数据）。这使得 UI 更具动态性和响应性，能够根据 AI 的决策和外部数据进行调整。

在前端，你可以像调用应用中的其他异步函数一样调用这个 Server Action。在本例中，该函数返回一个普通的 React 组件。

```tsx filename="app/page.tsx"
'use client';

import { useState } from 'react';
import { streamComponent } from './actions';

export default function Page() {
  const [component, setComponent] = useState<React.ReactNode>();

  return (
    <div>
      <form
        onSubmit={async e => {
          e.preventDefault();
          setComponent(await streamComponent());
        }}
      >
        <button>Stream Component</button>
      </form>
      <div>{component}</div>
    </div>
  );
}
```

## 从 OpenAI 迁移

AI SDK 的关键优势之一是其统一的 API，这使得在不同 AI 模型和提供商之间切换变得异常简单。当你想从一个模型迁移到另一个模型时，例如从 OpenAI 的 GPT 模型迁移到 DeepInfra 上托管的 Meta Llama 模型，这种灵活性尤为有用。

迁移过程可以如此简单：

**OpenAI 示例**：

```tsx
import { generateText } from 'ai';
import { openai } from '@ai-sdk/openai';

const { text } = await generateText({
  model: openai('gpt-6-astra'),
  prompt: 'What is love?',
});
```

**DeepInfra 上的 Llama 示例**：

```tsx
import { generateText } from 'ai';
import { deepInfra } from '@ai-sdk/deepinfra';

const { text } = await generateText({
  model: deepInfra('meta-llama/Meta-Llama-3.1-70B-Instruct'),
  prompt: 'What is love?',
});
```

得益于统一的 API，代码的核心结构保持不变。主要区别在于：

1. 创建 DeepInfra 客户端
2. 将模型名称从 `openai("gpt-6-astra")` 改为 `deepInfra("meta-llama/Meta-Llama-3.1-70B-Instruct")`。

只需这几处改动，你就完成了从 OpenAI 的 GPT-6 Astra 到 DeepInfra 上托管的 Meta Llama 3.1 的迁移。`generateText` 函数及其用法保持完全一致，充分展示了 AI SDK 统一 API 的威力。

这一特性让你可以轻松试验不同的模型、比较它们的性能，并针对你的具体用例选择最佳模型，而无需重写代码库的大部分内容。

## 提示词工程与微调

虽然 Llama 3.1 系列模型开箱即用就很强大，但通过有效的提示词工程（prompt engineering）和微调（fine-tuning）技术，还可以进一步提升其性能。

### 提示词工程

提示词工程是指精心设计输入提示词（prompt）以从语言模型中引出期望输出的实践。它涉及以特定方式组织和措辞提示词，引导模型生成更准确、更相关、更连贯的响应。

如需了解提示词工程技巧（针对 Llama 模型）的更多信息，请查看以下资源：

- [Llama 3.1 官方提示词指南](https://llama.meta.com/docs/how-to-guides/prompting)
- [使用 Llama 3 进行提示词工程](https://github.com/amitsangani/Llama/blob/main/Llama_3_Prompt_Engineering.ipynb)
- [如何为 Llama 3 编写提示词](https://huggingface.co/blog/llama3#how-to-prompt-llama-3)

### 微调

微调是指在特定数据集或任务上对预训练模型进行进一步训练，以便针对特定用例定制其性能。这一过程让你能够将 Llama 3.1 适配到你的特定领域或应用，有望提升其准确性和与你需求的相关性。

如需了解 Llama 模型微调的更多信息，请查看以下资源：

- [Llama 官方微调指南](https://llama.meta.com/docs/how-to-guides/fine-tuning)
- [使用 Llama 3 进行微调与推理](https://docs.inferless.com/how-to-guides/how-to-finetune--and-inference-llama3)
- [使用 Fireworks AI 微调模型](https://docs.fireworks.ai/fine-tuning/fine-tuning-models)
- [使用 Modal 微调 Llama](https://modal.com/docs/examples/llm-finetuning)
