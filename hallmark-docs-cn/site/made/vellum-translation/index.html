一部翻译小说读起来，应当像它最初就是用你手中的语言写成的。

谁第一个读这本书？

译者。在改动任何一句之前，从封面读到封底。

寄出什么，收回什么？

从第一次通读到定稿。

阶段你寄来我们寄回
通读原书一份供版权决策参考的审读报告
试译一个章节那一章的译文
翻译全书文本成书
修订你的编辑的疑问清单修订稿

出版社还会问什么？

你们接诗歌或戏剧吗？

很少。小说与随笔才是我们的正业；尽管来问，如果不合适我们会直说。

校样还是成书？

都可以。校样的 PDF 最便于工作，也最便于对照引文。

书上署谁的名字？

译者的名字，至少在扉页上，以合同约定为准。

费用如何确定？

按篇幅与文本类型而定。动工之前，报价单上写明唯一的数字。

下一本该读什么书？

我们会回复一个开始通读的日期。
