别家厨房打烊之后，来一碗 ramen。

给还没睡的人，留一张吧台凳。

找到这家店

每张凳子都面对汤锅。

隔着吧台点单，一碗面直接从台上递过来——给刚下班的厨师、下夜班的护士，和走得最晚的人。趁热吃完，再把凳子让给还在等的人。

一碗面，自上而下。

先倒调味汁，最后铺配料。

  1. 配料

    最后铺上，最先吃掉。

  2. 香油

    薄薄一层油脂，把香气送到你面前。

  3. 面条

    从沸水中捞起，趁还有嚼劲时折进碗里。

  4. 汤底

    最厚的一层，滚烫地浇在调味汁上。

  5. 调味汁

    沉在碗底的调味，给整碗面定咸淡。

等街上安静下来，再来。
