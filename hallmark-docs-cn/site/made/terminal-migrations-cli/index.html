每一次迁移，都自带撤销。

shift 用一个 CLI 为 Postgres 和 MySQL 执行安全、可回滚的迁移。

$ brew install shift-cli

从 shift new 到 shift down

朴素的 SQL 文件，五条命令。

  1. shift new <name>

    生成 0046_<name>.up.sql 和对应的 .down.sql

  2. shift plan

    与每条命令一样，接受 --db 与 --to

  3. shift check

    需要在 --scratch 里给一个一次性数据库

  4. shift up --to <n>

    停在文件 <n>，并逐一核对校验和

  5. shift down --to <n>

    从最新开始回滚，回到 <n>

先在预发环境跑一次 shift plan

装上它，再读一读它将要做的事。

$ brew install shift-cli
$ shift plan --db $STAGING_URL
