一次同步，覆盖每台主机。

每台主机都通过 SSH 直连，中间不留任何东西。

~ $ burrow add ~/.zshrc ~/.gitconfig ~/.config/nvim
跟踪 3 个路径
 
~ $ burrow sync desk pi work
desk   ssh   3 个文件   完成
pi     ssh   3 个文件   完成
work   ssh   3 个文件   完成

无需服务器

三条命令。

这就是整个工具。

$ burrow add <path>
跟踪一个文件或文件夹。
$ burrow sync <host>…
把跟踪的内容通过 SSH 复制到每台主机。
$ burrow status
上次同步的结果，逐台主机列出。

你可以删掉的东西。

中间没有服务器，同步间隙也就没有需要一直跑着的东西。

按你顺手的方式安装。

然后在第一个开始想念的文件上运行 burrow add。

  • Homebrew$ brew install burrow
  • Cargo$ cargo install burrow
  • 脚本$ curl -fsSL script-url | sh
