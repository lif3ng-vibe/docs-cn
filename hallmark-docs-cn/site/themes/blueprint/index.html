一个框架如何起步

  1. 你提交方案

    平面、剖面或模型，无论进行到哪个阶段。

  2. 我们研读并回电

    由工程师——而非业务经理——与你逐项过一遍。

  3. 我们提出框架方案

    给出轴网、可选方案，以及每种选择对平面提出的要求。

把图纸发给我们

告诉我们建筑类型与所处阶段，并附上你手头的资料。
