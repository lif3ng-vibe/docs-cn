一个名字，三套系统

在一切未定之前，我们可能为同一家机构画出的样子。

识别系统要进驻的空间

鎏金、铸铁与白墙，收在同一套系统之下。

观众厅

节目册、字幕、票券

鎏金与红丝绒：节目册在这里必须撑得住场面。

裁切为 3:2，竖线取直。

舞台

海报、演出季、标牌

满光下的彩绘布景：海报必须能与它并立。

裁切为 3:2，竖线取直。

书库

标牌、索书号、卡片

五层铸铁书廊，每一块标牌都要让楼下的人读清。

裁切为 3:2，竖线取直。

展墙

展签、图说、地图

灰墙与长凳：展签立在作品一旁，而不是压在作品之上。

裁切为 3:2，竖线取直。

长厅

导视、墙文

一面长得需要专属标牌的白墙。

裁切为 3:2，竖线取直。
