NVIDIA OpenShell 是一个面向自主 AI 智能体编队的开源安全私有运行时。它提供沙箱化的执行环境，保护你的数据、凭据与基础设施。智能体以恰好满足所需的权限运行，不多不少；声明式策略约束其行为，阻止未经授权的文件访问、数据外泄与失控的网络活动。

<Aside type="note">
OpenShell 0.1.x 的新变化：[稳定的发布节奏](/about/support-matrix#发布)、新的[隔离原语](/about/architecture)，以及大幅扩展的[扩展面](/extensibility/overview)等。

所有变更详见[升级指南](/upgrade/0-1-0)。
</Aside>

两条命令安装 OpenShell 并创建你的第一个沙箱。
