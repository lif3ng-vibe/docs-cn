在 Node.js 应用与自动化中使用 TypeScript SDK。它提供精选沙箱 API 与一个 raw 生成客户端，覆盖完整的网关 RPC 表面。尽量使用同一 OpenShell 发布版本的 SDK 与网关。

## 安装 SDK

该包要求 Node.js 20.3 或更高版本，目前经 GitHub Packages 分发。在项目 `.npmrc` 中配置 `@nvidia` scope：

```text
@nvidia:registry=https://npm.pkg.github.com
```

用具有 `read:packages` 权限的 GitHub 令牌认证 npm，然后安装该包：

```shell
npm install @nvidia/openshell-sdk
```

## 连接到网关

`OpenShellClient.connect()` 接受网关 URL。它构造惰性客户端，启动时必须验证连通性就调用 `health()`：

```ts
import { OpenShellClient } from '@nvidia/openshell-sdk'

const client = await OpenShellClient.connect({
  gateway: 'https://gateway.example.com',
  oidcToken: process.env.OPENSHELL_TOKEN,
})

const health = await client.health()
console.log(`${health.status}: ${health.version}`)
```

长时间运行的 OIDC 服务自动化，使用可续期的 client-credentials 提供方：

```ts
import { clientCredentials, OpenShellClient } from '@nvidia/openshell-sdk'

const client = await OpenShellClient.connect({
  gateway: 'https://gateway.example.com',
  oidcTokenProvider: clientCredentials({
    issuer: 'https://idp.example.com/realms/openshell',
    clientId: 'openshell-service',
    clientSecret: () => process.env.OPENSHELL_OIDC_CLIENT_SECRET!,
    audience: 'openshell-gateway',
  }),
})
```

该提供方把凭据与令牌保留在内存中，并在过期前续期访问令牌。

## 获取提供商凭据

启用[操作员认证](/how-it-works/gateways/authentication#mtls-operator)之后，用受信任的 `OU=operator` 客户端证书直接连接。该连接不要提供 OIDC 或边缘令牌。不需要创建沙箱或挂接提供商。

```ts
import { readFileSync } from 'node:fs'
import { OpenShellClient } from '@nvidia/openshell-sdk'

const operator = await OpenShellClient.connect({
  gateway: 'https://gateway.example.com',
  caCert: readFileSync('ca.crt'),
  clientCert: readFileSync('operator.crt'),
  clientKey: readFileSync('operator.key'),
})
const credentials = await operator.providers.getCredentials(
  'my-graph',
  ['MS_GRAPH_ACCESS_TOKEN'],
  { workspace: 'production', minimumRemainingLifetimeSecs: 300 },
)
const token = credentials.MS_GRAPH_ACCESS_TOKEN!.value
```

`ProviderClient.connect()` 作为独立客户端提供相同的 API。与沙箱操作不同，`getCredentials()` 要求显式工作区。它返回 `ProviderCredentialValue` 对象的记录，含 `value` 与可选的 `expirationTime`（`Date`）。亚毫秒的过期精度会被截断。`minimumRemainingLifetimeSecs` 接受小数秒；省略或为零使用网关默认值。在操作选项中传 `signal` 或 `timeoutMs` 限定交付。该辅助方法不重试也不缓存导出；交付被取消不会回滚已经开始的网关刷新。

不要把返回值留在日志与共享输出中。新鲜度、受支持凭据与导出安全边界参见[获取运行时凭据](/how-it-works/providers/overview#获取运行时凭据)。

## 创建并使用沙箱

精选客户端使用 `default` 工作区，除非你在操作的选项中传 `workspace`：

```ts
const sandbox = await client.sandbox.create({
  name: 'sdk-example',
  image: 'registry.example.com/team/python-agent:1.0',
})

await client.sandbox.waitReady(sandbox.name, 120)

const result = await client.sandbox.exec(
  sandbox.name,
  ['python', '-c', "print('hello from OpenShell')"],
)
console.log(result.stdout.toString())

const deletion = await client.sandbox.delete(sandbox.name)
if (deletion.outcome === 'accepted') {
  await client.sandbox.waitDeleted(sandbox.name, 60, {
    expectedSandboxId: deletion.sandboxId,
  })
}
```

`create`、`get` 与 `list` 返回的沙箱引用包含 `createdAtMs`，即以纪元毫秒表示的创建时间。网关省略该字段时它不存在。

`client.sandbox` 还支持流式与交互式 exec、TCP 转发、SSH 会话、沙箱提供商挂接、配置与策略。用完请关闭操作作用域的流与转发句柄。根客户端不保留专用会话，也没有 `close()` 方法。

## 监控日志与事件

`watchLogs` 流式传输沙箱的日志行与平台事件，支持自动重连与感知丢失的续传。把之前条目的 `cursor` 作为 `resumeAfterCursor` 传回，即可在重启之后无缺口、无重复地继续：

```ts
for await (const item of client.sandbox.watchLogs(sandbox.name, { followLogs: true })) {
  if (item.kind === 'log') {
    console.log(`${item.line.level} ${item.line.message}`)
  } else if (item.kind === 'warning') {
    console.warn(`gap: ${item.message}`)
  }
}
```

续传游标已过期时，`watchLogs` 会以一个 `SdkError` 停止，其 `code` 为 `rpc`，`connectCode` 为 `Code.OutOfRange`。要接受缺失的事件，用空的 `resumeAfterCursor` 开始新的监视。

该方法实现的游标与续传契约参见[访问日志](/observability/accessing-logs)。

## 使用 raw 客户端

精选客户端尚未包装的 RPC 请用 `client.raw`。从 `@nvidia/openshell-sdk/raw` 导入生成的消息 schema 与类型。raw 调用返回 protobuf 线上形态，精选调用返回 SDK 专属类型。
