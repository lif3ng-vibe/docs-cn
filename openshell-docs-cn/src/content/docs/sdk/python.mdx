用 Python SDK 从应用、notebook 与自动化中管理沙箱。它可以复用 OpenShell CLI 创建的网关注册与认证状态。尽量使用同一 OpenShell 发布版本的 SDK 与网关。

## 安装 SDK

该包要求 Python 3.11 或更高版本。用 `uv` 把它加入项目：

```shell
uv add openshell
```

`openshell` 包包含 SDK。它不会安装 OpenShell CLI。

## 连接到已注册的网关

先用 CLI 注册并选择网关。然后从活动网关构造客户端：

```python
from openshell import SandboxClient

with SandboxClient.from_active_cluster() as client:
    health = client.health()
    print(health.version)
```

`from_active_cluster()` 读取所选网关端点、TLS 文件与 OIDC 令牌状态。它默认刷新即将过期的 OIDC 令牌，并把轮换后的凭据束写回，供其他 OpenShell 进程使用。

直接建立本地明文连接时，传入 `host:port` 端点：

```python
from openshell import SandboxClient

with SandboxClient("127.0.0.1:8080") as client:
    print(client.health().version)
```

面向 OIDC 网关做服务自动化时，使用 `ClientCredentialsAuth`。非回环端点要求 TLS：

```python
import os

from openshell import ClientCredentialsAuth, SandboxClient

auth = ClientCredentialsAuth(
    issuer="https://idp.example.com/realms/openshell",
    client_id="openshell-service",
    client_secret=lambda: os.environ["OPENSHELL_OIDC_CLIENT_SECRET"],
    audience="openshell-gateway",
)

with SandboxClient.from_active_cluster(client_credentials=auth) as client:
    print(client.health().version)
```

## 获取提供商凭据

启用[操作员认证](/how-it-works/gateways/authentication#mtls-operator)之后，用受信任的 `OU=operator` 客户端证书直接连接。该连接不要提供 Bearer 令牌，也不要用 OIDC 登录。不需要创建沙箱或挂接提供商。

```python
from datetime import timedelta
from pathlib import Path

from openshell import SandboxClient, TlsConfig

tls = TlsConfig(
    ca_path=Path("ca.crt"),
    cert_path=Path("operator.crt"),
    key_path=Path("operator.key"),
)
with SandboxClient("gateway.example.com:443", tls=tls) as client:
    credentials = client.providers().get_credentials(
        "my-graph",
        ["MS_GRAPH_ACCESS_TOKEN"],
        workspace="production",
        minimum_remaining_lifetime=timedelta(minutes=5),
    )
    token = credentials["MS_GRAPH_ACCESS_TOKEN"].value
```

`ProviderClient` 也接受既有的 `grpc.Channel`。其 `get_credentials()` 方法要求显式指定工作区与键。它返回 `ProviderCredentialValue` 对象字典，含 `value` 与可选的 `expiration_time`（UTC `datetime`）。`minimum_remaining_lifetime` 传 `timedelta`；省略或为零使用网关默认值。该辅助方法使用连接的超时，不重试也不缓存导出。网关失败抛出 `GatewayError`；本地选择无效抛出 `ValueError`。

值不会出现在对象的 `repr` 中，但序列化仍会暴露它。不要把导出的机密留在日志与共享输出中。新鲜度、受支持凭据与导出安全边界参见[获取运行时凭据](/how-it-works/providers/overview#获取运行时凭据)。

## 创建并使用沙箱

Python SDK 方法要求显式工作区。本例创建沙箱、等待就绪、运行命令并等待删除完成：

```python
from openshell import SandboxClient

with SandboxClient.from_active_cluster() as client:
    sandbox = client.create(
        workspace="default",
        name="sdk-example",
    )
    client.wait_ready(
        sandbox.name,
        workspace="default",
        timeout_seconds=120,
    )

    result = client.exec(
        sandbox.name,
        ["python", "-c", "print('hello from OpenShell')"],
        workspace="default",
    )
    print(result.stdout, end="")

    deletion = client.delete(sandbox.name, workspace="default")
    client.wait_deleted(
        sandbox.name,
        workspace="default",
        expected_sandbox_id=deletion.sandbox_id,
    )
```

需要一个保留沙箱名与工作区的对象以便反复执行 exec、stop、start 与 delete 时，使用 `create_session()`。list 方法返回惰性 `Pager` 实例；只有要取回完整集合时才用 `list_all()`。

## 实现凭据驱动

SDK 包含为凭据驱动与扩展协议生成的消息类、类型 stub 与 gRPC 绑定：

```python
from openshell._proto import credential_driver_pb2, credential_driver_pb2_grpc
from openshell._proto import datamodel_pb2, extension_pb2
```

继承 `credential_driver_pb2_grpc.CredentialDriverServicer`，并用同一模块中的 `add_CredentialDriverServicer_to_server()` 注册你的实现。客户端使用 `CredentialDriverStub`。生成的消息与 SDK 共享 `datamodel_pb2.CredentialHandle` 与 `extension_pb2.PeerMetadata`。请使用与网关同一 OpenShell 发布版本的绑定；这些模块暴露的是内部凭据驱动契约。
