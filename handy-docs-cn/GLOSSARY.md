# 术语表（翻译统一口径）

## 译法约定

- 意译为主；术语首次出现附英文原词「语音转文字（speech-to-text）」；此后纯中文。
- UI 选项名（设置页里的英文名称）首现译出并括注原文，之后用中文。代码、命令、键位组合不译。
- 语言名称列表（LanguageList 组件里的 99+ 语言名）属模型数据，保留英文原文不译；组件标题译。
- 下载相关引导一律指向官方页面 https://handy.computer/download （用户要求：镜像站不承载下载）。
