# 关于 Handy

我做 Handy 的起因很简单：我摔断了一根手指，打上石膏，一只手就这么废了。试了一圈现有的语音转文字应用，却发现没有一款既开源又可扩展。于是 Handy 就为填补这个空缺而生。

它大概是最简单的语音转文字应用了，唯一的功能就是把你说的话放进文本框：按住快捷键、说话、松开，你说的内容就出现在你正在打字的地方。它用 Whisper 完全离线运行，跨平台可用，不需要订阅，也不依赖云服务。

## 项目目标

Handy 不是想当最好的语音转文字应用，而是想成为最适合 fork 的那一个。

当你需要辅助功能、想折腾语音计算，或者只是偏爱真正属于自己、可以随意修改的工具时，Handy 就是一个现成的起点。这个项目刻意做得小巧而可扩展。它有自己的取舍，你提的功能需求不一定都会进主线，但我们非常欢迎你亲手实现它们。有了 Claude Code 和各类智能体编程工具的帮助，哪怕毫无编程经验，你也许真能做到。

拿去，fork 它，改它，搞坏它，再修好它。做出了不起的东西，分享给所有人。

## 背后的原理

- 按快捷键开始/停止录音（或使用按住说话（push-to-talk）模式）
- 通过 VAD（silero）滤镜去除静音
- 用你选择的 Whisper 或 Parakeet 模型转写你的语音
- 把文本直接粘贴进你正在使用的应用
- 完全在本机运行，可用时启用 GPU 加速
- 支持 Windows、macOS 和 Linux

就这么简单。
