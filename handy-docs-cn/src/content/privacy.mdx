# 隐私政策

**生效日期：September 18, 2026**

Handy 是一款由 CJ Pais 与各位贡献者维护的开源、本地优先语音转文字应用。本政策说明官方 Handy 桌面应用与 [handy.computer](https://handy.computer) 网站如何处理信息。

本政策适用于官方发布的 Handy 版本以及为 Handy 项目运营的各项服务。经过修改或再分发的 Handy 版本可能有不同的做法。

## 简要版本

- Handy 不需要注册账户。
- 语音识别在你的设备上运行。
- 在日常转写过程中，Handy 不会把你的麦克风音频或转写内容发送给 Handy 维护者或 Handy 服务器。
- Handy 不包含广告、行为分析或用户跟踪遥测。
- 网络访问仅用于软件更新、模型下载，以及你自行选择配置的可选服务。
- 录音、转写文本、设置与日志均存储在你的设备本地。

## 本地语音处理与存储

Handy 的语音识别模型在你的设备上运行。当你使用 Handy 时，应用可能在本地处理并存储以下信息：

- 麦克风音频与录音；
- 原始及后处理的转写文本；
- 转写历史记录、时间戳与保存状态；
- 应用设置、自定义词与自定义提示词；
- 麦克风、音频设备、语言与模型的选择；
- 诊断日志；以及
- 可选后处理服务商的凭据。

默认情况下，Handy 只保留有限数量的近期历史记录条目及其录音。被你标记为已保存的条目可能会一直保留，直到你删除它们。你可以删除单条记录、调整保留期限，或将历史上限设为零。

官方发布版本会在诊断日志中隐去转写内容。开发版或自行编译的调试版可能产生更详细的日志。

Handy 使用操作系统权限来实现麦克风访问、全局键盘快捷键、借助辅助功能进行粘贴以及剪贴板访问等功能。这些权限仅用于提供你所请求的功能。

## 网络连接

Handy 可能发起以下网络连接。

### 软件更新

在启用更新检查时，Handy 会连接 GitHub Releases，以判断是否有新版本可用并下载更新。更新检查默认启用，可以在 Handy 的设置中关闭。

### 模型下载

当你下载语音识别模型时，Handy 可能连接 Hugging Face 及其内容分发服务商。如果 Hugging Face 下载失败，Handy 可能改从 `blob.handy.computer` 获取模型，该服务由 Cloudflare 提供。

这些服务可能收到常规的技术请求信息，例如你的 IP 地址、请求时间、所请求的模型或文件、通过 HTTP 头传递的应用或设备信息，以及下载状态。模型下载与更新请求不包含你的麦克风音频或转写内容。

### 可选后处理

Handy 通过你自行选择的 AI 服务商、本地服务或自定义端点提供可选的后处理功能。云端后处理默认关闭，只有在你完成配置并主动调用时才会启用。

当你调用云端后处理时，Handy 会把转写内容、所选提示词、模型信息以及该请求所需的身份验证凭据，从你的设备直接发送给你选择的服务商。Handy 的维护者不会接收或代理这些内容。

由所选服务商进行的处理受该服务商的隐私政策与条款约束。受支持的服务商可能包括 OpenAI、Anthropic、OpenRouter、Groq、Cerebras、Z.AI 与 AWS Bedrock。自定义端点则受该端点运营者的政策约束。如果你不希望转写内容被发送给其他服务，请保持云端后处理关闭，或使用设备端或本地端点。

## 网站

Handy 网站目前不嵌入广告、行为分析或第一方跟踪 Cookie。它可能在本地使用浏览器信息，为你的操作系统显示合适的下载选项。

网站与模型下载基础设施使用 Cloudflare 提供托管、内容分发、安全性与可靠性保障。Cloudflare 可能处理诸如 IP 地址、浏览器与设备信息、所请求的页面或文件、时间戳以及安全信号等技术信息。Cloudflare 可能在必要时使用基本的安全机制来保护服务。

网站包含指向 GitHub、捐赠服务商、赞助商及其他第三方网站的链接。当你点开这些链接时，第三方会收到你的请求，并按照其自身的隐私政策处理信息。

## 沟通、社区参与与捐赠

如果你通过电子邮件、GitHub、Discord 或其他社区平台联系 Handy 维护者，我们可能使用你自愿提供的信息来回复、排查问题或维护项目。提交到公开 GitHub issue、讨论区或其他公开社区的信息是公开的。

捐赠由 Stripe、GitHub Sponsors 等第三方服务商处理。Handy 不会收到完整的支付卡信息，但服务商可能与项目维护者共享交易、联系方式或支持者信息。

## 信息的共享与出售

Handy 不出售个人信息，也不为定向广告而共享个人信息。

信息只会在以下情况下被披露：

- 你指示 Handy 与第三方服务通信时；
- 为运营网站、分发软件或模型而必需的基础设施服务商；
- 你通过支持或社区渠道自愿提供信息时；或
- 为遵守适用法律或保护项目、其用户或他人所必需时。

## 保留与删除

Handy 维护者不会保留本地处理的音频、录音或转写历史的副本，因为这些信息根本不会送达维护者手中。

本地信息会依照你的保留设置留在你的设备上，直到你删除它们。卸载 Handy 未必会自动删除其应用数据目录。Handy 的「关于」与「调试」页面提供了前往相应数据、录音与日志目录的快捷方式。

基础设施服务商可能按照其自身政策与配置的保留期限保留技术请求日志。支持沟通与捐赠记录可能会在对回复、维护项目档案、防止滥用或履行法律义务属合理必要的范围内予以保留。

## 安全

Handy 通过在本地处理语音来尽量减少数据传输。本地应用数据由你的操作系统账户与文件系统控制机制保护。Handy 目前没有为其本地历史记录或设置文件增加额外的应用层加密。保护好你的设备以及为外部服务输入的凭据，是你自己的责任。

## 法律依据与跨境处理

在适用法律要求法律依据的情况下：网站与下载相关技术数据的处理，是运营、保障并改进本项目这一正当利益所必需的；沟通信息的处理是为了回复你的请求；记录的处理可能是为了履行法律义务。可选的第三方处理，仅发生在你选择并指示 Handy 使用该服务之时。

Cloudflare、GitHub、Hugging Face、社区平台以及可选服务商可能在你的所在国以外的国家/地区处理信息。它们对国际传输的处理方式见各自隐私政策。

## 你的选择与权利

你可以：

- 关闭更新检查；
- 保持云端后处理关闭；
- 使用设备端或本地后处理端点；
- 删除单条历史记录；
- 调整录音保留设置；
- 将历史上限设为零以停用转写历史；以及
- 删除 Handy 的本地应用数据。

由于 Handy 不运营用户账户，也不会接收你本地的转写内容，维护者通常无法访问、导出或删除仅存储在你设备上的信息。

根据你所在地的法律，对于项目维护者掌握的个人信息（例如支持沟通记录或捐赠记录），你可能享有相关权利。如需提出请求，请通过下方的地址联系我们。你可能还有权向所在地的数据保护机构投诉。
