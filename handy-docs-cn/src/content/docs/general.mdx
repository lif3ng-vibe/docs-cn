## 转写快捷键

用于录制并转写你语音的键盘快捷键。在默认的按住说话(push-to-talk)模式下,按住快捷键开始录音,松开即停止;在切换模式(toggle mode)下,按一次开始,再按一次停止。

默认快捷键在 macOS 上是 `Option + Space`,在 Windows/Linux 上是 `Ctrl + Space`。你可以点击快捷键输入框并按下自己喜欢的组合键来自定义。

在 macOS 上,很多人喜欢用 `Fn` 键。在 Windows 和 Linux 上,快捷键默认要求至少一个修饰键(Ctrl、Alt、Shift)加一个普通按键。你可以在[高级](/docs-cn/handy/docs/advanced#快捷键实现)设置中启用实验性的 Handy Keys 实现,获得更灵活的键位绑定。

如果你确实选了 `Fn`(或 Globe 键),有一点值得了解:它只有从 Apple 键盘——Mac 的内置键盘或 Apple 外接键盘——才能传到 macOS。`Fn` 不属于标准 USB HID 键盘规范,因此第三方键盘完全在各自的固件里处理该键,不会发出任何可供 Handy 检测的信号。如果你使用 Apple 键盘,它依然是一个极佳的快捷键;如果你在 Apple 键盘和第三方键盘之间切换,建议用标准修饰键(`Ctrl`、`Option`、`Shift`、`Command`)或普通按键来构建快捷键,这样两者都能触发。

## 按住说话

按住快捷键录音,松开停止。这是默认的录音模式,非常适合快速听写,也能避免麦克风一直开着。

### 切换模式

关闭按住说话后,Handy 改用切换模式。按一次快捷键开始录音,再按一次停止并转写。

## 声音

### 麦克风

选择 Handy 录音所用的麦克风。默认情况下,Handy 使用系统的默认输入设备。如果你有多个麦克风(USB、蓝牙、内置),可以在这里指定某一个。在 MacBook 上,我们强烈建议使用内置麦克风。

注意,蓝牙设备在 Handy 上可能存在问题。我们正在持续改进对蓝牙麦克风/耳机的支持。

使用下拉框旁边的刷新按钮,可以重新扫描新接入的设备。

### 录音时静音

启用后,Handy 会在录音期间静音系统音频。也就是说,正在播放的音乐或其他声音都会被暂时静音。

### 提示音

启用后,Handy 会在录音开始和结束时播放提示音(audio feedback),给你一个清晰的听觉信号,表明 Handy 正在聆听。

### 输出设备

选择播放提示音的音频设备。仅在启用提示音后可用。使用刷新按钮可重新扫描设备。

### 音量

调节提示音的音量。仅在启用提示音后可用。
