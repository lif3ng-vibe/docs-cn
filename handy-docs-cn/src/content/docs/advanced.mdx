高级(Advanced)设置标签页包含应用行为、文本输出微调、历史记录管理和实验性功能等选项,可在 **设置 > 高级** 中访问。粘贴方式与打字工具请见专门的[粘贴方式](/docs-cn/handy/docs/paste-methods)页面。

## 应用

### 启动时隐藏

启动 Handy 时直接进入系统托盘,不打开主窗口。适合想让 Handy 始终在后台运行的场景。

### 开机自启

登录电脑时自动启动 Handy。

### 显示托盘图标

在系统托盘中显示 Handy 图标。启用后,你可以右键点击托盘图标访问快捷操作,例如卸载模型。

### 悬浮层位置

控制录音和转写期间视觉反馈悬浮层(overlay)出现的位置。

- **底部**(Bottom)- 悬浮层出现在屏幕底部
- **顶部**(Top)- 悬浮层出现在屏幕顶部
- **无**(None)- 不显示悬浮层

在 Linux 上推荐选择 **无**(None),因为悬浮层可能抢走目标窗口的焦点,导致无法粘贴。

#### 悬浮层状态

悬浮层会显示当前状态:

- **录音中**(Recording)- Handy 正在监听你的麦克风
- **处理中**(Processing...)- 正在转写(如启用了后处理,也会一并执行)

**注意**:悬浮层上的 (x) 按钮会取消录音并丢弃所有音频,而不是停止并转写。要停止录音并获得转写结果,请再按一次键盘快捷键。

### 取消录音

如果误触开始录音,可以取消:

- 录音时按 `Escape` 取消,不进行转写
- 点击悬浮层上的 (x) 按钮
- 悬浮层会消失,不会粘贴任何内容

你可以在[调试](/docs-cn/handy/docs/debug)设置中自定义取消快捷键(Linux 上不可用)。

### 卸载模型

当模型在指定时间内未被使用时,自动释放 GPU/CPU 内存,可选范围从立即释放到 1 小时后。设为“从不”(Never)可让模型始终驻留内存;设为“立即”(Immediately)则在转写完成后立刻释放内存。如果你还要运行其他 GPU 密集型应用,希望 Handy 在空闲时释放内存,这个选项会很有用。你也可以右键点击系统托盘图标并选择“卸载模型”(Unload Model)手动释放内存。

## 输出

### 自动发送

在文本插入后自动发送一个按键组合。适合聊天应用和命令行等听写完就想立即发送的场景。

选项:
- **关闭**(Off)- 不自动发送(默认)
- **Enter** - 模拟按下 Enter 键
- **Cmd+Enter** - 适用于用 Cmd+Enter 发送的 macOS 应用
- **Super+Enter** - 适用于 Windows/Linux 应用
- **Ctrl+Enter** - 适用于用 Ctrl+Enter 发送的应用(例如部分聊天应用)

### 剪贴板处理

控制 Handy 粘贴文本后剪贴板的处理方式。

- **不修改剪贴板**(Don't Modify Clipboard)- Handy 在粘贴后恢复你之前的剪贴板内容,剪贴板历史得以保留。
- **复制到剪贴板**(Copy to Clipboard)- Handy 在粘贴后把转写内容留在剪贴板中。如果你想在别处再次粘贴同样的文本,这会很有用。

## 转写

### 自定义词

添加在转写中经常被听错的词。Handy 会自动把发音相近的词纠正成你列表中的写法。这对模型容易搞错的人名、行话或技术术语很有用。不过这个功能并不完美,想要更好的效果,[实验性的后处理功能](/docs-cn/handy/docs/post-processing)可能是你的最佳选择。

示例:

| 听错的词 | 纠正为 |
|----------|-------------|
| "handy" | "Handy" |
| "astro js" | "Astro.js" |
| "c j" | "CJ" |

你可以通过[调试](/docs-cn/handy/docs/debug)设置中的词纠错阈值(Word Correction Threshold)调整纠正的激进程度。

### 追加尾随空格

启用后,Handy 会在粘贴的转写文本后追加一个空格。适合连续听写的场景,让相邻两次转写之间有空白隔开。

## 历史记录

### 历史记录上限

设置保留的历史记录条数上限。达到上限后,较旧的记录会被移除。设为 **0** 可完全禁用历史记录。

### 自动删除录音

自动删除旧的音频录音以节省磁盘空间。你可以只保留最近 N 条录音(使用历史记录上限的数值),也可以删除超过设定期限(3 天、2 周或 3 个月)的录音。

查看和管理转写历史请见[历史记录](/docs-cn/handy/docs/history)页面。

## 实验性功能

启用仍在开发中的实验性功能。开启后会显示更多选项:

### 后处理

启用转写后的 AI 文本润色。启用后,侧边栏会出现新的 **后处理**(Post Process)分区。设置方法见[后处理](/docs-cn/handy/docs/post-processing)指南。

### 快捷键实现

选择键盘快捷键的后端实现,它决定 Handy 如何注册和监听键盘快捷键。大多数情况下默认实现就够用了。如果遇到快捷键无法注册的问题,可以尝试切换实现。

**注意**:更改快捷键实现可能会把你的键盘快捷键重置为默认值。
