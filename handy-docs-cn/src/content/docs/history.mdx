历史记录(History)标签页展示你所有的历史转写,可从 Handy 设置窗口的侧边栏进入。

每条记录都会显示时间戳、转写文本,以及一个用于回放原始录音的音频播放器。你可以把任意转写复制到剪贴板、加星标以防自动删除,或将其彻底删除。使用历史记录标签页顶部的按钮,可以打开磁盘上的录音文件夹。

## 管理历史记录

这些设置位于[高级 > 历史记录](/docs-cn/handy/docs/advanced#历史记录)。

### 历史记录上限

设置保留的历史记录条数上限。达到上限后,较旧的记录会被移除。设为 **0** 可完全禁用历史记录。

### 自动删除录音

自动删除旧的音频录音以节省磁盘空间。“保留最近 N 条”(Keep latest N)选项使用历史记录上限的数值;其他选项则按时间范围而非录音条数来删除。
