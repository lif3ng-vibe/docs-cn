# Handy 按钮

Handy 按钮是专为触发 Handy 快捷键而做的单一用途输入设备。它们可以非常好玩：几乎任何能塞进一块微控制器和一个按钮的东西，都能做成 Handy 按钮。现成的硬件也可以改造再利用。放开脑洞，玩得开心，做一个属于你自己的语音转文字按钮吧！

## 亲手做一个 Handy 按钮

Handy 按钮的核心思路，是做一个键盘输入设备，让它替你按下你想要的快捷键。
这件事听起来相当复杂，某种程度上也确实如此。好在 DIY 机械键盘社区的文档通常都很完善，能让这件事容易不少。

**你需要准备几样主要材料**：
* 一个你想改造成按钮的东西
* 一块支持 QMK/ZMK 或类似键盘固件的微控制器
* 固件本身
* 某种作为按钮的开关

将来我们可能会整理一份更完整的制作指南；不过眼下，先看看现有的 Handy 按钮和它们的制作记录吧！
