## 什么时候用

`/impeccable quieter` 是 `/impeccable bolder` 的配重。界面视觉攻击性过强、刺激过载，或者什么都用最大音量抢戏时，找它。暗底霓虹、满屏渐变文字、6 种强调色、全部带动画、20px 的阴影。设计需要喘口气、而你又想要精修而不是丢掉立场时，用 quieter。

`/impeccable bolder` 玩过头之后，它也很好用。

## 工作原理

这项技能靠做减法，沿四条轴展开：

1. **颜色**：去饱和，在 OKLCH 里降彩度，把强调色收敛为一个主色加低调辅助。有意使用的颜色不超过两个。
2. **对比**：把极端的深与浅调柔和，收窄范围。背景从纯白与纯黑，走向纸与墨。
3. **装饰**：去掉不干活的阴影，删掉不承重的边框，让只为营造气氛而非服务层级的渐变退场。
4. **动效与特效**：把动画放慢，移除一切自动播放的东西，除非服务可读性，否则去掉视差和模糊。

技能保留设计的意图。原作有立场的话，安静版仍持同样的立场，只是更有底气。是精修，不是中和。

## 试一试

```
/impeccable quieter the pricing page
```

典型 diff：

- 价格上的渐变文字移除，换成加粗一号的实色墨色
- 三种强调色收敛为一种（品红），另外两种变成中性变体
- 卡片阴影从 `0 20px 40px rgba(0,0,0,0.2)` 降到 `0 1px 0 var(--color-mist)`（一根发丝线）
- 背景从深色渐变换成纸色，顶部带一层细微的奶油色晕染
- hero 动画从 1.2s easeOut、3 个元素错峰进场，收成一个 260ms 的淡入

## 常见陷阱

- **用力过猛**。对本来已经克制的东西跑 Quieter，会磨掉个性。设计太吵时用它；恰到好处的自信不需要它。
- **把 quieter 和 distill 搞混**。Quieter 降强度，Distill 删元素。是两步不同的棋。
- **因为 critique 说"太闹"就跑它**。"闹"通常指东西太多，不是声音太大。先试试 `/impeccable distill`。
