## 什么时候用

`/impeccable layout` 针对那些技术上没毛病、但也毫无呼吸感的页面。处处相同的内边距、千篇一律的卡片网格、顶到边的内容、只靠字号撑起来的层级。当布局"感觉不对"而你说不清为什么时，用它。

典型的触发语："一切都好挤""读起来像一堵墙""不知道先看哪儿"。

## 工作原理

这项技能过一遍五个布局维度：

1. **间距**：间距刻度是否一致，还是到处是随机的 13px 空隙；相关元素是否紧挨成组、组间留白充足；到底有没有节奏。
2. **视觉层级**：视线能否在 2 秒内落到主操作上；层级是在干实事，还是所有元素都在喊叫。
3. **网格与结构**：有没有底层网格，还是布局全凭随机；元素有没有对齐基线。
4. **节奏**：页面是否在紧凑与宽松之间交替，还是处处均匀。
5. **密度**：布局是局促还是浪费；密度与内容类型是否匹配。

修复通常包括：重建间距刻度、引入不对称、把单调网格收拢为 hero 与辅助元素混排的布局，以及给主操作真正的空间。

## 试一试

```
/impeccable layout the settings page
```

典型改动：

- 间距刻度统一为 8 / 16 / 24 / 48 / 96px
- 分节间距 48px，行距 16px，表单字段组 8px
- 主操作从表单流中拉出，留出 32px 缓冲
- 去掉装饰性边框，改用间距驱动的分组
- 侧栏与主栏的比例重新平衡（280 / flex，取代 25 / 75）

## 常见陷阱

- **把排布（arrange）和提纯搞混**。如果问题是东西太多，先跑 `/impeccable distill`。Layout 解决的是给已经合适的一组东西排布。
- **指望它拯救一个坏掉的网格**。如果页面压根没有网格，排布也会建一个。只是心里要有数：diff 会比你以为的大。
- **无视层级判定**。如果排布判定"没有东西是主角"，再多间距功夫也救不了。你需要的是内容决策，不是布局微调。
