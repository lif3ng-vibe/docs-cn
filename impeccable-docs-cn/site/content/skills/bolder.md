## 什么时候用

当界面看起来和所有其他界面一个样时，就用 `/impeccable bolder`。大路货的无衬线体、中等字重、柔和阴影、收敛的强调色、合理的间距——毫无记忆点。设计没有错，只是太保守。当项目撑得起气场、而当前状态又完全没带来气场时，用 bolder。

不要用在让人一盯几个小时的仪表盘上。大胆适合营销页、hero 区和内容型功能，不适合操作型工具。

## 工作原理

这项技能在不破坏可用性的前提下放大四个轴：

1. **尺度**：展示字体推到 clamp(3rem, 6vw, 6rem) 甚至更大。让标题填满视口，而不是在视口里缩手缩脚。
2. **字重对比**：用 300 细体对 800 重体，而不是 medium 对 regular。真正的张力，而不是耸耸肩。
3. **色彩投入**：强调色以全强度出现，不被稀释。背景可以表态（墨色、强调色、奶油色），而不是清一色纸白。
4. **构图自信**：不对称、出格、引文块、悬挂标点、尺度跳变。布局有了自己的声音。

这项技能不做加法。它放大已有的东西。如果设计有三个颜色，bolder 不会加第四个，而是把这三个用得更坚决。

## 试一试

```
/impeccable bolder the landing page hero
```

预期变化：

- hero 标题从 3rem 提到 clamp(3.5rem, 7vw, 6.5rem)，展示字体，字重 700
- 副标题从 regular 换成 1.5rem 斜体，相对标题左移 8px 做光学对齐
- 背景从纸白切换为奶油色到纸白的渐变，营造更温暖的容器
- CTA 按钮改为实心填充，去掉投影，圆角缩小，hover 状态反转配色
- 配图用负上边距轻微推出网格，制造不对称

## 常见陷阱

- **用错了页面**。产品仪表盘、设置页和表单不该追求大胆，该追求易读。改用 `/impeccable layout` 或 `/impeccable polish`。
- **把大胆当成吵闹**。大胆意味着坚决和自信，吵闹意味着喊叫。bolder 是前者。如果结果显得咄咄逼人，接着跑 `/impeccable quieter`。
- **在同一轮里搭配 `/impeccable delight`**。delight 在稳定的视觉基线上效果最好。先大胆，再稳定，最后加乐趣。
