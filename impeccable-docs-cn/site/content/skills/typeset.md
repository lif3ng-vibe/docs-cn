## 什么时候用

页面上的文字看起来是默认排版而非设计过的排版时，用 `/impeccable typeset`。层级浑浊、三个字号看起来一个样、正文 14px、展示字体其实就是 Inter 加粗、标题完全没管过字距。

常见的触发语："层级很平""可读性不对劲""字体一股大路货味"。

## 工作原理

这项技能沿五个维度评估排版：

1. **字体选择**：是不是在用毫无存在感的默认字体（Inter、Roboto、Arial、Open Sans）；字体是否贴合品牌；字族是否超过 2 到 3 个。
2. **层级**：标题、正文、说明文字是否一眼可辨；相邻级差的字号对比是否至少 1.25 倍；字重对比是否清晰可读。
3. **字号与字阶**：字阶是否连贯；正文是否达到 16px 下限；应用 UI 用的是固定 rem 字阶，还是营销页的流式 clamp。
4. **可读性**：行长 45 到 75 字符；行高为字体与语境调校过；对比度。
5. **一致性**：同一元素处处同一处理；没有随处散落的单点 font-size 覆盖。

然后它修掉发现的问题：挑有个性的字体、建模块化字阶、拉开层级对比、设定合适的行长与行距。

## 试一试

```
/impeccable typeset the article layout
```

预期 diff：

- 展示字体从 Inter 700 换成一款真正的展示字体
- 字阶重建：3rem / 2rem / 1.25rem / 1rem / 0.875rem，比率 1.333
- 正文从 14px 提到 16px
- 文章栏的行长钳制在 68ch
- 行高正文 1.6，展示字体 1.1
- 清掉散落在组件样式里的 4 处单点 `font-size`

## 常见陷阱

- **没有上下文就要求换字体**。Typeset 会依据 `PRODUCT.md` 的品牌语调来挑。没跑过 `/impeccable init`，建议就会很平庸。
- **问题出在布局却去找 typeset**。段落没问题但页面显得局促，你要的是 `/impeccable layout`。
- **指望应用 UI 用流式 clamp 字阶**。Typeset 对应用界面用固定 rem 字阶。流式排版属于行长变化剧烈的营销页和内容页。
