## 示例

### 单独使用

不带图标的单张卡片——适合需要标题的文字说明块。

<Example code={`<Card title="一切都归你所有">
  每个组件都在你的仓库里。不存在会破坏兼容性的上游 API。
</Card>`} contentClass="w-full">
  <div class="w-full">
    <Card title="一切都归你所有">
      每个组件都在你的仓库里。不存在会破坏兼容性的上游 API。
    </Card>
  </div>
</Example>

### 带图标

Iconify 图标名开箱即用——任意 `ph:*`（Phosphor）名称都可以。

<Example code={`<Card title="智能体就绪" icon="ph:robot">
  每个页面都附带 markdown 版本，智能体无需解析页面外壳即可读取内容。
</Card>`} contentClass="w-full">
  <div class="w-full">
    <Card title="智能体就绪" icon="ph:robot">
      每个页面都附带 markdown 版本，智能体无需解析页面外壳即可读取内容。
    </Card>
  </div>
</Example>

### 卡片网格

把多张卡片包进 CardGrid，即可组成响应式的落地页区块。

<Example code={`<CardGrid>
  <Card title="快速" icon="ph:lightning">
    Astro 静态输出。Pagefind 搜索。没有运行时框架开销。
  </Card>
  <Card title="自主掌控" icon="ph:package">
    组件复制进你的仓库。想改就改。
  </Card>
  <Card title="智能体优先" icon="ph:robot">
    markdown 版本与 llms.txt 开箱即用。
  </Card>
  <Card title="自由组合" icon="ph:puzzle-piece">
    通过 \`nimbus-docs add\` 只安装你需要的部分。
  </Card>
</CardGrid>`} contentClass="w-full">
  <CardGrid>
    <Card title="快速" icon="ph:lightning">
      Astro 静态输出。Pagefind 搜索。没有运行时框架开销。
    </Card>
    <Card title="自主掌控" icon="ph:package">
      组件复制进你的仓库。想改就改。
    </Card>
    <Card title="智能体优先" icon="ph:robot">
      markdown 版本与 llms.txt 开箱即用。
    </Card>
    <Card title="自由组合" icon="ph:puzzle-piece">
      通过 <code>nimbus-docs add</code> 只安装你需要的部分。
    </Card>
  </CardGrid>
</Example>
