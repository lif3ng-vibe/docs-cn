---
title: LinkButton
tagline: "按钮样式的链接——主要、次要、极简三种变体，三种尺寸。"
props:
  - name: href
    type: string
    required: true
    description: 目标 URL。
  - name: variant
    type: '"primary" | "secondary" | "minimal"'
    defaultValue: '"primary"'
    description: 视觉样式。
  - name: size
    type: '"sm" | "md" | "lg"'
    defaultValue: '"md"'
    description: 相对尺寸；影响内边距和字号。
  - name: shape
    type: '"base" | "square" | "circle"'
    defaultValue: '"base"'
    description: 纯图标链接请用 "square" 或 "circle"（并传入 aria-label）。
  - name: icon
    type: boolean
    defaultValue: "false"
    description: 渲染一个尾部的箭头，悬停时会轻轻前移。
