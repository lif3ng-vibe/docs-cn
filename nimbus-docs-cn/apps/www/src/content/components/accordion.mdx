## 示例

### 单独使用

单独一个 Accordion——适合折叠面板不属于列表的场景。

<Example code={`<Accordion>
  <AccordionTrigger>Nimbus 为什么附带 markdown 版本？</AccordionTrigger>
  <AccordionContent>
    智能体可以直接读取 .md 文件，无需解析 HTML 页面外壳。\`src/content/docs/\` 里的每个页面都会自动附带一份。
  </AccordionContent>
</Accordion>`} contentClass="w-full">
  <div class="w-full">
    <Accordion>
      <AccordionTrigger>Nimbus 为什么附带 markdown 版本？</AccordionTrigger>
      <AccordionContent>
        智能体（agent）可以直接读取 .md 文件，无需解析 HTML 页面外壳。<code>src/content/docs/</code> 里的每个页面都会自动附带一份。
      </AccordionContent>
    </Accordion>
  </div>
</Example>

### 默认展开

在 Accordion 上传入 `open`，初始即为展开状态。

<Example code={`<Accordion open>
  <AccordionTrigger>已经展开</AccordionTrigger>
  <AccordionContent>
    当第一项承载最重要的答案时最有用。
  </AccordionContent>
</Accordion>`} contentClass="w-full">
  <div class="w-full">
    <Accordion open>
      <AccordionTrigger>已经展开</AccordionTrigger>
      <AccordionContent>
        当第一项承载最重要的答案时最有用。
      </AccordionContent>
    </Accordion>
  </div>
</Example>
