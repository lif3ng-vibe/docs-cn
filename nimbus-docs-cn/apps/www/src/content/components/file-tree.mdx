## 示例

### 扁平结构

单层列表——只有顶层文件，没有嵌套目录。

<Example code={`<FileTree>
- README.md
- package.json
- astro.config.mjs
- tsconfig.json
</FileTree>`} contentClass="w-full">
  <div class="w-full">
    <FileTree>
      <ul>
        <li>README.md</li>
        <li>package.json</li>
        <li>astro.config.mjs</li>
        <li>tsconfig.json</li>
      </ul>
    </FileTree>
  </div>
</Example>

### 嵌套结构

以 `/` 结尾表示目录；在行内嵌套一个列表即可添加子级。

<Example code={`<FileTree>
- src/
  - components/
    - Header.astro
    - Footer.astro
  - pages/
    - index.astro
</FileTree>`} contentClass="w-full">
  <div class="w-full">
    <FileTree>
      <ul>
        <li>
          src/
          <ul>
            <li>
              components/
              <ul>
                <li>Header.astro</li>
                <li>Footer.astro</li>
              </ul>
            </li>
            <li>
              pages/
              <ul>
                <li>index.astro</li>
              </ul>
            </li>
          </ul>
        </li>
      </ul>
    </FileTree>
  </div>
</Example>

### 高亮与占位

用 `**...**` 包裹条目即可高亮。单独占一行的 `...` 表示省略的占位行。

<Example code={`<FileTree>
- src/
  - components/
    - **Header.astro**
    - Footer.astro
    - ...
  - pages/
    - ...
</FileTree>`} contentClass="w-full">
  <div class="w-full">
    <FileTree>
      <ul>
        <li>
          src/
          <ul>
            <li>
              components/
              <ul>
                <li><strong>Header.astro</strong></li>
                <li>Footer.astro</li>
                <li>...</li>
              </ul>
            </li>
            <li>
              pages/
              <ul>
                <li>...</li>
              </ul>
            </li>
          </ul>
        </li>
      </ul>
    </FileTree>
  </div>
</Example>
