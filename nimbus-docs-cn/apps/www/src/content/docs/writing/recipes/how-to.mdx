处于工作状态，动手执行——读者已经知道自己要什么，需要的是步骤，不是理论。他们的开场问题是：*"X 怎么做？"*这是任何文档站上产量最大的类型。

## 何时使用

当**目标只有一个、结果只有一个、读者有能力照着指引走**时，就写操作指南。它不是：

- **教程。**教程通过做出一个东西来教学；作者全程搀扶读者，不允许任何环节出错。操作指南服务于任务中途、自己赶路的读者。如果页面必须对一无所知的读者生效，那就写教程。
- **参考。**如果读者在查一个取值、一个选项或一项限额——而不是执行一串操作——那就是参考。操作指南*链接*到参考；绝不把整张选项表搬进正文。
- **概念。**一旦你解释产品为何这样运作超过了一句话，砍掉它，链去概念页。解释混在步骤中间，正是读者跟丢的地方。

一页一个目标。"Rotate a signing secret"（轮换签名密钥）和"Revoke a signing secret"（吊销签名密钥）是两页，不是一页的两半。当心那些夹带多个目标蒙混过关的伞状动词——"Manage secrets"和"Configure allowlists"各自都藏着创建、修改和删除。

## 标题与描述

- **标题：陈述目标的祈使动词短语。**"Rotate a signing secret""Add a second endpoint"。不用动名词（"Rotating secrets"），不用光杆名词（"Secret rotation"），不加"How to"前缀——祈使动词短语本身就是类型的信号。
- **描述公式：**"*动词开头做那件事，带上收益或关键约束*。"——例如"Rotate a signing secret without dropping deliveries. Both secrets stay valid during the overlap window."（轮换签名密钥且不丢失投递。两把密钥在重叠窗口内同时有效。）

## 组件建议

- **编号步骤**是定义性结构——用 Steps 组件或普通有序列表皆可；两者在 `.md` 版本中的读感必须一致。如果一页没有步骤，就该质疑它是不是操作指南。
- **Tabs / code groups** 在*同一个*规范页面内部承载变体维度（语言、平台、CLI 还是控制台）。按变体复制整页是失败的形态。对于不同的*方法*，不要用标签页——选定推荐方法，其余用链接。
- **提示块：**破坏性步骤之前放警告（这是主路径的一部分），以及主路径的例外（"如果你还在旧版套餐上，……"）。一篇被例外提示块淹没的操作指南，说明主路径选错了。
- **不适合：**Cards（在"后续步骤"之前这一页无处可路由）、冗长的概念旁白、完整的选项表（链接去参考）。

## 结尾

固定页脚，按序：**Verify（验证）** → 不可逆的收尾步骤（如果该任务有的话）→ **Optional blocks（可选块）** → **Next steps（后续步骤）**，附 2–4 条精选链接。绝不要在最后一个编号步骤上结束——停在第 6 步的页面会让读者拿不准自己是否做完了。

## 阈值

- **每个阶段 ≤ 约 10 步。**目标单一但流程很长的过程，用 `###` 分阶段；*目标*变多了的页面则拆分。检验在标题：如果需要"和"，那就是两页。
- **背景引言 ≤ 2 句。**更长了，说明概念内容在渗入。
- **一个目标。**伞状动词（"Manage X"）正是目标不止一个的信号。

## 链接与时效性

深度内容*外链*解决：为什么链概念，取值链参考，接下来做什么链相邻的操作指南。步骤*内部*的链接要尽量少——每个步骤中途的链接都是一条出口匝道。功能一变，就对照真实产品重新验证步骤，并记录下来（frontmatter 里的 `lastVerified` 日期或同等物），让过期可见而不是靠人发现——步骤漂移的操作指南比没有页面更糟，因为缺失的页面只是让人失望，错误的步骤却在主动误导。

## 智能体须知

- 每一步都必须脱离上下文页面也能执行：写明产品区域、完整命令、确切的设置项名称——绝不写"如上文所配置"。
- 预期输出放在围栏代码块里，取完整、真实的值——不要用 `…` 截断凭据；智能体靠你展示的内容做匹配。
- 标签页变体必须在 `.md` 版本里摊平成带标签的小节；绝不能让某一步的唯一副本住在一个生成 Markdown 时会被丢弃的组件里。
- Verify 小节兼任智能体的验收检查——把它写成可运行的东西，并把失败分支写明。

## 检查清单

仅供参考——供作者自查或智能体终检，绝非构建关卡：

- [ ] 标题是祈使动词短语；一个目标，没有伞状动词
- [ ] 前提条件完整——满足前提的读者不离开本页就能做完
- [ ] 每一步：动词开头、只做一个动作、先说位置再说动作
- [ ] 主路径不中断——变体维度放标签页/选择器，替代方法择一并链接，可选项隔离在 Verify 之后
- [ ] 警告先于破坏性步骤；Verify 先于难以撤销的步骤
- [ ] Verify 存在——可运行且带失败分支，或一句不言自明的话
- [ ] 不可逆的收尾步骤（删除、切换、结束重叠期）放在 Verify 之后，独立成节
- [ ] 以 Next steps（2–4 条链接）收尾，而不是以最后一个步骤收尾
- [ ] 每阶段 ≤ 约 10 步；背景 ≤ 2 句
- [ ] 无位置式引用（"如上所述"）；每节自洽
