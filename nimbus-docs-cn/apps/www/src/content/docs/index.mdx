人们和智能体最先看到的，是你的文档，而不是你的产品。Nimbus 就是你在智能体世界中构建文档的方式：一切归你所有。基于 Astro 构建，默认智能体原生（agent-native）。

```sh
npx @cloudflare/create-nimbus-docs@latest
```

## 为什么选择 Nimbus

- **每个文件都归你所有**。没有需要 fork 应付的上游主题——而且当没有任何东西被隐藏时，智能体的推理也更顺畅。
- **人类与智能体皆为一等公民**。为两者同时做好阅读与创作，开箱即用。
- **把低质内容挡在外面**。正文 linter 让人和智能体都保持诚实；草稿发布时带着标记，而非默认可信。
