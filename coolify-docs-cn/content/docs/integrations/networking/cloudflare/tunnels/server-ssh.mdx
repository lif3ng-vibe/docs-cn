# 通过 Cloudflare Tunnel 进行服务器 SSH 访问

通过 Cloudflare Tunnel 走 SSH 访问你的服务器，是一种安全便捷的远程连接方式，同时还能隐藏服务器的 IP 地址。


## 适合谁使用

以下场景非常适合这种方案：

- 希望服务器的 IP 地址保持私密。
- 希望关闭服务器上的 SSH 端口。
- 不想依赖静态公网 IP 来访问远程服务器。
- 服务器没有静态公网 IP（仅在进行[手动配置](#手动)时相关）。

## 开始之前

- 默认你已经有一台运行 Coolify 的服务器，并且想把另一台服务器通过隧道接入 Coolify。
- 如果你试图在 Coolify 所在的服务器上配置隧道，而且没有其他服务器需要接入，那么你不需要 SSH 隧道。Coolify 对它所在的服务器已拥有完整 root 权限，这种情况下无需 SSH 隧道。

# 配置方式

有两种配置方式：
- 自动（Automated）
- 手动（Manual）

主要区别在于：手动方式需要你自己安装 cloudflared，而自动方式由 Coolify 代劳。


<Tabs items={['自动', '手动']}>

<Tab value="自动">

  要使用 Coolify 的 Cloudflare Tunnel 自动配置：
  
  - 你的远程服务器在初始配置阶段必须有**公网 IP 地址**和**可用的 SSH 端口**，Coolify 才能完成隧道配置。配置完成后，你就可以关闭服务器上的所有端口。
  - 如果你的服务器没有公网 IP 地址，那么自动配置**不适合你**。请改阅手动配置指南。
  - 你需要一个 **DNS 托管在 Cloudflare** 的域名。

  <Callout type="warn" title="示例数据">
  
  本指南在步骤中使用以下示例数据。请照做时替换为你自己的真实数据：
  
  - **远程服务器 IPv4 地址**：`192.168.1.93`
  - **SSH 域名**：`helixa.shadowarcanist.com`
  - **用户名**：`root`
  - **SSH 端口**：`22`
  
  </Callout>

  ## 1. 创建 SSH 私钥 [!toc]
  
  <ZoomImage src="/docs-cn/coolify/images/integrations/networking/cloudflare/tunnels/server-ssh/automated/0.webp" />
  
  1. 在 Coolify Dashboard 中进入 **Keys & Tokens**。
  2. 打开 **Private Keys（私钥）**。
  3. 选择 **New private key**。
  
  选择 **Generate ED25519** 或 **Generate RSA**，Coolify 会立即生成并保存密钥。
  
  <ZoomImage src="/docs-cn/coolify/images/integrations/networking/cloudflare/tunnels/server-ssh/automated/1.webp" />
  
  1. 打开已保存密钥的编辑图标，输入名称和可选的描述。
  2. 选择 **Save changes（保存更改）**。
  3. 复制 **Public key（公钥）**，下一步会用到。
  
  ## 2. 把公钥添加到你的服务器 [!toc]
  
  通过 SSH 登录你想接入 Coolify 的服务器：
  
  ```bash
  ssh root@192.168.1.93
  ```
  
  登录后，把你的公钥追加到授权密钥文件中：
  
  ```bash
  echo "<PASTE YOUR PUBLIC KEY INSIDE OF THESE QUOTES>" >> ~/.ssh/authorized_keys
  ```
  
  ## 3. 把你的服务器添加到 Coolify [!toc]
  
  <ZoomImage src="/docs-cn/coolify/images/integrations/networking/cloudflare/tunnels/server-ssh/automated/2.webp" />
  
  1. 在 Coolify Dashboard 中进入 **Servers（服务器）**。
  2. 选择 **New server**，再选择 **IP address or domain**。
  
  系统会提示你填写服务器的详细信息。请确保信息准确无误，Coolify 将使用这些信息来访问你的服务器。
  
  <ZoomImage src="/docs-cn/coolify/images/integrations/networking/cloudflare/tunnels/server-ssh/automated/3.webp" />
  
  1. **Name（名称）** —— 起一个便于在 dashboard 中识别服务器的名字。
  2. **Description（描述）** ——（可选）为服务器填写一段描述。
  3. **IP address or domain** —— 填入服务器的公网 IP 地址。
  4. 在 **Advanced settings** 下，**Port（端口）** —— 填入服务器用于 SSH 连接的端口号。
  5. 在 **Advanced settings** 下，**User（用户）** —— 填入 Coolify 将使用的用户名（该用户在服务器上应具有 root 权限）。
  6. **Private key（私钥）** —— 选择你在步骤 1 中创建的私钥。
  7. 填写完信息后，点击 **Continue** 按钮。
  
  ## 4. 在 Coolify 中验证你的服务器 [!toc]
  
  选择 **Validate connection** 打开验证面板，并按照面板中的检查项逐项操作。
  
  <ZoomImage src="/docs-cn/coolify/images/integrations/networking/cloudflare/tunnels/server-ssh/automated/4.webp" />
  
  在此过程中，Coolify 会登录你的服务器，并完成接入所需的一切设置。
  
  验证完成后，你的服务器页面会呈现为：
  
  <ZoomImage src="/docs-cn/coolify/images/integrations/networking/cloudflare/tunnels/server-ssh/automated/5.webp" />


  ## 5. 创建 Cloudflare Tunnel [!toc]
  
  要创建 Cloudflare Tunnel，先登录你的 [Cloudflare dashboard](https://dash.cloudflare.com/)
  
  <ZoomImage src="/docs-cn/coolify/images/integrations/networking/cloudflare/tunnels/server-ssh/automated/6.webp" />
  
  1. 在侧边栏进入 **Networking（网络）**。
  2. 点击 **Tunnels**。
  3. 点击 **Create tunnel** 按钮。
  
  
  <ZoomImage src="/docs-cn/coolify/images/integrations/networking/cloudflare/tunnels/server-ssh/automated/7.webp" />
  
  系统会提示你输入隧道名称。填一个你喜欢的名字，然后点击 **Create tunnel** 按钮。
  
  <ZoomImage src="/docs-cn/coolify/images/integrations/networking/cloudflare/tunnels/server-ssh/automated/8.webp" />
  
  1. 选择 **Docker** 选项。
  2. 复制 docker run 命令，其中包含你这条隧道的令牌（令牌以 "`eyJ`" 开头）。请只保存令牌本身（去掉前面的命令部分），并妥善保管，后面会用到。


  ## 6. 在 Coolify 上配置 Cloudflare Tunnel [!toc]

  <ZoomImage src="/docs-cn/coolify/images/integrations/networking/cloudflare/tunnels/server-ssh/automated/9.webp" />

  1. 打开该服务器，在其侧边栏选择 **Cloudflare Tunnel**。
  2. 在 **Automated setup（自动配置）** 下，填入 **Cloudflare token** 和 **SSH domain**。
  3. 选择 **Configure tunnel**。

  <Callout type="success" title="提示">
  
    你在上一步复制的 **docker run 命令**中就包含 Cloudflare token。该令牌以 `eyJ` 开头。
  
  </Callout>

    cloudflared 开始运行后，你就能在 Cloudflare dashboard 上看到它的状态：
    
    <ZoomImage src="/docs-cn/coolify/images/integrations/networking/cloudflare/tunnels/server-ssh/automated/10.webp" />

    点击继续按钮完成隧道创建。
  
  ## 7. 配置隧道路由 [!toc]
  
  1. 点击你的隧道。
  2. 点击 **Configure（配置）** 选项。
  
  <ZoomImage src="/docs-cn/coolify/images/integrations/networking/cloudflare/tunnels/server-ssh/automated/11.webp" />
  
  1. 选择 **Routes（路由）**。
  2. 点击 **Add route** 按钮。
  
  <ZoomImage src="/docs-cn/coolify/images/integrations/networking/cloudflare/tunnels/server-ssh/automated/12.webp" />
  
  3. 选择 **Published Application** 作为路由类型。
  
  <ZoomImage src="/docs-cn/coolify/images/integrations/networking/cloudflare/tunnels/server-ssh/automated/13.webp" />
  
  1. **Subdomain（子域名）** ——（可选）你可以让资源通过任意子域名/域名访问。本指南使用 `helixa` 子域名。
  2. **Domain（域名）** —— 选择你要用于隧道的域名。
  3. **Path（路径）** —— 留空。
  4. **Service URL** —— 填入 **ssh://localhost:22**（这一步非常关键）。如果你的 SSH 端口不是 22，请改用实际端口。
  6. 填写完信息后，点击 **Add route** 按钮。
  
  <ZoomImage src="/docs-cn/coolify/images/integrations/networking/cloudflare/tunnels/server-ssh/automated/14.webp" />
  
  <ZoomImage src="/docs-cn/coolify/images/integrations/networking/cloudflare/tunnels/server-ssh/automated/15.webp" />

  隧道配置完成后，Coolify 会自动把服务器的 IP 地址改为 Cloudflare SSH 域名。
  
  如果没有自动更新，请在此处手动把 IP 地址改为 SSH 域名：
  
  <ZoomImage src="/docs-cn/coolify/images/integrations/networking/cloudflare/tunnels/server-ssh/automated/16.webp" />
  
  **恭喜**！你已经成功配置了一台服务器，Coolify 现在可以通过你的域名、经由 Cloudflare Tunnel 用 SSH 访问它。

  现在你就可以根据需要，在服务器上封锁 SSH 端口了。

## 已知问题与解决办法

当你在隧道上创建新路由时，Cloudflare 会为该主机名创建一条 DNS 记录。

但如果该主机名的 DNS 记录已经存在，Cloudflare 不会更新已有记录。

这种情况下你的应用将无法工作。要解决这个问题，请按以下步骤操作：

<ZoomImage src="/docs-cn/coolify/images/integrations/networking/cloudflare/tunnels/all-resource/8.webp" />

1. 点击你的隧道。
2. 点击 **Configure（配置）** 选项。

<ZoomImage src="/docs-cn/coolify/images/integrations/networking/cloudflare/tunnels/all-resource/18.webp" />

3. 在 Tunnels 详情区域复制你的隧道 ID。

<ZoomImage src="/docs-cn/coolify/images/integrations/networking/cloudflare/tunnels/all-resource/19.webp" />

按以下信息创建一条新的 DNS 记录：

1. 在 Cloudflare dashboard 中进入 **DNS**。
2. 选择 **Records（记录）**。
3. 添加一条 **CNAME** 记录。
4. 名称填 `*` 或你的子域名（应与隧道上应用的主机名一致）。
5. **Target（目标）** 填入隧道 ID，后跟 `.cfargotunnel.com`。
6. 把代理状态设为 **Proxied（已代理）**。

现在访问你应用的域名，应该就能正常访问了。
