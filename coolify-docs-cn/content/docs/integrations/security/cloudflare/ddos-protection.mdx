# Cloudflare DDoS 防护

Cloudflare 为你的服务器和应用提供了强大的一层 DDoS 防护。

使用 Cloudflare 的代理、CDN 与安全功能后，所有进入 Coolify 托管应用的流量都会经由 Cloudflare 的全球网络加固，免受 DDoS 等恶意攻击。

---

## 为什么在 Coolify 中使用 Cloudflare 做 DDoS 防护？

1. 在恶意流量到达你的服务器之前就将其拦截。
2. DDoS 攻击期间无需扩容服务器资源——Cloudflare 会吸收冲击。
3. 通过 Cloudflare 的全球网络代理你的应用，隐藏服务器的真实 IP 地址。

---

## 什么时候不适合用 Cloudflare 做 DDoS 防护

1. 你不希望所有流量都经由 Cloudflare 的网络路由。
2. 出于隐私考虑：Cloudflare 会终结 TLS，这意味着它们可以检查传入的请求。
3. 你需要深层子域名的免费泛域名支持（超过一层的子域名——例如 `*.sub.domain.com`，Cloudflare 免费版不提供）。

## 1. 配置源站 TLS 证书
你的服务器与 Cloudflare 之间的通信使用 TLS 证书加密。

有两种做法：

* 使用 Cloudflare 提供的 TLS 证书
* 从受信任的公共证书颁发机构获取你自己的 TLS 证书（这需要进行 DNS 验证）



下面是 **Cloudflare 源站证书（Cloudflare Origin Certificate）** 与 **公共 CA 证书（Public CA Certificate）** 的简要对比：

| 对比项 | Cloudflare 源站证书 | 公共 CA 证书 |
|----------|------------------------|----------------|
| 受信方 | 仅 Cloudflare | 浏览器、操作系统、Cloudflare |
| 适用场景 | 仅 Cloudflare ↔ 源站 | 任何直接访问的客户端 |
| 浏览器直接访问 | 用户绕过 Cloudflare 时会报证书错误 | ✅ 正常工作 |
| 需要 CF 代理 | ✅ 是 | ❌ 否 |
| 无 CF 时可用 | ❌ 否 | ✅ 是 |
| 签发方 | Cloudflare | 公共 CA（如 Let's Encrypt） |
| 费用 | 免费 | 免费 |
| DNS 验证 | ❌ 不需要 | ✅ 需要 |

<Callout type="success" title="提示">
  如果你计划让 Cloudflare 始终位于应用之前，请使用 Cloudflare 源站证书；否则请使用公共 CA 证书。
</Callout>

配置源站 TLS 证书有两种方式，请从下面选择其中一种：

## A. 创建 Cloudflare 源站证书 [!toc]
<ZoomImage src="/docs-cn/coolify/images/integrations/security/cloudflare/ddos-protection/1.webp" />

1. 在你的 Cloudflare dashboard 中进入 **SSL/TLS**。
2. 选择 **Origin Server（源服务器）**。
3. 选择 **Origin Certificates**。
3. 点击 **Create Certificate** 按钮。

<ZoomImage src="/docs-cn/coolify/images/integrations/security/cloudflare/ddos-protection/2.webp" />

1. 密钥类型选择 **RSA (2048)**。
2. 添加你希望证书覆盖的主机名。
3. 把证书有效期设为 **15 years（15 年）**。
4. 点击 **Create** 按钮。

<Callout type="warn" title="注意！">

  - **`shadowarcanist.com`** 只覆盖主域名。
  - **`*.shadowarcanist.com`** 覆盖所有子域名。
  
  在 Cloudflare 免费套餐中，泛域名证书只覆盖一层子域名。
  
  例如，它对 **`coolify.shadowarcanist.com`** 有效，但对 **`www.coolify.shadowarcanist.com`** 无效。
  
  要覆盖多层子域名，你需要购买 [Advanced Certificate Manager ↗](https://www.cloudflare.com/application-services/products/advanced-certificate-manager/)。

</Callout>

<ZoomImage src="/docs-cn/coolify/images/integrations/security/cloudflare/ddos-protection/3.webp" />

1. 密钥格式选择 **PEM**。
2. 复制你的 **Origin Certificate（源站证书）** 并妥善保存。
3. 复制你的 **Private Key（私钥）** 并妥善保存。
4. 点击 **Ok** 按钮。

接下来，把这些文件放到运行 Coolify 的服务器上，并配置 Coolify 使用该证书。

## B. 把证书添加到你的服务器 [!toc]
通过 SSH 登录你的服务器，或使用 Coolify 的终端功能。本指南使用我本地的外部终端：
```bash
ssh shadowarcanist@203.0.113.1
```

登录后，进入 Coolify 代理目录：
```bash
$ cd /data/coolify/proxy
```

证书路径在 Caddy 与 Traefik 之间略有差异，请根据你使用的代理，从下面对应的小节中选择。

<Tabs items={['Traefik', 'Caddy']}>

<Tab value="Traefik">

创建 `certs` 目录：
```bash
$ mkdir certs
```

确认目录已创建：
```bash
$ ls
> acme.json  certs docker-compose.yml  dynamic
```

现在进入 **certs** 目录：
```bash
$ cd certs
```

</Tab>

<Tab value="Caddy">

创建 `caddy/data/certs` 目录：
```bash
$ mkdir -p caddy/data/certs
```

确认目录已创建：
```bash
$ ls caddy/data
> certs
```

现在进入 **certs** 目录：
```bash
$ cd caddy/data/certs
```

</Tab>

</Tabs>


为证书和私钥创建两个新文件：
```bash
$ touch shadowarcanist.cert shadowarcanist.key
```

确认文件已创建：
```bash
$ ls
> shadowarcanist.cert shadowarcanist.key
```

打开 **shadowarcanist.cert** 文件，粘贴来自 Cloudflare dashboard 的证书：
```bash
$ nano shadowarcanist.cert 
```
粘贴证书后保存并退出。

对 **shadowarcanist.key** 文件做同样的操作，粘贴私钥：
```bash
$ nano shadowarcanist.key 
```
保存并退出。

至此，源站证书已安装到你的服务器上。

## C. 配置 Coolify 代理使用源站证书 [!toc]
<ZoomImage src="/docs-cn/coolify/images/integrations/security/cloudflare/ddos-protection/8.webp" />

1. 在侧边栏进入 **Server（服务器）** 部分。
2. 选择 **Proxy（代理）**。
3. 打开 **Dynamic Configuration** 页面。
4. 点击 **Add** 按钮。

系统会提示你输入动态配置。

动态配置文件在 Caddy 与 Traefik 之间略有差异，请根据你使用的代理，从下面对应的小节中选择。


<Tabs items={['Traefik', 'Caddy']}>

<Tab value="Traefik">

<ZoomImage src="/docs-cn/coolify/images/integrations/security/cloudflare/ddos-protection/9.webp" />

1. 为你的配置取一个名字（必须以 `.yaml` 结尾）。
2. 在配置字段中填入以下内容：
```yaml
tls:
  certificates:
    -
      certFile: /traefik/certs/shadowarcanist.cert
      keyFile: /traefik/certs/shadowarcanist.key
```

3. 保存配置。

<Callout type="info" title="添加多张证书">
  
  如果你想添加多张证书与私钥，可以这样写：
  ```yaml
  tls:
    certificates:
      -
        certFile: /traefik/certs/shadowarcanist.cert
        keyFile: /traefik/certs/shadowarcanist.key
      -
        certFile: /traefik/certs/name2.cert
        keyFile: /traefik/certs/name2.key
      -
        certFile: /traefik/certs/name3.cert
        keyFile: /traefik/certs/name3.key
  ```
  
</Callout>


</Tab>

<Tab value="Caddy">

<ZoomImage src="/docs-cn/coolify/images/integrations/security/cloudflare/ddos-protection/10.webp" />

1. 为你的配置取一个名字（必须以 `.caddy` 结尾）。
2. 在配置字段中填入以下内容：
```bash
*.shadowarcanist.com, shadowarcanist.com {
    tls /data/certs/shadowarcanist.cert /data/certs/shadowarcanist.key
}
```

<Callout type="info" title="说明">
  
泛域名 `*.shadowarcanist.com` 覆盖所有子域名；如果你只想保护单个域名（即 `shadowarcanist.com`），请把它去掉。
</Callout>


3. 保存配置。

<Callout type="info" title="添加多张证书">
  
  如果你想添加多张证书与私钥，可以这样写：
  ```bash
  *.shadowarcanist.com, shadowarcanist.com {
      tls /data/certs/shadowarcanist.cert /data/certs/shadowarcanist.key
  }
  
  *.name2.com, name2.com {
      tls /data/certs/name2.cert /data/certs/name2.key
  }
  
  *.name3.com, name3.com {
      tls /data/certs/name3.cert /data/certs/name3.key
  }
  ```
  
</Callout>


</Tab>

</Tabs>

从现在起，Coolify 会使用源站证书处理匹配该主机名的请求。

</Tab>

## 2. 配置 DNS 记录
要让流量经由 Cloudflare 路由，请在 Cloudflare 中配置你的 DNS 记录：

<ZoomImage src="/docs-cn/coolify/images/integrations/security/cloudflare/ddos-protection/4.webp" />

1. 在 Cloudflare dashboard 中进入 **DNS**。
2. 选择 **Records（记录）**。
3. 添加 2 条 A 记录：
4. 名称分别填 **`shadowarcanist.com`** 和 `*`。
5. 两条记录的内容都填你服务器的 **IP 地址**。
6. 把两条记录的代理状态都设为 **Proxied（已代理）**。


<Callout type="info" title="说明">

为 `shadowarcanist.com` 和 `*` 两条 A 记录同时启用 "Proxied"（橙色云朵）选项，会通过泛域名一并代理根域名和所有一层子域名。

如果你只需要为特定域名提供代理（或 DDoS 防护），则不必这样做。这种情况下，只需为你想要保护的域名启用代理即可。

</Callout>

## 3. 配置 TLS 加密模式
要让 Cloudflare 在连接你的服务器时使用更严格的加密，请在 Cloudflare 中配置 TLS 加密：

<ZoomImage src="/docs-cn/coolify/images/integrations/security/cloudflare/ddos-protection/5.webp" />

1. 在 Cloudflare 中进入 **SSL/TLS**。
2. 选择 **Overview（概述）**。
3. 点击 **Configure** 按钮。

<ZoomImage src="/docs-cn/coolify/images/integrations/security/cloudflare/ddos-protection/6.webp" />

1. 加密模式选择 **Full (Strict)**。
2. 点击 **Save** 按钮。

## 4. 配置 Always Use HTTPS
要让 Cloudflare 自动把 HTTP 请求重定向到 HTTPS，请在 Cloudflare 中配置重定向：

<ZoomImage src="/docs-cn/coolify/images/integrations/security/cloudflare/ddos-protection/7.webp" />

1. 在 Cloudflare 中进入 **SSL/TLS**。
2. 选择 **Edge Certificates（边缘证书）**。
3. 启用 **Always Use HTTPS**。


## 5. 配置防火墙

<Callout type="info" title="说明">
  这一步完全可选，但推荐执行。
</Callout>

配置防火墙，只允许来自 [Cloudflare 的 IP 段 ↗](https://www.cloudflare.com/en-gb/ips/) 的流量访问 **443** 端口。

除 SSH 端口外，封锁所有其他入站流量。

这样能防止攻击者绕过 Cloudflare，直接以 80 或 443 端口的流量攻击你的服务器。


完成！你的服务器现在已配置源站 TLS 证书，所有流量都经由 Cloudflare 的网络代理，因此像 DDoS 这样的入站攻击都会在到达你的服务器之前被 Cloudflare 拦截。
