# Update

更新 API 令牌所绑定团队的设置

## 用法

```sh
coolify teams update
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--build-server-fallback` | `boolean` | 是 | `false` | 允许在没有可用构建服务器时回退到部署服务器（必填） |

## 查看当前帮助

```sh
coolify teams update --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
