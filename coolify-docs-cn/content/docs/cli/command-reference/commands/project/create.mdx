# Create

创建新项目

## 用法

```sh
coolify project create
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--description` | `string` | 否 | — | 项目描述 |
| `--name` | `string` | 是 | — | 项目名称（必填） |

## 查看当前帮助

```sh
coolify project create --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
