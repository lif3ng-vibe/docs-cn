# Environments delete

删除项目环境

## 用法

```sh
coolify project environments delete <project_uuid> <environment>
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--force (-f)` | `boolean` | 否 | `false` | 跳过确认提示 |

## 查看当前帮助

```sh
coolify project environments delete --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
