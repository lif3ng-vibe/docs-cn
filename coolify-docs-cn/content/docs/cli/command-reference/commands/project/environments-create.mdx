# Environments create

在项目中创建环境

## 用法

```sh
coolify project environments create <project_uuid>
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--name` | `string` | 是 | — | 环境名称（必填） |

## 查看当前帮助

```sh
coolify project environments create --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
