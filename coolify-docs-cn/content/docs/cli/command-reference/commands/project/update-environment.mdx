# Update environment

更新项目环境。推荐使用：coolify project environments update

## 用法

```sh
coolify project update-environment <project_uuid> <environment>
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--description` | `string` | 否 | — | 环境描述 |
| `--name` | `string` | 否 | — | 环境名称 |

## 查看当前帮助

```sh
coolify project update-environment --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
