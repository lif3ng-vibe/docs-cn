# Previews create

打开或重新部署预览部署

## 用法

```sh
coolify app previews create <app_uuid> <pr_id>
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--commit` | `string` | 否 | — | 要部署的提交 SHA（Bitbucket 必填） |
| `--docker-tag` | `string` | 否 | — | Docker 镜像标签（仅 Docker 镜像应用） |
| `--force` | `boolean` | 否 | `false` | 不使用缓存重建 |
| `--git-type` | `string` | 否 | — | 拉取请求的 Git 提供商：github、gitlab、gitea 或 bitbucket |
| `--no-deploy` | `boolean` | 否 | `false` | 仅创建预览，不排队部署 |
| `--url` | `string` | 否 | — | 拉取请求 URL |

## 查看当前帮助

```sh
coolify app previews create --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
