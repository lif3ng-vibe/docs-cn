# Storage set backup

创建或替换存储卷备份计划

## 用法

```sh
coolify app storage set-backup <app_uuid> <storage_uuid>
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--disable-local-backup` | `boolean` | 否 | `false` | 禁用本地备份保留 |
| `--enabled` | `boolean` | 否 | `true` | 启用该计划 |
| `--frequency` | `string` | 是 | — | cron 频率（必填） |
| `--retention-amount-locally` | `integer` | 否 | `7` | 本地保留数量 |
| `--retention-amount-s3` | `integer` | 否 | `7` | S3 保留数量 |
| `--retention-days-locally` | `integer` | 否 | `0` | 本地保留天数 |
| `--retention-days-s3` | `integer` | 否 | `0` | S3 保留天数 |
| `--retention-max-storage-locally` | `float64` | 否 | `0` | 本地最大存储空间 |
| `--retention-max-storage-s3` | `float64` | 否 | `0` | S3 最大存储空间 |
| `--s3-storage-uuid` | `string` | 否 | — | 设置 --save-s3 时使用的 S3 存储 UUID |
| `--save-s3` | `boolean` | 否 | `false` | 同时将备份保存到 S3 |
| `--stop-during-backup` | `boolean` | 否 | `false` | 备份期间停止资源 |
| `--timeout` | `integer` | 否 | `3600` | 备份超时秒数 |

## 查看当前帮助

```sh
coolify app storage set-backup --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
