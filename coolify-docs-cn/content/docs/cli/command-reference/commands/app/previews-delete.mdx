# Previews delete

删除应用的预览部署。第一个参数是应用 UUID，第二个是拉取请求 ID。

## 用法

```sh
coolify app previews delete <app_uuid> <pr_id>
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--force` | `boolean` | 否 | `false` | 跳过确认提示 |

## 查看当前帮助

```sh
coolify app previews delete --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
