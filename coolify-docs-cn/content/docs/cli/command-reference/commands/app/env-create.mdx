# Env create

为指定应用创建新环境变量。使用 --key 和 --value 标志指定变量。

## 用法

```sh
coolify app env create <app_uuid>
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--build-time` | `boolean` | 否 | `true` | 构建时可用（默认：true） |
| `--comment` | `string` | 否 | — | 环境变量的备注 |
| `--is-literal` | `boolean` | 否 | `false` | 将值视为字面量（不插值变量） |
| `--is-multiline` | `boolean` | 否 | `false` | 值为多行 |
| `--key` | `string` | 是 | — | 环境变量键名（必填） |
| `--preview` | `boolean` | 否 | `false` | 在预览部署中可用 |
| `--runtime` | `boolean` | 否 | `true` | 运行时可用（默认：true） |
| `--value` | `string` | 是 | — | 环境变量值（必填） |

## 查看当前帮助

```sh
coolify app env create --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
