# Destinations add

附加目标

## 用法

```sh
coolify app destinations add <uuid>
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--destination` | `string` | 否 | — | 目标 UUID |

## 查看当前帮助

```sh
coolify app destinations add --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
