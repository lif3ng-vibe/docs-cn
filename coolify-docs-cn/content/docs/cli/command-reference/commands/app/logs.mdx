# Logs

获取应用日志

## 用法

```sh
coolify app logs <uuid>
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--follow (-f)` | `boolean` | 否 | `false` | 跟随日志输出（类似 tail -f） |
| `--lines (-n)` | `integer` | 否 | `100` | 要获取的日志行数 |
| `--service` | `string` | 否 | — | Docker Compose 服务名称（在多服务应用中选择一个容器） |
| `--show-timestamps` | `boolean` | 否 | `false` | 日志输出中显示时间戳 |

## 查看当前帮助

```sh
coolify app logs --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
