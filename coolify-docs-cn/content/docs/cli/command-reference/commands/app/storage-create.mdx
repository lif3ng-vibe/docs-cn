# Storage create

为应用创建存储

## 用法

```sh
coolify app storage create <app_uuid>
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--content` | `string` | 否 | — | 文件内容（仅 file） |
| `--fs-path` | `string` | 否 | — | 宿主机目录路径（仅 file，设置 --is-directory 时必填） |
| `--host-path` | `string` | 否 | — | 宿主机路径（仅 persistent） |
| `--is-directory` | `boolean` | 否 | `false` | 是否为目录挂载（仅 file） |
| `--mount-path` | `string` | 是 | — | 容器内挂载路径（必填） |
| `--name` | `string` | 否 | — | 卷名称（仅 persistent） |
| `--type` | `string` | 是 | — | 存储类型：'persistent' 或 'file'（必填） |

## 查看当前帮助

```sh
coolify app storage create --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
