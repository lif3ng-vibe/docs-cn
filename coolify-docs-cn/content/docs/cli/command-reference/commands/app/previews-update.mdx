# Previews update

更新预览部署的域名

## 用法

```sh
coolify app previews update <app_uuid> <pr_id>
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--compose-domain` | `stringArray` | 否 | — | Docker Compose 服务域名，格式为 &lt;service&gt;=&lt;url&gt;[,&lt;url&gt;]（可重复） |
| `--domains` | `string` | 否 | — | 域名（逗号分隔） |
| `--force-domain-override` | `boolean` | 否 | `false` | 即使其他资源正在使用这些域名也保存 |

## 查看当前帮助

```sh
coolify app previews update --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
