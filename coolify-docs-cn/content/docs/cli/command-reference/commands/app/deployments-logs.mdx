# Deployments logs

获取应用的部署日志

## 用法

```sh
coolify app deployments logs <app-uuid> [deployment-uuid]
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--debuglogs` | `boolean` | 否 | `false` | 显示调试日志（包括隐藏命令和内部操作） |
| `--follow (-f)` | `boolean` | 否 | `false` | 跟随日志输出（类似 tail -f） |
| `--lines (-n)` | `integer` | 否 | `0` | 要显示的日志行数（0 表示全部） |

## 查看当前帮助

```sh
coolify app deployments logs --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
