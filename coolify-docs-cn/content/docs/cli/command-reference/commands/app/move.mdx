# Move

将应用移动到其他环境

## 用法

```sh
coolify app move <uuid>
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--environment-uuid` | `string` | 是 | — | 目标环境 UUID（必填） |

## 查看当前帮助

```sh
coolify app move --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
