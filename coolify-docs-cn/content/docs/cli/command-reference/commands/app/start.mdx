# Start

启动应用（发起一次部署）。

## 用法

```sh
coolify app start <uuid>
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--force` | `boolean` | 否 | `false` | 强制重建 |
| `--instant-deploy` | `boolean` | 否 | `false` | 立即部署（跳过排队） |

## 查看当前帮助

```sh
coolify app start --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
