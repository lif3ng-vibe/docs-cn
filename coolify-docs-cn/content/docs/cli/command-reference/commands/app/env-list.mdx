# Env list

列出应用的所有环境变量

## 用法

```sh
coolify app env list <app_uuid>
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--all` | `boolean` | 否 | `false` | 显示所有环境变量（先非预览，后预览） |
| `--preview` | `boolean` | 否 | `false` | 显示预览环境变量而非常规环境变量 |

## 查看当前帮助

```sh
coolify app env list --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
