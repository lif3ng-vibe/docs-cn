# Create dockerimage

从预构建的 Docker 镜像创建应用

## 用法

```sh
coolify app create dockerimage
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--custom-internal-name` | `string` | 否 | — | 自定义内部主机名 |
| `--description` | `string` | 否 | — | 应用描述 |
| `--destination-uuid` | `string` | 否 | — | 服务器有多个目标时的目标 UUID |
| `--disable-build-cache` | `boolean` | 否 | `false` | 禁用构建缓存 |
| `--docker-images-to-keep` | `integer` | 否 | `0` | 保留的 Docker 镜像数量 |
| `--docker-registry-image-name` | `string` | 是 | — | 来自镜像仓库的 Docker 镜像名称（必填） |
| `--docker-registry-image-tag` | `string` | 否 | — | Docker 镜像标签（默认为 'latest'） |
| `--dockerfile-target-build` | `string` | 否 | — | Dockerfile 目标构建阶段 |
| `--domains` | `string` | 否 | — | 应用的域名 |
| `--environment-name` | `string` | 否 | — | 环境名称 |
| `--environment-uuid` | `string` | 否 | — | 环境 UUID |
| `--gpu-count` | `string` | 否 | — | GPU 数量 |
| `--gpu-device-ids` | `string` | 否 | — | GPU 设备 ID |
| `--gpu-driver` | `string` | 否 | — | GPU 驱动 |
| `--gpu-options` | `string` | 否 | — | GPU 选项 |
| `--health-check-enabled` | `boolean` | 否 | `false` | 启用健康检查 |
| `--health-check-path` | `string` | 否 | — | 健康检查路径 |
| `--include-source-commit-in-build` | `boolean` | 否 | `false` | 构建中包含源提交 |
| `--inject-build-args-to-dockerfile` | `boolean` | 否 | `false` | 向 Dockerfile 注入构建参数 |
| `--instant-deploy` | `boolean` | 否 | `false` | 创建后立即部署 |
| `--is-consistent-container-name-enabled` | `boolean` | 否 | `false` | 使用一致的容器名称 |
| `--is-env-sorting-enabled` | `boolean` | 否 | `false` | 排序环境变量 |
| `--is-git-lfs-enabled` | `boolean` | 否 | `false` | 启用 Git LFS |
| `--is-git-shallow-clone-enabled` | `boolean` | 否 | `false` | 使用 Git 浅克隆 |
| `--is-git-submodules-enabled` | `boolean` | 否 | `false` | 克隆 Git 子模块 |
| `--is-gpu-enabled` | `boolean` | 否 | `false` | 启用 GPU |
| `--is-gzip-enabled` | `boolean` | 否 | `false` | 启用 gzip 压缩 |
| `--is-log-drain-enabled` | `boolean` | 否 | `false` | 启用应用日志外发 |
| `--is-pr-deployments-public-enabled` | `boolean` | 否 | `false` | 将拉取请求部署设为公开 |
| `--is-preview-deployments-enabled` | `boolean` | 否 | `false` | 启用预览部署 |
| `--is-raw-compose-deployment-enabled` | `boolean` | 否 | `false` | 部署原始 Docker Compose 定义 |
| `--is-stripprefix-enabled` | `boolean` | 否 | `false` | 启用路径前缀剥离 |
| `--limits-cpus` | `string` | 否 | — | CPU 限制 |
| `--limits-memory` | `string` | 否 | — | 内存限制 |
| `--max-restart-count` | `integer` | 否 | `0` | 容器最大重启次数 |
| `--name` | `string` | 否 | — | 应用名称 |
| `--ports-exposes` | `string` | 是 | — | 暴露端口，如 '80' 或 '80,443'（必填） |
| `--ports-mappings` | `string` | 否 | — | 端口映射（host:container） |
| `--preview-url-template` | `string` | 否 | — | 预览 URL 模板 |
| `--project-uuid` | `string` | 是 | — | 项目 UUID（必填） |
| `--server-uuid` | `string` | 是 | — | 服务器 UUID（必填） |
| `--stop-grace-period` | `integer` | 否 | `0` | 容器停止宽限期（秒） |
| `--tag` | `stringArray` | 否 | — | 要分配给应用的标签（可重复） |
| `--tags` | `stringSlice` | 否 | — | 要分配给应用的标签 |
| `--use-build-secrets` | `boolean` | 否 | `false` | 构建期变量使用 Docker Build Secrets |

## 查看当前帮助

```sh
coolify app create dockerimage --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
