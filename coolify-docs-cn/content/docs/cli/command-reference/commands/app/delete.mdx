# Delete

删除应用。此操作无法撤销。

## 用法

```sh
coolify app delete <uuid>
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--force (-f)` | `boolean` | 否 | `false` | 跳过确认提示 |

## 查看当前帮助

```sh
coolify app delete --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
