# Secret manager set

设置应用的密钥管理器来源

## 用法

```sh
coolify app secret-manager set <app_uuid>
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--integration-token` | `string` | 是 | — | 密钥管理器集成令牌的 UUID（必填） |
| `--settings` | `string` | 否 | — | 以 JSON 对象表示的提供商设置 |

## 查看当前帮助

```sh
coolify app secret-manager set --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
