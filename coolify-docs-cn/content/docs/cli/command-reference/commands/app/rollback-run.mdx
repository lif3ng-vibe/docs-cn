# Rollback run

将应用回滚到某个提交

## 用法

```sh
coolify app rollback run <uuid>
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--commit` | `string` | 否 | — | Git 提交 SHA |

## 查看当前帮助

```sh
coolify app rollback run --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
