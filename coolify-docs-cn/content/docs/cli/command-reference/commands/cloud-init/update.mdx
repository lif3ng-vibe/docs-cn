# Update

更新 cloud-init 脚本

## 用法

```sh
coolify cloud-init update <uuid>
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--name` | `string` | 否 | — | 脚本名称 |
| `--script` | `string` | 否 | — | 脚本内容 |
| `--script-file` | `string` | 否 | — | 从文件读取脚本内容 |

## 查看当前帮助

```sh
coolify cloud-init update --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
