# List

列出审计事件，最新优先

## 用法

```sh
coolify audit list
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--action` | `string` | 否 | — | 按操作过滤，如 created、updated、deleted（all 表示所有操作） |
| `--page` | `integer` | 否 | `1` | 页码 |
| `--per-page` | `integer` | 否 | `25` | 每页事件数（1-100） |
| `--search` | `string` | 否 | — | 搜索文本 |
| `--source` | `string` | 否 | — | 按来源过滤：all、ui、api、mcp、webhook、system、scheduler |

## 查看当前帮助

```sh
coolify audit list --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
