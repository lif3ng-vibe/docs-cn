# Application start

启动或重新部署服务中的应用

## 用法

```sh
coolify service application start <service-uuid> <application-uuid>
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--force` | `boolean` | 否 | `false` | 重建应用 |
| `--latest` | `boolean` | 否 | `false` | 拉取最新镜像 |

## 查看当前帮助

```sh
coolify service application start --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
