# Database import upload

分块上传本地备份文件（最大 10 GiB）。输出上传 ID，供 'start --upload-id' 使用。

## 用法

```sh
coolify service database import upload <service_uuid> <database_uuid> <file>
```

## 查看当前帮助

```sh
coolify service database import upload --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
