# Database logs

获取服务中数据库的日志

## 用法

```sh
coolify service database logs <service-uuid> <database-uuid>
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--lines (-n)` | `integer` | 否 | `100` | 要获取的日志行数 |

## 查看当前帮助

```sh
coolify service database logs --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
