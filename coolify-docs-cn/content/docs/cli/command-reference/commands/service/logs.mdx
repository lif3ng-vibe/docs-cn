# Logs

获取服务子资源的日志

## 用法

```sh
coolify service logs <uuid>
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--lines (-n)` | `integer` | 否 | `100` | 要获取的日志行数 |
| `--show-timestamps` | `boolean` | 否 | `false` | 日志中包含时间戳 |
| `--sub-service-name` | `string` | 是 | — | 服务应用或数据库列表中的子服务名称（必填） |

## 查看当前帮助

```sh
coolify service logs --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
