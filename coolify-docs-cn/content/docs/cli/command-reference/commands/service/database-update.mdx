# Database update

更新服务中的数据库

## 用法

```sh
coolify service database update <service-uuid> <database-uuid>
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--description` | `string` | 否 | — | 描述 |
| `--exclude-from-status` | `boolean` | 否 | `false` | 从服务状态中排除 |
| `--human-name` | `string` | 否 | — | 人类可读的名称 |
| `--image` | `string` | 否 | — | 容器镜像 |
| `--log-drain-enabled` | `boolean` | 否 | `false` | 启用日志外发 |
| `--public` | `boolean` | 否 | `false` | 将数据库公开暴露 |
| `--public-port` | `integer` | 否 | `0` | 数据库公网端口 |
| `--public-port-timeout` | `integer` | 否 | `0` | 公网代理超时时间（秒） |

## 查看当前帮助

```sh
coolify service database update --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
