# Delete

删除服务，可选清理其配置、卷和网络。

## 用法

```sh
coolify service delete <uuid>
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--delete-configurations` | `boolean` | 否 | `true` | 删除配置 |
| `--delete-connected-networks` | `boolean` | 否 | `true` | 删除已连接的网络 |
| `--delete-volumes` | `boolean` | 否 | `true` | 删除卷 |
| `--docker-cleanup` | `boolean` | 否 | `true` | 运行 Docker 清理 |
| `--force (-f)` | `boolean` | 否 | `false` | 跳过确认提示 |

## 查看当前帮助

```sh
coolify service delete --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
