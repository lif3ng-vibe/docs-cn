# Application update

更新服务中的应用

## 用法

```sh
coolify service application update <service-uuid> <application-uuid>
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--description` | `string` | 否 | — | 描述 |
| `--exclude-from-status` | `boolean` | 否 | `false` | 从服务状态中排除 |
| `--force-domain-override` | `boolean` | 否 | `false` | 允许冲突或重复的域名 |
| `--gzip-enabled` | `boolean` | 否 | `false` | 启用 gzip 压缩 |
| `--human-name` | `string` | 否 | — | 人类可读的名称 |
| `--image` | `string` | 否 | — | 容器镜像 |
| `--log-drain-enabled` | `boolean` | 否 | `false` | 启用日志外发 |
| `--stripprefix-enabled` | `boolean` | 否 | `false` | 启用路径前缀剥离 |
| `--url` | `string` | 否 | — | 逗号分隔的公开 URL |

## 查看当前帮助

```sh
coolify service application update --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
