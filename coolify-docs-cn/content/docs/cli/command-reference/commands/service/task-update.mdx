# Task update

更新服务计划任务

## 用法

```sh
coolify service task update <service_uuid> <task_uuid>
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--command` | `string` | 否 | — | 要运行的命令 |
| `--container` | `string` | 否 | — | 要在其中运行命令的容器名称 |
| `--enabled` | `boolean` | 否 | `true` | 任务是否启用 |
| `--frequency` | `string` | 否 | — | cron 表达式或频率 |
| `--name` | `string` | 否 | — | 任务名称 |
| `--timeout` | `integer` | 否 | `300` | 超时时间（秒） |

## 查看当前帮助

```sh
coolify service task update --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
