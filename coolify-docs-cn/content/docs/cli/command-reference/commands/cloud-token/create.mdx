# Create

创建云服务商令牌

## 用法

```sh
coolify cloud-token create
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--name` | `string` | 否 | — | 令牌友好名称 |
| `--provider` | `string` | 否 | — | 云服务商：hetzner、digitalocean、vultr 或 hostinger |
| `--provider-token` | `string` | 否 | — | 提供商 API 令牌（敏感；不会包含在输出中） |

## 查看当前帮助

```sh
coolify cloud-token create --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
