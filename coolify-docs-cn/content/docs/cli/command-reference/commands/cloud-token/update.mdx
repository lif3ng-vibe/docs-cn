# Update

重命名云服务商令牌

## 用法

```sh
coolify cloud-token update <uuid>
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--name` | `string` | 否 | — | 新的令牌友好名称 |

## 查看当前帮助

```sh
coolify cloud-token update --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
