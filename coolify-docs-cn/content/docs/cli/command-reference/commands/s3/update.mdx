# Update

更新 S3 存储

## 用法

```sh
coolify s3 update <uuid>
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--bucket` | `string` | 否 | — | 存储桶名称 |
| `--description` | `string` | 否 | — | 描述 |
| `--endpoint` | `string` | 否 | — | S3 端点 URL |
| `--key` | `string` | 否 | — | 访问密钥 |
| `--name` | `string` | 否 | — | 存储名称 |
| `--region` | `string` | 否 | — | 区域 |
| `--secret` | `string` | 否 | — | 密钥 |
| `--usable` | `boolean` | 否 | `true` | 将存储标记为可用 |

## 查看当前帮助

```sh
coolify s3 update --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
