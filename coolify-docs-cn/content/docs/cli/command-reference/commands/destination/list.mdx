# List

列出目标

## 用法

```sh
coolify destination list
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--server` | `string` | 否 | — | 仅限属于该服务器 UUID 的目标 |

## 查看当前帮助

```sh
coolify destination list --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
