# Delete

删除 GitHub App 集成。接受应用 UUID（也接受数字 ID）。该应用不得被任何应用使用。

## 用法

```sh
coolify github delete <app_uuid>
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--force (-f)` | `boolean` | 否 | `false` | 跳过确认提示 |

## 查看当前帮助

```sh
coolify github delete --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
