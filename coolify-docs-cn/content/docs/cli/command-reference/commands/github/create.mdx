# Create

创建 GitHub App 集成

## 用法

```sh
coolify github create
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--api-url` | `string` | 否 | — | GitHub API URL（省略时由 --html-url 推导） |
| `--app-id` | `integer` | 是 | `0` | GitHub App ID（必填） |
| `--client-id` | `string` | 是 | — | GitHub OAuth 客户端 ID（必填） |
| `--client-secret` | `string` | 是 | — | GitHub OAuth 客户端密钥（必填） |
| `--custom-port` | `integer` | 否 | `0` | SSH 自定义端口（默认：22） |
| `--custom-user` | `string` | 否 | — | SSH 自定义用户（默认：git） |
| `--html-url` | `string` | 是 | — | GitHub HTML URL（必填，如 https://github.com） |
| `--installation-id` | `integer` | 是 | `0` | GitHub 安装 ID（必填） |
| `--name` | `string` | 是 | — | GitHub App 名称（必填） |
| `--organization` | `string` | 否 | — | GitHub 组织 |
| `--private-key-uuid` | `string` | 是 | — | 现有私钥的 UUID（必填） |
| `--system-wide` | `boolean` | 否 | `false` | 该应用是否系统级（仅云实例） |
| `--webhook-secret` | `string` | 否 | — | GitHub webhook 密钥 |

## 查看当前帮助

```sh
coolify github create --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
