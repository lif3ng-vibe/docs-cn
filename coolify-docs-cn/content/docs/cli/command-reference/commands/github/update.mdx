# Update

更新现有 GitHub App 集成。提供应用 UUID（也接受数字 ID）以及要更新的字段。

## 用法

```sh
coolify github update <app_uuid>
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--api-url` | `string` | 否 | — | GitHub API URL |
| `--app-id` | `integer` | 否 | `0` | GitHub App ID |
| `--client-id` | `string` | 否 | — | GitHub OAuth 客户端 ID |
| `--client-secret` | `string` | 否 | — | GitHub OAuth 客户端密钥 |
| `--custom-port` | `integer` | 否 | `0` | SSH 自定义端口 |
| `--custom-user` | `string` | 否 | — | SSH 自定义用户 |
| `--html-url` | `string` | 否 | — | GitHub HTML URL |
| `--installation-id` | `integer` | 否 | `0` | GitHub 安装 ID |
| `--name` | `string` | 否 | — | GitHub App 名称 |
| `--organization` | `string` | 否 | — | GitHub 组织 |
| `--private-key-uuid` | `string` | 否 | — | 私钥的 UUID |
| `--system-wide` | `boolean` | 否 | `false` | 该应用是否系统级 |
| `--webhook-secret` | `string` | 否 | — | GitHub webhook 密钥 |

## 查看当前帮助

```sh
coolify github update --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
