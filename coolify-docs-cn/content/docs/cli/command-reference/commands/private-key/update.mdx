# Update

更新私钥

## 用法

```sh
coolify private-key update <uuid>
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--description` | `string` | 否 | — | 私钥描述 |
| `--name` | `string` | 否 | — | 私钥名称 |
| `--private-key` | `string` | 是 | — | 私钥内容或密钥文件路径（必填） |

## 查看当前帮助

```sh
coolify private-key update --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
