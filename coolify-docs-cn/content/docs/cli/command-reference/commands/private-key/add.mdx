# Add

添加私钥

## 用法

```sh
coolify private-key add <key_name> <private_key_or_file>
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--description` | `string` | 否 | — | 私钥描述 |

## 查看当前帮助

```sh
coolify private-key add --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
