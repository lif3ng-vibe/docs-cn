# Batch

按名称部署多个资源

## 用法

```sh
coolify deploy batch <name1,name2,...>
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--docker-tag` | `string` | 否 | — | 本次部署覆盖的 Docker 镜像标签 |
| `--force` | `boolean` | 否 | `false` | 强制部署 |
| `--pull-request-id` | `integer` | 否 | `0` | 预览部署的拉取请求 ID |

## 查看当前帮助

```sh
coolify deploy batch --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
