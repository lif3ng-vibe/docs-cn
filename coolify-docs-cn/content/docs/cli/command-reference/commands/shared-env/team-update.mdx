# Team update

更新团队共享环境变量

## 用法

```sh
coolify shared-env team update <id>
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--comment` | `string` | 否 | — | 备注 |
| `--key` | `string` | 否 | — | 变量键名 |
| `--literal` | `boolean` | 否 | `false` | 将值视为字面量 |
| `--multiline` | `boolean` | 否 | `false` | 多行值 |
| `--shown-once` | `boolean` | 否 | `false` | 仅显示一次值 |
| `--value` | `string` | 否 | — | 变量值 |

## 查看当前帮助

```sh
coolify shared-env team update --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
