# Email update

通过 --json 以 JSON 传入设置。需要 write:sensitive 权限。示例：coolify settings email update --json '&#123;"smtp_ehlo_domain":"coolify.example.com"&#125;'

## 用法

```sh
coolify settings email update
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--json` | `string` | 否 | — | 要更新字段的 JSON 对象 |

## 查看当前帮助

```sh
coolify settings email update --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
