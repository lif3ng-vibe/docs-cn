# Update

更新现有 GitLab App 集成。提供应用 ID 或 UUID 以及要更新的字段。

## 用法

```sh
coolify gitlab update <app_id_or_uuid>
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--api-url` | `string` | 否 | — | GitLab API URL |
| `--client-id` | `string` | 否 | — | GitLab OAuth 应用 ID |
| `--client-secret` | `string` | 否 | — | GitLab OAuth 应用密钥 |
| `--custom-port` | `integer` | 否 | `0` | 自定义 SSH 端口 |
| `--custom-user` | `string` | 否 | — | 自定义 SSH 用户 |
| `--group-name` | `string` | 否 | — | 可选的逗号分隔分组过滤器 |
| `--html-url` | `string` | 否 | — | GitLab 实例 URL |
| `--name` | `string` | 否 | — | GitLab App 名称 |
| `--redirect-uri` | `string` | 否 | — | OAuth 重定向 URI |
| `--system-wide` | `boolean` | 否 | `false` | 该应用是否系统级 |
| `--webhook-token` | `string` | 否 | — | webhook 密钥令牌 |

## 查看当前帮助

```sh
coolify gitlab update --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
