# Update

通过 --json 以 JSON 传入设置。示例：coolify notification update webhook --json '&#123;"webhook_enabled":true&#125;'

## 用法

```sh
coolify notification update <channel>
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--json` | `string` | 否 | — | 要更新字段的 JSON 对象 |

## 查看当前帮助

```sh
coolify notification update --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
