# Env create

为指定数据库创建新环境变量。使用 --key 和 --value 标志指定变量。

## 用法

```sh
coolify database env create <database_uuid>
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--comment` | `string` | 否 | — | 环境变量的备注 |
| `--is-literal` | `boolean` | 否 | `false` | 将值视为字面量（不插值变量） |
| `--is-multiline` | `boolean` | 否 | `false` | 值为多行 |
| `--is-shown-once` | `boolean` | 否 | `false` | 仅显示一次值 |
| `--key` | `string` | 是 | — | 环境变量键名（必填） |
| `--value` | `string` | 是 | — | 环境变量值（必填） |

## 查看当前帮助

```sh
coolify database env create --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
