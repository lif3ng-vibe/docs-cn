# Env update

更新现有环境变量。通过 UUID 或键名标识。

## 用法

```sh
coolify database env update <database_uuid> <env_uuid_or_key>
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--comment` | `string` | 否 | — | 环境变量的备注 |
| `--is-literal` | `boolean` | 否 | `false` | 将值视为字面量 |
| `--is-multiline` | `boolean` | 否 | `false` | 值为多行 |
| `--is-shown-once` | `boolean` | 否 | `false` | 仅显示一次值 |
| `--key` | `string` | 否 | — | 新环境变量键名（重命名） |
| `--value` | `string` | 是 | — | 新环境变量值（必填） |

## 查看当前帮助

```sh
coolify database env update --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
