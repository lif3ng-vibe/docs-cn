# Logs

获取数据库日志

## 用法

```sh
coolify database logs <uuid>
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--lines (-n)` | `integer` | 否 | `100` | 要获取的日志行数 |
| `--show-timestamps` | `boolean` | 否 | `false` | 日志中包含时间戳 |

## 查看当前帮助

```sh
coolify database logs --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
