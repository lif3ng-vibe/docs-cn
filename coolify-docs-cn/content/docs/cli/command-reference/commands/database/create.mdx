# Create

创建新数据库

## 用法

```sh
coolify database create <type>
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--clickhouse-admin-password` | `string` | 否 | — | Clickhouse 管理员密码 |
| `--clickhouse-admin-user` | `string` | 否 | — | Clickhouse 管理员用户 |
| `--description` | `string` | 否 | — | 数据库描述 |
| `--destination-uuid` | `string` | 否 | — | 服务器有多个目标时的目标 UUID |
| `--dragonfly-password` | `string` | 否 | — | Dragonfly 密码 |
| `--environment-name` | `string` | 否 | — | 环境名称 |
| `--environment-uuid` | `string` | 否 | — | 环境 UUID |
| `--image` | `string` | 否 | — | Docker 镜像 |
| `--instant-deploy` | `boolean` | 否 | `false` | 创建后立即部署 |
| `--is-public` | `boolean` | 否 | `false` | 将数据库设为公开访问 |
| `--keydb-password` | `string` | 否 | — | KeyDB 密码 |
| `--limits-cpus` | `string` | 否 | — | CPU 限制（如 '0.5'、'2'） |
| `--limits-memory` | `string` | 否 | — | 内存限制（如 '512m'、'2g'） |
| `--mariadb-database` | `string` | 否 | — | MariaDB 数据库名称 |
| `--mariadb-password` | `string` | 否 | — | MariaDB 密码 |
| `--mariadb-root-password` | `string` | 否 | — | MariaDB root 密码 |
| `--mariadb-user` | `string` | 否 | — | MariaDB 用户 |
| `--mongo-database` | `string` | 否 | — | MongoDB 数据库名称 |
| `--mongo-root-password` | `string` | 否 | — | MongoDB root 密码 |
| `--mongo-root-username` | `string` | 否 | — | MongoDB root 用户名 |
| `--mysql-database` | `string` | 否 | — | MySQL 数据库名称 |
| `--mysql-password` | `string` | 否 | — | MySQL 密码 |
| `--mysql-root-password` | `string` | 否 | — | MySQL root 密码 |
| `--mysql-user` | `string` | 否 | — | MySQL 用户 |
| `--name` | `string` | 否 | — | 数据库名称 |
| `--postgres-db` | `string` | 否 | — | PostgreSQL 数据库名称 |
| `--postgres-password` | `string` | 否 | — | PostgreSQL 密码 |
| `--postgres-user` | `string` | 否 | — | PostgreSQL 用户 |
| `--project-uuid` | `string` | 是 | — | 项目 UUID（必填） |
| `--public-port` | `integer` | 否 | `0` | 公网端口 |
| `--redis-password` | `string` | 否 | — | Redis 密码 |
| `--server-uuid` | `string` | 是 | — | 服务器 UUID（必填） |
| `--sqlite-databases` | `string` | 否 | — | SQLite：逗号分隔的数据库文件名（如 'app.db,cache.db'） |
| `--tag` | `stringArray` | 否 | — | 要分配的标签（可重复） |
| `--tags` | `stringSlice` | 否 | — | 要分配的逗号分隔标签 |

## 查看当前帮助

```sh
coolify database create --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
