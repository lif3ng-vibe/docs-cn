# Import status

显示导入状态

## 用法

```sh
coolify database import status <database_uuid> <activity_id>
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--poll-interval` | `duration` | 否 | `3s` | 设置 --wait 时的状态轮询间隔 |
| `--wait` | `boolean` | 否 | `false` | 等待导入完成；失败时以非零状态退出 |

## 查看当前帮助

```sh
coolify database import status --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
