# Update

通过 UUID 更新数据库配置。

## 用法

```sh
coolify database update <uuid>
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--description` | `string` | 否 | — | 数据库描述 |
| `--image` | `string` | 否 | — | Docker 镜像 |
| `--is-public` | `boolean` | 否 | `false` | 将数据库设为公开访问 |
| `--limits-cpus` | `string` | 否 | — | CPU 限制 |
| `--limits-memory` | `string` | 否 | — | 内存限制 |
| `--name` | `string` | 否 | — | 数据库名称 |
| `--public-port` | `integer` | 否 | `0` | 公网端口 |
| `--sqlite-databases` | `string` | 否 | — | 逗号分隔的 SQLite 数据库文件名（仅 SQLite） |

## 查看当前帮助

```sh
coolify database update --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
