# Env delete

从数据库中删除环境变量。第一个 UUID 是数据库，第二个是要删除的具体环境变量。

## 用法

```sh
coolify database env delete <database_uuid> <env_uuid>
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--force` | `boolean` | 否 | `false` | 跳过确认提示 |

## 查看当前帮助

```sh
coolify database env delete --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
