# Env get

获取指定环境变量的详细信息。第一个 UUID 是数据库，第二个是环境变量的 UUID 或键名。

## 用法

```sh
coolify database env get <database_uuid> <env_uuid_or_key>
```

## 查看当前帮助

```sh
coolify database env get --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
