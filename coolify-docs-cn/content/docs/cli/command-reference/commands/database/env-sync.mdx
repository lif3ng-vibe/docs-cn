# Env sync

从 .env 文件同步环境变量

## 用法

```sh
coolify database env sync <database_uuid>
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--file (-f)` | `string` | 是 | — | .env 文件路径（必填） |
| `--is-literal` | `boolean` | 否 | `false` | 将所有值视为字面量（不插值变量） |

## 查看当前帮助

```sh
coolify database env sync --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
