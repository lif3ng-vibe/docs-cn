# Backup delete

删除备份配置，可选从 S3 删除其全部执行记录。第一个 UUID 是数据库，第二个是具体的备份配置。

## 用法

```sh
coolify database backup delete <database_uuid> <backup_uuid>
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--delete-s3` | `boolean` | 否 | `false` | 从 S3 删除备份文件 |

## 查看当前帮助

```sh
coolify database backup delete --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
