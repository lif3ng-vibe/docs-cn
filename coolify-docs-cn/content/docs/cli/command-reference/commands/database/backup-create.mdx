# Backup create

创建新的定时备份配置

## 用法

```sh
coolify database backup create <database_uuid>
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--databases-to-backup` | `string` | 否 | — | 要备份的数据库列表（逗号分隔） |
| `--disable-local-backup` | `boolean` | 否 | `false` | 禁用本地备份存储 |
| `--dump-all` | `boolean` | 否 | `false` | 转储所有数据库 |
| `--enabled` | `boolean` | 否 | `false` | 启用备份计划 |
| `--frequency` | `string` | 否 | — | 备份频率（cron 表达式，如每天为 '0 0 * * *'） |
| `--retention-amount-locally` | `integer` | 否 | `0` | 本地保留的备份数量 |
| `--retention-amount-s3` | `integer` | 否 | `0` | S3 中保留的备份数量 |
| `--retention-days-locally` | `integer` | 否 | `0` | 备份本地保留天数 |
| `--retention-days-s3` | `integer` | 否 | `0` | 备份在 S3 的保留天数 |
| `--retention-max-storage-locally` | `float64` | 否 | `0` | 本地备份的最大存储空间（GB） |
| `--retention-max-storage-s3` | `float64` | 否 | `0` | S3 备份的最大存储空间（GB） |
| `--s3-storage-uuid` | `string` | 否 | — | S3 存储 UUID |
| `--save-s3` | `boolean` | 否 | `false` | 将备份保存到 S3 |
| `--timeout` | `integer` | 否 | `0` | 备份超时时间（秒） |

## 查看当前帮助

```sh
coolify database backup create --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
