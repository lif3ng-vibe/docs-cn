# Storage update

更新数据库的存储

## 用法

```sh
coolify database storage update <db_uuid>
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--content` | `string` | 否 | — | 文件内容（仅 file） |
| `--host-path` | `string` | 否 | — | 宿主机路径（仅 persistent） |
| `--id` | `integer` | 否 | `0` | 存储 ID（已弃用，请改用 --uuid） |
| `--is-preview-suffix-enabled` | `boolean` | 否 | `false` | 为该存储启用预览后缀 |
| `--mount-path` | `string` | 否 | — | 容器内挂载路径 |
| `--name` | `string` | 否 | — | 存储名称（仅 persistent） |
| `--type` | `string` | 是 | — | 存储类型：'persistent' 或 'file'（必填） |
| `--uuid` | `string` | 否 | — | 存储 UUID（必填，可用 'storage list' 查找） |

## 查看当前帮助

```sh
coolify database storage update --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
