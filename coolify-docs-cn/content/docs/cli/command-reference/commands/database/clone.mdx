# Clone

将数据库克隆到目标

## 用法

```sh
coolify database clone <uuid>
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--clone-volumes` | `boolean` | 否 | `false` | 克隆卷数据 |
| `--destination` | `string` | 否 | — | 目标 UUID |
| `--name` | `string` | 否 | — | 可选的新名称 |

## 查看当前帮助

```sh
coolify database clone --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
