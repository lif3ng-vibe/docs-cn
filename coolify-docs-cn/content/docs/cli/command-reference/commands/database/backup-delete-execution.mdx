# Backup delete execution

删除指定的备份执行记录，可选同时从 S3 删除。第一个 UUID 是数据库，第二个是备份配置，第三个是具体的执行记录。

## 用法

```sh
coolify database backup delete-execution <database_uuid> <backup_uuid> <execution_uuid>
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--delete-s3` | `boolean` | 否 | `false` | 从 S3 删除备份文件 |

## 查看当前帮助

```sh
coolify database backup delete-execution --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
