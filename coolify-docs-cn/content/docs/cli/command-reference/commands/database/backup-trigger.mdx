# Backup trigger

为指定备份配置立即触发一次备份。第一个 UUID 是数据库，第二个是要触发的具体备份配置。

## 用法

```sh
coolify database backup trigger <database_uuid> <backup_uuid>
```

## 查看当前帮助

```sh
coolify database backup trigger --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
