# Import start

开始导入到数据库

## 用法

```sh
coolify database import start <database_uuid>
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--dump-all` | `boolean` | 否 | `false` | 备份包含所有数据库 |
| `--file` | `string` | 否 | — | 要上传并导入的本地备份文件 |
| `--keep-owners` | `boolean` | 否 | `false` | PostgreSQL：从单数据库归档恢复对象所有者和权限 |
| `--poll-interval` | `duration` | 否 | `3s` | 设置 --wait 时的状态轮询间隔 |
| `--replace-existing` | `boolean` | 否 | `false` | PostgreSQL：恢复单数据库归档前先删除匹配的对象 |
| `--restore-mysql-users` | `boolean` | 否 | `false` | MySQL/MariaDB 全库备份：同时恢复用户、密码和权限 |
| `--s3-path` | `string` | 否 | — | 备份在 S3 存储中的路径 |
| `--s3-storage-uuid` | `string` | 否 | — | 用于导入的 S3 存储 UUID（需要 --s3-path） |
| `--server-path` | `string` | 否 | — | 备份在数据库服务器上的绝对路径 |
| `--sqlite-database` | `string` | 否 | — | SQLite：要恢复到的数据库文件（如 app.db） |
| `--upload-id` | `string` | 否 | — | 之前上传的备份文件 ID |
| `--wait` | `boolean` | 否 | `false` | 等待导入完成；失败时以非零状态退出 |

## 查看当前帮助

```sh
coolify database import start --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
