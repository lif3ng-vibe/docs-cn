# Backup executions

列出某个备份配置的所有执行记录。第一个 UUID 是数据库，第二个是具体的备份配置。

## 用法

```sh
coolify database backup executions <database_uuid> <backup_uuid>
```

## 查看当前帮助

```sh
coolify database backup executions --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
