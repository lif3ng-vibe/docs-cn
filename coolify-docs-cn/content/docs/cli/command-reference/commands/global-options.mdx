# Global options

Coolify CLI

## 用法

```sh
coolify
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--context` | `string` | 否 | — | 按名称使用指定上下文 |
| `--debug` | `boolean` | 否 | `false` | 调试模式 |
| `--format` | `string` | 否 | `table` | 输出格式（table\|json\|pretty） |
| `--show-sensitive (-s)` | `boolean` | 否 | `false` | 显示敏感信息 |
| `--token` | `string` | 否 | — | 用于认证的令牌（覆盖上下文令牌） |

## 查看当前帮助

```sh
coolify --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
