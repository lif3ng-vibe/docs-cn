# Create

创建并验证密钥管理器集成令牌

## 用法

```sh
coolify integration-token create
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--metadata` | `string` | 否 | — | 以 JSON 对象表示的提供商元数据（infisical 和 vault 必填） |
| `--name` | `string` | 是 | — | 令牌友好名称（必填） |
| `--provider` | `string` | 是 | — | 密钥管理器提供商：doppler、infisical、vault（必填） |
| `--provider-token-stdin` | `boolean` | 否 | `false` | 从 stdin 读取提供商令牌 |

## 查看当前帮助

```sh
coolify integration-token create --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
