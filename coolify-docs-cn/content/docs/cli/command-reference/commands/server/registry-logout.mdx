# Registry logout

在服务器上退出 Docker 镜像仓库登录

## 用法

```sh
coolify server registry logout <server_uuid> <registry>
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--force (-f)` | `boolean` | 否 | `false` | 跳过确认提示 |

## 查看当前帮助

```sh
coolify server registry logout --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
