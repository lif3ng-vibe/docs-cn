# Digitalocean create

创建 DigitalOcean 服务器

## 用法

```sh
coolify server digitalocean create
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--cloud-init` | `string` | 否 | — | cloud-init YAML |
| `--cloud-token` | `string` | 否 | — | 云服务商令牌 UUID |
| `--enable-ipv6` | `boolean` | 否 | `true` | 启用公网 IPv6 |
| `--image` | `string` | 否 | — | DigitalOcean 镜像 ID 或 slug |
| `--monitoring` | `boolean` | 否 | `true` | 启用 DigitalOcean 监控 |
| `--name` | `string` | 否 | — | 服务器名称 |
| `--private-key` | `string` | 否 | — | Coolify 私钥 UUID |
| `--region` | `string` | 否 | — | DigitalOcean 区域 |
| `--size` | `string` | 否 | — | DigitalOcean 实例规格 |
| `--ssh-key-ids` | `intSlice` | 否 | — | 附加的 DigitalOcean SSH 密钥 ID |
| `--validate` | `boolean` | 否 | `false` | 创建后验证 |

## 查看当前帮助

```sh
coolify server digitalocean create --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
