# Hetzner create

创建 Hetzner 服务器

## 用法

```sh
coolify server hetzner create
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--cloud-init` | `string` | 否 | — | cloud-init YAML |
| `--cloud-token` | `string` | 否 | — | 云服务商令牌 UUID |
| `--enable-backups` | `boolean` | 否 | `false` | 启用 Hetzner 备份 |
| `--enable-ipv4` | `boolean` | 否 | `true` | 启用公网 IPv4 |
| `--enable-ipv6` | `boolean` | 否 | `true` | 启用公网 IPv6 |
| `--firewall-ids` | `intSlice` | 否 | — | Hetzner 防火墙 ID |
| `--image` | `integer` | 否 | `0` | Hetzner 镜像 ID |
| `--location` | `string` | 否 | — | Hetzner 机房位置名称 |
| `--name` | `string` | 否 | — | 服务器名称（省略时自动生成） |
| `--network-ids` | `intSlice` | 否 | — | Hetzner 网络 ID |
| `--private-key` | `string` | 否 | — | Coolify 私钥 UUID |
| `--server-type` | `string` | 否 | — | Hetzner 服务器类型 |
| `--ssh-key-ids` | `intSlice` | 否 | — | 附加的 Hetzner SSH 密钥 ID |
| `--validate` | `boolean` | 否 | `false` | 创建后验证 |

## 查看当前帮助

```sh
coolify server hetzner create --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
