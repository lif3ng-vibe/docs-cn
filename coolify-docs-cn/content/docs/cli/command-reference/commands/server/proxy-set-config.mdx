# Proxy set config

保存原始代理配置

## 用法

```sh
coolify server proxy set-config <server_uuid>
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--configuration` | `string` | 否 | — | 原始代理配置 |
| `--configuration-file` | `string` | 否 | — | 从文件读取配置 |

## 查看当前帮助

```sh
coolify server proxy set-config --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
