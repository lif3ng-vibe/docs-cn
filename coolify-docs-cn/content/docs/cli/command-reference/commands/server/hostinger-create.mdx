# Hostinger create

购买 Hostinger VPS 并添加为服务器（付费）

## 用法

```sh
coolify server hostinger create
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--cloud-token` | `string` | 否 | — | 云服务商令牌 UUID |
| `--data-center-id` | `integer` | 否 | `0` | Hostinger 数据中心 ID |
| `--enable-backups` | `boolean` | 否 | `false` | 启用 Hostinger 每周备份（额外收费；默认关闭） |
| `--force (-f)` | `boolean` | 否 | `false` | 跳过购买确认提示 |
| `--item-id` | `string` | 否 | — | Hostinger 目录价格 ID（套餐 + 计费周期，如 hostingercom-vps-kvm1-usd-1m） |
| `--name` | `string` | 否 | — | 服务器名称（省略时自动生成） |
| `--post-install-script-id` | `integer` | 否 | `0` | Hostinger 安装后脚本 ID |
| `--private-key` | `string` | 否 | — | Coolify 私钥 UUID |
| `--ssh-key-ids` | `intSlice` | 否 | — | 附加的 Hostinger SSH 密钥 ID |
| `--template-id` | `integer` | 否 | `0` | Hostinger 操作系统模板 ID |
| `--validate` | `boolean` | 否 | `false` | 创建后验证 |

## 查看当前帮助

```sh
coolify server hostinger create --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
