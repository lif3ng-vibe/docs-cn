# Docker cleanup update

更新 Docker 清理设置

## 用法

```sh
coolify server docker-cleanup update <server_uuid>
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--delete-unused-networks` | `boolean` | 否 | `false` | 删除未使用的网络 |
| `--delete-unused-volumes` | `boolean` | 否 | `false` | 删除未使用的卷 |
| `--disable-image-retention` | `boolean` | 否 | `false` | 禁用应用镜像保留 |
| `--force` | `boolean` | 否 | `false` | 强制清理 |
| `--frequency` | `string` | 否 | — | cron 频率 |
| `--threshold` | `integer` | 否 | `0` | 磁盘使用率阈值（百分比） |

## 查看当前帮助

```sh
coolify server docker-cleanup update --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
