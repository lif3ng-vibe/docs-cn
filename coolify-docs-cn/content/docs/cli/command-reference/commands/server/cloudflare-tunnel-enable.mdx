# Cloudflare tunnel enable

启用 Cloudflare tunnel 开关

## 用法

```sh
coolify server cloudflare-tunnel enable <server_uuid>
```

## 查看当前帮助

```sh
coolify server cloudflare-tunnel enable --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
