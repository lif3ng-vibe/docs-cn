# Update

更新服务器

## 用法

```sh
coolify server update <uuid>
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--concurrent-builds` | `integer` | 否 | `0` | 最大并发构建数 |
| `--connection-timeout` | `integer` | 否 | `0` | SSH 连接超时时间（秒） |
| `--deployment-queue-limit` | `integer` | 否 | `0` | 部署队列上限 |
| `--description` | `string` | 否 | — | 服务器描述 |
| `--disk-usage-check-frequency` | `string` | 否 | — | 磁盘使用率检查频率（cron） |
| `--disk-usage-notification-threshold` | `integer` | 否 | `0` | 磁盘使用率通知阈值（百分比） |
| `--dynamic-timeout` | `integer` | 否 | `0` | 动态超时 |
| `--instant-validate` | `boolean` | 否 | `false` | 更新后验证服务器 |
| `--ip` | `string` | 否 | — | 服务器 IP 地址 |
| `--is-build-server` | `boolean` | 否 | `false` | 已弃用：请使用 --server-role build（true）或 --server-role both（false） |
| `--is-terminal-enabled` | `boolean` | 否 | `false` | 启用终端访问 |
| `--name` | `string` | 否 | — | 服务器名称 |
| `--port` | `integer` | 否 | `22` | SSH 端口 |
| `--private-key-uuid` | `string` | 否 | — | 私钥 UUID |
| `--proxy-type` | `string` | 否 | — | 代理类型（如 TRAEFIK、CADDY、NGINX） |
| `--server-role` | `string` | 否 | — | 服务器角色（deployment\|build\|both）：'deployment' 需要另一台可用的构建服务器 |
| `--user` | `string` | 否 | — | SSH 用户 |

## 查看当前帮助

```sh
coolify server update --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
