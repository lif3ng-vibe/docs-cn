# Digitalocean ssh keys

列出 DigitalOcean SSH 密钥

## 用法

```sh
coolify server digitalocean ssh-keys <cloud_token_uuid>
```

## 查看当前帮助

```sh
coolify server digitalocean ssh-keys --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
