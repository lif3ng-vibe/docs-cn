# Remove

移除服务器

## 用法

```sh
coolify server remove <uuid>
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--delete-from-provider` | `boolean` | 否 | `false` | 同时从云服务商（Hetzner、Vultr 或 DigitalOcean）删除该服务器。此操作无法撤销 |
| `--force` | `boolean` | 否 | `false` | 同时删除服务器上的所有资源 |

## 查看当前帮助

```sh
coolify server remove --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
