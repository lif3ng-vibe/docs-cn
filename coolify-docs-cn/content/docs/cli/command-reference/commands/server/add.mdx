# Add

添加服务器

## 用法

```sh
coolify server add <server_name> <ip_address> <private_key_uuid>
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--port (-p)` | `integer` | 否 | `22` | 端口 |
| `--server-role` | `string` | 否 | — | 服务器角色（deployment\|build\|both）：'deployment' 需要另一台可用的构建服务器 |
| `--user (-u)` | `string` | 否 | `root` | 用户 |
| `--validate` | `boolean` | 否 | `false` | 验证服务器 |

## 查看当前帮助

```sh
coolify server add --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
