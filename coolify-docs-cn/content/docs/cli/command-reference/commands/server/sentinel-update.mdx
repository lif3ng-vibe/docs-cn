# Sentinel update

通过 JSON 更新 Sentinel 设置

## 用法

```sh
coolify server sentinel update <server_uuid>
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--json` | `string` | 否 | — | 要补丁更新的 JSON 字段 |

## 查看当前帮助

```sh
coolify server sentinel update --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
