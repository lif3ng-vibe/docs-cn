# Get

按 UUID 获取服务器详情

## 用法

```sh
coolify server get <uuid>
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--resources` | `boolean` | 否 | `false` | 显示部署在服务器上的资源而非服务器详情 |

## 查看当前帮助

```sh
coolify server get --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
