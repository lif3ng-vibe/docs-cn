# Hostinger post install scripts

列出 Hostinger 安装后脚本

## 用法

```sh
coolify server hostinger post-install-scripts <cloud_token_uuid>
```

## 查看当前帮助

```sh
coolify server hostinger post-install-scripts --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
