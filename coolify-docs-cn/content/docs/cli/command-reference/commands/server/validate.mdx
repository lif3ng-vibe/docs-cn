# Validate

验证服务器

## 用法

```sh
coolify server validate <uuid>
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--install` | `boolean` | 否 | `false` | 安装缺失的前置依赖和 Docker（可能重启 Docker） |

## 查看当前帮助

```sh
coolify server validate --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
