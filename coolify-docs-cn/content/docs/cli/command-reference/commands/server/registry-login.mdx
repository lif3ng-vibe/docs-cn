# Registry login

在一台或多台服务器上登录 Docker 镜像仓库

## 用法

```sh
coolify server registry login <server_uuid> [<server_uuid>...]
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--password-stdin` | `boolean` | 否 | `false` | 从 stdin 读取密码或访问令牌 |
| `--registry` | `string` | 是 | — | 镜像仓库主机，可带端口（如 ghcr.io、registry.example.com:5000，Docker Hub 为 docker.io）（必填） |
| `--username (-u)` | `string` | 是 | — | 镜像仓库用户名（必填） |

## 查看当前帮助

```sh
coolify server registry login --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
