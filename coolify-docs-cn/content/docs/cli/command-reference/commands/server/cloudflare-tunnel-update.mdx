# Cloudflare tunnel update

设置 Cloudflare tunnel 的启用状态

## 用法

```sh
coolify server cloudflare-tunnel update <server_uuid>
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--enabled` | `boolean` | 是 | `false` | 启用（true）或禁用（false）Cloudflare tunnel |

## 查看当前帮助

```sh
coolify server cloudflare-tunnel update --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
