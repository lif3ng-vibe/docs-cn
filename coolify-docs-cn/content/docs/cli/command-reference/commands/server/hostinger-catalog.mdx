# Hostinger catalog

列出 Hostinger VPS 套餐与价格（条目 ID 用于创建）

## 用法

```sh
coolify server hostinger catalog <cloud_token_uuid>
```

## 查看当前帮助

```sh
coolify server hostinger catalog --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
