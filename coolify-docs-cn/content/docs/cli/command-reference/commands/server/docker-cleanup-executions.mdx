# Docker cleanup executions

列出 Docker 清理执行记录

## 用法

```sh
coolify server docker-cleanup executions <server_uuid>
```

## 查看当前帮助

```sh
coolify server docker-cleanup executions --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
