# Vultr create

创建 Vultr 服务器

## 用法

```sh
coolify server vultr create
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--cloud-init` | `string` | 否 | — | cloud-init YAML |
| `--cloud-token` | `string` | 否 | — | 云服务商令牌 UUID |
| `--disable-public-ipv4` | `boolean` | 否 | `false` | 禁用公网 IPv4 |
| `--enable-ipv6` | `boolean` | 否 | `true` | 启用公网 IPv6 |
| `--name` | `string` | 否 | — | 服务器名称 |
| `--os-id` | `integer` | 否 | `0` | Vultr 操作系统 ID |
| `--plan` | `string` | 否 | — | Vultr 套餐 |
| `--private-key` | `string` | 否 | — | Coolify 私钥 UUID |
| `--region` | `string` | 否 | — | Vultr 区域 |
| `--ssh-key-ids` | `stringSlice` | 否 | — | 附加的 Vultr SSH 密钥 ID |
| `--validate` | `boolean` | 否 | `false` | 创建后验证 |

## 查看当前帮助

```sh
coolify server vultr create --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
