# Proxy update

更新代理设置

## 用法

```sh
coolify server proxy update <server_uuid>
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--generate-exact-labels` | `boolean` | 否 | `false` | 生成精确标签 |
| `--proxy-type` | `string` | 否 | — | 代理类型（如 TRAEFIK） |
| `--redirect-enabled` | `boolean` | 否 | `true` | 启用代理重定向 |
| `--redirect-url` | `string` | 否 | — | 重定向 URL |

## 查看当前帮助

```sh
coolify server proxy update --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
