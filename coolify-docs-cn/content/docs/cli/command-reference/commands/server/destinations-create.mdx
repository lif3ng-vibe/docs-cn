# Destinations create

创建服务器目标

## 用法

```sh
coolify server destinations create <server_uuid>
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--name` | `string` | 否 | — | 目标名称 |
| `--network` | `string` | 是 | — | Docker 网络名称（必填） |
| `--type` | `string` | 否 | — | 目标类型：standalone 或 swarm |

## 查看当前帮助

```sh
coolify server destinations create --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
