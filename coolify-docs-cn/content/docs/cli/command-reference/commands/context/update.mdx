# Update

更新上下文属性（名称、URL、令牌）

## 用法

```sh
coolify context update <context_name>
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--name (-n)` | `string` | 否 | — | 上下文的新名称 |
| `--token (-t)` | `string` | 否 | — | 上下文的新令牌 |
| `--url (-u)` | `string` | 否 | — | 上下文的新 URL |

## 查看当前帮助

```sh
coolify context update --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
