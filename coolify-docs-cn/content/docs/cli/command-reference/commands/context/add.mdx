# Add

添加新上下文

## 用法

```sh
coolify context add <context_name> <url> <token>
```

## 选项

| 选项 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `--default (-d)` | `boolean` | 否 | `false` | 设为默认上下文 |
| `--force (-f)` | `boolean` | 否 | `false` | 上下文已存在时强制覆盖 |

## 查看当前帮助

```sh
coolify context add --help
```

已安装 CLI 的帮助信息会反映你的 CLI 版本实际支持的选项。
