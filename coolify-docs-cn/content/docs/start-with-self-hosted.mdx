# 从自托管开始

自托管 Coolify，意味着 Coolify 实例运行在你自己掌控的基础设施上。

<CoolCallout icon={ArrowsRight} title="简要版">

Coolify 需要 2 个 CPU 核心、2 GB 内存和 10 GB 磁盘空间才能运行。如果你的服务器满足这一配置，用下面的安装脚本即可安装 Coolify：

```sh
curl -fsSL https://cdn.coollabs.io/coolify/install.sh | bash
```

安装完成后，终端会打印后续步骤，照着执行即可。

</CoolCallout>

### 3. 最低硬件要求

| 项目 | 最低要求 | 备注 |
| :--- | :--- | :--- |
| CPU | 2 核 | 单机跑多个工作负载时请增加核心数。 |
| 内存 | 2 GB RAM | 随工作负载增长增加内存。 |
| 磁盘 | 10 GB 可用空间 | 为 Docker 镜像、卷（volume）和备份预留额外空间。 |
| 架构 | amd64 或 arm64 | Raspberry Pi OS 安装必须使用 ARM64。 |

<CoolCallout icon={SackDollar} title="预算有限时的硬件资源规划">

Coolify 也能在更小的服务器上运行（例如 1 个 CPU 核心、512 MB 内存、4 GB 磁盘），但不推荐这么做。

如果预算紧张，可以从 1 个 CPU 核心、1 GB 内存的配置起步，待工作负载增长或服务器因资源吃紧变慢时再升级。

如果你要在同一台服务器上同时跑构建任务和 Coolify，请密切留意资源占用。资源耗尽可能让服务器失去响应。

</CoolCallout>

### 1. 运行安装脚本
打开终端，以 root 或具备 sudo 权限的用户 SSH 登录服务器，然后运行以下命令：
```sh
curl -fsSL https://cdn.coollabs.io/coolify/install.sh | bash
```

<Accordions type="multiple">
  <Accordion title="安装器都做了什么？">

  - 安装所需的软件包（curl、wget、git、jq、openssl）
  - 安装 Docker Engine（在发行版支持的情况下）
  - 配置 Docker 设置（日志、守护进程）
  - 在 `/data/coolify` 下创建 Coolify 目录结构
  - 配置用于服务器管理的 SSH 密钥
  - 安装并启动 Coolify
  
  查看[脚本源码](https://github.com/coollabsio/coolify/blob/v4.x/scripts/install.sh)
  
  </Accordion>
</Accordions>


<Callout type="warning" title="运行安装器之前">

  1. 如果 Docker 是通过 snap 安装的，请先卸载它，改用[官方 Docker 方式](https://docs.docker.com/engine/install/)安装 Docker Engine，或者让安装脚本自动处理。

  2. 如果你使用 Ubuntu，请选择 20.04、22.04 或 24.04 等 LTS 版本。非 LTS 的 Ubuntu 表现可能不一致，若安装器出问题，请改用手动安装方式。
</Callout>

<Callout type="danger" title="保护你的管理员账户">

  **请在安装完成后立即创建管理员账户。谁先到达注册页面，谁就能成为实例管理员并获得你服务器的 root 权限。**

### 前提条件
运行手动安装命令之前，请确认服务器已具备：

- 已安装 [curl](https://curl.se/)，用于下载 Coolify 所需文件。
- 来自官方 Docker 软件源的 Docker Engine 24 或更新版本。请按照适用于你 Linux 发行版的 [Docker Engine 安装指南](https://docs.docker.com/engine/install/#服务器)操作。
- 使用即将执行安装命令的用户可 SSH 访问服务器。

---

### 1. 创建所需目录
在 `/data/coolify` 下创建 Coolify 的基础目录：

```sh
mkdir -p /data/coolify/{source,ssh,applications,databases,backups,services,proxy,webhooks-during-maintenance}
mkdir -p /data/coolify/ssh/{keys,mux}
mkdir -p /data/coolify/proxy/dynamic
```

---

### 2. 生成并注册 SSH 密钥
生成一把供 Coolify 管理服务器用的 SSH 密钥：

```sh
ssh-keygen -f /data/coolify/ssh/keys/id.root@host.docker.internal -t ed25519 -N '' -C root@coolify
```

然后，把公钥追加到你的 `~/.ssh/authorized_keys`：

```sh
cat /data/coolify/ssh/keys/id.root@host.docker.internal.pub >> ~/.ssh/authorized_keys
chmod 600 ~/.ssh/authorized_keys
```

<Callout type="info" title="可以复用现有 SSH 密钥">

如果你已有 SSH 密钥，可以跳过生成新密钥这一步，但记得安装完成后把它添加到 Coolify 实例中。

</Callout>

---

### 3. 下载所需文件
从 Coolify 的 CDN 下载必要文件到 `/data/coolify/source`：

```sh
curl -fsSL https://cdn.coollabs.io/coolify/docker-compose.yml -o /data/coolify/source/docker-compose.yml
curl -fsSL https://cdn.coollabs.io/coolify/docker-compose.prod.yml -o /data/coolify/source/docker-compose.prod.yml
curl -fsSL https://cdn.coollabs.io/coolify/.env.production -o /data/coolify/source/.env
curl -fsSL https://cdn.coollabs.io/coolify/upgrade.sh -o /data/coolify/source/upgrade.sh
```

---

### 4. 设置权限
为 Coolify 的文件和目录设置正确的权限：

```sh
chown -R 9999:root /data/coolify
chmod -R 700 /data/coolify
```
---

### 5. 生成安全的环境变量值
用安全的随机值更新 `.env` 文件：

```sh
sed -i "s|APP_ID=.*|APP_ID=$(openssl rand -hex 16)|g" /data/coolify/source/.env
sed -i "s|APP_KEY=.*|APP_KEY=base64:$(openssl rand -base64 32)|g" /data/coolify/source/.env
sed -i "s|DB_PASSWORD=.*|DB_PASSWORD=$(openssl rand -base64 32)|g" /data/coolify/source/.env
sed -i "s|REDIS_PASSWORD=.*|REDIS_PASSWORD=$(openssl rand -base64 32)|g" /data/coolify/source/.env
sed -i "s|PUSHER_APP_ID=.*|PUSHER_APP_ID=$(openssl rand -hex 32)|g" /data/coolify/source/.env
sed -i "s|PUSHER_APP_KEY=.*|PUSHER_APP_KEY=$(openssl rand -hex 32)|g" /data/coolify/source/.env
sed -i "s|PUSHER_APP_SECRET=.*|PUSHER_APP_SECRET=$(openssl rand -hex 32)|g" /data/coolify/source/.env
```

<Callout type="warning" title="重要">

  这些值只在第一次安装 Coolify 时生成一次。之后再改动可能导致安装损坏。务必妥善保管！

</Callout>

---

### 6. 创建 Docker 网络
创建 Coolify 用来连接其内部服务的 Docker 网络：

```sh
docker network create --attachable coolify
```

---

### 7. 启动 Coolify
用 Docker Compose 启动 Coolify：

```sh
docker compose --env-file /data/coolify/source/.env -f /data/coolify/source/docker-compose.yml -f /data/coolify/source/docker-compose.prod.yml up -d --pull always --remove-orphans --force-recreate
```

<Callout type="info" title="注意">

  如果 Docker 无法拉取所需镜像，请先运行 **`docker login`**，再重新启动 Coolify。

</Callout>

---

### 8. 访问控制台
在浏览器打开 `http://192.168.1.69:8000`（把 `192.168.1.69` 换成你的服务器 IP），并创建管理员账户。

<Callout type="danger" title="保护你的管理员账户">

  **请在安装完成后立即创建管理员账户。谁先到达注册页面，谁就能成为实例管理员并获得你服务器的 root 权限。**
</Callout>

搞定！现在可以开始使用 Coolify了。

### 前提条件
要在 Raspberry Pi OS 上运行 Coolify，请使用支持 64 位的树莓派型号：

| 型号 | 备注 |
| :--- | :--- |
| Raspberry Pi Zero 2 W | 唯一受支持的 64 位 Zero 系型号。 |
| Raspberry Pi 400 | 支持全部型号。 |
| Raspberry Pi 3 | 支持全部型号。 |
| Raspberry Pi 4 | 支持全部型号。 |
| Raspberry Pi 5 | 支持全部型号。 |

---
  
### 1. 烧录 64 位系统

在电脑上下载并安装 [Raspberry Pi Imager](https://www.raspberrypi.com/software/)，然后插入你的 microSD 卡。

在 Raspberry Pi Imager 中：

1. 点击 `Choose Device`，选择你的树莓派型号。
2. 点击 `Choose OS`。
3. 选择 `Raspberry Pi OS (other)`。
4. 选择 `Raspberry Pi OS Lite (64-bit)`。
5. 点击 `Choose Storage`，选择你的 microSD 卡。

<Callout type="warning" title="注意">

  必须使用 64 位操作系统。Coolify 与 32 位 Raspberry Pi OS 镜像不兼容。
</Callout>

<Callout type="info" title="说明">

  你可以使用 `Raspberry Pi OS (64-bit)`、`Raspberry Pi OS Full (64-bit)` 或 Ubuntu，但 `Raspberry Pi OS Lite (64-bit)` 占用资源最少，是推荐的起步选择。
</Callout>

---

### 2. 启用 SSH

点击 `Next`，选择 `Edit settings`，切到 `Services` 标签页，启用 SSH 并选择公钥认证。

<Callout type="warning" title="注意">

### 1. Root 用户
适用于希望在安装期间就预创建 root 账户、让注册页面永不暴露的场景。

| 变量 | 必填 | 说明 |
| :--- | :--- | :--- |
| `ROOT_USERNAME` | 是 | 3-255 个字符。允许：字母、数字、空格、下划线和连字符。 |
| `ROOT_USER_EMAIL` | 是 | 必须是有效邮箱格式且 DNS 记录有效，最长 255 个字符。 |
| `ROOT_USER_PASSWORD` | 是 | 至少 8 个字符，须包含大写、小写、数字和特殊符号。 |

<Tabs items={['Automated', 'Manual']}>
<Tab value="Automated" icon={Autobrightness2}>

```sh
env ROOT_USERNAME=RootUser \
ROOT_USER_EMAIL=example@example.com \
ROOT_USER_PASSWORD='StrongPassword123!' \
bash -c 'curl -fsSL https://cdn.coollabs.io/coolify/install.sh | bash'
```

如果你不是以 `root` 登录：

```sh
sudo -E env ROOT_USERNAME=RootUser \
ROOT_USER_EMAIL=example@example.com \
ROOT_USER_PASSWORD='StrongPassword123!' \
bash -c 'curl -fsSL https://cdn.coollabs.io/coolify/install.sh | bash'
```

</Tab>

<Tab value="Manual" icon={LaptopCode}>

编辑：

```sh

```

添加：

```sh
ROOT_USERNAME=RootUser
ROOT_USER_EMAIL=example@example.com
ROOT_USER_PASSWORD='StrongPassword123!'
```

然后运行：

```sh
docker compose --env-file /data/coolify/source/.env -f /data/coolify/source/docker-compose.yml -f /data/coolify/source/docker-compose.prod.yml up -d --pull always --remove-orphans --force-recreate
```

### 示例

#### A. 添加容器标签

为监控或日志聚合等外部工具添加标签：

```yaml
services:
  coolify:
    labels:
      com.example.monitoring: "true"
      com.example.environment: "production"
```

---

#### B. 设置资源限制

限制 Coolify 主容器的 CPU 与内存用量：

```yaml
services:
  coolify:
    cpus: 2.0
    mem_limit: 2G
    mem_reservation: 512M
```

可用属性的完整清单见 Docker Compose 文档：[cpus](https://docs.docker.com/reference/compose-file/services/#cpus?utm_source=coolify.io)、[mem_limit](https://docs.docker.com/reference/compose-file/services/#mem_limit?utm_source=coolify.io)、[mem_reservation](https://docs.docker.com/reference/compose-file/services/#mem_reservation?utm_source=coolify.io)以及[其他资源约束](https://docs.docker.com/reference/compose-file/services/#cpu_count?utm_source=coolify.io)。

---

#### C. 更改端口绑定

端口号可以通过 Coolify `.env` 文件（`/data/coolify/source/.env`）中的 `APP_PORT` 变量修改。不过，覆盖文件能让你控制端口*如何*绑定——这是 `.env` 做不到的。

把 Coolify UI 只绑定到 localhost，使其只能经由反向代理访问：

```yaml
services:
  coolify:
    ports:
      - "127.0.0.1:8000:8080"
```

或者干脆关闭端口，完全依赖 Docker 网络（在已为 Coolify 控制台启用并配置 Coolify Proxy 时很有用）：

```yaml
services:
  coolify:
    ports: !override []
```

<Callout type="warning" title="保住控制台访问">

如果你移除或限制了端口访问，请确保还有别的途径能打开 Coolify UI（例如反向代理），否则你会把自己锁在门外。

</Callout>

---

#### D. 调整数据库配置

添加自定义 PostgreSQL 参数：

```yaml
services:
  postgres:
    command: postgres -c max_connections=200 -c shared_buffers=512MB
```

---

#### E. 组合多项自定义

一个覆盖文件可以同时修改多个服务：

```yaml
services:
  coolify:
    mem_limit: 2G
    labels:
      com.example.monitoring: "true"

  postgres:
    mem_limit: 1G

  redis:
    mem_limit: 256M
```
