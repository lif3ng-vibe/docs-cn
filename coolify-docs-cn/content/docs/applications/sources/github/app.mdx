# 设置 GitHub App

GitHub App 可以让 Coolify 访问单个仓库、选定的若干仓库，或个人账户/组织中的全部仓库。

当你希望通过一个集成完成仓库选择、自动部署与拉取请求事件时，请使用 GitHub App。若无法安装 GitHub App，或只需要对单个仓库的只读访问，请使用[部署密钥](/applications/sources/deploy-keys)。

## 选择安装方式

- **自动安装**：利用 GitHub 的 manifest 流程自动配置所需的权限、webhook、凭据与回调。GitHub.com 适用此方式。
- **手动安装**：需要你自己创建应用、权限、事件、凭据、私钥并完成安装。GitHub Enterprise 或需要自定义权限时适用。

推荐使用自动安装，因为它能减少需要手动搬运的凭据和设置数量。

<Callout type="info" title="示例值">

截图使用了以下示例值：

- **Coolify 中的 GitHub App 名称**：`GitHub App Tutorial`
- **GitHub 上的 GitHub App 名称**：`coolify-github-app-tutorial`
- **Webhook 端点**：`https://coolboxy.shadowarcanist.internal`

请替换为你自己的名称与 Coolify 公网 URL。

</Callout>

<Tabs id="github-app-installation-method" items={['自动安装', '手动安装']}>
<Tab value="自动安装">

### 1. 在 Coolify 中创建 GitHub App 来源

<ZoomImage src="/docs-cn/coolify/images/applications/ci-cd/github/setup-app/1.webp" alt="Coolify 的 Sources（来源）页面与 Add 按钮" />

1. 从 Coolify 侧边栏打开 **Sources**（来源）。
2. 选择 **New source**（新建来源）> **GitHub App**。

<ZoomImage src="/docs-cn/coolify/images/applications/ci-cd/github/setup-app/2.webp" alt="Coolify 中新建 GitHub App 来源的表单" />

3. 为来源输入名称。
4. 如果应用属于某个组织，填入 GitHub 组织名称。个人账户请将 **Organization**（组织）留空。
5. 在 **Use this App for**（将此 App 用于）下，如需预览部署请选择 **Pull request previews**（拉取请求预览）。然后选择 **Continue**（继续）。

对于自托管的 GitHub Enterprise，展开 **Self-hosted / Enterprise GitHub** 并填写其 HTML URL、API URL、Git 用户与 Git 端口。

<Callout type="warning" title="全实例访问会影响所有团队">

在自托管 Coolify 上，**System wide**（全实例）会让该 GitHub App 对实例上的所有团队可用。如果只希望当前团队使用，请保持关闭。

Coolify Cloud 不提供该设置，因为来源无法与其他 Cloud 客户共享。

</Callout>

### 2. 选择自动安装

<ZoomImage src="/docs-cn/coolify/images/applications/ci-cd/github/setup-app/3.webp" alt="Coolify 中的 GitHub App 安装方式与 webhook 端点设置" />

使用 **Automated installation**（自动安装）区域。

在 **Webhook endpoint**（webhook 端点）中选择 **Use an instance endpoint**（使用实例端点）并选定一个 **Instance endpoint**（实例端点）。当 GitHub 需要调用另一个公网 URL（例如通过隧道暴露的域名）时，选择 **Use a custom endpoint**（使用自定义端点）并填写 **Custom endpoint**（自定义端点）。

只填基础 URL，例如 `https://coolify.example.com`，不要追加 `/webhooks`。

<Callout type="warning" title="GitHub 必须能访问该 webhook 端点">

如果 GitHub 无法访问该端点，仓库访问可能仍然正常，但自动部署与预览部署会失败。

</Callout>

<ZoomImage src="/docs-cn/coolify/images/applications/ci-cd/github/setup-app/4.webp" alt="Preview Deployments 权限与 Register Now 按钮" />

如果希望 Coolify 把部署信息写进拉取请求，请将 **Preview deployment access**（预览部署访问）设为 **Read and update pull requests**（读取并更新拉取请求）。这会授予拉取请求的读写权限。

必需权限会授予仓库内容、元数据与邮箱地址的读取权限。

选择 **Register with GitHub**（在 GitHub 上注册）。

### 3. 在 GitHub 上注册应用

<ZoomImage src="/docs-cn/coolify/images/applications/ci-cd/github/setup-app/5.webp" alt="GitHub 上用于命名并创建 GitHub App 的 manifest 页面" />

1. 输入一个唯一的 GitHub App 名称。
2. 选择 **Create GitHub App**（创建 GitHub App）。

应用创建完成后，GitHub 会将你带回 Coolify。Coolify 会保存生成的 App ID、客户端凭据、webhook secret 与私钥。

### 4. 安装仓库访问权限

<ZoomImage src="/docs-cn/coolify/images/applications/ci-cd/github/setup-app/6.webp" alt="Coolify 中的 Install Repositories on GitHub 操作" />

在注册后出现的仓库访问提示中，选择 **Install repositories**（安装仓库）。

<ZoomImage src="/docs-cn/coolify/images/applications/ci-cd/github/setup-app/7.webp" alt="GitHub App 的仓库访问范围选择" />

选择 **All repositories**（所有仓库）或 **Only select repositories**（仅选定仓库），然后选择 **Install**（安装）。

如果应用不需要访问整个账户，请选择仅选定仓库。

<ZoomImage src="/docs-cn/coolify/images/applications/ci-cd/github/setup-app/8.webp" alt="Coolify 中配置完成的 GitHub App 来源" />

GitHub 跳回 Coolify 后，确认来源页面显示了安装信息与仓库管理操作。

### 5. 创建应用

<ZoomImage src="/docs-cn/coolify/images/applications/ci-cd/github/setup-app/9.webp" alt="带 New 按钮的 Coolify 项目页面" />

1. 打开目标项目与环境。
2. 选择 **+ New**（新建）。

<ZoomImage src="/docs-cn/coolify/images/applications/ci-cd/github/setup-app/10.webp" alt="Private Repository (with GitHub App) 资源类型" />

3. 选择 **Private Repository (with GitHub App)**（私有仓库（通过 GitHub App））。

### 6. 选择部署服务器

<Callout type="info" title="自托管 Coolify 自带 localhost">

自托管安装自带一台 **localhost** 服务器。在没有其他部署服务器可用时，Coolify 会自动选中它。

</Callout>

<ZoomImage src="/docs-cn/coolify/images/applications/ci-cd/github/setup-app/11.webp" alt="新建 GitHub 应用时的服务器选择" />

选择应用将要运行的服务器。

### 7. 选择 GitHub App

<ZoomImage src="/docs-cn/coolify/images/applications/ci-cd/github/setup-app/12.webp" alt="新建应用时的 GitHub App 来源选择" />

选择你刚创建的 GitHub App 来源。

### 8. 配置并部署应用

<ZoomImage src="/docs-cn/coolify/images/applications/ci-cd/github/setup-app/13.webp" alt="GitHub App 应用的仓库选择" />

选择仓库，然后选择 **Load Repository**（加载仓库）。

<ZoomImage src="/docs-cn/coolify/images/applications/ci-cd/github/setup-app/14.webp" alt="GitHub App 应用的分支与构建配置" />

选择分支、**Build pack**（构建包）、基础目录、内部端口以及其他所需的构建设置。若拿不准该选哪种构建方式，请阅读[构建应用](/applications/builds/overview)。

选择 **Continue**（继续），配置应用域名与变量，然后部署。

打开 **Deployment Logs**（部署日志），确认 Coolify 克隆的是所选仓库与 commit。

</Tab>
<Tab value="手动安装">

自托管 GitHub Enterprise，或必须完全掌控 GitHub App 配置时，请使用手动安装。

你需要把以下值填入 Coolify：

- App ID
- Installation ID
- Client ID
- Client Secret
- Webhook Secret
- GitHub App 私钥

### 1. 在 Coolify 中创建来源

<ZoomImage src="/docs-cn/coolify/images/applications/ci-cd/github/setup-app/15.webp" alt="Coolify 的 Sources（来源）页面与 Add 按钮" />

打开 **Sources**（来源），选择 **New source**（新建来源）> **GitHub App**。

<ZoomImage src="/docs-cn/coolify/images/applications/ci-cd/github/setup-app/16.webp" alt="新建 GitHub App 来源的名称与组织字段" />

输入来源名称和组织（可选），然后选择 **Continue**（继续）。

自动安装路径中介绍的 **System wide**（全实例）与自托管 GitHub 设置在这里同样适用。

<ZoomImage src="/docs-cn/coolify/images/applications/ci-cd/github/setup-app/17.webp" alt="GitHub App 来源的 Manual Installation 选择" />

在 **Manual installation**（手动安装）中选择 **Continue manually**（继续手动安装）。Coolify 会打开来源字段，稍后你在其中填入 GitHub App 凭据。

### 2. 打开 GitHub App 设置

GitHub 把应用创建入口放在不同的账户设置里。

<Tabs id="github-app-owner" items={['个人账户', '组织']}>
<Tab value="个人账户">

<ZoomImage src="/docs-cn/coolify/images/applications/ci-cd/github/setup-app/19.webp" alt="个人 GitHub 账户中的 Developer settings" />

1. 打开你的 GitHub 账户设置。
2. 选择 **Developer settings**（开发者设置）。

<ZoomImage src="/docs-cn/coolify/images/applications/ci-cd/github/setup-app/20.webp" alt="个人账户设置中的 New GitHub App 按钮" />

3. 选择 **GitHub Apps**。
4. 选择 **New GitHub App**（新建 GitHub App）。

</Tab>
<Tab value="组织">

<ZoomImage src="/docs-cn/coolify/images/applications/ci-cd/github/setup-app/21.webp" alt="组织的 GitHub Apps 设置" />

1. 打开 GitHub 组织设置。
2. 选择 **Developer settings**（开发者设置）。
3. 选择 **GitHub Apps**。
4. 选择 **New GitHub App**（新建 GitHub App）。

</Tab>
</Tabs>

### 3. 配置 GitHub App

<ZoomImage src="/docs-cn/coolify/images/applications/ci-cd/github/setup-app/22.webp" alt="GitHub App 名称与 Homepage URL 字段" />

1. 输入一个唯一的 **GitHub App name**（GitHub App 名称）。
2. 将 Coolify 公网 URL 填作 **Homepage URL**（主页 URL）。

把 webhook URL 设置为：

```txt
https://coolify.example.com/webhooks/source/github/events
```

把 `https://coolify.example.com` 替换为你 Coolify 实例的公网 URL。

生成一个足够长的随机 **Webhook secret**（webhook 密钥），保存到密码管理器，并启用 **SSL verification**（SSL 校验）。

<ZoomImage src="/docs-cn/coolify/images/applications/ci-cd/github/setup-app/24.webp" alt="手动创建的 GitHub App 的仓库权限" />

在 **Repository permissions**（仓库权限）下授予：

| 权限 | 访问级别 |
| :--- | :--- |
| Contents（内容） | Read-only（只读） |
| Metadata（元数据） | Read-only（只读） |
| Email addresses（邮箱地址） | Read-only（只读） |
| Pull requests（拉取请求） | 仅在需要预览部署时授予读写 |

<ZoomImage src="/docs-cn/coolify/images/applications/ci-cd/github/setup-app/25.webp" alt="GitHub App 的 webhook 事件订阅与安装范围" />

在 **Subscribe to events**（订阅事件）下：

1. 启用 **Push**（推送）。
2. 需要预览部署时启用 **Pull request**（拉取请求）。
3. 除非其他账户也要安装此应用，否则把安装范围限制在当前账户。
4. 选择 **Create GitHub App**（创建 GitHub App）。

### 4. 收集应用凭据

<ZoomImage src="/docs-cn/coolify/images/applications/ci-cd/github/setup-app/26.webp" alt="GitHub App 设置页中的 App ID 与 Client ID" />

复制 **App ID** 与 **Client ID**。

<ZoomImage src="/docs-cn/coolify/images/applications/ci-cd/github/setup-app/27.webp" alt="GitHub 上的 Generate a new client secret 操作" />

选择 **Generate a new client secret**（生成新的客户端密钥），然后复制生成的 **Client Secret**。

<ZoomImage src="/docs-cn/coolify/images/applications/ci-cd/github/setup-app/28.webp" alt="GitHub 上的 Generate a private key 操作" />

在 **Private keys**（私钥）下选择 **Generate a private key**（生成私钥）。GitHub 会下载一个 `.pem` 文件。

请妥善保管 Client Secret、Webhook Secret 与私钥，切勿外泄。

### 5. 安装应用并找到 Installation ID

<ZoomImage src="/docs-cn/coolify/images/applications/ci-cd/github/setup-app/29.webp" alt="GitHub App 设置中的 Install App 导航项" />

打开 **Install App**（安装应用），在目标账户或组织一侧选择 **Install**（安装）。

<ZoomImage src="/docs-cn/coolify/images/applications/ci-cd/github/setup-app/30.webp" alt="安装 GitHub App 时的仓库访问范围选择" />

选择所有仓库或仅选定仓库，然后完成安装。

<ZoomImage src="/docs-cn/coolify/images/applications/ci-cd/github/setup-app/31.webp" alt="已安装 GitHub App 的 Settings 操作" />

打开该安装的设置。

<ZoomImage src="/docs-cn/coolify/images/applications/ci-cd/github/setup-app/32.webp" alt="浏览器 URL 中的 GitHub App Installation ID" />

从 URL 中 `/installations/` 之后的数字部分复制 Installation ID。

### 6. 将私钥与凭据添加到 Coolify

<ZoomImage src="/docs-cn/coolify/images/applications/ci-cd/github/setup-app/33.webp" alt="Coolify 中 Keys and Tokens 下的 Private Keys 页面" />

1. 打开 **Keys & Tokens**（密钥与令牌）> **Private Keys**（私钥）。
2. 选择 **New private key**（新建私钥）> **Add manually**（手动添加）。

<ZoomImage src="/docs-cn/coolify/images/applications/ci-cd/github/setup-app/34.webp" alt="Coolify 中的新建私钥表单" />

3. 为密钥取一个描述性名称。
4. 粘贴 `.pem` 文件的完整内容。
5. 选择 **Continue**（继续）保存私钥。

<ZoomImage src="/docs-cn/coolify/images/applications/ci-cd/github/setup-app/35.webp" alt="Coolify 中的 GitHub App 凭据字段" />

6. 回到 **Sources**（来源），打开该 GitHub App，选择 **General**（常规）。
7. 填入 App ID、Installation ID、Client ID、Client Secret，以及与 GitHub 上配置一致的 Webhook Secret。
8. 选择你刚添加的私钥。
9. 选择 **Save changes**（保存更改）。
10. 选择 **Sync name**（同步名称）。同步成功即说明 Coolify 能以该 GitHub App 的身份通过身份验证。

### 7. 创建并部署应用

<ZoomImage src="/docs-cn/coolify/images/applications/ci-cd/github/setup-app/36.webp" alt="带 New 按钮的 Coolify 项目页面" />

打开项目和环境，然后选择 **+ New**（新建）。

<ZoomImage src="/docs-cn/coolify/images/applications/ci-cd/github/setup-app/37.webp" alt="Private Repository (with GitHub App) 资源类型" />

选择 **Private Repository (with GitHub App)**（私有仓库（通过 GitHub App））。

<ZoomImage src="/docs-cn/coolify/images/applications/ci-cd/github/setup-app/38.webp" alt="GitHub 应用的部署服务器选择" />

选择部署服务器。

<ZoomImage src="/docs-cn/coolify/images/applications/ci-cd/github/setup-app/39.webp" alt="GitHub App 来源选择" />

选择手动创建的 GitHub App。

<ZoomImage src="/docs-cn/coolify/images/applications/ci-cd/github/setup-app/40.webp" alt="该 GitHub App 的仓库选择" />

选择仓库，然后选择 **Load Repository**（加载仓库）。

<ZoomImage src="/docs-cn/coolify/images/applications/ci-cd/github/setup-app/41.webp" alt="应用的分支与构建设置" />

选择分支与构建设置，继续完成应用配置，然后部署。

在 **Deployment Logs**（部署日志）中确认仓库克隆与所选 commit。

</Tab>
</Tabs>

## 更改仓库访问权限

打开 **Sources**（来源），选择该 GitHub App，进入 **General**（常规），再选择 **Repositories**（仓库）。在 GitHub 上调整该安装的仓库访问范围，然后回到 Coolify。

再创建新应用前，先刷新仓库列表。收回某仓库的访问权限后，使用该仓库的应用将无法再次克隆，也无法通过 webhook 部署。
