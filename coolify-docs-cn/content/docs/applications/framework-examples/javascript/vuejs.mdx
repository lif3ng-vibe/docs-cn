# Vue

Vue.js 是一个平易近人、高性能且多用途的 Web 用户界面构建框架。

[示例仓库。](https://github.com/coollabsio/coolify-examples/tree/main/javascript/frameworks/vue)

## 服务器构建（NodeJS|Express）

- 将 **Build strategy**（构建策略）设为 `nixpacks`。
- 将 'Start Command' 设为 `node server.js`。

## 静态构建（SPA）

- 将 **Build strategy**（构建策略）设为 `nixpacks`。
- 在 **Site type**（站点类型）中选择 **Static**（静态）。
- 将 `Output Directory` 设为 `dist`。

## 带路由的静态构建（SPA）

- 将 **Build strategy**（构建策略）设为 `nixpacks`。
- 在 **Site type**（站点类型）中选择 **Static**（静态）。
- 将 `Output Directory` 设为 `dist`。
