# Vite

Vite 是一款构建工具，致力于为现代 Web 项目提供更快、更轻的开发体验。

[示例仓库。](https://github.com/coollabsio/coolify-examples/tree/main/javascript/build-tools/vite)

## 原生 TypeScript 构建（静态）

- 将 **Build strategy**（构建策略）设为 `nixpacks`。
- 在 **Site type**（站点类型）中选择 **Static**（静态）。
- 将 `Publish Directory` 设为 `dist`。


## 原生 JavaScript 构建（静态）

- 将 **Build strategy**（构建策略）设为 `nixpacks`。
- 在 **Site type**（站点类型）中选择 **Static**（静态）。
- 将 `Publish Directory` 设为 `dist`。
