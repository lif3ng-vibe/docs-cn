# 应用

Coolify 把应用作为 Docker 容器部署到已接入的服务器上。可以从 Git 仓库、免 Git 直接填写的 Dockerfile 或现有 Docker 镜像创建 Application。基于 Git 的 Application 还能使用仓库中的 Docker Compose 定义。

如果你刚接触自托管，或正从托管部署平台迁移过来，请从**认识 Application**开始。这一部分会讲清 Coolify 管理哪些基础设施、哪些仍由你负责，以及如何选择部署方式。

<Callout type="info" title="在找一键应用？">

以现成 Coolify 服务模板形式分发的软件，请使用 [Services](/services)。当你掌控源码、Docker 配置或镜像引用时，使用 Applications。

</Callout>

## 从第一个应用开始

如果你之前没部署过应用，请按照[部署你的第一个应用](/deploy-your-first-app)操作。该指南使用 `nginx:alpine`，让你在接入源码之前先验证服务器、Docker、代理和自动生成的域名。

完成首次部署后，根据你想运行的应用选择对应的路径。
