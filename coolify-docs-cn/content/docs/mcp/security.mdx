# MCP 安全

MCP 让 AI 客户端能够访问 Coolify 数据，并在获准的情况下执行生命周期操作。请把令牌当作密码来对待。

## 遵循最小权限原则

| 需求 | 权限 |
| :--- | :--- |
| 查看资源 | `read` |
| 读取受支持的敏感数据或日志摘要 | `read:sensitive` |
| 部署、启动、停止、重启或取消 | `deploy` |
| 更改实例的 MCP 设置 | 启用/禁用 API 需要 `root` 令牌 |

不要把 `root` 令牌用于日常 MCP 访问。

## 团队作用域

一个令牌只属于一个团队。MCP 无法用这个令牌读取其他团队的资源。团队所有者可以在不禁用实例端点的前提下，为自己的团队单独禁用 MCP。

## 保护客户端配置

- 把令牌保存在客户端的机密存储中。
- 不要提交包含令牌的 MCP 配置。
- 不要把令牌粘贴到提示或聊天记录里。
- 限制对运行客户端的那台机器与用户账户的访问。
- 令牌一旦泄露，立即撤销。

MCP 响应绝不会返回环境变量值或文件内容。日志与部署摘要仍可能包含运维数据；脱敏是尽力而为的。
