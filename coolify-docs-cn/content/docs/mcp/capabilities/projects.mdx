# 项目

| 工具 | 用途 |
| :--- | :--- |
| `list_projects` | 列出项目及其 UUID、名称和描述。 |
| `get_project` | 查看某个项目、其环境及资源数量。 |
| `get_environment` | 按名称或 UUID 查找环境，并返回资源摘要。 |
| `list_resources` | 将应用、服务和数据库合并在一个列表中返回。 |
| `search_resources` | 按名称、UUID 或域名模糊搜索项目与资源。 |
| `list_tags` | 列出团队拥有的标签。 |
| `list_resource_tags` | 列出附加在某个应用、数据库或服务上的标签。 |
