# 日志

| 工具 | 权限 | 用途 |
| :--- | :--- | :--- |
| `get_logs` | `read:sensitive` | 获取应用、数据库、服务或服务子资源最近的日志。 |
| `get_deployment` | `read:sensitive` | 通过 `include_log_summary=true` 可选返回条数封顶、尽力脱敏的部署日志摘要。 |

`get_logs` 要求目标容器正在运行且所在服务器可达。它最多返回 500 行日志，并可能在失败时返回结构化的失败原因以及建议接下来调用的工具。

日志脱敏只是尽力而为，并非保证。除非确有必要，请不要把未加过滤的生产日志发给 AI 客户端。
