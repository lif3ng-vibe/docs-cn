# 概览

Coolify MCP 为 API 令牌所关联的团队提供工具、资源与提示词。

## 从这些工具开始

| 工具 | 用途 |
| :--- | :--- |
| `coolify_help` | 按意图查找工具。 |
| `get_infrastructure_overview` | 获取团队资源的数量与健康状态提示。 |
| `search_resources` | 在资源类型未知时，按名称、UUID 或域名查找资源。 |
| `list_unhealthy_resources` | 找出看起来不健康或已宕机的资源。 |

## 能力页面

| 页面 | 内容 |
| :--- | :--- |
| [团队](/mcp/capabilities/teams) | 当前团队与团队成员。 |
| [服务器](/mcp/capabilities/servers) | 服务器、Docker 目标（Destination）、托管域名与服务器资源。 |
| [项目](/mcp/capabilities/projects) | 项目、环境、资源与标签。 |
| [应用](/mcp/capabilities/applications) | 应用与预览部署。 |
| [数据库](/mcp/capabilities/databases) | 独立数据库与备份计划。 |
| [服务](/mcp/capabilities/services) | 服务及其应用或数据库组件。 |
| [部署](/mcp/capabilities/deployments) | 部署历史，以及部署、取消、启动、停止和重启操作。 |
| [日志](/mcp/capabilities/logs) | 容器日志与部署日志摘要。 |
| [环境与存储](/mcp/capabilities/environment-and-storage) | 环境变量名与存储挂载。 |
| [集成](/mcp/capabilities/integrations) | GitHub App、仓库与分支。 |
| [自动化](/mcp/capabilities/automation) | 计划任务、执行记录、健康状态提示与不健康资源。 |
| [提示词与资源](/mcp/capabilities/prompts-and-resources) | 只读 MCP 资源与引导式提示词。 |
| [分页](/mcp/capabilities/pagination) | 分页参数与续读响应。 |

所有列表类工具返回的数据都经过分页。在遍历大量结果之前，请先阅读[分页](/mcp/capabilities/pagination)。
