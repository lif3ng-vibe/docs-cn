# 环境与存储

| 工具 | 权限 | 用途 |
| :--- | :--- | :--- |
| `list_env_keys` | `read` | 列出应用、数据库或服务的环境变量键名。绝不返回变量值。 |
| `list_shared_env_keys` | `read` | 列出项目或环境范围内的共享键名。绝不返回变量值。 |
| `list_storages` | `read` | 列出持久化存储与文件存储挂载。绝不返回文件内容。 |

任务命令正文及受支持的敏感字段需要 `read:sensitive` 权限。这些工具不会返回环境变量的值。
