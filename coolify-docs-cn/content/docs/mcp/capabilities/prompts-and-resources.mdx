# 提示词与资源

## 资源

| 资源 | 用途 |
| :--- | :--- |
| `coolify://overview` | 通过身份验证的团队的基础设施概览。 |
| `coolify://application/{uuid}` | 团队名下某个应用的 JSON 摘要。 |

## 提示词

| 提示词 | 用途 |
| :--- | :--- |
| `troubleshoot_application` | 引导完成应用诊断：先做数据库检查，再按需获取实时日志。 |
| `explain_failed_deploy` | 结合部署详情与可选的日志摘要，解释一次部署失败的原因。 |

提示词不会扩展令牌权限。它们推荐使用的工具仍会强制执行团队范围与令牌能力限制。
