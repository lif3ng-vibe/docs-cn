# 连接其他 MCP 客户端

任何支持远程 Streamable HTTP 服务器的 MCP 客户端都可以连接 Coolify。

## 必需配置

```yaml
server_url: https://app.coolify.io/mcp
transport: streamable-http
authorization: Bearer 67|abcthisisa123dummytoken
```

各客户端的配置格式不尽相同。添加远程服务器、设置 HTTP 请求头时，请遵循你所用的客户端自己的文档。

## 验证连接

调用 `get_current_team` 或 `get_infrastructure_overview`。如果客户端无法连接，请查阅[疑难排查](/mcp/troubleshooting)。
