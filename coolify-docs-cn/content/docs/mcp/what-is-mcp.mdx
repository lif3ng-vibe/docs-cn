# 什么是 MCP？

Coolify 的 Model Context Protocol（MCP）服务器让兼容的 AI 客户端能够通过一条标准 HTTP 连接，检查并操作 Coolify 团队中的资源。

MCP 为 AI 客户端提供对 Coolify 数据的结构化访问。客户端可以询问基础设施状况、查找资源、检查部署、读取受支持的日志，并执行其 API 令牌所允许的生命周期操作。

## MCP 提供什么

| 能力 | 用途 |
| :--- | :--- |
| 工具（Tools） | 让 AI 客户端调用 Coolify 操作，例如列出应用或启动资源。 |
| 资源（Resources） | 提供可寻址的只读数据，例如基础设施概览或应用摘要。 |
| 提示（Prompts） | 为排查应用问题、解释部署失败等任务提供引导式工作流。 |
| Streamable HTTP | 让 MCP 客户端经由 `/mcp` 连接 Coolify，无需本地 MCP 进程。 |

## MCP 不做什么

MCP 不会绕过 Coolify 的身份验证、团队作用域、API 访问、令牌权限或敏感值脱敏。每个请求都使用 API 令牌，每个资源都属于该令牌绑定的团队。
