你已经决定使用 Coolify 了，好选择！

接下来你可能在纠结：是选 **Coolify Cloud**，还是自己动手**自托管**。下面我们就把两种方式拆开讲清楚，帮你挑出最适合的那一个。

## Coolify Cloud

Coolify Cloud 是最省心的起步方式。它是一项付费服务（每月仅需 **5 美元**起），你自带服务器，把它们接入一个由我们团队全权托管的 Coolify 实例。


<Callout type="warn" title="注意">

**我们会替你托管并更新 Coolify 实例，你无需在自己的服务器上为 Coolify 划拨任何资源，但你的服务器本身以及服务器上运行的其他服务，仍由你全权负责**

</Callout>


## Coolify 自托管

如果你更喜欢亲自动手，自托管 Coolify 也许正合你意。

它完全免费（当然，服务器费用除外），而且一切尽在你掌控。

你要在自己的服务器上安装 Coolify、保持更新，并自行管理所有相关服务。

## 两者如何对比？

_下表的所有功能只针对 Coolify 实例本身，不涉及你的整台服务器或其他服务。_

| 功能                 | Coolify Cloud                                                       | 自托管 Coolify                                       |
| ----------------------- | ------------------------------------------------------------------- | --------------------------------------------------------- |
| **维护**         | 我们替你托管并更新 Coolify 实例   | 实例能否平稳运行由你把关 |
| **支持**             | 来自 Coolify 专家与核心团队的帮助                         | 在 Discord 上与社区交流                        |
| **邮件通知** | 预先配置好，开箱即用且免费                            | 需要自行设置                       |
| **备份**             | Coolify 实例的自动备份由我们处理               | 为 Coolify 实例自建备份体系    |
| **高可用**   | 我们为 Coolify 实例提供可靠的在线率保障 | 取决于你自己的搭建方式                          |
| **稳定性**           | 更新上线前经过我们的充分测试                  | 升级前由你自己先行验证                     |
| **费用**                | **每月 5 美元**起                                              | 永久免费（只需支付服务器费用）                   |

顺便说一句，我们不搞"**功能锁定**"那一套。无论你选 Coolify Cloud 还是自托管，拿到的都是同样的完整功能。

无论走哪条路，我们都要让你体验到完整的 Coolify。

## 哪一种更适合你？

如果你想要快速、省事的搭建，也不介意为了便利支付一点费用，那 **Coolify Cloud** 正合适。

但如果你享受动手折腾、想把每一分钱都省下来、并喜欢一切尽在掌控的感觉，那**自托管**就是不二之选。

如果还是拿不定主意，就来我们的 [Discord 社区](https://coolify.io/discord)提问吧！我们会帮你一起判断哪种方案最符合你的需求。
