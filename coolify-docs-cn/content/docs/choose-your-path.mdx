# 选择你的路径

Coolify 有两种使用方式：自托管（Self-hosted），即自己运行并维护 Coolify 实例；或者使用 Coolify Cloud，由 Coolify 团队代为运行和维护 Coolify 实例。

<CoolCallout icon={ArrowsRight} title="简要版">

自托管和 Cloud 提供完全相同的 Coolify 功能。区别只在于由谁来运营 Coolify 实例：你自己管理，或者交给 Coolify 管理。

</CoolCallout>

| 对比维度 | 自托管 | Coolify Cloud |
| :--- | :--- | :--- |
| Coolify 实例 | 由你负责安装、更新、备份、监控和恢复 Coolify 实例。 | Coolify 团队负责运行、更新、备份、监控和恢复 Coolify 实例。 |
| 你的服务器 | 服务器由你提供，操作系统的安全、SSH 访问、防火墙和网络也由你保障。 | 服务器同样由你提供，操作系统的安全、SSH 访问、防火墙和网络同样由你保障。 |
| 你的工作负载 | 应用、数据库、卷（volume）、机密（Secret）和运行时安全仍由你负责。 | 应用、数据库、卷、机密和运行时安全仍由你负责。 |
| Coolify 更新 | 由你决定何时更新 Coolify，以及如何安排维护窗口。 | Coolify 团队为你应用控制平面更新。 |
| 成本模式 | 无 Coolify 许可费。你只需为自己的基础设施和运维时间买单。 | Coolify 实例属于付费托管服务。你自己的服务器费用仍需自理。 |
| 功能集 | 包含全部 Coolify 功能。 | 与自托管完全一致，没有 Cloud 独占功能的付费墙。 |

<CoolCallout icon={Checklist2} title="为什么这个选择很重要">

两条路带给你的核心产品体验完全相同，差别在于由谁来运营和维护 Coolify 实例。

Coolify Cloud 的托管实例按月订阅收费，而自托管让你自己运行实例，无需支付持续的平台费用。

</CoolCallout>

<CoolCallout icon={Warning22} title="仍然拿不定主意？" type="warn">

**如果你有信心运维控制平面，就从自托管开始。**

自托管从第一天起就给你最清晰的所有权模型。当你希望 Coolify 团队替你处理实例维护时，再选 Cloud。

</CoolCallout>
