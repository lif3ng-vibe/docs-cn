# Imgcompress

<ZoomImage src="/docs-cn/coolify/images/services/imgcompress-logo.webp" alt="Imgcompress logo" height="1" />


## Imgcompress 是什么？

Imgcompress 是一个自托管图片处理工具箱，在同一个 Web 界面里完成压缩、格式转换和 AI 背景移除。它支持 **70 多种输入格式**（包括 PSD、HEIC 和 RAW），可以输出常见格式或生成 PDF，全程不会把文件发送到外部服务。

<ZoomImage src="/docs-cn/coolify/images/services/imgcompress-ui.webp" alt="Imgcompress Web 界面" />

核心能力：

- **格式转换**：PSD、HEIC、RAW 等 70 多种格式一站式互转
- **图片压缩**：在不损失画质的前提下缩小照片和截图的体积
- **PDF 导出**：直接在浏览器里把图片转成 PDF
- **AI 抠图**：在本地移除背景，文件隐私有保障
