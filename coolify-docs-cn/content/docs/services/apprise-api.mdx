# Apprise API 是什么？

[Apprise-api](https://github.com/caronc/apprise-api) 通过一套友好的 API，让你能在自己的网络中调用 [Apprise](https://github.com/caronc/apprise) 的能力。

- 可向 100 多种服务发送通知。
- 极其轻量的 Apprise 网关。
- 随时可用的生产级微服务。
- 提供简洁的网页，用于验证和测试你的配置。

Apprise API 的设计目标是轻松融入各种寻求简单通知方案的现有（及全新）生态系统。
