## EMQX Enterprise 是什么？

EMQX Enterprise 是一款可扩展的分布式 MQTT 消息代理（broker），面向物联网（IoT）、工业物联网（IIoT）、车联网以及 AI 代理通信等场景。它可在大规模场景下提供实时发布/订阅消息能力，支持每个集群数百万并发连接、亚毫秒级消息分发、支持回放的持久化消息队列，并原生集成各类数据库、数据仓库与云服务，例如 Snowflake、Google BigQuery、Amazon Redshift 和 Amazon S3 Tables。

从 5.9 版本开始，EMQX 将原先的开源版与企业版统一为商业源代码许可证（Business Source License，BSL）1.1 下的单一平台。所有高级功能——包括多租户、细粒度安全（SSO、RBAC、审计日志）、跨地域复制、会话持久化、文件传输、消息编解码与校验，以及 40 多项原生数据集成——现已汇聚于同一产品。根据 BSL 附加使用授权（Additional Use Grant），EMQX 在非生产环境、测试以及单节点生产部署中仍然免费；更大规模的生产集群则需要付费许可证和商业支持；教育机构与非营利组织可申请免费的许可证密钥。
