<ZoomImage src="/docs-cn/coolify/images/services/miniflux.svg" alt="Miniflux 仪表盘" />

## Miniflux 是什么？

Miniflux 是一款极简且理念鲜明的订阅源阅读器，专注于简洁与性能。它支持 RSS、Atom 和 JSON 订阅源，提供全文搜索、键盘快捷键、移动端自适应设计以及稍后读服务集成等功能。Miniflux 追求快速、轻量、无干扰，非常适合想要清爽 RSS 阅读体验的用户。
