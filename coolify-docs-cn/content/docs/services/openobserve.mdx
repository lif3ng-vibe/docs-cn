# OpenObserve

<ZoomImage src="/docs-cn/coolify/images/services/openobserve-logo.svg" alt="OpenObserve 标志" />

## OpenObserve 是什么？

OpenObserve 是一个开源的可观测性平台，覆盖日志、指标、链路追踪、真实用户监控与会话回放。

## Coolify 部署

该 Coolify 模板以单节点模式在 `5080` 端口运行 OpenObserve。数据存储在 `openobserve-data` 卷的 `/data` 目录下，这种部署模式无需外部数据库。

## 默认凭据

默认的 root 邮箱为 `root@example.com`。如需使用其他地址，请在首次部署前修改 `ZO_ROOT_USER_EMAIL`。

root 密码由 Coolify 生成为 `SERVICE_PASSWORD_OPENOBSERVE`。其生成的值可在服务的环境变量中查看。
