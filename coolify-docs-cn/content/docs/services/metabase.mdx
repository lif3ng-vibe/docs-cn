## Metabase 是什么？

Metabase 是一种简单易用的开源方式，让公司里的每个人都能提问并从数据中获得洞见。

## 功能特性

- [五分钟完成设置](https://www.metabase.com/docs/latest/setting-up-metabase.html)（我们没开玩笑）。
- 让团队里任何人在不懂 SQL 的情况下也能[提出问题](https://www.metabase.com/docs/latest/users-guide/04-asking-questions.html)。
- 使用 [SQL 编辑器](https://www.metabase.com/docs/latest/questions/native-editor/writing-sql)执行更复杂的查询。
- 构建美观、可交互的[仪表盘](https://www.metabase.com/docs/latest/users-guide/07-dashboards.html)，支持筛选器、自动刷新、全屏模式和自定义点击行为。
- 创建[模型](https://www.metabase.com/learn/getting-started/models)，对原始表进行清理、标注或组合。
- 定义统一的[分段与指标](https://www.metabase.com/docs/latest/administration-guide/07-segments-and-metrics.html)，供团队使用。
- 通过[仪表盘订阅](https://www.metabase.com/docs/latest/users-guide/dashboard-subscriptions)，定时把数据发送到 Slack 或邮箱。
- 设置[警报](https://www.metabase.com/docs/latest/users-guide/15-alerts.html)，当数据发生变化时由 Metabase 通知你。
- 在你的应用中[嵌入图表和仪表盘](https://www.metabase.com/docs/latest/administration-guide/13-embedding.html)，甚至可以嵌入[整个 Metabase](https://www.metabase.com/docs/latest/enterprise-guide/full-app-embedding.html)。
