<ZoomImage src="/docs-cn/coolify/images/services/trailbase-logo.svg" alt="TrailBase logo" />

## TrailBase 是什么？

TrailBase 是一个开放、极速的单可执行文件 Firebase 替代品，基于 Rust、SQLite 与 Wasmtime 构建，提供类型安全的 REST 与实时 API，内置 WebAssembly 运行时、SSR、身份验证和管理界面。

化繁为简，减少活动部件：易于自托管的单一可执行文件，让你专注于移动端、Web 或桌面应用本身。亚毫秒级延迟让专用缓存不再必要，也告别过期或不一致的数据。
