## NextCloud 是什么？

NextCloud 是一个开源生产力平台，可作为 Google Drive 和 Dropbox 等流行云存储服务的安全私密替代方案。它可以让你在多台设备间存储、同步和共享文件、照片与视频，并提供文件版本管理、密码保护共享和协作工具等功能。

## 部署变体

在 Coolify 中，Nextcloud 提供四种部署配置：

### Nextcloud（默认）
- **数据库：**SQLite（内嵌）
- **适用场景：**简单部署、测试或个人文件存储
- **组件：**单个 Nextcloud 容器，内置 SQLite 数据库

### 使用 PostgreSQL 的 Nextcloud
- **数据库：**PostgreSQL
- **适用场景：**对性能和可扩展性要求更高的生产部署
- **组件：**
  - Nextcloud 容器
  - PostgreSQL 容器
  - 自动完成数据库配置与健康检查

### 使用 MySQL 的 Nextcloud
- **数据库：**MySQL
- **适用场景：**偏好使用 MySQL 的生产部署
- **组件：**
  - Nextcloud 容器
  - MySQL 容器
  - 自动完成数据库配置与健康检查

### 使用 MariaDB 的 Nextcloud
- **数据库：**MariaDB
- **适用场景：**偏好使用 MariaDB 的生产部署（推荐大多数用户使用）
- **组件：**
  - Nextcloud 容器
  - MariaDB 容器
  - 自动完成数据库配置与健康检查
