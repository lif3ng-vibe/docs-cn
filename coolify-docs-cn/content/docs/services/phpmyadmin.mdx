<Callout type="error" title="服务暂时停用">

由于 PHP 安全漏洞 **CVE-2026-109618** 和 **CVE-2026-109619**，该服务的一键模板已在 Coolify 中暂时停用。在修复后的容器镜像完成验证之前，无法从服务目录部署该服务。

关于既有部署的处理建议，请参阅 [PHP 安全公告](/knowledge-base/php-security-advisory-2026)；模板停用的详情与后续进展请查看[模板停用 PR](https://github.com/coollabsio/coolify/pull/12268)。

</Callout>
