## MinIO 是什么？

MinIO 是一个高性能的分布式对象存储系统，兼容 Amazon S3 API。它采用软件定义架构，可运行在符合行业标准的硬件上，并依据 AGPL v3.0 许可证 100% 开源。MinIO 提供高性能、Kubernetes 原生的对象存储，专为大规模 AI/ML、数据湖和数据库工作负载而设计。

## 常见问题

### 登录凭据无效

你需要让 MinIO 运行在 `https`（非自签名证书）上，以避免此问题。MinIO 不支持基于 http 的身份验证。
