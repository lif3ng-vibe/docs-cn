## Palworld 是什么？

Palworld 是一款多人的开放世界生存建造游戏，在广阔的世界中，你可以结识并收集被称为"帕鲁（Pals）"的神秘生物。该服务让你可以为自己和朋友们搭建一台 Palworld 专用服务器。

## 功能特性

- 专用服务器托管
- 多人游戏支持
- 世界持久化
- 自定义服务器配置
- 存档管理
