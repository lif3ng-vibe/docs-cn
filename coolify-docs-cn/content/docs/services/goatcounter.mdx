# GoatCounter 是什么？

GoatCounter 是一个开源的网站分析平台，致力于提供简单易用、富有意义且尊重隐私的网站分析。

- 注重隐私：不使用唯一标识符跟踪用户，也无需 GDPR 声明；可细粒度控制收集哪些数据。

- 轻量快速：只会给你的站点增加约 3.5K 的额外数据。还提供无需 JavaScript 的「跟踪像素」方案，也可以从应用的中间件中调用，或从日志文件导入。

- 使用不可识别身份的哈希来识别独立访问，完全不需要 Cookie。

- 保留有用的统计信息，例如浏览器信息、地区和屏幕尺寸，并支持跟踪来源站点与推广活动。

- 简单易用：如果你曾被 Google Analytics 和 Matomo 那些用不上的繁杂选项与灵活性搞得一头雾水，GoatCounter 会让你耳目一新。

- 无障碍访问是高优先级特性，界面对屏幕阅读器等辅助技术有良好支持。
