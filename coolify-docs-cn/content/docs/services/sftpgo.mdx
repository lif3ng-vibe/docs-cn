# SFTPGo

<ZoomImage src="/docs-cn/coolify/images/services/sftpgo-logo.png" alt="SFTPGo logo" />

## SFTPGo 是什么？

SFTPGo 是一套事件驱动的文件传输解决方案，支持多种协议（SFTP、SCP、FTP/S、WebDAV、HTTP/S）和多种存储后端。

借助 SFTPGo，你可以利用本地与云端存储后端，用早已熟悉的工具和流程，在内部或与商业伙伴之间交换和存储文件。

WebAdmin UI 让你可以轻松创建并管理用户、文件夹、分组及其他资源。
