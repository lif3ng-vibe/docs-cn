# Garage

<ZoomImage src="/docs-cn/coolify/images/services/garage-logo.svg" alt="Garage 标志" />

## Garage 是什么？

Garage 是一个实现了 Amazon S3 对象存储协议的轻量级跨地域分布式数据存储。它让应用能够在冗余的多节点环境中存储图片、视频、文档等大型 blob 对象。S3 协议非常灵活，甚至可以用来发布静态网站。
