## Once Campfire 是什么？

Once Campfire 是一个基于 Web 的聊天应用，支持你所期待的大多数功能，包括：

- 多个房间，支持访问控制
- 私信
- 文件附件及预览
- 搜索
- 通知（通过 Web Push）
- @提及
- API，支持机器人集成

## 配置

Once Campfire 几乎无需配置即可上手：

### 必需的环境变量

- **SECRET_KEY_BASE** - 用于加密的安全随机密钥（由 Coolify 自动生成）

### 可选的环境变量

- **VAPID_PUBLIC_KEY** - 用于 Web Push 通知
- **VAPID_PRIVATE_KEY** - 用于 Web Push 通知
- **DISABLE_SSL** - 设为 `true` 可禁用 SSL（默认：`true`）
- **SSL_DOMAIN** - 用于 SSL 配置的域名
- **SKIP_TELEMETRY** - 设为 `true` 可禁用遥测（默认：`true`）
- **SENTRY_DSN** - 用于错误上报
