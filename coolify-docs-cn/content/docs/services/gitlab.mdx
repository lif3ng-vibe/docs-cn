## GitLab 是什么？

GitLab 是一款基于 Web 的 DevOps 生命周期工具，充当 Git 仓库管理器，提供 Wiki、Issue 跟踪和 CI/CD 流水线等功能，基于 Ruby on Rails 框架构建。
