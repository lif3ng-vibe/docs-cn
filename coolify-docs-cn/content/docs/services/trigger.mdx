## Trigger 是什么？

Trigger 是一个面向 TypeScript 的开源后台任务（Background Jobs）框架。

## 部署变体

Trigger.dev 在 Coolify 中提供两种部署配置：

### Trigger.dev（默认）
- **数据库：** 内置 PostgreSQL
- **适用场景：** 使用托管数据库的标准部署
- **组件：**
  - Trigger.dev 容器
  - 内置 PostgreSQL 容器
  - 自动完成数据库配置与健康检查

### Trigger.dev（外接数据库）
- **数据库：** 外部（由用户提供）
- **适用场景：** 已有数据库基础设施或需要自定义数据库配置的高级部署
- **组件：**
  - Trigger.dev 容器
  - 需要 `DATABASE_URL` 环境变量指向你的外部数据库
