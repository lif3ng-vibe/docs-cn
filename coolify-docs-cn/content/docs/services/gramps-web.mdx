# Gramps Web

<ZoomImage src="/docs-cn/coolify/images/services/grampsweb-logo.svg" alt="Gramps Web logo" />

## Gramps Web 是什么？

一款免费开源的家谱系统，让你与家人协作构建家族树。它既可以独立使用，也可以作为 Gramps Desktop 的搭档，数据与隐私完全由自己掌控，这也是它的首要设计原则。
