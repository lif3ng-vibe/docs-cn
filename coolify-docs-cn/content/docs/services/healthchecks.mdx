# Healthchecks

<ZoomImage src="/docs-cn/coolify/images/services/healthchecks.webp" alt="Healthchecks logo" />

## Healthchecks 是什么？

Healthchecks 通过等待 HTTP 请求或电子邮件消息来监控 cron 任务和计划任务。当预期的 ping 没有按时到达时，它会发出告警。

## 创建第一个账户

部署完成后，你可以通过邮件发送的魔法链接创建账户，也可以在应用容器中运行 Healthchecks 的 `manage.py` 命令来创建超级用户。魔法链接认证需要先配置好可用的电子邮件设置。

支持的账户创建命令和邮件设置请阅读 [Healthchecks Docker 文档](https://healthchecks.io/docs/self_hosted_docker/)。
