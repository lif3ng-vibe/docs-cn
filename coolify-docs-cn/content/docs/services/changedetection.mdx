## Change Detection 是什么?

监测网站内容变化并执行有意义的后续动作——通过 Discord、电子邮件、Slack、Telegram、API 调用等众多渠道触发通知。

主动掌控你的数据生活。

## 使用场景示例

- 商品或服务的价格发生变动
- _缺货通知_与_补货通知_
- 监测并跟踪 PDF 文件的变化,第一时间知道 PDF 内容有改动
- 政府部门发布更新(变动往往只出现在其官网上)
- 不在邮件列表里也能收到新软件发布与安全公告
- 有变动的节庆活动
- Discogs 补货提醒与监控
- 房产挂牌信息变化
- 抢先知道你钟意的威士忌打折,或其他特惠活动上线
- 政府网站上与疫情相关的新闻
- 大学/机构官网发布的新闻
- 检测并监控 JSON API 响应的变化
- JSON API 监控与告警
- 法律文书及其他文档的变动
- 当网站出现指定文字时,通过通知触发 API 调用
- 借助 JSON 过滤器与 JSON 通知把多个 API 串起来
- 基于网页内容的变化生成 RSS 订阅源
- 监控 HTML 源码的异常变动,强化你的 PCI 合规
- 有一批非常敏感、必须盯紧的 URL,但又_不_想用付费方案(记住,_免费_模式下你自己就是产品)
- 当特定关键词出现在 Twitter 搜索结果时收到通知
- 主动求职:公司在招聘页面更新时收到通知,或按关键词搜索求职网站
- Bamboo HR 及其他招聘平台有新职位开放时收到提醒
- 网站篡改监控
- 宝可梦卡牌补货追踪 / Pokémon TCG 追踪
- RegTech——领先一步应对监管变化,保障合规

## 核心特性

- 丰富的触发过滤器,如 "Trigger on text"、"Remove text by selector"、"Ignore text"、"Extract text",还支持正则表达式!
- 使用 xPath(1.0) 与 CSS 选择器定位元素,用 JSONPath 或 jq 轻松监控复杂 JSON
- 可在无 JS 的快速抓取器与基于 Chrome JS 的抓取器之间切换
- 跟踪 PDF 文件的变化(监控 PDF 文本变动,也可监控 PDF 文件大小与校验和)
- 轻松设定每个站点的检查频率
- 提取文本前先执行 JS(适合模拟登录,界面里有示例!)
- 可覆盖请求头,可指定 `POST`、`GET` 等请求方法
- 借助 "Visual Selector" 可视化选择器精确定位元素
- 每个 watch 任务可单独配置[代理](https://github.com/dgtlmoon/changedetection.io/wiki/Proxy-configuration?utm_source=coolify.io)
- 检测到网页变化时,随通知一并发送截图
