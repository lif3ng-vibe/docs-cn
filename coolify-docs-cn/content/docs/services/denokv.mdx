## Deno KV 是什么

Deno KV 是一款自托管、JavaScript 优先的键值数据库,直接内置于 Deno 运行时。它由 FoundationDB 与 SQLite 驱动,提供稳健、高性能的数据存储方案,专为现代边缘计算与无服务器应用设计。

核心特性:

- **ACID 事务**:完整支持 ACID 事务,保证数据一致性,杜绝部分写入与数据损坏
- **基于 FoundationDB 构建**:企业级后端,每秒可处理数百万次操作
- **实时 Watch API**:实时监控数据库变化,轻松构建响应式应用、通知与实时更新
- **零配置**:开箱即用于 Deno 运行时,无需复杂设置
- **JavaScript 原生**:直接存储任意 JavaScript 值,无需手动序列化
- **层级化键名**:用结构化、类 REST 的键模式组织数据,建模直观
- **多档一致性级别**:按应用需求在性能与一致性之间取得平衡
- **自托管且开源**:MIT 许可证,基础设施完全由你掌控
