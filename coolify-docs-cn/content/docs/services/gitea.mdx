## Gitea 是什么？

Git with a cup of tea！一套轻松省心、开箱即用的自托管一体化软件开发服务，涵盖 Git 托管、代码评审、团队协作、软件包仓库和 CI/CD。

## 部署变体

- **Gitea：**使用内置的 SQLite 数据库。
- **Gitea with PostgreSQL：**附带一个 PostgreSQL 数据库。
- **Gitea with MySQL：**附带一个 MySQL 数据库。
- **Gitea with MariaDB：**附带一个 MariaDB 数据库。
- **Gitea Runner：**面向现有 Gitea 实例的独立 Actions 运行器。
