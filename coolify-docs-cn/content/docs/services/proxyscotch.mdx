# Proxyscotch

<ZoomImage src="/docs-cn/coolify/images/services/proxyscotch.png" alt="Proxyscotch (hoppscotch) 标志" />

## Proxyscotch 是什么

Hoppscotch 出品的小巧开源 CORS 代理。
> 与 Hoppscotch 搭配使用效果最佳，也可以独立使用。


## 设置说明
> 只有在为自托管的 Hoppscotch 实例配置 Proxyscotch 时才需要这一步。

如果你为代理服务器启用了安全保护（***推荐且默认开启***），就需要为 Hoppscotch 实例设置一些环境变量。

##### Proxyscotch 实例设置完成后：

- 找到 Coolify 为你生成的令牌。
- 在 Coolify 中 Hoppscotch 实例的设置里，进入 **Environment Variables**（环境变量）
- 新增一个名为 `VITE_PROXYSCOTCH_ACCESS_TOKEN` 的变量，将其值设置为刚才找到的令牌。
- 重启 Hoppscotch 实例。

- 重启完成后，打开 Web UI 并进入 **设置 > 拦截器（Interceptors）**。- 然后向下滚动到 **Proxy**（代理）
- 将代理 URL 设置为你的 Proxyscotch 实例的 URL
> 你可能需要先通过仪表盘中的开关启用代理，然后才能修改 URL。

现在，Hoppscotch 应该已经配置好并与你自己的 CORS 代理正常协作了！
