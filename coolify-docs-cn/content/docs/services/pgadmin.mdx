<ZoomImage src="/docs-cn/coolify/images/services/pgadmin-logo.svg" />

## pgAdmin 是什么？

pgAdmin 是一款基于 Web 的数据库管理工具，可通过友好易用的界面管理 PostgreSQL 数据库。它为数据库管理、查询开发和数据可视化提供了一整套完善的功能，是 PostgreSQL 最流行、功能最丰富的开源管理与开发平台。
