# Minecraft 是什么？

Minecraft 是由 Mojang Studios 开发的沙盒视频游戏，由 Markus "Notch" Persson 用 Java 编程语言创造。

这是一款既支持单人游玩、也支持多人联机的游戏，玩家可以在程序化生成的世界中探索、建造和挖掘。
