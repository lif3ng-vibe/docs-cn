# Databasus

<ZoomImage src="/docs-cn/coolify/images/services/databasus-logo.svg" alt="Databasus 徽标" />

## Databasus 是什么?

Databasus 是一款免费开源的自托管数据库备份工具,支持 PostgreSQL、MySQL、MongoDB 等数据库。可将备份存放到不同存储(S3、Google Drive、FTP 等),并通过 Slack、Discord、Telegram 等渠道接收进度通知。前身名为 Postgresus。
