## Mage AI 是什么？

Mage AI（Mage OSS）是一个自托管的开发环境，旨在帮助团队有把握地构建生产级数据管道。

无论是自动化 ETL 任务、设计数据流，还是编排数据转换，它都能胜任——一切都在由模块化代码驱动的快速笔记本式界面中完成。

## 默认凭据

全新部署后，你可以使用以下信息登录：

```
USERNAME: admin@admin.com
PASSWORD: admin
```

## 旧款 CPU 的问题

Mage AI 依赖现代 CPU 特性。在较老的设备上，你可能会看到如下错误：

```
The following required CPU features were not detected:
  sse4.2, popcnt, avx, avx2, fma, bmi1, bmi2, lzcnt, pclmulqdq
```

更多细节请参阅[这个 issue](https://github.com/pola-rs/polars/issues/15404)。
