# Cloudflare DDNS

<ZoomImage src="/docs-cn/coolify/images/services/cloudflare-ddns.svg" alt="Cloudflare DDNS 徽标" />

## Cloudflare DDNS 是什么?

Cloudflare DDNS 会检测服务器公网 IPv4 或 IPv6 地址的变化,并通过 Cloudflare API 更新选定的 DNS 记录。
