## Formbricks 是什么？

Formbricks 提供一个免费开源的问卷调查平台。通过精美的应用内、网站、链接和电子邮件问卷，在用户旅程的每个触点收集反馈。你可以在 Formbricks 之上进行二次开发，也可以直接使用其内置的数据分析能力。
