# Bluesky PDS

<ZoomImage src="/docs-cn/coolify/images/services/bluesky-logo.svg" alt="Bluesky 标志" />

## Bluesky PDS 是什么？

Bluesky PDS（Personal Data Server，个人数据服务器）是一台自托管数据服务器，将你的数据存储在 AT Protocol 网络中。它让你在继续参与 AT Protocol 网络的同时，掌控自己的社交媒体数据与身份。PDS 以去中心化的方式处理用户账户、帖子、关注者以及其他社交数据。

## 为尚未配置域名的情况设置 HTTPS 域名

Pdsadmin 要求你的 Bluesky PDS 启用 HTTPS。请确保已在 Coolify UI 中设置了带 HTTPS 的域名，并检查环境变量与之保持一致。

## 在你的 PDS 中创建账户

要创建账户并开始使用你的 PDS，可以在 Coolify UI 的 Terminal 标签页中使用以下 pdsadmin 命令：

```bash
pdsadmin create-invite-code
```

或者

```bash
pdsadmin account create <email> <handle>
```

要查看 pdsadmin 的其他可用命令，直接运行 `pdsadmin` 即可。

## 配置邮件

邮件功能对 Bluesky PDS 很重要，确认邮箱等操作都离不开它！

你需要在 Coolify UI 中编辑两个环境变量。前往 Environment Variables 标签页，找到 `PDS_EMAIL_FROM_ADDRESS`，这里要填的内容基本一目了然：发送邮件时使用的邮箱地址，例如 `user@domain.com`。

另一个环境变量是 `PDS_EMAIL_SMTP_URL`，它就没那么直观了，填写方法如下：

这个变量有多种填法，这里举几个例子：

`smtps://user%40example.com:password@mail.example.com:465`（启用 SSL 的 SMTP）

`smtp://user%40example.com:password@mail.example.com:587`（不启用 SSL 的 SMTP）

`smtps://resend:<your Resend api key>@smtp.resend.com:465`（Resend）

为了让邮件配置正常工作，你可能需要对用户名和密码进行 URL 编码。

大功告成，你的 PDS 已可投入使用，用起来和其他 PDS 没有任何区别！
