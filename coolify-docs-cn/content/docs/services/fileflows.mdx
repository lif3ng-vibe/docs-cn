## FileFlows 是什么？

还在为手动管理文件而烦恼吗？来试试 FileFlows——自动化文件处理的终极方案！

FileFlows 让你通过自定义流程监控和处理任何类型的文件。视频、音频、图片、压缩包、漫画、电子书——应有尽有！

## 安装

1. 在 Coolify 中创建该服务。
2. 如果你的设备支持，可以在 compose 文件中取消注释以下段落来启用硬件转码：

```yaml
#devices:
# - "/dev/dri:/dev/dri"
```
