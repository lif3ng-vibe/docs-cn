## Mautic 是什么？

Mautic 是全球最大的开源营销自动化项目，已被全球超过 200,000 个组织采用。它提供了一个注重隐私、完全可定制的营销自动化平台，让你对自己的数据和营销基础设施拥有完全的控制权。

主要功能包括：

- **多渠道营销**：在一个平台上管理邮件营销活动、短信、Web 通知和社交媒体
- **活动构建器**：通过直观的拖放界面创建复杂的自动化工作流
- **潜在客户管理**：跟踪联系人、为线索评分，并根据行为和属性细分受众
- **自托管且注重隐私**：完全的数据主权，内置符合 GDPR 及其他法规的合规功能
- **无限制且可定制**：用户、联系人或营销活动数量均不受限制，还可通过插件扩展功能
- **CRM 集成**：原生集成 HubSpot、Salesforce、Zoho CRM、Microsoft Dynamics 等
- **API 驱动**：提供全面的 REST API，支持自动化与自定义集成
