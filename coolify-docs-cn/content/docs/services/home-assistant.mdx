# Home Assistant

<ZoomImage src="/docs-cn/coolify/images/services/homeassistant-logo.svg" alt="Home Assistant logo" />

## Home Assistant 是什么？

Home Assistant 是一个专注本地控制与隐私的开源家庭自动化平台。它把灯具、传感器、摄像头、媒体播放器等设备连接在一起——让你自动化日常例程、搭建仪表盘，并从一个地方控制所有设备。

## 功能特性

- **1000+ 集成**：支持数千种智能家居设备与服务
- **本地控制**：完全在你的环境中私密运行，不依赖云服务
- **强大的自动化**：用 YAML 配置或可视化界面创建复杂例程
- **多平台访问**：移动应用、Web 仪表盘、语音控制和远程访问
- **隐私优先**：数据留在你自己的服务器上，无跟踪、无遥测
- **可扩展**：附加组件、自定义集成，以及活跃的社区支持
