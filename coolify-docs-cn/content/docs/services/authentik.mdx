## authentik 是什么？

Authentik 是一个强调灵活性与多样性的开源身份提供方（Identity Provider），可以无缝集成到现有环境中，为其支持新协议。

如果你想在应用中实现注册、找回等同类功能，Authentik 也是绝佳选择，帮你省去自行处理的麻烦。
