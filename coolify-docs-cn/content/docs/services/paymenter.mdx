## Paymenter 是什么？

Paymenter 是一个专为主机托管公司打造的开源计费平台。它简化了托管服务的管理工作，为服务商和客户双方都带来顺畅的体验。Paymenter 基于现代 Web 技术构建，能够为你的托管业务提供灵活而稳健的解决方案。

## 如何在 Coolify 中配置 Paymenter

1. 使用 **Paymenter** 服务创建一个新资源。
2. 启动该资源。
3. 通过终端设置正确的应用 URL：

选择 Paymenter 容器并运行以下命令：

```bash
php artisan app:init
```

4. 创建第一个管理员用户：
   ```bash
   php artisan app:user:create
   ```
