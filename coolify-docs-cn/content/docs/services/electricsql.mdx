# ElectricSQL

<ZoomImage src="/docs-cn/coolify/images/services/electricsql.svg" alt="/ dashboard" />

## ElectricSQL 是什么？

ElectricSQL 让开发者无需更改技术栈，就能构建快速、现代的协作型应用。

## 部署注意事项

创建 PostgreSQL 数据库时，务必启用逻辑复制：在 PostgreSQL 配置中加入 `wal_level = logical` 即可实现。

## 环境变量

- SERVICE_URL_ELECTRIC_3000：暴露 electricsql 的 3000 端口，你的客户端将连接到这里
- DATABASE_URL：PostgreSQL 数据库的 URL（需已启用逻辑复制）
- ELECTRIC_SECRET：electricsql 用于验证请求的密钥（更多信息见[这里](https://electric-sql.com/docs/guides/security#api-token)）
- ELECTRIC_STORAGE_DIR：electric 需要存储一些数据和缓存等内容，这些内容会放在这里
- ELECTRIC_USAGE_REPORTING：用于配置是否向 [https://electric-sql.com](https://electric-sql.com) 回传匿名使用数据
