## LibreChat 是什么？

LibreChat 是一款可自托管、功能强大且注重隐私的多模型 AI 聊天界面，支持 OpenAI GPT、Anthropic Claude、Azure OpenAI 等众多模型。它提供统一界面来对接各类 AI 服务商，同时让你的对话保持私密、尽在掌控。LibreChat 支持会话分线程、消息编辑、插件集成以及可自定义的预设配置。
