## Logto 是什么？

Logto 是一款专为现代应用和 SaaS 产品打造的 Auth0 替代方案。它为开发者提供顺滑的使用体验，非常适合个人与成长型公司。

🧑‍💻 **覆盖前端到后端的完整身份解决方案**

- 通过 Logto SDK 实现基于 OIDC 的身份验证。
- 支持免密登录，以及邮箱、手机号、用户名、Google、Facebook 等多种社交登录方式。
- 提供精美的 UI 组件，CSS 可自定义，灵活贴合你的业务需求。

📦 **开箱即用的基础设施**

- 内置拿来即用的管理 API，直接充当你的身份验证提供方，省去额外开发。
- 提供多平台、多语言的 SDK，与你的开发环境无缝衔接，轻松把应用接入 Logto。
- 提供灵活的连接器（connector），可随社区贡献不断扩展，并支持按 SAML、OAuth 和 OIDC 协议定制。

💻 **企业级就绪方案**

- 实现基于角色的访问控制（RBAC），支撑可扩展的角色授权，覆盖各类使用场景。
- 便捷管理用户并提供审计日志，帮你掌握用户身份相关信息、保障安全。
- 无需额外编码即可启用单点登录（SSO）与多因素认证（MFA）。
- 借助 Logto Organizations 轻松构建多租户应用。

用更通俗的话说，我们把这套方案称为「[客户身份与访问管理（CIAM）](https://en.wikipedia.org/wiki/Customer_identity_access_management)」，或者干脆叫「客户身份解决方案」。
