# Inngest

<ZoomImage src="/docs-cn/coolify/images/services/inngest-logo.svg" alt="Inngest logo" />

## Inngest 是什么？

Inngest 是一个开源的持久化工作流引擎，可用于后台任务、队列、计划作业与事件驱动函数。应用通过 HTTP 发送事件，由 Inngest 负责执行、重试以及各个工作流步骤的管理。
