由于 PHP 安全漏洞 **CVE-2026-109618** 和 **CVE-2026-109619**，该服务的一键模板已在 Coolify 中暂时停用。在修复后的容器镜像完成验证之前，无法从服务目录部署该服务。

# Privatebin

<ZoomImage src="/docs-cn/coolify/images/services/privatebin-logo.svg" alt="Privatebin 仪表盘" />

## PrivateBin 是什么

PrivateBin 是一款极简的开源在线 pastebin（文本粘贴服务），服务器对粘贴的数据完全不可知。
