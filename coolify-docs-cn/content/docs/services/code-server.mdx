## Code Server 是什么?

在任何机器上运行 [VS Code](https://github.com/Microsoft/vscode),并通过浏览器访问。

## 亮点

- 在任意设备上编码,开发环境始终如一
- 借助云服务器加速测试、编译、下载等任务
- 外出时更省电:所有高负载任务都在你的服务器上运行

## 环境要求

最低配置请参阅[环境要求](https://coder.com/docs/code-server/latest/requirements?utm_source=coolify.io)。

**简而言之:** 一台启用 WebSocket 的 Linux 机器,1 GB 内存,2 个 vCPU。
