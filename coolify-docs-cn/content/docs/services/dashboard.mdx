## Dashboard 是什么?

Dashboard 名副其实,就是一个仪表盘。它受 [SUI](https://github.com/jeroenpardon/sui) 启发,具备 SUI 的全部特性,例如通过 JSON 文件即可完成简单定制,还带一个帮助你更高效搜索互联网的搜索栏。

## 特性

那么,这个项目与 SUI 相比有何不同(甚至更胜一筹)?

- "Display URL" 功能(应用展示的 URL 可以与实际 URL 不同)
- 应用分类管理
- 主题与搜索引擎可通过 JSON 更换
- 支持 imprint(版权声明)功能
