# Satisfactory 是什么？

Satisfactory 是一款第一人称开放世界工厂模拟游戏，重点在于在一颗外星星球上进行建造、自动化与探索。玩家作为 FICSIT Inc. 的"Capital Pioneers"（开拓先锋），探索地图、采集资源，并建造由传送带互联的多层巨型工厂，实现生产自动化。

## 信息

服务器在低于 8GB 内存时也可能运行，但按照[官方 Wiki](https://satisfactory.wiki.gg/wiki/Dedicated_servers#Requirements?utm_source=coolify.io) 的建议，仍推荐 8GB - 16GB 内存。当游戏推进到后期（或者 4 名以上玩家一起游玩）时，你可能需要调大容器定义的 `--memory` 限制。

### 更新

容器启动或重启时游戏会自动更新（除非你设置了 `SKIPUPDATE=true`）。

### 环境变量

| 参数 | 默认值 | 说明 |
|-------------------------|:---------:|------------------------------------------------------------|
| `AUTOSAVENUM` | `5` | 轮换保存的自动存档文件数量 |
| `DEBUG` | `false` | 用于调试服务器 |
| `DISABLESEASONALEVENTS` | `false` | 禁用 FICSMAS 活动（你这扫兴鬼） |
| `LOG` | `false` | 禁用 Satisfactory 日志修剪 |
| `MAXOBJECTS` | `2162688` | 设置服务器的对象上限 |
| `MAXPLAYERS` | `4` | 设置服务器的玩家上限 |
| `MAXTICKRATE` | `30` | 设置服务器的最大模拟 tick 频率 |
| `MULTIHOME` | `::` | 设置服务器的监听网络接口（通常无需设置） |
| `PGID` | `1000` | 设置服务器运行用户的组 ID |
| `PUID` | `1000` | 设置服务器运行用户的用户 ID |
| `SERVERGAMEPORT` | `7777` | 设置游戏服务器端口 |
| `SERVERMESSAGINGPORT` | `8888` | 设置游戏消息端口（内部与外部） |
| `SERVERSTREAMING` | `true` | 切换游戏是否启用资源流式加载 |
| `SKIPUPDATE` | `false` | 在容器启动/重启时跳过游戏更新 |
| `STEAMBETA` | `false` | 使用实验性游戏版本 |
| `STEAMBETAID` | - | 设置自定义 Beta 游戏版本（用于测试） |
| `STEAMBETAKEY` | - | 设置 Beta 游戏版本的密码（用于测试） |
| `TIMEOUT` | `30` | 设置客户端超时时间（秒） |
| `VMOVERRIDE` | `false` | 跳过 CPU 型号检查（通常不应启用） |
