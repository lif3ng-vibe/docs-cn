## Kuzzle 是什么？

Kuzzle 是一个通用后端，提供了每类应用都离不开的基础构建模块。

有了 Kuzzle，你不必在每次新建应用时都把同一批标准功能从头写一遍——它直接把这些功能开箱即用地提供给你，让你可以专注于构建高层次、高价值的业务功能。

## 功能特性

借助 Kuzzle，你可以迅速构建现代 Web 应用和复杂的物联网网络。

- API 优先：使用标准化的多协议 API。
- 持久化数据：存储数据并对其执行高级搜索。
- 实时通知：使用 pub/sub 系统，或订阅数据库通知。
- 用户管理：登录、登出与安全规则不再成为负担。
- 可扩展：使用内置框架直接开发高级业务功能。
- 客户端 SDK：使用官方 SDK 加速前端开发。
