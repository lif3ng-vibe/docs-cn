## SilverBullet 是什么？

SilverBullet 是一个基于 Markdown 构建的开源个人效率平台，并借助 Lua 的脚本能力获得强力加持。你可以把它自托管在自己的服务器上，然后在任意设备（台式机、笔记本、手机）上用现代浏览器访问。由于 SilverBullet 以 Local First（本地优先）PWA 的方式构建，它完全支持离线使用。暂时没有网络？没关系，等你重新上线后，SilverBullet 会自动同步你的内容。
