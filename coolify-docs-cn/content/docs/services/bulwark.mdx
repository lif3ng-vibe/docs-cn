## Bulwark 是什么？

Bulwark 是使用 [JMAP 协议](https://jmap.io/)为 [Stalwart Mail Server](https://stalw.art?utm_source=coolify.io)打造的现代开源网页邮箱客户端。只需一次登录，即可使用邮件、日历、联系人和文件存储。

## 前提条件

部署 Bulwark 之前，你需要一台运行中的 JMAP 兼容邮件服务器。Stalwart 是经过主要测试的后端，也是推荐选择。如果还没有，请先在 Coolify 上部署 [Stalwart](/services/stalwart) 服务再回来。

要使用完整功能（账户设置、应用密码、Sieve 过滤器、管理仪表盘），需要 Stalwart **0.16 或更新版本**。

## 配置 Bulwark

在 Coolify 中创建服务后，按照以下步骤完成 Bulwark 的配置。

### JMAP 服务器 URL

首次部署前，请将 `JMAP_SERVER_URL` 环境变量设置为你的 JMAP 服务器 URL。这是必需变量，缺少它服务将无法启动。

如果你在 Coolify 上运行 [Stalwart](/services/stalwart) 服务，这里就填 Stalwart 的服务 URL，例如 `https://mail.yourdomain.com`。Bulwark 会探测该 URL 下的 `/.well-known/jmap` 端点来定位你的 JMAP 服务器。

要将 Bulwark 连接到多个 JMAP 服务器，把 `JMAP_SERVER_URL` 设置为以逗号分隔的 URL 列表。登录表单会在可能时根据邮箱域名自动选择服务器。

### 会话密钥

`SESSION_SECRET` 环境变量由 Coolify 自动生成，无需手动处理。它用于加密持久化会话、设置同步数据以及多账户状态。

### 访问网页邮箱

部署完成后，即可通过由 `SERVICE_URL_BULWARK_3000` 生成的服务 URL 访问网页邮箱。使用你 JMAP 服务器上某个邮箱的凭据登录。

### Stalwart 专属功能

连接 Stalwart 0.16 或更新版本时，Bulwark 会启用一些依赖 Stalwart JMAP `x:` 方法的额外功能：

- 在账户设置中修改密码
- 启用带恢复码的 TOTP 双因素认证
- 生成应用专用密码（例如供 IMAP/SMTP 客户端使用）
- 在服务器端管理 Sieve 过滤器
- 配置休假自动回复
- 查看存储配额并与服务器同步身份

## 故障排除

如果 Bulwark 无法连接你的邮件服务器：

- 运行 `curl https://<your-jmap-server>/.well-known/jmap`，确认返回了 JMAP 会话资源，以此验证 JMAP 端点可以访问。
- 如果 Bulwark 与邮件服务器不在同一域名下，请确保邮件服务器已启用 CORS：
  - 在 Stalwart 管理面板中，依次进入 **Settings**（设置）> **Network**（网络）> **HTTP** > **Security**（安全），将 `Permissive CORS policy` 设为 `enabled`（启用）。

<ZoomImage src="/docs-cn/coolify/images/services/bulwark-cors.webp" alt="在 Stalwart 管理面板中启用 Permissive CORS policy" />

  - 保存后，在 Coolify 中重启 Stalwart 服务使更改生效（或在 **Management**（管理）> **Actions**（操作）> **Reload**（重载）> **Server Settings**（服务器设置）中重载配置）。

<ZoomImage src="/docs-cn/coolify/images/services/bulwark-reload-server-settings.webp" alt="在 Stalwart 管理面板中重载服务器设置" />
