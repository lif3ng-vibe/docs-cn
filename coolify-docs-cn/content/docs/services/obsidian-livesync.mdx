## Obsidian LiveSync 是什么？

Obsidian LiveSync 是一个自托管同步后端，为 [Obsidian](https://obsidian.md/?utm_source=coolify.io) 的 [LiveSync 社区插件](https://github.com/vrtmrz/obsidian-livesync?utm_source=coolify.io)而设计。它以 CouchDB 作为底层数据库，在多台设备之间实时同步你的 Obsidian 仓库（vault）——无论是桌面端、移动端，还是任何能运行 Obsidian 的平台。

与官方的 Obsidian Sync 服务不同，LiveSync 让你在自己的基础设施上运行同步服务器，从而完全掌控自己的数据。所有笔记内容都保存在你自己的 CouchDB 实例中，绝不会经过任何第三方服务器。

## 工作原理

该 Coolify 服务会部署一个预配置好的 CouchDB 实例，并已针对 Obsidian 应用的来源（`app://obsidian.md`、`capacitor://localhost`、`http://localhost`）启用了 CORS。部署完成后，在 Obsidian 中将 LiveSync 插件指向你的服务器地址和凭据，即可开始同步。

## 配置

在 Coolify 中部署该服务后：

1. 打开 Obsidian，从社区插件列表中安装 **Self-hosted LiveSync** 插件。
2. 在插件设置中，选择 **Remote Database** 并选择 **CouchDB**。
3. 填入服务地址（即 Coolify 分配的域名，例如 `https://your-domain.example.com`）。
4. 填入用户名和密码——可在 Coolify 的 **Environment Variables**（环境变量）面板中找到（`COUCHDB_USER` 和 `COUCHDB_PASSWORD`）。
5. 点击 **Test Database Connection**（测试数据库连接），确认配置无误。
6. 启用 **LiveSync** 或 **Periodic Sync**（定期同步）模式，开始同步。

## 环境变量

| 变量 | 默认值 | 说明 |
|---|---|---|
| `COUCHDB_USER` | 自动生成 | CouchDB 管理员用户名 |
| `COUCHDB_PASSWORD` | 自动生成 | CouchDB 管理员密码（64 位字符） |
| `MAX_DOCUMENT_SIZE` | `52428800`（50 MB） | 单个 CouchDB 文档的最大体积（字节） |
| `MAX_HTTP_REQUEST_SIZE` | `67108864`（64 MB） | HTTP 请求的最大体积（字节）——应大于 `MAX_DOCUMENT_SIZE`，以容纳多部分请求的额外开销 |

仅当你会在笔记中附加非常大的文件时，才需要调大 `MAX_DOCUMENT_SIZE` 和 `MAX_HTTP_REQUEST_SIZE`。
