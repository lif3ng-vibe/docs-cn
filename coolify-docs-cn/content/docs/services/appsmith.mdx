# Appsmith

<ZoomImage src="https://raw.githubusercontent.com/appsmithorg/appsmith/release/static/images/appsmith-in-100-seconds.png" alt="Appsmith" />

## Appsmith 是什么

企业会构建仪表盘、数据库 GUI、管理后台、审批应用、客服工具等内部应用，以改进业务运营。

Appsmith 是一款开源开发者工具，可以快速开发这类应用。你只需拖放预置的组件，就能搭建出 UI。

通过它的数据源功能，可以安全地连接你的数据库和 API，再用查询与 JavaScript 编写业务逻辑来读写数据。

## 为什么选择 Appsmith

Appsmith 让构建与任意数据源交互的 UI 变得简单。只需几个简单步骤，从简单的 CRUD 应用到复杂的多步骤工作流都能创建：

- 连接数据源：接入数据库或 API。Appsmith 支持最流行的数据库和 REST API。
- 搭建 UI：使用内置组件构建应用布局。
- 编写逻辑：在编辑器的任意位置用查询和 JavaScript 表达业务逻辑。
- 协作、部署、分享：Appsmith 支持基于 Git 的版本控制，可以用分支协作构建应用、跟踪并回滚变更。部署应用后即可与其他用户分享。
