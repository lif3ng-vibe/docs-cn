# Obsidian

<ZoomImage src="/docs-cn/coolify/images/services/obsidian-logo.svg" alt="Obsidian" />

## Obsidian 是什么？

[Obsidian](https://obsidian.md?utm_source=coolify.io) 是一个功能强大的知识库与笔记应用，构建在本地纯 Markdown 文件文件夹之上。它让你可以创建笔记、在笔记之间建立链接并进行整理，形成个人知识图谱；同时拥有丰富的插件生态，包括 1000 多个社区插件和主题，可自由定制你的工作流。

该 Coolify 模板使用 [LinuxServer.io](https://linuxserver.io?utm_source=coolify.io) 镜像，将 Obsidian 以 **Linux 桌面容器**的方式运行。应用会通过 HTTPS 将完整的图形化桌面串流到你的浏览器——本地电脑无需安装任何东西。你的仓库（vault）保存在服务器上一个命名的 Docker 卷中，并在容器更新时持续保留。

## 系统要求

Obsidian 以 Electron/Chromium 应用的形式在容器内运行，并向浏览器串流视频画面，因此比普通 Web 应用更消耗资源。

| 资源 | 最低配置 | 推荐配置 |
|---|---|---|
| CPU | 2 核 | 4 核 |
| 内存 | 2 GB | 4 GB |
| 磁盘 | 1 GB | 4 GB 以上（随仓库大小增长） |
| 架构 | x86-64 或 arm64 | x86-64 |

<Callout type="info">
容器的 1 GB 内存会被预留为共享内存（`shm_size`）供 Chromium 使用。若宿主机空闲内存不足 2 GB，容器将在启动时崩溃。
</Callout>

支持 GPU 加速（Intel、AMD 或 Nvidia），可降低 CPU 占用并获得更好的串流质量，但并非必需。GPU 配置详情请参阅 [LinuxServer 文档](https://docs.linuxserver.io/images/docker-obsidian?utm_source=coolify.io)。

## 部署 Obsidian

1. 在 Coolify 中进入 **Services**（服务），搜索 **Obsidian**。
2. 点击 **Deploy**（部署）。Coolify 会自动生成安全的用户名和密码——基础部署无需任何额外配置。
3. 容器运行起来后，点击 **Open**（打开）按钮，在浏览器中启动 Obsidian。
4. 当浏览器提示输入凭据时，使用 Coolify 环境变量面板中显示的 **`CUSTOM_USER`** 和 **`PASSWORD`**。

## 首次设置

首次启动时，你会在浏览器窗口中看到 Obsidian 的仓库选择界面。

1. 点击 **Open folder as vault**（以仓库形式打开文件夹），定位到 `/config` 内的某个文件夹——例如 `/config/vault`。该位置位于持久化的 Docker 卷内，容器更新后依然保留。
2. Obsidian 会打开你的仓库。像平常一样安装插件和主题即可——所有写入 `/config` 的内容都会持久保存。

## 安全须知

<Callout type="warn">
该容器提供特权访问。请勿在未经身份验证的情况下将其暴露到互联网。
</Callout>

- 图形界面内置了一个支持**免密 `sudo`** 的终端。任何能访问该 URL 的人都在容器内拥有完整的 root 控制权。
- 默认通过 HTTP Basic Auth（`CUSTOM_USER` / `PASSWORD`）启用身份验证。若部署在公网环境，建议在服务前面再加一层认证（例如 Authelia 或 Authentik）。
- 在较旧的宿主机内核上，容器需要 `seccomp=unconfined`。如果你的主机运行较新的 Linux 内核（5.15+），可以删除 compose 文件中的 `security_opt` 配置块，以获得更严格的安全配置。

## 查看登录凭据

自动生成的登录凭据以 Coolify 环境变量的形式保存。查看或修改方法如下：

1. 在 Coolify 中打开该服务，点击 **Environment Variables**（环境变量）标签页。
2. 找到 `CUSTOM_USER` 和 `PASSWORD`。
3. 修改任一值后，点击 **Save**（保存），再点击 **Redeploy**（重新部署），更改才会生效。

## 更新 Obsidian

LinuxServer 镜像内置了 Obsidian 版本——更新时需拉取最新镜像并重建容器。`obsidian-config` 卷中的仓库数据不会受影响。

在 Coolify 中，先点击 **Pull Latest Image**（拉取最新镜像），再点击 **Redeploy**（重新部署）。
