## Nitropage 是什么？

Nitropage 是一个基于 SolidStart 的可扩展可视化网站构建器，提供不断丰富的多功能构建块库。

## 部署变体

在 Coolify 中，Nitropage 提供两种部署配置：

### Nitropage（默认）
- **数据库：**SQLite（内嵌）
- **适用场景：**简单部署、测试或小型网站
- **组件：**单个 Nitropage 容器，内置 SQLite 数据库

### 使用 PostgreSQL 的 Nitropage
- **数据库：**PostgreSQL
- **适用场景：**对性能和可扩展性要求更高的生产部署
- **组件：**
  - Nitropage 容器
  - PostgreSQL 容器
  - 自动完成数据库配置与健康检查

## 功能特性

- 可复用的元素**预设**（Presets）与**布局**（Layouts）
- 带**版本修订**（Revisions）的发布工作流
- 内含数十个 Blueprint 的入门套件
- 单个实例托管多个网站
- 支持按**焦点**（focal point）裁剪的图片优化
- 为自定义 [SolidJS](https://www.solidjs.com/?utm_source=coolify.io) 页面元素提供 API
- 基于 [Vite](https://vitejs.dev/?utm_source=coolify.io) 的强大开发者架构
- 自动处理 sitemap.xml 和 Atom 订阅源
