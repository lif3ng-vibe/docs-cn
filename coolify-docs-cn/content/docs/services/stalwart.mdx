# Stalwart

<ZoomImage src="/docs-cn/coolify/images/services/stalwart-logo.svg" alt="Stalwart logo" />

## Stalwart 是什么

Stalwart 是一个用 Rust 编写的一体化邮件与协作服务器。它以单一平台取代了传统的多组件堆栈（MTA、IMAP 服务器、垃圾邮件过滤器、日历服务器），支持 SMTP、IMAP、POP3、JMAP、CalDAV、CardDAV 和 WebDAV。

## 配置 Stalwart

在 Coolify 中创建服务后，按照以下步骤完成 Stalwart 的配置。

### 初始设置

1. Coolify 会为管理界面自动生成一个服务 URL（来自 `SERVICE_URL_STALWART_8080`），你可以立即访问管理面板。不过，要收发邮件就需要你自己的域名——参见下方的 DNS 记录一节。
2. 在服务 URL 下打开 `/admin`，用用户名 `admin` 登录。首次启动时，Stalwart 以引导模式运行，并会向容器日志输出一个临时管理员密码（只显示一次）。获取方法：
   - 在 Coolify 中打开 Stalwart 服务的**日志**，或
   - 通过 SSH 登录服务器并运行 `docker logs <container-name>`。

   如果想改用固定密码，可以在首次部署前向服务环境变量添加 `STALWART_RECOVERY_ADMIN=admin:<your-password>`，设置完成后移除即可。
3. 按照设置向导添加你的域名，并创建第一个邮箱。
4. 在 **Accounts**（账户）> **Mailboxes**（邮箱）下创建更多邮箱。

### DNS 记录

要让 Stalwart 收发邮件，请在你的域名注册商处配置以下 DNS 记录：

| 记录 | 类型 | 值 |
|--------|------|-------|
| MX | MX | `mail.yourdomain.com`（优先级 10） |
| SPF | TXT | `v=spf1 mx ~all` |
| DKIM | TXT | 在 Stalwart 的 **Settings**（设置）> **MTA** > **DKIM** 中生成 |
| DMARC | TXT | `v=DMARC1; p=quarantine; rua=mailto:admin@yourdomain.com` |

PTR（反向 DNS）需要通过 VPS 提供商的控制面板设置，让你的服务器 IP 反向解析到邮件服务器主机名。参见服务商指南：

- [Hetzner：反向 DNS](https://docs.hetzner.com/de/networking/dns/technical-concepts/architecture/#reverse-dns-rdns)
- [Contabo：如何设置反向 DNS](https://contabo.com/blog/contabo-dns-rdns-management-setup-guide/)

### 故障排除

访问管理界面时如果出现 **502 Bad Gateway** 错误，很可能是 Stalwart 对你的反向代理（Traefik）做了限速。由于 Traefik 会通过同一个 IP 转发大量连接，可能触发 Stalwart 的端口扫描防护。

#### 找到你的反向代理网络

通过 SSH 登录服务器，或使用 Coolify 终端，运行：

```bash
docker inspect coolify-proxy | grep -A 5 "Networks"
```

在输出中找到 `IPv4Address`。如果显示的是 `10.0.1.6/24`，那么你的网络就是 `10.0.1.0/24`。

#### 恢复访问

如果你已经被锁在外面：

1. 在环境变量中添加 `STALWART_RECOVERY_MODE=1` 和 `STALWART_RECOVERY_ADMIN=admin:<your-password>`，然后重新部署。恢复访问后把两者都移除。
2. 前往 **Settings**（设置）> **Security**（安全）> **Blocked IPs**（被封禁的 IP），删除被封禁的 IP。

<ZoomImage src="/docs-cn/coolify/images/services/stalwart-blocked-ips.webp" alt="Stalwart 被封禁 IP 页面" />

#### 将反向代理网络加入白名单

1. 在 Stalwart 管理面板中前往 **Security**（安全）> **IP Allowlist**（IP 白名单）。
2. 添加你的 Traefik 网络（例如 `10.0.1.0/24`）。也可以添加 `10.0.0.0/8` 以信任所有 Docker 网络。
3. 原因（reason）随意填写（例如 Traefik reverse proxy）。

<ZoomImage src="/docs-cn/coolify/images/services/stalwart-allowed-ips.webp" alt="Stalwart 白名单 IP 页面" />

4. 前往 **Settings**（设置）> **Network**（网络）> **Services**（服务）> **HTTP** > **General**（常规），启用 **Obtain remote IP from Forwarded header**（从 Forwarded 头获取远程 IP）。

<ZoomImage src="/docs-cn/coolify/images/services/stalwart-forwarded-header.webp" alt="Stalwart Forwarded 头设置" />
