# 全部服务

Coolify 全部一键服务的完整目录，按分类整理。

## AI

- [9Router](/services/9router) - AI 编程网关，将来自编程工具的请求路由到多个 LLM 提供商。
- [AnythingLLM](/services/anythingllm) - 帮助开发者快速构建并扩展工作流的开源 LLM 客户端。
- [Argilla](/services/argilla) - 用于构建、训练和评估对话式 AI 模型的开源平台。
- [Chroma](/services/chroma) - 面向 AI 原生应用的开源向量数据库,专为 embedding 应用打造。
- [Docling](/services/docling) - 文档处理服务,可将 PDF、办公文档、图片和 HTML 转换为 Markdown、JSON 等格式。
- [Engram](/services/engram) - 面向 AI 编程代理（MCP）的持久化记忆同步服务器。
- [Flowise](/services/flowise) - 通过拖放界面构建自定义 LLM 流程。
- [Hermes Agent](/services/hermes-agent) - 来自 Nous Research 的自主 AI 代理，具备持久记忆、计划任务与 Web 界面。提供双容器 WebUI 套件或单容器 Dashboard 两种形态。
- [Honcho](/services/honcho) - 为构建具备有状态对话的个性化 AI 代理提供记忆与推理工具。
- [Label Studio](/services/labelstudio) - 开源数据标注平台。
- [Langflow](/services/langflow) - 基于 Python 的开源 AI 应用构建框架。
- [Langfuse](/services/langfuse) - 开源 LLM 工程平台。
- [LibreChat](/services/librechat) - 可自托管、功能强大且注重隐私的多模型 AI 聊天界面。

- [Litellm](/services/litellm) - 开源 LLM 网关，以 OpenAI 格式统一管理 100 多个 LLM 的身份验证、负载均衡与开销追踪。
- [LobeChat](/services/lobe-chat) - 开源的现代 AI 聊天框架，支持多家服务商与知识库管理。
- [MetaMCP](/services/metamcp) - 一个应用集 MCP 聚合器、编排器、中间件与网关于一体。
- [Mindsdb](/services/mindsdb) - 把 AI 带入数据库的机器学习平台。
- [NewAPI](/services/newapi) - 新一代 LLM 网关与 AI 资产管理系统，支持多种语言。
- [Ollama](/services/ollama) - 一个轻量高效的服务器，用于在本地机器或云端运行大语言模型（LLM）。
- [Open Webui](/services/open-webui) - 对用户友好的 LLM WebUI，前身为 Ollama WebUI。
- [OpenClaw](/services/openclaw) - 支持多 AI 供应商与浏览器自动化的 AI 编程助手。
- [Qdrant](/services/qdrant) - 开源的 AI 原生向量数据库。
- [Spacebot](/services/spacebot) - 具备思考、工作与记忆专职进程的 AI 智能体系统。
- [Unstructured](/services/unstructured) - 为检索增强生成（RAG）与模型微调摄取和处理非结构化文档的开源平台与工具。
