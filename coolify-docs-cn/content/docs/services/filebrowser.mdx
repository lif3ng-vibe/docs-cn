## Filebrowser 是什么？

Filebrowser 在指定目录内提供一个文件管理界面，可用于上传、删除、预览、重命名和编辑文件。它支持创建多个用户，每个用户都可以拥有自己的目录，也可以作为独立应用使用。

## 设置

- 使用 Coolify 模板部署 Filebrowser
- 在 Filebrowser 界面中使用以下凭据登录：
  - 用户名：`admin`
  - 密码：随机生成，可在日志中查看
