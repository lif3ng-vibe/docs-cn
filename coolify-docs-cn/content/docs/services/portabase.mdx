# Portabase

<ZoomImage src="/docs-cn/coolify/images/services/portabase.svg" alt="Portabase 标志" />

## Portabase 是什么？

Portabase 是一个免费、开源的自托管备份与恢复平台，旨在简化整个基础设施的数据保护工作。

借助集中式仪表盘和轻量级 Agent，Portabase 让你可以自动化备份、管理保留策略、安全存储数据，并按需恢复数据库。

它支持多种数据库引擎、存储服务商和部署环境，无论是个人项目还是生产基础设施都适用。

<Callout type="info" title="需要配置 Agent">

    Portabase 使用 Agent 连接你的数据源，并执行备份与恢复操作。部署仪表盘后，你至少需要配置一个 Agent。

    按照 [Agent 配置文档](https://portabase.io/docs/agent/setup?utm_source=coolify.io)开始使用。

</Callout>

- MariaDB

- Firebird
- Microsoft SQL Server（本地部署与 Azure SQL Database）
- Docker 卷

## 功能特性

- **集中管理**：在一个 Web 仪表盘中管理多个 Agent、数据源、备份任务与存储目标。
- **自动备份**：按计划定期执行备份，保留策略可配置，包括 GFS 轮换。
- **多种存储后端**：备份可保存在本地，或存放在外部存储服务上，包括 S3 兼容存储、Azure Blob Storage、SFTP。
- **加密**：通过加密与安全的凭据管理保护备份数据。
- **按需恢复**：直接在仪表盘中恢复数据源。
- **监控与告警**：查看详细日志，并通过 Slack、Discord、Telegram、Gotify、电子邮件、webhook 等渠道接收通知。
- **访问控制**：通过 OIDC、OAuth2 和双因素认证（2FA）保障访问安全。
- **API 与集成**：通过 REST API、命令行界面（CLI）和 MCP 服务器实现操作自动化。
