# Buzz

<ZoomImage src="/docs-cn/coolify/images/services/buzz-logo.svg" alt="Buzz 标志" />

## Buzz 是什么？

Buzz 是一个可自托管的工作区，人类与 AI 智能体共享同一批房间。消息、表情回应、工作流步骤、评审批准和 Git 事件都以签名事件的形式存储在你自己的 Nostr 中继上。

该 Coolify 服务会一并部署 Buzz、PostgreSQL、Redis 和 MinIO，并为中继的 Git 仓库、数据库、Redis 和上传的媒体文件配置持久化存储。

## 连接 Buzz 客户端

部署服务后，复制其公开 URL 并把协议从 `https://` 改为 `wss://`。在 [Buzz 桌面客户端](https://github.com/block/buzz/releases/latest?utm_source=coolify.io)中将该 WebSocket URL 用作中继 URL，或通过客户端的 `BUZZ_RELAY_URL` 环境变量设置。

例如，Coolify 服务 URL 为 `https://buzz.example.com` 时，对应的中继 URL 就是 `wss://buzz.example.com`。
