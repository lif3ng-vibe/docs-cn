# Langflow

<ZoomImage src="/docs-cn/coolify/images/services/langflow.svg" alt="Langflow" />

## Langflow 是什么？

Langflow 是一个基于 Python 的开源 AI 应用构建框架。它将可视化编辑体验与完整的编程访问能力结合在一起，帮助团队对 AI 智能体和工作流进行原型设计、测试与部署。

它通过**拖拽式界面**加速开发，同时保留**自定义 Python 组件**的灵活性，足以应对各种高级用例。

## 凭据

在 Coolify 上部署 Langflow 后，你可以使用以下环境变量中自动生成的凭据登录仪表盘：

| 变量                           | 说明                     |
|--------------------------------|--------------------------|
| `LANGFLOW_SUPERUSER`           | 管理员账户的用户名        |
| `LANGFLOW_SUPERUSER_PASSWORD`  | 管理员账户的密码          |
