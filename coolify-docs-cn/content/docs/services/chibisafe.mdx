# Chibisafe

<ZoomImage src="/docs-cn/coolify/images/services/chibisafe-logo.svg" alt="Chibisafe 徽标" />

## Chibisafe 是什么?

Chibisafe 是一个美观又高效的云端仓库,帮你存放所有文件。它是对文件上传服务的一次现代化自托管演绎,凭借稳健而快速的 API、分块上传支持等能力,无论多大的文件量都能从容应对。
