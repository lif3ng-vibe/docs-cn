## Meilisearch 是什么？

一个快如闪电的搜索引擎，可轻松融入你的应用、网站与工作流

Meilisearch 能让你在瞬间打造出色的搜索体验，众多开箱即用的功能为你的工作流提速。

## ✨ 功能特性

- **输入即搜：**不到 50 毫秒即可返回搜索结果
- **[容错搜索](https://www.meilisearch.com/docs/learn/configuration/typo_tolerance?utm_campaign=oss&utm_source=github&utm_medium=meilisearch&utm_content=features)：**即使查询中包含拼写错误，也能返回相关结果
- **[筛选](https://www.meilisearch.com/docs/learn/fine_tuning_results/filtering?utm_campaign=oss&utm_source=github&utm_medium=meilisearch&utm_content=features)与[分面搜索](https://www.meilisearch.com/docs/learn/fine_tuning_results/faceted_search?utm_campaign=oss&utm_source=github&utm_medium=meilisearch&utm_content=features)：**用自定义筛选器提升用户的搜索体验，几行代码即可构建分面搜索界面
- **[排序](https://www.meilisearch.com/docs/learn/fine_tuning_results/sorting?utm_campaign=oss&utm_source=github&utm_medium=meilisearch&utm_content=features)：**按价格、日期或用户需要的几乎任何条件对结果排序
- **[同义词支持](https://www.meilisearch.com/docs/learn/configuration/synonyms?utm_campaign=oss&utm_source=github&utm_medium=meilisearch&utm_content=features)：**配置同义词，让搜索结果覆盖更多相关内容
- **[地理搜索](https://www.meilisearch.com/docs/learn/fine_tuning_results/geosearch?utm_campaign=oss&utm_source=github&utm_medium=meilisearch&utm_content=features)：**基于地理数据对文档进行筛选和排序
- **[广泛的语言支持](https://www.meilisearch.com/docs/learn/what_is_meilisearch/language?utm_campaign=oss&utm_source=github&utm_medium=meilisearch&utm_content=features)：**支持任意语言的数据集搜索，并针对中文、日语、希伯来语以及拉丁字母语言做了优化
- **[安全管理](https://www.meilisearch.com/docs/learn/security/master_api_keys?utm_campaign=oss&utm_source=github&utm_medium=meilisearch&utm_content=features)：**通过支持细粒度权限控制的 API 密钥，管理哪些用户可以访问哪些数据
- **[多租户](https://www.meilisearch.com/docs/learn/security/tenant_tokens?utm_campaign=oss&utm_source=github&utm_medium=meilisearch&utm_content=features)：**为任意数量的应用租户提供个性化的搜索结果
- **高度可定制：**按具体需求定制 Meilisearch，或直接使用开箱即用、省心省力的预设
- **[RESTful API](https://www.meilisearch.com/docs/reference/api/overview?utm_campaign=oss&utm_source=github&utm_medium=meilisearch&utm_content=features)：**借助插件和 SDK 将 Meilisearch 集成到你的技术栈中
- **安装、部署和维护都很轻松**
