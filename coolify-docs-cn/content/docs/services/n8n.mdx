## N8N 是什么？

N8N 是一个开源的工作流自动化工具，可以让你把不同的应用和服务连接起来。它是 Zapier、Make 等工具的开源替代品。

## 部署变体

在 Coolify 中，N8N 提供三种部署配置：

### n8n（默认）
- **数据库：**SQLite（内嵌）
- **适用场景：**简单部署、测试或低流量工作流
- **组件：**单个 n8n 容器，内置 SQLite 数据库

### 使用 PostgreSQL 的 n8n
- **数据库：**PostgreSQL（外部）
- **适用场景：**对性能、可扩展性和数据持久性要求更高的生产部署
- **组件：**
  - n8n 容器
  - PostgreSQL 16 容器
  - 自动完成数据库配置与健康检查

### 使用 PostgreSQL 和 Worker 的 n8n
- **数据库：**PostgreSQL + Redis
- **适用场景：**需要基于队列执行和并行工作流处理的大规模生产部署
- **组件：**
  - n8n 主容器
  - 用于分布式执行的 n8n-worker 容器
  - PostgreSQL 16 容器
  - 用于队列管理的 Redis 容器
  - 自动完成数据库配置与健康检查

### 使用自定义依赖扩展 n8n

要为 n8n 添加自定义依赖，可以按照下面的示例将其添加到你的 Dockerfile 中：

```dockerfile
...
RUN apk add --no-cache ffmpeg
...
```

### Dockerfile 示例

```dockerfile
FROM n8nio/n8n:latest

# Switch to root user to install packages and modify system directories
USER root

# Install necessary system packages using apk
# build-base, python3-dev, geoip-dev are needed for potential native dependencies
# wget for downloading, git for source control (might be needed by Go), bash (useful shell)
RUN apk update && \
    apk add --no-cache \
        wget \
        ffmpeg


ENV N8N_HOST=${SUBDOMAIN}.${DOMAIN_NAME}
ENV N8N_PORT=5678
ENV N8N_PROTOCOL=https
ENV NODE_ENV=production
ENV WEBHOOK_URL=https://${SUBDOMAIN}.${DOMAIN_NAME}/

# Switch back to the non-root user that n8n runs as (typically 'node')
USER node
```
