## Infisical 是什么？

Infisical 是一个开源安全基础设施平台，工程师用它进行机密管理、内部 PKI、密钥管理和 SSH 工作流编排。

- 机密管理（Secrets Management）：Infisical 的机密管理模块让开发者能够集中、安全地管理应用配置、API 密钥、数据库凭据和其他敏感数据。
- 公钥基础设施（PKI）：Infisical PKI 让你运营内部证书颁发机构，为服务、应用和设备管理完整的 X.509 证书生命周期。
- 密钥管理系统（KMS）：Infisical KMS 帮助你生成并安全管理加密密钥，用于数据的加密/解密。
- SSH 证书管理：Infisical SSH 用基于短期证书的认证取代传统静态 SSH 密钥，为工程师快速开通安全、短时效的基础设施 SSH 访问。
