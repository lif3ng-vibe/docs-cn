## Evolution API 是什么？

Evolution API 是一个功能强大的平台，致力于为小型企业、创业者、自由职业者以及资源有限的个人赋能——提供的远不止一个基础的 WhatsApp™ 消息解决方案。

## 需要配置什么才能让 Coolify 与 Evolution API 协同工作？

Coolify 内置的 docker-compose 应该能装好你入门 Evolution API + Postgres + Redis + Evolution Manager 所需的一切。

一切运行起来后，即可访问你的 https://url/manager。
