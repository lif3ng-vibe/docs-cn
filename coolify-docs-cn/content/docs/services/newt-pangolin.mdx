## Newt 是什么？

Newt 是一个完全运行在用户态的 WireGuard 隧道客户端和 TCP/UDP 代理，用于安全地暴露由 Pangolin 管理的私有资源。使用 Newt，你无需再管理复杂的 WireGuard 隧道和 NAT 设置。

## 环境变量

| 名称              | 说明 | 必填 | 默认值 |
| ----------------- | ----------- | -------- | ------------- |
| NEWT ID           | -           | 是      |
| NEWT SECRET       | -           | 是      |
| PANGOLIN ENDPOINT | -           | 是      | domain.tld    |
