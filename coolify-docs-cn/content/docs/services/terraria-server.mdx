<ZoomImage src="/docs-cn/coolify/images/services/terraria.svg" alt="Terraria Server" />

## Terraria 是什么？

Terraria 是一款 2D 沙盒冒险游戏，你可以在广阔的程序生成世界里挖掘、战斗、探索和建造。玩家可以与敌人作战、寻获宝藏、打造武器与护甲，并在各种生物群系中建造建筑。

## 环境变量

| 名称 | 说明 | 必填 | 默认值 |
| --- | --- | --- | --- |
| AUTOCREATE | 若在 -world 指定的路径下找不到世界，则自动创建一个。世界大小由该值指定：1（小）、2（中）、3（大）。 | 是 | 2 |
| WORLDNAME | 使用 -autocreate 时设置世界的名称。 | 是 | world1 |
| DIFFICULTY | 使用 autocreate 时设置世界难度。可选值：0（普通）、1（专家）、2（大师）、3（旅程） | 是 | 1 |
| MAXPLAYERS | 允许的最大玩家数量 | 是 | 8 |
| PASSWORD | 为服务器设置密码 | 是 | mypassword |
| MOTD | 设置服务器的每日格言文本。 | 是 | Welcome to the server! |
| LANGUAGE | 通过语言代码设置服务器语言。可用代码：en/US = 英语 de/DE = 德语 it/IT = 意大利语 fr/FR = 法语 es/ES = 西班牙语 ru/RU = 俄语 zh/Hans = 中文 pt/BR = 葡萄牙语 pl/PL = 波兰语 | 是 | en/US |
| SECURE | 防作弊选项。（1：禁止作弊；0：允许作弊） | 是 | 1 |
