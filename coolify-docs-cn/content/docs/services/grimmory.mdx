<img src="/docs-cn/coolify/images/services/grimmory.svg" alt="Grimmory Logo" />

## Grimmory 是什么？

Grimmory 是一款自托管的电子书库管理与阅读器，也是 Booklore 的后继项目。它让你通过清爽的 Web 界面整理、管理和阅读自己的电子书收藏，并支持通过 bookdrop 文件夹自动导入图书。
