# SeaweedFS

<ZoomImage src="/docs-cn/coolify/images/services/seaweedfs-logo.svg" alt="SeaweedFS logo" />

## SeaweedFS 是什么？

SeaweedFS 是一套面向 blob、对象、文件与数据湖的高速分布式存储系统，可支撑数十亿文件！Blob 存储具备 O(1) 磁盘寻道与云端分层能力；Filer 支持 Cloud Drive、xDC 复制、Kubernetes、POSIX FUSE 挂载、S3 API、S3 Gateway、Hadoop、WebDAV、加密与纠删码。企业版请见 seaweedfs.com。
