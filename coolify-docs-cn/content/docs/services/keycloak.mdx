# Keycloak

<ZoomImage src="/docs-cn/coolify/images/services/keycloak-logo.svg" alt="Keycloak 仪表盘" />

## Keycloak 是什么

Keycloak 是一款开源的身份与访问管理（Identity and Access Management）工具。

## 部署变体

Coolify 中提供两种 Keycloak 部署配置：

### Keycloak（默认）
- **数据库：** 内嵌 H2（开发用）
- **适用场景：** 开发、测试或评估用途
- **组件：** 单个 Keycloak 容器，内置 H2 数据库

### Keycloak with PostgreSQL
- **数据库：** PostgreSQL
- **适用场景：** 对可靠性、性能和数据持久化有要求的生产部署
- **组件：**
  - Keycloak 容器
  - PostgreSQL 容器
  - 自动完成数据库配置并执行健康检查
