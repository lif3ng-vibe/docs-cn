# NocoDB 是什么？

<ZoomImage src="/docs-cn/coolify/images/services/nocodb1.webp" alt="NocoDB 仪表盘" />

NocoDB 是一个开源的 Airtable 替代品，能把任何 MySQL、PostgreSQL、SQL Server、SQLite 与 MariaDB 数据库变成智能表格。
