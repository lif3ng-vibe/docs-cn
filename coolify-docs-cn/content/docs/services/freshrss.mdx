# Freshrss

<ZoomImage src="/docs-cn/coolify/images/services/FreshRSS-logo.png" alt="FreshRSS 标志" />

## Freshrss 是什么

一款免费、可自托管的订阅源聚合器。

## 部署变体

FreshRSS 在 Coolify 中提供四种部署配置：

### FreshRSS（默认）
- **数据库：** SQLite（内嵌）
- **适用场景：** 简单部署、测试或个人 RSS 阅读
- **组件：** 单个 FreshRSS 容器，内置 SQLite 数据库

### FreshRSS 搭配 PostgreSQL
- **数据库：** PostgreSQL
- **适用场景：** 需要更好性能和可扩展性的生产部署
- **组件：**
  - FreshRSS 容器
  - PostgreSQL 容器
  - 自动配置数据库并进行健康检查

### FreshRSS 搭配 MySQL
- **数据库：** MySQL
- **适用场景：** 偏好 MySQL 的生产部署
- **组件：**
  - FreshRSS 容器
  - MySQL 容器
  - 自动配置数据库并进行健康检查

### FreshRSS 搭配 MariaDB
- **数据库：** MariaDB
- **适用场景：** 偏好 MariaDB 的生产部署
- **组件：**
  - FreshRSS 容器
  - MariaDB 容器
  - 自动配置数据库并进行健康检查
