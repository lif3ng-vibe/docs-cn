## Typesense 是什么？

Typesense 是一款开源的容错搜索引擎，专为即时（通常低于 50 毫秒）的边输边搜体验和开发者效率而优化。

如果你听说过 ElasticSearch 或 Algolia，可以这样理解 Typesense：

- Algolia 的开源替代品，并修复了它的一些关键痛点；
- 比 ElasticSearch 更易用、开箱即用的替代品。
