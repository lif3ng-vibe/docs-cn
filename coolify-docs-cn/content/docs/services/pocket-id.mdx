# Pocket ID

<ZoomImage src="/docs-cn/coolify/images/services/pocket-id_screenshot.webp" alt="Pocket ID 横幅" />

## Pocket ID 是什么？

Pocket ID 是一个简单的 OIDC 提供商，使用[通行密钥](https://www.passkeys.io/)（passkey）实现无密码认证。它的设计理念就是直接、易用。它只支持通行密钥认证，让你可以使用 Yubikey 等硬件安全密钥，在各个自托管服务之间安全登录。

## 部署变体

Pocket ID 在 Coolify 中提供两种部署配置：

### Pocket ID（默认）
- **数据库**：SQLite（内嵌）
- **适用场景**：简单部署、测试或个人认证服务器
- **组件**：单个 Pocket ID 容器，内置 SQLite 数据库

### Pocket ID（PostgreSQL）
- **数据库**：PostgreSQL
- **适用场景**：对性能和数据可靠性要求更高的生产部署
- **组件**：
  - Pocket ID 容器
  - PostgreSQL 容器
  - 自动完成数据库配置与健康检查

## 功能特性

- **无密码认证**：使用通行密钥代替密码，安全性更高
- **OIDC 提供商**：可与支持 OpenID Connect 的应用集成
- **设置简单**：相比复杂的同类方案，安装和配置更轻松
- **兼容性广**：可与 Nextcloud、GitLab 等[多种服务](https://pocket-id.org/docs/client-examples?utm_source=coolify.io)配合使用
- **通行密钥支持**：完整支持 Yubikey 等硬件安全密钥
- **自托管**：完全掌控你的认证基础设施

## 快速开始

部署完成后，你可以使用管理员账号在以下地址登录：

```
https://<your-app-url>/setup
```

按照 Pocket ID 的设置向导配置实例，并创建你的第一个通行密钥。
