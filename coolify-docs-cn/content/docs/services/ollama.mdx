## Ollama 是什么？

Ollama 是一个轻量高效的服务器，用于在本地机器或云端运行大语言模型（LLM）。

它还内置了 OpenWebUI——一个用于与模型交互的 Web 界面。

## 使用 NVIDIA GPU 运行 Ollama

要使用 NVIDIA GPU 加速模型推理，需要先准备好宿主机，并在 Compose 配置中启用 GPU 透传。

1. **硬件要求**
   - 一台配备 NVIDIA GPU 的服务器（已在 RTX 3060 12 GB 上测试）
   - 建议内存至少 32 GB
   - 为计划运行的模型准备足够的磁盘空间

2. **宿主机软件配置**
   - 安装 NVIDIA 驱动
   - 安装 NVIDIA Container Toolkit
   - 配置 Docker 使用 NVIDIA 运行时

3. **Coolify 配置**
   - 使用一键安装器部署 Ollama
   - 编辑 Compose 配置以添加 GPU 支持（添加一个带 `nvidia` 驱动的 `deploy.resources.reservations.devices` 条目）
   - 添加模型进行 GPU 加速所需的环境变量

4. **模型管理**
   - 拉取并管理你需要的模型
   - 监控 GPU 使用情况，并按需调整模型参数

完整的分步教程请参阅这篇[社区指南](https://geek.sg/blog/how-i-self-hosted-llama-32-with-coolify-on-my-home-server-a-step-by-step-guide?ref=coolify.io)。
