## Jellyfin 是什么？

Jellyfin 是一套自由软件媒体系统（Free Software Media System），让你完全掌控媒体的管理与串流。它是专有软件 Emby 和 Plex 的替代品，能够通过多种应用把媒体内容从专用服务器提供给最终用户设备。Jellyfin 源自 Emby 3.5.2 发布版，并移植到了 .NET Core 框架，从而实现完整的跨平台支持。

这里没有任何附加条件，没有付费许可证或付费功能，也没有藏着掖着的小算盘：只有一群想把事情做得更好并为此携手努力的团队成员。欢迎任何有兴趣的人加入我们，一同踏上这段旅程！
