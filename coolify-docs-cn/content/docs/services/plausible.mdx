## Plausible Analytics 是什么？

Plausible 是一款直观、轻量的开源网站分析软件。它不使用任何 Cookie，完全符合 GDPR、CCPA 与 PECR 的要求。

## 如何通过 Coolify 部署 Plausible Analytics？

由于商标问题，我们无法为 Plausible Analytics 提供全自动的一键服务安装。不过别担心，手动安装依然非常简单。

## 安装

1. 添加新资源，并选择 `Docker Compose Empty` 应用部署类型。
2. 将以下[文件](https://raw.githubusercontent.com/coollabsio/coolify/v4.x/templates/compose/plausible.yaml)的内容（连同注释）复制到输入框中。
3. 点击 `Save` 按钮。
4. 进入 `Plausible` 服务的设置页面（右侧的 `Settings` 按钮）。
5. 在 `Domains` 输入框中填入你的自定义域名（也可以点击自动生成域名旁边的编辑图标来修改域名）。
6. 点击 `Save` 按钮。
7. 点击 `Deploy` 按钮，等待部署完成。
