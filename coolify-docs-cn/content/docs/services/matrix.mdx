# Matrix (Synapse)

<ZoomImage src="/docs-cn/coolify/images/services/matrix-logo.svg" alt="Matrix 仪表盘" />

## Matrix 是什么？

Matrix 是一个开源的去中心化通信协议，支持安全、实时的通信。它提供端到端加密的消息、语音与视频通话、文件共享，以及基于房间（room）的会话。作为 Slack、Discord 等专有平台的优秀替代品，Matrix 还具备联邦（federation）能力，让不同的 Matrix 服务器之间可以互相通信。

## Synapse 是什么？

Synapse 是一个用 Python/Twisted 编写的 [Matrix 主服务器（homeserver）](https://matrix.org/ecosystem/servers/)，由 Matrix 的创造者 [Element](https://element.io/) 团队[开发并维护](https://github.com/element-hq/synapse)。

## 部署变体

在 Coolify 中，Synapse Matrix 服务器提供两种部署配置：

### 使用 SQLite 的 Synapse

- **数据库：**SQLite（内嵌）
- **适用场景：**简单部署、测试或个人 Matrix 托管
- **组件：**单个 Synapse 容器，内置 SQLite 数据库

### 使用 PostgreSQL 的 Synapse（推荐）

- **数据库：**PostgreSQL
- **适用场景：**对性能和可扩展性要求更高的生产部署
- **组件：**
  - Synapse 容器
  - PostgreSQL 容器
  - 自动完成数据库配置与健康检查

## 安装步骤

所有部署变体的安装步骤都相同。

### Matrix 域名设置（重要）

Matrix 使用一个名为**服务器名称**（server name）的值来生成用户 ID 和房间别名。

- 服务器名称设为 `example.org` 时会得到：
  - `@user:example.org`
  - `#room:example.org`

Matrix 服务器本身可以运行在另一个域名上，例如 `matrix.example.org`。

### 推荐设置

- Matrix 服务器名称：`example.org`
- Matrix Synapse 服务器服务域名：`matrix.example.org`

这样，用户和房间可以使用 `:example.org` 后缀，同时把 Synapse 托管在子域名上。

### Coolify 配置

#### 域名

在服务配置中，将域名设置为 `matrix.example.org:8008`

#### 环境变量

设置以下环境变量：

- `SYNAPSE_SERVER_NAME=example.org`

### 委派（必需）

由于 Synapse 运行在 `matrix.example.org` 上，但对外标识为 `example.org`，因此需要进行[委派（delegation）](https://element-hq.github.io/synapse/latest/delegate.html)。

在 `https://example.org` 上提供以下文件：

- `/.well-known/matrix/client`，用于服务器委派

```json
{
  "m.homeserver": {
    "base_url": "https://matrix.example.org"
  }
}
```

- `/.well-known/matrix/server`，用于联邦（Federation）发现

```json
{
  "m.server": "matrix.example.org:443"
}
```
