# Langfuse 是什么？

[Langfuse](https://langfuse.com/) 是一个 **[开源](https://github.com/langfuse/langfuse) LLM 工程平台**，帮助团队协作式地**调试**、**分析**并**迭代**他们的 LLM 应用。

它提供**可观测性**、**链路追踪**、**提示词管理**、**评估**与**分析**等工具，加速整个开发流程。

## 核心功能

### 可观测性与链路追踪

- **洞察**：借助详细的追踪能力，深入理解 LLM 的行为细节。
- **集成**：与 [LangChain](https://langfuse.com/docs/integrations/langchain)、[Llama Index](https://langfuse.com/docs/integrations/llama-index)、[OpenAI](https://langfuse.com/docs/integrations/openai) 等主流框架无缝集成。

### 提示词管理

- **关联追踪**：将提示词版本与追踪数据关联起来，全景查看每次交互。
- **零延迟**：提示词管理不会给你的应用带来额外延迟。
- **高效管理**：组织提示词并管理其版本，持续优化模型表现。

### 评估与分析

- **基于模型的评估**：使用内置工具，或接入 [UpTrain](https://langfuse.com/guides/cookbook/evaluation_with_uptrain)、[Ragas](https://langfuse.com/guides/cookbook/evaluation_of_rag_with_ragas) 等外部评估流水线。
- **自定义指标**：定义并跟踪自定义评分与标注，衡量模型表现。
- **分析仪表盘**：通过可视化图表与报告监控用量、成本与模型效果。
