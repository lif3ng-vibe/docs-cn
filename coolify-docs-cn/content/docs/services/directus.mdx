## Directus 是什么?

Directus 是一套实时 API 加应用仪表盘,用于管理 SQL 数据库中的内容。

- **开源。** 没有人为限制,没有厂商锁定,也没有隐藏的付费墙。
- **REST 与 GraphQL API。** 即刻为任意 SQL 数据库叠上一层极速的 Node.js API。
- **直接管理纯 SQL。** 全新或既有 SQL 数据库都能用,无需迁移。
- **数据库任选。** 支持 PostgreSQL、MySQL、SQLite、OracleDB、CockroachDB、MariaDB 与 MS-SQL。
- **本地部署或上云。** 可以本地运行、装在自己的机房,也可以使用[自助式 Cloud 服务](https://directus.io/pricing?utm_source=coolify.io)。
- **完全可扩展。** 天生支持白标定制,模块化平台轻松改造。
- **现代化仪表盘。** 无代码 Vue.js 应用对非技术用户安全又直观,无需培训即可上手。

## 部署变体

Coolify 中 Directus 提供两种部署配置:

### Directus(默认)
- **数据库:** SQLite3(基于文件)
- **适用场景:** 开发、测试或小规模部署
- **组件:** 单个 Directus 容器,内嵌 SQLite 数据库

### Directus + PostgreSQL
- **数据库:** PostgreSQL + Redis
- **适用场景:** 对性能、可扩展性与缓存有更高要求的生产部署
- **组件:**
  - Directus 容器
  - PostgreSQL 16 容器
  - 用于缓存的 Redis 7 容器
  - 自动完成数据库配置与健康检查
