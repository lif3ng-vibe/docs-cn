## Beszel 是什么？

轻量级服务器监控中心，提供历史数据、Docker 统计与告警。

<ZoomImage src="/docs-cn/coolify/images/services/beszel-ui.webp" alt="Beszel 界面" />

## 设置步骤

### 1. 部署 Beszel
在 Coolify 上创建一个新资源，搜索 `Beszel` 并选择 `Beszel` 模板（如果只想部署 Agent，可以选择 `Beszel Agent`）

然后点击部署按钮，等待部署完成。

首次部署带 Agent 的 Beszel 时，beszel-agent 会处于不健康并不断重启的状态，这是正常且符合预期的，因为它还需要一些额外的设置步骤，下文会逐一说明。


<ZoomImage src="/docs-cn/coolify/images/services/beszel-setup-1.webp" alt="Beszel 设置步骤 1" />

### 2. 在 Beszel 仪表盘上添加系统
访问 Beszel 的 URL，在 Beszel 仪表盘上创建你的第一个管理员账户。

创建账户后，点击顶角的"**Add a new System**"（添加新系统）按钮。


<ZoomImage src="/docs-cn/coolify/images/services/beszel-setup-2.webp" alt="Beszel 设置步骤 2" />

<br />

<ZoomImage src="/docs-cn/coolify/images/services/beszel-setup-3.webp" alt="Beszel 设置步骤 3" />

- 为 Agent 起一个名字
- Host/IP 一栏：如果使用 **Beszel** 模板，填入 `beszel-agent`；如果使用 **Beszel Agent** 模板，则填入 Agent 所部署服务器的 IP 地址
- 复制 `Public Key` 和 `Token` 的值，然后点击"Add system"（添加系统）

### 3. 在 Coolify 中设置 KEY 和 TOKEN 环境变量
前往 Coolify 的 **Environment Variables**（环境变量），为 `KEY` 和 `TOKEN` 变量填入对应的值，也就是上一步从 Beszel 仪表盘复制的公钥（Public Key）和令牌（Token）。

<ZoomImage src="/docs-cn/coolify/images/services/beszel-setup-4.webp" alt="Beszel 设置步骤 4" />

### 4. 重启 Beszel
设置好环境变量（上一步）后，点击重启按钮重启 Beszel。

重启完成后，`beszel-agent` 服务将转为健康状态，Beszel 仪表盘也会开始显示数据。


<Callout type="warn" title="注意">

如果你使用的 Coolify 版本低于 v4.0.0-beta.452，请在 hub 服务的设置中禁用 gzip 压缩。

在 Coolify 中进入 Beszel 服务，点击"settings"（设置），取消勾选 `gzip compression` 选项。

</Callout>
