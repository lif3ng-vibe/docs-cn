## Gotify 是什么？

Gotify 是一个通过 WebSocket 实时收发消息的简易服务器。它自带精美的 Web UI 用于管理通知，并让你对自己的通知数据拥有完全的控制权。

## 功能特性

- **自托管、隐私优先：**数据完全由自己掌控，无需依赖任何第三方服务
- **REST API：**通过简洁而强大的 REST API 发送消息
- **WebSocket：**通过 WebSocket 连接实时接收消息
- **跨平台：**使用 Go 编写，可在包括 Docker 在内的多种平台上运行
- **Android 与 iOS 支持：**提供用于接收推送通知的原生移动应用
- **用户管理：**管理多个用户、客户端与应用
- **轻量：**服务器高效运行，不会占用过多资源
- **开源：**采用 MIT 许可证，由社区维护
- **易于集成：**简单的 API 让它轻松接入现有应用与服务

## 使用场景

非常适合接收来自以下场景的通知：

- 监控系统与告警
- CI/CD 流水线
- 家庭自动化服务
- 自定义脚本与应用
- 服务器与应用监控
- 备份通知
