# OpenWA

<ZoomImage src="/docs-cn/coolify/images/services/openwa.png" alt="OpenWA 标志" />

开源自托管的 WhatsApp API 网关，自带管理仪表盘。

## 部署变体

- **OpenWA**：在单个容器中使用 SQLite 存储。
- **OpenWA with PostgreSQL and Redis**：包含 PostgreSQL 与 Redis 容器。
