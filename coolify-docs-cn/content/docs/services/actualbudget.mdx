## Actual Budget 是什么？

Actual Budget 是一款速度极快、注重隐私的理财应用，其核心是久经考验、深受喜爱的信封预算法（Envelope Budgeting）。

数据完全归你所有，可随意处置。它还支持多设备同步、可选的端到端加密等众多特性。
