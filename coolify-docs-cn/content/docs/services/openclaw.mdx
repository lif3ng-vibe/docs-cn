# OpenClaw

<ZoomImage src="/docs-cn/coolify/images/services/openclaw-logo.svg" alt="OpenClaw" />

## OpenClaw 是什么？

OpenClaw [GitHub](https://github.com/openclaw/openclaw?utm_source=coolify.io) 是一个 AI 驱动的编程助手。它支持 20 多家 AI 供应商，内置浏览器自动化，并可与 Telegram、Discord、Slack、WhatsApp 等聊天平台集成。


<Callout type="warn" title="必须使用 HTTPS">

OpenClaw 需要在启用 HTTPS 的条件下才能正常工作。请确保你的部署已配置并启用 HTTPS。

</Callout>


## 身份验证

OpenClaw 使用 HTTP Basic Auth。`AUTH_USERNAME` 和 `AUTH_PASSWORD` 环境变量由 Coolify 在部署时自动生成。

同时还会生成一个用于 API 访问的网关令牌（`OPENCLAW_GATEWAY_TOKEN`）。

## AI 供应商

至少需要配置一家 AI 供应商的 API 密钥。请为你使用的供应商设置对应的环境变量：

- **Anthropic** — `ANTHROPIC_API_KEY`
- **OpenAI** — `OPENAI_API_KEY`
- **Google Gemini** — `GEMINI_API_KEY`
- **OpenRouter** — `OPENROUTER_API_KEY`
- **Groq** — `GROQ_API_KEY`
- **Mistral** — `MISTRAL_API_KEY`
- **xAI** — `XAI_API_KEY`
- **Cerebras** — `CEREBRAS_API_KEY`
- **Amazon Bedrock** — `AWS_ACCESS_KEY_ID`、`AWS_SECRET_ACCESS_KEY`、`AWS_REGION`
- **Ollama（本地）** — `OLLAMA_BASE_URL`

使用 `OPENCLAW_PRIMARY_MODEL` 设置默认模型。


<Callout type="info" title="代理供应商的模型命名规则">

使用 **OpenRouter** 或 **OpenCode** 等代理供应商时，必须在模型名前加上供应商路径前缀。例如：

- **OpenRouter**：`OPENCLAW_PRIMARY_MODEL=openrouter/google/gemini-2.5-flash`
- **OpenCode**：`OPENCLAW_PRIMARY_MODEL=opencode/google/gemini-2.5-flash`

只写 `google/gemini-2.5-flash` 而不带供应商前缀是无法使用的。请始终使用完整的 `provider/model` 路径。

</Callout>


### 基于订阅的身份验证

如果你订阅了 **Anthropic**（Claude）或 **OpenAI**（Codex），可以使用它们的 CLI 登录流程完成身份验证，而无需 API 密钥。在 OpenClaw 容器中打开终端并运行：

**Anthropic**（Claude）：

```bash
openclaw models auth login --provider anthropic
```

**OpenAI**（Codex）：

```bash
openclaw models auth login --provider openai
```

也可以使用上手引导向导，以交互方式完成认证配置：

```bash
openclaw onboard
```

可以用以下命令验证认证状态：

```bash
openclaw models status
```

支持的供应商与配置选项的完整列表，请参阅 [GitHub 仓库](https://github.com/coollabsio/openclaw?utm_source=coolify.io)。

## 浏览器

`/browser` 端点会打开一个由 OpenClaw 通过 Chrome DevTools Protocol（CDP）控制的远程浏览器。这适用于 OAuth 流程、2FA、验证码处理以及需要登录态的网页抓取。

浏览器会话通过专用卷持久保存，重启后依然有效。可以使用以下环境变量配置浏览器：

- `BROWSER_DEFAULT_PROFILE` — 浏览器配置文件的名称（默认：`openclaw`）
- `BROWSER_SNAPSHOT_MODE` — 快照模式（默认：`efficient`）
- `BROWSER_EVALUATE_ENABLED` — 是否启用 JavaScript 求值（默认：`true`）
