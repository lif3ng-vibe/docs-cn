## Dozzle 是什么？

Dozzle 是一个由 Docker OSS 赞助的开源项目，是一款旨在简化容器监控与调试的日志查看器。这款轻量级的 Web 应用通过直观的界面提供实时日志流式传输、过滤与搜索能力。

用户可以快速查看 Docker 容器产生的日志，因此它是 Docker 环境下调试与排查应用问题的得力工具。默认情况下，Dozzle 支持 JSON 日志，并进行智能配色标注。

Dozzle 安装配置都很简单，对于希望为 Docker 环境配备一款高效、易用的日志查看器的开发者和系统管理员而言，它是理想之选。该工具基于 MIT 许可证发布，由开发者 Amir Raminfar 持续维护。

## 部署变体

Dozzle 在 Coolify 中提供两种部署配置：

### Dozzle（默认）
- **身份验证：** 无身份验证（开放访问）
- **适用场景：** 开发环境、可信网络或单用户场景
- **组件：** 单个 Dozzle 容器，可访问 Docker socket

### 带身份验证的 Dozzle
- **身份验证：** 内置身份验证，支持用户管理
- **适用场景：** 生产环境、多用户访问或对安全敏感的部署
- **组件：**
  - 启用身份验证的 Dozzle 容器
  - 用户凭据管理
  - Docker socket 访问
