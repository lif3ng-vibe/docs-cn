## Drupal 是什么

Drupal 是一款免费开源的 Web 内容管理系统，使用 PHP 编写，基于 GNU 通用公共许可证（GNU GPL）发布。

## 部署变体

- **Drupal with PostgreSQL：**附带一个 PostgreSQL 数据库。
