# Elasticsearch

<ZoomImage src="/docs-cn/coolify/images/services/elasticsearch-logo.svg" alt="ElasticSearch" />

## Elasticsearch 是什么？

Elasticsearch 是一款开源的搜索与分析引擎，专为快速、可扩展的数据检索而设计，非常适合处理海量结构化与非结构化数据。

## 如何在 Coolify 上部署 Elasticsearch

在 Coolify 上部署 Elasticsearch 有两种方式：

- **Elasticsearch 独立部署**（无图形界面）
- **Elasticsearch 搭配 Kibana**（图形界面）

---

## Elasticsearch 独立部署

1. 在 Coolify 上新建一个资源，并从服务列表中选择 **Elasticsearch with Kibana**。
2. 点击 **Deploy（部署）** 按钮，拉取 Docker 镜像并启动容器。
3. 待 `Elasticsearch` 服务显示为健康状态后，即可通过分配给它的域名访问。
   > ⚠️ 注意：此版本不包含图形界面——你需要通过 CLI 工具或 API 与之交互。

---

## 部署 Elasticsearch with Kibana

1. 在 Coolify 上新建一个资源，并从服务列表中选择 **Elasticsearch with Kibana**。
2. 点击 **Deploy（部署）** 按钮，拉取 Docker 镜像并启动容器。
3. 待 `Elasticsearch` 服务开始运行、且 `Kibana Token Generator` 显示 **exited**（已退出）状态后：
   - 打开 `Kibana Token Generator` 服务的日志。
   - 从日志中复制 **Service Token**（服务令牌）。
   - 将令牌粘贴到 `ELASTICSEARCH_SERVICEACCOUNTTOKEN` 环境变量中。
   - 重启服务（点击 **Restart（重启）** 按钮）。
4. 待 `Elasticsearch` 和 `Kibana` 两个服务都健康运行后，访问分配给该服务的域名。
   - 你会看到 Elastic 的登录页面。
   - **用户名：** `elastic`  
     **密码：** `SERVICE_PASSWORD_ELASTICSEARCH` 环境变量的值。

如果以上步骤有不清楚的地方，可以参考[这个 Pull Request](https://github.com/coollabsio/coolify/pull/6470)，其中包含整个部署过程的视频演示。

---

### Elasticsearch with Kibana 注意事项

1. 所有服务完全启动可能需要 **2 分钟**以上（取决于服务器性能）。
2. JVM 堆大小默认设为 **512MB**，以防止 Elasticsearch 耗尽服务器内存。
   > 如需调大该值，请修改 Docker Compose 文件中的环境变量：  
   > `ES_JAVA_OPTS=-Xms512m -Xmx512m`。
3. `Kibana Token Generator` 服务的设计就是**运行一次后即退出**。这是预期行为，不会影响 Elastic 或 Kibana 服务的健康状态。
4. 通过 `discovery.type=single-node` 环境变量，集群功能**默认处于禁用状态**。
   > 如果需要集群功能，请修改此项设置。
