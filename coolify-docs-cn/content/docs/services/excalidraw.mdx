## Excalidraw 是什么？

Excalidraw 是一块用于绘制手绘风图示的虚拟白板。它是一款协作式绘图工具，让你画出的图表带有手绘质感。Excalidraw 非常适合线框图、头脑风暴、绘制流程图以及协作设计讨论。它支持实时协作，可导出多种格式，界面直观，让数字绘图拥有自然的手写感受。
