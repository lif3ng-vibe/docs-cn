## Plex 是什么？

Plex 几乎可以在任何设备上使用，也是唯一一个将免费广告支持的电影、剧集与直播电视集于一身的流媒体平台。

## 安装

1. 在 Coolify 中创建该服务。
2. 在启动服务之前，先设置 `PLEX_CLAIM` 变量。你可以在这里获取 claim 令牌：https://plex.tv/claim
3. 如果你的设备支持，可以在 compose 文件中取消以下部分的注释来启用硬件转码：

```yaml
#devices:
# - "/dev/dri:/dev/dri"
```
