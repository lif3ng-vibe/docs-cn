# KaraKeep

<ZoomImage src="/docs-cn/coolify/images/services/karakeep-logo.svg" alt="Karakeep 仪表盘" />

## KaraKeep 是什么？

KaraKeep 是一款可自托管的全能书签应用，支持基于 AI 的自动打标签。它是一个功能齐全的「稍后阅读」服务，可作为 Pocket 或 Omnivore 的替代品。KaraKeep 能借助 AI 自动对保存的内容进行分类和打标签，让你轻松整理并重新发现想留待日后查看的文章、视频及其他网页内容。
