# Flowise

<ZoomImage src="/docs-cn/coolify/images/services/flowise.jpg" alt="Flowise 仪表盘" />

## Flowise 是什么

Flowise 是一款开源低代码工具，开发者可以用它构建自定义的 LLM 编排流程和 AI 代理。

## 部署变体

Flowise 在 Coolify 中提供两种部署配置：

### Flowise（默认）
- **数据库：** SQLite（内嵌）
- **适用场景：** 简单部署、测试或个人 AI 工作流开发
- **组件：** 单个 Flowise 容器，内置 SQLite 数据库

### Flowise 搭配数据库
- **数据库：** PostgreSQL + Redis
- **适用场景：** 需要更好性能、缓存和可扩展性的生产部署
- **组件：**
  - Flowise 容器
  - 用于数据持久化的 PostgreSQL 容器
  - 用于缓存和会话管理的 Redis 容器
  - 自动配置数据库并进行健康检查
