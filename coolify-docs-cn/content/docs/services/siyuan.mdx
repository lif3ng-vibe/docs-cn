<ZoomImage src="/docs-cn/coolify/images/services/siyuan.svg" alt="Siyuan logo" />

## Siyuan 是什么？

Siyuan 是一套隐私优先的个人知识管理系统，既支持完全离线使用，也支持端到端加密的数据同步。它基于 TypeScript 和 Golang 构建，采用独特的块（block）式笔记方法，将大纲的灵活性与双向链接的强大能力结合在一起。

该平台让你用相互连接的块来组织想法与信息，轻松搭建一个完整的个人知识库。凭借本地优先存储、端到端加密和跨平台同步等特性，Siyuan 保证你的数据在所有设备上都保持私密且随时可用。
