# GitHub Runner

<ZoomImage src="/docs-cn/coolify/images/services/githubrunner-logo.png" alt="GitHub Runner 仪表盘" />

## GitHub Runner 是什么？

GitHub Runner 是 GitHub Actions 的自托管运行器，让你可以在自己的基础设施上运行 CI/CD 工作流。这套基于 Docker 的方案对执行环境有更强的掌控力，为私有仓库提供更好的安全性，面对高负载任务时也可能更具成本效益。它支持为多个仓库和组织运行工作流。
