# Calibre Web Automated with Downloader 是什么

<ZoomImage src="/docs-cn/coolify/images/services/calibre-web-automated-with-downloader.png" alt="Calibre Web Automated 标志" />

## Calibre Web Automated

Calibre 虽然在其时代是一款出色的工具，但容器化后会暴露出几个问题：UI 依赖 KasmVNC 服务器实例，在移动设备上几乎没法用；如果你像我一样运行的是小型低功耗服务器，它也相对比较吃资源。

### 相关链接

- [GitHub](https://github.com/crocodilestick/Calibre-Web-Automated)

## Downloader

一个用于搜索和请求下载图书的直观网页界面，与 Calibre-Web-Automated 无缝协作。该项目简化了图书下载流程，并为导入你的 Calibre 书库做好准备。
