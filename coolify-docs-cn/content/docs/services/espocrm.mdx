## EspoCRM 是什么？

EspoCRM 是一套开源客户关系管理（CRM）系统，可将销售、营销和客户支持集中在一处管理。它轻量灵活，让组织对自己的数据拥有完全掌控。

适用场景：

* 管理线索、联系人和销售管道
* 通过工作流自动化业务流程
* 跟踪客户沟通与活动
* 处理支持工单与服务请求
* 生成报表与分析，洞察业务状况
* 与电子邮件及第三方服务集成

## 为什么选择 EspoCRM？

* **开源且透明**。EspoCRM 是开源软件，你可以审查代码，确切了解自己的数据是如何被处理的。
* **高度可定制**。你可以添加自定义实体、字段、关系和按钮，让自己的工作流得到完整匹配。EspoCRM 既可以作为 CRM 使用，也可以作为构建自定义业务应用的平台。
* **界面简洁、响应迅速**。UI 清爽且易于导航，帮助团队快速上手。
* **易于集成**。EspoCRM 提供简单直接的 REST API，便于连接外部工具和服务。
