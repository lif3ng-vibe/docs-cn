# Supertokens

<ZoomImage src="/docs-cn/coolify/images/services/supertokens.png" alt="Supertokens 仪表盘" />

## Supertokens 是什么

一套开源身份验证方案，为 Web 与移动应用简化安全用户认证与会话管理的实现。

## 部署变体

SuperTokens 在 Coolify 中提供两种部署配置：

### 基于 MySQL 的 SuperTokens
- **数据库：** MySQL
- **适用场景：** 偏好 MySQL 的生产部署
- **组件：**
  - SuperTokens 容器
  - MySQL 容器
  - 自动数据库配置与健康检查

### 基于 PostgreSQL 的 SuperTokens
- **数据库：** PostgreSQL
- **适用场景：** 偏好 PostgreSQL 的生产部署
- **组件：**
  - SuperTokens 容器
  - PostgreSQL 容器
  - 自动数据库配置与健康检查

两种变体功能完全等价——根据你的数据库偏好或现有基础设施来选择即可。
