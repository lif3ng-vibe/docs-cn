## OpenPanel 是什么？

OpenPanel 是 Mixpanel 与 Plausible 的开源产品分析替代方案。它提供以隐私为核心的分析能力，深入洞察用户行为、事件与转化。OpenPanel 支持实时分析、自定义事件追踪、漏斗分析和用户分群，在尊重用户隐私的同时，让你完全掌控自己的数据。
