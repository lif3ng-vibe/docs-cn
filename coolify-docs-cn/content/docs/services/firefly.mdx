## Firefly III 是什么？

"Firefly III" 是一款（自托管的）个人财务管理工具。它帮助你跟踪支出与收入，从而花得更少、攒得更多。Firefly III 支持预算、分类和标签，还可以借助多种外部工具导入数据，并内置了大量实用的财务报表。

Firefly III 应该让你看清并掌控自己的财务。钱应该是好用的，而不是可怕的。你应该知道自己把钱花在了哪里，能感受到每一笔支出的去向……哇，我是不是说得有点过头了？

但你明白意思就好：这是你的钱，这些是你的支出，别再让它们反过来控制你。我做这个工具，是因为我开始讨厌钱了——有钱也好，没钱也罢，用钱付账单等等，你懂的。但我不想再这样。无论余额多少，我都想感到"安心"。希望这个工具也能帮到你，我知道它帮了我。
