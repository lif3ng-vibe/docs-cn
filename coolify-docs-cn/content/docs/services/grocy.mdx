## Grocy 是什么？

Grocy 是一款基于 Web 的自托管食品杂货与家务管理方案。
安装完成后，默认凭据为用户名：`admin`，密码：`admin`。
请务必尽快登录并在设置中编辑 `admin` 用户修改这些凭据，设置入口位于屏幕右上角。
