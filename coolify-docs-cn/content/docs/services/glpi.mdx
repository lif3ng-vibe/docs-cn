# GLPI

<ZoomImage src="/docs-cn/coolify/images/services/glpi-logo.svg" alt="GLPI (Gestionnaire Libre de Parc Informatique)" />

## GLPI 是什么

GLPI（Gestionnaire Libre de Parc Informatique）是一个免费开源的 IT 服务管理（ITSM）平台，用于 IT 资产管理、帮助台与服务台运营，帮助组织盘点软硬件、管理事件、跟踪请求，并借助 CMDB、工单和自动化等功能简化 IT 支持流程。

### 初始设置

部署模板后，GLPI 会自动完成安装流程，请预留 4~5 分钟等待其完全启动。然后你可以使用以下账号登录：

   ```bash
   # User
   glpi

   # password
   glpi
   ```
