# Engram

## Engram 是什么？

Engram 是一套面向 AI 编程代理的持久化记忆系统。它是一个与具体代理无关的 Go 二进制程序，会记录决策、约定、缺陷修复和新发现，再通过 MCP 服务器、HTTP API、CLI 和终端界面把这些记忆提供给代理。在本地，它将记忆保存在支持全文检索的 SQLite 中，让上下文得以跨会话延续，而不是随着对话结束而丢失。

这个一键模板部署的是 Engram Cloud，即运行 `engram cloud serve` 的可选复制服务器。本地的 Engram 实例会把项目记忆同步到它上面，从而让相同的记忆在多台机器之间可用，或在团队成员之间共享。该模板在运行服务器的同时还会运行一个 PostgreSQL 容器，用于存储复制过来的数据。

服务器在同一端口上同时提供仪表盘和 API。Coolify 会在部署时自动生成 API 令牌、仪表盘管理员令牌以及 JWT 签名密钥，因此整套服务启动时即已具备认证，无需手动配置。

<Callout type="info" title="项目白名单">
`ENGRAM_CLOUD_ALLOWED_PROJECTS` 默认为 `*`，即接受任何项目名称，同时访问仍由自动生成的 API 令牌把关。将它设置为逗号分隔的列表，即可把服务器限制为只服务特定项目。
</Callout>
