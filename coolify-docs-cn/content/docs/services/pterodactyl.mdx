## Pterodactyl 是什么？

Pterodactyl® 是一个用 PHP、React 和 Go 构建的免费开源游戏服务器管理面板。
Pterodactyl 以安全为核心设计，所有游戏服务器都运行在相互隔离的 Docker 容器中，同时为最终用户提供美观直观的 UI。

Pterodactyl 由两个协同工作的核心组件组成：**Panel**（Web 界面）和 **Wings**（服务器守护进程）。Panel 提供管理界面，而 Wings 负责处理每个节点上实际的游戏服务器操作。

## 当前功能

- 在单一仪表盘中管理多台服务器
- 带进程隔离的安全守护进程（Wings）
- 每台服务器均基于 Docker 容器化
- 基于 Web 的仪表盘
- 基于角色的用户权限
- 实时监控 CPU、内存和网络
- 自动完成服务器更新与备份

## Wings 是什么？

Wings 是 Pterodactyl 的服务器控制守护进程，使用 Go 编写。它运行在每台服务器节点上，处理所有游戏服务器操作，包括服务器实例的创建、管理和监控。

Wings 通过 Pterodactyl Panel 的 REST API 与之通信，接收命令和配置，同时回传实时统计信息、控制台输出和状态更新。每台游戏服务器都运行在由 Wings 管理的隔离 Docker 容器中。

核心能力：

- **服务器生命周期管理** - 启动、停止、重启和配置游戏服务器
- **Docker 容器编排** - 自动创建与隔离
- **实时监控** - 跟踪 CPU、内存、磁盘和网络使用情况
- **控制台流式传输** - 将服务器控制台输出实时传送到 Panel
- **文件管理** - 处理服务器文件、备份和计划任务
- **资源限制** - 为每个容器设置 CPU 和内存上限

## 在 Coolify 上安装

Coolify 为 Pterodactyl 提供两种部署选项：面向单服务器场景的 Panel + Wings 合并模板，或面向分布式架构的分开部署。

### 选项 1：Pterodactyl 搭配 Wings（合并模板）

最适合 Panel 与 Wings 运行在同一台服务器上的单服务器部署。

1. 从 **Coolify** 安装最新的 **Pterodactyl With Wings** 模板。
2. 部署该模板。
3. 访问面板 URL，使用管理员凭据登录。
4. 进入 **Admin Panel → Locations**（管理面板 → 位置），创建一个新位置（例如 `us`、`eu` 等）。
5. 创建一个新节点，并配置以下字段：

   - **FQDN** → `wings-abc1abc2abc3abc4.example.com`（不带 `http://` 或 `https://`）
   - **Communicate Over SSL** → 已启用（除非你清楚自己在做什么，否则不要改动）
   - **Daemon Port** → `443`（重要！Coolify 会自动将端口 `443` 转发到 `8443`）

<ZoomImage src="/docs-cn/coolify/images/services/pterodactly-with-wings1.png" alt="节点设置示例" />

6. 进入节点的配置标签页，并**保存配置**到安全的位置。

<ZoomImage src="/docs-cn/coolify/images/services/pterodactly-with-wings2.png" alt="配置文件示例" />

7. 在 Coolify 中进入 **Persistent Storages**（持久化存储），找到 `config.yml`。
   将以下值替换为你保存的配置中的对应值：

   - `uuid`
   - `token_id`
   - `token`
   - `api > ssl > cert`
   - `api > ssl > key`

8. 在 `allowed_origins` 下更新面板域名，使其与实际的面板域名一致。

9. 等待大约 3–5 分钟让 Wings 重启。
   如果配置成功，节点的 **About** 部分应显示你的守护进程（Daemon）版本及其他信息。

10. 现在面板已经可以使用了。

### 选项 2：分开安装 Panel 与 Wings

最适合 Wings 节点与 Panel 分布在不同服务器上的分布式部署。

在 Coolify 中单独安装 **Wings** 并使用反向代理时，不能让它直接监听容器内的 `443` 端口。
正确的做法是将其配置为内部使用 `8443` 端口，由 Coolify 把 `443` 转发到 `8443`。
**Pterodactyl Panel** 对外仍应配置为使用 `443` 端口。

**步骤**：

1. **在 Panel 中生成 Wings 配置**
   - 在 Pterodactyl Panel 中创建一个节点，并下载 `config.yml`。
   - 按以下方式配置节点：
     - **Hostname**（例如 `host.example.com`，不带 `https://`）——不要填 IP 地址
     - **Port**（端口）：`443`
     - **启用代理设置**

2. **在 Coolify 中更新配置**
   - 在 Coolify 的 Wings 服务中，打开 **Persistent Storages**（持久化存储）标签页。
   - 你会看到 `/etc/pterodactyl/config.yml` 已经存在，内容是默认模板。
   - 直接编辑它，将占位符替换为 Panel 生成的文件中的值。
   - 将 `api.port` 改为 `8443`：
     ```yaml
     api:
       host: 0.0.0.0
       port: 8443
     ```

3. **重启 Wings**
   - 保存更改后，重启 Wings 容器以应用新设置。

## 常见问题

**节点无法连接**
- 确保节点在 Panel 中配置为使用 `443` 端口。
- 确认 Wings 在使用 Coolify 反向代理时已配置为内部使用 `8443` 端口。

**无法访问节点上的服务器**
- 确认你已在 Wings 配置的 `allowed_origins` 中添加面板域名。
