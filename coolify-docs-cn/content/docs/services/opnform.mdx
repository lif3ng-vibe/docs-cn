# OpnForm

<img src="/docs-cn/coolify/images/services/opnform.svg" alt="OpnForm" />

## OpnForm 是什么？

OpnForm 是一款开源表单构建工具，对开发者和普通用户同样友好。创建精美的表单并随处分享——速度飞快，而且无需任何编程知识。免费即可上手，表单、字段和提交数量均不设限。

## 功能特性

- 拖拽式表单构建
- 自定义主题与品牌
- 条件逻辑
- 文件上传
- 表单分析
- 邮件通知
- 自定义域名
- 无需编程
