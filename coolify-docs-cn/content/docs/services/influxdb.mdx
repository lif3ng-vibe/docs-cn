# InfluxDB

<ZoomImage src="/docs-cn/coolify/images/services/influxdb.svg" alt="InfluxDB logo" />

## InfluxDB 是什么？

InfluxDB 是一款专为存储和分析带时间戳数据而打造的开源时序数据库，常用于监控、可观测性、物联网应用以及实时分析场景。

## 功能特性

- 针对时序数据优化
- 高性能数据写入
- 支持 InfluxQL 与 Flux 查询
- 提供 REST API
- 可与 Grafana、Telegraf、Prometheus 集成
