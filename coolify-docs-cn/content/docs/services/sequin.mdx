<ZoomImage src="/docs-cn/coolify/images/services/sequin-logo.svg" alt="Sequin 仪表盘" />

## Sequin 是什么？

Sequin 是目前最快速的 Postgres 变更数据捕获（CDC）方案，帮助你把 PostgreSQL 数据库中的数据实时同步到其他系统。它捕获数据库变更并将变更流式发送到各类目的地，非常适合构建事件驱动架构、跨服务保持数据一致性，以及搭建实时分析管道。
