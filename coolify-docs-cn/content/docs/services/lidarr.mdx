## Lidarr 是什么？

Lidarr 是一款音乐收藏管理工具，帮你关注心水艺人、发现新专辑并整理自己的音乐库。它可以搜索音乐发行版，并将其推送到已配置的 Usenet 或 BitTorrent 下载客户端。
