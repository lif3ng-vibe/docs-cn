<ZoomImage src="/docs-cn/coolify/images/services/ntfy-logo.svg" alt="Ntfy 仪表盘" />

## Ntfy 是什么

ntfy 是一个简单易用的基于 HTTP 的发布/订阅通知服务。你可以通过脚本和/或 REST API，从任何计算机向手机或桌面发送通知。
