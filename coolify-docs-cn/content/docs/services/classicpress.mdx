## ClassicPress 是什么?

ClassicPress 是一个由社区主导、面向创作者的开源内容管理系统。它从 WordPress 6.2 分叉而来,默认保留 TinyMCE 经典编辑器。体积只有 WordPress 的一半,削减了冗余以提升性能,并且没有区块编辑器(Gutenberg/全站编辑)。

## 部署变体

- **ClassicPress + MariaDB:** 包含一个 MariaDB 数据库。
- **ClassicPress + MySQL:** 包含一个 MySQL 数据库。
- **ClassicPress(不含数据库):** 使用你另行配置的外部数据库。
