<Callout type="error" title="服务暂时停用">

由于 PHP 安全漏洞 **CVE-2026-109618** 和 **CVE-2026-109619**，该服务的一键模板在 Coolify 中暂时停用。在修复后的容器镜像完成验证之前，无法从服务目录发起新的部署。

关于现有部署的处理建议，请查看 [PHP 安全公告](/knowledge-base/php-security-advisory-2026)；详情与后续进展见[模板停用 PR](https://github.com/coollabsio/coolify/pull/12268)。

</Callout>

# Snapdrop 是什么？

一个可自托管的文件共享服务，无论在局域网还是互联网上，都能安全便捷地传输文件。
