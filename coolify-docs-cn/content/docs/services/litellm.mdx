# Litellm 是什么？

<ZoomImage src="/docs-cn/coolify/images/services/litellm1.avif" alt="Litellm 仪表盘" />

LiteLLM 是一个开源 LLM 网关，可用于统一管理 100 多个 LLM 的身份验证、负载均衡与开销追踪，全部采用 OpenAI 格式。
