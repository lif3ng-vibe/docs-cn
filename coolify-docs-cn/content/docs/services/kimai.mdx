由于 PHP 安全漏洞 **CVE-2026-109618** 和 **CVE-2026-109619**，该服务的一键模板在 Coolify 中暂时停用。在经过修复的容器镜像完成验证之前，无法从服务目录发起新的部署。

关于已有部署的处理建议，请参阅 [PHP 安全公告](/knowledge-base/php-security-advisory-2026)；详情与后续进展请查看[模板停用 PR](https://github.com/coollabsio/coolify/pull/12268)。

</Callout>
