# Ente

<ZoomImage src="/docs-cn/coolify/images/services/ente-logo.webp" alt="Ente" />

## Ente 是什么？

Ente 提供了一个完全开源的端到端加密平台，让你可以把数据存到云端，而无需信任服务提供商。在该平台之上，Ente 目前已推出两款应用：Ente Photos（Apple 和 Google Photos 的替代品）和 Ente Auth（2FA 验证器，可替代已停止维护的 Authy）。

了解更多请访问 [help.ente.io](https://help.ente.io/)。

## 配置对象存储

- 选择好服务后，你需要为 S3 存储桶或 MinIO 等替代品设置一些环境变量。

### 1. 远程 S3 存储桶

- 对于 AWS S3，你可以创建一个存储桶，并通过 IAM 角色/用户权限授予访问权。这会为你的 S3 存储桶生成访问密钥（access key）和秘密密钥（secret key）。

- 为 S3 存储桶应用以下 CORS 策略，以便 museum 服务正确进行访问控制。

```json
[
  {
    "AllowedOrigins": ["*"],
    "AllowedHeaders": ["*"],
    "AllowedMethods": ["GET", "HEAD", "POST", "PUT", "DELETE"],
    "MaxAgeSeconds": 3000,
    "ExposeHeaders": ["Etag"]
  }
]
```

- 填入 `endpoint`、`region`、`bucket`、`access key`、`secret key` 等凭据信息。

- 部署服务后即可开始使用。

### 2. Coolify 的 MinIO 存储桶

- MinIO 需要通过 HTTPS 对外暴露，依赖 SSL/TLS，因此请确保代理配置正确。这里有一份关于安装与配置的实用[教程](https://selfhostschool.com/minio-self-hosted-s3-storage-guide/)。

- 从 Coolify 部署 MinIO 服务后，你可以通过控制台 URL 登录该服务，使用与环境变量中设置相同的用户名和密码；后端或 shell 场景则使用 API URL。

```bash
# Set Alias
mc alias set <alias> <API_ENDPOINT> <ACCESS_KEY> <SECRET_KEY>

# List buckets (same us used in coolify to validate S3)
minio/mc ls myminio
```

- 登录后，创建一个供 Ente 使用的存储桶。

- MinIO 的默认区域（region）为 `us-east-1`，直接使用它即可。

- 在 Ente 配置中，将 API 端点用作存储桶端点。

**注意**：更多细节请参见[这里](https://help.ente.io/self-hosting/administration/object-storage)。

## 环境变量

| 变量名                                | 服务     | 说明                                                                                        | 默认值             | 必填 | 预填      |
| ------------------------------------- | -------- | ------------------------------------------------------------------------------------------- | ------------------ | -------- | --------- |
| `SERVICE_URL_MUSEUM_8080`             | museum   | museum 服务在 8080 端口上的 URL                                                             | -                  | 是       | 是        |
| `ENTE_HTTP_USE_TLS`                   | museum   | 启用/禁用 HTTP 连接的 TLS                                                                   | `false`            | 否       | 是        |
| `SERVICE_URL_WEB_3002`                | museum   | Web 相册服务的 URL                                                                          | -                  | 是       | 是        |
| `SERVICE_URL_WEB_3004`                | museum   | Web 投屏（cast）服务的 URL                                                                  | -                  | 是       | 是        |
| `SERVICE_URL_WEB_3001`                | museum   | Web 账户服务的 URL                                                                          | -                  | 是       | 是        |
| `ENTE_DB_HOST`                        | museum   | PostgreSQL 数据库主机                                                                       | `postgres`         | 否       | 是        |
| `ENTE_DB_PORT`                        | museum   | PostgreSQL 数据库端口                                                                       | `5432`             | 否       | 是        |
| `ENTE_DB_NAME`                        | museum   | PostgreSQL 数据库名称                                                                       | `ente_db`          | 否       | 是        |
| `SERVICE_USER_POSTGRES`               | museum   | PostgreSQL 数据库用户名                                                                     | `pguser`           | 否       | 是        |
| `SERVICE_PASSWORD_POSTGRES`           | museum   | PostgreSQL 数据库密码                                                                       | -                  | 是       | 是        |
| `SERVICE_REALBASE64_ENCRYPTION`       | museum   | Base64 编码的加密密钥                                                                       | -                  | 是       | 是        |

| `PRIMARY_STORAGE_ARE_LOCAL_BUCKETS`   | museum   | 主存储使用本地存储桶（除非通过 http 连接存储桶，否则为 false）                              | `false`            | 否       | 是        |

| `S3_STORAGE_KEY`                      | museum   | S3 存储访问密钥                                                                             | -                  | 是       | 否        |
| `S3_STORAGE_SECRET`                   | museum   | S3 存储秘密密钥                                                                             | -                  | 是       | 否        |
| `S3_STORAGE_ENDPOINT`                 | museum   | S3 存储端点 URL                                                                             | -                  | 是       | 否        |
| `S3_STORAGE_REGION`                   | museum   | S3 存储区域                                                                                 | `us-east-1`        | 否       | 是        |
| `S3_STORAGE_BUCKET`                   | museum   | S3 存储桶名称                                                                               | -                  | 是       | 否        |
| `SERVICE_URL_WEB_3000`                | web      | 主 Web 服务的 URL                                                                           | -                  | 是       | 是        |
| `SERVICE_URL_MUSEUM`                  | web      | museum 服务的 URL                                                                           | -                  | 是       | 是        |
| `SERVICE_URL_WEB_3002`                | web      | 相册服务的 URL                                                                              | -                  | 是       | 是        |
| `SERVICE_USER_POSTGRES`               | postgres | PostgreSQL 用户名                                                                           | `pguser`           | 否       | 是        |
| `SERVICE_PASSWORD_POSTGRES`           | postgres | PostgreSQL 密码                                                                             | -                  | 是       | 是        |
| `SERVICE_DB_NAME`                     | postgres | PostgreSQL 数据库名称                                                                       | `ente_db`          | 否       | 是        |
