## GoWa 是什么？

GoWa（Golang WhatsApp）是一款使用 Go 构建的 WhatsApp Web API 服务，内存占用高效、性能出色。它支持多设备，并允许你通过 REST API 将 WhatsApp 功能集成到自己的应用中。GoWa 设计轻量且易于扩展，非常适合需要 WhatsApp 自动化与集成能力的企业。
