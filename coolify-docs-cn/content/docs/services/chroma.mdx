## Chroma 是什么?

Chroma 是一款开源、AI 原生的向量数据库,专为基于 embedding 构建应用而设计。它为机器学习应用——尤其是涉及大语言模型(LLM)与语义搜索的场景——提供了存储、检索和搜索向量 embedding 的简单途径。Chroma 替你搞定向量运算、相似度搜索与元数据过滤这些复杂工作,因此特别适合检索增强生成(RAG)系统及其他 AI 应用。
