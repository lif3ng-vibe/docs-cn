## Forgejo 是什么？

Forgejo 是一个可自托管的轻量级软件 forge（代码托管协作平台），安装简单、维护省心，一门心思把事情做好。

## 部署变体

Forgejo 在 Coolify 中提供四种部署配置：

### Forgejo（默认）
- **数据库：** SQLite（内嵌）
- **适用场景：** 简单部署、测试或个人 Git 托管
- **组件：** 单个 Forgejo 容器，内置 SQLite 数据库

### Forgejo 搭配 PostgreSQL
- **数据库：** PostgreSQL
- **适用场景：** 需要更好性能和可扩展性的生产部署
- **组件：**
  - Forgejo 容器
  - PostgreSQL 容器
  - 自动配置数据库并进行健康检查

### Forgejo 搭配 MySQL
- **数据库：** MySQL
- **适用场景：** 偏好 MySQL 的生产部署
- **组件：**
  - Forgejo 容器
  - MySQL 容器
  - 自动配置数据库并进行健康检查

### Forgejo 搭配 MariaDB
- **数据库：** MariaDB
- **适用场景：** 偏好 MariaDB 的生产部署
- **组件：**
  - Forgejo 容器
  - MariaDB 容器
  - 自动配置数据库并进行健康检查

## SSH 访问

基于 SSH 的 Git 操作需要占用服务器上的一个端口，因为代理只按域名转发 HTTP 和 HTTPS。默认端口为 `22222`，Forgejo 会在 SSH 克隆 URL 中显示它。

如果要在同一台服务器上运行多个 Forgejo 实例，请为每个实例将 `FORGEJO_SSH_PORT` 环境变量设置为一个空闲端口，然后重新部署。通过 HTTPS 克隆则始终可以经由域名使用。

## Forgejo Actions Runner

Forgejo 提供了第一方的 "actions runner"（动作运行器），可[在仓库上执行任务作业](https://forgejo.org/docs/latest/user/actions/)，与 [GitHub Actions](https://docs.github.com/en/actions) 或 [GitLab CI](https://docs.gitlab.com/ee/ci/index.html) 十分相似。

Coolify 提供的 Forgejo 服务内置单个 runner，使用 [Docker-in-Docker](https://hub.docker.com/_/docker) 来运行作业。与上面的变体一样，这些服务可选择 SQLite、PostgreSQL、MySQL 和 MariaDB。

部署完成后 runner 即可使用，无需任何手动设置：

- Coolify 会生成 runner 注册所需的共享密钥（`SERVICE_HEX_64_RUNNER`）。
- Forgejo 的安装会自动完成。使用 `SERVICE_USER_ADMIN` 和 `SERVICE_PASSWORD_ADMIN` 环境变量中的管理员凭据登录。如需修改管理员邮箱，可在首次部署前设置 `FORGEJO_ADMIN_EMAIL`。
- 作业可以使用 `docker`（Node.js 22）、`ubuntu-latest` 和 `ubuntu-22.04` 这些标签，也可以使用 Docker 命令，例如构建镜像。

Forgejo 也兼容第三方 CI 应用和平台。由于 Forgejo 是 Gitea 的分支，接入这些 CI 的方法对两者可能同样适用。
