# Soju

<ZoomImage src="/docs-cn/coolify/images/services/soju-logo.svg" alt="Soju logo" />

## Soju 是什么？

Soju 是一款对用户友好的 IRC bouncer（保持在线的中转服务）。Soju 以用户的名义连接上游 IRC 服务器，从而提供额外功能。它支持众多特性，例如多用户、大量 IRCv3 扩展、聊天记录回放和离线频道（detached channels）。无论小型还是大型部署，它都得心应手。
