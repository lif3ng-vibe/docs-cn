# Superset

<ZoomImage src="/docs-cn/coolify/images/services/superset-logo.svg" alt="Superset logo" />

## Superset 是什么？

Superset 是一个现代化的数据探索与数据可视化平台。对许多团队而言，Superset 可以替代或增强专有的商业智能工具。Superset 能与多种数据源良好集成。

## 变体

- **Superset with PostgreSQL：** 包含 PostgreSQL 和 Redis。

## 非官方 Docker 镜像

Superset [不支持在生产环境中使用 Docker Compose](https://superset.apache.org/admin-docs/installation/docker-compose/)。Coolify 的 Superset 模板使用的是 [amancevice 制作的第三方非官方 Docker 镜像](https://github.com/amancevice/docker-superset)。

## 使用方法

### 初始设置

部署模板后，你需要初始化数据库并创建管理员用户。操作如下：

1. 打开一个连接到 Superset Docker 容器的终端会话。

2. 运行下面的命令之一，注意 `-` 符号：

   ```bash
   # Basic initialisation
   superset-init

   # Alternatively, to also load demo data, use
   superset-demo
   ```

   这些脚本的源码可在[这里](https://github.com/amancevice/docker-superset/tree/main/bin)查看。

3. 按照提示完成设置。

你可以在 [Coolify GitHub 仓库的 pull request #4891](https://github.com/coollabsio/coolify/pull/4891) 中找到这一过程的视频演示。

### 连接 Coolify 网络上的其他数据库

要连接托管在 Coolify 上、但在 Superset 服务模板之外的数据库，请启用 [Connect To Predefined Network](/applications/builds/docker-compose#connect-to-predefined-networks)（连接到预定义网络），并使用数据库的内部主机名和端口进行连接。

为了实现网络隔离，你可以[创建一个独立的目标（Destination）](/core/networking/destinations/create)，把 Superset 和它需要的数据库都部署到该目标上。即便如此，你仍需为 Superset 启用 **Connect To Predefined Network**（连接到预定义网络）：服务栈默认使用自己的网络。共享网络上的容器使用自动生成的名称，因此请核实数据库的实际主机名，不要想当然地使用 `postgres` 这类通用名称。

### 配置 Superset

如何调整 `superset_config.py`，请参阅[官方文档](https://superset.apache.org/docs/configuration/configuring-superset)。

这个 Python 配置文件可以在服务的 **Persistent Storages**（持久化存储）页面中编辑。文件编辑方式与大小限制请阅读 [File Mounts](/core/persistent-storage/storage-mounts/file-mounts)。
