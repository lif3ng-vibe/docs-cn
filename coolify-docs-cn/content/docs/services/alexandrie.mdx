<ZoomImage src="/docs-cn/coolify/images/services/alexandrie.webp" alt="Alexandrie 界面" />

## Alexandrie 是什么？

Alexandrie 是一款自托管 Markdown 笔记应用，为速度、离线使用与长期知识管理而生。  
它专注于速度与设计，支持在大型笔记集合中快速导航，并在文档之间建立明确的链接。

## 功能特性

- 支持实时预览的 Markdown 编辑器
- 快速全文搜索、基于标签的组织方式与层级结构
- 可从容管理数百份文档的高级管理功能
- 基于 Docker 的简单部署
