# Open Archiver

<ZoomImage src="/docs-cn/coolify/images/services/openarchiver-logo.svg" alt="Open Archiver 标志" />

## Open Archiver 是什么？

Open Archiver 是一个安全的自托管邮件归档解决方案，完全开源。这款邮件归档工具支持对邮件和附件进行全文检索，可从 Google Workspace、Microsoft 365 以及任何 IMAP 服务器建立永久、可检索且合规的邮件归档。
