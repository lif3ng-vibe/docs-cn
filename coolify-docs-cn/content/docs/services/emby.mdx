## Emby 是什么？

Emby 是一款免费的个人媒体服务器，基于众多流行的开源技术构建。

## 系统要求

Windows、Mac、Linux 或 FreeBSD 计算机

### 最低配置——无需转码

- Intel Core 2 Duo 处理器，主频 1.6 GHz 或更高
- Windows/Mac OS X 至少 1GB 内存
- Linux 至少 512MB 内存
- Windows：Vista 或更高版本
- OS X：MacOS 10.13 或更高版本
- Ubuntu、Debian、Fedora、CentOS 或 SuSE Linux

### 推荐配置——转码高清内容

- Intel Core 2 Duo 处理器，主频 2.4 GHz 或更高
- 如果要为多台设备转码，可能需要更快的 CPU
- 至少 2GB 内存
- Windows：Vista 或更高版本
- OS X：MacOS 10.13 或更高版本
- Ubuntu、Debian、Fedora、CentOS 或 SuSE Linux
