## Penpot 是什么？

Penpot 是一款开源的设计与原型工具，帮助团队创建精美的交互式原型，并实现无缝协作。

## 部署变体

- **Penpot**：将上传的资源存储在本地卷中。
- **Penpot with S3**：包含一个兼容 S3 的存储服务，用于存放上传的资源。
