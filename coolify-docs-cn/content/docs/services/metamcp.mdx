## MetaMCP 是什么？

MetaMCP 是一个 MCP 聚合器/编排器，可让你把多个 MCP 服务器归组到命名空间（namespace）中、应用中间件，并对外暴露一个统一端点。它支持 SSE 和 Streamable HTTP 传输（还支持 OpenAPI），兼容主流 MCP 客户端，旨在简化工具的组装，并托管在 API 密钥或 OAuth 访问控制之后。
