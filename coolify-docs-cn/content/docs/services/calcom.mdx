## Calcom 是什么

面向所有人的日程安排基础设施。

## 在 x86（amd64）上部署

要让 cal.com 在 x86（amd64）上正常运行，需要把默认的 Docker Compose 改成如下形式：

```yaml
services:
  calcom:
    image: 'calcom/cal.com:<VERSION compatible with amd64>
    platform: linux/amd64
    (... same ...)
```

最新的 amd64 兼容版本可在[这里](https://hub.docker.com/r/calcom/cal.com/tags)查看。

示例：

```yaml
services:
  calcom:
    image: 'calcom/cal.com:v5.9.0
    platform: linux/amd64
    (... same ...)
```
