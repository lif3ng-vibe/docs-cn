# PingvinShare


<Callout type="error" title="服务已从 Coolify 移除">

由于原作者已停止维护，该服务已从 Coolify 的一键服务目录中移除。项目归档的更多信息请见[这里](https://github.com/stonith404/pingvin-share?tab=readme-ov-file#%EF%B8%8F-project-archived)

我们仍保留着该服务最后一个已知可用的 Docker Compose 文件，你可以按照下方的安装步骤手动部署。

</Callout>



## PingvinShare 是什么？

PingvinShare 是一个轻巧又美观的自托管文件共享平台。它让你可以通过临时链接轻松与他人共享文件，支持密码保护和过期时间，并提供简洁现代的界面。PingvinShare 旨在成为商业文件共享服务的轻量替代品，同时让你完全掌控自己的数据。

## 如何通过 Coolify 部署 PingvinShare？

由于 PingvinShare 已不再由原作者维护，全自动的一键服务安装已不可用。不过，你仍然可以按照以下步骤，轻松部署最后一个发布版本。

## 安装

1. 添加新资源，并选择 `Docker Compose Empty` 应用部署类型。
2. 将以下[文件](https://raw.githubusercontent.com/coollabsio/coolify/v4.x/templates/compose/pingvinshare.yaml)的内容（连同注释）复制到输入框中。
3. 点击 `Save` 按钮。
4. 进入 `PingvinShare` 服务的设置页面（右侧的 `Settings` 按钮）。
5. 在 `Domains` 输入框中填入你的自定义域名（也可以点击自动生成域名旁边的编辑图标来修改域名）。
6. 点击 `Save` 按钮。
7. 点击 `Deploy` 按钮，等待部署完成。
