## Docuseal 是什么?

面向每个人的文档签署工具:个人永久免费,企业与开发者可扩展。DocuSign、PandaDoc 等产品的开源替代品。

## 部署变体

Coolify 中 DocuSeal 提供两种部署配置:

### DocuSeal(默认)
- **数据库:** SQLite(内嵌)
- **适用场景:** 简单部署、测试或小批量的文档签署
- **组件:** 单个 DocuSeal 容器,内置 SQLite 数据库

### DocuSeal + PostgreSQL
- **数据库:** PostgreSQL
- **适用场景:** 对性能、可扩展性与并发访问有更高要求的生产部署
- **组件:**
  - DocuSeal 容器
  - PostgreSQL 容器
  - 自动完成数据库配置与健康检查
