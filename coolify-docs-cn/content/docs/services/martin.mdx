<ZoomImage src="/docs-cn/coolify/images/services/martin.png" alt="Martin 仪表盘" />

## Martin 是什么？

Martin 是一个瓦片服务器（tile server），能够从大型 PostGIS 数据库、PMTiles（本地或远程）以及 MBTiles 文件即时生成并提供矢量瓦片，还支持将多个瓦片源动态合并为一个。
