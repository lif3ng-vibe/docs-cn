# Homebox

<ZoomImage src="/docs-cn/coolify/images/services/homebox-logo.svg" alt="Homebox logo" />

## Homebox 是什么？

Homebox 是一款专为家庭用户打造的物品清单与整理系统。它可以为你编目和跟踪个人物品、创建存放位置与分类、管理保修和收据，并为家庭物品保留详细记录。借助照片附件、搜索功能和报表能力，Homebox 非常适合保险登记、收藏整理以及日常的家庭物品清单管理。

## 配置

要创建第一个账户，你需要前往 Homebox 的环境变量，把 `HBOX_OPTIONS_ALLOW_REGISTRATION` 设为 true，然后重启容器使更改生效。
现在你就可以创建第一个账户了。之后你可以把 `HBOX_OPTIONS_ALLOW_REGISTRATION` 重新设为 false 以阻止新注册，也可以继续保持开放，让其他用户加入你的 Homebox。
