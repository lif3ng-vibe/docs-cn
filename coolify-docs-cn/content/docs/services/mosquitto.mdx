## Mosquitto 是什么？

Mosquitto 是一个开源的 MQTT（Message Queuing Telemetry Transport，消息队列遥测传输）消息代理，通过实现轻量的 MQTT 协议来促进 IoT 设备之间的通信。它专为带宽有限或网络不稳定的场景提供可靠的消息投递，是 IoT 和家庭自动化系统的关键组件。
