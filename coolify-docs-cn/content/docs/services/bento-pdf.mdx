## BentoPDF 是什么？

为隐私而生的 PDF 工具箱。

- 无需注册
  - 即开即用，不需要账户或邮箱。

- 无需上传
  - 100% 客户端处理，文件绝不离开你的设备。

- 永久免费
  - 所有工具全部开放，没有试用限制，也没有付费墙。

- 没有限制
  - 想用多少用多少，没有隐藏上限。

- 批量处理
  - 一次性处理任意数量的 PDF。

- 极致快速
  - 即刻完成 PDF 处理，无需等待或延迟。
