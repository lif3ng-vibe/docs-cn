## 公开端口访问


<Callout type="warn" title="注意：">

数据库公开访问目前存在一个 bug，很快会修复。在此期间，你可以使用以下变通方法：

</Callout>


把 **Supabase Db** 设为公开（public）

<ZoomImage src="/docs-cn/coolify/images/services/supabase-db-fix.webp" alt="Supabase 仪表盘" />

然后

进入 **General**（常规）标签页，再点 **Edit Compose File**（编辑 Compose 文件）

然后添加这一行：
```yaml
ports:
      - ${POSTGRES_PORT:-5432}:${POSTGRES_PORT:-5432}
```
到

```yaml
supabase-db:
  image: "supabase/postgres:15.6.1.146"
  healthcheck:
    test: "pg_isready -U postgres -h 127.0.0.1"
    interval: 5s
    timeout: 5s
    retries: 10
  depends_on:
    supabase-vector:
      condition: service_healthy
  ports:
    - ${POSTGRES_PORT:-5432}:${POSTGRES_PORT:-5432}
```

然后重启

> 注意：如果你把端口整个换成了一个新端口，请同步更新环境变量中的 POSTGRES_PORT

## 使用 ufw-docker 开放端口

最后，要让外部访问 Docker 环境中的 PostgreSQL 端口，你需要用以下命令在防火墙中开放该端口：

```bash
ufw route allow proto tcp from any to any port 5432
```

这条规则确保流量可以经由 Docker 网络到达你的 PostgreSQL 数据库。更多信息请阅读 [ufw-docker](https://github.com/chaifeng/ufw-docker) 的文档。

### 使用 Hetzner 的防火墙 UI

如果你的服务器托管在 Hetzner 上，可能无需 ufw-docker。你可以直接使用 [Hetzner 的防火墙 UI](https://docs.hetzner.com/cloud/firewalls/overview) 开放相关数据库端口（例如 5432）。
