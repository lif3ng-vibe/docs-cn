# Pi-hole

<ZoomImage src="/docs-cn/coolify/images/services/pihole-logo.svg" alt="Pi-hole 仪表盘" />

## Pi-hole 是什么？

Pi-hole 是一款作用于整个网络的广告拦截器，充当 DNS 沉坑（DNS sinkhole），无需在设备上安装任何客户端软件，即可保护你的设备免受不良内容侵扰。它通过过滤 DNS 请求，在网络层面拦截广告、跟踪器与恶意软件。Pi-hole 还能提供网络 DNS 查询的详细统计分析，并在不良内容到达设备之前就将其拦截，从而显著提升浏览速度。
