# Convex

<ZoomImage src="/docs-cn/coolify/images/services/convex-logo.svg" alt="Convex 徽标" />

## Convex 是什么

Convex 是一款面向应用开发者的开源响应式数据库。

## 如何生成管理密钥

要在 Coolify 中为你的 Convex 应用生成管理密钥(admin key),请按以下步骤操作:
1. 进入 Coolify 仪表盘。
2. 选中你的 Convex 应用。
3. 打开 Terminal 标签页。
4. 连接到后端终端。
5. 在终端中执行以下命令:`./generate_admin_key.sh`
6. 复制生成好的管理密钥并妥善保存。
