## Gotenberg 是什么？

Gotenberg 提供一套对开发者友好的 API，可调用 Chromium 和 LibreOffice 等强大工具，把多种文档格式（HTML、Markdown、Word、Excel 等）转换成 PDF 文件，还有更多能力等你发掘！

Gotenberg **没有图形界面**。请前往[文档](https://gotenberg.dev/docs/getting-started/introduction)了解如何使用它 🚀。
