## Cloudflared 是什么?

Cloudflare Tunnel 是一款隧道软件,让你在任意类型的基础设施上快速加密并保护应用流量——隐藏 Web 服务器的 IP 地址、阻断直接攻击,然后安心交付出色的应用。
