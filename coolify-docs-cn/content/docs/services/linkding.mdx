# Linkding

<ZoomImage src="/docs-cn/coolify/images/services/linkding-logo.svg" alt="Linkding logo" />

## Linkding 是什么？

Linkding 是一款极简主义的自托管书签管理器，专注于简洁与性能，提供干净利落的界面来保存、整理和搜索你的书签。

## Linkding 的不同版本

Linkding 提供两个版本：

| 版本            | 说明 |
|-----------------|-------------|
| `latest`        | 提供 linkding 的基础功能 |
| `plus`          | 额外支持将网站归档为 HTML 快照。注意：该版本镜像体积明显更大，因为它内置了 Chromium；运行 Chromium 需要更多内存，保存 HTML 快照也需要更多磁盘空间 |
