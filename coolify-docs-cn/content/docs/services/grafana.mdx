## Grafana 是什么？

一套开放、可组合的可观测性与数据可视化平台。可视化来自 Prometheus、Loki、Elasticsearch、InfluxDB、Postgres 等多种数据源的指标、日志和链路追踪。

## 部署变体

Grafana 在 Coolify 中提供两种部署配置：

### Grafana（默认）
- **数据库：**内嵌（SQLite）
- **适用场景：**简单的监控环境、测试或临时仪表盘
- **组成：**单个 Grafana 容器，内置数据库

### Grafana with PostgreSQL
- **数据库：**PostgreSQL
- **适用场景：**需要持久化数据存储、高可用性与更佳性能的生产部署
- **组成：**
  - Grafana 容器
  - PostgreSQL 16 容器
  - 自动完成数据库配置与健康检查

## 功能特性

Grafana 让你无论指标存放在哪里，都能查询、可视化、告警并深入理解它们。与团队一起创建、探索和分享仪表盘，培养数据驱动的文化：

- **可视化：**快速灵活的客户端图表，选项丰富。面板插件提供多种不同的指标与日志可视化方式。
- **动态仪表盘：**借助模板变量创建动态且可复用的仪表盘，模板变量会以下拉框形式出现在仪表盘顶部。
- **指标探索（Explore Metrics）：**通过临时查询和动态下钻探索数据。支持分屏视图，并排对比不同时间范围、查询和数据源。
- **日志探索（Explore Logs）：**体验在保留标签筛选条件的情况下从指标切换到日志的魔力。可快速搜索所有日志，也可实时流式查看。
- **告警：**以可视化方式为最重要的指标定义告警规则。Grafana 会持续评估，并把通知发送到 Slack、PagerDuty、VictorOps、OpsGenie 等系统。
- **混合数据源：**在同一个图表中混用不同数据源！你可以按查询粒度指定数据源，甚至对自定义数据源也同样适用。
