# Snipe-IT

<ZoomImage src="/docs-cn/coolify/images/services/snipe-it-logo.webp" alt="Snipe-IT" />

## Snipe-IT 是什么

Snipe-IT 是一套免费开源的 IT 运维资产管理系统：掌握谁在使用哪台笔记本、设备何时购买以便正确计提折旧、管理软件许可证等等。

### 初始设置

部署服务后，Snipe-IT 会在后台运行一些任务来完成安装。之后你会看到 [Pre-Flight](https://snipe-it.readme.io/docs/pre-flight-setup)（飞行前检查）界面，帮助你确认环境是否配置正确。
