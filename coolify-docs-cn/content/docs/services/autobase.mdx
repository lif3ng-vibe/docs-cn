<ZoomImage src="/docs-cn/coolify/images/services/autobase-logo.svg" alt="Autobase 标志" />

## Autobase 是什么？

**Autobase for PostgreSQL®** 是 Amazon RDS、Google Cloud SQL、Azure Database 等云托管数据库（DBaaS）的开源替代方案。

这一自动化数据库平台让你能够创建并管理生产可用、高可用的 PostgreSQL 集群。它简化了部署流程，降低了运维成本，即使没有专业知识的团队也能轻松管理数据库。

*轻松自动化部署、故障转移、备份、恢复、升级、扩展等各项任务。*
