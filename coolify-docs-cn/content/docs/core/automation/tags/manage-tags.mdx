# 管理标签

从希望纳入分组的那个应用或服务入手管理标签。名称不存在时，Coolify 会创建新的团队标签；已存在时则复用现有标签。

## 为资源添加标签

<Steps>
<Step>

### 打开资源

打开要打标签的应用或服务，然后选择 **Tags**。

</Step>
<Step>

### 输入一个或多个名称

在 **Create new or assign existing tags** 中输入标签名。要一次添加多个标签，请用空格分隔名称：

```txt
production storefront eu
```

每个名称至少包含两个字符。Coolify 会去除 HTML，并以小写形式保存名称。

</Step>
<Step>

### 添加标签

点击 **Add**。新建和复用的标签都会出现在 **Assigned Tags** 下。

</Step>
</Steps>

在主侧边栏打开 **Tags** 并选择其中一个已分配的名称，该资源应出现在对应标签的详情中。

---

## 分配已有标签

当前团队中尚未分配给该资源的标签会显示在 **Existing Tags** 下。点击名称即可完成分配，无需重新输入。

同一个标签可以分配给团队内不同项目或环境中的应用和服务。

---

## 移除标签

在 **Assigned Tags** 下，点击标签名称旁的移除图标。Coolify 会立即从该资源上移除该标签。

移除标签不会停止、重启或重新部署资源。

---

## 未使用标签的清理机制

标签从最后一个应用或服务上解除关联后，Coolify 会将它从团队中移除。主 **Tags** 页面上没有单独的删除操作。

如果想保留某个分组，请让该标签至少保留在一个应用或服务上。

---

## 故障排除

<Accordions type="multiple">
<Accordion title="Coolify 提示标签无效">

请使用至少两个字符的名称，多个名称之间用空格而不是逗号分隔。

</Accordion>
<Accordion title="Coolify 提示标签重复">

该资源已经带有这个标签。请检查 **Assigned Tags**，不要再次添加同名标签。

</Accordion>
<Accordion title="Tags 页面为只读">

你需要拥有更新该资源的权限才能分配或移除标签。请联系团队管理员调整你的角色，或由其代为修改。

</Accordion>
</Accordions>
