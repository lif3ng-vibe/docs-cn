# Cron 语法

Coolify 使用 cron 表达式来调度任务、备份、更新、Docker 清理以及其他周期性工作。大多数调度字段接受标准的五字段表达式，部分字段还接受 Coolify 的命名调度。

## 五字段格式

一个 cron 表达式包含五个以空格分隔的字段：

```txt
┌───────────── minute (0-59)
│ ┌───────────── hour (0-23)
│ │ ┌───────────── day of month (1-31)
│ │ │ ┌───────────── month (1-12)
│ │ │ │ ┌───────────── day of week (0-7, Sunday is 0 or 7)
│ │ │ │ │
* * * * *
```

### 常用运算符

| 字符 | 含义 | 示例 |
| --- | --- | --- |
| `*` | 所有可能取值 | `* * * * *` 每分钟运行一次。 |
| `,` | 取值列表 | `0 8,16 * * *` 在每天 08:00 和 16:00 运行。 |
| `-` | 包含端点的范围 | `0 9 * * 1-5` 在周一至周五的 09:00 运行。 |
| `/` | 步长间隔 | `*/15 * * * *` 每 15 分钟运行一次。 |

### 字段专属取值

| <span className="inline-block min-w-32 whitespace-nowrap">取值</span> | 字段 | 含义 | 示例 |
| --- | --- | --- | --- |
| <span className="whitespace-nowrap">`JAN`-`DEC`</span> | 月份 | 三字母月份缩写 | `0 0 1 JAN *` 在 1 月 1 日运行。 |
| <span className="whitespace-nowrap">`SUN`-`SAT`</span> | 星期几 | 三字母星期缩写 | `0 9 * * MON-FRI` 在工作日的 09:00 运行。 |
| <span className="whitespace-nowrap">`?`</span> | 日期或星期几 | 该字段不指定具体值 | `0 9 ? * MON` 在每个周一的 09:00 运行。 |
| <span className="whitespace-nowrap">`L`</span> | 日期 | 当月最后一天 | `0 0 L * *` 在每月最后一天的 00:00 运行。 |
| <span className="whitespace-nowrap">`W`</span> | 日期 | 距指定日期最近的工作日 | `0 9 15W * *` 在距 15 日最近的工作日的 09:00 运行。 |
| <span className="whitespace-nowrap">`L`</span> | 星期几 | 当月最后一次出现的指定星期几 | `0 9 * * 5L` 在最后一个周五的 09:00 运行。 |
| <span className="whitespace-nowrap">`#`</span> | 星期几 | 当月内第几次出现的指定星期几 | `0 9 * * 5#2` 在第二个周五的 09:00 运行。 |

## 命名调度

Coolify 识别以下精确取值，并将它们转换为五字段表达式：

| 命名调度 | 等价表达式 | 运行时机 |
| --- | --- | --- |
| `every_minute` | `* * * * *` | 每分钟 |
| `hourly` 或 `@hourly` | `0 * * * *` | 每小时第 0 分钟 |
| `daily`、`@daily` 或 `@midnight` | `0 0 * * *` | 每天 00:00 |
| `weekly` 或 `@weekly` | `0 0 * * 0` | 每周日 00:00 |
| `monthly` 或 `@monthly` | `0 0 1 * *` | 每月 1 日 00:00 |
| `yearly`、`@yearly` 或 `@annually` | `0 0 1 1 *` | 每年 1 月 1 日 00:00 |

不支持 `@every_minute`。请改用 `every_minute` 或 `* * * * *`。

---

## 常见示例

| 调度 | 表达式 |
| --- | --- |
| 每五分钟 | `*/5 * * * *` |
| 每天 02:30 | `30 2 * * *` |
| 周一至周五 09:00 | `0 9 * * 1-5` |
| 每周日 03:00 | `0 3 * * 0` |
| 每月 1 日 00:00 | `0 0 1 * *` |

## 时区

调度运行时使用的是所属功能采用的时区。

计划任务使用运行应用或服务的服务器所配置的时区。其他调度功能可能使用各自设置页中说明的实例或服务器时区。

当确切的本地时间很重要时，保存调度前请先确认相关时区。

---

## 验证调度

将表达式填入调度的 **Frequency** 字段并保存设置。Coolify 会拒绝其 cron 解析器无法解析的取值。

对于计划任务，可分别用 **Execute Now** 验证命令和容器。手动执行会立即测试命令本身，但并不能证明另一条 cron 表达式代表的就是你想要的时间。
