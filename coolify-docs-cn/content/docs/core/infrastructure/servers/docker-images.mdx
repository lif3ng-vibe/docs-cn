# Docker 镜像

打开 **Servers > [server] > Images**（镜像）查看该服务器上存储的镜像。页面会显示每个镜像的仓库、标签、镜像 ID、创建时间、大小以及使用它的容器。可以按仓库、标签或 ID 搜索，变更后点击 **Refresh**（刷新）。

**Total**（总计）显示镜像占用的磁盘空间，**Reclaimable**（可回收）显示 Docker 可释放的空间。没有被任何容器引用的镜像会标记为 **Unused**（未使用）。

## 删除未使用的镜像

1. 找到标记为 **Unused** 的镜像，核对其引用情况。
2. 点击其删除操作。
3. 输入要求确认的镜像引用并确认。
4. 刷新列表并检查可回收空间。

这里只能删除未使用的镜像。之后的部署可能需要重新拉取或重新构建被删除的镜像。定时清理请使用 [Docker 清理](/core/infrastructure/servers/automated-docker-cleanup)。
