title: 移除成员
description: 把一个人从 Coolify 团队移除,而不删除其账户或团队的资源。
---

# 移除成员

移除成员会结束其在当前团队的成员身份。其 Coolify 账户和其他团队成员身份保持不变。

## 移除成员之前

你必须是当前团队的 **Owner** 或 **Admin**。

角色层级限制了你能移除谁:

- Owner 可以移除任何其他团队成员,包括另一位 Owner。
- Admin 可以移除 Admin 和 Member,但不能移除 Owner。
- 你不能在 **Members** 页面移除自己。

确认此人不再需要访问该团队的项目、服务器、凭据、共享变量或其他资源。

---

## 移除成员

<Callout type="warning" title="移除立即生效">
**Manage > Remove member** 操作不会打开确认步骤。选择之前,请核实此人的姓名、电子邮箱地址和角色。
</Callout>

<Steps>
<Step>

### 打开成员列表

1. 确认目标团队处于激活状态。
2. 在 Coolify 侧边栏选择 **Team**。
3. 选择 **Members**。

</Step>
<Step>

### 选择 Remove

按姓名和电子邮箱地址找到此人,在其所在行打开 **Manage**,然后选择 **Remove member**。

Coolify 会移除该团队成员身份,并吊销属于该用户和该团队的 API 令牌。

</Step>
<Step>

### 确认移除

核实此人的行已不再出现在成员列表中。

被移除的人无法再在该团队中工作。如果其仍处于登录状态,Coolify 会在其下一次请求校验成员身份时,清除不可用的当前团队选择。

</Step>
</Steps>

---

## 移除会改变什么

移除成员不会:

- 删除其 Coolify 账户
- 把其移出其他团队
- 删除该团队拥有的项目、服务器、应用、数据库、服务或设置
- 把团队资源转移给其他人

以后要恢复其访问,请[重新邀请此人](/core/team/members/add-a-member)并选择其应获得的角色。
