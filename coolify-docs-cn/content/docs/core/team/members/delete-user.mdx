# 删除用户

删除用户会把用户账户本身从自托管 Coolify 实例中移除。这与[移除成员](/core/team/members/remove-a-member)不同:移除成员只是结束此人在当前团队的成员身份,其账户仍然可用。

<Callout type="warning" title="此操作可能删除服务器资源">
如果 Coolify 与该用户的服务器之间仍有可用连接,删除该用户也会删除这些服务器上的所有资源,而不只是 Coolify 数据库中的记录。
</Callout>

## 删除用户之前

- 你必须属于 `root` 团队。只有 `root` 团队成员能从 UI 删除用户。
- `root` 团队和 `root` 用户无法被删除。
- 确认该用户属于哪些团队,以及这些团队拥有哪些资源。

## 删除用户

1. 进入 **Team** 页面。
2. 切换到 **Admin View** 标签页。这里列出在 Coolify 注册的每一个用户。
3. 在要移除的用户旁边选择 **Delete**。

## 删除期间会发生什么

Coolify 会遍历该用户所属的每个团队,并对每个团队应用以下规则:

### 用户是团队中唯一的成员

该团队及其所有资源会从服务器和 Coolify 数据库中一并删除。

### 用户不是团队中唯一的成员

1. 该用户是所有者或管理员,不存在其他所有者或管理员,且团队**有**其他成员:
   - 所有权转移给第一位不是所有者或管理员的团队成员。
   - 该用户从团队中移除。不删除任何资源。

2. 该用户是所有者或管理员,不存在其他所有者或管理员,且团队**没有**其他成员:
   - 该团队及其所有资源会从服务器和 Coolify 数据库中一并删除。

3. 该用户不是团队的所有者或管理员:
   - 该用户从团队中移除。不删除任何资源。

## 删除你自己的账户

删除自己的账户请使用[个人资料与账户删除](/core/security/authentication/profile)。Root 团队管理员无法在团队管理视图中删除 root 用户、root 团队所有者或他们自己的账户。
