# 管理成员

使用当前团队的 **Members** 页面审查访问权限、更改其他成员的角色,以及撤销不应再被接受的邀请。

## 查看成员列表

1. 确认目标团队处于激活状态。
2. 在 Coolify 侧边栏选择 **Team**。
3. 选择 **Members**。

表格显示 **Name**、**Email**、**Role**,以及你的角色允许的操作。Owner 和管理员还能看到 **2FA** 状态。使用搜索以及角色或 2FA 筛选器缩小列表范围。

定期查看该列表,并移除不再需要的访问。一个人的角色只对当前团队生效;同一个账户在其他团队中可以拥有不同的角色。

---

## 更改成员角色

Owner 和 Admin 可以更改其他成员的角色。可用操作取决于你的角色和对方的当前角色。

| 你的角色 | 可进行的角色变更 |
| :--- | :--- |
| **Owner** | 把其他 Owner、Admin 或 Member 改为其余任意角色。 |
| **Admin** | 把 Admin 改为 Member,或把 Member 改为 Admin。Owner 不可更改。 |
| **Member** | 没有角色变更操作。 |

找到该成员,打开 **Manage**,然后选择 **Make owner**、**Make admin** 或 **Make member**。

<Callout type="info" title="角色变更会吊销团队 API 令牌">
更改成员角色时,Coolify 会吊销该用户在本团队的 API 令牌。如果此人仍需要 API 访问,必须重新创建令牌。
</Callout>

更改后成员列表会重新加载。确认 **Role** 列已显示新角色。

你不能在成员列表中更改自己的角色。请让另一位拥有足够权限的人来操作。

---

## 查看待处理邀请

Owner 和 Admin 可以在邀请表单下方查看 **Pending Invitations**。

每一行显示:

- 被邀请的电子邮箱地址
- 该邀请是以电子邮件方式创建,还是以链接方式创建
- 此人将获得的角色
- 邀请链接

邀请链接的有效期为三天。一个邮箱地址上有效的邀请必须被接受、撤销或自然过期,才能为该地址创建新的邀请。

---

## 撤销邀请

对于不应再授予访问的邀请,点击其旁边的 **Revoke**。

Coolify 会立即移除该待处理邀请。确认其行已从 **Pending Invitations** 中消失。如果此人仍需要访问,请用正确的角色创建新的邀请。
