# 团队审计日志

团队管理员和所有者可以打开 **Team > Audit Log**,审查来自 UI、API、MCP 和 webhook 的活动。通过搜索和筛选事件,找到某位操作者、资源或操作。

事件覆盖资源变更、部署、备份、代理控制、成员管理、API 令牌、集成、账户安全,以及服务器、应用、服务和实例设置。每条记录在可用时都会记载操作者、资源和请求上下文。

## 查看变更

选择 **View changes** 可以对比被更改字段的前后值。变更静态加密存储。机密、命令和配置内容会被排除,敏感的请求元数据会被脱敏。审计日志是活动记录,而不是配置备份。

事件会在 90 天后被清理。如果你的团队需要超出该时间范围的独立存档,请通过 API 导出事件。

## API 访问

使用 `GET /audit-events`,并携带团队管理员或所有者拥有的令牌。操作者邮箱、令牌上下文、元数据、变更内容、IP 地址和 user agent 只有在具备 `read:sensitive` 或 `root` 权限时才会返回。筛选与分页参见 [API 参考](/api/overview),令牌能力参见 [API 权限](/api/permissions)。
