# 自定义 SSL 证书

Traefik 通常通过 `letsencrypt` 证书解析器获取 HTTPS 证书。当私有 CA、组织管理的证书或其他证书流程必须在 Traefik 处终结 TLS 时，可以使用自定义证书。

证书和私钥必须存在于每台由 Traefik 代理服务该域名的服务器上。

## 准备证书文件

你需要：

- 一份 PEM 编码的证书文件，包含所有必需的中间证书
- 与之匹配的未加密私钥
- 运行该资源的服务器上的 shell 访问权限

<Callout type="warning" title="保护好私钥">
通过加密连接复制密钥，限制其权限，绝不把它提交到代码仓库或粘贴到 Coolify 面板。
</Callout>

在资源服务器上创建证书目录：

```bash
sudo install -d -m 700 /data/coolify/proxy/certs
```

把文件从你的电脑复制到资源服务器，替换其中的本地路径和服务器地址：

```bash
scp /path/to/example.com.crt root@<server-address>:/data/coolify/proxy/certs/example.com.crt
scp /path/to/example.com.key root@<server-address>:/data/coolify/proxy/certs/example.com.key
```

限制服务器上私钥的访问：

```bash
sudo chmod 600 /data/coolify/proxy/certs/example.com.key
```

Coolify 会把 `/data/coolify/proxy/` 挂载到 Traefik 容器内的 `/traefik/`。

## 添加动态 TLS 配置

打开 **Servers > your server > Proxy > Dynamic Configurations**，选择 **Add**，创建一个诸如 `custom-certificates.yaml` 的文件：

```yaml
tls:
  certificates:
    - certFile: /traefik/certs/example.com.crt
      keyFile: /traefik/certs/example.com.key
```

保存文件。Traefik 会监视动态配置目录，当请求到达时，根据证书的使用者备用名称（SAN）选出匹配的证书。

## 验证证书

打开 HTTPS 域名，检查证书颁发者、使用者备用名称（SAN）和有效期。也可以在终端中检查：

```bash
openssl s_client -connect example.com:443 -servername example.com </dev/null 2>/dev/null \
  | openssl x509 -noout -subject -issuer -dates
```

如果 Traefik 仍在提供另一张证书，确认证书覆盖了所请求的主机名，并检查 **Servers > your server > Proxy > Logs**，寻找文件或密钥解析错误。
