# 监控概览

Coolify 会跟踪已连接服务器的状态以及其上运行的工作负载。仪表盘显示当前状态，通知渠道则可以把选定的故障和运维事件报告给你的团队。

<CoolCallout icon={ArrowsRight} title="简要版本">

[Sentinel](/core/observability/monitoring/sentinel) 在受支持的服务器上提供首选的服务器到 Coolify 状态链路。[指标](/core/observability/monitoring/metrics)在此基础上增加 CPU 与内存历史图表。指标可以单独禁用，Sentinel 仍会继续上报服务器与容器健康状态。

</CoolCallout>

## Coolify 监控什么

Coolify 的监控涵盖服务器状态、工作负载状态、资源用量、运维事件和日志。

## 监控边界

内置监控提供平台与容器层面的可见性，但它并不是一套完整的外部可观测性系统。

  id="monitoring-boundaries"

  title="Coolify 覆盖的范围"

>

日志转发（log drain）负责转发工作负载容器输出。它不转发 Coolify 部署日志，也不能替代日志服务商中的保留与告警控制。

## 代理流量分析

[流量分析](/core/observability/monitoring/traffic-analytics)为 Traefik 和 Caddy 提供请求量、带宽、访客、延迟与流量拆解数据。需要在每台服务器上单独启用，采集默认关闭。
