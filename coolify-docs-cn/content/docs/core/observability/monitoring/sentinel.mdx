# Sentinel

[Sentinel](https://github.com/coollabsio/sentinel) 是 Coolify 运行在已连接服务器上的 Rust 轻量代理。它把服务器与容器健康状态报告给你的 Coolify 实例，并可以采集 CPU 与内存图表所需的数据。

<CoolCallout icon={ArrowsRight} title="简要版本">

Coolify 在每台符合条件的服务器上以 `coolify-sentinel` 容器的形式运行 Sentinel。Sentinel 向 Coolify 发送经过身份验证的状态更新，并在指标启用时把指标历史存储在本地。

</CoolCallout>

<CoolCallout type="warning" icon={Warning22} title="并非所有服务器都可用 Sentinel">

构建服务器和 Docker Swarm 服务器不支持 Sentinel。配置 Sentinel 之前，请先验证一台标准 Docker 服务器。

</CoolCallout>

## 启用或同步 Sentinel

1. 打开**服务器（Servers）**，选择该服务器。
2. 打开**Sentinel > Configuration**。
3. 如果 Sentinel 处于禁用状态，选择 **Enable Sentinel**（启用 Sentinel）。
4. 如果 Coolify 显示 **Out of Sync**（未同步），选择 **Sync**（同步）。如果 Sentinel 已经在运行，同一按钮会显示为 **Restart**（重启）。
5. 等待服务器头部显示 **Sentinel In Sync**。

Sentinel 需要一个能从已连接服务器访问的 URL。如果 **Coolify URL** 为空，请先配置实例 [URL](/core/instance-management/instance-settings#url)，然后回到 Sentinel 再次同步。

## Sentinel 设置

| 设置 | 默认值 | 允许的取值与作用 |
| :--- | :--- | :--- |
| **Coolify URL** | 由 Coolify 实例设置生成 | 一个完整 URL。Sentinel 把更新发送到这个地址。更改实例 URL 会同步更新使用生成 URL 的远程服务器。 |
| **Sentinel token** | 由 Coolify 生成 | 必需的身份验证令牌。请使用 **Regenerate**（重新生成），不要自建令牌。 |

采集率、历史保留与推送间隔在服务器的**图表（Charts）**页面配置。参见[采样与保留](/core/observability/monitoring/metrics#采样与保留)。

更改 Sentinel 自定义镜像后，请使用 **Apply and restart**（应用并重启）。Sentinel 以 Docker 的 `unless-stopped` 重启策略运行。Coolify 会重启不健康或停止推送的代理，并在 Sentinel 未同步期间显示最近一次推送错误。

请把 Sentinel token 当作机密对待。Coolify 会把它加密存储在实例数据库中，并以环境变量的形式发送给 Sentinel 容器。

## 故障排查

<Accordions type="multiple">

<Accordion title="Sentinel 一直处于 Out of Sync">

确认服务器已通过验证，并且在 Coolify 中显示为可达。然后打开 **Sentinel > Configuration**，选择 **Sync**。

如果 Sentinel 仍未同步，打开 **Sentinel > Logs**，阅读 `coolify-sentinel` 容器的输出。

恢复之后，确认服务器头部变为 **Sentinel In Sync**，且时间戳持续更新。

</Accordion>

<Accordion title="Coolify URL 为空或不可达">

Sentinel 需要一个已连接服务器能够访问的 **Coolify URL**。

如果该字段为空，请配置实例 [URL](/core/instance-management/instance-settings#url)，然后回到 **Sentinel > Configuration**，再次选择 **Sync**。

</Accordion>

<Accordion title="Sentinel 日志显示身份验证错误">

打开 **Sentinel > Configuration**，选择 **Sentinel token** 旁边的 **Regenerate**。

Coolify 会创建新令牌并重启 Sentinel。确认服务器恢复到 **Sentinel In Sync**。

</Accordion>

</Accordions>
