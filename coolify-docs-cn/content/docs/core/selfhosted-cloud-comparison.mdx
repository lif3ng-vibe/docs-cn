# 自托管与 Coolify Cloud 对比

你有两种使用 Coolify 的方式:自己运行 Coolify 实例,或使用由 Coolify 团队托管维护的实例。

Coolify 实例是提供仪表盘并协调部署的控制平面。无论哪种模式,你的应用、数据库和服务都仍然运行在你连接的服务器上。

<CoolCallout icon={ArrowsRight} title="简要版">

如果你想自己运维 Coolify 实例,掌控它的更新、备份、可用性和恢复,请选择**自托管 Coolify**。

如果你希望由 Coolify 团队代为运维实例,请选择 **Coolify Cloud**。工作负载所在的服务器仍然由你提供并保障安全。

</CoolCallout>

## 哪些保持不变

你的选择改变的只是由谁运维 Coolify 实例。资源工作流程不会变化,工作负载也不会被搬到 Coolify 托管的服务器上。

## 自托管 Coolify 与 Coolify Cloud 对比

主要差异在于控制平面运维、仪表盘访问、通知送达方式和成本。

| 方面 | 自托管 Coolify | Coolify Cloud |
| :--- | :--- | :--- |
| Coolify 实例 | 运行在你掌控的基础设施上。 | 运行在 Coolify 团队管理的基础设施上。 |
| 安装与维护 | 由你安装、监控、维护,并从备份恢复实例。 | 由 Coolify 团队安装、监控、维护,并从备份恢复实例。 |
| Coolify 更新 | 由你决定何时更新实例。 | 控制平面更新由 Coolify 团队管理。 |
| Coolify 实例备份 | 由你配置、存放并演练实例备份。 | Cloud 实例的备份由 Coolify 团队管理。 |
| 仪表盘访问 | 由你为实例配置域名。 | 使用 [app.coolify.io](https://app.coolify.io)。 |
| 邮件告警 | 由你配置 SMTP 或 Resend。 | Coolify 通知的邮件送达由 Coolify 团队预先配置。 |
| 其他通知渠道 | 每个渠道由你自行配置,例如 Discord 或 Telegram。 | 每个渠道由你自行配置,例如 Discord 或 Telegram。 |
| 功能 | 包含当前及未来的所有 Coolify 功能,永久免费。 | 当前及未来的所有 Coolify 功能都包含在订阅内。 |
| 代码库 | 开源。 | 开源。 |
| 团队 | 不限数量。 | 不限数量;每个团队需要单独的订阅。 |
| 团队成员 | 不限数量。 | 不限数量。 |
| 已连接的服务器 | 不限数量。 | 不限数量。前两台之后的每台服务器都会增加订阅费用。 |
| 工作负载服务器与数据 | 应用、数据库、服务和持久化数据运行在你的服务器上。 | 应用、数据库、服务和持久化数据运行在你的服务器上。 |
| 平台成本 | 无 Coolify 授权费,只需为你的基础设施付费。 | 付费托管服务;工作负载服务器仍需你自行付费。 |

---

## 成本对比

自托管 Coolify 没有授权费。但运行 Coolify 实例和工作负载的基础设施仍需你付费。

Coolify Cloud 每月 5 美元起,最多包含两台已连接的服务器。每增加一台已连接的服务器,每月加收 3 美元。

Cloud 定价可能调整。订阅前请查看[当前 Coolify Cloud 定价](https://coolify.io/pricing)。

## 理解责任边界

Coolify Cloud 管理的是控制平面,而不是你连接到它的服务器和工作负载。如果自托管,这条边界的两侧都由你运维。
