# 重置 Root 密码

当你无法登录 root 账户、也无法使用邮件密码重置链接时，可以在服务器终端重置 root 密码。

<Callout type="warning" title="仅限自托管实例">
Coolify Cloud 用户无法访问运行该命令的容器。如果无法访问你的 Coolify Cloud 账户，请[联系 Coolify 团队](/support)。
</Callout>

## 选择合适的恢复方式

优先使用影响最小的方式：

- 如果你已登录且知道当前密码，打开 **Profile > General**，在 **Change Password** 下输入当前密码和新密码，然后选择 **Save**。
- 如果实例可以发送事务邮件给你，在登录页选择 **Forgot Password**，使用邮件中的重置链接。
- 如果两种方式都不可用，再使用下文的终端流程。它不要求当前 root 密码，也不依赖可用的邮件配置。

## 重置密码之前

请确认你已具备以下条件：

- 可以 SSH 访问运行自托管 Coolify 实例的服务器
- 在该服务器上运行 Docker 命令的权限
- root 账户的当前登录邮箱，或已计划在重置后[修改 root 邮箱](/core/backup-and-recovery/change-root-email)
- 一个已准备好的高强度唯一密码，需要输入两次

终端命令只检查两次输入的密码是否一致，不会执行 Coolify 仪表盘的密码规则。请使用一个长的随机生成密码，不要与其他账户共用，并存入密码管理器。

<Callout type="warning" title="root 会话和 API 令牌将被吊销">
密码修改后，Coolify 会在所有设备上登出 root 账户，并吊销该账户拥有的所有 API 令牌。其他用户的会话和 API 令牌不受影响。
</Callout>

## 通过终端重置 root 密码

<Steps>
<Step>

### 连接到 Coolify 服务器

通过 SSH 连接到运行 Coolify 控制平面的机器：

```sh
ssh root@<server-ip>
```

把 `<server-ip>` 替换为服务器的 IP 地址。如果你以非 root 用户连接，该账户必须有运行 Docker 命令的权限。如果你的服务器要求，可在下文的 Docker 命令前加上 `sudo`。

</Step>
<Step>

### 确认 Coolify 容器正在运行

```sh
docker inspect --format '{{.State.Status}}' coolify
```

该命令应输出 `running`。如果 Docker 报告 `coolify` 容器不存在或未运行，请先[更新或修复 Coolify 安装](/core/instance-management/update)再继续。

</Step>
<Step>

### 运行重置密码命令

```sh
docker exec -it coolify php artisan root:reset-password
```

Coolify 会显示如下交互提示：

```console
You are about to reset the root password.
Give me a new password for root user:
Again:
```

在第一个提示处输入新密码，然后再次输入相同的密码。输入过程中终端不会显示密码。

当两次输入一致且 root 账户存在时，Coolify 会输出：

```console
Updating root password...
Root password updated successfully.
```

该命令只更新 root 账户密码，不会重启 Coolify，也不会中断已部署的应用、数据库或服务。

</Step>
</Steps>

## 验证 root 访问

在浏览器的隐私窗口中打开 Coolify 登录页，并使用以下信息登录：

- root 账户的当前邮箱
- 新密码
- root 账户的双因素认证码（如果启用了 2FA）

使用隐私窗口可以在不依赖既有浏览器会话的情况下验证一次全新登录。密码修改后，原有的 root 会话应无法再打开仪表盘。

<Callout type="info" title="替换已吊销的 API 令牌">
如果某个集成使用了 root 账户的 API 令牌，请在登录后创建替代令牌并更新该集成。被吊销的令牌无法恢复。
</Callout>

## 重置失败时

<Accordions type="multiple">

<Accordion title="两次输入的密码不一致">

两次输入不同，因此 Coolify 没有修改密码。重新运行命令，并在两个提示处输入相同的值。

</Accordion>

<Accordion title="未找到 root 用户">

实例数据库中不存在用户 ID `0` 的 root 账户。不要手动创建或修改数据库记录。确认你连接的是正确的 Coolify 服务器，然后从已知可用的备份[恢复实例数据库](/core/backup-and-recovery/instance-restore)，或[联系支持](/support)。

</Accordion>

<Accordion title="更新 root 密码失败">

Coolify 找到了命令，但无法保存新密码。确认 `coolify-db` 容器正在运行：

```sh
docker inspect --format '{{.State.Status}}' coolify-db
```

如果命令没有输出 `running`，请先修复 Coolify 安装再重试。如果数据库正在运行而重置仍然失败，请保留命令输出并[联系支持](/support)。

</Accordion>

<Accordion title="命令执行成功但登录仍然失败">

确认你使用的是 root 账户的当前邮箱，以及终端中输入的精确密码。如果不再知道或无法使用 root 邮箱，请按照[修改 Root 邮箱](/core/backup-and-recovery/change-root-email)操作，然后重新尝试全新登录。

如果密码验证通过后 2FA 仍阻止登录，请按照[重置 2FA](/core/backup-and-recovery/reset-2fa)操作。

</Accordion>

</Accordions>
