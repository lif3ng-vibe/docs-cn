# Coolify 是什么

Coolify 是一个开源、可自托管的平台,用于在你掌控的服务器上部署和管理应用、数据库和服务。

Coolify 为你提供平台即服务(PaaS)式的工作流程:从仪表盘或 API 配置、部署和运维资源,而工作负载始终是你基础设施上的标准 Docker 资源。

<CoolCallout icon={ArrowsRight} title="简要版">

Coolify 是你基础设施的控制平面。它通过 SSH 连接到每台服务器,把服务器准备好以运行 Docker 工作负载,并协调构建、部署、域名、HTTPS、健康检查和日常运维。

你可以自己运行 Coolify 实例,也可以使用 Coolify Cloud。两种情况下,应用、数据库和服务所在的服务器都由你提供。

</CoolCallout>

## Coolify 管理什么

Coolify 把每个可部署的条目称为**资源(Resource)**。资源属于某个项目和环境,然后运行在连接到 Coolify 的服务器上。

Coolify 实例负责协调工作;Docker 在你连接的服务器上运行生成的资源。

已部署的资源使用你服务器上的标准 Docker 容器、网络和存储,因此不依赖任何专有的 Coolify 运行时。如果 Coolify 实例不可用,已在运行的资源会继续运行;在实例恢复之前,你失去的是 Coolify 的自动化和仪表盘控制。

工作负载数据和持久化存储保留在已连接的服务器上。控制平面、已连接服务器、Docker 和代理流量的更多细节,参阅[Coolify 的工作原理](/core/how-coolify-works)。

## 哪些仍在你的掌控之中

Coolify 不是工作负载服务器的托管商。Coolify 在你提供的基础设施上自动化部署工作,但基础设施本身仍由你运维。

## 自托管还是 Coolify Cloud

Coolify 有两种部署模式。资源工作流程完全相同,差别只在于由谁运维 Coolify 控制平面。
