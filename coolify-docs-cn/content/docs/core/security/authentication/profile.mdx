# 个人资料与账号删除

打开用户菜单并选择 **个人资料**（Profile），即可管理你的账号和[两步验证（2FA）](/core/security/authentication/2fa)。已关联的 SSO 身份会显示在这里。如果你的邮箱由提供商管理，请在提供商处修改；Coolify 不允许在本地编辑该邮箱。

对于已关联 OAuth 身份的账号，危险操作需要输入文字确认，而无需输入 Coolify 密码。继续操作前，请仔细核对确认框中列出的每一项操作。

## 删除你的账号

在 **个人资料** 页面使用删除账号操作并完成确认。删除账号会：

- 删除你作为唯一成员的团队
- 将你从其他所有团队中移除
- 撤销你的 API 令牌和会话

以下情况会阻止删除：root 用户本人；你独自拥有的团队仍持有服务器、项目或 Git 源；以及你退出共享团队后该团队将没有管理员或所有者。

重试被阻止的删除之前，请先移除剩余资源，或在每个团队中安排好所需的所有者和管理员。账号删除不同于通过团队管理移除成员；参见[移除成员](/core/team/members/remove-a-member)。
