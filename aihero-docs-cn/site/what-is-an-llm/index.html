    什么是 LLM？

    了解大语言模型（LLM）的基础：结构、运作方式与创建过程。适合准备深入 AI 世界的初学者。

    Matt Pocock

    在本文中，我们会讲讲大语言模型的基础：它们是什么、如何工作，并顺带聊聊创建它们的过程。

    市面上的大多数资料都会深挖 LLM 的工作原理——我们不打算这么做。相反，我会简要介绍最常见的那些概念，让你可以直接动手开始构建。

    什么是大语言模型？

    一个大语言 模型 本质上是一个巨大的压缩文件——可以把它想成一个 1TB 的 zip 文件。这个文件里包含一堆以 16 位浮点数编码的数字。这些数字就是模型的 参数 。

    0.1239784871238176123 // Parameter 1

    0.1515689756890123123 // Parameter 2

    这些参数代表着模型的“大脑”。它们是模型 预训练（pre-training）的结果：这一过程把海量文本数据“压缩”成这些数字。它们代表着模型对世界的理解，并赋予它记住事实、做出决策的能力。

    这些参数的数量代表着模型“大脑”的体积。一般来说，“大脑”更大的模型表现更好，但运行更慢。一个拥有 70B 参数的模型，运行速度会比 7B 参数的模型慢约 10 倍.

    我们已经能看到体积与速度之间的权衡——这是选择大语言模型时的常见主题。

    如何运行一个大语言模型？

    要让模型做任何有用的事，你需要对模型执行 推理（inference） 。

    推理就是把文本发给模型并取回响应的过程。这要借助 推理函数（推理（inference） function） 来完成——它是一段软件，接收模型的参数，并在其上运行算法来找出下一个词。这比预训练模型便宜得多，在你的笔记本电脑上就能完成。

    想深入了解推理的工作原理，请看 这份精彩的交互式演练.

    采样策略

    为了找出下一个词，模型会审视所有可选的 token，并从中挑出一个。

    为此，它会使用 采样策略（sampling strategy） ——由开发者选定。这一策略决定了模型如何选择下一个词。最常见的策略有：

    • 贪婪采样：模型总是挑选可能性最高的那个词。
    • Top-K 采样：模型从可能性最高的前 K 个词中挑选。
    • Top-P 采样：模型从构成概率质量前 P% 的那些词中挑选。
    • Temperature 采样：模型在挑选过程中引入随机性，从而产生更多样的输出。

    深入这些策略的细节超出了本文的范围。通常，作为 AI 工程师，你无法更改所用模型的采样策略。不过，你可以调整一些变量（比如 temperature）来获得不同的结果。

    什么是输入 token？

    当你把文本发送给模型时，文本首先要被 分词（tokenize）。这一过程把文本拆分成单个的词，再把这些词转换成数字。这些数字就是 输入 token（input tokens），它们会被传给推理引擎。

    每个模型都有自己的分词器（tokenizer）。 Tiktokenizer 是探索不同分词器的绝佳 playground。

    如何创建一个模型？

    要得到参数，你需要训练模型。训练大语言模型是极为复杂的过程，需要大量时间、专业知识和资金。学习如何训练超出了本文的范围。

    一个粗略的参考：取互联网的一小块，比如说 10TB 数据。动用 6,000 张 GPU 跑 12 天，花费约 200 万美元。最后你会得到一个约 140GB 的文件，里面是模型的全部参数。

    训练过程有两个主要阶段：

    1. 预训练：通过把海量互联网数据压缩成参数，赋予模型知识
    2. 后训练：通过细致的指令与示例，塑造模型的性格与行为。

    最终你得到的是一个巨大的参数文件——它是模型所训练数据的某种“压缩”版本，其性格由后训练塑造。没有后训练，模型只会是一坨惰性的知识堆——它不知道该如何扮演一个乐于助人的助手。

    如何内省一个模型？

    深入模型的参数、弄清哪些参数对应哪些现实世界概念，是可能的（尽管非常困难）。例如，Anthropic 发现模型能够：

    • 跨语言共享概念，暗示存在某种通用的“思维语言”
    • 写作时提前规划（比如预先安排诗歌中的押韵）
    • 用多条并行通路处理任务（比如心算）
    • 有时编造听起来合理的推理过程，而不是展示真实的思考过程

    通过理解模型如何思考，我们可以更好地预测它们的行为，并有望揭开让它们难以取信于人的某些“魔法”。这可能会催生更可控、更确定性的 AI 系统——但相关研究仍处于早期阶段。

    结语

    大语言模型把海量知识压缩成数值形式的参数。虽然它们建立在复杂数学之上，但要有效地使用它们，你并不需要理解其内部机制。对整体格局有个基本了解，就足以建立关于它们如何工作的敏锐直觉。
