    免费技能

    写烂代码的代价，从未如此之高。

    很多人以为，软件开发的规则正在被 AI 重写。他们觉得代码很廉价，觉得软件工程作为一门学科已经落幕。

    Claude Code 和 Codex 这类编码智能体交付代码的速度，超过了以往任何人类。但缺少精心的引导，它们会把代码库越搞越糟；代码库越糟，AI 的表现就越差。这是个恶性循环。

    如果你能设计出智能体喜爱的代码库，就能收获这个新时代的红利。AI Hero 献给每一个在意自己交付代码的人。
