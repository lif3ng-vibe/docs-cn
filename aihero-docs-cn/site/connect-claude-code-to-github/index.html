    将 Claude Code 连接到 GitHub MCP 服务器

    用 GitHub MCP 增强你的 Claude Code！了解开发者如何借助这一强大的终端应用集成，顺畅地修改代码库。

    Matt Pocock
    下一课
    本页内容
    • 接下来

    在深入 MCP 的抽象细节之前，先来看看它实际跑起来是什么样。

    我是开发者，我的受众也大多是开发者，所以我们来看一个开发者的用例。

    我们把一个 GitHub MCP 服务器连接到 Claude Code。Claude Code 是一个非常强大的终端应用，可以用 LLM 来修改代码库。

    上面的视频里我会完整走一遍这个演示，以下是我执行的步骤：

    1. 安装 Claude Code.

    2. 获取一个 GitHub API Key 并复制到剪贴板。

    3. 运行这条命令：

    claude mcp add

    1. 添加 github-server 作为 MCP 服务器的名称。

    2. 作用域限定到当前项目。

    3. 添加 npx 作为命令。

    4. 添加 -y @modelcontextprotocol/server-github@latest 作为参数。

    5. 添加 GITHUB_PERSONAL_ACCESS_TOKEN=your-token-here 填入环境变量。

    6. 现在，你的 MCP 服务器应该已经可以使用了。
