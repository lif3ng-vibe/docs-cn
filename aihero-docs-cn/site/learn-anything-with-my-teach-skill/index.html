    用我的 /teach 技能学会任何东西

    学会在 Claude Code 里使用 /teach 技能，为任何主题——语言、编程、技能——创建带互动练习的个性化 AI 课程。

    Matt Pocock
    本页内容
    • 完成的步骤
    • 相关阅读

    这个 /teach 技能 的设计初衷是让你以 Claude 为个性化老师学会任何东西。它不只是随机生成课程——它理解 你 的目标，适应 你 的水平，并打造专为你量身定制的课程。

    这个技能会记录你的使命，寻找高质量资源，生成带音频和测验的互动课程，并保存你的学习进度记录，让它始终清楚你走到旅程的哪一步。

    课程

    现场体验这种学习方式

    训练营正是跑在这套工作流上——加入下一期面向真正工程师的 AI 编程的候补名单。

    加入候补名单

    完成的步骤

    设置你的项目

    mkdir learning-french

    cd learning-french
    code .

    安装 /teach 技能

    如果还没有 Node， 去 nodejs.或g 下载.

    npx skills@latest add mattpocock/skills

    用上下方向键导航，然后按 space 来选中它。

    同样用方向键和空格来选择。

    修复智能体目录（如有需要）

    如果安装创建的是 .agents 目录而不是 .claude，你需要创建一个 symlink，让两个目录指向同一个位置。

    ln -s .agents .claude

    这确保 Claude Code 和你的智能体都能读取同一个目录，一处的更改会反映到另一处。

    用 /teach 技能创建你的第一课

    例如： teach me French 或 teach me React hooks 或 teach me how to make sourdough bread.

    智能体会问你一些澄清性的问题，关于：

    • 你为什么想学这个
    • 你目前的水平
    • 对你而言成功是什么样子
    • 你偏好怎样的学习方式

    回答要具体——你给的细节越多，个性化课程就越好。

    智能体会在你的项目里生成几个文件：

    • MISSION.md ——你的学习目标与上下文

    • RESOURCES.md ——为你的具体目标筛选过的资源

    • reference/glossary.html ——一份可以随学习不断补充的速查表

    • lessons/ ——带音频和测验的互动 HTML 课程

    • learning-records/ ——你的进度历史

    在浏览器中打开课程文件（智能体会告诉你要运行什么命令），完成互动内容。许多课程带有“点按即听”的音频按钮和即时反馈测验。

    继续你的学习

    回到 Claude Code，描述你学到了什么、哪里让人困惑、接下来想重点学什么。就当是在和一位对你的进度了如指掌的真人老师聊天。

    智能体会创建新课程、更新你的学习记录，并在你推进学习旅程的过程中持续充实你的参考资料。
