    通过 stdout 运行 MCP 服务器

    用一个 TypeScript 文件搭建 MCP 服务器；连接 Claude Code，无缝运行脚本。

    Matt Pocock

    我来给你展示搭建 MCP 服务器最简单的方式。

    我们要创建一个 MCP 服务器，把它连接到 Claude Code，然后用它来运行我们想要的任何脚本。

    而且全程只用一个 TypeScript 文件，不需要任何构建步骤。

    开始吧。

    服务器

    我们先来创建一个 main.ts 文件。

    接着初始化一个 McpServer:

    import { McpServer } from "@modelcontextprotocol/sdk/server/mcp.js";

    

    const server = new McpServer({

      name: "Weather Service",

      version: "1.0.0",

    });

    这个 MCP 服务器来自 @modelcontextprotocol/sdk 包。

    Scrollycoding

    1

    然后我们给这个服务器添加一个工具。先定义工具的名称 getWeather.

    2

    接着定义工具运行时需要接收哪些参数。这里我们只需要城市（city），它是一个字符串，我们用 Zod 来声明。

    3

    最后，添加一个只在工具被调用时才运行的回调函数。我们返回一个内容对象数组，这里返回的是文本，并声明该地的天气是晴天。

    如果真要实现这个功能，真正去调用天气 API 的就是这里。

    server.tool("getWeather");

    我们的服务器其实已经完成了，但还需要一种方式让 Claude Code 与它通信。

    它的做法是运行这个文件，并通过 stdin 与之通信。

    要让这一切跑起来，我们可以用一个 StdioServerTransport ，它来自 @modelcontextprotocol/sdk.

    我们先定义 transport，再把服务器连接上去。

    import { StdioServerTransport } from "@modelcontextprotocol/sdk/server/stdio.js";

    

    const transport = new StdioServerTransport();

    await server.connect(transport);

    连接到 Claude Code

    现在在 Claude Code 里，我们可以运行 claude mcp add。这会开启一段交互式对话，你可以在其中选择想连接的服务器。

    目前 Claude Code 只支持 stdio transport——这正是我们在用的。

    上面的视频里我演示了交互步骤，但你也可以用一条命令完成：

    claude mcp add "weather-example" npx tsx "/path-to-the-file.ts"

    这告诉 Claude：要运行这个文件，它应该调用 npx tsx /path-to-the-file.ts.

    npx 让我们可以运行来自 npm. tsx 是无须构建步骤运行 TypeScript 文件的绝佳方式。然后我们传入文件的路径。

    就这样，我们应该就能运行 claude 并让它与我们的 MCP 服务器通信了。演示请看上面的视频。

    这为什么很酷？

    这太棒了：无需搭建构建步骤或服务器，就能把任意 TypeScript 函数接入 Claude Code。

    这是定制你自己的 Claude Code 实例，或 Cursor、Windsurf 等 MCP 宿主（host）的强大方式。

    随着越来越多桌面应用开始集成 MCP，这将成为为其扩展自定义能力的强大途径。
