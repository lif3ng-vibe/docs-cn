    我的 Claude Code 训练营——预告

    这是我的 Claude Code 课程预告：涵盖 LLM 的局限、规划、转向、反馈回路、自主智能体与人在回路技术。

    为期 2 周的学习训练营 • 3 月 30 日开营

    过去几个月，我一直在打造一门超越 Claude Code 基础的完整课程。它是一套让你成为更高效的 AI 辅助开发者的框架。

    以下是课程内容的预览。

    1. 从基础开始（在你碰 Claude Code 之前）

    在深入 Claude Code 本体之前，课程先讲两节关于 LLM 局限与子智能体（sub-agent）的重要课。这看起来有点本末倒置，但这是有意为之。

    大多数开发者还没搞懂 LLM 为什么会这样表现，就直接开始写提示词。从这里入手，能帮你避免之后事情不如预期时的挫败感。

    子智能体值得特别关注，因为它们是 Claude Code 工作方式的核心。理解它们会影响你如何拆分任务。

    2. 掌握核心循环：探索、构建、清空

    第一天聚焦于基于代码的探索——这是最基础的原语，其余一切都由此展开。

    你将学会：

    • 系统地探索你的代码库
    • 用 Claude Code 构建单个功能
    • 接上上下文感知
    • 有效使用 计划模式（plan mode） 的技巧
    • 实现 压缩（compaction） 来清空上下文窗口

    第一天结束时，你就能交付一个完整的功能。但你还不知道如何稳定地让 Claude Code 朝着你的设想前进。

    3. 学会用 AGENTS.md 和技能转向

    第二天介绍转向（steering），解决困扰 LLM 的无状态问题。

    由于语言模型不会在会话之间保留记忆，你需要一些机制来引导它们的行为。课程会教你使用 AGENTS.md 文件和自定义智能体技能（Agent 技能）。

    技能把你的开发实践编码成可复用的工具，Claude Code 可以反复调用，从而保证整个代码库的一致性。

    4. 把庞大的任务拆成多阶段计划

    当任务超出 上下文窗口（context window）时，大多数开发者就会碰壁。第三天教你如何把庞大的功能拆成多个阶段。

    你将学到用于描述你要构建什么的 PRD 框架，以及如何组织多阶段计划，在阶段之间清空上下文窗口。

    曳光弹（tracer bullet，借鉴自《程序员修炼之道》）帮你先啃有价值的部分。这种方式能降低陷入实现细节、却什么有用东西都没交付的概率。

    5. 构建紧密的反馈回路

    第四天会重新定义你对代码质量的看法。

    你添加的每一行代码都带着维护负担。你不能指望让 Claude Code 一路硬啃问题还能得到好结果。相反，你需要反馈回路来引导智能体找到更好的方案。

    课程会介绍一个“do work”技能，把你的开发周期编码进去：调试、探索、构建、运行反馈回路和测试。你每次调用 Claude Code，它都会遵循这一流程。

    测试驱动开发（TDD）在这里很关键。LLM 在训练数据里早就理解了这些概念。红-绿（red-green）-重构循环会从好的提示词中自然涌现，而更好的测试会带来更好的智能体表现。

    6. 进阶到 Ralph 自主智能体

    Ralph 是课程里对自主 AI 智能体的称呼：它们无需人工干预就能向你的仓库提交代码。

    你学到的一切都汇聚于此。转向机制、反馈回路和架构模式都变得不可或缺。Ralph 之所以能自主运行，是因为你的反馈回路和 AGENTS.md 文件有效地约束着它。

    最后一步是把 Ralph 接到你的 GitHub 工单（issue）清单上：你创建工单，智能体逐一处理。

    7. 在关键处把人请回来

    最后一天会承认：自主智能体无法包办一切。

    某些任务更适合人在回路（human-in-the-loop）模式：调研阶段让你在 Ralph 执行之前先融入你的品味，原型（prototype）让你探索设计空间，QA 计划则在代码落地前保证质量。

    你还将学到如何设计对 AI 智能体友好的代码库，把软件架构当作你开发品味的一部分。

    课程形式：自学进度 + 训练营福利

    这是一门自学进度的课程，所有材料永久保留。但它同时以训练营的形式组织，材料在两周内陆续发布。

    这种混合模式效果很好。你可以参加实时答疑时间（office hours），加入满是同路开发者的 Discord。你不能盲目照搬框架，得把它套用到自己的代码库和约束条件上——这正是训练营有用的地方。

    整体图景

    这门课程构建的是一个完整系统：多阶段计划带来更好的 Ralph 执行效果，转向机制提升代码质量，反馈回路引导智能体找到更好的方案。每一环都在强化其他环节。

    课程结束时，你将理解那些让 AI 辅助开发规模化生效的软件工程原则。

    如果这打动了你，训练营里见。
