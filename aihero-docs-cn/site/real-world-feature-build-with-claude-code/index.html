    用 Claude Code 构建真实功能：每一步都有讲解

    学习 Claude Code 工作流：grill 追问会话、PRD、GitHub 工单（issue）、AFK 智能体与 QA 回路，用 AI 高效构建功能。

    Matt Pocock
    本页内容
    • 相关阅读

    在这期视频里，我完整走了一遍真实案例：把 Claude Code 用在我的课程视频管理器上——那是一个我每天用来创作内容、组织课程和管理视频的 React Router 应用。

    我会展示我的完整工作流：从用 grill me 技能做最初的功能头脑风暴，到创建 PRD 并拆解成工单（issue），再到运行自主的 Ralph 循环，让我不在工位时功能也能被实现。

    这不是一支精心打磨的教程，而是原生态、无脚本的实录：看看在一个拥有 1,200 多次提交、637 个已关闭工单的真实代码库上，我究竟是怎么与智能体协作的。你会看到混乱的部分、QA 回路，以及我一路做下的种种决策。

    我要做的这个功能，是改进应用里“幽灵课”（ghost lesson）和“真实课”的运作方式。幽灵课只存在于数据库中，而真实课在磁盘上有实际文件。眼下的工作流很笨拙，创建或删除课程都要走好几个步骤。到本次会话结束时，我会把整个流程理顺，并顺带加上对“幽灵课程”的支持。

    如果你想从头学会这些技能，可以看看 面向真正工程师的 Claude Code，我的训练营，教你把真正的工程实践用到 AI 辅助开发上。
