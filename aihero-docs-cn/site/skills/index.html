    技能

    按你会伸手用它们的时机分组。多数人从主流程开始。

    • 01快速上手

      只需配置一次，之后就能轻车熟路。

      起点是 /setup-matt-pocock-skills

      • /setup-matt-pocock-skills/setup-matt-pocock-skills 技能配置好一个仓库，让其他技能了解它的运作方式。
      • /ask-matt/ask-matt 技能弄清楚你眼下的处境该用哪个技能。

    • 02主流程

      从想法到上线的主轴，依次排列。

      起点是 /grill-with-docs

      • /grill-with-docs/grill-with-docs 技能就一份计划接受访谈，并把决策记录下来。
      • /to-spec/to-spec 技能把一场谈定了的对话写成一份规格。
      • /to-tickets/to-tickets 技能把规格拆成智能体可构建的小工单。
      • /implement/implement 技能把一份完成的规格构建成代码，测试先行。
      • /code-review/code-review 技能按你的标准和规格评审一个 diff。
      • /retro/retro 技能回顾一场会话，提出对仓库的改进建议。

    • 03塑形

      探索一个悬而未决的问题，产出一个反哺主流程的决策或答案。

      起点是 /wayfinder

      • /wayfinder/wayfinder 技能把一项大型工作绘成决策地图，并逐一敲定。
      • /prototype/prototype 技能用一段随后就删掉的代码回答一个设计问题。
      • /research/research 技能得到带引用的答案，从一手来源读起。

    • 04工程

      保持代码库与 issue 列表健康，同时为流程生成工作。

      起点是 /improve-codebase-architecture

      • /improve-codebase-architecture/improve-codebase-architecture 技能以一份可视化报告找出值得重构的模块。
      • /diagnosing-bugs/diagnosing-bugs 技能从一个会失败的复现（repro）出发，诊断棘手的 bug。
      • /triage/triage 技能把原始 issue 整理成可以直接开工的工作。
      • /wizard/wizard 技能生成一个带人一步步完成配置的脚本。
      • /implement-spec/implement-spec 技能用并行子智能体一口气构建整份规格。

    • 05效率技能

      面向人的工作流，由你来运行，与代码无关。

      起点是 /grill-me

      • /grill-me/grill-me 技能先把想法对齐，再做出承诺。
      • /handoff/handoff 技能把一场长会话写成文档，让另一个智能体能接着干。
      • /to-questionnaire/to-questionnaire 技能把悬而未决的问题变成一份由别人来填的文档。
      • /teach/teach 技能跨越多个相互衔接的会话学会一个主题。
      • /wait-what/wait-what 技能让智能体用大白话把刚才的话再说一遍。
      • /writing-for-agents/writing-for-agents 技能如何写技能和其他智能体会读的文档。

    • 06参考技能

      可复用的一层，供其他技能调用或引用。

      起点是 /pr

      • /pr/pr 技能一份 pull request 描述应有的形状。
      • /codebase-design/codebase-design 技能设计深模块的词汇。
      • /domain-modeling/domain-modeling 技能磨利一个项目使用的词语，并写下来。
      • /grilling/grilling 技能其他技能用来对计划做压力测试的那场访谈。
      • /tdd/tdd 技能红-绿-重构（red-green-refactor）循环的规则。

    什么是技能（skill）？

    技能是交给你编码智能体的一小段锋利指令，让它像资深工程师那样干活。装上你想要的技能，输入一个斜杠命令，智能体就会遵循一套你真正信得过的流程。

    问题所在

    智能体有多强，取决于你给它的流程有多好。放任它瞎猜，它会写出看似合理的代码，悄悄腐蚀整个代码库。

    解决办法

    一项技能把一个好习惯固化下来（追问一份计划、撰写一份规格、评审一个 diff），让智能体每次都以同样的方式执行它。

    为什么能滚雪球

    技能连成一条链。前一个的输出就是后一个的输入，因此当你调优单个环节时，整个工作流都会跟着变好。
