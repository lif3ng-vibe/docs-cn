    Vercel AI SDK 教程

    用 Vercel AI SDK 在 TypeScript 中构建各种 LLM 应用。学习流式传输、结构化输出、工具调用与智能体。

    开始第 1 课 代码
    Matt Pocock

    最近我用 TypeScript 和 AI 构建了很多东西：智能体、工作流、自定义脚本和各种 CLI，帮助我更快、更聪明地工作。

    而 Vercel AI SDK 一直是我工具箱里的一件利器。

    这个库解决了使用 LLM 时的许多痛点。

    在本教程中，我会给你一份完整的指南，带你彻底掌握它。

    写得真好！学到了几件我原本不知道的事。

    Addy Osmani —— Google Chrome 工程负责人

    任何能运行 JavaScript 的地方都可以用 AI SDK Core。这正是我为之兴奋的原因：它如此通用、如此强大，而且抽象层次对几乎所有任务来说都恰到好处。

    前往 AI Hero 的 GitHub 仓库 即可获取全部代码并运行示例。

    你将学到

    1. 01热切换模型
    2. 02流式传输
    3. 03结构化输出
    4. 04处理图片与文件
    5. 05工具调用
    6. 06构建智能体

    16 节课，按顺序排列

    1. 01

      Vercel AI SDK 是什么？

      了解 Vercel AI SDK 如何通过统一的 API 简化 AI 应用开发，与不同的 LLM 提供商交互。
    2. 02

      用 Vercel AI SDK 生成文本

      学习如何用 Vercel AI SDK 配合 Anthropic 的 Claude 模型生成 AI 文本响应。在 TypeScript 中进行文本生成的简单配置。
    3. 03

      用 Vercel AI SDK 流式输出文本

      学习如何用 Vercel AI SDK 流式输出文本，大幅提升用户体验。
    4. 04

      用 Vercel AI SDK 添加系统提示词

      学习如何在 Vercel AI SDK 中使用系统提示词（system prompt）来定制 LLM 的行为。
    5. 05

      用 Vercel AI SDK 热切换 AI 模型

      学习如何用 Vercel AI SDK 轻松切换 AI 模型，实现灵活解耦的应用开发。
    6. 06

      用 Vercel AI SDK 处理消息历史

      学习如何用 Vercel AI SDK 的 CoreMessage 数组管理 AI 聊天机器人的会话历史。附 TypeScript 示例的实用指南。
    7. 07

      用 Vercel AI SDK 使用本地模型

      学习如何通过 OpenAI 兼容 API 把 Vercel AI SDK 连接到本地或远程模型，包含在 localhost 上集成 LM Studio 的实战。
    8. 08

      用 Vercel AI SDK 生成结构化输出

      了解如何用 Vercel AI SDK 配合 OpenAI 实现结构化输出，聚焦以预定义格式高效取回数据。
    9. 09

      用 Vercel AI SDK 流式输出对象

      学习如何用 Vercel AI SDK 从 LLM 流式获取结构化输出。
    10. 10

      用 Vercel AI SDK 生成枚举

      学习如何用枚举和 AI SDK 构建情感分析系统，只用几行代码就能把文本分为正面、负面或中性。
    11. 11

      用 Vercel AI SDK 生成数组

      学习如何用 Vercel AI SDK 配合 Zod schema 生成对象数组，创建仿真用户数据。
    12. 12

      用 Vercel AI SDK 打造替代文本生成器

      通过一份简单指南，学习如何用 Vercel AI SDK 基于本地文件和 URL 为图片生成替代文本（alt text）。
    13. 13

      用 Vercel AI SDK 从 PDF 提取结构化数据

      学习如何用 Vercel AI SDK 和 Zod schema 从 PDF 发票中提取结构化数据，实现自动化数据处理与数据库存储。
    14. 14

      用 Vercel AI SDK 创建嵌入

      学习如何用 Vercel AI SDK 为词语和数据创建并检索嵌入（embedding）。
    15. 15

      用 Vercel AI SDK 进行工具调用

      用尽可能简单的例子，学习如何在 TypeScript 中用 Vercel AI SDK 进行工具调用。
    16. 16

      用 Vercel AI SDK 构建你的第一个智能体

      我们来构建一个 AI 智能体（agent）。了解如何用 Vercel AI SDK 让 LLM 对工具调用的结果做出响应。
