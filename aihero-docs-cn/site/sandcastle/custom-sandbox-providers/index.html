    自定义沙箱提供方

    S和castle 内置 Docker、Podman 与 Vercel 提供方，你也可以创建自己的提供方。沙箱提供方告诉 S和castle 如何在隔离环境中执行命令。它分为两类：

    • 绑定挂载（bind-mount） ——沙箱可以挂载宿主机目录。S和castle 在宿主机上创建 worktree，由提供方把它挂载进去，无需文件同步。适用于 Docker、Podman 或任何本地容器运行时。
    • 隔离型（isolated） ——沙箱拥有自己的文件系统（例如云上 VM）。提供方负责通过 copyIn 和 copyFileOut在沙箱与宿主机之间同步代码。当沙箱无法访问宿主机文件系统时，就用这种方式。

    沙箱句柄约定

    两类提供方都会返回一个 沙箱句柄 ，它来自 create() 函数。该句柄暴露：

    方法必填描述
    exec两者运行一条命令，可选经其逐行流式输出 stdout： options.onLine
    close两者拆除沙箱
    copyFileIn绑定挂载（bind-mount）把单个文件从宿主机复制进沙箱
    copyFileOut两者把单个文件从沙箱复制回宿主机
    copyIn隔离型（isolated）把文件或目录从宿主机复制进沙箱
    worktreePath两者沙箱内仓库目录的绝对路径

    ExecResult

    每次 exec 调用都会返回一个 ExecResult:

    interface ExecResult {

      readonly stdout: string;

      readonly stderr: string;

      readonly exitCode: number;

    }

    绑定挂载（bind-mount）提供方示例

    一个最小的绑定挂载提供方，通过 shell 调用本地进程（无容器）：

    import {

      createBindMountSandboxProvider,

      type BindMountCreateOptions,

      type BindMountSandboxHandle,

      type ExecResult,

    } from "@ai-hero/sandcastle";

    import { execFile, spawn } from "node:child_process";

    import { copyFile as fsCopyFile, mkdir as fsMkdir } from "node:fs/promises";

    import { dirname } from "node:path";

    import { createInterface } from "node:readline";

    

    const localProcess = () =>

      createBindMountSandboxProvider({

        name: "local-process",

        create: async (

          options: BindMountCreateOptions,

        ): Promise<BindMountSandboxHandle> => {

          const worktreePath = options.worktreePath;

    

          return {

            worktreePath,

    

            exec: (

              command: string,

              opts?: { onLine?: (line: string) => void; cwd?: string },

            ): Promise<ExecResult> => {

              if (opts?.onLine) {

                const onLine = opts.onLine;

                return new Promise((resolve, reject) => {

                  const proc = spawn("sh", ["-c", command], {

                    cwd: opts?.cwd ?? worktreePath,

                    stdio: ["ignore", "pipe", "pipe"],

                  });

    

                  const stdoutChunks: string[] = [];

                  const stderrChunks: string[] = [];

    

                  const rl = createInterface({ input: proc.stdout! });

                  rl.on("line", (line) => {

                    stdoutChunks.push(line);

                    onLine(line); // forward each line to Sandcastle

                  });

    

                  proc.stderr!.on("data", (chunk: Buffer) => {

                    stderrChunks.push(chunk.toString());

                  });

    

                  proc.on("error", (err) => reject(err));

                  proc.on("close", (code) => {

                    resolve({

                      stdout: stdoutChunks.join("\n"),

                      stderr: stderrChunks.join(""),

                      exitCode: code ?? 0,

                    });

                  });

                });

              }

    

              return new Promise((resolve, reject) => {

                execFile(

                  "sh",

                  ["-c", command],

                  { cwd: opts?.cwd ?? worktreePath, maxBuffer: 10 * 1024 * 1024 },

                  (error, stdout, stderr) => {

                    if (error && error.code === undefined) {

                      reject(new Error(`exec failed: ${error.message}`));

                    } else {

                      resolve({

                        stdout: stdout.toString(),

                        stderr: stderr.toString(),

                        exitCode: typeof error?.code === "number" ? error.code : 0,

                      });

                    }

                  },

                );

              });

            },

    

            copyFileIn: async (hostPath: string, sandboxPath: string) => {

              await fsMkdir(dirname(sandboxPath), { recursive: true });

              await fsCopyFile(hostPath, sandboxPath);

            },

    

            copyFileOut: async (sandboxPath: string, hostPath: string) => {

              await fsMkdir(dirname(hostPath), { recursive: true });

              await fsCopyFile(sandboxPath, hostPath);

            },

    

            close: async () => {

              // nothing to tear down for a local process

            },

          };

        },

      });

    隔离型（isolated）提供方示例

    一个使用临时目录的最小隔离型提供方：

    import {

      createIsolatedSandboxProvider,

      type IsolatedSandboxHandle,

      type ExecResult,

    } from "@ai-hero/sandcastle";

    import { execFile, spawn } from "node:child_process";

    import { copyFile, mkdir, mkdtemp, rm } from "node:fs/promises";

    import { tmpdir } from "node:os";

    import { dirname, join } from "node:path";

    import { createInterface } from "node:readline";

    

    const tempDir = () =>

      createIsolatedSandboxProvider({

        name: "temp-dir",

        create: async (): Promise<IsolatedSandboxHandle> => {

          const root = await mkdtemp(join(tmpdir(), "sandbox-"));

          const worktreePath = join(root, "workspace");

          await mkdir(worktreePath, { recursive: true });

    

          return {

            worktreePath,

    

            exec: (

              command: string,

              opts?: { onLine?: (line: string) => void; cwd?: string },

            ): Promise<ExecResult> => {

              if (opts?.onLine) {

                const onLine = opts.onLine;

                return new Promise((resolve, reject) => {

                  const proc = spawn("sh", ["-c", command], {

                    cwd: opts?.cwd ?? worktreePath,

                    stdio: ["ignore", "pipe", "pipe"],

                  });

    

                  const stdoutChunks: string[] = [];

                  const stderrChunks: string[] = [];

    

                  const rl = createInterface({ input: proc.stdout! });

                  rl.on("line", (line) => {

                    stdoutChunks.push(line);

                    onLine(line);

                  });

    

                  proc.stderr!.on("data", (chunk: Buffer) => {

                    stderrChunks.push(chunk.toString());

                  });

    

                  proc.on("error", (err) => reject(err));

                  proc.on("close", (code) => {

                    resolve({

                      stdout: stdoutChunks.join("\n"),

                      stderr: stderrChunks.join(""),

                      exitCode: code ?? 0,

                    });

                  });

                });

              }

    

              return new Promise((resolve, reject) => {

                execFile(

                  "sh",

                  ["-c", command],

                  { cwd: opts?.cwd ?? worktreePath, maxBuffer: 10 * 1024 * 1024 },

                  (error, stdout, stderr) => {

                    if (error && error.code === undefined) {

                      reject(new Error(`exec failed: ${error.message}`));

                    } else {

                      resolve({

                        stdout: stdout.toString(),

                        stderr: stderr.toString(),

                        exitCode: typeof error?.code === "number" ? error.code : 0,

                      });

                    }

                  },

                );

              });

            },

    

            copyIn: async (hostPath: string, sandboxPath: string) => {

              const info = await stat(hostPath);

              if (info.isDirectory()) {

                await cp(hostPath, sandboxPath, { recursive: true });

              } else {

                await mkdir(dirname(sandboxPath), { recursive: true });

                await copyFile(hostPath, sandboxPath);

              }

            },

    

            copyFileOut: async (sandboxPath: string, hostPath: string) => {

              await mkdir(dirname(hostPath), { recursive: true });

              await copyFile(sandboxPath, hostPath);

            },

    

            close: async () => {

              await rm(root, { recursive: true, force: true });

            },

          };

        },

      });

    分支策略

    分支策略控制智能体的提交落在哪里。在构造提供方时配置它：

    策略行为绑定挂载（bind-mount）隔离型（isolated）
    head智能体直接写入宿主机工作目录。不创建 worktree默认不适用
    merge-to-headS和castle 创建一条临时分支，完成后合并回 HEAD支持默认
    branch提交落在你显式指定的命名分支上支持支持

    各自的使用时机：

    • head ——开发期间快速迭代。没有分支间接层，也没有合并步骤。只适用于绑定挂载提供方，因为智能体需要直接访问宿主机文件系统。
    • merge-to-head ——自动化的安全默认值。智能体在一条用完即弃的分支上工作；出了问题 HEAD 也不受影响。CI 或无人值守运行请用它。
    • branch ——当你希望提交落在特定分支上时（例如为了发 PR）。传入 { type: "branch", branch: "agent/fix-42" }.

    分支策略现在配置在 run()上，而不是配置在提供方上：

    import { run, claudeCode } from "@ai-hero/sandcastle";

    import { docker } from "@ai-hero/sandcastle/sandboxes/docker";

    

    // head — direct write, bind-mount only (default for bind-mount providers)

    await run({

      agent: claudeCode("claude-opus-4-8"),

      sandbox: docker(),

      prompt: "…",

    });

    // merge-to-head — temp branch, merge back (default for isolated providers)

    await run({

      agent: claudeCode("claude-opus-4-8"),

      sandbox: tempDir(),

      prompt: "…",

    });

    // branch — explicit named branch

    await run({

      agent: claudeCode("claude-opus-4-8"),

      sandbox: docker(),

      branchStrategy: { type: "branch", branch: "agent/fix-42" },

      prompt: "…",

    });

    传入 run()

    把你的自定义提供方通过 sandbox 选项传入——它的用法与内置的 docker() 提供方完全相同：

    import { run, claudeCode } from "@ai-hero/sandcastle";

    

    const result = await run({

      agent: claudeCode("claude-opus-4-8"),

      sandbox: localProcess(), // your custom provider

      prompt: "Fix issue #42 in this repo.",

    });

    真实案例参见：
