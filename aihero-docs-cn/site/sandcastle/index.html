    Sandcastle

    一个用于在隔离沙箱中编排 AI 编码智能体的 TypeScript 库。

    GitHub 星标
    8,711
    每周 npm 下载量
    220,470
    开始使用在 GitHub 上查看
    $npm install --save-dev @ai-hero/sandcastle
    import { run, claudeCode } from "@ai-hero/sandcastle";

    import { docker } from "@ai-hero/sandcastle/sandboxes/docker";

    

    await run({

      agent: claudeCode("claude-opus-4-8"),

      sandbox: docker(), // or podman(), vercel(), or your own provider

      promptFile: ".sandcastle/prompt.md",

    });

    工作原理

    1. 1

      你只需用一个 sandcastle.run().

    2. 2

      Sandcastle 通过可配置的分支策略处理智能体的沙箱隔离。

    3. 3

      分支上产生的提交会被合并回来。

    分支策略

    沙箱提供方

    • Docker@ai-hero/sandcastle/sandboxes/docker绑定挂载（bind-mount）
    • Podman@ai-hero/sandcastle/sandboxes/podman绑定挂载（bind-mount）
    • Vercel@ai-hero/sandcastle/sandboxes/vercel隔离型（isolated）
    • 无沙箱（no-sandbox）@ai-hero/sandcastle/sandboxes/no-sandbox无
    • 自定义提供方沙箱能挂载宿主机目录时用绑定挂载（bind-mount）；沙箱拥有自己的文件系统时用隔离型（isolated）。

    文档

    从这里开始

    • 快速上手一个用于在隔离沙箱中编排 AI 编码智能体的 TypeScript 库。

    指南

    • 沙箱提供方Sandcastle 使用 SandboxProvider（沙箱提供方）创建隔离环境。
    • 工作原理Sandcastle 使用配置在沙箱提供方上的分支策略，控制智能体的改动与分支之间的关系。
    • 提示词Sandcastle 使用一套灵活的提示词系统。
    • 配置所有按仓库粒度的沙箱配置都存放在 .sandcastle/ 目录中。

    参考

    • APISandcastle 导出 run() 函数，可用于脚本、CI 流水线或自定义工具。
    • CLI 命令生成 .sandcastle/ 配置目录并构建容器镜像。
    • 自定义沙箱提供方Sandcastle 内置 Docker、Podman 与 Vercel 提供方，你也可以创建自己的提供方。
