    打造完美的 Claude Code 状态栏

    我打造了一个完美的 Claude Code 状态栏——包含 Git 信息和上下文用量。以下是分步指南。

    Matt Pocock
    本页内容

    • 亲手试试
    • 相关阅读

    我觉得自己打造出了完美的 Claude Code 状态栏：

    matt/course-video-manager | main | S: 0 | U: 1 | A: 0 | 17.3%

    首先，它会显示我当前工作的仓库，路径相对于我的仓库目录（matt/course-video-manager）。如果你和我一样，可能也是把所有仓库都放在同一个目录里。

    所以我在状态栏里把它设置成只显示相对于我 ~repos/ 目录的相对路径。

    然后是 Git 信息：

    main | S: 0 | U: 1 | A: 0

    包括我所在的分支，以及已暂存（staged）、未暂存（unstaged）和新增（added）的变更。这部分算可选，但我很喜欢它：当我只在终端里工作、不用 IDE 时，能随时看到 Git 里正在发生什么。

    最后一点，也是最重要的一点，是本次会话中已使用的 上下文窗口（context window） 占比：

    17.3%

    这一点始终让我提心吊胆。我总是想把上下文用量压到最低，因为塞进上下文窗口的东西越多，AI 的表现就越差。

    随时能一眼看到这个数字，盯着它心想“哦，到 60 左右大概就该停了”，这种感觉真是太好了。

    Claude Code 状态栏应该显示什么？

    一个有用的 Claude Code 状态栏，应该在你决定下一步做什么之前，把需要的事实摆在你眼前。

    对我而言，这意味着：

    • 我当前在哪个仓库
    • 我当前在哪个 Git 分支上
    • 有没有已暂存或未暂存的变更
    • 本次会话用掉了多少上下文窗口

    仓库和 Git 状态能帮我避免在错误的地方干活。上下文百分比则帮我决定何时继续、何时压缩（compaction），或者交接给一个全新的会话。

    具体格式并不重要，重要的是让这些关键信号一目了然，而不必让 Claude Code 再花一轮去检查它们。

    配置方式

    配置方式是使用 settings.json 文件，它位于 .claude 目录：

    {

      "hooks": {}

    可以看到，它会运行 bash ~/.claude/statusline-wrapper.sh。这个状态栏包装脚本本质上就是执行一个状态栏命令脚本。

    然后我们还会获取一个名为 ccStatusLine的 CLI 的输出，借助它拿到上下文百分比：

    {

      "version": 3,

      "lines": [

        [

          {

            "id": "1",

            "type": "context-percentage",

            "color": "yellow",

            "bold": true,

            "rawValue": true

          }

    然后把这几个输出拼接在一起。

    亲手试试

    如果你想自己配置，下面是具体步骤。

    第 1 步：安装 ccstatusline

    首先，全局安装 ccstatusline 包：

    npm install -g ccstatusline

    第 2 步：配置 ccstatusline

    在如下位置创建配置文件： ~/.config/ccstatusline/settings.json:

    {

      "version": 3,

      "lines": [

        [

          {

            "id": "1",

            "type": "context-percentage",

            "color": "yellow",

            "bold": true,

            "rawValue": true

          }

        ],

        [],

        []

      ],

      "flexMode": "full-minus-40",

      "compactThreshold": 60,

      "colorLevel": 2,

      "inheritSeparatorColors": false,

      "globalBold": false,

      "powerline": {

        "enabled": false,

        "separators": [""],

        "separatorInvertBackground": [

          false

        ],

        "startCaps": [],

        "endCaps": [],

        "autoAlign": false

      }

    }

    这里的关键是 "rawValue": true ，它只显示百分比数字、不带“Ctx:”标签；然后是 "bold": true ，用来与 Git 数字的配色保持一致。

    第 3 步：创建 Git 状态脚本

    创建 ~/.claude/statusline-command.sh:

    #!/bin/bash

    

    # Read JSON input

    input=$(cat)

    

    # Extract values from JSON (without jq)

    cwd=$(echo "$input" | sed -n 's/.*"current_dir":"\([^"]*\)".*/\1/p')

    

    # Git information (skip optional locks for performance)

    if git -C "$cwd" rev-parse --git-dir > /dev/null 2>&1; then

      # Get repo name relative to ~/repos/

      repo_name=$(echo "$cwd" | sed "s|^$HOME/repos/||")

    

      # Get branch

      branch=$(git -C "$cwd" --no-optional-locks rev-parse --abbrev-ref HEAD 2>/dev/null)

    

      # Count staged files

      staged=$(git -C "$cwd" --no-optional-locks diff --cached --name-only 2>/dev/null | wc -l)

    

      # Count unstaged files (modified + deleted, not untracked)

      unstaged=$(git -C "$cwd" --no-optional-locks diff --name-only 2>/dev/null | wc -l)

    

      # Count untracked files

      untracked=$(git -C "$cwd" --no-optional-locks ls-files --others --exclude-standard 2>/dev/null | wc -l)

    

      printf '\033[01;36m%s\033[00m | \033[01;32m%s\033[00m | S: \033[01;33m%s\033[00m | U: \033[01;33m%s\033[00m | A: \033[01;33m%s\033[00m' \

        "$repo_name" "$branch" "$staged" "$unstaged" "$untracked"

    else

      # Not a git repo

      printf '\033[01;36m%s\033[00m' "$cwd"

    fi

    注意： 请修改 ~/repos/ （第 12 行），如果你的仓库放在其他目录的话。

    第 4 步：创建包装脚本

    创建 ~/.claude/statusline-wrapper.sh:

    #!/bin/bash

    

    # Read JSON input once

    input=$(cat)

    

    # Get git info from existing script

    git_info=$(echo "$input" | bash ~/.claude/statusline-command.sh)

    

    # Get context percentage from ccstatusline

    context_pct=$(echo "$input" | npx ccstatusline)

    

    # Combine outputs

    printf '%s | %s' "$git_info" "$context_pct"

    第 5 步：让脚本可执行

    chmod +x ~/.claude/statusline-command.sh

    chmod +x ~/.claude/statusline-wrapper.sh

    第 6 步：更新 Claude 设置

    把下面这段加进你的 ~/.claude/settings.json:

    {

      "statusLine": {

        "type": "command",

        "command": "bash ~/.claude/statusline-wrapper.sh"

      }

    }

    第 7 步：重启 Claude Code

    重启 Claude Code，就能看到新状态栏生效了！
