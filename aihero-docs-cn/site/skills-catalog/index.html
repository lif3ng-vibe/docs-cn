    真正工程师的 AI 技能

    一套实用的技能体系，让工程师用上 AI 而不放弃自己的标准。

    开始第 1 课 代码
    Matt Pocock

    这些是我每天都要用的智能体技能。它们存放在我的 ~/.claude 目录里，并以公开仓库的形式发布，任何人都可以安装它们、fork 它们，或用自己的技能开一个 PR。

    什么是技能（skill）？

    技能（skill）是一段智能体可以运行的、聚焦且可复用的工作流。它把一套清晰的指令、所需的输入和可预期的输出打包在一起。技能以小小的 markdown 文件存在，任何兼容 Claude 的智能体都能识别。

    关键不是给智能体套上脚手架，而是把我面对某个问题时的确切做法写下来，让智能体每次都照我本人的方式执行。

    安装

    一条命令就能把整个目录拉进你的全局技能目录：

    npx skills add mattpocock/skills -y -g

    去掉 -g 即可只安装到当前项目。装好之后，任何会读取 ~/.claude/skills （Claude 代码 是最典型的一个）的智能体，都能从目录里挑一个技能来运行。

    不想装全套，也可以只装单个技能。去源码里浏览各个技能的 slug： github.com/mattpocock/skills.

    我怎么用它们

    下面的每个技能都对应我会伸手去用的一个具体时刻：一段要盘问的模糊规格、一个要建模的领域、一份要写的 PRD、一堆要拆解的工单、一个要测试驱动的功能。它们不是“AI 效率小技巧”，而是智能体干活的同时、我用来保住自己品味与标准的方法。

    开源

    目录放在 github.com/mattpocock/skills。如果你打磨出了一个在你的工作流里站稳脚跟的技能，欢迎分享出来。
