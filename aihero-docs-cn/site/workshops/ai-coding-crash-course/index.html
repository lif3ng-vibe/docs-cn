    AI 编码速成课

    用软件工程基本功掌控你的代码，以前所未有的速度交付。

    Matt Pocock

    我们都见识过 AI 编码是如何出岔子的： 上手比以往任何时候都容易，但之后便一路走下坡。

    新建一个项目的感觉如同 魔法；但当你打磨想法、修 bug、加功能时，智能体糟糕的代码决策会迅速累积，每次改动都来得更慢、更糟。

    把小任务外包出去感觉 威力十足 ，甚至很有趣；但任务一旦更大、更复杂、耗时更长，就会像雪球一样越滚越大，超出你的掌控。

    最糟糕的是，智能体永远不知疲倦，而你却比以往任何时候都更心力交瘁。机器人堆代码的速度远超你的审查速度，这意味着你得花更多时间去接受、监督、下达指令和反复解释，留给令人满足的创造性工作的时间反而更少。

    在整个过程中，你几乎能真切地感到掌控感正在一点点溜走，一次提示词就溜走一分。

    也许这已经发生在你身上。又也许你还没尝试过，正是因为担心会这样。

    无论如何，这都不是你入行时想做的工作。一定有更好的办法。

    好消息是： 更好的办法，确实存在。

    我全新的 AI 编码速成课 将把掌控权交回你的手中——通过学习、分析，以及最重要的， 动手构建 ，而这一切都建立在对这些工具工作原理更深理解的基础上。

    Matt Pocock 是一位真正的教育者，我很佩服他能为我们身处的这团乱麻带来秩序。

    Mario Zechner（@badlogicgames），Pi coding harness 的创作者

    想从编码智能体那里拿到出色的结果，最好的办法就是把它的运作方式从头到尾学个透：

    1. 大语言模型（LLM）是如何工作的？
    2. harness 是如何工作的——无论是 Claude Code、Codex，还是其他任何一种？
    3. 如何把这些知识结合起来，构建一个高效、可重复的软件工程循环？

    到这门自学制速成课结课时，你将能凭借亲身实践，独立回答所有这些问题。

    哪怕你此前从未用过编码智能体。哪怕你此前从未写过软件。

    这不是一门“氛围编程（vibe coding）”课程。 这是一套从零打基础的方法，教你如何从编码智能体手里拿到最佳结果，让你能用真正的工程（Real Engineering）原则构建高质量、可上生产的软件。

    像真正的工程师（Real Engineer）一样掌控你的编码智能体

    我的 AI 编码方法把经典的真正工程原则与一套循序渐进的过程结合起来，深入理解工具、技术与工作流的方方面面。我们会一起把这些理解化为练习，始终守住质量与一致性的高标准。

    以下只是你将学到的一部分内容：

    • 聪明区 / 笨区（smart zone / dumb zone） ——什么是上下文窗口（context window）、它为什么重要、如何辨别智能体何时还在敏锐推理、何时上下文已然退化，以及如何让你的工作留在聪明区。
    • 管理上下文 ——究竟是什么在吃掉智能体的上下文、它为什么会满、如何保持精简，以及如何读取确切状态而不是靠猜。
    • 压缩（compaction）还是交接（handoff） ——上下文满了之后继续推进的三种方式、各自适用的时机，以及为什么任务中途压缩容易出岔子。
    • 追问（grilling） ——如何拉上你的智能体一起，把一个模糊的想法盘问到底，直到项目需求变得清晰锐利——而这一切都发生在写下第一行代码之前。
    • 代码库探索 ——如何帮助你的智能体理解现有代码库，让它复用已有的代码，而不是重复发明、写了又写。
    • AGENTS.md ——如何用好这份引导智能体在整个项目中行为的指令文件，以及里面真正该放些什么。
    • 技能 ——如何把可复用的指令做成模式与包（package）来创建和部署，让智能体按需取用，以及如何从自己反复使用的提示词与工作流中写出自己的技能。
    • 渐进披露（progressive disclosure） ——把这些指令文件组织得井井有条，让智能体只加载需要的内容，保持上下文精简。
    • 清清楚楚的需求 ——如何把一场追问会话（grilling session）变成一份智能体可以照着构建的清晰规格（spec），交付你真正想要的结果。
    • 把复杂工作拆解成会话大小的块 ——如何把大项目拆成智能体能逐个执行的阶段，以及如何（何时）新建会话。
    • 交接（handoff） ——如何为你的智能体留下一路面包屑，让你和它都能从上次中断的地方精确续接——无论是下一小时，还是下一周。
    • 子智能体（subagent） ——如何把探索等任务委派给拥有全新上下文的“子”会话，让你的主会话保持敏锐——全程无需在多个终端窗口之间手忙脚乱。

    以上这些概念以及更多内容，都可以学习和练习。你可以在几天里一鼓作气跑完全程，也可以摊开来，配合你生活的日程和节奏。

    从“发了就祈祷”到一套值得信赖的好结果流程

    你会从必须掌握的核心概念起步，学会像老手一样驾驭 harness（比如 Claude Code 命令行界面）。

    你会学到如何清晰地给智能体指定要执行的工作——确保你构建的是正确的东西——以及如何执行代码质量标准，让你的代码库日后易于扩展。

    到最后，你将能接手单个提示词装不下的大工作，并且在做的过程中始终保持对代码库的掌控。

    常见问题

    这是自学制还是直播授课？

    自学制。按自己的日程、在自己的代码库里推进，技能有更新时随时回来重温。

    需要某个特定的 AI 编码工具吗？

    这些技能就是 markdown，任何兼容 Claude 的智能体都能读取（Claude Code 显而易见是其中之一）。而这种 实践 可以迁移到任何有能力的智能体——工作流才是耐久的部分，工具不是。

    我是智能体编码新手，能跟上吗？

    能。你需要的是好奇心和动手构建的意愿，而不是 AI 专家背景。每节课都小到可以一口气学完，整套方法也是一块一块逐层搭建起来的。
