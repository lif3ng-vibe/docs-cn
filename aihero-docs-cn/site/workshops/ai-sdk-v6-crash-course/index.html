    用 TypeScript 交付现代 LLM 功能的入场券

    你现有的 TypeScript 技能比以往任何时候都更值钱，而我正是来帮你升级为 AI 工程师的。

    我的全新 AI SDK v6 速成课包含 94 个视频 ，引导你完成 59 个动手练习 ，分布在 10 个模块。（别担心，它们有趣又利落！）

    学完之后，你将对以下内容有扎实的理解：

    • LLM 基础，比如 token 和上下文窗口（context window） 究竟 是如何运作的
    • 核心 LLM 设计模式：智能体（agent）、工作流、工具调用等等
    • 生产就绪的工具 ，比如遥测埋点（instrumentation）与错误处理
    • 如何运用 评测驱动开发（Eval-Driven-Development） 来杜绝幻觉
    • 当然，还有…… 如何充分释放 AI SDK v6 的威力 来把这些事统统做成

    没错：你可以从“ 究竟 什么是 token？？”一路进阶到交付生产就绪的 LLM 功能 是如何运作的，配上输出防护、消息持久化与错误处理。

    你 你 唯一需要带来的就是 TypeScript。其他你需要的一切都已包含在内。

    而且这门速成课并 不是 一堂让你干坐着、苦苦集中注意力的讲授课。你了解我的，我们可不这么玩！

    你将通过 动手构建 真实项目来学习：

    • A 聊天标题生成器，附带完整的评测（eval）数据集
    • A 生成器/评估器工作流 ，能替你撰写 Slack 消息并自动打磨
    • A 模型护栏（guardrail） ，为你的应用保驾护航
    • A 请求路由器 ，可以把简单请求路由给更便宜的 LLM
    • 一个功能完备的 调研智能体 ，替你搜索网络

    简而言之，你将有能力为你的 TypeScript 应用规划、开发并上线生产就绪的 AI 功能。

    别担心：你学到的会非常多，但每个视频都短小精悍，只有 2-3 分钟，许多练习也是一小口就能完成的量！任何日程都安排得下，哪怕是你的。

    顺便一提，如果你一直在用“老式办法”构建 AI 集成（抱歉啦）？这正是更新技能组合的绝佳时机。你将学到 AI SDK 的全部核心功能，以及这些 v5 新特性： ModelMessages 又 UIMessages、自定义数据部件（custom data parts）、从后端到前端的类型安全工具（对我们这些 TypeScript 迷是大利好），以及优雅得多的 parts 数组，用于消息渲染与持久化。

    而在这次更新中，我们还会讲到破坏性变更与 v6 新特性，比如通过 streamText!

    当然，技术与 AI SDK 本身还会持续演进、不断改进。但只要你修完这套动手实操、贴近真实、构建工具的经验，你就能与它一同成长进步。

    AI SDK 库的下载量之所以飙升到 350 万 次每周，是有原因的：

    • AI SDK 是一套完全开源的应用工具箱。你可以复制、修改、fork 它，甚至按自己的意愿重新打包、重新授权，这要归功于非常宽松的 Apache 2.0 许可证.
    • 它能与所有框架集成。它面向 TypeScript 和 JavaScript，为每个主流前端框架都提供了一套 hooks（甚至为原生 Vanilla JS 也提供了抽象）。
    • 它几乎能与所有 LLM 协作，包括能跑在你自己硬件上的开源模型。 不骗你—— 去看看支持的提供商列表吧.
    • 它让你只需 1 行代码就能切换模型。 因为 AI SDK 为你提供了 面向所有 LLM 的统一接口，切换模型或提供商就像改配置一样简单。你还可以在同一个代码库里使用多个模型，全部使用统一的命令。无论生态将来怎么变，你都准备好了。
    • 它让遥测埋点变得简单。 你可以省去为可观测性手写埋点的苦差事，因为 AI SDK 能自动把 OpenTelemetry 导出到所有主流平台。
    • 它随处可跑。AI SDK 完全不挑平台。Deno 能跑，Bun 能跑，Node 也能跑。AI SDK 出自 Vercel 之手，但你尽可随意选择。
    • 它正在收获广泛的生态支持。 AI SDK 实在太受欢迎（每周 300 万次下载），以至于 Langfuse, Braintrust 等平台都已经构建了与之集成的 hooks。我预计还会有更多。

    这一切加起来，就是省下的时间、精力、金钱和麻烦——更多自由、更多乐趣，还有更多时间去做 令人兴奋的 AI 功能.

    AI SDK v6 让 LLM 应用变得和应用开发的其他部分一样现代。终于等到了！
