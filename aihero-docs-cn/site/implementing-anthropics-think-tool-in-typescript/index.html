    用 TypeScript 实现 Anthropic 的“think”工具

    在 TypeScript 中配合 Claude 实现 Anthropic 的“think”工具，增强 LLM 解决问题的能力。

    Matt Pocock
    源代码
    本页内容
    • 提示词
    • 工具
    • 结语

    Anthropic 刚刚发布了一些 新研究 ，介绍了一种简单技巧，可以帮助 Claude（多半也包括其他 LLM）应对需要复杂问题解决能力的任务。

    很简单——你给 LLM 提供一个它可以调用的“think”工具。

    （想知道工具是什么？看看 这份指南.)

    理论上，这个工具的价值在于让 LLM 在做决定之前有片刻思考时间。它为模型提供了一种结构化的方式，在继续之前复盘手头的信息。

    这让 LLM 能把重要信息存进上下文，供之后做出更好的决策。它与 ReAct、Reflexion 这些耳熟能详的概念遥相呼应。

    我们来试着实现它。

    提示词

    我们先抽出一个 description 变量，它将作为工具的描述：

    const description = `

    Use the tool to think about something.

    It will not obtain new information or change the

    database, but just append the thought to the log.

    Use it when complex reasoning or some cache memory

    is needed.`;

    这段文字取自 Anthropic 的文章。

    就这么简单！我们在 Claude 3.7 Sonnet 里实现了“think”工具。

    这是在特定情况下非常实用的技巧。Anthropic 建议将它用于“需要在长链条的工具调用中保持策略遵循与推理的复杂任务”。只需几行代码就能为你的 LLM 实现带来有意义的提升。
