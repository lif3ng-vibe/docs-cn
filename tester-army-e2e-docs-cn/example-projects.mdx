每个示例都是一个独立的问候应用，带三个 locator 测试和两个智能体测试。输入
名字、按下 Greet、检查结果。这些项目从 npm 安装已发布的 e2e 包，在本仓库
之外也能使用。

安装、构建和运行命令请看各自项目的 README。配置和测试文件与应用放在一起；
SwiftUI、Jetpack Compose、Kotlin Multiplatform 和 Flutter 项目把它们放在
`e2e/` 目录中。

locator 测试不需要模型。设置 `AI_GATEWAY_API_KEY` 才能运行智能体测试；没有
它这些测试会跳过。模型配置见 [Models](/models)，把自己的应用接入 e2e 见
[Quickstart](/quickstart)。
