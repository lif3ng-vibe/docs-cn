`@e2e-dev/mobile` 用你正常的 debug 或 release 构建驱动模拟器或仿真器，不需要 Detox framework。React Native 的 `testID` 属性在两个平台上都能配合 `getByTestId` 使用。

按[移动端指南](/mobile)配置 target，按[快速上手](/quickstart)配置模型。一次迁移一个 spec 时，各个 runner 可以共用同一台模拟器。

## 配置

| Detox (`.detoxrc.js`) | e2e |
| --- | --- |
| `apps.<name>.binaryPath` | target 上的 `app: { appPath }`，外加 fixture 中每个设备一次 `device.installApp()`；引擎自身什么也不安装 |
| `apps.<name>.bundleId` | target 上的 `app: { bundleId: 'com.example.app' }`，即 `app.open()` 启动的 app |
| `devices.<name>.device.type` | `mobile({ device: 'iPhone 17' })` |
| `configurations` | `targets`，每个平台一个引擎 |
| Jest 配置, `maxWorkers` | `workers`，每个设备一个 |
| `detox build` | 你正常的构建。没有 Detox framework，也没有 `detox build` 步骤 |
| `device.launchApp({ permissions })` | target 上的 `app.permissions`，每次全新启动前都会设置；或对单次授权用 `device.openApp(app, { relaunch: true, permissions })`；`grant`、`deny`、`reset` 对应 `YES`、`NO`、`unset` |
| `device.launchApp({ launchArgs })` | target 上的 `app.launchArguments`，或单次用 `device.openApp(app, { relaunch: true, launchArguments })`；是平台启动命令接受的一串字符串，不是映射表 |

```ts title="e2e.config.ts"
import type { E2EConfig } from 'e2e';
import { mobile } from '@e2e-dev/mobile';

export default {
  targets: [
    {
      name: 'ios',
      engine: mobile({ platform: 'ios' }),
      app: { bundleId: 'com.example.app', appPath: 'ios/build/MyApp.app' },
    },
    {
      name: 'android',
      engine: mobile({ platform: 'android' }),
      app: { bundleId: 'com.example.app', appPath: 'android/app/build/outputs/apk/debug/app-debug.apk' },
    },
  ],
  workers: 1,
} satisfies E2EConfig;
```

## 改写前后的测试

```js title="Detox"
describe('login', () => {
  beforeAll(async () => { await device.launchApp({ newInstance: true }); });

  it('shows the home screen', async () => {
    await element(by.id('email')).typeText('ada@example.test');
    await element(by.id('password')).typeText('hunter2');
    await element(by.text('Sign in')).tap();
    await waitFor(element(by.id('home'))).toBeVisible().withTimeout(10000);
    await expect(element(by.text('Welcome, Ada'))).toBeVisible();
  });
});
```

```ts title="e2e"
import { test } from '@e2e-dev/mobile';
import { expect, credentials } from 'e2e';

test('shows the home screen', async ({ agent, app, screen }) => {
  await app.open();
  const ada = credentials.user('ada');
  await agent.act('sign in as {username}', { params: { username: ada.username, password: ada.password } });
  await expect(screen.getByTestId('home')).toBeVisible({ timeout: 10_000 });
  await expect(screen.getByText('Welcome, Ada')).toBeVisible();
});
```

`app.open()` 全新启动所配置的 app；没有任何东西会自行启动。密码来自[配置好的凭据](/authentication)。

## API 对照表

| Detox | e2e |
| --- | --- |
| `by.id('x')` | `screen.getByTestId('x')` |
| `by.text('t')` | `screen.getByText('t')` |
| `by.label('l')` | `screen.getByLabel('l')` |
| `by.type('RCTImageView')` | `device.locator('role=Image')`，agent-device 的选择器语法 |
| `by.id('x').withAncestor(by.id('row'))` | `screen.getByTestId('row').getByTestId('x')` |
| `.atIndex(n)` | `.nth(n)` |
| `.tap()`, `.multiTap(2)`, `.longPress()` | `.tap()`, `.doubleTap()`, `.longPress()` |
| `.tap({ x, y })` | `.tap({ position: { x, y } })` |
| `.typeText(t)`, `.replaceText(t)` | `.fill(t)`，会替换全部内容 |
| `.clearText()` | `.clear()` |
| `.tapReturnKey()` | `.press('Enter')` |
| `.swipe('up', 'fast')` | `.swipe({ direction: 'down', momentum: 'fast' })`：Detox 按手指移动的方向命名，e2e 按内容滚动的方向命名 |
| `.scroll(200, 'down')` | `screen.swipe({ direction: 'down' })` |
| `waitFor(el).toBeVisible().whileElement(list).scroll(...)` | `screen.scrollUntilVisible(el)` |
| `waitFor(el).toBeVisible().withTimeout(ms)` | `await expect(el).toBeVisible({ timeout: ms })` |
| `expect(el).toBeVisible()`, `.toExist()` | 可见性用 `.toBeVisible()`；存在性用 `.toHaveCount(1)` |
| `expect(el).not.toBeVisible()` | `.toBeHidden()` |
| `expect(el).toHaveText(t)` | `.toHaveText(t)` |
| `expect(el).toHaveToggleValue(true)` | `.toBeChecked()` |
| `expect(el).toHaveValue(v)` | `.toHaveValue(v)` |
| `device.launchApp({ newInstance: true })` | `app.restart()` |
| `device.launchApp({ delete: true })` | `app.clearState()` |
| `device.reloadReactNative()` | 无对应物。`app.restart()` 最接近 |
| `device.sendToHome()`, `device.pressBack()` | `device.home()`, `device.back()` |
| `device.setLocation(lat, lon)` | `device.setLocation({ latitude, longitude })` |
| `device.setOrientation('landscape')` | `device.setOrientation('landscape-left')` |
| `device.setBiometricEnrollment(true)` | `device.enrollBiometrics('faceid', true)` |
| `device.matchFace()`, `device.unmatchFace()` | `device.setBiometrics('faceid', 'match' \| 'nonmatch')` |
| `device.setStatusBar`, `device.setURLBlacklist` | 无对应物 |
| `device.disableSynchronization()` | 无对应物。e2e 依靠动作等待和重试断言撑过等待。 |
| `device.takeScreenshot()` | `app.screenshot('label')`，受机密策略约束 |
| 测试名中的 `:ios:` / `:android:` | 测试上的 `{ platforms: ['ios'] }` |

行为与 Detox 不同之处：

- 动作和单节点读取或断言要求恰好一个匹配；匹配到多个即报 `LOCATOR_AMBIGUOUS` 失败。用 `.filter()`、`.first()` 或 `.nth()` 收窄，见 [screen](/reference/screen)。
- 设备上没有 `test.setup` 或 `{ session }`，见[与 web 的差异](/mobile#与-web-的差异)。

`by.text` 在 Detox 中是精确匹配，这里的 `getByText` 同样是精确匹配。

## 优先迁移什么

从需要频繁维护的流程开始。如果它的界面需要时间才能稳定，可配置引擎的 [`settle` 和 `transition` 选项](/reference/mobile#引擎)。
