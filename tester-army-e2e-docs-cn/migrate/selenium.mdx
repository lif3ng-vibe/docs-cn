e2e 测试使用 TypeScript、基于角色和 label 的定位器，以及会一直重试直到通过或超时的断言。Java 或 Python 套件需要重写。迁移期间可以两套并行，一次只移一个流程。

按[快速上手](/quickstart)安装 e2e。只有智能体调用才需要模型；下面基于定位器的示例没有模型也能跑。

## 配置

| Selenium | e2e |
| --- | --- |
| 每个 `driver.get` 里的 URL | target 上的 `app: { url }`，之后用相对路径 |
| 用脚本启动 app | `app: { url, command }`，见[启动你的应用](/web#启动你的应用) |
| 每种浏览器一个 driver | 每种浏览器一个 target，`web({ browser: 'firefox' })` |
| Selenium Grid | 并行用 `workers`；`connect` 可经 CDP 挂上远程 Chromium，而 [Kernel](/integrations/kernel) 这类[浏览器提供者](/browser#托管浏览器)可租用托管浏览器 |
| `manage().window().setSize` | `web({ viewport })` |
| 隐式等待 | `actionTimeout` 与 `assertionTimeout`，分别为动作和断言设定期限 |
| 用于登录的页面对象 | `test.setup` 与 `{ session }`，见[登录](/authentication) |

## 改写前后的测试

```java title="Selenium"
driver.get("http://localhost:3000/login");
WebDriverWait wait = new WebDriverWait(driver, Duration.ofSeconds(10));
wait.until(visibilityOfElementLocated(By.id("username"))).sendKeys("admin@example.test");
driver.findElement(By.id("password")).sendKeys(System.getenv("ADMIN_PASSWORD"));
driver.findElement(By.xpath("//button[contains(., 'Sign in')]")).click();
wait.until(urlContains("/dashboard"));
assertEquals("Welcome back, admin!",
    driver.findElement(By.cssSelector(".greeting")).getText());
```

```ts title="e2e"
import { test } from '@e2e-dev/web';
import { expect, credentials } from 'e2e';

test('signs in', async ({ app, screen, browser }) => {
  const admin = credentials.user('admin');
  await app.open('/login');
  await screen.getByLabel('Username').fill(admin.username);
  await screen.getByLabel('Password').fill(admin.password);
  await screen.getByRole('button', 'Sign in').tap();
  await expect(browser).toHaveURL('/dashboard');
  await expect(screen.getByRole('status')).toHaveText('Welcome back, admin!');
});
```

定位器动作会等待目标出现，断言会自动重试。密码来自[配置好的凭据](/authentication)。也可以用 `agent.act`，从一个目标让智能体完成登录。

## API 对照表

| Selenium | e2e |
| --- | --- |
| `driver.get(url)` | `app.open(path)` |
| `driver.navigate().back()`, `.refresh()` | `app.back()`, `browser.reload()` |
| `By.id('x')` | `browser.locator('#x')`；或配 `web({ testIdAttribute: 'id' })` 后用 `screen.getByTestId('x')` |
| `By.name('x')` | `browser.locator('[name="x"]')`，不可移植；优先用角色或 label |
| `By.linkText`, `By.partialLinkText` | `screen.getByRole('link', { name })`，`name: /part/` |
| `By.cssSelector`, `By.xpath` | `browser.locator('css or xpath')`，不可移植 |
| `findElements(...).size()` | `await locator.count()` |
| `findElements(...).get(n)` | `locator.nth(n)` |
| `.click()` | `.tap()` |
| `.sendKeys('text')` | `.fill('text')`，会替换全部内容 |
| `.sendKeys(Keys.ENTER)` | `.press('Enter')` |
| `.clear()` | `.clear()` |
| `new Select(el).selectByVisibleText` | `.selectOption({ label })` |
| `.getText()`, `.getAttribute()`, `.isDisplayed()` | `.textContent()`, `.getAttribute()`, `.isVisible()`，不会重试 |
| `wait.until(visibilityOf(...))` | `await expect(locator).toBeVisible()` |
| `wait.until(textToBe(...))` | `await expect(locator).toHaveText(...)` |
| `wait.until(urlContains(...))` | `await expect(browser).toHaveURL(/.../)` |
| `Actions.moveToElement` | `.hover()` |
| `Actions.dragAndDrop` | `.dragTo(target)` |
| `Actions.keyDown(CONTROL).sendKeys('a')` | `.press('ControlOrMeta+a')` |
| `switchTo().frame()` | `browser.frameLocator('#frame')` |
| `switchTo().alert().accept()` | 在动作之前先调 `browser.onDialog('accept')` |
| `switchTo().window()` | 无对应物。不支持弹窗 |
| `executeScript` | `browser.evaluate` |
| `manage().addCookie` | `browser.setCookies` |
| `getScreenshotAs` | `app.screenshot('label')`，已脱敏 |
| `Thread.sleep` | 对所需条件用定位器断言 |
| 页面对象 | 来自 `test.extend` 的 fixture，或一个 `agent.act` 目标 |

行为与 WebDriver 不同之处：

- `findElement` 返回第一个匹配；e2e 则报 `LOCATOR_AMBIGUOUS` 失败。用 `.filter()`、`.first()` 或 `.nth()` 收窄，见 [screen](/reference/screen)。
- `textContent()` 只读一次、不重试。要用会轮询至期限为止的 `toHaveText()` 来断言。

## 优先迁移什么

从单个页面对象及其使用方流程开始；它的 setup 代码可以变成 fixture。
